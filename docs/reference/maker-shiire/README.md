## なぜリポジトリに置かないのか

**このリポジトリは PUBLIC です。** さらに `.claude/scripts/github-sync.sh` が30分ごとに `git add -A` → push するため、
置いた時点で自動的に全世界へ公開されます。

第三者が作った資料の原本をここに置くと、**当社が権利を持たないものを再配布する**ことになります。
実際、`パーフェクトマニュアルサンプル_EC-STARs-Lab.pdf` は**2026-06-09 から78日間、誰でもダウンロードできる状態**でした
（原本は権利者のブログでパスワード保護された登録者限定特典として配布されているもので、当社の公開はその対価の壁を外す行為にあたります）。

**線引きはシンプルです。**

- **リポジトリに置いてよい** … 当社が読んで書いた要約・気づき・判断
- **置かない** … 原本そのもの、逐語再現、丸写し
