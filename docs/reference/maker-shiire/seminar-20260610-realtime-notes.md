## 1. メーカー仕入れビジネスとは（序章）

**商流の比較（スライド 10:15）**
- メーカー仕入れ: メーカー →（直接卸）→ 小売業者（自分=Amazon出品）→ 消費者。中間マージンなし
- 一般流通: メーカー → 卸業者 → 小売業者 → 消費者
- せどり/転売: メーカー → 卸 → 小売 → 転売業者（Amazon）→ 消費者（小売→小売の二重流通）

**せどりとの違い**
- せどりは毎回リサーチが必要で利益が不安定。メーカー仕入れは一度取引が決まればリピート発注可能
- 発注は自分でコントロールでき、月2回程度の発注作業で運用可能
- 実例: ご当地ラーメン詰め合わせ、月96セット販売、月利約14.2万円、利益率26%

**5つのメリット**: ①直取引による最安値仕入れ ②何度でもリピート ③アカウント安全性（メーカー書類完備でクレーム・規制対応可）④独占・限定化による利益保護 ⑤社会的信頼

**3つの不安への回答**
- 資金: 小額から取引できるメーカーが多い（例: 月4万円で100個）。基本は現金取引・自己資金内で構築を推奨
- 個人で相手にされる？: コンサル生の9割以上が個人。法人必須は少数派
- ライバル増？: 限定化・独占化で防げる。受講1年後に利益50万以上が50%超。メーカーの担当者交代で再チャンスもある

**Q&Aより**
- メーカーがAmazonで自社販売しない理由: 中小は人手不足、B2C個別販売は費用対効果が悪い。「作る」特化で「売る」が苦手。ロット卸の方が見通しが立つ
- AIの影響: メーカーとのコミュニケーションは代替不可（営業代行500件ゼロ成約 vs 直接電話1件で成約の実例）。書類作成等の効率化には有効
- 販路: Amazonがメイン。楽天は初期費用・広告費が高く初心者非推奨
- 直接訪問: 会った方が良い（実施者は1割未満だが限定化につながる）

## 2. 第1章: ゼロから成果を上げる4ステップ

ステップ = ①リサーチ → ②問い合わせ → ③仕入れ判断 → ④管理

### ① リサーチ基準（3つ）
1. Amazon本体が出品していない
2. 売れ筋ランキング5万位以内
3. FBAライバルセラー2人以上（上限なし）
   - 1人 = OEM・メーカー直販のため取引不可（スライド 10:56）
   - 売れやすさは「①回転数(需要) ②出品者数(供給) ③カート獲得(選択)」の3要素。出品者数の上限は大きな問題ではなく、カート獲得が重要KPI
- ツールは **Keepa のみ**（月額約5,000円/29ユーロ）。「製品ファインダー」で3条件をフィルタ。酒類（免許要）等のサブカテゴリ除外も活用

### ② 問い合わせ
- **会社概要資料**を作り込んで送る（スライド 11:10）: 基本情報（顔写真があるとベスト）＋取引希望理由・事業への思い＋事業内容
- **肩書きは不要**（スライド 11:13）。重要なのは5つの心構え: 1.会社概要の作り込み 2.丁寧な対応 3.FAX・電話を使う 4.断られたら理由を聞く 5.利益が出ないなら条件を聞く
- （社長メモ: 「ホームページを作った方がいい」→ 会社概要URLでの認知獲得に対応）

### ③ 仕入れ判断
- **経費割合35%** だけ知っておけば概算可能（スライド 11:20 実例）:
  - 販売価格1,980円 − 販売手数料218円 − FBA送料434円 − 納品送料30円 − 商品代金1,188円 = **利益110円**
- **キーゾン**（Keepa連携Chrome拡張）で月間販売数を数字で確認（スライド 11:21）

### ④ 管理
- **必要資金の考え方**（スライド 11:28）: 1ヶ月ぴったりの在庫はNG（売れ残り/欠品の双方が損失）→ **1.2〜1.5倍の在庫**が必要
  - 目標月利10万円 → 必須在庫50万円 / 目標在庫75万円
  - 目標月利50万円 → 必須在庫250万円 / 目標在庫375万円
  - 目標月利100万円 → 必須在庫500万円 / 目標在庫750万円
- 物販サイクル: 仕入れ→納品・販売→売上→入金→再仕入れ。**Amazonの入金サイクルは2週間ごと**（毎日1回の都度払いも可能）（スライド 11:31）
- 在庫表（スプレッドシート）で販売可能在庫を把握（スライド 11:32）
- 管理のまとめ: 1.必要資金は1.5倍がちょうど良い 2.情報の9割は間違っている 3.100%目標達成したいなら在庫金額を知る

## 3. 第2章: 成長ステージの上げ方（外注化・融資・限定独占）

### ① 外注化
- 副業者の可処分時間は朝1〜2h＋夜2〜3h ≒ **月60〜90時間**（スライド 11:39）
- 外注可能な作業: リサーチ/問い合わせ 月30h（300通×6分）、発注書作成 月1h、梱包/納品 月16h、在庫管理/リピート 月4h → **計51時間を外注で創出可能**
- 梱包外注先 = **WAM NET**（wam.go.jp、福祉医療機構の就労支援施設検索）（スライド 11:41〜11:47）
  - 費用格安（**1商品5〜10円程度**）・委託が簡単・社会貢献（信用が貯まり融資に有利）
  - 手順: ①ワムネットで自県検索→施設に作業可否確認→アポ ②訪問して作業説明（受取/保管/梱包/ラベル貼り/引き渡し）③約1ヶ月のテスト梱包（置き場所・スピード・品質・ミス頻度をチェック）
- 成功事例: 池田さん（月利50万円達成、就労支援委託マニュアル自作・配布、3年間で委託できなかった受講者ゼロ）
- 受講者の8〜9割が最終的に就労支援施設へ移行。代行業者は高コスト・融通が利かない・紛失リスク。B型は安いが能力面の制約あり → A型・B型両方に話を聞くのが推奨

### ② 融資獲得
- 効果: 自己資金100万のみ→目標到達18ヶ月 / 融資活用→**9ヶ月**（約半分）（スライド 11:51）
- ルートは2つ: **日本政策金融公庫**（国100%出資）／**信用金庫＋信用保証協会**（保証協会が債務保証）
- 流れ: 1.売上実績を作る → 2.必要書類（事業計画書・試算表）→ 3.面談 → 4.実行
- 実績ゼロの融資は50〜100万円止まり。**売上100万円を立ててから申請**すると200〜300万円（売上の2〜3倍が目安）
- 積み上げ例: 自己資金＋融資400万 → 売上400万 → 追加融資500〜600万 → 計800〜900万で月利100万円の土台

### ③ 限定化・独占
- **限定化** = メーカーが卸先を制限すること。セラーが増えない→供給量安定→値崩れしにくい（前提: メーカーがAmazonの仕組みを理解する必要）
- **独占** = 販売者が自分だけの状態。Amazon販売責任者として任され、卸先一本化でメーカー側の管理も楽に（双方のメリット一致が条件）。5社→1社独占で利益5倍の可能性
- 実現の核心（スライド 11:56）: **「Amazonの性質を理解し、メーカーの困り事を解決するだけ」**
  - Amazonの性質: 1.価格破壊が起こりやすい 2.1ページに複数セラーが群がる 3.需要供給は決まっている 4.みんなから意味なく嫌われている
  - メーカーの困り事: 1.値崩れして困る 2.知らない人が販売している 3.仕組みがよく分からない 4.嘘つきが多くて嫌
- 順序: 仲良くなる → 助言をもらい提言する → メーカーにメリットを感じてもらう → 限定化・独占へ。**「初対面で結婚を申し込むな」**（段階を踏む）

## 4. まとめ（中西氏の3つのメッセージ）

1. **正しい作業の継続が最も再現性が高い** — メール・FAX・電話の実施、数字の計測、一社数千円〜数万円の階段状積み上げが現実的
2. **嘘のノウハウに騙されるな** — 「実店舗があると偽る」「あいのり販売では稼げない」等は誤情報。メーカーを騙す手法は必ずバレて排除される
3. **メーカーから選ばれる人になる** — 選ぶのはメーカー。信頼関係構築が全て
