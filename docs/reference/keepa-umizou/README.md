## 1. 概要と要点（原本）

- **テーマ/目的:** Amazonせどりの必須ツール「Keepa（有料版）」の登録手順、最適な初期設定、仕入れ判断に必要な波形の読み解き方（利益波形・お宝波形・危険波形）、およびプロダクトファインダーを用いた事前リサーチ手法の完全解説。
- **対象ユーザー/前提条件:** せどり初心者〜中級者。Amazonせどりで赤字リスクを減らしたい方、仕入れ判断の精度・スピードを高めたい方（PC/スマホブラウザ使用）。
- **結論/得られる成果:** Keepaの各指標（価格・ランキング・出品者数等）を正しく読み解き、アカウント停止リスクや赤字・不良在庫を回避しつつ、自宅での事前リサーチや店舗仕入れで確実に利益を出せる判断基準が身につく。

## 3. 操作手順・マニュアル（原本）

### パートA：Keepa有料版の登録手順

1. **アカウント作成** — ブラウザで「Keepa」を検索しトップページを開き、右上の「ログイン / アカウントの登録」→「アカウント登録」タブでユーザー名・パスワード・メールアドレスを入力して登録。
2. **サブスクリプション契約** — ログイン後、右上のユーザー名にカーソルを合わせ「サブスクリプション」→ 青い「サブスクライブ」→ 個人（Individual）を選択 → 氏名・住所・クレジットカード情報を入力 → プランを選択。
   > ⚠️ 原本の「月額19ユーロ／年払い189ユーロ」は失効。現行は **月額29€／年額290€**（検証注記#1）。

### パートC：仕入れ判断の基本3ステップ

1. **価格と利益計算** — 現在カート価格（Buy Box）を確認し、仕入れ値と比較。
2. **売れ行きの確認** — 緑のランキンググラフが直近3ヶ月でギザギザ動いているか確認し、月間想定販売個数を算出。
3. **出品者数の推移と仕入れ個数の決定** — 「月間販売個数 ÷（出品者数＋1人）」で1人あたりの月間販売ペースを計算。**原則「1ヶ月以内に売り切れる個数」のみ仕入れる**（資金拘束・不良在庫防止）。

### パートD：プロダクトファインダーによる高利益・プレミア商品抽出

1. Keepa上部メニュー「データ」→「製品ファインダー」。
2. 検索条件（高回転×価格高騰×持ち帰り可能な小型〜中型品）：

| 項目 | 値 |
|---|---|
| 売れ筋ランキング（現在） | 1 〜 20000 |
| 新品 - 下落（直近7日間） | −99 〜 −30（マイナス＝過去7日で30〜99%価格が高騰した商品） |
| Amazon価格 | 「在庫切れ」にチェック |
| 新品アイテム数（出品者数） | 2 〜 10（または12程度） |
| レビュー数 | 10以上 |
| メインカテゴリー | 狙うジャンル（例：ドラッグストア） |
| サブカテゴリーの除外 | 販売禁止品など（例：お酒） |
| FBA料金 | 589円以下（大型商品を除外し徒歩・電車で回収可能なサイズに限定） |

3. 「検索」→ リスト化 → 回収ルート確認：
   1. ネットショップ（楽天・Yahoo!・家電量販店EC等）に定価在庫があるか確認。
   2. ネットに在庫がない/取り寄せに時間がかかる場合は、実店舗（ヨドバシ、ドンキ、ドラッグストア等）の在庫を検索・電話確認して直接回収。

## 4. 重要な補足・Tips（原本）

### Keepaで最優先に見る「基本6項目」

| # | 項目 | 読み方 |
|---|---|---|
| 1 | Buy Box（カート価格） | 実際に売れている基準価格。送料別の新品最安値に惑わされない |
| 2 | Amazon | Amazon本体の有無 |
| 3 | 新品 | 全出品者の最安値 |
| 4 | 売れ筋ランキング | 下に折れたタイミング＝売れたタイミング |
| 5 | 月間販売数 | 直近1ヶ月の販売実績（バリエーション単体の売れ行き確認に最適） |
| 6 | 新品アイテム数 | 出品者の増減。**仕入れ判断の最重要指標** |

> ※ 各項目の線の色は原本では ピンク/オレンジ/青/緑/黄/紫 と説明されているが、当社の実画面確認と不一致（検証注記#5・#6）。**凡例ラベルで判断すること。**

### 知的財産権クレームを見抜く5大サイン

1. 出品者に「〇〇公式」「株式会社〇〇（正規店）」が存在する
2. 出品者グラフが突然垂直に落下（崖落ち＝一斉通報・削除の跡）
3. 出品者が常に1人（相乗りしてもすぐ排除されている）
4. 価格が一切ブレずに完全水平（メーカーが価格統制）
5. ドラッグストア・コスメ・ヘアケア・サプリメント等の規約が厳しい特定カテゴリ

### その他

- **プロダクトファインダーと店舗仕入れの使い分け**: ファインダーは「店舗に行けない日」や「事前リスト作成」用。最も時間対効果が高いのは店舗でオールジャンルを直接見ること。事前リサーチに時間をかけすぎない。
- **検索条件の保存**: 絞り込みURLをブックマークすれば、次回からワンクリック（毎朝5分）で最新の高騰・利益商品をチェック可能。
- **危険波形①超低回転**: ギザギザして見えても「月間販売数＜出品者数」なら売り切るまで数ヶ月かかり値崩れする。
- **危険波形④ノーブランド品カタログの罠**: ブランド品なのに「ノーブランド品」としてカタログ作成されており、相乗り出品がエラーになる。
