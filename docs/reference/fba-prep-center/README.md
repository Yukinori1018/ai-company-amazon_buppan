- **2系統ある**: 就労支援系（障害者就労支援A型/B型事業所）と一般物流系。
  - 就労支援系＝単価 10〜50円/点と圧倒的に安く、月額固定費ほぼ無料。納品 2〜3営業日。社会貢献性あり。
  - 一般物流系＝単価 40〜100円/点、月額 0〜1万円程度。システム連携・スピードに強い。
- **最安**: びーぷらすFBA（B型・東京杉並）ラベル貼り 10円/個、納品代行 300円/箱（〜15kg）、月額なし。

- **地方拠点**: 糸星（愛知）／ほっこりーな博多（福岡）。

   **「商品1点が施設に届いてから FBA 倉庫に発送されるまでの総額（着地コスト）」**で見積もりを取り比較すること。
2. 料金は **2026年8月時点の公開情報ベース**。変動するため依頼前に必ず最新見積もりを確認。
3. 契約前に**小ロット（30〜100点）の有償テスト**を推奨。
4. 誤ラベル・破損時の補填条件、保管料、送料負担の有無は必ず個別確認。
