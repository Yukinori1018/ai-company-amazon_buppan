| 4 | 「新品未使用の二次流通品は担当者により見解が分かれる」 | 🔶 **法文上は明確** | 古物営業法2条1項の古物＝「一度使用された物品」＋「**使用されない物品で使用のために取引されたもの**」。**一度でも消費者の手に渡れば未使用でも古物**。実務照会の推奨は妥当だが、**当社は保守的に「二次流通品＝古物」で運用**する |

**動画に無い重要事実（当社に直結・カズヨ追記）**

- **メーカー・問屋・小売店（イオン/ヤマダ/ビックカメラ/百貨店等）から新品を仕入れて売る行為は、そもそも「古物」の取引ではないため古物商許可は不要。** → 当社の本線②メーカー仕入れ・③OEM は**法的に許可不要**。
- 逆に **メルカリ・ヤフオク・ラクマ等の個人（C2C）からの仕入れは、新品未使用でも古物＝許可必須**。

## 1. 概要と要点（原本）

- **テーマ/目的**: せどり・転売ビジネスにおいて必須となる「古物商許可証」の概要、要否判断基準、具体的な申請・取得手順、取得後の義務・注意点を網羅的に解説する。
- **対象ユーザー/前提条件**: メルカリ、ヤフオク、Amazon、eBay等でせどり・転売を行っている人、またはこれから始めようとしている初心者。
- **結論/得られる成果**: 自身のビジネスで古物商許可が必要かを正確に判別でき、管轄警察署への申請から取得後のプレート設置・法令対応まで迷わず再現・実行できるようになる。

## 2. 詳細な構成とタイムライン（原本）

### [00:02] オープニング・古物商許可証とは
- せどり・転売で許可がないと法律違反になるリスクへの言及。
- 古物商許可証は中古品（古物）をビジネス（「業」）として売買する際に必要な警察の許可証 [01:01]。
- 目的は「盗難品の流通防止」および「犯罪捜査（犯人特定）」[03:37]。
- 無許可営業の罰則：3年以下の懲役または100万円以下の罰金 [04:37]。※→ 検証注記#2

### [05:32] 古物商許可証が必要になる6つのケース
1. 中古品を仕入れて販売する（二次流通品の新品扱い含む）[05:42]
2. 中古品を修理・加工して販売する（ブランドリペア等）[06:38]
3. 中古品の一部またはパーツを販売・バラ売りする（家電・スマホ部品等）[06:54]
4. 中古品の委託販売をして手数料（マージン）をもらう [07:46]
5. 中古品を買い取ってレンタル（貸出）する [08:38]
6. 利益目的で仕入れた古物を別の品物と交換（物々交換）する [09:30]

### [10:08] 古物商許可証が不要なケース
- 自身の不要品を販売する（不用品処分・断捨離）[10:12]
- 無料でもらったものを販売する（※有償で買い取ったものはグレー）[10:22]
- 自分で作ったオリジナル商品・ハンドメイド品を販売する [11:19]
- 飲食物・化粧品などの「消費財」を販売する [11:35]
- コンサートやスポーツ観戦チケットを販売する（※高額転売による迷惑防止条例違反は別問題）[11:58] ※→ **検証注記#1（誤り）**
- 海外で購入（輸入）したものを日本国内で販売する [12:34] ※→ 検証注記#3

### [14:04] 取得方法・申請窓口・費用
- 申請窓口：主たる営業所の所在地を管轄する警察署の生活安全課保安係 [14:10]
- 手数料：19,000円（警察署の会計窓口で納付、不許可・取り下げでも返金なし）[15:05]
- 審査期間：申請から約40日〜2ヶ月程度 [17:11]
- 古物13品目の中から扱う品目を決定（メイン1つを必ず選定）[16:30]

### [17:52] 申請時の注意点
- 過去の取消処分歴や重大な犯罪歴がある場合は欠格事由となり通らない [17:58]
- 営業所が「賃貸物件」の場合はオーナー（大家）の承諾書・使用許諾が必要になる場合がある（バーチャルオフィスは不可）[18:30]

### [20:31] 取得するメリット
- 業者間取引である「古物市場（競り）」に参加・安価仕入れができる [20:45]
- 開業届・青色申告による節税効果（最大65万円控除や経費計上）[21:24]
- 法的リスクを気にせず堂々と事業展開でき、許可番号による購入者からの信頼性向上 [22:10]

### [23:17] 取得後の手続き・義務
- 警察署での許可証受領と「古物商法令講習」の案内・受講（一部地域）[23:27]
- 「古物商プレート（標識）」の作成と営業所への掲示義務 [24:34]
- 申請代行サービス（「ショシナビ」等）の紹介 [25:21] ※→ 検証注記#9

## 3. 操作手順・マニュアル（原本：取得〜運用）

### Step 1: 営業所と取扱品目の決定
- **営業所の決定**: 自宅、実家、事務所利用可の賃貸物件などを「主たる営業所」として選定 [14:28]
- **取扱品目の選定**: 全13品目（美術品類、衣類、時計・宝飾品類、機械工具類など）から扱う品目をすべて選択し、その中から「メイン（主たる品目）」を1つ決める [16:30]。（例: 中古家電・ガジェット＝「機械工具商」[16:58]）
- **注意**: 賃貸物件はオーナー承諾が必要な場合あり [19:00]。バーチャルオフィスは審査に通らない [20:21]

### Step 2: 管轄警察署への事前確認と必要書類の収集
- 営業所所在地を管轄する警察署の「生活安全課（保安係）」に連絡または訪問し、必要書類とローカルルールを確認 [14:48]
- 必要書類 [15:30]:
  - 許可申請書（警察署HP等からダウンロード）
  - 住民票
  - 身分証明書（本籍地の市区町村役場で取得）
  - 誓約書
  - ネット販売を行う場合は販売ショップのURLが確認できる資料 [16:08]
  - 賃貸契約書／使用承諾書（賃貸物件の場合）
- 書類作成が煩雑なら行政書士の代行サービス（例：「ショシナビ」等）[25:30]

### Step 3: 警察署への申請と手数料の納付
- 生活安全課へ書類一式を提出 → 会計窓口で **19,000円** を支払う [15:05]
- 書類不備の取下げ・不許可でも**返金されない** [15:13]

### Step 4: 審査待ち〜許可証の受領
- 約40日〜2ヶ月の審査 [17:11] → 電話連絡後、警察署で許可証原本を受領 [17:20]
- 地域（東京都の一部等）によっては「古物商法令講習」の案内あり [23:28]

### Step 5: 古物商プレート（標識）の作成と掲示
- 規定サイズのプレートを自己調達（相場1,000〜3,000円）[25:05]
- 記載内容: 公安委員会名／許可証番号／メインの取扱品目／氏名または屋号
- 届出した「主たる営業所」の見える場所に掲示 [24:39]
- **警察署から支給されない**ため自己調達必須 [24:57]。掲示を怠ると古物営業法違反 [25:14]

## 4. 重要な補足・Q&A・Tips（原本）

- **「新品」でも古物になりうる（二次流通品問題）**: 一般消費者の手に一度渡った未開封・未使用品を買い取って販売する場合、担当者の見解が分かれるため事前に管轄警察署へ確認して言質を取ることが推奨 [06:14] ※→ 検証注記#4
- **「業（ビジネス）」の判断基準**: 法律上に明確な金額・個数の基準はなく、「継続性があるか」「営利目的であるか」で警察が総合判断 [02:42]
- **古物台帳の義務**: 取引時の本人確認と古物台帳への記録・保管が義務 [04:26]
- **行商（ぎょうしょう）**: 許可証の「行商する・しない」欄で「する」にしておくと、営業所以外（露店・フリマ等）での販売が可能 [24:17]
