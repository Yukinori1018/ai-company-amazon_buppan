本事業（Amazon物販）で採用検討する仕入れ手法の一つ。[[knowledge_maker_shiire_ecstars]]（EC STARs Lab. 中西恒太）と同じ「メーカー直取引・ストック型」系統だが、**ラベル/パッケージのみを自社ブランドに変える「簡易OEM」×超少ロット（6本〜）**という、より参入障壁の低い切り口が核心。

---

## 1. 概要・要点

- **テーマ/目的:** 個人・副業でも参入できる「国内ニッチOEM」（既存商品のパッケージ/ラベルのみ変更して自社ブランドとしてAmazon販売）のリサーチ→メーカー電話交渉→契約成立までの実流れを実演。
- **対象:** 物販初心者、副業で収入を増やしたい人、転売の労働から抜け出したい人、資金・時間の限られた個人。特別資格・大規模資金は不要。
- **結論/成果:** 大手や中国輸入品と競合しない「国内ニッチ商品」を、メーカーから超少ロット（6本〜）で仕入れて簡易OEM化し、Amazon販売することで、安定して月収を積み上げる「ストック型」の仕組みを再現できる。

## 3. 【最重要】操作手順・マニュアル（再現手順）

### Step 1: 実店舗での商品発掘（店舗リサーチ）
- **操作:** こだわり系スーパー/セレクトショップの棚を1列ずつ確認。裏面の「製造元/加工者」メーカー名を記録・撮影。
- **コツ:** 通常商品と少し異なる特徴を持つもの（例: 通常は瓶入りの醤油がスティック小分け）を探す。
- **注意:** 「要冷蔵」はAmazon FBA納品不可のため除外。**常温品 or 冷凍食品**を選ぶ。

### Step 2: Amazon需要・数値の精密リサーチ（セラースプライト Sellersprite）
キーワードを入力し、以下**4基準**を満たすか確認：
1. **月間検索ボリューム: 3,000〜30,000回**（有名すぎず・マイナーすぎず）
2. **転換率（CVR）: 3%以上**（高いほど購入意欲が高い）
3. **PPC入札額（広告費目安）: 100円以下**（ライバルが強すぎない指標）
4. **検索トレンド: 過去3年が横ばい〜右肩上がり**（右肩下がりは避ける）

- **コツ:** 単体語（例「米ぬか」）でなく複合語（「食べる米ぬか」「無添加 米ぬか」）で需要ポジションを探す。
- **注意:** 競合ページが大手の"ただ登録しているだけ"なら、画像/カタログを作り込めば後発でも勝てる。

### Step 3: メーカーへの電話交渉（簡易OEMの打診）
商品裏面の電話番号へ連絡し、以下のトーン&マナーで：
1. **挨拶＋称賛:** 「◯◯という商品を拝見し、非常に素晴らしい商品だと思いお電話しました」
2. **要件提示:** 「弊社でも健康食品（該当ジャンル）の販売事業を行っており、御社商品を【中身はそのまま・パッケージ/ラベルのみ自社オリジナルにする簡易OEM】でお取引したい」
3. **ロット/条件確認:** 初回希望ロット（例50〜100個 or 最低何箱から可能か）を伝え、対応可否と取引条件を確認。

- **コツ:** 個人事業主でも自由に決めた**屋号（例「◯◯商店」）**を名乗ればOK。サイトに「OEM受付」と書いていないメーカーの方が少ロットで柔軟に応じやすい。
- **注意:** 最初から配合変更・容器変更など完全オリジナルOEMを求めるとロットが跳ね上がる（300〜1000本）。まず**中身そのまま・ラベル変更のみ（簡易OEM）**で打診してハードルを下げる。

### Step 4: ラベルデザイン作成→Amazon納品・自動化
- **操作:** 自社ブランドのラベルを用意し、法律/表示ルール違反がないかメーカーにチェックを受ける。完成ラベルをメーカーへ送付→商品に貼付してもらい→**直接Amazon FBA倉庫へ直送**。
- **コツ:** 自宅に在庫を置かないことで、個人副業でも自動化・仕組み化が可能。

## 4. 補足・Tips

### 狙うべき「5つの条件」
1. **程よくニッチ** — 一般商品と形/切り口が少し異なる（例: 小分けスティック醤油）
2. **金額が少し高めでもOK** — 安売り競合を避け、品質重視で相場より高めに設定できる
3. **ちょっと健康的** — 無添加・オーガニック・国産素材など健康志向
4. **ちょっと便利** — 使いやすい/保存しやすい/持ち運びやすい
5. **国産が強みになる** — 食品や肌に触れるもの等、国産の信頼性が中国輸入セラーとの強力な差別化に

### 簡易OEMの強み
- 中身は既存商品をそのまま使うため、商品開発のコスト/リスクが不要
- ラベルだけ自社ブランドに変え、最短・最安（動画内6本〜）で自社ブランド商品を作れる

### 画面・実績データ
- 平井氏オフィスの午後時点の日売上: 78,400円（1日の着地目安20〜30万円）
- 商品数を増やすほど利益が積み上がる「ストック型」物販モデル

## 5. 留意点（採用時の注意）

- 動画末尾（00:50:37〜）は物販スクール「差別化物販戦略塾」の案内・受講生実績。**スクール/コンサル契約は§4.1「金銭が動く」= 要社長承認**。手法のみ採用する方針（[[knowledge_maker_shiire_ecstars]]と同じスタンス）。
- 「簡易OEM」でも**景表法・食品表示法上のラベル表示義務**（原材料/アレルゲン/製造者表示等）を必ず遵守。ラベル案はメーカー確認＋必要に応じ法務ハルオでチェック。
- FBA納品可否は温度帯依存（要冷蔵NG）。実オペは[[knowledge_fba_shipment_umizou]] / [[knowledge_fba_shipment_playbook]]と接続。
