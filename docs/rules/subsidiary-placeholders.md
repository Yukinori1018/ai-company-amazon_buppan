# 子会社化のプレースホルダー一覧

このリポを元に子会社（新事業）のリポを作るときに、置き換える値の一覧。
`scripts/create-subsidiary.sh` の Step C がこのファイルを読んで置き換える（実体は `scripts/subsidiary_placeholders.py`）。
CLAUDE.md の本文には `{{ }}` を置かない（2026-10-27 T-20261027-001。旧 CLAUDE.md §7 の役目をこのファイルが引き継いだ。旧§7の原文は `operations.md` 末尾）。

## 置き換える値（機械が読む表）

- 「このリポでの値」は、いまこのリポに書かれている値。子会社を作ると、子会社側のこの列は新しい値に書き換わる（孫会社も同じ手順で作れる）。
- 置き換え方
  - **全文置換**：`*.md` `*.json` `*.json.example` の中の「このリポでの値」を全部、新しい値に置き換える（`.git/`・`docs/reference/` は除く）
  - **§B1**：CLAUDE.md の `### §B1` の本文を、下のひな形で書き直す

<!-- placeholders:begin -->
| キー | オプション | このリポでの値 | 置き換え方 |
|---|---|---|---|
| 事業名 | --business-name | Amazon物販事業 | 全文置換 |
| ミッション | --mission | Amazon 上で利益と販売確度の高い SKU を100積み上げ、月商800万円・利益率20%を達成する | §B1 |
| 最重要KPI | --kpi | 月商800万円・利益率20%以上・SKU 数100 | §B1 |
| 主力商品/サービス | --products | 未定（社長と決める） | §B1 |
| 想定顧客 | --customers | 未定（社長と決める） | §B1 |
<!-- placeholders:end -->

## CLAUDE.md §B1 のひな形

子会社では、§B1 の本文がこの2行になる。根源目標（このリポでは「2028年9月に月営業利益200万円」）は事業ごとに違うので、子会社を作ったあと社長と決めて書き足す。

<!-- b1-template:begin -->
```
- ミッション：{{ ミッション }}。KPI は {{ 最重要KPI }}。
- 主力商品：{{ 主力商品/サービス }}。想定顧客：{{ 想定顧客 }}。根源目標は未定（社長と決める）。
```
<!-- b1-template:end -->

## 行を足すとき

1. 上の表に1行足す（オプション名は `create-subsidiary.sh` の引数と揃える）。
2. 置き換え方が「全文置換」なら、このリポでの値がほかの文に紛れ込まない固有の文字列か確かめる（短い語は別の語の一部を壊す）。
3. 一時ディレクトリで試す：`scripts/create-subsidiary.sh --replace-only <コピー先> --business-name テスト事業 ...`
