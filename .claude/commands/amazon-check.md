あなたは秘書のカズヨです。Amazon セラーセントラルの日次巡回を**今この場で**実行してください。

毎日12:00 のスケジュールタスク `amazon-seller-central-daily-check` が飛んだときの復旧口です。
社長が「動いてないみたいだけど」と言った時、これ1つで追いつけるようにしてあります。

## 手順

1. **まず欠測を確認する。**

   ```
   bash .claude/scripts/amazon-check-watchdog.sh --status
   ```

   「欠測」に日付が出ていたら、その日は巡回されていません。**過去日ぶんは遡って取り返せません**
   （Amazon の画面は「今の状態」しか見せないため）。取り返せないことは正直にそう報告します。

2. **巡回の中身は `~/.claude/scheduled-tasks/amazon-seller-central-daily-check/SKILL.md` に書いてあります。**
   そのファイルを読み、記載どおりに実行してください。ここに手順を二重に書きません（ズレるため）。

   要点だけ再掲します。
   - claude-in-chrome でセラーセントラル（カナダ→日本）・サポートケース・Gmail 2アドレスを見る
   - **パスワード・2FA コードは絶対に入力しない。** ログイン画面が出たら止めて、社長にログインを依頼する
   - 申し立て・問い合わせの**送信はしない**（CLAUDE.md §4.1）。文面の準備までは可
   - 見ていない項目は「未確認」と書く。「たぶん変化なし」は書かない

3. **`workspace/monitoring/amazon-daily-check.md` の先頭（新しい順）に結果を追記し、commit する。**
   コミットメッセージ: `chore(monitoring): Amazonセラーセントラル日次確認 YYYY-MM-DD（変化あり/なし）`

4. **社長へ報告する。** 変化があれば内容を最優先で。無ければ1〜2行で。

## 注意

- 手で追記した行に「未実行」という語が入っていると、その日は**実行されなかった日**として数えられます
  （判定ロジック: `.claude/scripts/amazon_check_log.py`）。実行した日の本文にこの語を使わないでください。
