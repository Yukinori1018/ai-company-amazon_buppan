スライド1: タイトル

画面に出す内容

  • タイトル: メーカー仕入れ式シンプル物販 完全ワークフロー
  • サブタイトル: メーカーから直接仕入れて、Amazonで売る。ただそれだけを、正しく回す。
  • 出典: EC STARs Lab. メーカー仕入れ手法（2026-06-10セミナー＋マニュアルより構成）

ナレーション

今日は「メーカー仕入れ」という物販手法の全ワークフローを解説します。やることは極めてシンプルです。メーカーから直接卸してもらい、Amazonで販売する。せどりのような掘り出し物探しも、転売のような店舗巡りもありません。その代わり、リサーチ・問い合わせ・仕入れ判断・管理という4つのステップを、決められた基準どおりに淡々と回します。このプレゼンでは、その4ステップと、軌道に乗った後の成長3施策（外注化・融資・限定独占）まで、実務レベルで詳しく見ていきます。

スライド2: メーカー仕入れとは — 商流で理解する

画面に出す内容

  • 3つの商流比較図:
  • 一般流通: メーカー → 卸業者 → 小売業者 → 消費者
  • せどり/転売: メーカー → 卸 → 小売 → 転売業者(Amazon) → 消費者（小売→小売の二重流通）
  • メーカー仕入れ: メーカー →【直接卸】→ 自分(Amazon出品) → 消費者
  • キーワード: 中間マージンなし＝最安値で仕入れられる立場

ナレーション

まず商流で位置づけを理解します。一般流通では、メーカーと消費者の間に卸業者と小売業者が入ります。せどりや転売は、さらにその小売から買って転売するので「小売から小売」の二重流通になり、仕入値が構造的に高い。メーカー仕入れは、このチェーンを一段飛ばしてメーカーから直接卸してもらいます。中間マージンがないため、その商品を扱う誰よりも安く仕入れられる立場に立てます。これが利益の源泉です。

スライド3: せどりと何が違うのか

画面に出す内容

  • 比較表:

| | せどり/転売 | メーカー仕入れ |

|---|---|---|

| リサーチ | 毎回必要（消耗戦） | 取引成立後は不要 |

| 仕入れ | 都度・偶発的 | メール1本でリピート発注 |

| 利益 | 不安定 | 安定（値崩れしにくい） |

| アカウント | 規制リスクあり | メーカー書類で防御可能 |

| 型 | フロー型 | ストック型 |

  • 実例: ご当地ラーメン詰め合わせ — 月96セット販売・月利約14.2万円・利益率26%

ナレーション

せどりとの最大の違いは「積み上がるかどうか」です。せどりは売るたびに次の商品を探す消耗戦ですが、メーカー仕入れは一度取引が決まれば、メール1本で何度でも同じ商品を仕入れられます。発注作業は月2回程度。取引メーカーが1社増えるごとに月数千円から数万円の利益が階段状に積み上がる、ストック型のビジネスです。実例として、ご当地ラーメンの詰め合わせ1商品だけで月96セット・月利14万円・利益率26%というケースがあります。1商品でこれです。これを10社、20社と積み上げていきます。

スライド4: 5つのメリットと3つの不安

画面に出す内容

  • 5つのメリット: ①直取引による最安値仕入れ ②何度でもリピート ③アカウントの安全性 ④独占・限定化による利益保護 ⑤社会的信頼
  • 3つの不安と回答:
  • 資金が要る？ → 月4万円・100個から取引できるメーカーも多い。現金・自己資金内で開始
  • 個人は相手にされない？ → 実践者の9割以上が個人。法人必須は少数派
  • ライバルが増える？ → 限定化・独占で防げる。担当者交代で再チャンスもある

ナレーション

メリットは5つ。最安値仕入れ、リピート性、そしてアカウントの安全性。メーカーから正規の書類をもらって仕入れているので、Amazonの真贋調査や規制にも書類一式で対応できます。せどりにはない強みです。一方、よくある不安が3つ。「資金が要るのでは」——月4万円程度から取引できる中小メーカーは多く、自己資金の範囲で始められます。「個人では相手にされないのでは」——実践者の9割以上が個人です。「ライバルが増えて値崩れするのでは」——これは後半で説明する限定化・独占で構造的に防ぎます。

スライド5: なぜメーカーは私たちに卸してくれるのか

画面に出す内容

  • 中小メーカーの実情:
  • 人手不足。B2Cの個別販売は費用対効果が悪い
  • 「作る」のプロだが「売る」のは苦手
  • ロットで卸す方が生産の見通しが立つ
  • AIに代替されない理由: 営業代行500件でゼロ成約 vs 本人の直接電話1件で成約、という実例

ナレーション

「メーカーが自分でAmazonに出せばいいのでは」と思うかもしれません。実際には、中小メーカーは人手不足で、1個ずつ消費者に売る作業は割に合いません。彼らは作ることのプロであって、売るのは苦手。まとまったロットで卸す方が生産計画も立てやすい。だから「Amazonでの販売を引き受けます」という私たちの提案には、ちゃんと需要があります。そしてこの関係構築は人と人のコミュニケーションそのもので、AIや営業代行では代替できません。営業代行500件でゼロ成約だった案件が、本人の電話1本で成約した実例もあります。ここが参入障壁であり、私たちの守りにもなります。

スライド6: 全体ワークフロー俯瞰

画面に出す内容

  • 基本4ステップ（毎日回す）: ①リサーチ → ②問い合わせ → ③仕入れ判断 → ④管理
  • 成長3施策（軌道に乗ったら）: ⑤外注化 → ⑥融資 → ⑦限定化・独占
  • 1サイクルの流れ: Keepaで候補抽出 → メール/FAXで打診 → 見積回収 → 35%概算で利益判定 → 小ロット発注 → FBA納品 → 販売 → 2週間で入金 → リピート発注

ナレーション

ここからが本題、ワークフローの全体像です。日々回すのは4ステップだけ。Keepaで条件に合う商品を抽出し、そのメーカーに問い合わせ、もらった見積を経費35%ルールで利益判定し、通った商品だけ小ロットで仕入れて管理する。販売はFBA、つまりAmazonの倉庫に送れば梱包も発送もAmazonがやってくれます。売上は2週間サイクルで入金され、売れた分をリピート発注する。この繰り返しです。そして月利が安定してきたら、外注化で時間を作り、融資で資金を増やし、限定化・独占で利益を守る。順番に詳しく見ていきます。

スライド7: STEP1 リサーチ — 基準はたった3つ

画面に出す内容

  • リサーチ3基準（中小メーカー狙い）:

1. Amazon本体が出品していない

2. 売れ筋ランキング5万位以内（1〜50,000位）

3. FBAライバルセラーが2人以上（上限は問わない）

  • 補足: FBAセラー1人だけ＝OEMかメーカー直販なので取引不可。大手メーカーは代理店経由のため対象外

ナレーション

リサーチの基準は3つだけです。1つ目、Amazon本体が出品していないこと。Amazon自身が売っている商品ではカートが取れず勝負になりません。2つ目、売れ筋ランキング5万位以内。これは「ちゃんと売れている商品」の足切りラインです。3つ目が重要で、FBAセラーが2人以上いること。意外に思えますが、セラーが1人しかいない商品はOEM品かメーカー直販で、そもそも卸してもらえません。複数のセラーがいるということは「卸す意思のあるメーカー」だという証拠なんです。ライバルの上限は気にしなくて構いません。狙うのは中小メーカー。大手は代理店制度があるので個人には卸しません。

スライド8: リサーチ実務 — Keepa製品ファインダーの使い方

画面に出す内容

  • 使うツールは Keepa のみ（月額約5,000円 / 29ユーロ）
  • 製品ファインダーでの絞り込み手順:

1. ランキング 1〜50,000位 を指定

2. 「Amazon本体の在庫なし」を条件に追加

3. FBAセラー数 2以上 を指定

4. 酒類（免許必要）など扱えないサブカテゴリを除外

5. ヒットした商品のメーカー名を控えてリスト化

  • 売れやすさの3要素: ①回転数（需要） ②出品者数（供給） ③カート獲得（選択）— KPIはカート獲得

ナレーション

ツールはKeepaひとつで足ります。月額29ユーロ、約5,000円。Keepaの「製品ファインダー」機能で、いま挙げた3条件をそのままフィルタにかけます。ランキング5万位以内、Amazon本体なし、FBAセラー2人以上。酒類のように免許が要るカテゴリは除外します。出てきた商品リストからメーカー名を控えて、問い合わせ先リストを作る。これがリサーチの実務です。なお「ライバルが多いと売れないのでは」という心配について。売れやすさは需要・供給・カート獲得の3要素で決まり、重要なのはカートを取れるかどうかです。出品者数そのものは、上限を気にする必要はありません。

スライド9: STEP2 問い合わせ — 武器は「会社概要資料」

画面に出す内容

  • 問い合わせ前に作るもの: 会社概要資料（A4・1〜2枚 or Webページ）
  • 基本情報＋顔写真（あるとベスト）
  • 取引を希望する理由・事業への思い
  • 事業内容（Amazon販売の実績・体制）
  • 肩書き・法人格は不要。ホームページがあると認知獲得に有利

ナレーション

リストができたら問い合わせです。その前に、最大の武器である会社概要資料を作り込みます。内容は3つ。顔写真つきの基本情報、なぜ御社と取引したいのかという思い、そして自分の事業内容です。メーカーの担当者は「知らない相手」からのメールを毎日捨てています。顔が見えて、思いが書いてあって、事業の実体が分かる相手は、それだけで上位数%に入ります。法人格や立派な肩書きは要りません。実践者の9割以上が個人です。ホームページを用意して概要資料からリンクできるようにしておくと、さらに信頼が増します。

スライド10: 初回メールの型と5つの心構え

画面に出す内容

  • 初回メールの4構成: ①書き出し（挨拶） → ②要件（取引したい旨） → ③会社案内（会社概要URL） → ④終わりの一言
  • 注意: テンプレ臭を消す。コピペ文面は読まれない
  • 5つの心構え:

1. 会社概要を作り込む

2. 丁寧に対応する

3. FAX・電話も使う（メールだけにしない）

4. 断られたら理由を聞く

5. 利益が出ない見積なら条件を聞く

ナレーション

初回メールは4部構成。挨拶、取引したいという要件、会社概要への誘導、締めの一言。シンプルですが、テンプレートをそのまま送ってはいけません。メーカーには同じような営業メールが大量に届いており、テンプレ臭がした瞬間に捨てられます。自分の言葉に書き直してください。そして心構えが5つ。特に効くのが3つ目以降です。中小メーカーはいまだにFAXと電話の文化なので、メールで返事がなければFAXを送り、電話をかける。これだけで成約率が変わります。断られたら必ず理由を聞く。値段が合わなければ条件を聞く。一往復で終わらせないことが、取引数の差になります。

スライド11: STEP3 仕入れ判断 — 経費35%の概算式

画面に出す内容

  • 概算ルール: 販売価格の35%が経費（Amazon販売手数料＋FBA配送料＋納品送料）
  • 利益式: `利益 = 販売価格 × 0.65 − 仕入価格`
  • セミナー実例（販売価格1,980円）:
  • 販売手数料 218円 ＋ FBA送料 434円 ＋ 納品送料 30円 ＝ 経費 682円（約35%）
  • 1,980 − 682 − 仕入1,188円 ＝ 利益110円
  • 見積が届いたらこの式に当てはめて、利益が出る商品だけ前に進める

ナレーション

メーカーから見積が届いたら、仕入れ判断です。ここで使うのが「経費35%ルール」。Amazonの販売手数料、FBAの配送代行手数料、倉庫への納品送料を合わせると、だいたい販売価格の35%になります。つまり、販売価格の65%から仕入価格を引いた残りが利益。セミナーの実例では、1,980円の商品で経費682円、仕入1,188円、利益110円でした。利益110円と聞くと小さく感じますが、月280個売れれば3万円。これが1商品分で、リピートで毎月続きます。まずこの概算で足切りし、有望なものだけ正確な計算に進めば、判断のスピードが落ちません。

スライド12: 月間販売数の確認 — キーゾンと定点観測

画面に出す内容

  • 仕入れ個数を決める前に「月に何個売れるか」を数字で確認
  • 方法①: キーゾン（Keepa連携のChrome拡張・無料）— 商品ページに月間販売数を表示
  • 方法②: 定点観測 — ライバルの在庫数を3〜5日間記録し、減り方から販売ペースを推定
  • 市場の月販数 ÷ （FBAセラー数＋1） ≒ 自分が売れる見込み数

ナレーション

利益が出ると分かったら、次は「何個仕入れるか」。その前提として月間販売数を必ず数字で確認します。方法は2つ。1つはキーゾンというChrome拡張で、Keepaのデータをもとに月間販売数を商品ページ上に表示してくれます。もう1つは定点観測。ライバルセラーの在庫数を3日から5日間記録して、減り方から売れるペースを推定する方法です。市場全体の月販数を、自分を含めたFBAセラー数で割れば、自分の取り分の目安が出ます。感覚で仕入れない。必ず数字で確認する。ここを省くと在庫を抱えます。

スライド13: 初回は必ず小ロット — 仕入個数のルール

画面に出す内容

  • 初回発注: 最小ロット・5個程度から
  • リピート発注の目安:
  • 現金前払い: 月販数の 1.5ヶ月分
  • 掛け払い(後払い): 月販数の 2〜3ヶ月分
  • 危険信号: 「初回から大ロット」「高額な最低発注額」の見積 → 無理に受けない。売れてからリピートで回収する設計

ナレーション

仕入れの鉄則は「必ず小さく始める」です。初回は最小ロット、5個程度で構いません。目的は利益ではなくテストです。本当に想定ペースで売れるのか、商品状態は問題ないか、メーカーの納期は正確か。それを確認してから、リピートで数を増やします。リピート時の目安は、現金前払いなら月販数の1.5ヶ月分、掛け払いなら2〜3ヶ月分。逆に、初回から大きなロットや高い最低発注額を求めるメーカーは要注意です。そこで無理をしない。売れる確証を得てから積み増す。この順番を守るだけで、物販の最大の失敗である「不良在庫」をほぼ回避できます。

スライド14: STEP4 管理 — 必要資金は月販の1.2〜1.5倍

画面に出す内容

  • 在庫の原則: 1ヶ月ぴったりの在庫はNG（売れ残りも欠品もどちらも損失）→ 月販の1.2〜1.5倍を持つ
  • 目標月利と必要在庫の目安:

| 目標月利 | 必須在庫 | 目標在庫 |

|---|---|---|

| 10万円 | 50万円 | 75万円 |

| 50万円 | 250万円 | 375万円 |

| 100万円 | 500万円 | 750万円 |

  • 管理の3原則: ①資金は1.5倍がちょうど良い ②情報の9割は間違っている ③目標達成したいなら在庫金額を知る

ナレーション

4つ目のステップ、管理です。ここで一番大事な数字が「在庫は月販の1.2〜1.5倍」。1ヶ月分ぴったりだと、少し売れ行きがブレただけで欠品します。欠品は売上ゼロというだけでなく、Amazonの検索順位が下がり、カート取得率も落ちる。かといって持ちすぎれば資金が寝る。その均衡点が1.2〜1.5倍です。この比率から逆算すると、目標月利10万円には在庫50〜75万円、月利50万円には250〜375万円が必要になります。つまり「いくら稼ぎたいか」は「いくら在庫を持てるか」で決まる。自分の在庫金額を常に把握していることが、目標達成の前提条件です。

スライド15: キャッシュサイクルと在庫表

画面に出す内容

  • 物販サイクル: 仕入れ → FBA納品・販売 → 売上 → 入金（2週間ごと） → 再仕入れ
  • Amazonの入金は2週間サイクル（毎日1回の都度払い設定も可能）
  • 在庫表（スプレッドシート）で管理する項目: 商品名／仕入価格／販売価格／FBA在庫数／販売ペース／次回発注予定日
  • 発注作業は月2回程度に集約できる

ナレーション

お金の流れを押さえます。仕入れて、FBA倉庫に納品して、売れて、2週間ごとに入金され、その資金でまた仕入れる。このサイクルが回り始めると、あとは在庫表の管理だけです。スプレッドシートに商品ごとの仕入価格、販売価格、FBA在庫数、販売ペースを記録し、在庫が1.5ヶ月分を切りそうになったらメールでリピート発注する。これを月2回やるだけ。せどりのように毎日リサーチに追われることはありません。だからこそ副業でも回りますし、後で説明する外注化で、さらに手離れさせることができます。

スライド16: 成長施策① 外注化 — 月51時間を買い戻す

画面に出す内容

  • 副業者の可処分時間: 朝1〜2h＋夜2〜3h ≒ 月60〜90時間
  • 外注できる作業と時間:
  • リサーチ・問い合わせ: 月30h（300通×6分）
  • 発注書作成: 月1h
  • 梱包・納品: 月16h
  • 在庫管理・リピート発注: 月4h
  • → 合計51時間を外注で創出可能
  • 残すのはメーカーとの関係構築（ここだけは自分）

ナレーション

ここからは月利が立ち始めた後の成長施策です。まず外注化。副業で使える時間は月60〜90時間程度しかありません。作業の内訳を見ると、リサーチと問い合わせ送信で月30時間、梱包・納品で16時間、発注書や在庫管理で5時間、合計51時間は外注可能です。つまり作業時間のほとんどは人に任せられる。自分に残すべきはただ一つ、メーカーとの関係構築です。ここは利益の源泉であり、外注も AI も代替できない部分。逆に言えば、それ以外を任せる仕組みを作った人から月利が伸びていきます。

スライド17: 梱包外注の具体策 — WAM NET（就労支援施設）

画面に出す内容

スライド18: 成長施策② 融資 — 目標到達を18ヶ月→9ヶ月に

画面に出す内容

  • 効果: 自己資金100万円のみ→目標到達18ヶ月 / 融資活用→9ヶ月（約半分）
  • ルートは2つ: 日本政策金融公庫 ／ 信用金庫＋信用保証協会
  • 鉄則: 売上100万円の実績を作ってから申請する
  • 実績ゼロ: 50〜100万円止まり
  • 実績あり: 売上の2〜3倍（200〜300万円）が目安
  • 流れ: 売上実績 → 事業計画書・試算表 → 面談 → 実行
  • 積み上げ例: 自己資金＋融資400万 → 売上400万 → 追加融資500〜600万 → 月利100万円の土台

ナレーション

2つ目の成長施策は融資です。このビジネスは在庫量が利益を決めるので、資金量がそのまま成長速度になります。自己資金100万円だけなら18ヶ月かかる目標が、融資を使えば9ヶ月、半分に縮まる。ルートは日本政策金融公庫か、信用金庫プラス信用保証協会の2つです。ここで大事な鉄則が一つ。「売上100万円の実績を作ってから申請する」こと。実績ゼロで申し込むと50〜100万円しか出ませんが、売上実績があれば売上の2〜3倍まで狙えます。同じ申請でも順番を間違えるだけで調達額が変わる。まず小さく売上を立てる、それから借りる、です。

スライド19: 成長施策③ 限定化・独占 — 利益を守る最終形

画面に出す内容

  • 限定化 = メーカーに卸先を制限してもらう → セラーが増えない → 値崩れしない
  • 独占 = Amazon販売者が自分だけ。5社→1社なら利益5倍の可能性
  • 実現の核心: 「Amazonの性質を理解し、メーカーの困り事を解決するだけ」

| Amazonの性質 | メーカーの困り事 |

|---|---|

| 価格破壊が起こりやすい | 値崩れして困る |

| 1ページに複数セラーが群がる | 知らない人が売っている |

| 需要と供給は決まっている | 仕組みがよく分からない |

| みんなから嫌われている | 嘘つきが多くて嫌 |

ナレーション

最後の成長施策が、限定化と独占です。限定化とはメーカーに卸先を絞ってもらうこと。セラーが増えなければ供給が安定し、値崩れが起きません。さらに進んで、Amazonでの販売者が自分だけになるのが独占。5社で分け合っていた市場を1社で取れば、単純計算で利益は5倍です。どうやって実現するか。核心はこの表に尽きます。Amazonには値崩れしやすい、無関係なセラーが相乗りしてくる、という性質がある。一方メーカーは、まさにその値崩れと無断販売者に困っていて、しかも仕組みがよく分からない。つまり、Amazonの仕組みを説明し、値崩れの原因を示し、卸先を絞ればそれが解決すると提案する。私たちの知識そのものが、メーカーの困り事の解決策なんです。

スライド20: 限定独占への段取り — 「初対面で結婚を申し込むな」

画面に出す内容

  • 正しい順序: ①仲良くなる → ②助言をもらい・提言する → ③メーカーがメリットを感じる → ④限定化 → ⑤独占
  • 合言葉: 「初対面で結婚を申し込むな」
  • 初回の問い合わせで独占を求めるのはNG。まず普通に取引し、売上実績と信頼を作ってから
  • メーカーの担当者交代はチャンス（関係構築のやり直しが利く）

ナレーション

ただし、順序を間違えてはいけません。合言葉は「初対面で結婚を申し込むな」。最初の問い合わせでいきなり独占契約を求めても、確実に断られます。まず普通に取引を始めて、きちんと売り、きちんと支払い、信頼を積む。そのうえでAmazonの状況について助言を求められる関係になり、値崩れ対策を提言し、メーカー側がメリットを感じて初めて、限定化、そして独占へ進みます。恋愛と同じで段階を踏むこと。なお、一度断られても、メーカーの担当者が交代したタイミングで再チャンスが来ることもあります。長期戦で構いません。

スライド21: やってはいけないこと

画面に出す内容

  • 嘘のノウハウに騙されない:
  • ✕「実店舗があると偽って信用させる」→ 必ずバレて取引終了
  • ✕「あいのり販売（相乗り）だけで大きく稼げる」→ 誤情報
  • ✕ メーカーを騙すテクニック全般 → 排除されて終わり
  • 成功原則は3つだけ:

1. 正しい作業の継続が最も再現性が高い（メール・FAX・電話、数字の計測、階段状の積み上げ)

2. 選ぶのは自分ではなくメーカー。選ばれる人になる

3. 一社数千円〜数万円を積み上げる現実的な期待値を持つ

ナレーション

注意点です。この業界には嘘のノウハウが出回っています。実店舗があると偽る、経歴を盛る、といったテクニックは必ずバレます。バレた瞬間に取引は終わり、業界は狭いので評判も残る。逆に、派手なテクニックは一切なくても、正しい作業を継続することが最も再現性が高い。メールを送り、FAXを送り、電話をかけ、数字を計り、一社あたり数千円から数万円の利益を階段のように積み上げる。地味ですが、これが実際に成果が出ている人たちの共通点です。忘れてはいけないのは、選ぶのはメーカー側だということ。メーカーから選ばれる誠実な事業者であることが、すべての前提です。
