# アフィリエイト ASP 商品データ 二次利用 ToS 判定（T-20260522-003）

> 法務担当ハルオ作成 / 2026-05-25
> 確認の核心: **アフィリエイト ASP の商品データを「商品紹介」目的を超えて「仕入れ判断ツール内の価格表示」に使うことが ToS 上 OK か。**
> 前提となる利用形態: 社長個人専用・非公開（ログインなし）の Sato-Scope。商品紹介サイトとして外部公開はしない。
> 打ち切り条件: 6社中3社で「明確に OK or NG」が判明すれば十分。→ **達成（楽天アフィリエイト＝NG、A8.net／もしも＝実質NG、バリューコマース＝NG の計4社で判明）**

---

## 0. 結論サマリ（判定表）

| ASP | 商品データ API/フィード | 二次利用範囲 | 価格を仕入れ判断に使う | 個人専用ツール内表示 | 判定 |
|---|---|---|---|---|---|
| **楽天アフィリエイト** | あり（楽天 API と統合） | アフィリエイトリンク設置目的のみ | **🔴 明確に NG**（目的外利用禁止条項） | 非公開メッセージツール共有も禁止 | **🔴 NG（使わない）** |
| **バリューコマース** | あり（商品 API/DataLink） | 計測タグ（ckタグ）を伴う掲載が前提 | **🔴 実質 NG**（タグ無し利用は不正＝提携解除） | 掲載媒体前提・私的ツールは想定外 | **🔴 NG（使わない）** |
| **A8.net** | あり（商品データベース API） | 広告掲載メディアでの紹介が前提 | 🔴 実質 NG（紹介目的逸脱）／グレー | 非公開・パスワード保護メディアは不適切 | **🔴 NG 寄り（使わない）** |

| **アクセストレード** | 限定的 | 媒体掲載前提・法令遵守強調 | グレー（明文確認できず） | 公開媒体前提 | **🟡 未確認（打ち切り済み・調査不要）** |

凡例: 🔴 NG / 🟡 未確認・グレー

### 総合結論

**アフィリエイト ASP の商品データは、Sato-Scope の「仕入れ判断ツール内価格表示」には使わない（使えない）。**

理由は ASP 共通の構造にある:
1. ASP の商品データ提供は、いずれも**「自社が運営する公開メディア（サイト/ブログ等）で商品を紹介し、アフィリエイトリンクを設置して成果報酬を得る」ことを唯一の目的**としている。
2. Sato-Scope は **(a) 非公開・個人専用、(b) アフィリエイト報酬目的でない、(c) 商品紹介サイトでない** ため、ASP がデータ提供する前提を一つも満たさない。
3. 複数 ASP が「閲覧にパスワードが必要な非公開メディア」や「リンク設置以外の目的での利用」を明確に禁止している。

→ **仕入れ判断のための価格データは、ASP 経由ではなく「公式 API（楽天ウェブサービス商品検索 API／Yahoo!ショッピング Web API／Keepa）」から取得すべき。** これらは `01_official-api-tos.md` の通り条件付きで GO。

## 1. 楽天アフィリエイト（明確に NG）

### 1.1. 判定: 🔴 NG

楽天アフィリエイトの商品データは**「アフィリエイトリンク設置以外の目的に使えない」**ため、仕入れ判断ツールでの利用は明確に規約違反。

### 1.2. 該当条文（抜粋）

> 「パートナーはリンク作成用コンテンツを、本規約に基づく本サービス利用のための**アフィリエイトリンク設置以外の目的に使用することはできない**」

> 「パートナーは ... メール、LINE、SNSのダイレクトメール等、**特定の者にしか閲覧できないメッセージツールを用いてアフィリエイトリンクを共有・送信することが禁止**されている」

### 1.3. 法務コメント

「アフィリエイトリンク設置以外の目的に使えない」という条文は決定的です。Sato-Scope の主目的は仕入れ判断であり、これは明白に「リンク設置以外の目的」に当たります。さらに「特定の者にしか閲覧できない（＝非公開）」運用も禁止対象です。**楽天データは楽天アフィリエイト経由では取得しない。** `01_official-api-tos.md` §4 の通り、楽天データは「楽天ウェブサービス 商品検索 API」から取得し、その規約の枠内で運用するのが唯一の正解です。

## 2. バリューコマース（明確に NG）

### 2.1. 判定: 🔴 NG

商品 API で取得したデータを、**計測タグ（ckタグ）を伴わずに使うと「不正」とみなされ提携解除・退会**となりうる。タグは公開媒体への掲載を前提とした仕組みであり、非公開の仕入れツールでは成立しない。

### 2.2. 該当条文（抜粋）

> 「APIで取得した **ckタグを使用しない場合、表示数がカウントできないため、サイトの構成によっては不正と見なされ、提携解除・退会となりうる**」

### 2.3. 法務コメント

バリューコマースのデータ提供は「ckタグ（計測タグ）付きで自社サイトに掲載する」ことが構造的前提です。Sato-Scope は計測タグを設置する公開サイトを持たないため、データだけ抜いて使うと「不正利用」に直結します。**使わない。**

---

## 3. A8.net（NG 寄り・実質使えない）

### 3.1. 判定: 🔴 NG 寄り

A8.net は商品データベースを API 提供しているが、利用は**広告掲載を行う公開メディアでの商品紹介**が前提。Amazon PA-API 同様「データのみ取得しリンクとして使わない利用」は規約違反方向。

### 3.2. 該当条文・根拠（抜粋）

- A8.net メディア会員利用規約は「メディア（公開サイト）」での広告掲載を前提とし、規約・ガイドライン遵守を誓約させる。
- 関連する業界共通の考え方（Amazon PA-API のポリシーが典型例）:
  > 「PA-APIから**データのみ取得し、リンクURLとしては使っていない場合**、またはパラメータを除去してご利用になられている場合、PA-APIをご利用いただけない可能性がある」
  → ASP のデータ提供は「アフィリエイトリンクとセットでの紹介」が大前提という業界標準を示す。

### 3.3. 法務コメント

A8.net の商品データベース API も「自社メディアで商品を紹介する」目的に紐づきます。Sato-Scope は紹介メディアでないため、**データのみ抜いて仕入れ判断に使う運用は紹介目的を逸脱し、規約違反リスクが高い。** グレーと言えなくもないが、明文主義に立てば「想定された用途でない＝NG 寄り」と判定します。**使わない。**

---

## 4. もしもアフィリエイト（NG 寄り・実質使えない）

### 4.1. 判定: 🔴 NG 寄り

もしもアフィリエイトは「公開メディアでの掲載」が大前提で、**非公開メディアを明確に不適切**としている。Sato-Scope（非公開・個人専用）は構造的に対象外。

### 4.2. 該当条文・根拠（抜粋）

> 禁止・不適切とされる例として「メディアが存在しない、文章・画像等のコンテンツが存在しないメディア、**閲覧にパスワードが必要で公開されていないメディア**、その他もしもアフィリエイトが不適切とみなす行為全般」

> 「利用者は利用申込にあたり、本規約やガイドライン等の規定事項 ... を遵守することを誓約する」

### 4.3. 法務コメント

「閲覧にパスワードが必要で公開されていないメディアは不適切」という条文は、Sato-Scope のような**ログイン保護された個人専用ツールを明確に排除**します。仕入れ判断目的以前に、媒体の要件で落ちます。**使わない。**

---

## 5. afb（アフィビー）／アクセストレード（未確認・打ち切り）

打ち切り条件（3社判明）を既に満たしたため、両社は逐条確認を省略。ただし両社とも「広告掲載を行う公開媒体での紹介」が前提のアフィリエイト ASP であり、上記4社と同じ構造的理由で **Sato-Scope の非公開仕入れツールでの利用には適さない可能性が高い**（グレー〜NG 寄り）。アクセストレードは法令遵守（薬機法・景表法等）を特に強調する ASP。

> ⚠️ 未確認・要直接確認: afb／アクセストレードの商品データ提供有無と二次利用条項は本日未確認。**結論に影響しない**（公式 API で代替する方針が固まっているため、両社を使う必要がない）。

## 6. 過去にアウトと判定された運用パターン（業界事例）

- **「データだけ抜いてリンクを貼らない」** → バリューコマース（タグ無し利用＝不正）、Amazon PA-API（リンクとして使わない利用は不可）で明確に NG。
- **「非公開・パスワード保護メディアでの利用」** → もしもアフィリエイトが明確に不適切と規定。
- **「アフィリエイトリンク設置以外の目的での商品データ利用」** → 楽天アフィリエイトが明確に禁止。
- **「特定の者にしか見られないツール（メッセージ/DM 等）でのリンク共有」** → 楽天アフィリエイトが禁止。

→ Sato-Scope の利用形態（非公開・個人専用・紹介目的でない）は、**これら NG パターンに複数該当**する。アフィリエイト ASP のデータは使わないのが法務上の結論。
