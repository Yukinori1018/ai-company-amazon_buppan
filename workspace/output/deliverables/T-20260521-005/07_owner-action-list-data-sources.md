# 📋 社長アクション一覧｜リサーチツールのデータ源準備

> 目的：自社リサーチツール（利益が出る商品を自動で一覧化）を動かすための「社長が用意するデータ源（APIキー等）」。
> 根拠：YouTuber朝野拓也氏「電脳せどり最強仕入れ先10選」(memory: knowledge_dennou_sedori_system) ＋ ツール設計(T-20260521-005)。

## 🟢 今すぐ（無料・これだけで(い)仕入れ元の自動収集が動く）
### 1. Yahoo!ショッピング API キー（APP ID）取得 ←★最優先・今やる
- なぜ: ツールが「安い仕入れ候補」を自動で集める入口。これ1つで(い)仕入れ元リサーチが実データで動く。
- 手順（5〜10分・無料）:
  1. https://e.developer.yahoo.co.jp/ に Yahoo! ID でログイン
  2. 「アプリケーションの管理」→「アプリケーションの開発」→ 新規作成
  3. 種別=サーバーサイド、用途=「自社の物販商品リサーチ」等
  4. 発行された **Client ID（＝アプリケーションID）** をコピー
  5. カズヨに共有

## 🟡 次に（無料・対応仕入れ先を増やす）
### 2. 楽天ウェブサービス アプリID取得
- なぜ: 楽天市場も主力仕入れ先（10選の主軸）。Yahooと合わせ候補が倍に。
- 手順（5分・無料）: https://webservice.rakuten.co.jp/ →楽天会員でログイン→「アプリID発行」→ **applicationId** をコピー→共有

## 💳 判断が必要（有料・Amazon側の心臓部）
### 3. Keepa API 契約（約€49/月）←★要・社長承認（§4.1）
- なぜ: 「Amazonでいくらで売れる・月に何個売れる」を自動取得する唯一の現実的手段。**これが入ると"儲かる商品が自動で一覧に並ぶ"が完成**（(あ)モード＋完全自動化に必須）。
- 承認後の手順: Keepa登録→Data API契約→APIキー取得→共有
- 費用: €49/月（約8,000〜9,000円）
- 代替: Amazon SP-API（無料だが設定数日級・売れ筋回数取れない）→初手は非推奨

## 🔜 後で・任意（今は不要）
- NETSEA等の卸API: 一般公開が薄く調査中（T-20260522-001）。当面は承認済み卸の商品を手動でツールに入れて判定。
- 価格.com / Qoo10 / ヤフオク: 公式API無し/制限/スクレイピング禁止 → 当面ツール対象外（手動）。
- ポイントサイト（モッピー/ハピタス）: ポイント込み実質仕入値の最適化用。急がない。
