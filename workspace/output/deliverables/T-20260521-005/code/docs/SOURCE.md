## NETSEA データの用途ルール（法務ハルオ判定 2026-08-31 / T-20260831-005）

| | 内容 |
|---|---|
| ○ 許可 | **NETSEA 内で完結する仕入れ実務**（商品選定・卸価格取得・在庫確認・NETSEA 上での発注） |
| ✗ 禁止 | NETSEA 外でのサプライヤーへの連絡（会員規約 第7条2項5号） |
| ✗ 禁止 | NETSEA 外での売買契約の締結（第19条3項） |
| ✗ 禁止 | サプライヤー情報の収集を目的とした利用（第7条1項3号・事前承諾の余地なし） |
| ✗ 禁止 | 取得した社名を**メーカー発見リストへ合流させること**（第7条2項3号） |
| 制裁 | 第27条4項＝**事業者名の公表・契約解除・違約金200万円＋売買代金の50%** |
