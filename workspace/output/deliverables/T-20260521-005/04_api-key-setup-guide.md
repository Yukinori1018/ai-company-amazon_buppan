# Sato-Scope Phase 2 — API キー取得・設定 手順書

> 対象: 社長（副業初心者向けに手順を細かく記載）
> 目的: Sato-Scope を「モックモード」から「実データモード」に切り替えるための3つのキーを取得し、`.env` に貼る
> 所要時間の目安: 合計 30〜45分（Keepa の決済が一番時間を要します）

---

## 0. まず全体像（結論ファースト）

Sato-Scope を本番データで動かすには **3つのキー**が要ります。

| # | キー | 料金 | §4.1 承認 | 所要 |
|---|---|---|---|---|
| 1 | **Keepa API キー** | **€49/月（約¥8,200）** | ✅ 取得済（2026-05-22 GO） | 10〜15分 |
| 2 | 楽天市場 ApplicationID | 無料 | 不要 | 5〜10分 |
| 3 | Yahoo!ショッピング Client ID | 無料 | 不要 | 5〜10分 |

3つとも社長の**個人アカウント**に紐づきます。取得したキーは最後に `.env` ファイルへ貼るだけです。

> ⚠️ キーは「パスワード」と同じ機密情報です。スクショで他人に共有しない／このリポジトリにコミットしない（`.env` は Git 管理外に設定済み）。

## 1. Keepa API キー（有料・€49/月）

Amazon の売値・月販・価格推移（Drop30）を取るための心臓部です。**ここだけ課金**が発生します（承認済み）。

1. ブラウザで **https://keepa.com/** を開く
2. 右上から**アカウント登録 / ログイン**（メールアドレスで作成。Google ログインも可）
3. ログイン後、上部メニューの **「API」**（または https://keepa.com/#!api ）を開く
4. プランを選択して契約する
   - 表示は月あたりの「トークン量」で選ぶ形式です。**€49/月 相当のプラン**を選択
   - ＊画面文言・プラン名は変わることがあります。月額がおよそ **€49** のものを選べばOK
5. 支払い方法に**クレジットカード（セゾンカードデジタル等）**を登録して決済
6. 契約完了後、API ページに表示される **「API key」**（英数字の長い文字列）をコピー
   → これが `KEEPA_API_KEY` です

> 困ったら: API ページに "Your API key" のような項目があります。見当たらない場合はそのままスクショを撮らずにキー文字列だけ私に「貼り場所が分からない」と伝えてください。

## 2. 楽天市場 ApplicationID（無料）

仕入れ候補（楽天市場の最安値）を取るためのキーです。**無料**です。

1. **https://webservice.rakuten.co.jp/** を開く
2. 右上の **「アプリ ID 発行」**（またはログイン）をクリック
   - 楽天会員 ID でログイン（普段の楽天ショッピングのアカウントでOK）
3. **「アプリ ID（=ApplicationID）を新規発行」**フォームに入力
   - アプリ名: 例）`Sato-Scope`（何でも可）
   - アプリ URL: 持っていなければ `http://localhost`（仮でOK。後で変更可）
4. 発行された **applicationId**（数字の長い文字列）をコピー
   → これが `RAKUTEN_APP_ID` です

> affiliateId は今回**不要**です（空欄のままでOK）。

---

## 3. Yahoo!ショッピング Client ID（無料）

楽天と並ぶもう一つの仕入れ候補ソースです。**無料**です。

1. **https://e.developer.yahoo.co.jp/dashboard/** を開く
2. **Yahoo! JAPAN ID** でログイン（普段の Yahoo! アカウントでOK）
3. **「アプリケーションの登録」**を選択
   - アプリケーションの種類: **サーバーサイド（Web アプリ）**を選択
   - 利用するスコープ: 特に指定不要（ショッピング検索は公開 API）
   - アプリケーション名: 例）`Sato-Scope`
   - サイト URL / コールバック: 持っていなければ `http://localhost` で可
4. 登録後に発行される **Client ID（アプリケーション ID）**をコピー
   → これが `YAHOO_APP_ID` です

> 「Client Secret」も一緒に出ますが、ショッピング商品検索 API では**今回は使いません**（Client ID だけでOK）。

## 4. キーを `.env` に貼る（仕上げ）

3つのキーが揃ったら、Sato-Scope のコードフォルダで設定します。

```bash
# コードフォルダに移動
cd ~/Documents/AI\ Company\ Outputs/Amazon物販事業/T-20260521-005/code
#   ↑ リポジトリ内で動かす場合は
#   cd <リポジトリ>/workspace/output/deliverables/T-20260521-005/code

# まだ .env が無ければテンプレからコピー
cp .env.example .env
```

`.env` をテキストエディタで開き、以下のように貼り付けます（`=` の右にキーを書くだけ）。

```dotenv
KEEPA_API_KEY=ここにKeepaのキー
RAKUTEN_APP_ID=ここに楽天のapplicationId
YAHOO_APP_ID=ここにYahooのClient ID
DEBUG=false
```

保存したら起動します。

```bash
source .venv/bin/activate   # 初回は README の「2. 仮想環境作成」を先に実施
uvicorn app.main:app --reload
```

→ http://localhost:8000/health を開き、各アダプタが **`mock` ではなく `live`**（実接続）になっていれば成功です。

## 5. 詰まったら

- **キーが1つでも未取得**でも大丈夫です。未設定のキーは自動で「モックモード」に戻るので、取得できたものから順に試せます（例: 楽天だけ先に live、Keepa は後日）。
- 取得画面で迷ったら、**どの手順の何番で止まったか**を私（カズヨ）に一言ください。その箇所を補足します。
- キー文字列そのものをチャットに貼るのは最小限に。可能なら「取得できた／できない」だけ教えていただければ進められます。
