## 1. このツールで「できること」（MVP スコープ）

### 🟢 MVP（v0.1）に入れる機能（must-have）

| # | 機能 | 説明 | 元ネタ |
|---|---|---|---|
| F1 | **キーワード／ASIN/JAN リサーチ** | 1件の商品コードを入力→Keepa から Amazon 側データを取得 | ADD×ONE と同等 |
| F2 | **Yahoo!ショッピング・楽天 横断検索** | 同一商品の最安値仕入れ候補を公式 API で取得 | ADD×ONE と同等 |

| F5 | **結果テーブル一覧** | ASIN／タイトル／売値／仕入値／利益／利益率／月販／Drop30／仕入元 を1画面で | ADD×ONE と同等 |
| F6 | **お気に入り保存（ローカル）** | 後で見返す商品を SQLite に保存。CSV エクスポート可 | ADD×ONE にあり |

## 2. 既存ツールとの差別化（サトル・タケシ統合）

| 軸 | Keepa 単体 | SellerSprite | アマサーチ | ADD×ONE | **Sato-Scope（本案）** |
|---|---|---|---|---|---|
| Amazon 売上データ | ◎ | ◎ | ○ | ◎（Keepa利用） | ◎（Keepa公式API） |
| 仕入れ先横断検索 | × | △ | × | ◎（Yahoo他） | ◎（公式API） |
| 真の利益計算 | △ | ○ | ○ | ○ | **◎**（自己発送＋MSS込み） |
| 判定フラグ | × | ○ | △ | ◎ | ◎ |
| 月額費用 | €19〜49 | $39〜 | 無料〜2,980円 | 150万円コース付属 | **€49 + 月数百円** |
| ToS リスク | なし | なし | なし | スクレイピング疑い | **なし（公式 API のみ）** |
| 社長専用カスタマイズ | × | × | × | × | **◎**（社長の好みに合わせ放題） |
| 学習コスト | 中（英語） | 高（英語） | 低 | 中（コミュ依存） | 低（自社で改修可） |

**戦略的優位（タケシ視点）**：
1. **ToS クリーン**: 朝野氏推奨ツール群（ポイポイポケット等）の多くは規約グレーゾーン。本案は法務リスクゼロで長期運用可
2. **物販ナレッジ１を反映した利益計算**: FBA vs 自己発送の真の利益式と MSS（マーケットプレイス配送サービス）の節約効果を表示できるツールは既存ツールに存在しない（朝野氏のコンサル動画の核心が「ツール化」されていない）
3. **社長専用＝改修自由度**: 大衆向けツールにできない「副業初心者にも分かるUI」「カズヨ口調のサジェスチョン」を埋め込める

## 3. MVP 仕様（タケシ確定版）

### 動作シナリオ

```
[社長] 楽天で気になる商品を発見 → JANコードをコピー
   ↓
[Sato-Scope] JAN入力 → Search ボタンクリック
   ↓
[内部] Keepa API → ASIN特定 → Amazon売値・月販・Drop30取得
       Yahoo!API → 同JANで最安値仕入れ候補取得
       楽天API → 同上
   ↓
[計算] 仕入値 vs 売値で FBA／自己発送 両方の利益計算
   ↓
[表示] 結果テーブル + 判定フラグ（🟢原石／🟡要検討／🔴除外）
   ↓
[社長] 気に入ったら★ボタン → ローカル DB に保存
```

### 入力

- JAN コード（バーコード13桁） or ASIN（Amazon商品コード） or 商品名キーワード

### 出力（1行に表示する項目）

| 項目 | 例 | 出所 |
|---|---|---|
| ASIN | B0CXXX | Keepa |
| 商品名 | XX社 ホットプレート HP-100 | Keepa |
| Amazon 売値 | ¥6,980 | Keepa |
| 月販 | 約 45 個/月 | Keepa |
| Drop30 | 28回 | Keepa |
| 仕入元 | 楽天: ¥3,500 / Yahoo: ¥3,680 | 各API |
| FBA利益 | ¥1,820（利益率26%） | 自社計算 |
| 自己発送利益（MSS） | ¥2,150（利益率31%） | 自社計算 |
| 判定 | 🟢 原石 | 自社ロジック |

### 判定ロジック（v0.1）

```
原石 🟢   : 利益率 ≥ 15% AND 利益額 ≥ ¥500 AND 月販 ≥ 5個 AND Drop30 ≥ 10
要検討 🟡  : 利益率 ≥ 5% AND 利益額 ≥ ¥300（朝野基準）
除外 🔴   : 上記未満
```

しきい値は社長の好みに合わせて画面から調整可能。

## 7. 技術スタック案（タカシ）

```
[フロント] HTML + Vanilla JS + 最小 CSS（モック）
           → 後で Alpine.js or HTMX に拡張
[バック]   Python 3.12 + FastAPI
[DB]       SQLite（社長 PC ローカル）
[API]      adapters/keepa.py / adapters/yahoo.py / adapters/rakuten.py
[計算]     calc/profit.py（FBA / 自己発送 / MSS 三本立て）
[認証]     当面なし。デプロイ時に Basic 認証 1人分
[配信]     当面 localhost。慣れたら Railway か Tailscale で社長端末間共有
```

設計原則：
- 外部 API は必ずアダプタ越し（差し替え可能性）
- 利益計算は UI から独立した純粋関数（テストしやすい）
- シークレットは `.env`、Git 管理外
