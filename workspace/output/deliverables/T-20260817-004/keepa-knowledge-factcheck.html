#本書の記述判定正（公式定義）
D5「↘31ドロップ/月」を主軸指標として扱い、関連資料で「BSRの急落回数＝推定販売件数」「＝売れた回数」と断定❌ 断定を撤回公式 salesRankDrops30＝「直近30日間の売れ筋ランキング下落の回数。販売を示すものとみなされる（considered to indicate sales）」。「販売個数と等しい」とは一言も書かれていません。1回のランク更新中に複数個売れても1ドロップなので構造的に過少になりうる代理指標。指標として使うのは妥当だが「推定販売件数」という断定形は使わない（正しくは「販売の代理指標」）
D6関連ナレッジで monthlySold を「月間売上予測」と表記❌ 誤り公式：「過去1か月にこの商品が購入された回数。Amazon 検索結果の "bought past month" の値。推定値ではない（It is not an estimate）」。「予測」は誤りで実測値です。ただし但し書きが必須：Amazon は "10+" "100+" のような階級値でしか提供しないため 1000＝「少なくとも1000回」であり、大半のASINはこの値を持たない（欠測）。値はバリエーション単位。「実測だから正確な数字」と読むのも同じくらい危険
D7「v1.3 の足切りに既に入っています（current_AMAZON_gte=-1 & current_AMAZON_lte=-1＝本体在庫なし／Amazon在庫切れ率90%以上）」❌ 実装に存在しないscan_v13.py の Finder ペイロードに outOfStockPercentage90 系のフィルタはありません（コード全文確認）。本書が実装より強く書かれていました。さらに current_AMAZON = -1 は「今この瞬間 Amazon 価格が無い」の意味で「Amazon が出品していない」ではありません。専用フィールド availabilityAmazon（-1＝Amazonのオファーが存在しない）が公式に存在します（discrepancies.md D3・社長 Go 済み・タカシが修正実施）
✅「新品 - 下落（直近7日間）に −99〜−30 で値上がり商品を抽出」→ 本書は「符号仕様は公式ドキュメントで裏が取れず。実機で1回試せば即確定」としていた✅ 解決・動画が正しい公式 deltaPercent[1,7,30,90]_<PRICE_TYPE>：「正の値は値下がりしたものを、負の値は値上がりしたものを絞り込む」。うみぞう動画の主張は公式仕様どおりで、実機テストは不要になりました。探し先（APIドキュメントの Product Finder ページ）が分かっていなかっただけです

「AIで抽出できないのか」への答え

抽出そのものはAIにやらせません。 Keepa API ＋ スクリプト（決定論的・数字が正確）が担当し、AIは「判定の要約・優先順位づけ・文章化」だけを担います。ここを逆にすると、社長が8/10にご指摘された「AIリサーチの数字が不正確で訂正作業に潰される」の再発になります。

⚠️ 当社未検証・要確認：2026年3月のAmazon BSA改定で「Agent Policy」が新設され、Amazonデータのスクレイピング／AI学習が明示的に禁止された、という報告があります。Keepa API 経由は正規ライセンスなので問題ありませんが、「トークン節約のために直接スクレイピング」という逃げ道は取らない方針とします。

2-2. 仕入れ個数の決め方 ― 当社の②メーカー仕入れでも有効

自分の月間販売ペース ＝ 月間販売個数 ÷（出品者数 ＋ 1人） 原則：1ヶ月以内に売り切れる個数だけ仕入れる

当社の「消化月数」基準（T-20260817-002 段1）とまったく同じ思想です。動画側は「1ヶ月」、当社は「3ヶ月以内」と閾値が違うだけ。せどりは資金回転が命なので1ヶ月、当社はメーカー仕入れでロットがある分3ヶ月、という違いで整合します。

2-3. 知財クレームを見抜く5サイン 当社にも直結

  1. 出品者に「〇〇公式」「株式会社〇〇（正規店）」がいる
  2. 出品者グラフが突然垂直に落下している（＝一斉通報・削除の跡）
  3. 出品者が常に1人（相乗りしてもすぐ排除されている）
  4. 価格が一切ブレず完全に水平（メーカーが価格統制している）
  5. ドラッグストア・コスメ・ヘアケア・サプリメント等の規約が厳しいカテゴリ

これは出品制限（ゲート）とは別軸のリスクです。ゲートは「Amazonが入口で止める」、知財クレームは「権利者が後から通報して消しにくる」。ゲート側は T-20260817-003 のガイドが担当します。
※ 当社の②メーカー仕入れはメーカーから直接買うため、このリスクは構造的に低い（むしろ自分が①②の側になる）。相乗り候補を見るときの警戒サインとして使います。
