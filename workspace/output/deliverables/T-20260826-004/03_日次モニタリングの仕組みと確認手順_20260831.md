## 1. 何を毎日確認するか

毎日 12:00、秘書カズヨがブラウザで下記を巡回します。

| # | 画面 | 見るもの |
|---|---|---|
| 1 | カナダ パフォーマンス通知 | 件数と最新の件名・日付 |
| 2 | カナダ アカウント健全性 | AHR・優先アクション・問題件数・停止表示 |
| 3 | カナダ 再開申請ページ | 違反件数と各申し立てのステータス |
| 4 | カナダ アカウント情報 | 上部の制限バナーの文言 |
| 5 | 日本 パフォーマンス通知 | 件数と最新 |
| 6 | 日本 アカウント健全性 | AHR・問題件数 |
| 7 | サポートケース一覧 | ステータスと Amazon の最終返信日時 |
| 8 | Gmail | `from:amazon` の新着 |

結果は毎日 `workspace/monitoring/amazon-daily-check.md` に1件追記され、その場で commit されます。
**変化がなくても1件書きます。** 書かれていない日＝実行されなかった日です。

パスワード入力・申し立ての送信・設定変更はしません（CLAUDE.md §4.1）。文面の準備までです。

## 2. 動いているかを社長が自分で確かめる方法

どれか1つで十分です。**上から順に手軽です。**

### 方法A：ログを見る（一番確実）

エディタかターミナルで開きます。

```

```

先頭の `## YYYY-MM-DD` が今日か昨日なら動いています。日付が飛んでいれば、その日は動いていません。

> このファイルは Finder のブックマーク（`AI Company Outputs`）には出ません。あちらは成果物フォルダへのリンクで、ログはリポジトリ内の別の場所にあるためです。この手順書自体はブックマークから見えます。

### 方法B：アプリのサイドバー「Scheduled」を見る

`amazon-seller-central-daily-check` があり、有効になっているかを見ます。
2026-08-31 時点の登録内容：

| 項目 | 値 |
|---|---|
| 名前 | amazon-seller-central-daily-check |
| スケジュール | 毎日 12:00（`0 12 * * *`） |
| 状態 | 有効 |

一覧に無い、または無効なら**登録が消えています**。カズヨに再登録を頼んでください。

### 方法C：git の履歴を見る

```

```

`chore(monitoring): Amazonセラーセントラル日次確認 …` が毎日1行ずつ増えていれば動いています。
**この方法だけは改ざんが効きません。** 日付はコミット時刻として残ります。

## 3. 動かない条件（正直に書きます）

このスケジュールタスクは万能ではありません。次の場合は動かないか、途中で失敗します。

| 条件 | 何が起きるか | どうなるか |
|---|---|---|
| 12:00 にアプリが閉じている | その時刻には実行されない | **次にアプリを起動した時に走ります**（12:00 ちょうどではない） |
| Mac がスリープ／電源オフ | 同上 | 起動後に走ります |
| Chrome が起動していない | 画面確認ができない | ログに「未確認」と記録され、社長に報告が来ます |
| セラーセントラルのログインが切れている | ログイン画面で停止 | パスワードは入力しません。**社長のログインが必要**です。報告が来たらログインしてください |
| ネットワーク断 | 画面確認が失敗 | 「未確認」として記録されます |

**「未確認」と書かれた行は、確認できていない行です。** 変化なしとは違います。ここを混同しないでください。

## 4. 実行漏れはどう分かるか

セッションを開始するたび、フック `.claude/hooks/session-start.sh` がログの最新日付を読みます。
**2日以上前なら、カズヨの画面の先頭に警告が出ます。**

> 【SessionStart リマインダー⑤：Amazon 日次チェックが N 日間実行されていません】
> 最後の記録は YYYY-MM-DD。日次チェックが N 日間実行されていません。スケジュールタスクが止まっている可能性があります。

ログファイルごと消えた場合も、記録が0件の場合も警告します。
判定材料は**ログに行が増えたことだけ**です。スケジューラの内部状態は見ません。「実行したが何も確認できなかった」を成功と数えてしまうためです。

警告が出たら、まずその場で手動確認を回し、そのうえで §2 の方法Bで登録の生死を点検します。
