## 3. 言ってはいけないこと

| 禁止 | 法務としての根拠 |
|---|---|
| **憶測で答える**（「たぶん」「〜だったと思います」で断定する） | 停止事由は ABSA **Section 3(b)**「your account has been, or our controls identify that it **may** be used for deceptive or fraudulent, or illegal activity」。**発言と記録の食い違いは、この「可能性」を裏づける材料になります**（出典：https://sellercentral.amazon.ca/help/hub/reference/external/G1791?mons_sel_locale=en_CA 2026-08-28 取得） |
| **覚えていないのに断定する** | 画面のチェックボックスに「品質管理・監査目的で**録画される場合がある**」と明記（2026-09-02 実測）。**発言は記録に残り、後から訂正しても記録は消えません** |
| **規約論争を持ち出す**（「3(b) は不当だ」「自動検知の誤りだ」） | ABSA は 3(b) の適用に不正の**認定を要求していません**（条文上「controls identify that it may be」で足りる）。**条文解釈で争う場ではありません。**加えて ABSA は準拠法＝ワシントン州法・紛争解決＝AAA 仲裁・クラスアクション放棄を定めており、**法的に争うルートは実質的に選べません**（同上） |
| **Amazon 側の不備を責める**（案内メールが来なかった等） | 面談担当者に停止解除や規約解釈の権限はない**と考えられます（※推測）**。不服はサポートケースで文書として処理するのが筋です |
| **感情的な訴え**（生活が困る、事業が止まる） | 本人確認の判定材料になりません。時間を10分から削るだけです |
| **家族・第三者に代わりに答えさせる** | 「アカウントの共有」を疑わせます（§2 の Q7 と正面から矛盾する） |

**正しい答え方は「分からないことは分からないと言う」です。**

「分かりません。手元で確認してご連絡します」は、本人確認において**減点になりません**。理由は2つ。
① 面談の目的は身元の確認であり、記憶力の試験ではない（画面表示の所要10分・要求物が身分証原本のみ、という設計から読める）。
② 一方、誤った断定は 3(b) の「虚偽」に直結します。**沈黙のコストより、誤答のコストが圧倒的に大きい。**これが法務の判断です。

## 4. 終了時に必ず確認する（5つ）

面談の最後に「いくつか確認させてください」と切り出して聞いてください。**メモを取りながら。**

1. **本日の確認で、不足している書類や追加提出物はありますか**
2. **結果はどこに、いつ通知されますか**（メールか、セラーセントラルのどの画面か。何営業日か）
3. **アカウント健全性評価（AHR）が 0 です。本人確認が完了すれば回復しますか。別の手続きが必要ですか**
   - 根拠：停止事由は 3(b) と 3(d)（AHR が閾値未満）の**2本**。**3(b) が晴れても 3(d) は自動では消えない可能性があります**。ここを確認しないと、面談を通過しても止まったままになり得ます
4. **日本ストア（amazon.co.jp / Satoy Select）の復活手順は、CA 再開後に日本店の「アカウントを再アクティブ化」から CA の再開日を入力する、という理解で正しいですか**
5. **本件の参照番号（ケース番号）を教えてください**

**終了直後に、聞かれた質問・答えた内容・言われた次の手順を、記憶が新しいうちに書き出してください。**カズヨに渡せばチケットのログに残します。
