前提（社長確定）: 初回からフル外注（FBA納品代行業者＋FBA）。社長は物を一切触らず、PC上で発注・指示・リサーチのみ＝完全PC完結。

副業初心者 / 個人事業 / 予算上限10万円 / 出品プラン=小口 / 店舗名=Satoy Select / Amazonセラー有効化済。仕入れ=B（国内卸=NETSEA等）→将来C。規制低カテゴリ（日用品雑貨・文具）中心。

料金・サービスは変動するため「2026年6月時点の目安／要確認」。出典は末尾。

このイシュー（最初に読む1画面）

答えを出すべき問い: 「社長が物を一切触らずに、卸で仕入れた商品をAmazonで売り切るには、どの業者を、どう使い、いくらコストが乗り、損益判定をどう変えるべきか」

  1. 物流の型は「NETSEAで卸発注 → 送り先を“FBA納品代行業者の倉庫”に指定 → 業者が検品・ラベル貼り・梱包・FBA納品 → 以降Amazonが販売・発送」。社長のタッチポイントは「PCで発注」「業者へ納品依頼」「ERESAでリサーチ」の3つだけ。
  2. 代行費の目安は2026年時点で1点40〜120円＋月額0〜4,900円＋荷受50円/箱（業者・会員プランで変動）。少量だと“最低利用料”が効いて割高（例: ラクロジは月の代行料が5,000円未満だと+3,000円）。
  3. 外注費を損益に必ず乗せるため、価格差リサーチガイド（T-20260603-002）の利益判定を“外注費込み”に上書き。「1個300〜500円残る」→「代行費を引いた後で300円以上残る」へ厳格化＝薄利商品はこれまで以上に弾かれる。

ひとことで: 「完全PC完結」は技術的に可能。ただし“少量×代行費”は割高になる構造なので、最初から「代行費を引いても利益が残る商品」だけを選ぶリサーチ規律が前提。

2. FBA納品代行業者（プレップセンター）とは

「あなたの代わりに、仕入れた商品をAmazon FBA倉庫に納品できる状態に整えて、Amazonへ送ってくれる外注倉庫」です。「prep（プレップ）」は prepare（準備する）の略。

作業内容外注する意味
荷受け卸/メーカーから直送された荷物を業者倉庫で受け取る自宅に荷物が来ない（スペース不要・在宅不要）
検品数量確認・破損/不良チェック不良品をAmazonに送る事故を防ぐ
商品ラベル貼りAmazonのFNSKUラベル（商品識別バーコード）を1点ずつ貼るFBA納品の必須作業を肩代わり
梱包/袋詰めOPP袋封入・緩衝材梱包などFBA要件に合わせる規定違反による受領拒否を防ぐ
FBA納品（発送）Amazon指定倉庫へ納品プラン通りに送る物流の最終工程まで代行
用語整理: FBA＝販売後の保管・梱包・発送・カスタマー対応・返品をAmazonが代行する仕組み。FBA納品代行（プレップセンター）＝そのFBA倉庫へ送り込む前の準備作業を代行する外注先。この2つを組み合わせると仕入れ後の物理作業がゼロ＝完全PC完結。

6. 損益への織り込み — 「外注費込み」で利益判定を上書き

6.1 フル外注の利益式（T-20260603-002 §4を上書き）

1個あたり利益 = 販売価格
              −（仕入値 + 卸送料/個）
              − 販売手数料（販売価格 × カテゴリ料率）
              − FBA配送代行料（1個あたり定額・Amazonに払う）
              − FBA在庫保管料/個
              − ★FBA納品代行業者の代行費/個（40〜120円目安）        ← 追加
              − ★代行の月額固定費・最低利用料の按分/個             ← 追加（少量ほど重い）
              − ★荷受料(50円/箱目安)・オプション(OPP袋/プチプチ等)の按分/個  ← 追加

価格差リサーチガイド §3 #1「1個300〜500円残る」は、上記★を引いた“後”で満たすことに上書き。特に効くのが“月額＋最低利用料”の按分。

6.2 具体例で1件試算（ホーム&キッチン小物・ラクロジ想定）

T-20260603-002のステンレスタンブラー（販売2,780円/仕入1,400円/卸送料按分130円/販売手数料15%=417円/FBA配送代行料455円/保管16円）に、ラクロジ代行費40円/個・荷受50円/箱(=1箱20個→2.5円/個)を加える。

ケースA: 月20個（少量）ケースB: 月150個（適量）
代行料合計40×20=800円 → 5,000円未満で+3,000円40×150=6,000円（追加なし）
外注固定費（月額+最低利用料）2,000+3,000=5,000円2,000円のみ
固定費の1個按分250円/個約13.3円/個
1個あたり利益2,780−1,400−130−417−455−16−40−2.5−250 = 約69.5円2,780−1,400−130−417−455−16−40−2.5−13.3 = 約306円
利益率約2.5%（基準割れ→見送り）約11%（利益額は基準到達）

結論: 同じ商品でも「月20個」と「月150個」で1個利益が69円→306円と激変。原因は外注の月額＋最低利用料の按分。フル外注では「1商品を少量」より「数SKUをまとめて一定量」流す方が単位コストが下がる。

リサーチ規律の上書き（社長への実務指示）: 価格差リサーチガイドの1枚チェックシートに 「⑩ 外注費（代行費＋月額/最低利用料の按分）を引いても300円以上残るか？」 の行を追加。これが今回の最重要アップデート。
