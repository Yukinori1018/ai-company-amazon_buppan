## このイシュー（最初に読む1画面）

**答えを出すべき問い: 「社長が物を一切触らずに、卸で仕入れた商品をAmazonで売り切るには、どの業者を、どう使い、いくらコストが乗り、損益判定をどう変えるべきか」**

結論を3行で：

1. **物流の型は「NETSEAで卸発注 → 送り先を“FBA納品代行業者の倉庫”に指定 → 業者が検品・ラベル貼り・梱包・FBA納品 → 以降Amazonが販売・発送」**。社長のタッチポイントは「PCで発注」「業者へ納品依頼」「ERESAでリサーチ」の3つだけです。
2. **代行費の目安は2026年時点で1点あたり40〜120円＋月額0〜4,900円＋荷受50円/箱**（業者・会員プランで変動）。**少量だと“最低利用料”が効いて割高**になります（例: ラクロジは月の代行料が5,000円未満だと+3,000円）。
3. **この外注費を損益に必ず乗せるため、価格差リサーチガイド（T-20260603-002）の利益判定を“外注費込み”に上書き**します。1個あたり利益の目安は「300〜500円残る」から、**代行費40〜120円を引いた後で300円以上残る**へ厳しくなります＝薄利商品はこれまで以上に弾かれます。

> ひとことで: **「完全PC完結」は技術的に可能。ただし“少量×代行費”は割高になる構造**なので、最初から「代行費を引いても利益が残る商品」だけを選ぶリサーチ規律が前提になります。

## 2. FBA納品代行業者（プレップセンター）とは

**FBA納品代行業者（プレップセンター, prep center）とは、「あなたの代わりに、仕入れた商品をAmazon FBA倉庫に納品できる状態に整えて、Amazonへ送ってくれる外注倉庫」**です。「prep（プレップ）」は prepare（準備する）の略で、Amazonに納品する前の下準備を代行する、の意味です。

具体的に代行してくれる作業：

| 作業 | 内容 | これを外注する意味 |
|---|---|---|
| **荷受け** | 卸/メーカーから直送された荷物を業者倉庫で受け取る | **自宅に荷物が来ない**（スペース不要・在宅不要） |
| **検品** | 数量確認・破損/不良チェック | 不良品をAmazonに送る事故を防ぐ |
| **商品ラベル貼り** | AmazonのFNSKUラベル（商品識別バーコード）を1点ずつ貼る | FBA納品の必須作業を肩代わり |
| **梱包/袋詰め** | OPP袋封入・緩衝材（プチプチ）梱包など、FBA納品要件に合わせる | 規定違反による受領拒否を防ぐ |
| **FBA納品（Amazon倉庫へ発送）** | Amazonが指定する倉庫へ、納品プラン通りに送る | 物流の最終工程まで代行 |

> 「FBA納品代行」と「FBA」の違い（用語整理）:
> - **FBA（フルフィルメント by Amazon）**＝Amazon倉庫に商品を預ければ、**販売後の保管・梱包・発送・カスタマー対応・返品をAmazonが代行**する仕組み。これは社長がすでに使う前提。
> - **FBA納品代行（プレップセンター）**＝そのFBA倉庫に**送り込む前の準備作業（検品・ラベル・梱包・納品発送）を代行**する外注先。**この2つを組み合わせると、仕入れ後の物理作業がゼロ**になり、完全PC完結が成立します。

> 前提: 社長は事前に「①Amazonセラー（小口・有効化済）」「②使う代行業者の契約」「③NETSEA等の卸会員登録」を済ませる。

| ステップ | 物の流れ | 社長がPC画面でやること |
|---|---|---|
| **S0 リサーチ** | （まだ動かない） | ERESA PROで候補を「§6の外注費込み損益」で判定 → 仕入れる商品とロットを決める |

## 6. 損益への織り込み — 「外注費込み」で利益判定を上書きする

### 6.1 フル外注の利益式（T-20260603-002 §4を外注費込みに上書き）

```
1個あたり利益 = 販売価格
              −（仕入値 + 卸送料/個）
              − 販売手数料（販売価格 × カテゴリ料率）
              − FBA配送代行料（1個あたり定額・Amazonに払う）
              − FBA在庫保管料/個
              − ★FBA納品代行業者の代行費/個（40〜120円目安）       ← 今回追加
              − ★代行の月額固定費・最低利用料の按分/個            ← 今回追加（少量ほど重い）
              − ★荷受料(50円/箱目安)・オプション(OPP袋/プチプチ等)の按分/個  ← 今回追加
```

- **価格差リサーチガイド（T-20260603-002）§3 #1の利益判定「1個あたり300〜500円残る」は、上記★を引いた“後”で満たすこと**に上書きします。
- **特に効くのは“月額固定費＋最低利用料”の按分**。少量期はここが1個あたり数十〜数百円に化けます（下の例）。

### 6.2 具体例で1件試算（ホーム&キッチン小物・ラクロジ想定・少量と適量を比較）

T-20260603-002 §4.2のステンレスタンブラー（販売2,780円/仕入1,400円）に、**ラクロジの代行費**を乗せます。

**共通項目**（T-20260603-002より）:
- 販売価格 2,780円 / 仕入値 1,400円 / 卸送料按分 130円 / 販売手数料15% 417円 / FBA配送代行料(標準) 455円 / FBA保管料 16円
- 代行費（ラクロジ基本）40円/個 / 荷受 50円/箱（仮に1箱=20個 → 2.5円/個）

**ケースA: 月20個だけ納品（少量）**
- 月の代行料 = 40円×20個 = 800円。**ラクロジは月5,000円未満で+3,000円**の最低利用料 → 月の外注固定的コスト ≒ 月額2,000円 + 追加3,000円 = **5,000円**。
- これを20個で按分 = **250円/個**。
- 1個あたり利益 = 2,780 −1,400 −130 −417 −455 −16 −40（代行）−2.5（荷受）−250（月額+最低利用按分）= **約69.5円**　**利益率 約2.5%**。
- → **T-20260602-002の基準（300円以上/15%）を大きく割り込み“見送り”**。少量×外注費の割高さがそのまま出ます。

**ケースB: 月150個納品（最低利用料の壁を越える適量）**
- 月の代行料 = 40円×150個 = 6,000円（5,000円超 → 追加3,000円は不発生）。固定費は月額2,000円のみ → 150個按分 = **約13.3円/個**。
- 1個あたり利益 = 2,780 −1,400 −130 −417 −455 −16 −40 −2.5 −13.3 = **約306円**　**利益率 約11%**。
- → 利益額は基準ギリギリ到達。**“量を集約して固定費の壁を越える”と外注は現実的になる**ことを示します。

> **結論（事実）**: **同じ商品でも「月20個」と「月150個」で1個利益が69円→306円と激変**します。原因は**外注の月額＋最低利用料の按分**。よって**フル外注では「1商品を少量」より「数SKUをまとめて一定量」流す方が単位コストが下がる**。これは戦略判断の材料（プランナーへ）。

> **リサーチ規律の上書き（社長への実務指示）**: 価格差リサーチガイドの1枚チェックシートに、**「⑩ 外注費（代行費＋月額/最低利用料の按分）を引いても300円以上残るか？」**の行を1つ足してください。これが今回の最重要アップデートです。

### 7.2 注意点・地雷

| 地雷 | 何が起きるか | 回避法 |
|---|---|---|
| **少量割高の罠（最重要）** | 月額＋最低利用料の按分で1個利益が消える（§6.2ケースA） | 外注費込みで利益判定。少量なら数SKUを集約して固定費の壁を越える |
| **大口必須業者を選ぶ罠** | 社長は小口。FBA代行センター等は**大口契約必須で契約不可** | 契約前に「小口出品で契約できるか」を必ず確認（§4★★★） |
| **卸直送NG業者を選ぶ罠** | 自宅経由を強いられ完全PC完結が崩れる | 「メーカー/問屋からの直送受取OK」を公式で確認（ラクロジは明記） |
| **料金非公開で損益が読めない罠** | 単価が見積りでしか出ず、事前に損益へ織り込めない | 公開単価のある業者を優先、または見積りで点/箱/オプション全単価を取得 |
| **FBA納品要件違反** | ラベル/梱包/危険物表示の不備でAmazonが受領拒否 | 検品・ラベル・梱包は業者に任せ、要件を業者と事前すり合わせ |
| **危険物・サイズの罠** | スプレー/リチウム電池単体等は危険物扱い、大型はFBA手数料増 | 規制低カテゴリ（日用品雑貨・文具・標準サイズ）に限定（T-002 §8） |
| **「1点◯円」だけ比較の罠** | 月額・荷受・最低利用料・オプションを見落とし実コストを過小評価 | §3の「実コスト＝点単価＋固定費按分＋荷受＋オプション」で比較 |
| **オプション漏れ** | 日用品でOPP袋/プチプチ必須だと別料金が積む | 取扱商品にどのオプションが要るか業者に事前確認（基本料込みか別か） |
