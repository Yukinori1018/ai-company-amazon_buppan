## 5. なぜこの表現にしたか

### 5-1. 件名に「429」「自動取得」を出さない

件名は**分類**です。用件を1語に圧縮すると、フォームの一次受けで「技術的な質問」「クレーム」に仕分けられ、回答が定型文になります。本件で欲しいのは**判断（許容範囲の提示）**なので、件名は「商品情報の取り扱いについてのご相談」に留め、**お客様番号を件名に入れて会員照会を先に済ませてもらう**設計にしました。

ただし**伏せてはいません**。本文の4行目から自ら開示します。件名で分類、冒頭で開示。これは丸進への1通目（成果物05 §4-1）と同じ設計です。

### 5-2. 開示を「お伺いしたいこと」より前に置いた

順序は**開示 → 停止の報告 → 質問**です。逆にすると、質問に答えた後で「実はもう163社分取っていました」と出す形になり、**後出しに読まれます**。これは避けなければなりません（法務判定30 §5：後から「当社は拒否を迂回していない」と言うための材料は、その時点で残した記録だけ）。

見出しを「**これまでに行ったことを、こちらから先にお伝えします**」としたのも同じ理由です。「ご報告」「お詫び」ではなく「**先にお伝えします**」。自発性が主語に残ります。

### 5-3. 「問題ないと考えます」を1語も書いていない

法務が明確に禁じた主張です（判定29 §1・30 §3）。したがって本文には次のいずれも入れていません。

| 書かなかった表現 | 理由 |
|---|---|
| 「規約に禁止の記載がないため」 | これを書いた時点で**弁解**になり、事前相談ではなくなります |
| 「ログインしていないため会員規約の対象外と理解しています」 | 法務が採れないと判定した主張（29 §2.4）。書けば相手に否認され、心証だけ落ちます |
| 「負荷は軽微です」「一般的な範囲です」 | 軽重を当社が決める文。**決めるのは相手**です |
| 「他社も同様に行っており」 | 比較は言い訳の定型。関係を悪くします |

代わりに置いたのが「**貴社が許容される範囲を当方が把握しないまま続けるべきではないと考え**」です。判断の主体を相手に渡す一文で、本文の背骨にあたります。**ここは削らないでください。**

### 5-4. 質問1に「ご遠慮いただきたい場合」を自分から書いた

**この1文が本文で最も重要です。** 「ご遠慮いただきたい場合は、その旨をお知らせいただければ、以後は行わず、手作業での閲覧に切り替えます。」

理由は2つあります。

1. **回答コストが下がる。** 担当者が「許可を出す権限が自分にあるか」で止まるのを防げます。「ご遠慮ください」と一言返せば済む逃げ道を、こちらから用意しておく。これが**回答が返る確率を上げる唯一の設計**です。
2. **拒否されても関係が壊れない。** 「代替手段がある（手作業に切り替える）」と先に述べているので、相手は「この会員を止める必要はない」と判断できます。会員資格を握っている相手に対し、**拒否の回答を安全な選択肢にしておく**ことが目的です。

なお、この一文は当社にとって不利ではありません。法務の推奨はすでに「発注の直前に人が1社読む」（判定29 §6-A）であり、**手作業への切り替えは当社の既定の方針です。** 譲歩を装った嘘ではありません。

### 5-5. 短縮版で落としたのは第17条だけ

削る順番は、①**第17条の同意のお願い** → ②質問3の「出展企業製品カタログ」の行 → ③開示の箇条書きを1文に畳む、の順で設計しました。短縮版では①と③を実施しています。

第17条を最初に落とす理由は、**今すぐ必要ではない**ためです。当社は現在 URL を社内資料の外に出しておらず（PUBLIC リポには書かない運用）、必要になるのは公開する資料を作る段階です。一方、質問1〜3は**今この瞬間、停止を解くか決めるために必要**です。**1通に詰めて回答の焦点がぼやけるより、第17条は回答を受けた後の2通目に回す**のが順序として正しいと判断しました。

**逆に、短縮版でも絶対に落とさないもの（4点）**

1. お客様番号・会員名・氏名（名乗り）
2. 開示の中身のうち「**画像・卸価格は取得していない／外部転載なし**」
3. 「**現在は自主的に停止しております**」
4. 「貴社が許容される範囲を当方が把握しないまま続けるべきではないと考え」（§5-3）

### 5-6. 質問2の書き方 — 「解除してください」と読まれないようにした

429 の質問は、一歩間違うと「**弾かれたので通し方を教えてください**」になります。そう読まれた記録は、TLS 指紋の偽装と同じ扱いを受けます（判定30 §5）。

そこで文の重心を**末尾**に置きました。「避けるべき条件がございましたら、それに合わせます。」——聞いている対象は**回避の方法ではなく、守るべき条件**です。

事実の書き方も限定しました。「同一のページへ12秒の間隔をあけて送信した2回目で429」。**当社が観測した事実だけ**を書き、原因の推測は「ように見受けられます」に留めています。法務自身が各方向 n=1 で確定していないと明記しているため（判定30 §2）、断定すると**訂正が必要な文を相手に残す**ことになります。

### 5-7. 期限に触れていない

当社は 2026-11-30 のサイトオープン条件を負っていますが、**本文に一切書いていません。** 書けば「期限があるので早く回答してほしい」と読まれ、急かす文になります。「お待ちしております」で止め、**期日を指定していません。**

同時に、**卑屈にもしていません。** 「誠に申し訳ございません」「ご迷惑をおかけしました」を入れていないのは、当社が現時点で違反を確定していない（規約に禁止条項がない／robots.txt 違反もない＝判定30 §4-1）ためです。謝罪から入ると「違反を認めた会員」という記録になります。**開示はする、謝罪はしない。**ここが本件のトーンの中心です。

### 5-8. 体裁の細部

| 判断 | 理由 |
|---|---|
| 【】で見出しを立てた（長文版） | フォームの入力欄は装飾が効きません。プレーンテキストで構造を出す唯一の手段が記号です。担当者が3つの質問を**見つけられる**ことを優先しました |
| 質問を番号付きにした | 回答が番号で返ります。**照合が要らない返信**をもらうための形です |
| 1行を全角35字前後で改行した | フォームの表示幅が不明なため、折り返しに依存しない形にしています |
| 「御社」ではなく「貴社」 | 書き言葉。フォームは文書です |
| 社名を「株式会社ラクーンコマース」と正式表記 | SD の運営会社です。「スーパーデリバリー様」だけでは宛先が事業名になります |
