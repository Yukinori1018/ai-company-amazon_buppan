## 1. 結論（3行）

1. **「NETSEA だけ」は事業判断ではなく道具の都合でした。**NETSEA Buyer API は `jan_code` 単独では 400 を返し、`supplier_ids` の同時指定が必須です。つまり**機械で探せる範囲が「当社が承認を取り終えた220社」に閉じていた**（NETSEA の出店企業は実測 622社）。母集団の 1/3 だけを見て「NETSEA には無い」と言っていたことになります。
2. **社長の「SD の方が得策」は、当たっています。根拠は2つ。**①**母数**：SD の一括申請の結果、**卸価格が見える取引先が 2,176社**（2026-09-30 カズヨが全件吸い出し）。NETSEA の承認済み 221社の**約10倍**です。②**突合の精度**：JAN 記載率 SD 71% / NETSEA 48%、会社情報が非ログインで読める、上代が全件表示。
   **ただし1軸だけ逆です。Amazon への寛容さ**は、**SD は態度が判明した48社中17社（35%）が Amazon を名指しで不可**、NETSEA は実測25商品中1件（4%）。**2,176社のうち約3分の1は Amazon 不可と見込まれます（推測・確度中／根拠は N=55 の人気順サンプル）。申請が通っていても売ってよいとは限りません。**
3. **仮説「SD＝メーカー直販／NETSEA＝転売業者混在」は、NETSEA 側だけ裏が取れました。**NETSEA 自身の「業態」で当社の承認済み210社を数えると**メーカーは25社＝11.9%**、**卸および小売業（＝小売も兼ねる＝同じ棚の競合になりうる）が98社＝46.7%**。一方 SD も公式には「メーカー・卸事業者向け」であって**メーカー専業ではありません**（下の §4 で定量）。

### 4-3. なぜこの差が生まれるのか（出展側の構造）

**事実として言えること**：SD は**10〜15%の従量手数料＋契約締結**という入口なので、薄利で回す転売業者は構造的に入りづらい。NETSEA は**個人事業主でも規約同意で出展でき、EC運営者が卸に回る導線を公式に宣伝している**。
**推測（確度：中）**：この入口の差が、業態構成と「Amazon への態度」の差を生んでいる。SD の出展企業は既存の卸先・ブランド価値を守る動機が強いので Amazon を嫌い、NETSEA の出展企業は販路を問わず数を出したいので Amazon を嫌わない。**つまり「SD の方が良い企業が多い」ことと「SD の方が当社にとって使いやすい」は、同じ理由で両立しません。**

## 7. 中国系（1688 / 義烏購）

**事実**：両サイトとも到達可（HTTP 200・2026-09-30）。
**当社の目的に対する構造的な不一致**：

| 論点 | 内容 |
|---|---|
| JAN | **中国国内向け商品には JAN が付かないものが主体。**Amazon の既存 ASIN（JAN 起点）に当てられない → §3.3-9 の「売れている棚を卸で買えるか」に**使えない** |
| 使えるとしたら | ③簡易OEM／新規 ASIN 作成の経路。①既存棚への相乗りではない |
| 輸入者責任 | 電気用品（PSE）・無線（技適）・食品（食品衛生法）・化粧品/サプリ（薬機法）で**当社が輸入者＝責任者**になる |
| 関税・消費税 | 課税対象。**原価は「卸値＋国際送料＋関税＋消費税＋国内送料」で見ないと必ず外れる** |

## 9. ここから先はタケシ（プランナー）の領分です

事実は出しました。**戦略判断が必要な論点を3つ、そのまま渡します。**

1. **SD と NETSEA の役割分担をどう決めるか。** 事実は「SD＝突合の精度が高いが承認の壁とAmazon NG 35%／NETSEA＝壁が低くAmazon NG 4% だが JAN が半分しかない」。**どちらを主にするかは戦略判断**です。
2. **SD の 11/30 サイトオープン条件と、一括申請の順序。** 事実は「一括申請は事業紹介と店舗画像を更新しないと押せない／キャンセル不可」。**押す前にどこまで店舗情報を磨くかはトレードオフ**です。
3. **上代の4〜6掛けと利益率20%は両立するのか。** SD 公式の目安は4〜6掛け。**6掛けでは利益率20%が数学的に成立しない**ことは既に社内で確定済み（`knowledge_bottleneck_is_suppliers_not_capital`）。**4掛け側の商品だけを狙うのか、単価を上げるのか、条件交渉に行くのかは戦略判断**です。
