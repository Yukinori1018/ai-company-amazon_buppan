## 1. 判定結果

### B0DJNX12KZ — 不二貿易 洗えるバスケット カトラリー収納 2点セット

| 確認項目 | 結果 |
|---|---|
| **① カートの販売元** | ○ **第三者セラー**。独立3根拠（`buyBoxIsAmazon` / `buyBoxSellerId` / カート保持者の直近履歴）が一致 |
| **② 本体の在庫履歴** | ○ **本体は直近1年ずっと在庫なし**。直近90日も在庫なし |
| **③ 出品一覧の実数** | ○ ライブの新品オファー **2本**（出品者2／FBA 1・自己発送 1）。**本体は含まれない** |
| **総合** | ✅ **GO** |

### B0FN3NWKYZ — サンワダイレクト LEDライト 作業灯 充電式（800-LED096BK）

| 確認項目 | 結果 |
|---|---|
| **① カートの販売元** | ○ **第三者セラー**。独立3根拠が一致 |
| **② 本体の在庫履歴** | ○ **本体は直近1年ずっと在庫なし**。直近90日も在庫なし |
| **③ 出品一覧の実数** | ○ ライブの新品オファー **1本**（出品者1／自己発送）。**本体は含まれない** |
| **総合** | ✅ **GO** |

カート保持者は**自己発送**の1社のみです。FBA で入ればカート獲得の位置取りは有利ですが、
**出品者が1社しかいない棚は、当社が入った瞬間に値下げ合戦の相手が1社に特定されます**。
在庫を持つのは当社と相手の2社だけなので、相手が降りなければ価格は下がり続けます。

### 対照: B0FVL8QST6（発注済み・和平フレイズ）

3点すべて FAIL。カート保持者は Amazon.co.jp 本体、本体は直近1年の大半で在庫を持ち、
ライブの新品オファー7本に本体が混ざっていました。

## 3. まだ残っている確認（機械では代替できない）

CLAUDE.md §3.3 は「**社長の Chrome（キーゾン入り）で実画面を見る。API だけで済ませない**」と
定めています。今回の判定は **API 側の3点のみ**で、実画面確認は未実施です。

| 残作業 | 誰が | 内容 |
|---|---|---|
| 実画面のカート保持者 | 秘書カズヨ | 商品ページの「販売元」とキーゾンの「アマゾン直販」表示 |
| 出品一覧の目視 | 秘書カズヨ | `/gp/offer-listing/<ASIN>/?f_new=true` を開いて数える |

Keepa の値は「Keepa がその ASIN を最後に巡回した時点」のものです。**発注の直前に実画面を見る
理由はここにあります。**このツールは実画面確認を置き換えるものではなく、
**実画面を見る前に候補を落とすための関門**です。

## 4. 再発防止として何が変わったか

| 前 | 後 |
|---|---|
| 商品ページの `#merchant-info` 1要素だけを読む | **独立3根拠が2本以上一致して初めて**「第三者」と判定 |
| 根拠が取れなければ暗黙に「本体なし」扱い | **UNKNOWN として明示し、絶対に GO にしない**（fail-closed） |
| オファー本数だけを見る | ライブの新品オファーを**出品者単位**で数え、**本体の有無を内訳で出す**。一覧が打ち切られていたら UNKNOWN |
| 人が毎回目視 | **コマンド1本で何件でも。判定基準はテスト15件で固定** |

判定ロジックは `verdict.py` に純関数で切り出してあり、`python3 test_verdict.py` で
全分岐を検証できます（ネットワーク・Keepa トークンを使いません）。
「本体が居るのに GO」「データが無いのに GO」を落とすテストが入っています。
