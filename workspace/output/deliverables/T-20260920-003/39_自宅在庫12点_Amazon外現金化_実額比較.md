## 5. FBM（出品者出荷）でも駄目かの検算 — 結論：駄目。配送方法は制限の判定に入らない

**事実（一次情報）**：Amazon が公開している Selling Partner API の出品制限モデル
`listingsRestrictions_2021-08-01.json`（amzn/selling-partner-api-models、2026-10-09取得）では、

1. 出品制限を取得する `GET /listings/2021-08-01/restrictions` のリクエストパラメータは
   **`asin`（必須）／`conditionType`／`sellerId`（必須）／`marketplaceIds`（必須）／`reasonLocale`／`productType`** の6つだけ。
   **FBA か出品者出荷かを指定するパラメータは存在しない。**
2. 返ってくる `Restriction` オブジェクトは **`marketplaceId` × `conditionType`** で修飾される。
   `conditionType` の enum は `new_new` / `new_open_box` / `new_oem` / `refurbished_refurbished` / `used_*` / `collectible_*` / `club_club` の13種。
   **ここにも配送方法の次元が無い。**
3. `reasonCode` の enum は3種のみ：
   - `APPROVAL_REQUIRED` — 「承認が必要。**解除経路（path forward link）が提供される**」
   - `ASIN_NOT_FOUND`
   - **`NOT_ELIGIBLE` — 「指定ASINの出品を作成する資格がない。**制限を解除する path forward link は提供されない**」**

**判定**：10/9 に通った和平フレイズのブランドゲートは `APPROVAL_REQUIRED` 型（解除経路あり＝書類で開いた）。
いま残っている「現在、この商品の新しい出品情報は受け付けておりません」は **`NOT_ELIGIBLE` 型＝解除経路が存在しない**制限である。
**制限は ASIN × マーケットプレイス × コンディションで決まり、配送方法（FBA／出品者出荷）は判定要素に入っていない。したがって FBM に切り替えても結果は変わらない。**

**出典**
- `https://raw.githubusercontent.com/amzn/selling-partner-api-models/main/models/listings-restrictions-api-model/listingsRestrictions_2021-08-01.json`（Amazon公式リポジトリ amzn/selling-partner-api-models、取得 2026-10-09）
- 補強：実機で確認した制限ページの URL 自体が `?asin=B0FVL8QST6&itemcondition=New` の2変数しか取らず、拒否文が「**その他の商品／再生品のコンディションの…／コレクター商品のコンディションの…**」とカテゴリー×コンディションで列挙されている（2026-10-09 社長環境で確認済み・チケット記載）

**確度：高。**（Amazon公式のデータモデルによる構造的な証明。実機でのFBM操作は未実施だが、モデル上そもそも分岐点が存在しない）

## 6. 推奨：A（Yahoo!フリマ・単品 × 12口）

### 理由（損益と作業時間の両方を加味）

1. **黒字になりうるのは A だけ。** A の損益分岐は2,680円（手数料0%特典時 2,546円）で、燕三ブランド新品の実SOLDレンジ（2,250〜8,000円）に入る。C は2,048円/個・B は1,860円/個が分岐点だが、まとめ売りの実SOLDは1,100〜1,200円/点で、**どう値付けしても届かない**。
2. **売り切れる確度が最も高い。** 同じ鍋を3個・12個欲しい買い手は家庭には存在しない（業務用のみ）。単品の買い手母数が最大。現金化できない在庫は、損益がいくらでも意味がない。
3. **新規出品者の手数料0%特典（90日・50件）は複数出品でしか取れない。** 条件は「はじめての出品から30日以内に3個売れる」。B（1口）では構造的に達成不可能、C（4口）でも効くのは最後の1口だけ。A なら4件目以降が0%になり、損失が ▲2,284円 → **▲1,168円**に下がる。
4. **作業は166分（2.8時間）で、4.5時間ではない。** 写真1セット・複製出品・ヤマト集荷（または外出ついでのコンビニ持込）で、1件あたり9分×12回に分散する。まとめ売り（B・59分）との差は107分だが、その107分で損益が5,978円変わる（＝**時間を3,350円/時で売る**取引）。
5. **副産物：Amazon 以外の販路の一次データが12サンプル取れる。** 当社はフリマ販路の売価・回転・発送オペの実測値を1件も持っていない。12点は、損失1千円台でこれを買える規模のテストになる。

### 推奨の前提が崩れる条件（これに当たったら C へ落とす）

- 最初の3件が**30日以内に売れない**（＝0%特典が取れず、かつ単品の回転が実測で遅いと判明）
- 最初の数件の**実売が2,000円を割る**（この場合 A の損益は ▲7,756円まで悪化し、C（▲4,876円）に劣後する）
- → **先に3点だけ単品で出し、実売価格と日数を実測してから残り9点の荷姿を決める**のが、情報の価値を考えれば合理的。これは戦略判断なので**タケシ（プランナー）の領分**。
