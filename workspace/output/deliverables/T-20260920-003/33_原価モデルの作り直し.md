## 0. 結論（先に3行）

1. **社長の指摘は正しい。**821円は、〔別商品の標準区分3の配送代行 415円〕＋〔22cm土鍋1点の実測 206円〕＋〔費用でない安全マージン 200円〕の合算で、**小型雑貨の実額は351円**（売価1,000円以下なら 285円）でした。**470円（57%）が架空**です。内訳：誤差幅 200円（そもそも費用ではない）／FBA配送代行の過大 127円（415→288）／保管料の過大 82円（87→5.1）／納品送料の過大 44円（64→20.3）／梱包資材の過大 42円（55→12.8）。※外注費25円は旧モデルに無かったので新モデル側で足しています。
2. **1点の原価を税込220円と置くと、小型区分・ホーム&キッチンの単品は売価600円から黒字、750円で利益率27.1%です。**旧モデルが同条件に引いた線は **1,369円**。正しい損益分岐（535円）の **2.6倍**でした。
3. ただし **648件が0件になった主因は原価モデルではありません。**648件のうち採算の線をクリアしていたのは **226件**（44.9%）。その226件を落としたのは〔単位ずれ疑い83件／売れ筋ランクによる生存判定181件／Amazon本体の存在／1SKU発注額が予算枠超過〕です。**原価モデルを直すだけでは GO は出ません。**次に直すのはセット数（単位）の確定と予算枠の置き方です。

## 1. 821円の内訳と、どこが間違っていたか

### 1.1 旧モデルの式（`set_family.py` / README 720行）

```
必要な売価の下限 = (821 + 1.1 × 仕入原価〔税抜〕 × n) ÷ 0.8376
  821円  = FBA配送代行 415 ＋ 保管 87 ＋ 納品送料 64 ＋ 梱包資材 55（=206） ＋ 誤差幅 200
  0.8376 = 1 − 販売手数料 8.4%×1.1（=9.24%） − 誤差幅 7%
```

### 1.2 誤りの一覧（金額つき）

| # | 項目 | 旧 | 正 | 差 | 誤りの性質 |
|---|---|---|---|---|---|
| ① | 誤差幅（固定ぶん） | 200円を**費用として加算** | 0円 | **−200円** | 判定の不確実性を原価に混ぜた。二重に厳しい |
| ① | 誤差幅（率） | 7% を**分母から引く** | 0pt | **分母 +0.07** | 同じ。売価500円では誤差幅が売価の47%になる（後述 §6） |
| ② | FBA配送代行 | 415円（全商品） | 小型 **222〜288円**／標準1 252〜318円／標準3 358〜415円 | **−127〜−193円**（小型） | **415円は成果物10（別商品・標準区分3）の値**。鍋 L001 の実測は 472円（標準区分7）で、出典が混ざっていた（サトルが 2026-10-04 に特定） |
| ③ | 保管料 | 87円 | 小型雑貨 **5.1円** | **−82円** | 22cm土鍋（体積6,728cm³・繁忙期1.5ヶ月）の実測を小型雑貨（600cm³）に当てた |
| ③ | 納品送料 | 64円 | 1箱30個で **20.3円**／100個で6.1円 | **−44〜−58円** | 箱単位の費用を按分していなかった＝「量で薄まる」が入っていない |
| ③ | 梱包資材 | 55円 | 1箱30個で **12.8円** | **−42円** | 同じ |
| ④ | 販売手数料率 | 8.4% | **ホーム&キッチン/文房具/DIY/家具は15.4%** | **逆に +7pt 厳しくなる** | 誰も気づいていなかった4つ目の誤り。8.4%は服&ファッション小物の率 |

- ①②③の合計で旧モデルは **470円/個 厳しすぎ**（小型区分。外注費25円を新たに足した後の純差）、④で **売価の7.7pt（税込）甘すぎ**。向きが逆の誤りが同居していました。
- 社長の「固定費がかかると言っても、量を増やせば薄まる」は③について正しく、**納品送料・梱包資材・外注費は箱の入り数で薄まります**。一方 **保管料は薄まりません**（体積比例）。**FBA配送代行も薄まりません**（1個につき1回。ただしセットにすれば「Amazonの1個」の数が減る＝後述 §7）。

### 1.3 正しい式

```
必要な売価の下限 P
  = ( FBA配送代行(区分, Pが1,000円以下か)
    + 保管料(体積 × 料率 × 計上月数)
    + FC納品送料(箱代 ÷ 1箱の入り数)
    + 梱包資材(1個固定 + 箱代 ÷ 入り数)
    + 外注費
    + 仕入原価〔税抜〕 × 1.1 × n )
  ÷ ( 1 − 販売手数料率 × 1.1 − 目標利益率 )
```

誤差幅はこの式に入れません（§6 で別建てにします）。

## 6. 🔴 誤差幅は費用と分けてどう扱うべきか（私の意見）

### 6.1 いまのやり方の問題

旧モデルは誤差幅を **売価の7% + 200円** と置き、それを**必要売価の分子・分母の両方に入れていました**。結果：

| 売価 | 誤差幅 | 売価に対する比率 |
|---|---|---|
| 500円 | 235円 | **47.0%** |
| 800円 | 256円 | **32.0%** |
| 1,000円 | 270円 | **27.0%** |
| 2,000円 | 340円 | 17.0% |
| 5,000円 | 550円 | 11.0% |

**低単価商品では「誤差幅が利益の全部を食う」設計です。**社長が狙いたい低単価・高回転の棚だけを狙い撃ちで落とす形になっていました。
加えて、率（7%）と定額（200円）を足す形は、**定額ぶんが単価の小さい側で暴れます**（社内 memory `knowledge_first_purchase_cost_model_2026-09` §2 で同じ事故を記録済み。前回は率が高単価側で暴れました。今回は定額が低単価側で暴れています。構造は同じ）。

### 6.2 推奨：誤差幅は「原価」ではなく「GOの等級」に使う

**① 必要売価の式から誤差幅を外す。**式は実費だけで組む。

**② 不確実性は費目ごとに悲観値を当てて、感度分析にする。**「誤差幅」という1本の数字をやめ、どの前提がどれだけ結論を動かすかを出す。

| 前提 | 中央 | 悲観の当て方（根拠のある幅） | 手残りへの効き |
|---|---|---|---|
| 売価 | 直近のBuyBox価格 | **90日平均と現在値の低い方** | 直接 |
| FBAサイズ区分 | 実寸から当てた区分 | **1段上の区分**（寸法未確定なら） | 最大 +66円 |
| 販売手数料率 | Keepa の実測率 | **そのカテゴリーの最高段（15.4%）** | 最大 +7.7pt |
| 保管月数 | 消化月数÷2 | **消化月数 × 1.0**（＝2倍） | 小型で+3円、大型で+115円 |
| 1箱の入り数 | 容積から計算した満載数 | **その7割** | 送料・資材が1.43倍 |
| セット数 n | 商品名＋`packageQuantity` の一致 | **一致しないなら計算しない（UNKNOWN）** | 符号が変わる |

**③ GOを3等級に分ける。**

| 等級 | 条件 | 行動 |
|---|---|---|
| **A** | 中央・悲観の**両方**で利益率20%以上 | 発注してよい |
| **B** | 中央で黒字、悲観で赤字 | 最小のロットで一度だけ実際に買って確かめる（落とさない。社長は小さく試したい） |
| **C** | 中央で赤字 | 落とす |

**④「単位ずれ」は誤差幅で扱ってはいけません。**これは幅ではなく**真偽**です。Amazonの1個が卸の何点かが確定していない行は、金額を幅で膨らませるのではなく **計算しない（UNKNOWN）** のが正しい。いまのパイプラインは誤差幅で潰していますが、それだと「単位が確定した安い商品」まで一緒に落ちます。

> ひとことで言うと、**誤差幅は「いくら損しうるか」ではなく「どれを人間が確かめるか」を決める道具**です。原価に足すと、確かめるべき候補が見えなくなります。

### 結論：**外注前提では FBM に優位はありません**

| ケース | 判定 |
|---|---|
| **社長の既定方針（物理作業は外注・PC完結）** | **FBM は全手段で FBA より高い。**発送代行の実額（319〜442円/件）で見ると **+219〜+342円/個**。**FBA が正解。** |

**FBMで安くなる条件は3つ全部を満たすときだけです。**①1kg以下、②厚さ3cm以下（三辺60cm・長辺34cm以内）、③**社長自身が梱包・発送する**。
③は社長の方針（`owner_not_labor_intensive_build_systems`：労働集約型は目指さない）と正面から衝突します。

**FBMの非金銭コスト（費用表に出ないが効くもの）**

- **プライムマークが付かない＝カートボックス獲得で不利。**Amazonの購買の約8割はカート経由なので、1個130円の節約よりカート喪失の方が大きい可能性が高い（定量化できていません＝未確認）。
- 出荷遅延率・追跡可能率がアカウント健全性指標に直撃する。社長は過去にアカウント停止を経験しており、ここのリスクは金額換算しない方がよい。
- 返品対応が自社負担になる。

> **推奨：FBA 一本。**FBM は「FBAに入らない商品（危険物・寸法超過）」の逃げ道としてだけ持ち、原価モデルの主系統には入れません。

## 9. 旧モデル vs 新モデル — 648件での検算

データ：`workspace/output/agent_output/T-20260920-003/pipeline/buy_list_private.csv`（648行・NO-GO 479／UNKNOWN 169）。

### 9.1 まず事実 — 「原価モデルが0件の原因」ではありませんでした

**🔴 648件のパイプラインは、固定費821円の式を使っていません。**調べた結果：

|---|---|
| `candidate_pipeline.py`（648件の判定本体） | **Keepa の ASIN別実測値**（`fbaFees.pickAndPackFee` と `referralFeePercent`）。415円固定ではない |
| 同・その他費用 | **206円を全商品に固定**（🔴 ここは誤り。鍋の実測） |
| 同・誤差幅 | 売価7%+200円を**NO-GO ではなく UNKNOWN の線**として使用（費用には足していない） |
| `set_family.py` / `run_supplier_first.py`（卸起点のふるい） | **821円の式を使用**（🔴 ここが全面的に誤り） |
| README 720行の結論「日用消耗品の単品は構造的に赤字」 | **821円の式が根拠**（🔴 結論が誤り） |

### 9.2 503行の分布

| 旧モデルでの位置 | 件数 | 構成比 |
|---|---|---|
| 誤差幅を越えて黒字（採算クリア） | **226件** | 44.9% |

### 9.4 821円の式を使っていた「仕入れ起点のふるい」での効果

カズヨが実画面で見た日用消耗品（Amazon 単品 売価330円／10個セット 2,576円、**仕入原価は売価の59.4%**＝原価率が高い商品）で検算：
