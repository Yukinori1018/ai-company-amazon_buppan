1-4. この表の読み方

  1. 1個の利益だけ見れば BASE が最良（+848円）。 理由は単純で、海外送料を購入者が払うから。鍋の最大のコストは国際送料1,320〜2,460円であり、これを外部化できる唯一の販路が BASE。
  2. しかし BASE は集客がゼロ。 モールではないので「出したら見られる」が成立しない。12点の現金化という目的には最も弱い。
  3. Shopee 台湾は、新規90日の手数料無料を使えば 766 TWD で +449円/個の黒字。 ただし通常期の料率（20.25%）に戻ると 3,800円では ▲96円で、90日が切れた瞬間に赤字に変わる。鍋は「90日の優遇期間に売り切る在庫」でしかない。
  4. eBay（米国）は分岐点が $34。 送料が2,460円と高く、DDP 義務でセラーが関税を前払いする。低単価・嵩物の鍋には最も不向き。
  5. 🔴 1件あたりの作業は Shopee が53分、BASE が10分。 12点なら 636分 対 120分。社長が労働集約を嫌う方針（memory owner_not_labor_intensive_build_systems）に照らすと、Shopee の53分/件は単独では持続しない。

2-2. なぜ Shopee 台湾か（理由を数字で）

  1. 立てるコストがほぼゼロ。 初期費用0円・月額固定費0円（Shopee Japan 公式）。法人番号・開業届がなくても個人で出店できる（公式Q&A）。失敗しても失うのは時間だけ。
  2. 7マーケットの中で台湾が最安。 合計18.25% で、SG(20.75%)・MY(25.0%)・TH(26.3%)・VN(26.2%)・PH(23.7%) より低い。しかも2026-09-21 から始まったトラフィック成長手数料2%の対象外（対象外は台湾とフィリピンのみ）。
  3. 国際送料も台湾が最安。 日本郵便の地帯区分で台湾は第1地帯（中国・韓国と同じ）。700gまで1,320円で、第2地帯（東南アジア）の1,470円より安く、米国の2,460円の半分。
  4. 購入者に関税が乗らない。 台湾は完税価格（商品＋運賃＋保険）NT$2,000以下なら関税・営業税が免税（航空速達貨物通関弁法 第11条）。766 TWD＋送料は枠内に収まる。
  5. 新規90日の販売手数料無料を使えば黒字。 766 TWD（3,800円）で12点売れれば +5,388円。国内フリマ（▲792〜2,284円）より 6,000〜7,700円良い。
  6. 言語が障壁にならない。 台湾は繁体字中国語だが、社長は「英語も含めすべて AI で対応する」方針（memory owner_not_labor_intensive_build_systems）。Shopee 公式も「外部の翻訳サイトを使って問題なく対応されている」と明記している。セラー向けサポートは日本語。
  7. 🔴 Amazon のゲートは Shopee に一切かからない。 今日 Amazon で NOT_ELIGIBLE（解除経路が存在しない制限）に当たって19,756円が宙に浮いたが、これは Amazon のカタログ内部の制限であり、Shopee には出品できる。ゲート耐性のある販路を持つこと自体が、今日の損失の回収になる。

2-3. 同時に BASE を併設する理由（費用0円）

  • スタンダードプランは月額0円で、「かんたん海外販売」は2026-03-18 から標準機能として自動で有効。つまり何もしなくても海外に売れる状態になる。
  • 社長の作業は「いつも通り国内配送するだけ」。国際郵便マイページでのラベル作成も、郵便局への持込も、外国語の問い合わせ対応も不要。
  • これは「労働集約でない海外販路」の唯一の形。 Shopee が53分/件、BASE が10分/件。
  • ただし BASE 単独では売上が立たない（集客が自力）。Shopee で売り、BASE を箱として持つのが正しい組み合わせ。隠さず言えば、BASE は12点の現金化には効かない。

2-4. 推奨の前提が崩れる条件

  • shopee.tw の実画面で、22cm級の日本製ステンレス鍋が 766 TWD 以上で売れている形跡が無い（「已售出」が0件ばかり）→ 鍋は Shopee でも売れない。その場合は鍋を 39_ の国内フリマ A案に回し、Shopee の5商品枠は別の商材（§4 の帯）で埋める
  • 台湾の販売価格が 775 TWD（通常期の分岐）を下回る → 90日の優遇が切れた時点で赤字。鍋は90日で売り切る前提でしか置けない

  1. Shopee で実際に売れているものと、当社の索引で最も厚い帯が一致している。 2026年9月の Shopee 実売TOPは サプリ／コスメ／ティッシュ／抹茶／スキンケア で、当社索引の最厚帯は美容・スキンケア4,307件。偶然ではなく、日本の卸にその帯が最も多いから。
  2. 鍋は、当社が持つ在庫の中で最も海外に向かない帯だった。 重量0.5kg・3辺63cm・単価1,646円。送料が原価の80%になる。それでも最初の在庫として使う価値があるのは、「出店条件（5商品以上）を満たす」という用途があるからで、完売を目的にすべきではない。
  3. Amazon のゲート耐性という利点は、金額で測れる。 今日 Amazon で失ったのは19,756円だが、失ったのはそれだけではない。ブランドゲート申請に費やした時間と、「仕入れてから出品できないと分かる」という構造リスクである。Shopee/BASE/eBay には ASIN カタログが存在しないため、同じ型の事故は原理的に起きない（商品ページを自分で作るので「出品できない」は発生しない。代わりにブランド品・化粧品は仕入証明書の提出を求められることがある＝Shopee 公式）。
  4. 当社の仕入れ索引は、Amazon 専用の資産ではない。 JAN と卸値と在庫が入った60,037件は、Shopee でも BASE でも使える。販路を1本増やすたびに、この索引の価値が倍になる。
