## 1. なぜ空欄を埋めるのか（前提）

SD の会員情報ページに「出展企業はこの店舗情報をもとに取引の可否を判断しています」と明記されています。SD は卸価格を非公開にし、商品ごとに「卸価格を見る(申請)」→ 出展企業の承認で初めて価格が見える仕組みです。つまり**店舗情報は、当社が出展企業に提出する唯一の申請書**です。

SD 公式ヘルプは「各出展企業はご登録時の販売形態によって、お取引の判断をしております」（＝ブランド保護・商圏バッティング防止のための販路規制）としています。当社は実店舗がなく、Amazon 中心＝**出展企業が最も警戒する販売形態**です。だから文面の仕事は「規模の大きさを見せること」ではなく、**値崩れを起こさない相手だと読ませること**に絞ります。

## 3. 「開業前」の扱い方（推奨1案）

**推奨：隠さず「販売開始の準備段階」と書き、直後に自社サイト公開済みを添える。**（A・B案がこの形）

- **隠せません。** SD 側の会員名が「【開業前】Satoy Select」で、出展企業には最初から見えています。文面で「販売しています」と書けば、会員名との矛盾が一目で分かり、信用を落とします。
- **「開業前」の一語だけだと、相手の頭に「何も無い人」と映ります。** そこで①開業届を出した月（2026年8月）、②公開済みの自社サイト、③物流の手当（FBA）の3点を並べ、**準備が具体的に進んでいる**と読ませます。実績ゼロは変えられないので、変えられる「段取りの確かさ」で埋める、という設計です。
- 採らなかった案：(a) 開業前に触れない → 会員名と矛盾。(b)「近日オープン」等の期日を書く → Amazon 日本ストアの再開（T-20260920-001・期限 9/22）が済むまで日付は約束できません。**守れない期日を書くと、SD の 11/30 サイトオープン条件と二重に効いて不利になります。**

### Amazon ストアフロント URL は、いま載せません

`https://www.amazon.co.jp/sp?seller=A1QBYCHTVOMJJM` は 9/20 時点で**停止中・出品0件**です。URL を載せると出展企業がクリックし、「商品が無い店」を見ます。**No Image より悪い**。日本ストアが再開して出品が見える状態になってから、店舗情報に追記するのが順序です（同時に SD へネットショップ URL を連絡すれば「【開業前】」も外れます）。

## 4. 店舗写真の案（作成・アップロードはしていません）

出展企業の審査ではネット販売の場合「規模・コンセプト・クオリティー」が見られます。当社は規模が出せないので、**コンセプトとクオリティーが伝わる1枚**を置きます。

| 案 | 中身 | 狙い | 評価 |
|---|---|---|---|
| **案1（推奨）** | 自社サイト `https://satoy-select.com/` の**トップページ全体のキャプチャ**。ブラウザの URL バーを入れる | 「販売サイトが実在する」証明と、店の雰囲気の提示を1枚で兼ねる。実店舗の外観写真に最も近い役割 | ◎ |
| 案2 | Satoy Select の**ロゴ**（白または淡色背景・正方形） | ブランドは伝わるが、サイトが実在する証明にならない | ○（複数枚載せられる場合の2枚目） |

- 複数枚載せられるなら **案1 → 案2 → サイトの商品一覧ページのキャプチャ** の順。
- **他社サイト・Amazon 商品ページ・フリー素材の生活写真は使いません。**第三者の著作物であり、当社の店舗写真として虚偽になります（実店舗写真の流用も同じ理由で不可）。
- キャプチャは Retina 等倍で撮り、縮小しないこと。文字が潰れた画像は「クオリティー」の評価を直接下げます。

## 6. なぜこの表現にしたか（編集意図）

| 表現 | 意図 |
|---|---|
| 「暮らしの道具を目利きしてお届けする」 | 自社サイトの文言をそのまま使用。サイトを見た出展企業が同じ言葉に出会い、記載が一致する |
| 「現在は販売開始の準備段階です」 | 「開業前」を言い換えず、かつ止まっていないと読める最短形 |
| 「保管と配送はAmazonのFBA（Amazon倉庫からの発送）を利用します」 | 出展企業の実務上の不安は「小さい店で在庫と配送を回せるのか」。FBA の一語で潰す。相手が用語を知らない前提で括弧で補足 |
| 「希望小売価格を尊重し、値崩れを起こさない販売を方針としています」 | SD が卸価格を非公開にしている理由（ブランド保護・販路規制）への直接の回答。**Amazon 販路で最初に疑われる点に先回りする** |
| 「定番品を長く取り扱うことを目標に」 | 「ネット販売に手が回っていないメーカーを狙う」は当社の戦略だが、**読むのは SD に出展済み＝ネット販売をしているメーカー**なので、そのまま書くと失礼に当たる。相手の関心（継続取引）に翻訳した |
| 書かなかったもの | 独占販売・OEM（初回接触で出す話ではない）／売上・SKU 目標（実績ゼロで数字を出すと空虚）／Amazon アカウントの停止（聞かれていない上に、店舗情報欄で書く事柄ではない） |
