  ヘッダーに **`Anti-bot check`** が表示され、ページはサポート画面のまま遷移しなかった。
  Keepa 側のボット検知が働いている。
  **CAPTCHA/ボット検知の回避は社内ルールおよび安全規則で禁止されているため、ここで打ち切った。**
