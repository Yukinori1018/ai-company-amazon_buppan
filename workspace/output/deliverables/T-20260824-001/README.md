## 3行サマリ

1. **公式のユーザーマニュアルは存在しない**（`/help` `/faq` `/manual` 等はすべて404）。**存在するのは `https://keepa.com/api-docs/` の英語APIリファレンス30ページだけ**で、これが Keepa で最も厳密な一次情報。
2. **未確定だった3ラベルは全部解決した。**「BUY BOX の平均売上数」は**売上ではなく Buy Box を争う平均競合出品者数**（日本語UIの完全な誤訳）。「購入ボックス切り替えの所有者」＝新品Buy Box平均獲得率、「ボックスを購入する 中古の所有者」＝中古Buy Box平均獲得率（当社の推定は正しかった）。
3. **当社スキャンスクリプトに実害のある取り違えが4件見つかった。**うち2件（「過去1年最安値」が実は全期間最安値／「BuyBox価格」列が実は新品最安値）は、**保存済み raw JSON から 0 トークンで再計算できる**ため再スキャン不要。
4. カズヨが実機で取った公式FAQの「データ更新は1日1回」は、**API経由の当社スキャンには当てはまらない**（APIは配信前に自動リフレッシュされる）。ただし**レビュー件数・BuyBox・FBA系だけは別で、`offers` を付けない限り更新されない** — 点検すべきはここ（discrepancies.md D12）。

- 「公式定義」列は **keepa.com 公式ドキュメントの原文**に基づきます。第三者の解説・動画由来の情報は本書では定義として採用していません。
- **公式に記述が無いものは「❓不明」と明記**し、推測で埋めていません（glossary §9 に一覧）。
