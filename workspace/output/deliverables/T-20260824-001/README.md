## ⚠️ 前提の注記（2026-08-24 の方針転換）

社長指示により、本事業の成果物は「**厳選 top100**」ではなく「**できるだけ長い候補プール ＋ 想定仕入れ金額 ＋ メーカー連絡先**」に変わりました。**フィルタの思想が反転しています：「良いものを絞る」→「明らかに無理なものだけ落とす」。**

本書群に出てくる `top100` の数字（35%汚染・36件入替・1位交代）は**方針転換以前の前提**による切り口です。**数字は消していません**が、**順位づけの妥当性ではなく「フィールド取り違えがどれだけ効いていたか」を示す汚染率の指標**として読んでください。
**用語の定義そのものは方針に依存しません。**「COUNT_NEW はオファー数であって出品者数ではない」は、絞ろうが母数を増やそうが同じです。

## 3行サマリ

1. **公式のユーザーマニュアルは存在しない**（`/help` `/faq` `/manual` 等はすべて404）。**存在するのは `https://keepa.com/api-docs/` の英語APIリファレンス30ページだけ**で、これが Keepa で最も厳密な一次情報。
2. **未確定だった3ラベルは全部解決した。**「BUY BOX の平均売上数」は**売上ではなく Buy Box を争う平均競合出品者数**（日本語UIの完全な誤訳）。「購入ボックス切り替えの所有者」＝新品Buy Box平均獲得率、「ボックスを購入する 中古の所有者」＝中古Buy Box平均獲得率（当社の推定は正しかった）。
3. **当社スキャンスクリプトに実害のある取り違えが5件。**（D1 過去1年最安値／D2 BuyBox価格列／D3 Amazon本体判定／D4 想定月販の分母／**D11 レビュー件数フィルタ**）。**社長 Go を得てタカシがコード修正を完了**し、多くは保存済み raw JSON から 0 トークンで再計算できました。**効果〔実測〕：top100 の36件が入れ替わり1位も交代。**汚染率は top100 で35.0%、GO母集団 標本 n=150 で 38.7%（95%CI 31〜46%）。
5. **実測でしか分からなかったことが4件**：**D11 は「古い値」ではなく「そもそも値が返っていなかった」**（raw 4,002件で `csv[17]` 0件・`current[17]` 全件 -1）／**D8 は当たり**（`variationCount 0〜0` が 97,484件で現行の帯 93,574件より多い＝**母数2倍の機会損失**）／**カズヨの「FBA品なら送料0だから影響なし」という推論は実測で否定**（59.1% 対 58.5%）／**根本原因は共有アダプタ**で、同じ欠陥が2チケットに別々に実装されていた。
4. カズヨが実機で取った公式FAQの「データ更新は1日1回」は、**API経由の当社スキャンには当てはまらない**（APIは配信前に自動リフレッシュされる）。ただし**レビュー件数・BuyBox・FBA系だけは別で、`offers` を付けない限り更新されない** — 点検すべきはここ（discrepancies.md D12）。
