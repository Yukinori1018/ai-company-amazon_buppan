# 電脳せどりは事業になるか — 原石密度の実測PDCA【v2・2,000件・訂正版】

**実施日:** 2026-07-05〜06 ／ **担当:** カズヨ（司令塔）＋サトル（サンプリング再設計）
**問い（社長）:** 電脳せどりは事業（月50万利益）になるか。稼げる商品（仕入れ値とAmazon価格の差）は本当に存在するか。
**前回からの修正:** ①235件は少なすぎ→**2,000件**へ。②サンプリングが素人的（Yahoo無選別）だった→**プロの逆順**へ。③前回「全件Buy Box無し」は**私の測定ミス**（Keepaのbuyboxパラメータ未指定で未取得値を"無し"と誤読）→今回訂正。

> **結論（訂正）:** 稼げる商品は「ほとんど無い」わけではありませんでした。ただし「濃くもない」。正しい手法（Amazon側で条件を絞り→仕入れ先を逆引き）で測ると、**誤突合を除いたクリーンな流動性原石は"突合できた商品の5.3%"（母集団比2.3%）＝2,000件から47件**。うち約7割は相乗り可能で、純利益 中央値¥1,620・仕入資本 中央値¥4,167。**AIで正しく絞れば事業の芽はあるが、無選別・ワンクリックでは罠だらけ**という結論です。

---

## P（Plan）— サンプリングを「プロの逆順」に再設計
サトルが社内ナレッジ（朝野YouTube・EC STARsセミナー・ERESA・PoiPoi実装値）を精査。前回の誤りは「仕入れ先を無選別に舐めた」こと。プロは逆順：
- **Amazon側でPoiPoi標準条件を先に絞る**：ランク5万〜15万・新品出品者2人以上・価格3,000円以上・**Amazon本体が在庫切れ**（出せば売れる中位帯）
- その各ASINの**JANで仕入れ先（Yahoo＋楽天）を逆引き最安**
- 合格基準は朝野式に緩和：利益率8%・利益額300円（分母を最大化）

## D（Do）— Keepa Product Finderで2,000件を実測（自走約3時間）
- Amazon側 条件合致 **1,999件** 抽出（10カテゴリ配分）
- JANあり 1,543 → **仕入先が付いた（突合）890件（突合率44.5%）**
- 原石188 / 持続177 / **流動性ある原石（Buy Box実在確認）131件**

## C（Check）— 生値は"盛られている"。誤突合を剥がすと真値が出る
| 段階 | 件数 | 対突合% |
|---|---|---|
| 流動性ある原石（生） | 131 | 14.7% |
| − 入数不一致・別モデル誤突合を除去（差が2.5倍超等） | −84 | |
| **クリーンな流動性原石（真値）** | **47** | **5.3%** |

- **生14.7%の正体**：仕入¥3,620の消火器**1本**が「19本セット¥78,750」に誤突合、¥495が12kgドッグフードに誤突合…といった**入数不一致・別モデル誤突合**。私のスキャンは既存の入数照合ガードを省いたため水増しされた。
- **クリーン47件の質**：差の比率 中央値**1.73倍**（現実的）。純利益 中央値¥1,620／平均¥2,949／範囲¥250〜12,063。仕入資本 中央値¥4,167（小資本で回せる）。ブランド出品制限の疑い28%（＝約7割は相乗り可能）。
- **カテゴリ勝ち筋**：おもちゃ10・家電9・ホビー8・ホーム&キッチン6・スポーツ6が濃い。ドラッグ/ベビーは突合率が低い（薬機/JAN無）。
- **前回結論の訂正**：「全件Buy Box無し→投資可能≈0%」は測定ミス由来。実際はBuy Boxは存在し、クリーン47件中ほぼ全てが実売Buy Box価格でも基準を維持。

## A（Act）— この2,000件が確定させた方針
1. **ツールに"罠フィルタ"を必ず組み込む**。生値は真値の約3倍に盛れる。必須＝①入数照合（1個 vs Nセット）②名寄せ信頼度（別モデル誤突合）③Buy Box実在確認（buyboxパラメータ必須）④ブランド出品制限・薬機の警告。これが無いAIリサーチは害。
2. **カテゴリを勝ち筋に寄せる**：おもちゃ・ホビー・家電・ホーム&キッチン。ドラッグ/ベビーは低効率。
3. **「探す」より「絞る」がAIの主戦場**。母集団2,000→クリーン47は、人手では回せない量をAIが捌いて初めて成立する。
