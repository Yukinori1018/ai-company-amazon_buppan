## 結論

**先に：サトルの 05（書いている途中で届きました）では、ケース1の可能性が高いです。** Amazon 公式の比較表と案内では、**カートの利用資格は大口の機能**で、**カテゴリーの出品許可は小口では申請できません**。ブランドの出品許可は公式の明文がなく、二次情報では大口が前提です。1周目は、取引が成立すれば必ずカートで売るので、大口は1周目の途中で必ず要ります。ケース2の表は参考として残します。

1. **ケース1（1周目にどのみち大口が必要）でも、A案の追加費用は「ほぼ0円」になりません。** 大口が本当に要るのは最初の発注の後（中央 11月前半）なので、9/16 に切り替えると約2か月分、**10,780円**の前払いになります（中央）。さらに、1周目で取引が成立しない確率が60〜76%（推測・マサル／タケシ）あり、その場合は1周目のうちに大口を使う場面がありません。確率で重み付けすると、A−D は **約 −17,000〜−19,000円**です。
2. **ケース2（小口のままで回せる）では、9/4 の結論（A案は赤字）は変わりませんが、金額は変わります。** 前提だった「Amazon の復旧待ち」が無くなったので、A−D は中央 **−18,960円**（9/4 は −26,200円）です。
3. **どちらのケースでも順位は C ＞ D ＞ A・B′ です。** 1周目はメーカー直一本で、SD（スーパーデリバリー）を使う予定がありません。そのため、A案で SD を早く使えるようにしても、1周目の中では得になりません。
4. **大口に切り替える時期は「最初の発注を確定する直前」です（ケース1）。** ゲートの無いメーカーだけで取引が成立した場合は「初回 FBA 納品プランの直前」です。いずれもカナダの本人確認が片付いていることを条件にします（タケシ O-4）。
5. **大口の月額は10万円の枠に入れず、1周目の損益報告には必ず入れる**のを推奨します。1社だけの成立（中央）なら、枠に入れても入れなくても発注額は変わりません。

## 1. 計算の考え方（9/4 と同じ）

A案とD案（今回の SD 登録はキャンセルし、後で申し込み直す）は、どちらも最終的には SD を使えます。違いは次の2つだけです。

- **増分コスト**：大口が本当に必要になる日（下の「本来の切替日」）より前に払う月額
- **増分便益**：SD を何週間早く使えるか

期間は1周目の締め（2027-01-15）までで区切ります。

## 2. ケース1：ゲート申請やカートに大口が必要な場合

### 2-1. 本来の切替日

ゲートの解除申請にはメーカーの請求書が要ります（公式要件：180日以内・10点以上）。請求書は**発注した後**に出るので、「どのみち大口が要る」としても、必要になるのは**早くても発注の時点**です。今ではありません。

| シナリオ | 事業の状況 | 本来の切替日 | 9/16 に切り替えた場合の前払い |
|---|---|---|---|
| 楽観 | 波1の社と早く成立し、10月上旬に発注 | 10月中旬 | 1回 **5,390円**（9/16分） |
| **中央** | 成立し、発注は中央値の 10/20 | 11月前半（タケシの日程） | 2回 **10,780円**（9/16・10/16分） |
| 悲観 | 1周目は不成立（W-7 の第2陣を含む） | 1周目の中では来ない | 4回 **21,560円**（9/16〜12/16分）。解約しなければ以後も毎月 |

⚠️ **ここで使う「悲観」は、いちばん起こりやすい結果です。** 不成立の確率は60〜76%（推測）あります。

### 2-2. A−D（ケース1）

| シナリオ | 増分コスト | 増分便益（仮定） | **A−D** |
|---|---:|---:|---:|
| 楽観 | −5,390円 | +6,000円 | **+610円** |
| **中央** | **−10,780円** | **+1,500円** | **−9,280円** |
| 悲観 | −21,560円 | 0円 | **−21,560円** |
| 確率で重み付け（成立 24〜40%。成立した場合は中央の値） | | | **約 −16,600〜−18,600円** |

増分便益は仮定です。9/4 の計算方法を予算10万円に置き換えました（2周目の SD を2〜4週間早く使えることの価値＝1周の利益 × SD でしか買えない割合30%（仮定）× 0.5〜1周）。**1周目の中での便益は0円です**（1周目の経路に SD が入っていないため）。

→ **A案が黒字になるのは、楽観シナリオだけで +610円、ほぼトントンです。** 「追加費用はほぼ0円」という見立ては、「ゲート申請を今すぐ出す運用」の場合にしか成り立ちません。タケシの現行案では申請は 11月前半なので、この場合には当たりません。

## 4. ケース2：1周目は小口のままで回せる場合

### 4-1. 9/4 の試算はそのまま使えるか

**結論（A案は赤字）は使えます。金額は使えません。** 9/4 の3シナリオは「Amazon がいつ復旧するか」で分けていましたが、日本ストアの再開でその前提が無くなりました。今回は、1周目の中で大口を使う場面が無い前提で計算し直します。

## 5. 大口に切り替えるのに最適な時期

| 条件 | 最適な時期 | 理由 |
|---|---|---|
| ケース1で、ゲートのある社（北陸製菓・北尾化粧品部・池本刷子工業）と成立した | **最初の発注を確定する直前**（見積もりで O-1〜O-3 がそろった時点） | 5万円を払う前に、ゲート申請の画面と必要書類を自分で確かめられます。「ゲート申請の直前」（着荷の後）より数日から数週間早いだけで、差は最大でも1回 5,390円です。守れる金額は初回の最大 50,000円です |
| ケース1で、ゲートの無い社（朝倉染布・河野製紙）とだけ成立した | **初回 FBA 納品プランの直前** | ゲート申請が要らないので、大口が必要になるのはカートを取るときだけです |
| ケース2 | 1周目の中では切り替えない（納品代行が大口を必須にしている場合だけ、FBA 納品プランの直前） | 小口の成約料 110円 × 月49点が、大口の月額と釣り合う点です |
| **どのケースでも** | **カナダの本人確認が片付いた後**（O-4） | 片付く前に変えると、リスク1（§3）で1周目の本線が止まります |
| **どのケースでも** | **9/16（SD の都合）には合わせない** | SD の期限は、1周目の本線より優先する理由になりません |

**「ゲート申請の直前」と「FBA 納品の直前」の二択への答え：** ケース1では「ゲート申請の直前」、さらに言えば「最初の発注を確定する直前」です。ゲート申請は FBA 納品より前に来るので、FBA 納品まで待つことはできません。

## 6. 大口の月額 5,390円を、1周目の予算10万円に含めるか

**推奨：枠（10万円）には含めない。1周目の損益には必ず含めて報告する。** タケシの推奨A（含めない）と、枠についての結論は同じです。

| 論点 | 数字 |
|---|---|
| 1周目に大口を払う回数（ケース1で成立・中央） | 11月前半に切替 → 11月・12月・1月初めの **3回 16,170円**（1/15 まで） |
| 1社だけ成立（中央）の場合 | 発注5万円＋大口 16,170円＝66,170円。**10万円に入れても入れなくても、発注額は変わらない** |
| 2社成立（楽観）の場合 | 発注10万円＋大口 16,170円＝**現金の最大 116,170円**。枠に含めると、2社目の発注を約 83,800円 − 5万円 ＝ 33,800円に削ることになる |
| 大口の月額を1点あたりに割り振った場合 | 16,170円 ÷ 仕入れ25〜50点 ＝ 1点あたり 323〜647円（推定）。**SKU ごとの利益率5% の判定に混ぜると、ほぼ全件が赤字に見えます** |

理由：
1. **10万円は「在庫にいくらまで賭けるか」の上限です。** 大口の月額は、特定の商品ではなく事業に付く固定費です。枠に入れると、効いてくるのが2社目の発注を削る場面（楽観）だけになります。測れる SKU の数が減り、1周目の目的（成立率 p を実際に測ること）を損ないます。
2. **ただし、1円もごまかしません。** 1周目の締め（1/15）の報告には、次の2段を並べます。
   - **SKU の損益**：販売手数料・FBA 配送代行手数料・保管手数料・納品代行費・送料を差し引いたもの（利益率5% の判定に使う）
   - **1周目の事業損益**：SKU の損益から大口の月額（最大 16,170円）を差し引いたもの
3. 社長に「最悪いくら出ていくか」をお伝えするときは、**最大 116,170円**（2社成立・大口3回）とお伝えしてください。
