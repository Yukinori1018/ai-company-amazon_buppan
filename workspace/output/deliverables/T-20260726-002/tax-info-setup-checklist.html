0. 結論（3行）

  1. 免税事業者なので「VAT/GST登録番号」ページ（/tax/jpregistrations）は空欄のままでOK。罰則も不利益もなし（そもそも番号を持っていないので入れられません）。
  2. 別物として、基本の「納税情報」（設定 → 出品用アカウント情報 → 納税情報）は登録済み・最新であることが必須。売上金受取の前提なのでここだけは確認。
  3. 任意インボイス登録は現段階では非推奨（B2C・小規模）。売上1,000万円ラインが見えてきたら初めて検討でOK。

1. 「VAT/GST登録番号」ページの正体と免税事業者の扱い

このページは何か

日本セラーがここに入れる番号 = 適格請求書発行事業者の登録番号（インボイス番号／"T" + 13桁）。Amazon が社長に請求する手数料（販売手数料・FBA配送代行料など）にかかる消費税について、Amazon が社長宛に適格請求書を発行するか判定するために使います。

「空欄でOK」の根拠 （事実）

  • 登録番号は課税事業者しか取得できない。免税事業者は課税事業者になって登録しない限り番号を持てません。
  • 基準期間の課税売上1,000万円以下などの免税事業者はインボイス登録は任意 → このページへの入力も任意で、未入力に罰則なし。
  • 社長は T+13桁を保有していないため、入れようがない = 空欄が正しい状態。

Amazon 手数料の消費税と「控除可否」（要注意）

Amazon の販売手数料・FBA手数料は消費税の課税対象。ただし仕入税額控除ができるのは課税事業者だけです。免税事業者はそもそも消費税を申告・納税しないため、手数料の消費税を控除する場面がありません。
→ 番号の有無で控除可否が変わるのは「課税事業者になった後」の話。 今の社長（免税）には、番号を入れても控除メリットは発生しません。
結論: 免税のうちはこのページは空欄で実質的な不利益ゼロ。番号が効くのは「課税事業者化＋インボイス登録」の後です。

2. 任意インボイス登録の是非（免税事業者が Amazon B2C で売る場合）

大前提: 一般消費者は仕入税額控除をしないので適格請求書を必要としません。インボイスが要るのは「買った側が事業者で控除に使いたい」ケース。B2C 中心なら買い手からインボイスを求められる場面がほぼない = 登録の主目的が薄い。
メリットデメリット
・法人／事業者の顧客にインボイスを出せる（B2B で選ばれやすい）
・課税事業者になり、手数料・仕入の消費税を仕入税額控除できる
・将来 B2B・卸に広げるなら早めに慣れられる 		・免税 → 課税事業者化で売上の消費税納税義務が発生
・申告・記帳の事務負担が増える
・B2C 中心では顧客がインボイス不要なのでメリットが活きない

負担軽減措置（登録した場合・2026年時点の最新）

  • 2割特例（納税額を売上税額の2割に圧縮）: 個人事業者は令和8年分（2026年分）が最後。令和8年度税制改正で個人に限り令和9・10年（2027・2028年）は「3割特例」に移行して2年延長（法人は延長なし）。（事実／適用可否は税理士確認）
  • 免税事業者からの仕入れに係る経過措置（＝社長"から買う事業者側"の控除割合。社長自身の納税ではない）: 2026/9/30まで80%控除 → 2026/10/1以降50%控除に縮小。顧客が一般消費者なら社長には実務上ほぼ無関係。
現段階の推奨: 今は任意登録しない（免税のまま）。
  • 根拠1: 販売相手がほぼ一般消費者 → インボイスを求められない → 登録の主目的が立たない。
  • 根拠2: 登録すると売上の消費税納税義務が発生 → 小規模・副業初期の手取り／キャッシュフローを直接圧迫。
  • 根拠3: 免税のうちは手数料消費税の控除メリットも発生しない（第1章）。
再検討トリガー: (a) B2B・法人顧客が増えインボイスを求められ始めたとき／(b) 課税売上が1,000万円ラインに近づいたとき（課税化が避けられなくなるので登録デメリットが消える）。
※一般的推奨です。登録の最終判断は税理士に確認を。

4. 免税事業者としての実務注意

記帳

免税でも、所得税の確定申告のために売上・仕入・経費の記帳と証憑（領収書・請求書）の保存は必要。自分の帳簿は必ずつける。

確定申告（事業所得 / 雑所得）

  • 副業の所得区分は事業所得か雑所得かで扱いが変わる（事業所得は青色申告特別控除などのメリット）。
  • 目安: 継続性・独立性・規模＋帳簿あり → 事業所得寄り／小規模・単発・帳簿なし → 雑所得寄り（令和4年通達で「売上300万円以下かつ帳簿保存なしは原則雑所得」の整理）。どちらで申告するかは税理士相談を推奨。
  • 給与所得者の副業は副業所得が年20万円超で確定申告が必要が一般的目安（住民税は別途申告要の場合あり）。

消費税「課税事業者化」のタイミング（=インボイス登録を検討する合図）

  • 原則: 基準期間（2年前）の課税売上高が1,000万円超でその課税期間から課税事業者（個人ならある年の売上1,000万円超 → 翌々年から課税）。
  • 特定期間（前年上半期）の課税売上＋給与がいずれも1,000万円超なら翌年から課税の場合も。
  • 実務の合図: 課税売上が1,000万円ラインに近づいたら、①税理士に課税化時期・2割/3割特例・簡易課税を相談 → ②どのみち課税になるならそのタイミングでインボイス登録を前向きに検討（登録デメリット＝納税義務が"どうせ発生"に変わり、登録の相対デメリットが消えるため）。
  • ※年数・要件は一般的整理。適用は税理士確認を推奨。

5. 「今やること／今はやらなくていいこと」チェックリスト

✅ 今やること（PC 上で完結）

  • 設定 → 出品用アカウント情報 → 納税情報を開き、入力済み・最新か確認（未入力なら本人が入力。売上金受取の前提）
  • 氏名・住所が本人確認書類と完全一致か目視チェック（ズレ＝入金トラブルの元）
  • VAT/GST登録番号ページは空欄のままと確認して閉じる（何も入れない）
  • 日々の売上・仕入・経費の記帳と領収書保存を習慣化

⏸ 今はやらなくていいこと

  • インボイス（適格請求書発行事業者）の任意登録 → 今はしない（B2C・小規模）
  • 消費税の申告・納税の準備 → 免税のうちは不要
  • 手数料の消費税を控除する作業 → 免税では発生しないので不要

🔭 将来のトリガー（どちらか来たら税理士に相談）

  • 課税売上が1,000万円ラインに近づいた → 課税化時期＋インボイス登録＋2割/3割特例・簡易課税を相談
  • 法人・事業者の顧客からインボイスを求められ始めた → B2B 比率と登録メリットを再評価
