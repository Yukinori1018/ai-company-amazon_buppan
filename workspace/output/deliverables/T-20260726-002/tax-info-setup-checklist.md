## 1. 「VAT/GST登録番号」ページの正体と、免税事業者の扱い

### このページは何か
- Seller Central の「VAT/GST登録番号」ページ（/tax/jpregistrations）で日本セラーが入れる番号 = **適格請求書発行事業者の登録番号（インボイス番号／"T" + 13桁）**。
- Amazon がこの番号を使うのは、**Amazon が社長に請求する各種手数料（販売手数料・FBA配送代行料など）にかかる消費税**について、Amazon が社長宛に「適格請求書（インボイス）」を発行するかどうかを判定するため。

### 免税事業者は「空欄でOK」の根拠
- **適格請求書発行事業者の登録番号は、課税事業者しか取得できません**（免税事業者は課税事業者になって登録しない限り番号を持てない）。
- 基準期間の課税売上が1,000万円以下などの免税事業者は、**インボイス登録は任意**。よって**このページへの入力も任意**で、**未入力に罰則はありません**（事実。国税庁・Amazon 公式ヘルプで整理）。
- 社長は T + 13桁の番号を保有していないため、**入れようがない = 空欄が正しい状態**です。

### 「入れるとどうなるか」
- 番号を入れられるのは登録済み（課税事業者）だけ。**存在しない番号を無理に入れることはできず、する必要もありません**。
- 参考: 将来インボイス登録した場合にここへ番号を入れると、Amazon が手数料について適格請求書を発行 → その手数料に含まれる消費税を **仕入税額控除**できるようになります。

### Amazon 手数料の消費税と「控除可否」（ここが要注意ポイント）
- Amazon の販売手数料・FBA手数料は**消費税の課税対象**（手数料にも消費税がかかっている）。
- **仕入税額控除ができるのは「課税事業者」だけ**です。**免税事業者は、そもそも消費税の確定申告・納税をしないため、手数料の消費税を控除する場面がありません**。
  - → **番号の有無で控除可否が変わるのは「課税事業者になった後」の話**。今の社長（免税）には、番号を入れても控除メリットは発生しません。（事実整理。ハジメの推測ではなく制度上の帰結）
- まとめ: **免税のうちは、このページは空欄で実質的な不利益ゼロ**。番号が効いてくるのは「課税事業者化＋インボイス登録」の後。

## 2. 任意インボイス登録の是非（免税事業者が Amazon B2C で売る場合）

### 大前提: 社長の販売相手はほぼ「一般消費者」
- **一般消費者は仕入税額控除をしないので、適格請求書（インボイス）を必要としません。**（事実）
- インボイスが要るのは「買った側が事業者で、消費税の控除に使いたい」ケース。B2C 中心なら、**買い手からインボイスを求められる場面がほぼない** = 登録の主目的が薄い。

### 任意登録の メリット / デメリット

| | 内容 |
|---|---|
| **メリット** | ・法人／事業者の顧客にインボイスを出せる（B2B 取引で選ばれやすくなる）<br>・課税事業者になるので、Amazon手数料や仕入にかかった消費税を**仕入税額控除**できる（納める消費税を減らせる）<br>・将来 B2B や卸に広げるなら早めに慣れておける |
| **デメリット** | ・**免税 → 課税事業者になる** = 売上にかかる消費税の**納税義務が発生**（今まで払っていなかった消費税を納める）<br>・消費税の申告・記帳の事務負担が増える<br>・**B2C 中心では、そもそも顧客がインボイスを要らないので、上のメリットが活きない** |

### 負担軽減措置（登録した場合の緩和策・2026年時点の最新）
- **2割特例**（納める消費税を「売上税額の2割」に圧縮できる小規模事業者向け特例）:
  - **個人事業者は令和8年分（2026年分）が2割特例の最後**。
  - **令和8年度税制改正**で、**個人事業者に限り令和9年（2027年）・令和10年（2028年）は「3割特例」に移行して2年延長**（割合は2→3割に引き上げ）。法人は延長なし（当初どおり終了）。
  - （出典ベースの事実。適用可否・具体額は税理士確認を推奨）
- **免税事業者からの仕入れに係る経過措置**（＝社長「から買う側」の控除割合。社長自身の納税ではなく、社長の"取引先が事業者だった場合"の話）:
  - **2026年9月30日までは80%控除、2026年10月1日以降は50%控除**に引き下げ（段階的に縮小）。
  - **社長の顧客が一般消費者なら、この経過措置は実務上ほぼ無関係**（消費者は控除しないため）。

### 現段階の推奨（根拠つき）
- **推奨: 今は任意登録しない（免税事業者のまま）。**
  - 根拠1: 販売相手がほぼ一般消費者 → インボイスを求められない → 登録の主目的が立たない。
  - 根拠2: 登録すると売上の消費税納税義務が発生 → 小規模・副業初期には**手取りとキャッシュフローを直接圧迫**。
  - 根拠3: 免税のうちは手数料消費税の控除メリットも発生しない（第1章参照）。
- **再検討のトリガー**: (a) B2B・卸・法人顧客の比率が上がり、インボイスを求められ始めたとき／(b) 課税売上が1,000万円ラインに近づき、いずれ課税事業者化が避けられなくなったとき（→ その時は登録デメリットが消えるので登録を前向きに検討）。
- ※これは一般的推奨です。**登録の最終判断は税理士に確認してください。**

## 4. 免税事業者としての実務注意（記帳・確定申告・課税事業者化のライン）

### 記帳
- 免税事業者でも、**所得税の確定申告のために売上・仕入・経費の記帳と証憑（領収書・請求書）の保存は必要**。
- 免税事業者から仕入れる側の書類要件（区分記載請求書と同様の記載）とは別に、**自分の帳簿は必ずつける**。

### 確定申告（事業所得 / 雑所得）
- 副業の所得区分は **事業所得** か **雑所得** かで扱いが変わる（事業所得は青色申告特別控除などのメリットがある）。
  - 一般的な目安: 継続性・独立性・規模があり帳簿をきちんとつけている → 事業所得に寄る。小規模・単発的で帳簿なし → 雑所得に寄る（令和4年の通達で「売上300万円以下かつ帳簿保存なしは原則雑所得」の整理あり）。
  - **どちらで申告するかは税理士に相談を推奨**（青色申告のメリット/要件含む）。
- 給与所得者の副業は、**副業所得が年20万円超で確定申告が必要**になるのが一般的な目安（住民税は別途申告要の場合あり）。金額・区分は税理士確認を。

### 消費税「課税事業者化」のタイミング（=インボイス登録を検討し始める合図）
- 原則: **基準期間（2年前の課税期間）の課税売上高が1,000万円を超えると、その課税期間から課税事業者**（=個人なら、ある年の売上が1,000万円超 → 翌々年から課税）。
- 特定期間（前年の上半期）の課税売上高と給与等がいずれも1,000万円超なら、翌年から課税になる場合も。
- **判断基準（実務の合図）**: 課税売上が1,000万円ラインに近づいてきたら、
  1. 税理士に「課税事業者化の時期」と「2割/3割特例・簡易課税の使い方」を相談。
  2. **どのみち課税になるなら、そのタイミングでインボイス登録を前向きに検討**（登録デメリット＝納税義務が、課税化で"どうせ発生する"ものになるため、登録の相対的デメリットが消える）。
- ※上記の年数・要件は一般的整理です。**適用は税理士確認を推奨。**
