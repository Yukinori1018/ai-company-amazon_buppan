## これは何か

現行サイトの内容・トーンを踏襲したまま、**見た目だけを一段引き上げたトップページ1枚**。
狙いは「AI で量産した感」の脱却 —— 実在する堅実な会社が、少しデザインに投資したように見える佇まい。
派手さではなく、**B2B（メーカー・卸売業者）から見た信用**を最優先にしている。

| 観点 | 現行版 | このモック |

| 書体 | OS標準ゴシックのみ | 見出しに **Zen Old Mincho**（明朝）、本文に **Zen Kaku Gothic New**。日本語の明朝は「堅実・品格」を最短で伝える |

## 本番グレードアップに転用できる知見（この実験の本体）

社長ご指示の目的は「AI で高品質な HP を作れるかの検証」。**以下がこの回で確かめられた再現可能な知見。**

### 1. 「AIで量産した感」の正体は3つしかない

実験前後を比べると、素人臭さは装飾の不足ではなく**この3点**から出ていた。逆に言えば、この3つを外すだけで印象は変わる。

1. **純白 `#FFFFFF` の地色。** ブラウザ既定色そのままは「未設定」に見える。`#FAF8F4` 程度の温かい紙色にするだけで印刷物の質感が出る
2. **OS 標準ゴシックのみ。** 日本語サイトは書体で9割決まる。**見出しを明朝にするのが最も費用対効果が高い**（Zen Old Mincho は Google Fonts で無料）
3. **カードの均等並べ。** 全要素が同じ大きさの箱に入っていると情報の軽重が消え、テンプレートに見える。**セクション番号＋罫線の誌面型**に変えると階層が立つ

### 2. 金（アクセント色）は「面」で使うと安くなる

現行版は金をボタンや見出しに面で使っていた。**面で使う金はメッキに見える。**
v1 では金をヘアライン・下線・セクション番号に限定し、面で使うのは CTA ボタン1つだけにした。**使用面積を減らすほど高く見える**という逆説。

### 3. 余白は「量」ではなく「可変」で設計する

固定 px の余白は、スマホで詰まりすぎ・PC で間延びする。`clamp(72px, 10vw, 132px)` のように**画面幅に連動させる**。
「デザインに投資している感」の実体は、装飾ではなく**余白の総量**。

### 4. 写真は1枚で実在感が決まる

イラストとプレースホルダだけのページは、どれだけ整えても「まだ作っている途中の何か」に見える。
**写真を1枚入れた瞬間に「実在する会社」に変わる。** 選定基準は [CREDITS.md](CREDITS.md) に4条件で明文化した（低彩度・他社ロゴなし・CG不可・人物顔なし）。

### 5. 動きは「足す」より「削る」

入れたのは「画面に入ったら一度だけフェードイン」だけ。パララックス・スクロール追従は入れていない。
**B2B サイトで動きが多いのは、信用のマイナス**（読ませたい情報が読めなくなる）。`prefers-reduced-motion` の尊重は実装コスト数行。

### 6. 作業手順として効いたこと

- **公開版を1バイトも触らずに別ディレクトリで作る。** 「戻せる」保証があるから思い切った変更ができる（今回 git diff で無変更を証明した）
- **文章を先に確定させ、見た目は後。** コピーが決まっていない状態で装飾を始めると、必ず作り直しになる
- **3幅（375/768/1440）で必ず実機確認する。** 今回、縦位置写真をモバイルで横長に潰して主題が切れる不具合を1件、グリッドの自動配置ミスを1件、この確認で潰した

### 7. 次の実験で試す価値があるもの

- 現行の**選び方ガイド記事ページ**を同じ設計で作り替える（記事は滞在時間＝信用に直結する）
- **メーカーに手渡す会社概要（`profile.html` / PDF）**を同じトーンに揃える。取引先が最後に見るのはここ
- 写真を社長ご提供の実写に差し替えたときに、印象がどこまで変わるかの比較

## 動作確認済み

- 幅 375 / 768 / 1440px で破綻なし（768px 以下はハンバーガーメニューに切り替え）
- `prefers-reduced-motion: reduce` でフェードインを無効化（メニュー開閉は動作を維持）
- コンソールエラー 0 件
- Tab キーのみで全リンク・ボタンを操作可能（`:focus-visible` で金色の枠を表示）
- 小さい文字の金色は `#7F6229`（紙色に対しコントラスト 5.2:1、WCAG AA 適合）
