## これは何か

現行サイトの内容・トーンを踏襲したまま、**見た目だけを一段引き上げたトップページ1枚**。
狙いは「AI で量産した感」の脱却 —— 実在する堅実な会社が、少しデザインに投資したように見える佇まい。
派手さではなく、**B2B（メーカー・卸売業者）から見た信用**を最優先にしている。

## 現行版との違い（デザイン意図）

| 観点 | 現行版 | このモック |
|---|---|---|
| 書体 | OS標準ゴシックのみ | 見出しに **Zen Old Mincho**（明朝）、本文に **Zen Kaku Gothic New**。日本語の明朝は「堅実・品格」を最短で伝える |
| 地色 | 純白 `#FFFFFF` ＋ 寒色グレー | 温かみのある紙色 `#FAF8F4` / `#F3EFE7`。純白を避けると印刷物の質感が出て、テンプレ感が薄れる |
| 金の使い方 | ボタン・見出しに面で使用 | **ヘアラインと下線に限定**。面で使うのはCTA1つだけ。金は「効かせる」ほど上質に見える |
| 構成 | カードを並べる | セクション番号（01/02/03）＋ 罫線で区切る**エディトリアル（誌面）型**。情報の階層が視覚的に出る |
| 余白 | 一定 | `clamp()` で画面幅に応じて 72〜132px。余白量そのものが「投資している感」の正体 |
| 動き | スライダーのみ | 画面に入ったら一度だけフェードイン（下から14px）。追従・パララックスは意図的に不採用 |
| メーカー向け | ページ下部にリンク1本 | **紺地の帯セクションを新設**し、約束3点と「小ロット・前払い」を先出し |

文章は現行の誠実なトーンを維持している。**「2026年開業の新しい事業者」「長い取引実績はない」を隠していない**（引き継ぎメモの決定事項④の精神）。

## 制作手順

`docs/reference/web-site-build/web-site-build-playbook.md` の**工程の規律**に沿った（素材 → 文章 → 構造 → 装飾 → 動き）。
同手順書のデフォルト配色（paprika/sun/leaf の高彩度パレット）と丸ゴシックは、B2B 会社サイトには不適合のため**流用していない**。

## 個人情報の扱い

**このモックには住所・氏名・メールアドレス・電話番号を一切入れていない。**
フッターの所在地は `〔所在地〕` のプレースホルダ表記。事業者情報は公開版にのみ掲載する。
（`公開用/`・`会社概要_配布用/` と違い、このディレクトリは Git 追跡対象。自動同期で公開される前提で作っている）

## 差し替え前提の箇所

| 箇所 | 現状 | 差し替え |
|---|---|---|
| ヒーロー右のパネル | 線画イラスト＋「PHOTO PLACEHOLDER」ラベル | 商品または作業風景の写真（縦 4:5 推奨、1000×1250px 以上） |
| 選び方ガイドのサムネイル | 公開版の SVG を流用（下地が寒色） | 紙色に合わせて描き直すか、写真に差し替え |
| 各リンク | すべて `#`（ページ内アンカー） | 実装時に公開版の各ページへ |
| `〔所在地〕` | プレースホルダ | 公開時に `fill.py` 相当の仕組みで注入 |

## 動作確認済み

- 幅 375 / 768 / 1440px で破綻なし（768px 以下はハンバーガーメニューに切り替え）
- `prefers-reduced-motion: reduce` でフェードインを無効化（メニュー開閉は動作を維持）
- コンソールエラー 0 件
- Tab キーのみで全リンク・ボタンを操作可能（`:focus-visible` で金色の枠を表示）
- 小さい文字の金色は `#7F6229`（紙色に対しコントラスト 5.2:1、WCAG AA 適合）
