#論点判定
①NETSEA で仕入れた商品を Amazon で売ってよいか条件付き可。 会員規約に販路制限は無い。ただしサプライヤーが商品単位で「ネット販売 不可」を掛けられる仕組みが実在するため、商品ごとの確認が必須
②第24条1項（バイヤー情報の公開）公開範囲が条文から特定できない。 公開バイヤー名簿は実測で発見できず。社長の登録内容の実確認が必要（ログイン＝秘書へ依頼）
③仕入れ商品の規制転売者にも義務が生じる法律が4つある（電安法・酒税法・家表法・薬機法広告）。古物商許可は「原則不要」だが NETSEA には中古品が実在するため一律不要とは言えない

加えて、着手前に処理すべき既発事案が1件あります。 公開 GitHub リポジトリに NETSEA の卸価格 227 行が commit 済みです。§4.1（不可逆な削除）に当たるため当職は手を出していません。→ §5

① NETSEA で仕入れた商品を Amazon で転売してよいか

1-1. 会員規約本体に販路制限は無い（＝原則 OK）

バイヤー会員規約全文（agent_output/T-20260831-005/legal/netsea_buyer_agreement_20260831.txt、49,614字）を全文検索。

検索語ヒット

モール3件（いずれも「モールクーポン」＝NETSEA自社クーポンの名称。販路の意味ではない）

第15条は「バイヤー会員は…商品等を購入することができます」とだけ定め、購入後の処分に条件を付けていません。第7条（禁止事項）にも販路に関する号はありません。

明文が無い＝禁止されていない。 会員規約のレベルでは、Amazon で売ることは制限されていません。 出典：https://www.netsea.jp/agreement/statement （2024-08-20施行／2025-04-01改訂版施行・2026-08-31 当職確認）

【第3層】サプライヤーの自由記述「販売条件」（API では取れない）

商品ページには「販売条件／支払方法／送料／返品条件」というタブがあり、NETSEA 自身が 「出展企業毎に異なりますので、必ずご確認ください」と注記しています。

実測サンプル（同商品の「販売条件」原文・抜粋）：

■販売について】 ・直接のお取引はお断りしております。NETSEAを通してのご購入をお願いします。 ・『定価販売』『売価厳守』等の記載のある商品の販売価格は記載を遵守して下さい。

ここに「Amazon 不可」「モール不可」が書かれうる。そしてこの自由記述テキストは API の商品スキーマに含まれていません（items.json の全フィールドを確認済み。delivery_terms＝出荷条件はあるが、販売条件の自由記述は無い）。

結論：API だけで自動判定を完結させることはできません。 API で deal_net_shop_flag == "Y" に絞り、発注前に商品ページの「販売条件」を人が読む。この二段構えが唯一の安全な運用です。

【前段の関門】取引申請の承認制

サプライヤー会員規約 第7条1項（https://supplier.netsea.jp/agreement/statement ／2026-08-31 取得）：

会員は、当社所定の方法で選択する自己の取引対象バイヤーに該当しないバイヤーからは取引申請を受けることができないものとします。

同2項：

会員は、取引申請の承諾をいつでも撤回できるものとします。

→ サプライヤーは相手を選べるし、後から切れます。「今買えている」は「明日も買える」を意味しません。単一サプライヤー依存の SKU 構成は撤退リスクが高い。

1-3. 「売価厳守」条項の扱い（当職の警告）

上記サンプルの「『定価販売』『売価厳守』等の記載のある商品の販売価格は記載を遵守して下さい」は、 売り手側から見れば再販売価格の拘束（独占禁止法2条9項4号・不公正な取引方法）に触れうる類型です。 ただし当社は買い手であり、違反の主体ではありません。当社にとっての問題は法違反ではなく実務です。

選択肢帰結
従うAmazon の価格競争でカートを取れない。値下げ不能な SKU を抱える
従わない契約違反 → 取引申請の承諾撤回（サプライヤー規約7条2項）→ 仕入れ経路が消える

→ 「売価厳守」表記のある商品は、Amazon 販売の候補から外すのが合理的です。利益計算の前に落としてください。

③ 仕入れ商品の法的な注意点（転売者＝当社が負う義務）

3-1. 前提：NETSEA 仕入れは「輸入」ではない ＝ ここが有利

当社が NETSEA から国内サプライヤーを通じて仕入れる限り、当社は輸入者ではありません。 これにより、直輸入（並行輸入・中国仕入れ）で負う重い義務の大半を回避できます。

製造物責任法 第2条3項（「製造業者等」の定義）： 1号 業として製造、加工又は輸入した者 / 2号 自ら製造業者として氏名・商号・商標等を表示した者、または製造業者と誤認させる表示をした者 / 3号 実質的な製造業者と認めうる表示をした者

NETSEA 品をそのまま売る限り、当社は PL 法上の「製造業者等」に当たりません。（1号にも2号にも該当しない） ただし OEM・自社ラベル貼付をした瞬間に2号で責任を負います。③OEM 路線と混ぜないこと。 出典：https://hourei.net/law/406AC0000000085 （2026-08-31 確認）

3-2. 転売者にも義務が生じる法律（ここが本題）

法律当社（非輸入・転売者）の義務根拠実務での効き方
電気用品安全法PSE マーク等の表示が付されていない電気用品を、販売・販売目的で陳列してはならない（第27条）。違反は1年以下の拘禁刑または100万円以下の罰金（第57条）電安法27条／METI「電気用品安全法の概要」 https://www.meti.go.jp/policy/consumer/seian/denan/act_outline.html届出は不要。ただし「マークの確認義務」は転売者にもある。家電・PC・AV機器・照明・ACアダプタ付き商品を仕入れるなら現物のPSE表示を必ず確認
酒税法（酒類販売業免許）酒類を販売するには酒類販売業免許が必要。一般消費者に売るなら一般酒類小売業免許酒税法9条／NETSEA公式 https://www.netsea.jp/help/manual/liquor_purchasing.htmlNETSEA 側でゲートされている。免許確認済みバイヤーしか酒類カテゴリを仕入れられない。公式に「仕入れた商品は、酒税法に則り、所持する免許の区分にて認められた品目、販売先に対して販売を行ってください」と明記。免許なしなら酒類カテゴリは触らない
家庭用品品質表示法表示義務者は「製造業者、販売業者、又は表示業者」のいずれか。販売業者も名宛人。不適正表示 → 指示 → 事業者名の公表 → 表示命令 → 販売禁止命令消費者庁 https://www.caa.go.jp/policies/policy/representation/household_goods/outline/outline_02.html対象は繊維製品・合成樹脂加工品・電気機械器具・雑貨工業品の政令指定品。アパレル・日用雑貨は直撃。タグ・表示のない商品を仕入れないこと
薬機法（広告規制）第66条1項は「何人も」。当社が製造販売業者でなくても、商品説明・広告の表現規制を受ける。違反は罰則＋課徴金（2021年8月〜）薬機法66条／東京都保健医療局 https://www.hokeniryo.metro.tokyo.lg.jp/anzen/iyaku/koukokukisei/bassui化粧品・医薬部外品・健康食品を扱うなら、Amazon の商品説明文が規制対象。「効く」「治る」を書いた瞬間にアウト
食品衛生法常温保存可能な容器包装入り食品のみを販売する場合は、営業許可・営業届出とも不要。ただし乳類・食肉・魚介類・野菜果物・米穀類・弁当は包装済みでも届出が必要食品衛生法（2021-06-01 施行の届出制度）／愛知県 https://www.pref.aichi.jp/soshiki/eisei/kyoka-todokede-minaoshi.htmlNETSEA の食品カテゴリには要届出業種が混在。カテゴリ単位で「食品はOK」と判断しないこと
薬機法（販売業）化粧品・医薬部外品の「販売」に許可・届出は不要（他社が製造・輸入したものを仕入れて売る場合）。医薬品は店舗販売業許可が必要埼玉県 https://www.pref.saitama.lg.jp/a0707/hajimete1.html ／東京都健康安全研究センター https://www.tmiph.metro.tokyo.lg.jp/k_yakuji/i-sinsa/bugaihin/bugaihin_yaku/化粧品・医薬部外品は販売自体は自由。効くのは上の広告規制のみ
景品表示法「自己の供給する商品」の表示をした者が名宛人。Amazon 出品者は表示主体。優良誤認・有利誤認は課徴金対象景表法5条・8条サプライヤーの説明文をそのままコピーしても、責任は出品者である当社が負う

「輸入者でないから安全」は誤りです。電安法27条・家表法・薬機法66条は、転売者を名宛人に含みます。

3-3. 古物営業法 — 「NETSEA は卸だから不要」は正しくない

既存メモリ knowledge_kobutsusho_license の判定基準（要否は「新品か」ではなく「一度消費者の手に渡ったか」）は正しく、 NETSEA のサプライヤーがメーカー・卸である限り、古物商許可は不要です。

しかし NETSEA には中古品が実在します。

実測（https://www.netsea.jp/search/?keyword=中古 ／2026-08-31・非ログイン）：

  • 「中古」でヒット 212 件
  • 例：「中古vintage アクセサリーかわいい ダックスフント ブローチ コサージュ ピン」

古物営業法2条1項の「古物」＝①一度使用された物品、②使用されない物品で使用のために取引されたもの、③これらに幾分の手入れをしたもの。 これを売買する営業は許可が必要（同2条2項1号）。

判定：NETSEA 仕入れ一般には古物商許可は不要。ただし中古・ヴィンテージ・リユース品を1点でも扱うなら必要。 運用ルール（守れば安全）： 商品名・説明に「中古」「ヴィンテージ」「USED」「リユース」「アウトレット（返品再生品）」を含む商品は、許可取得まで仕入れ候補から除外する。 許可は手数料19,000円・審査約40日。②メーカー仕入れ・③OEM では不要ですが、①電脳せどり・④無在庫を将来やるなら必須です。先行取得は依然として合理的、という前回結論は維持します。

④ 未解決の論点 — API 第8条2「加工」（グレー。原則 NO の対象）

4-1. 何が問題か

API 利用規約 第8条2：

APIユーザーは本ライセンスの使用により得た情報を加工する場合、事前に当社に書面による承諾を得るものとします。

タカシが設計しているパイプライン（NETSEA の卸価格 × Keepa の相場 → 利益計算 → 候補リスト生成）は、 文言上「加工」に読める余地があります。「加工」の定義は規約内になく、NETSEA の公開文書にも見当たりません（2026-08-31 時点で当職が確認した範囲）。

4-2. 当職の判定

用途判定理由
