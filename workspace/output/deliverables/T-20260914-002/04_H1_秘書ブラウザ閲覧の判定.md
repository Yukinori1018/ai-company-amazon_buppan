# H-1 秘書（AI）がブラウザで楽天・Yahoo!ショッピングを見て価格を転記してよいか

T-20260914-002／2026-09-14／法務 ハルオ／一次情報の確認日はすべて 2026-09-14

## 結論

| 対象 | 判定 | 決め手 |
|---|---|---|
| 楽天市場 | 不可 | 楽天ショッピングサービスご利用規約 第7条1項7号が、ロボット等の「自動化された手段」による「商品ページ上の情報取得等」を明文で禁止。件数・頻度・人の指示の有無で要件は変わらない |
| Yahoo!ショッピング | 条件付き可（確度中・グレー寄り） | LINEヤフー共通利用規約と Yahoo!ショッピングガイドラインに、自動化手段による閲覧そのものを禁じる条項が無い。効くのは §14（提供目的外の利用）と §15(5)（BOT 等での不正操作）。§3 の8条件を守る場合に限る |

- タケシの読み（AI の閲覧は「人が見る」に当たらない）は正しい。AI のブラウザ操作は「自動化された手段」の側に入る。そのうえで、可否は各社の条文が自動化手段の何を禁じているかで分かれる。
- 社長の時間は、タケシの見込みどおりには週4時間減らない。減るのは Yahoo 側の照合だけで、楽天側の社長の目視は残る。楽天分は、カズヨが JAN 検索 URL を表に並べておく方法で1件あたりの時間を縮められる（§5）。

## 1. 問いの立て直し

9/6 の判定「人が手動閲覧してメモ＝可／自動で定期取得＝不可」は、各社の禁止条項がすべて「自動化された手段」を要件にしていたことが根拠だった。したがって、問いは次の2つに分かれる。

1. AI エージェントが人の指示で1件ずつブラウザを操作することは「自動化された手段」か。
2. 当たる場合、各社の条文はそれを禁じているか。

1 の答えは「当たる」。ページの取得・読み取り・転記を実行しているのはソフトウェアで、人の手と目ではない。人の指示があることは要件を外さない。自動購入ツールも「この商品を買え」という人の指示で動くが、楽天は明文で禁じている。Claude in Chrome は普通の Chrome の UA で通信するので、相手からは人と区別できない。区別できないことは適法の根拠にならない。

## 2. 条文

### 2-1 楽天市場（不可）

楽天ショッピングサービスご利用規約（https://www.rakuten.co.jp/doc/info/rule/ichiba_shopping.html ・文書内の日付「2017年4月1日制定／2026年4月1日最終改定」）

> 第7条1項 お客様は、本サービスの利用において以下の各号に定める行為をしてはならないものとします。
> （７）当社の事前の許可を得ることなく、自動化された手段（自動購入ツール・ロボットなどこれらに準ずる手段）を用いて商品を購入すること（商品ページ上の情報取得等を含む）

- 「ロボットなどこれらに準ずる手段」は例示で、AI ブラウザエージェントはこれに当たる。「商品ページ上の情報取得等を含む」の括弧書きが、購入に至らない閲覧・取得まで射程に入れている。
- 件数・速度・定期性で判定が変わる書き方になっていない。1件でも該当する。例外は「当社の事前の許可」だけ。
- 名宛人は「お客様」。第1条3項「本規約等に同意していない場合、本サービスを利用することはできません」で、会員登録の有無を問わず利用者に及ぶ（会員の扱いは第2条で別に置いている）。ログアウトしていても違反は消えない。
- 違反時の措置（第7条2項・3項）：利用停止、楽天会員資格の停止・取消、ポイント・クーポン・特典の取消と不当利得の返還、損害賠償。
- 楽天自身の案内（https://event.rakuten.co.jp/anshin/security/caution/）：「自動化された手段（自動購入ツール、ロボット等）は利用しないでください」「アカウントロックや注文キャンセルを行う可能性」。
- robots.txt（item.rakuten.co.jp は `?i=` `?s=` のみ Disallow、search.rakuten.co.jp はパラメータ付き検索を多数 Disallow）は商品ページを許しているが、robots.txt は許可の意思表示ではない。契約である規約の明文が優先する。

### 2-2 Yahoo!ショッピング（条件付き可）

LINEヤフー共通利用規約（https://www.lycorp.co.jp/ja/company/terms/ ・Yahoo! JAPAN 利用規約 2025年2月3日改定）

> 2.2 無料で提供している当社サービス（アカウント登録いただかなくても利用できるサービスに限ります。）につきましては、実際にご利用いただくことにより本利用規約にご同意いただいたものとします。
> 14. お客様は、別途当社が定める場合を除き、当社サービスやそれらを構成するデータを、その提供目的を超えて利用することができません。この場合、当社は、それらの行為を差し止める権利ならびにそれらの行為によってお客様が得た利益相当額を請求する権利を有します。
> 15.（5）…BOT、チートツール、その他の技術的手段を利用して当社サービスを不正に操作する行為…
> 15.（8）個人情報、登録情報、利用履歴情報等の第三者に関する情報を不正に収集、蓄積したり…

Yahoo!ショッピングガイドライン（https://shopping.yahoo.co.jp/notice/shopinfo/guidelines/ ・2025年9月24日改定施行）：購入者の順守事項は「誠実な履行」「購入意志のない注文の禁止」だけ。自動化・収集の条項は無い（全文4,432字を検索、「自動」「ロボット」「収集」とも0件）。

- 楽天のような「自動化手段による情報取得」の明文禁止は無い。
- §15(5) は「不正に操作する」が要件。商品ページを読むことは操作の改変ではない。ただし BOT と明記されているので、LINEヤフーが「BOT による利用」と見る余地は残る。これがグレーの中身。
- §14 の「提供目的」は、商品を比べて買うこと。「この商品を Yahoo で買うか」の判断のために価格を読むことは提供目的の内側と読める。価格を時系列で蓄積し、市場調査の DB にすると目的の外に出る。9/6 の「サイトの自動取得＝不可」は後者（定期取得・蓄積）を射程にしている。今回の判定はこの射程を狭めるものではない。
- §15(8) は個人情報等の話で、商品価格には当たらない。
- robots.txt（shopping.yahoo.co.jp・store.shopping.yahoo.co.jp）は商品ページと `/search?p=` を Disallow していない。Disallow は `/searchbff/` `/async/` `/rss` `/h_api/`、絞り込みパラメータ付きの検索など。

## 3. Yahoo を「可」にする運用条件（8つ・全部必須）

| # | 条件 | 理由 |
|---|---|---|
| 1 | 社長の指示で始めたセッション内だけで行う。夜間自走・/loop・スケジュール起動では実行しない | 定期性・自律性がクローラの性質。§14 の射程（定期取得）に入らないため |
| 2 | 1セッション20件以内・週60件以内・同時1タブ・1ページ5秒以上の間隔 | 人の閲覧と同じ水準。当社採用値（同一ホスト3秒・同時1）より保守側 |
| 3 | 対象は Keepa 側の足切りを通った ASIN の JAN だけ。開くのは商品ページと `shopping.yahoo.co.jp/search?p=<JAN>` だけ。robots.txt の Disallow パスと API エンドポイントは開かない | 探索（一覧の巡回）をしない＝収集ではなく照合に留める |
| 4 | 専用の Chrome プロファイルで行う。Yahoo! JAPAN ID・楽天・Amazon セラーセントラルにはログインしない。Keepa 拡張も入れない | §17.1 の措置（全アカウント対象）を社長の ID に波及させない。8/24 のセラーセントラル分離と同じ |
| 5 | 転記は JAN・価格・送料・ポイント・在庫の有無・URL・日付だけ。画像・説明文・レビュー本文は写さない | 事実のみ。著作物と §14 の「データ」の二次利用を避ける |
| 6 | 表は購入判断の作業表に限る。同じ商品の価格を追い続ける履歴列・価格監視をしない。PUBLIC リポに入れない（agent_output か非公開シート） | 蓄積＝市場調査 DB 化で §14 の外に出る。PUBLIC は公開そのもの |
| 7 | CAPTCHA・「表示できません」・HTTP 500 などの制限に当たったら、その日は中止して報告。回避しない | 不正アクセス禁止法・個情法20条寄りの回避行為をしない |
| 8 | カート投入・購入・問い合わせは AI がしない。購入は社長が自分のセッションで行う | 決済は §4.1。購入まで AI がやると楽天 7号と同型になる |

### 3点セット（グレーを進める条件）

| 項目 | 内容 |
|---|---|
| リスクシナリオ | ①LINEヤフーが BOT と判定し IP を一時制限（同じ回線の社長の購入も巻き込む。可逆）②§14 に基づく差止・利益相当額の請求（確率は極小。額は当該商品の利益程度）③Cookie・IP から社長の Yahoo! JAPAN ID と紐づけられ §17.1 の措置（確率は低いが不可逆・影響大。条件4で遮断する） |
| 発生時の対応 | 即時停止し、社長の目視に戻す。LINEヤフーから連絡が来たら秘書経由で社長へ。当社から弁明を送らない（§4.1 第三者連絡） |
| 撤退条件 | アクセス制限2回／LINEヤフーからの警告1回／規約・ガイドライン・robots.txt に AI エージェント・自動閲覧の禁止文言が入った時点で停止。条件1〜8のどれかを守れない週が出たら停止。再確認は半年後（2027-03） |

## 4. 実害の型と当社が失うもの

| 事象 | 楽天（AI が閲覧した場合） | Yahoo（条件付き運用） |
|---|---|---|
| アカウント | 楽天会員資格の停止・取消（第7条2項1号）。楽天はせどりの仕入れ口座そのもので、失えば楽天レーンが消える。楽天 ID は楽天グループ各サービス共通 | ログアウト運用なら直接は及ばない |
| ポイント・特典 | 取消・不当利得返還（同4号） | — |
| IP ブロック | 起こりうる（「個人利用の範囲を著しく超える傾向」で制限） | 起こりうる。一時的 |
| 損害賠償 | 第7条3項で明文 | §14 の利益相当額請求 |
| 3軸 | 確率 中・影響 大・不可逆性 高 → 不可 | 確率 低・影響 小〜中・不可逆性 低（条件4がある場合） |

社長が楽天 ID・Yahoo! JAPAN ID を個人で持っているか、カズヨのブラウザがそのセッションに入っているかは未確認。推測では、社長の日常の Chrome にはログイン済みの可能性が高い。条件4はそのための必須条件。

## 5. 代替手段

| 手段 | 判定 | 根拠 |
|---|---|---|
| 社長が楽天・Yahoo を目で見る | 可 | 両社とも禁止要件は自動化手段 |
| カズヨが楽天の JAN 検索 URL を表に並べ、社長がクリックして読む | 可 | カズヨは楽天にアクセスしない。URL の文字列を作るだけ。社長の1件あたり時間を縮める（3〜5分→1〜2分は推測） |
| 楽天に第7条1項7号の「事前の許可」を求める | 文言上は可・見込みは低い | 問い合わせは §4.1 第三者連絡。希望があれば下書きまで作る |
| 楽天ウェブサービス API | 不可 | 規約 Article 10(1)(4)「Rakuten Affiliate 以外で収益」(6)競合 (9)不特定多数と共有できる場所への保存（2026-09-14 再読・最終改定 2012-06-28） |
| Yahoo!ショッピング Web API | 現状不可。個別協議で可の余地 | サポート記事 H000011080「利用者自身の便宜をはかる非商用目的のみに使用することが認められています」。商用は API 窓口と協議（Yahoo! JAPAN ID でログインして問い合わせ＝§4.1）。WebFetch 経由の引用で確度中。9/6 の「未確認」はこれで埋まった |
| Keepa | 使えない | API の `AmazonLocale` は US/GB/DE/FR/JP/CA/IT/ES/IN/MX/BR のみ（github.com/keepacom/api_backend）。楽天・Yahoo の価格は無い |
| Google ショッピングを AI が見る | 不可 | google.com/robots.txt が `/shopping?` `/shopping/product/` `/search` を Disallow＋Google 利用規約（8/31 と同じ型）。人が見るのは可 |
| 価格.com を AI が見る | 未確認＝着手不可 | robots.txt は `/ksearch/` `/prdsearch/pricehistory_data/` を Disallow。規約本文（/help/kiyaku.asp）は 404 で未取得。人が見るのは可 |
| メーカー希望小売価格・メーカー公式通販の価格 | 可（上限値としてのみ） | 8/31 判定「メーカー公式サイトの低速クロール＝条件付き可」。実売価格ではないので照合の代わりにはならない |

## 6. 社長判断の材料（緩和①とセットで）

| 案 | 内容 | 規約 | 社長の照合時間 |
|---|---|---|---|
| A | 楽天・Yahoo とも社長の目視（案C の現行） | 問題なし | タケシ見込みの週4〜5時間 |
| B（推奨） | Yahoo はカズヨ（§3 の8条件）。楽天は社長の目視＋カズヨが JAN 検索 URL を事前に並べる | 楽天は問題なし。Yahoo はグレー寄りで3点セット付き | 推測で週2〜3時間。楽天と Yahoo の件数比で変わる |
| C | 楽天もカズヨが見る | 楽天 第7条1項7号の明文違反 | 最少。ただし楽天の仕入れ口座を賭ける |

推奨は B。C は仕入れ口座を失えば楽天レーンごと消え、不可逆性が高い。時間の数字は推測なので、タケシ・マサルに楽天/Yahoo の件数比で再計算してもらう必要がある。

## 7. 依頼範囲外で見つけたこと

- 楽天の案内は「商品の買い占めや転売はトラブルの元」「個人利用の範囲を著しく超える傾向が見られた場合は制限がかかる可能性」と書く。規約違反ではないが、楽天でのせどり仕入れそのものがアカウント制限の事由になりうる。社長が目視で買う場合も同じ。1ロット2〜5個・週2回の決済は、この点でも上限を上げない方がよい。
- タケシ §6 の感応度「楽天ポイントで利益率11%」について。楽天会員規約（ポイント規約 第5条）は「その他楽天が会員に付与されたポイントを取り消すことが適当と判断した場合」の取消を定める。転売目的の購入で付いたポイントが取り消されうる前提で見るべきで、利益に算入するのは危うい。取消の実例は未確認。
- 案C の撤退条件に「楽天からのアカウントロック・注文キャンセル1回」を加えるよう、タケシに提案する。
