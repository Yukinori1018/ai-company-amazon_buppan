## 一行で

`salesRankDrops30` は販売ではなく **Keepa がその商品を何回見に行ったか**を測っている
（相関 0.991・充填率 0.48）。現行 S5（`>= 1`）は死んでいる疑いのある商品の 65% を通す。

**社長判断でドロップ数は捨てず、足切りとして使う方針に決定（第2報）。**
足切りは **X=10、ただし「30日で20回以上観測されている」条件とセット**でのみ意味を持つ。
**今回の失敗SKUは X=10 を超えており、①では防げない。防いだのは②カート最終獲得日。**
32SKU バックテストの生存は 5 件。
