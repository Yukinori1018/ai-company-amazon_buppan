# 既存データで数えたメーカーの分母（T-20260915-003 タカシ分）

2026-09-15 / IT エンジニア タカシ。新たな API 呼び出しはゼロ。手元の3つのデータを数え直しただけです。

## 結論

| 見方 | 社数 | 月300通で一巡 |
|---|---|---|
| 3ソースの打診対象（重複除去） | **2,331社** | **約7.8ヶ月** |
| 展示会の国内判定を緩めた場合 | 2,968社 | 約9.9ヶ月 |
| NETSEA を「メーカー」業態だけにした場合 | 1,968社 | 約6.6ヶ月 |
| 1カテゴリに絞った場合（最大のキッチン・日用品） | 323社 | 約1.1ヶ月 |

- 手元のデータだけで、月300通を半年以上続けられる数はあります。
- ただし1カテゴリに絞ると1ヶ月前後で尽きます。
- 3ソースの社名の重なりは1〜3%でした。ソースごとにほぼ別の会社です。名簿を足せば、分母はまだ増えます（推測：飽和していない）。

## 4. 3つの重なり（社名の一致）

照合は T-20260831-001 の正規化（法人格・和英併記・記号を落としたキー）で行いました。

| 組み合わせ | 一致した社 | 率 |
|---|---|---|
| T-1 × 展示会 | 27 | T-1 の1.3%／展示会の1.1% |
| T-1 × NETSEA | 11 | T-1 の0.5%／NETSEA の2.4% |
| 展示会 × NETSEA | 12 | 展示会の0.5%／NETSEA の2.6% |
| 3つすべて | 4 | — |

- 一致した約40組には、同名の別会社（ありふれた社名）が数件混じっている可能性があります。1組ずつの確認はしていません。
- 前回の実測（展示会の出展社を Keepa で引いて0.1%）より高いのは、今回が「T-1 の約2,000社」という広い名簿との照合だからです。どちらも「ほとんど重ならない」という結論は同じです。
- 意味（推測）：売れている単品を持つメーカーは展示会にほとんど出ていません。展示会の出展社は、Amazon で売れ筋を持っていない会社がほとんどです。

## 6. 読み方の注意

- **事実**：件数・率はすべて手元ファイルの集計です（再現は `02_denominator.py`）。
- **推測**：「飽和していない」「展示会の出展社は売れ筋を持たない」は、重なりの低さからの推測です。
- T-1 は Amazon の売れ筋のごく一部です（公表≥50・単品・価格帯・オファー数で絞った3,385 ASIN）。条件を広げれば社数は増えます（子 ASIN を含めると ASIN は約3倍。社数の増え方は未計測）。
- 月300通の計算は、1社に1通・再送なしです。
