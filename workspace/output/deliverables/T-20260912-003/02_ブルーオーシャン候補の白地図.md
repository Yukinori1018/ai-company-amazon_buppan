## 0. 結論（先に5行）

1. 2026年の amazon.co.jp で「競合が少ない場所」は、商品カテゴリではなく**手続きの壁**にある。危険物（大口限定・SDS・審査2週間）、要期限管理、大型、認証（PSE・医療機器届出）、古物商、商標＋ブランド登録。壁はどれも個人で越えられ、越えた側に残る出品者が減る。
2. 日本は主要マーケットプレイスで唯一、国内セラーが過半（54%）。ただし2024年の新規登録は中国系が50%超 [S6]。「日本語・日本の認証・日本の卸との関係」が守る場所は、今後も縮む前提で見るべき。
3. 「Amazonにない商品を新規ASINで持ち込む」型は、母集団が実在する。伝統的工芸品産業はEC対応が全体の2割・1社平均5.2人 [S15]。展示会出展社の67%はAmazon不在（社内実測・T-20260831-005）。壁は「相手が個人と取引するか」で、公開データでは測れない（フォーラムでは14社当たって0件の事例 [S19]）。
4. 制度変化で有利になった側：ブランド登録者（新規出品者特典で売上5%還元・Vine・透明性）、標準サイズ20〜80cmの出品者（FBA配送代行 平均38円引下げ）。不利になった側：750円超の全商品（販売手数料+0.4pt）、12ヶ月超の在庫（最低20円/点/月）、Yahoo!併売者（2026-09から月1万円+2.5%）[S1][S23]。
5. 個人セラーの日本のベースレート（1年生存率・月商分布・撤退理由）は、信頼できる一次情報が**無い**。Amazon公式は「中小事業者約16万社・平均年商1,000万円超（2021年）」まで [S8][S9]。海外調査（Jungle Scout）は日本を分離していない。

## 1. イシューと前提

**イシュー：実績ゼロ・日本語のみ・PC完結・1周目10万円・回転6ヶ月以内の個人セラーが、2026年の amazon.co.jp で「参入障壁に守られる場所」をどこに作れるか。**

### 1-2. スコープと打ち切り

- 対象：外部の公開情報（Amazon公式・官公庁・業界団体・調査会社・公開記事・セラーフォーラム）。社内知見は `01_既存知見の棚卸し.md`（サトル①）。
- 打ち切り：案20本以上＋一次情報URL 20本以上で止める。結果：案26本（うち「該当なし」2本）・出典54行（一次25・二次29）。
- 空欄の書き分け：「未調査」＝当たっていない／「未確認」＝当たったが取れなかった／「該当なし」＝存在しないことを確認。

### 1-3. 「ブルーオーシャン」の判定基準（本書の物差し）

「誰もやっていないから」は根拠にしない。**なぜ競合が少ないか＝何が壁か**を次の10種で分類する。

| 壁の型 | 内容 | 個人が越えられるか |
|---|---|---|
| 手間 | セット組み・カタログ作成・SDS・期限管理 | 越えられる（外注費で買える） |
| ゲート | ブランド/カテゴリ出品許可・危険物プログラム | 越えられる（請求書・大口） |
| ロット | 最小発注数 | 10万円で越えられる範囲が狭い |
| 言語 | 英語交渉 | 緩和候補（AIメール） |
| 地域 | 産地・展示会・実店舗 | PC完結では越えにくい |
| 資格 | 古物商・医療機器届出・PSE届出 | 取得可能なものと不可能なものがある |
| 資本 | 商標・在庫・広告 | 10万円で商標1区分（44,900円）は買える |
| 時間 | 信頼構築・審査期間 | 6ヶ月回転と衝突する |
| 知識 | 適合情報・法令・カタログ品質 | 越えられる |
| 規約 | Makuake配送完了前禁止・卸の「Amazon不可」 | 越えられない（守るしかない） |

## 5. 各案の詳細

### 5-A. 相乗り不可の状態を作る系

#### A1. 非食品セット組み（バンドル）で独自ASIN

| 項目 | 内容 |
|---|---|
| 手法名と一言 | 既存メーカー品2〜3点を用途で組み合わせ、独自の製品コード（JAN）で新規ASINを作る。単品の製品コード転用は不可・商品名に「セット」明記・メイン画像に全構成品 [S46] |
| ブルーオーシャンである根拠 | 壁＝手間と知識。セット組みは納品代行で1点30〜100円 [S34]。JANはGS1事業者コードが要る（年商1億円未満：1年17,050円・3年27,500円・審査3営業日）[S14]。単品相乗りと違い、同じ組み合わせを同じJANで出せるのは自分だけ |
| 競合密度の証拠 | 未調査（セット品ASINの出品者数は人手でしか確認できない） |
| 社長の制約との適合 | ◎。個人事業主可・日本語・PC完結（組み立ては代行）・10万円内。食品は組まない（法務判定：小分け・セット組みは食品表示責任が発生） |
| 初期資金・期間 | GS1 17,050円＋構成品仕入れ＋代行費。1件目まで2〜4週（推測・確度中：仕入れ→代行→FBA受領3〜5日） |
| 利益構造 | 粗利は構成品の合算。単品より販売価格を上げやすいが、FBA配送代行は寸法で上がる（標準 318〜532円 [S3]）。固定費はGS1年会費のみ |
| 適法性の論点 | 製品コード免除申請の条件・構成品メーカーの「セット販売」可否（卸規約）・景表法（セット価格表示）・PL責任の帰属 |
| 既存事例 | 公開の個人事例は商材系ブログのみ（信頼度低・URL不採用）。公式ルールは [S46] |
| 既存手法との接続 | 数を打つ（NETSEA既存仕入れの2〜3点を組む）。本丸ではメーカーに「セット限定独占」を提案する素材 |
