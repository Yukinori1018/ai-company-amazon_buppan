## 2. なぜ休止か：1注文の固定費と参考上代の倍率（試算）

R1 の仕入れ条件（売れ値≥損益分岐×1.25）を、卸値に対する倍率に直しました。置き値は、メルカリShops の手数料10%・発送代行で最安の1社（S-11・ネコポスサイズ・保管1か月）・入庫です。金額は out/ にあります。

| 卸値の帯 | 必要な売れ値（卸値の倍率） | 参考上代の倍率（JAN なし・実測の中央値） | 差 |
|---|---:|---:|---|
| S-12 の下限の帯 | 約2.5倍 | 約1.6倍 | 参考上代の約1.6倍で売れる必要がある |
| S-12 の中ほど | 約2.1〜2.4倍 | 約1.6倍 | 約1.3〜1.5倍 |
| S-12 の上限の帯 | 約1.8倍 | 約1.6倍 | 約1.15倍 |
| ネコポスに入らない品（60サイズ） | 上の各帯に＋0.3〜0.9倍 | 同じ | さらに開く |

- 事実：参考上代÷卸値は、JAN なし品で中央値1.56〜1.67倍（01・04 の実測。偏った標本）。発送代行の1件の費用は S-11。
- 推測：メルカリで、新品が参考上代を3割以上上回って売れるのは、指名で探される品（人気ブランド・限定品・品薄品）に限られる。汎用雑貨は、同じ用途の最安（海外の直接出品を含む）に引っぱられる。
- 読み：**損益を決めていたのは需要ではなく、1注文ごとの固定費と卸値の比率でした。** Amazon の単品で勝てない理由（v1 の §2・FBA の1点固定費）と同じ構造が、メルカリにもそのまま残っていました。v1 は売価を卸値の2.5倍と置いたため、この構造を見落としました。

### 参考：Amazon の単品とまとめ売り（v1 から変更なし）

| 卸単価（税抜） | 単品の利益率（上代＝卸値の2倍） | 5個まとめ | 10個まとめ |
|---|---:|---:|---:|
| 中央値付近 | −1% | +17% | +21% |
| その約7割 | −9% | +13% | +19% |

- Amazon の単品が成り立つのは売価2,000円以上です。まとめ売りは、卸値が Amazon の1個あたりの価格の60%以下のときだけ成り立ちます。

## 4. やること2：追加で数える候補（38件から）

条件：汎用品ではなく、型番・品名・色番号で「同じ品」と特定できるもの。そのうえで、足切り（30日220件以上）と R1（売れ値≥損益分岐×1.25）を通る見込みがあるか。

| 候補 | 特定できるか | 足切りの見込み | R1 の見込み | 判定 |
|---|---|---|---|---|
| C23・C32（韓国コスメのコンシーラー。同じ品の色違い。数えるときは1品） | できる（ブランド・品名・色番号） | ある（人気の品。推測） | 低い（必要な売れ値は卸値の約2.4倍。ブランド品は定価と並行輸入の価格が基準になる） | **唯一の候補。通る確率 約10%（推測）** |
| C31・C33（国際大会の公式グッズ。型番あり） | できる | 大会期間中だけ | — | 外す。大会は9/19〜10/4の予定。§4.1 を本線の初回 FBA 納品の後に置くと、出品が大会後になる。回転6ヶ月も破る |
| C13・C27（キャラクターのフリース・クッション） | おおむねできる | 不明 | — | 外す。最小ロットが12個を大きく超える（R3 違反） |
| C34（業務用の殺虫スプレー） | できる（NETSEA の商品コードが JAN の形） | — | — | 案3の対象外。JAN のある品なので、Amazon の本線（既存 ASIN への同梱）で照合する |
| 残りの30件 | できない（汎用品。パイロットの2件と同じ型） | — | — | 見込み無し |

- **結論：見込みがあるのは実質1品（C23・C32）です。3 SKU に届かないので、この1品が通っても案3は始められません。**
- だから、**追加の計数はしないことを推奨します**（判断を変えない調査はしない）。カズヨさんの手が空いていて、再開条件の手がかりを取りたい場合に限り、C23・C32 の1品だけを数えてください（10分以内。数え方は下）。
- 同じ品の数え方（R2・再開時にも使う）：写真と品名・型番（色番号）が一致するものだけ。中古・まとめ売り・同じ出品者の再出品（2件目以降）は数えない。売れた日が出ない場合は、商品ページの「◯日前」で30日を超えたところで止める。

## 5. 案の整理（v2）

### 案3　JAN の無い品をメルカリShops で売る → 休止（再開時の型だけ残す）

| 項目 | 内容 |
|---|---|
| 休止の理由 | §2（必要な売れ値が参考上代の約1.15〜1.6倍）と §4（通る見込みが1品）。3 SKU に届かない |
| 再開時の足切り | ①同じ品と特定できる（型番・品名・色番号）②30日の売り切れ220件以上 ③直近の売れ値（送料込みの中央値）≥損益分岐×1.25 ④ネコポスサイズに入る ⑤最小ロットが12個以下 |
| 再開時のロット | 足切り通過 SKU×12個（最小3 SKU・最大5 SKU） |
| 再開時の物流 | 月額0円の発送代行で、メルカリShops との API 連携（受注の自動取り込み）があるもの。サイズ区分ごとの料金で損益を出す |
| 再開時の社長の §4.1 | メルカリShops の出店申請（規約同意）／**発送代行の契約（規約同意）**／サプライヤーへの了承依頼（NETSEA のメッセージ・第三者連絡）／発注／出品の最後のクリック。実行は**本線の初回 FBA 納品の後** |
| 再開時の撤退条件 | 出品30日で、取り分の実測が置き値の0.3倍未満なら追加しない。60日で消化20%未満なら損益分岐まで値下げして終える。申告・承認の撤回が1件でもあれば全 SKU を止める |
| 再開時の KPI | 北極星：6ヶ月の累計損益（売れ残りは0円で評価）>0。先行：取り分の係数（売り切れ件数に対する当社の比率）が確定すること。行動：同じ品と特定できる候補を週10件確かめる |

### 案2　同じ品の N 個パック → 見送り（S-14 の結果、条件を通る品が0件）

| 項目 | 内容 |
|---|---|
| S-14 の結果（タカシ・事実） | 8件中0件が全条件を通過。組めるロットは0円 |
| 落ちた理由 | 季節性：4件／パックにしても赤字（Amazon 本体の売価が卸値と同程度以下）：2件／最小発注の数量が6ヶ月で売り切れない：2件（約9.6ヶ月・約15.6ヶ月分） |
| パックへ流れる率 | 同じ JAN のパック ASIN は、単品が月3,000個売れていても月50個未満（2%未満）。v1 の置き値3%は楽観側だった |
| 惜しい1件 | 子ども用歯ブラシ（10個パックなら利益率 約20%）。ただし最小発注を下げてもらう交渉が要る＝第三者連絡（§4.1）。回転6ヶ月を守るには最小発注の引き下げが前提で、交渉が通る保証は無い。**1周目は交渉しない**（本線の §4.1 を優先。再開条件3と同じ扱いで記録だけ残す） |
| 訂正 | v1 の候補のうち1件（住居用クリーナー）は「2個セット」ではなく「本体＋詰め替え2個」だった（金額入りの版で訂正） |
| 扱い | 見送り。本線への同梱もしない |

### 案1　JAN のある品を新規 ASIN で出す → 1周目は外す（マサルの判断を支持）

- 売価帯を満たす候補が1社の旧型品に偏っています。旧型品は利益率で並べると上位に来る型です（`knowledge_discontinued_bias_in_margin_ranking`）。

### 案4　本線の FBA 納品への同梱 → 既定どおり続ける

- 本線（スーパーデリバリー＋メーカー直）の初回 FBA 納品に、NETSEA の2件を同梱します。SD が不承認で本線が止まったら、単独では出しません（10 の決定どおり）。
- C34（JAN の形のコードを持つ殺虫スプレー）は、ここで既存 ASIN を照合する候補に加えます（0円・既存データの照合のみ）。

| 6 | 脇線の §4.1 は、本線の初回 FBA 納品の後に置く | 社長の手の配分。どの脇線にも同じ順番を適用する |
| 7 | まとめ売りへ流れる率は2%未満（S-14 の実測）。最小発注の数量だけで回転6ヶ月を破る品がある | 足切りに「最小発注÷当社の月販≤6ヶ月」を最初から入れる。まとめ売りの需要は既存パックの実販で見る |
| 8 | 判断を変えない調査はしない | 追加の調査を発注する前に、「結果が出たら何が変わるか」を1行書く |
