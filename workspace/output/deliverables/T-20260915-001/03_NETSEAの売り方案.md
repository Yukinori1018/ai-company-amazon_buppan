## 0. 結論

| # | 結論 |
|---|---|
| 1 | NETSEA で成り立っている事業者は、Amazon の単品では勝っていないと読みます（推測）。原因は FBA の1点ごとの固定費です。卸の中央値の商品を上代（卸値の約2倍）で売っても、1点の利益はほぼ0です（試算）。 |
| 2 | さらに、JAN が無くブランドが印字された品（NETSEA の多く）は、Amazon には出せません（02 L1-b が NG）。NETSEA の約3分の2は、Amazon 以外でしか売れないということです。 |
| 3 | 成り立つ形は3つに絞れます。①JAN のある商品で、他のモールで売れていて Amazon に無いものを、新規 ASIN で出す。②売れ筋の単品を錨にして、同じ品を N 個まとめたパックを出す。③JAN の無い品を、固定費0の別の売り場（メルカリShops）で売る。 |
| 4 | 推奨は案3です。本線の FBA 納品への相乗り（案4）は常に併走させます。母数が最も大きく、需要を「売り切れ件数＝実際の販売」で直接見られるのは案3だけだからです。ただし、0円の入口確認（出荷費用）と、サプライヤーの了承（NETSEA 経由・§4.1）を通してから着手します。 |
| 5 | どの案も、1周目の12ヶ月の現金への効果はほぼゼロです（期待値は1周目で数千円）。価値は「どの形なら横に広げられるか」を、6ヶ月で1つに決めることにあります。 |

**判断していただくこと（カズヨ経由・3つ）**
1. 案3を1周目の NETSEA 脇線にするか（推奨）。
2. 入口確認が通った時点で、次の2つを進めてよいか。①メルカリShops の出店申請（規約への同意＝§4.1）②候補のサプライヤーに、メルカリShops で売ることの了承を NETSEA のメッセージで依頼する（第三者連絡＝§4.1。下書きはカズヨが送信ボタンの手前まで作ります）。
3. 案3は Amazon の SKU 数（KPI の100）には数えられません。月商と利益への寄与として数えてよいか。

## 1. お客様の Preference 構造（出発点）

| 誰が | なぜ | いつ | どれだけ | 当社への意味 |
|---|---|---|---|---|
| Amazon で検索する人 | 用途で検索し、Prime・レビュー・1個あたりの価格で選ぶ。ブランドで選ぶ人もいる | 必要になったとき | 消耗品は定期的・まとめて | JAN があり、ブランドで探される商品しか見つけてもらえない。価格は同じ用途の最安が基準になる |
| メルカリで探す人 | 安い・かわいい・今すぐ。ブランドは問わない | 眺めている途中（衝動） | 1〜2個 | NETSEA の JAN の無い雑貨・ホビー・ファッション小物（NETSEA の約3分の2）と合う |
| まとめ買いする人（Amazon） | 1個あたりの安さ、買い置き | 切れる前 | 3〜10個を1回 | 売れ筋の消耗品で、単品の需要の一部がまとめ売りに流れる |

- 事実：NETSEA の JAN 保有率は34%。ホビーは9%、ファッション雑貨は13%。卸単価の中央値は、ホビー・雑貨・美容で250〜550円の帯（01・実測 A）。
- 推測：Amazon で JAN の無い汎用雑貨を探す人は、海外から直接出品しているセラーの価格を基準にする。国内の輸入卸を経由した NETSEA の卸値では、価格で勝ちにくい。確かめる調査は S-13。

## 2. なぜ Amazon の単品で勝てないか（試算）

置き値はすべて推定です。
- 販売手数料：12%（税込）
- FBA 配送代行手数料：320円（売価1,000円未満）／380円（3,000円未満）／480円（3,000円以上）
- 納品：50円／点
- 上代：卸値の2倍（参考上代のある商品の中央値。01 の実測 A から集計。分布は out/）

| 卸単価 | 売価（上代） | 1点の利益 | 利益率 |
|---:|---:|---:|---:|
| 250円 | 500円 | −211円 | −42% |
| 650円（全体の中央値付近） | 1,300円 | −17円 | −1% |
| 1,000円 | 2,000円 | +206円 | +10% |
| 1,250円 | 2,500円 | +365円 | +15% |

同じ品を5個まとめると、FBA の固定費は1回で済みます（売価は、単品の上代×5×0.9）。

| 卸単価 | 単品 | 5個まとめ | 10個まとめ |
|---:|---:|---:|---:|
| 450円 | −9% | +13% | +19% |
| 650円 | −1% | +17% | +21% |

- Amazon で単品として成り立つのは、売価2,000円以上の商品です。
- まとめ売りは、卸値が Amazon の1個あたりの価格の60%以下のときだけ成り立ちます。11 と同じ理由で、卸値が70%以上なら赤字です。

## 4. 案の比較

### 案1　JAN のある他社ブランド品で、他のモールで売れていて Amazon に無いものを、新規 ASIN で出す（単品・売価2,000円以上）

| 項目 | 内容 |
|---|---|
| 成り立つ理由 | ページを作るのは当社なので、最初の価格は当社が決める。作成直後の出品者は0人。ただし、02 L1-a の条件で**相乗りされる前提**になる。価格決定権は、相乗りが来るまでの期間に限られる |
| 規約 | L1-a は条件付きで可。条件は4つ。①メーカーの正規 JAN を使う ②ブランド名は印字どおりにする ③同じ JAN の ASIN が無いことを確かめる ④相乗りを前提にする。ブランド登録がある品は、所有者の書面許可が要る（L1-c）。**1周目は、ブランド登録のある品を除く** |
| 画像 | 当社で撮影する（02 の推奨。許諾の問題が生じない）。撮影は外注する（費用は S-16）。NETSEA の画像を使う場合は、共有カタログに使うことの了承を NETSEA 経由で取る（L3。第三者連絡なので §4.1） |
| 母数（実測） | 40社・JAN 213件を照合した。Amazon に無いものが45件、うち非食品が33件（10社。1社に偏りがある）。売価2,000円以上に置けるものは22件 |
| 需要の確かめ方（Keepa の代わり） | ①同じ JAN が楽天・Yahoo で売れているか（レビュー件数・ランキングへの掲載）。②用途が同じ既存 ASIN の上位3件の月販（Keepa の monthlySold）の合計が300個以上か。③Amazon の検索候補に、用途の語が出るか。予測は桁までしか当たらない（0.3〜4.3倍）ので、初回は1 SKU 10個までにする |
| 足切り | ①と②の両方を満たすこと。①が無いものは「売れていないから Amazon に無い」とみなして落とす |
| 作業と社長の関与 | サトル：他モールの販売実績を確かめる。ヒデアキ：出品文。カズヨ：出品の入力。社長：発注と出品の最後のクリックだけ。物理作業は、納品代行（撮影を含む）から FBA へ |
| 最初の検証 | 3〜4 SKU×10個、約4万円。本線の FBA 納品に同梱する。出品から60日で判定し、6ヶ月以内に売り切る |
| 6ヶ月の利益 | 楽観 +1.2万（20%）／中央 +0.4万（50%）／悲観 −0.4万（30%）。期待値 +0.3万（撮影の外注費と、相乗りによる値下がりを織り込み、前の版から下げた） |
| 評価の基準 | 60日で、1 SKU 以上が月10個以上売れる（取り分の実測）。①の「他モールの実績」と、Amazon での販売が合っていたか。相乗りが何日で来たか |
| 次の一手 | 合っていれば、同じ足切りで全221社に広げる（母数は非食品で百数十件の推計。推測で、偏りがある）。合っていなければ、①は予測に使えないとして案1を終える |
| 撤退条件 | 60日で全 SKU が月3個以下なら、追加しない。残りは損益0まで値下げして売る |
| 成功の確率 | 60日で1 SKU 以上が月10個以上：楽観40%／中央20%／悲観10% |

### 案2　売れ筋の単品を錨にして、同じ品を N 個まとめたパックを出す（5〜10個）

| 項目 | 内容 |
|---|---|
| 成り立つ理由 | FBA の固定費が1回で済む（§2）。パックのページは単品の棚から外れる。単品の棚は、出品者18人・Amazon 本体あり70%。パックのページではカートの取り合いが小さい |
| 規約 | L6 の代替の形（同じ商品の N 個パック）で行う。メーカーの JAN のまま、個数を入力し、商品名に数量を書く。専用の JAN もブランド認証も要らない。条件は2つ。①個装は開けない ②同じ JAN のパック ASIN が既にあれば、新しく作らずに相乗りする。他社品を組み合わせた独自セット（専用の JAN が要る）は1周目ではしない |
| 母数（実測・既存データの再解釈） | T-20260909-002 の月100個以上の738件のうち、次を満たすのが89件：本体なし・非食品・直送専門以外・入数が確定。そのうち卸値が Amazon の1個あたりの価格の60%以下は8件（4社）。これがこの案の上限（8 SKU） |
| 需要の確かめ方 | 単品の monthlySold（Keepa。社長ルールの月100以上をそのまま使える）に、パックへ流れる率を掛ける。率の置き値は3%（楽観8%／悲観1%）。率は、同じ JAN の既存パック ASIN の月販で確かめる（S-14） |
| 足切り | 単品の月販が200個以上。同じ JAN のパック ASIN が1件以下。本体なし。卸値の比率が0.6以下 |
| 作業と社長の関与 | タカシ：8件の月販の実値（数トークン）。カズヨ：出品の入力。社長：発注とクリック。物理作業：N 個の束ね（外装を開けず、袋にまとめてラベルを貼る）は納品代行に外注する（費用は S-15） |
| 最初の検証 | 2 SKU×8パック、約4万円。本線に同梱する。60日で判定する |
| 6ヶ月の利益 | 楽観 +0.8万（20%）／中央 +0.35万（50%）／悲観 −0.3万（30%）。期待値 +0.25万 |
| 評価の基準 | 60日でロットの50%以上が消化される。パックへ流れる率の実測が、置き値の0.3倍以上 |
| 次の一手 | 上限が8 SKU なので、広げる先は SD・メーカー直で仕入れた売れ筋（卸値の比率が低い）に移す。NETSEA だけで広げることはしない |
| 撤退条件 | 60日で消化が20%未満なら、追加しない |
| 成功の確率 | 60日で消化50%以上：楽観50%／中央35%／悲観15% |

### 案3　JAN の無い品を、メルカリShops で売る（推奨）

| 項目 | 内容 |
|---|---|
| 成り立つ理由 | NETSEA の約3分の2は JAN が無い。JAN が無くブランドが印字された品は Amazon に出せない（L1-b）ので、Amazon の出品者はここに入って来ない。メルカリの買い手はブランドを問わない（§1）。手数料は10%だけで、固定費は0（01・S10）。NETSEA 公式も、メルカリと楽天を売り先に挙げている |
| 価格決定権 | 部分的。個人の出品と並ぶので、同じ品の最安が基準になる。新品・即日発送・まとめ買い割で差をつける |
| 規約 | L4：メルカリShops は条件付き。①「ネットオークション可」が Y の品に限る（74%）②サプライヤーの了承を NETSEA のメッセージで取り、記録を残す（第三者連絡なので §4.1）。L5-c：在庫を持って出品する（無在庫は NG）。画像：自社の出店での出品用なので、NETSEA の許諾の範囲に入る（S5）。ただし、画像転載可が Y の品に限る |
| 母数（実測） | 40社の3,809件のうち、JAN の無いものが2,518件。24社は JAN が1つも無い。オークション可・画像転載可の両方を満たすのは約6割。案の中で最大 |
| 需要の確かめ方 | メルカリの「売り切れ」で絞り込み、同じ品の直近30日の売り切れ件数を人が数える。これは推定ではなく、販売の実数。足切りは30日で110件以上（取り分5%の置き値で月5.6個＝10個ロットを悲観でも6ヶ月で売り切れる線）。補助に楽天のランキングを見る。機械では取得しない |
| 物理作業 | 注文ごとの発送は、月額0円の発送代行に外注する（1件の費用は S-11）。Amazon のマルチチャネル（FBA の在庫から出荷する仕組み）は ASIN が要る。印字の無いノーブランド品で、GTIN 免除を取った品に限って使える（L2）。1周目は発送代行で組む |
| 作業と社長の関与 | サトル：売り切れ件数と発送代行の費用。カズヨ：サプライヤーへの了承依頼の下書き（送信ボタンの手前まで）と、出品の入力。ヒデアキ：出品文。社長：出店申請（本人確認・規約同意）、了承依頼の送信、発注、出品の最後のクリック |
| 最初の検証 | 5 SKU×20個、約5万円。発送代行へ直送する（本線の納品とは別便。1回の送料で100点になるので送料負けしない）。了承の返事を待つ時間を見込み、了承の依頼は候補の8社に出す（5社から了承が得られる置き値）。出品から60日で判定し、6ヶ月以内に売り切る |
| 1点の採算（試算） | 売価を卸値の2.5倍にすると、1点の利益は卸450円の品で+158円（14%）、卸650円の品で+387円（24%）。置き値は送料210円（小型）＋代行費150円／件。代行費が300円／件なら、利益率は約10ポイント下がる |
| 6ヶ月の利益 | 楽観 +1.35万（20%）／中央 +0.5万（50%）／悲観 −0.35万（30%）。期待値 +0.4万 |
| 評価の基準 | 60日で消化40%以上。取り分の実測が、置き値（売り切れ件数の5%）の0.5倍以上。1件の出荷費用の実額が400円以下 |
| 次の一手 | 通れば、足切りを通る SKU を221社に広げる（NETSEA で SKU を積める唯一のレーン）。売れた品のうち、印字が一切無いノーブランド品は、GTIN 免除で Amazon にも出す（L2。売価2,000円以上になるパックに限る。§2） |
| 撤退条件 | 入口：1件の出荷費用が400円を超える、または了承が3社未満なら、着手しない（案2へ回す）。販売後：60日で消化が20%未満なら、追加をやめて損益0まで値下げする。申告・承認の撤回が1件でもあれば、全 SKU を止める（02 §3） |
| 成功の確率 | 60日で消化40%以上：楽観55%／中央40%／悲観20% |

## 5. やらないこと

| やらないこと | 規約上の状態（02） | 理由 |
|---|---|---|
| JAN が無くブランドが印字された品を、Amazon に「ノーブランド品」として出す | NG（L1-b） | 禁止。メーカーに JAN を取ってもらう道はあるが、1周目では追わない |
| 印字の無いノーブランド品を、GTIN 免除で Amazon の単品として出す（売価1,000円未満） | 条件付き（L2） | 規約上は出せるが、売価1,000円未満は FBA の固定費で赤字になる（§2）。価格の基準は海外の直接出品になる（推測・S-13）。案3で需要が実証され、パックで2,000円以上になる品に限って後から出す |
| 当社のブランド名を印字する | 条件付き（L2'） | 印字すると表示製造業者として PL 責任を負う。OEM（③）の段階で判断する |
| 他社品を組み合わせた独自セット | 条件付き（L6） | 専用の JAN・外箱の表示の書き分け・サプライヤーごとの可否確認が要る。同じ品の N 個パック（案2）で、同じ効果（固定費の圧縮）が得られる |
| ゲートの無い分野（アパレル・ホビー・季節雑貨）で、Amazon の単品を出す | カテゴリによる | ゲートの無い棚は取り分が薄い（knowledge_filter_order）。アパレルはサイズと返品。季節品は6ヶ月の回転を超えやすい。卸単価の中央値250〜550円は、§2 で赤字 |
| 注文後の仕入れ（無在庫・直送） | L5-a は非推奨、L5-c（メルカリ）と L5-d（楽天）は NG。L5-b（取り寄せてから当社が発送）は条件付き | 日本は復活した直後で、ポリシー違反1件が重い。L5-b は、当社に発送の手が無い（社長は PC 作業のみ）ので外注費がかかり、キャンセル率2.5%未満の管理も要る。在庫を持つ形に限る |

## 6. 推奨：案3（＋案4 を併走）

| 比較 | 案1 | 案2 | 案3 | 案4 |

- 確度：推奨として約55%です。入口確認（S-11 の出荷費用、サプライヤーの了承が3社以上）で逆転しうるので、通らなければ案2を1周目にします。
