# 02 売り方の規約判定（L1〜L7）

- チケット：T-20260915-001 ／ 担当：法務ハルオ ／ 確認日：2026-09-15
- 入力：`01_NETSEAで成り立つ事業者の実態.md` §4
- 対象：Amazon.co.jp（大口・FBA／出品者出荷）、NETSEA バイヤー会員規約・ヘルプ・API 規約、サプライヤーの取引条件、メルカリShops、楽天市場

## 0. 読み方と確度の限界

- 判定は **OK／条件付き／NG** の3段階です。NG にも適法な代替を付けています（`feedback_legal_no_is_not_a_prefilter`）。実行するかは社長の判断です。
- **Seller Central のヘルプ本文は、ログインしないと読めません**（JS 描画のため curl で本文が返りません。G201808410・G200426310 で確認済み）。Amazon の判定は次の2つを根拠にしています。①Amazon 公式アカウント News_Amazon のフォーラム投稿（一次）②解説記事（二次）。二次に頼った箇所は「確度」欄に書きました。**確度が「中」の行は、秘書がログインした画面でヘルプ原文を見て確定させてください。**
- リスクの評価軸は「発生確率 × 影響度 × 不可逆性」です。**当社の Amazon アカウントは現在、日本・北米とも停止中で、復旧手続きをしています。** 停止中や復旧直後にポリシー違反を1件でも出すと、影響度と不可逆性は最大になります。そのため、確率が低い論点でも「条件付き」と判定しました。

## 2. 横断の結論（売り方の設計に効くもの）

1. **Amazon の新規 ASIN は「JAN のある他社ブランド品」か「印字の無いノーブランド品」のどちらかでしか作れません。** JAN が無いのにブランドが印字されている品（NETSEA 品の多く）は、メーカーの協力がなければ出せません。
2. **画像は「当社撮影」が最も安全です。** NETSEA の画像を使うなら、共有カタログに使うことについてサプライヤーの了承を記録に残してください。
3. **無在庫で出品者出荷をすると、アカウントの復旧を賭けることになります。** 当面は、在庫を持つ形（FBA、または取り寄せてから当社が発送）に限るのが法務の推奨です。
4. **NETSEA 外でサプライヤーと合意してはいけません。** 直送の条件もセット化の了承も、NETSEA のメッセージ機能の中で取り、記録を残してください（19条3項・27条3項）。

## 3. グレーを進める場合の3点セット（L3・L4 メルカリShops・L5-a）

| 項目 | 内容 |
|---|---|
| リスクシナリオ | L3：サプライヤーから画像削除の要求が来る、または Amazon に著作権侵害の申告が出る → 出品が削除され、アカウント健全性の知的財産の項目に記録が残る。L4：サプライヤーから取引申請の承認を撤回される（サプライヤー規約 7条2項）。L5-a：送り状の依頼主がサプライヤー名になっていて購入者から通報される → 出品者出荷が制限される |
| 発生時の対応 | 該当する出品をただちに停止し、画像を差し替える。サプライヤーには NETSEA 経由でお詫びし、事実を確認する。Amazon の知的財産の申告には、許諾の記録（NETSEA のメッセージ）を添えて異議を出す |
| 撤退条件 | 申告または撤回を **1件** 受けたら、その売り方を全 SKU で停止する。アカウント健全性に知的財産またはポリシー違反の記録が1件でも付いたら、L5-a は恒久的にやめる |
