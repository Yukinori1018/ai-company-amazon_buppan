# 01 NETSEA で成り立つ事業者の実態（公開版）

T-20260915-001 / リサーチャー サトル / 2026-09-15。事実の収集だけを扱う。売り方の仮説はタケシの担当。
卸値・ASIN ごとの値は `out/`（Git 追跡外）にある。

## イシュー

NETSEA の卸値で利益を出している事業者は、どの売り場とどの売り方で「価格決定権」と「競合の少なさ」を得ているのか。Amazon の既存 ASIN への相乗り以外に何があるのか。

## 2. 実測（手元のデータ）

### 実測 A：承認済みサプライヤーの商品の販売条件（2026-09-15 取得）

- 母集団：当社の承認済みサプライヤー 221社。無作為に40社を選び、1社あたり最大100件を取得した（3,809件）。
- 定義は NETSEA Buyer API の schemas/items.json による（S15）。

| 項目 | 件数 | 比率 |
|---|---|---|
| JAN あり（本体か規格のどちらか） | 1,291 | 34% |
| 画像転載可（`image_copy_flag`=Y） | 3,154 | 83% |
| ネット販売可（`deal_net_shop_flag`=Y） | 3,809 | 100% |
| ネットオークション可（`deal_net_auction_flag`=Y） | 2,816 | 74% |
| 商品配送可（`direct_send_flag`=Y） | 3,809 | 100% |
| CSV ダイレクト注文可 | 400 | 11% |
| 参考上代がオープンプライス | 2,949 | 77% |

- JAN の有無はサプライヤー単位で分かれる。JAN が0%の社が 24/40、90%以上の社が 12/40。
- 注意1：ネット販売可が 100% なのは、承認申請の時点で当社がネット販売可の社を選んだ結果の可能性がある。API が絞っているかどうかは確認していない。
- 注意2：`direct_send_flag` の定義は「商品配送可」。公式ヘルプの「消費者へ直送 対応可／販売後注文可」と同じものかは確認できていない。同一視しない。

### 実測 B：JAN がある商品は Amazon にあるか（Keepa、2026-09-15）

- 対象：実測 A のうち JAN がある商品から、1社最大15件で213件（16社）。Keepa の product API に JAN で照会した。

| 項目 | 値 |
|---|---|
| Amazon に ASIN あり | 168（79%） |
| Amazon に ASIN なし | 45（21%）。うち15件が1社。カテゴリは家電19・食品12・ホビー6 |
| ASIN が2つ以上ある JAN | 36 |
| Amazon 本体が現在出品 | 43/168（26%） |
| 新品オファー数（取れた120件） | 中央値3、1〜2本 54件、3〜9本 43件、10本以上 23件 |
| monthlySold の表示あり | 13/168（うち100以上が8） |
| 売れ筋ランク（取れた117件） | 中央値 約28.5万位。30万位以内は60件 |

- 注意1：新品オファー数は Keepa の `COUNT_NEW` の現在値で、セラーの数ではない。今回はオファーを付けずに照会したので、値が古い可能性がある。48件は値が無かった。
- 注意2：「ASIN なし」は「Keepa が JAN を追跡していない」場合を含む。
- 注意3：承認済みサプライヤーは、過去のチケットで Amazon と照合して選んだ社が多い。Amazon にある比率は、NETSEA 全体より高く出ていると考える（推測）。

## 4. 規約上の論点（ハルオに回す候補）

| # | 論点 | 分かっている事実 | 分かっていないこと |

| L1 | 他社ブランドの NETSEA 商品で新規 ASIN を作れるか | GTIN 免除は「ブランド名＋カテゴリ」で申請し、ブランド名が印字された写真が要る（S8、二次） | 他社ブランド品で免除を取ることが Amazon のブランド要件に反しないか。Seller Central の公式ヘルプはログインが要り、読めていない |
| L2 | ノーブランド品（JAN なし 66%）を Amazon に出せるか | 同上 | 「ノーブランド」表記の可否。当社が GS1 の JAN を取って付ける場合の表示の責任 |
| L3 | 画像転載可の画像を Amazon のカタログに使えるか | 用途は「自社サイト…各ご出店のモール出品用」（S5） | Amazon のカタログは他のセラーも使う共有ページ。これが「自社の出品用」に当たるか。API 規約 第8条2項（情報の加工は書面承諾）と「CSV は加工して使う」（S5）の関係 |
| L4 | 「ネットオークション不可」（26%）は Amazon・メルカリShops を含むか | フラグの定義は「ネットオークション可」だけ（S15） | オークションの範囲の定義 |

| L6 | セット組み | セット商品は GTIN 免除の対象例（S8、二次） | 他社商品を組み合わせたセットの商標・表示の扱い。サプライヤーごとのセット化の可否 |
| L7 | 住所の公開（既知の未了論点） | 会員規約 第24条1項 | 社長判断が未了 |

## 5. 分かっていないこと

- **分かりようがないこと（公開情報では）**：NETSEA 仕入れの事業者の業態別の件数・利益率・生存率。NETSEA が公開していない。
- **追加の手間で分かること**：①JAN の無い商品が Amazon に出ているかどうか（商品名で検索する必要がある。Amazon 本体の機械取得は法務 NO なので、人が見るか Keepa の検索になる）②セット化の可否（サプライヤーの注意事項欄を読めば分かる）③楽天・Yahoo の公式の手数料ページ。
- **ここから先はタケシ（プランナー）の領分です**：どの売り場・どの売り方で当社が NETSEA を使うか。
