## 4. 依頼の論点への答え

### 4.1 需要の証拠が弱い場合、6ヶ月で売り切れるか

売り切れません（確度70%）。
- タケシの足切り（30日で110件・取り分5%）では、1 SKU が月5.6個です。20個を売り切るのに4ヶ月弱かかります。
- 取り分が悲観の1.5%なら月1.7個です。20個に約12ヶ月かかり、**回転6ヶ月を超えます**。
- 証拠が弱い世界の計算では、6ヶ月の消化率の中央が54%、完売の確率は0%です。
- 直し方：①悲観の取り分でも6ヶ月で売り切れる線に足切りを置く（30日で220件以上。1.5%で月3.3個＝12個が約4ヶ月）②1 SKU を12個にする。

### 4.2 発送代行の費用がずれたときの損益分岐

1点の利益＝0 になる代行費（送料は置き値のまま）を、タケシの置き値（代行費）に対する倍率で示します。

| 卸値の帯 | 売価＝参考上代（卸値の1.56倍） | 売価＝卸値の2.0倍 | 売価＝卸値の2.5倍（タケシ） |
|---|---|---|---|
| NETSEA の JAN なし候補の中央値の帯 | 送料だけで赤字 | 0.1倍 | 1.0倍 |
| タケシの下限の帯 | 送料だけで赤字 | 0.9倍 | 2.3倍 |
| タケシの上限の帯 | 0.3倍 | 2.0倍 | 3.9倍 |

- 読み方：タケシの売価（2.5倍）が通るなら、代行費は置き値の2〜4倍まで耐えます。**売価が2倍に落ちると、下限の帯は置き値ちょうどで赤字になります。** 損益を決めているのは代行費ではなく売価です。
- 実勢の目安（料金を公開している従量課金の業者）は、送料・作業・資材込みで、タケシの置き値（送料＋代行費）の約0.7倍です。ただし、60サイズになると約1.4〜1.9倍です。**S-11 は「1件いくら」ではなく「サイズ区分ごとにいくら」で取ってください。**
- NETSEA の JAN なし候補（両方の条件を満たす1,689件）の卸単価の中央値は、タケシの売価帯の前提より低い帯にあります。タケシの帯（下限以上）に入るのは約4割、上限以上は約3割です。**プールの過半は、どの売価でも構造的に赤字の帯です。**

### 4.5 ロードマップ上の価値と、時間に見合うか

- **横に広げられるかは判定できます。** ただし、条件が1つあります。売価を卸値の倍率で置くと、失敗したときに「需要の読みが外れた」のか「値付けが高すぎた」のかを分けられません。売価を売れ値に合わせれば、60日で測れるのは「売り切れ件数に対する当社の取り分」の1つだけになります。これは、2周目で221社に広げるときに必要な唯一の係数です。
- 広げたときの天井（推測）：30 SKU で月商は20万円前後、利益は月数万円です。月商800万の目標に対しては数%で、Amazon の SKU 数には入りません。

- 案2を「案3が通らなかったときの代替」に置くのはやめてください。§1 のとおり、案2は入口で止まる確率が55%あります。代替は「脇線の休止」です。

|---|---|---|
| R1 | 売価を「卸値の2.5倍」から「同じ品の直近の売れ値（送料込みの中央値）」に変える。仕入れる条件は「売れ値≥損益分岐×1.25」とする。S-12 で、売り切れ件数と一緒に売れ値を取る | 参考上代は卸値の1.56倍（中央値）。2.5倍は根拠が無い |
| R2 | 足切りを「30日で110件以上」から「220件以上」に上げる。同一品の判定基準（写真と型番の一致、中古は除外、同じ出品者の再出品は1件）を S-12 に書く | 悲観でも回転6ヶ月・月3個以上を守るため |
| R3 | ロットを「5 SKU×20個」から「足切りを通った SKU×12個（最大5 SKU）」に変える。通過が3 SKU 未満なら3 SKU で始める。5 SKU にこだわらない。候補は100件前後を見る | 足切りの通過率は約4割 |
| R4 | 出荷費用をサイズ区分で持つ。候補はネコポスに入る品を優先する。S-11 にメルカリShops との API 連携（受注の自動取り込み）、入庫・保管・資材・返品の料金を加える | 損益を決めるのはサイズ。社長の毎日の作業を防ぐ |
| R5 | 社長の §4.1 一覧に「発送代行の契約」を加える。§4.1 の実行時期を「本線の初回 FBA 納品の後」に置く | 社長の手の取り合いを避ける |
| R6 | 案2を代替から外し、代替を「脇線の休止」にする。案2を残すなら、8件のブランド登録・ゲート・単品 JAN でのパック作成の可否を先に確かめる（ハルオ・0円） | 案2は入口で止まる確率が55% |
| R7 | 撤退条件に「出品30日で、取り分の実測が置き値の0.3倍未満なら追加しない」を加える。KPI の「広げられる SKU 3件以上」は、「取り分の係数が確定すること」に置き換える | 60日を待たずに悪い世界を見分けるため |

案1は1周目から外す判断を支持します（候補が1社の旧型品に偏っているため）。案4は既定のまま進めてください。
