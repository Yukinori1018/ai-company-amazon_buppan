0. このレポートのイシュー

「副業初心者の社長が、Amazon物販の界隈で消耗せず勝ち筋に乗るために、最初に持つべき地図は何か」

先に結論（3行）
  1. 手法は「単純転売（せどり）→ メーカー仕入れ／OEM」へ重心が移動。2026年は規制強化で相乗り新品転売の難易度が上がり、再現性は「仕入れ先の信頼性」で決まる方向。
  2. 初心者の失敗は技術不足ではなく「出品制限の確認漏れ」「資金繰り」「ツール数字の誤読」の3つに集中。事前知識でほぼ回避できる（＝本レポート最大の価値）。
  3. 発信者は玉石混交。実務系（無料情報が具体的）と煽り商材系（高額スクール導線・誇大表現）を必ず区別。鵜呑み厳禁。

1. 物販手法の分類（用語地図）

用語補足: 「せどり」= 安く仕入れ高く売る転売の総称（語源は古本の背取り）。「物販」はOEM等の自社商品販売まで含む上位概念。

1.1 仕入れチャネルによる分類

手法何をするか難易度主なリスク補足
店舗せどり実店舗で値札と相場の差を取る中労働集約・在庫の偶然性相場観が早く身につく
電脳せどりネット仕入れ→Amazon販売中価格改定・ポイント規約在宅完結。既存メモリに詳細
新品せどり新品を転売中〜高出品制限・真贋調査・垢停止2026年は規制が最も厳しい
中古せどり中古品を仕入れ販売中古物商許可必須・状態クレーム専門知識で利益率高・ライバル少
無在庫販売注文後に仕入れ発送高規約グレー〜違反・欠品初心者は非推奨
メーカー仕入れメーカー/卸と直接継続取引中（交渉）初回ロット・交渉ハードル2026年の主流の勝ち筋
OEM/簡易OEM自社ブランド品を製造高在庫・品質・PL/食品衛生法差別化の最終形。資金と時間要
輸入/輸出海外Amazonとの価格差高関税・規制法・為替・納期OEM前段の中国輸入が定番

1.2 「相乗り出品」vs「単独出品」

用語補足: Amazonは1商品=1ページが原則。同じページに複数出品者が並ぶのが「相乗り」、自分だけのページが「単独（OEM等）」。
  • 相乗り: 即出品できるが価格競争に巻き込まれやすい。注意相乗り禁止商品に出すとアカウント停止リスク。
  • 単独: 価格競争から逃げられるが、ページ作成・広告・レビュー獲得の手間と資金が必要。

1.3 販売方式: FBA vs 自己発送

詳細は既存メモリ「48歳コンサル Part3」に整理済み（送料負けの真実・MSS）。要点: FBA=保管〜CSをAmazon代行・初心者向き。自己発送=手数料ゼロだがMSSで送料圧縮。ツールの利益表示はFBA手数料控除後が多く、そこから二重に送料を引く「赤字錯覚」に注意。

2. 初心者の典型的失敗（事前に潰せる）

#失敗パターン何が起きるか回避策
1出品制限の確認漏れ仕入れ後に出品不可→不良在庫。新品家電（SONY/Panasonic/Apple/Nintendo/Canon/象印 等が名指し規制）で多発仕入れ前に必ずセラーセントラルでASIN/JANを検索し出品可否確認（鉄則）
2真贋調査で垢停止本物の証明（請求書）を出せず売上金凍結→大赤字領収書を残せる正規ルート仕入れを優先
3価格差だけでリサーチ売れ行き（ランキング）を見ず、安いだけの不良在庫Keepa/ERESAでランキング推移・販売頻度を確認
4資金繰りの読み違い入金は2週間サイクル＋引当金で一部保留。資金が尽きる初期資金は理想30万円。回転30〜60日以内を選ぶ
5ツール数字の誤読FBA控除後利益から二重に送料を引き黒字商品を捨てるFBA/自己発送の費用構造を理解
6利益率にこだわり動けない完璧商品を探し続け経験も実績も積めず停滞利益率5%・利益500円・月販5個まで緩め「60点の行動を量産」
7古物商許可なしで中古販売無許可営業は古物営業法違反警察署で取得（約19,000円・1〜2ヶ月）

3. 勝ち筋パターン（2024-2026の重心）

3.1 重心シフト: 単純転売 → 信頼性ある仕入れ先 確度 高

事実: 2026年版の複数ソースが「メーカー仕入れへのシフト」「規制強化対応が主要テーマ」で一致。相乗り新品せどりは「いつ止められるか分からない」構造的リスク。
勝ち筋: 領収書を出せる正規ルートでリピート仕入れ→自分だけの定番を資産化。

3.2 仕組み化（システム型物販） 確度 中・特定発信者

既存メモリ「電脳せどりシステム化」（朝野拓也）に詳しい。ただし中〜上級の話。初心者がいきなり外注化は時期尚早。

3.3 専門知識 × ニッチ 確度 中

自分の詳しい領域の中古・専門品はライバル少・利益率高。当社KPI「ニッチ良品100SKU」と方向一致 → 社長の得意領域の棚卸しが起点になり得る（プランナーへの論点）。

3.4 ツールで判断を高速化 確度 高

既存メモリ「ERESA」に詳しい。セラーリサーチ×詳細検索×カート取得率分析の3点が最ROI。軸A（T-003）と直結。

5. 学習ロードマップ（1ヶ月 → 3ヶ月 → 半年）

実 Do（仕入れ・契約・課金）は社長承認 / CLAUDE.md §4.1 対象。

Phase 1: 最初の1ヶ月 — 土台と1回転

  • 知識: 本レポート＋既存メモリ3本。手法地図と失敗7パターンを頭に。
  • 環境: 専用口座・Gmail、梱包材（100均でOK）、必要ならプリンタ。
  • アカウント: 大口出品（月4,900円・税込）が無難（FBA・広告・審査安定）。※課金は §4.1。
  • 小さく1回転: 出品制限なしの低リスク商品で「売り切る経験」を優先。FBA体験。
  • 鉄則: 仕入れ前に出品可否チェックを習慣化。

Phase 2: 3ヶ月 — リサーチの型と回転率

  • ツール検証: ERESA 7日無料お試しで自ジャンルの利益商品抽出を検証（軸A連動）。※有料契約は §4.1。
  • 回転率重視: 30〜60日で売り切るSKUに絞る。資金繰りを実体験で理解。
  • 得意領域: 詳しい分野でニッチ中古/専門品を当たる（中古は古物商許可）。
  • 発信の取捨選択: 実務系の無料情報のみ。煽り系はミュート。

Phase 3: 半年 — 資産化と差別化の選択

  • 重心移動: 単純転売の消耗を感じたらメーカー仕入れ（正規ルート・資産化）へ。
  • 仕組み化の入口: 自動リサーチ・一部外注を「必要になったら」導入（最初からはやらない）。
  • OEM/輸入は任意: 資金・時間に余裕が出てから。
  • KPI接続: SKU100・月商800万・利益率20%に向け勝ちSKUを定番化。

6. 分かっていること / いないこと / 分かりようがないこと

区分内容
分かっていること（事実）手法分類、初心者失敗の頻出パターン、2026年の規制強化と仕入れ先重視への重心移動、FBA/自己発送の費用構造、主要発信者の存在と高額商材導線
分かっていないこと各発信者の最新実績の真偽（自社調べは割引が必要）、X個別アカウントの現時点の信頼度、社長の得意領域に適したニッチ
分かりようがないこと「絶対に稼げる商品/手法」は存在しない。相場・規制・アカウント状況で常に変動

7. プランナー（タケシ）への論点バトン

  1. 入口の手法選択: 軸B体験仕入れは電脳せどり（在宅・低資金）か店舗せどり（相場観が早い）か。社長の生活時間と相性で A/B。
  2. 得意領域の棚卸し: 社長の前職・趣味からニッチ候補を引き出すワークが必要か。
  3. ツール導入タイミング: 軸A（T-003）と連動。Phase1から入れるか、Phase2の体験後か。
  4. 発信者との距離: 無料情報の参照範囲をどこまで許容し、高額スクールは原則「不要」と置くか。
