## 0. 結論

1. **一番の問題は「価格の約束」でした。**サイト・会社概要PDF・メール・電話台本のすべてに「希望小売価格・下限価格のご指定に従います」「希望小売価格を守って販売します」がありました。独占禁止法の再販売価格の拘束に読まれうるので、全部「値下げ競争に頼った販売はしません。販売価格は当店が判断して決めます」に置き換えました。
2. **事実と違う記載が4つありました。**「事業用口座を保有」（屋号付き口座は未開設）、「これまで一度も価格を崩したことがない」（販売ゼロなので当然そうなる＝誤解を誘う）、「海外への販売は行いません」（Shopee 台湾を準備中）、そして**いま添付している会社概要PDFに同じ文が2回入っていました**。全部直し、PDF を作り直しました。
3. **食品と医薬部外品の方針が、法務の判断・打診先と食い違っていました。**サイトは「医薬部外品は見合わせ／常温の食品は取り扱います」でしたが、法務46では医薬部外品も許可なしで販売でき、打診第1弾146社のうち16社は、注意列に「/partners と衝突」と書かれたまま（医薬部外品・入浴剤・スプレー等）でした。方針を「**扱う／品目ごとに確認して扱う／いまは扱わない**」の3段に分け、全ページでそろえました。食品を「扱える」とは断定していません。
4. **/partners の冒頭に「事業者情報」を新設し、「販売実績：現時点ではありません」と書きました。**取引条件は「当店の希望」と明記し、「御社の最低発注数量など条件があればそれを前提に相談します」を添えました。
5. **打診メールは本文を約100字短くし（680〜731字 → 579〜635字）、要点を箇条書き4行にしました。**担当者が「誰が・何を・どの条件で・何を返せばよいか」を上から30秒で拾える順です。「本業を別に持っており」は削りました。146社分を新しい型で作り直しました。

**公開前に社長に見ていただきたい点は §5 の3つです**（医薬部外品の方針変更／署名と /partners の電話番号／作成済みの Gmail 下書き34通の扱い）。

### 1-1. 秘書の指摘のうち、そのまま採らなかったもの（CLAUDE.md §3.3-39）

| 指摘 | 判断 | 理由 |
|---|---|---|
| 署名に個人宅の住所・携帯番号を直書きしている（プライバシー） | **住所・電話は残す。表記をサイトとそろえる** | ①特定電子メール法4条・施行規則9条で、メールには送信者の住所の表示が要る（法務10 §6）。②住所はサイトの全ページのフッター、電話は /about で**すでに公開済み**で、署名から消してもプライバシーは守れない。③会ったことのない個人事業主から住所も電話も無いメールが来れば、担当者はかえって警戒する。プライバシーを本当に守るなら、電話は 050 番号に替えるのが筋（§5-2） |
| 「今後このようなご連絡が不要な場合は…」は営業メール感を強める | **一文は残し、言い方を和らげて最後の行へ** | 署名に /partners の URL を載せるので、法務10の判定どおり特定電子メールとして送る。その場合「受信を断る方法」の表示は法4条2号の義務で、削れない。「今後のご連絡がご不要の場合は、info@satoy-select.com 宛にその旨お知らせください」とした（法務確認で通知先アドレスを明記） |

### 2-3. 打診文の型

**新しいメールの本文（共通部分）**。〔 〕は社ごとの差し込み、〔住所〕〔電話〕は送信前に秘書が埋めます。

```
〔会社名〕
〔宛名〕

突然のご連絡を失礼いたします。
Satoy Select（サトイセレクト）の佐藤之則と申します。国内メーカーの商品を Amazon.co.jp で販売する個人事業主です。

〔対象：御社の「商品名」〕を、少量から仕入れさせていただけないかというご相談です。
〔個別文：公式で読んだ事実1文＋Amazon での売れ方の固定句〕

要点を先にお伝えします。
・開業：2026年8月。販売実績はまだございません
・販売先：Amazon.co.jp
・初回：5〜10点ほど・前払い（銀行振込）を希望します。最低発注数量など御社の条件があれば、それに沿って検討いたします
・その後：売れ行きを見て数量を段階的に増やし、継続して仕入れることを目指します

販売にあたっては、商品情報を御社の公式情報どおりに載せ、ブランドのイメージを大切にいたします。値下げの追いかけ合いには加わりません。販売状況は、ご希望に応じてご報告いたします。

〔前置き〕卸価格・最低発注数量・お支払い条件・納期をお知らせいただけますでしょうか。
直接のお取引が難しい場合は、〔紹介先：卸問屋様〕をご紹介いただけるだけでも大変ありがたく存じます。

会社概要（PDF）を添付いたしました。ご検討いただけますと幸いです。

――――――――――――――――
Satoy Select（サトイセレクト）　佐藤之則
住所：〔住所〕
電話：〔電話〕
メール：info@satoy-select.com
取引先の皆さまへのご案内：https://satoy-select.com/partners
いただいたご連絡先は、本件のご相談にのみ使用いたします。
今後のご連絡がご不要の場合は、info@satoy-select.com 宛にその旨お知らせください。以後お送りいたしません。
――――――――――――――――
```

| 2行目「国内メーカーの商品を Amazon.co.jp で販売する個人事業主です」 | 「誰が」を1行で。「営んでおります」（営業中と読める）をやめ、業態の説明にとどめた |
| 4行目「〜を、少量から仕入れさせていただけないかというご相談です」 | 「何を」と「少量」を最初に出す。「売り込みではなく」は削った |
| 箇条書き4行 | 「どの条件で」を地の文から出した。実績ゼロは1行目に置く（隠していないことが一番伝わる位置） |
| 「御社の条件があれば、それに沿って検討いたします」 | 5〜10点は希望であって条件ではない。メーカーの最低ロットを先に否定しない |
| 販売の段落 | 値下げしないことは方針として言い切り、価格の約束はしない。「本業がある」という理由付けは削った |
| 依頼と卸問屋 | 「次に何をしてほしいか」。返事の選択肢を2つ渡す（変更なし） |
| 署名 | 法定の表示（名前・住所・連絡先・受信拒否の方法）と利用目的を残した。「送信者：」の見出しを外して普通の署名の形にした |

**フォーム（300字以内）**：1行目「商品のご購入（仕入れ）のご相談です。」（法務10 §6 の推奨）→ 名乗りと業態 → 対象 → 個別文 → 「2026年8月開業で販売実績はまだございません。初回は5〜10点・前払いを希望しますが、御社の条件に沿って検討いたします。」→ 依頼 → 利用目的。「希望小売価格を尊重し…お約束」の行を削除。

**電話**：「Amazon.co.jp でネットショップを営んでおります」→「サトイセレクトの佐藤と申します。Amazon.co.jp で国内メーカーの商品を販売する個人事業主です」。「希望小売価格を守って販売いたします」を削除し「御社のお取引条件に沿って検討いたします」に。口頭の約束は記録に残らない分、書面より危うい。

### 2-4. 個別の一文の書き方（型から外れてよい唯一の欄）

07 §6 の決まりは引き続き有効です。今回足したのは下の3つです。

| 決まり | 理由 |
|---|---|
| **価格に触れない**（「価格を守る」「希望小売価格で」「値崩れを防げる」を個別文に書かない） | 共通部分で価格の約束をやめても、個別文に1つ残れば同じ問題になる |
| **相手の扱う品目が「品目ごとに確認して扱う」（食品・化粧品・医薬部外品・電気用品・スプレー等）に当たるときは、本文で「扱えます」と書かない** | 法定表示・出品要件・書類を確認する前に断定しない。/partners の囲みが説明している |
| **「いまは扱わない」（医薬品・酒類・要冷蔵/冷凍食品・中古）に当たる社には送らない**。迷う品（チーズ、薬用の表記など）は注意列に「要確認」と書いて秘書に返す | 自社の公開物と送り先が食い違うと、添付資料を開いた時点で信用を失う |

既存の決まり（要約）：公式ページで読んだ事実を1つ／効能を書かない／販売数などの数字を書かない／2文目は Amazon での売れ方の固定句／流通を絞っている社には「販売店を通じて」を書かない／商品名・ブランド名を繰り返さない。

## 4. 期待する効果（推測）

**事実**：打診はまだ1通も送っておらず、返信率・成約率の実測はありません。以下はすべて推測です。

| 変更 | 期待する効果 |
|---|---|
| 価格の約束をやめた | メーカーの法務・コンプライアンス担当の段階で止められる理由が1つ減る。大手寄りの社ほど効く |
