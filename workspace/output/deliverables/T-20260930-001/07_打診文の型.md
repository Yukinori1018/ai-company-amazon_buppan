## 0. 結論

1. 型は**3種**。メール（本文544字）、フォーム（800字以内の版と300字以内の版）、電話の台本（発信・不在・折り返し受けの3本）。
2. どの型も**「Amazon で売る」「開業したばかりで販売実績はない」を最初の3段落以内に書く**。隠さずに、初回5〜10点・前払い・希望小売価格の尊重とセットで出す。
3. 各社に**1〜2文の個別文**（その会社の商品を知っている証拠）を入れる。本書の型から外れて書き足してよいのはこの欄だけ。

**用語の補足（初出）**

| 用語 | 意味 |
|---|---|
| 卸価格（下代） | メーカーから仕入れる値段 |
| 最低ロット | 1回に注文できる最小の数・金額 |
| 前払い | 注文後に請求書を受け取り、先に振り込む払い方。実績のない相手との取引で最も一般的 |
| 希望小売価格（上代） | メーカーが決めている店頭の目安価格 |
| 卸問屋 | メーカーと小売店の間に立つ卸売業者。直接取引できないメーカーが紹介してくることがある |
| 特定電子メール法 | 広告・宣伝を含むメールの送り方を定めた法律。署名の表示義務がある（§5） |

## 1. 差し込み欄

| 欄 | 中身 | どこから取るか |
|---|---|---|
| 【屋号】【氏名】【住所】【電話番号】【メール】 | 当社の事業者情報 | 会社概要（`T-20260817-006/会社概要_配布用/`。リポには置かない） |
| 〔会社名〕 | 相手の正式社名 | 送信キュー（台帳シート） |
| 〔宛名〕 | 部署が分かれば「〇〇部 ご担当者様」、分からなければ「お取引ご担当者様」 | 公式サイトの窓口名 |

| 〔個別文〕 | その会社だけに書く1〜2文。§6 の決まりに従う | 打診前確認（51） |

## 2. メール版

### 件名

```
【お取引のご相談】〔商品名〕の仕入れについて（【屋号】）
```

### 本文

```
〔会社名〕
〔宛名〕

突然のご連絡を失礼いたします。
Amazon.co.jp で、作り手のはっきりした良い品を選んで扱うネットショップ「【屋号】」を営んでおります、【氏名】と申します。
売り込みではなく、御社の〔商品名〕を仕入れさせていただきたいというご相談です。

〔個別文：1〜2文〕

先に、正直に申し上げます。
販売先は Amazon.co.jp です。また、当店は2026年8月に開業したばかりで、販売実績はまだございません。
ですので、御社にご負担のかからない形でお願いいたします。

・初回は5〜10点ほどの少量で結構です。売れ行きを見て、段階的に増やしてまいります
・お支払いは前払い（銀行振込）で承ります

Amazon で価格が崩れるのは、出品者どうしが値下げを追いかけ合うときです。
当店はこれに加わりません。本業を別に持っており、売り急ぐ必要がないためです。
希望小売価格を尊重し、御社の商品の価値とブランドイメージを下げない売り方をお約束します。
販売を始めましたら、毎月の販売数もご報告いたします。

つきましては、卸価格・最低ロット・お支払い条件・納期をお知らせいただけますでしょうか。
直接のお取引が難しい場合は、お取引のある卸問屋様をご紹介いただけるだけでも大変ありがたく存じます。

会社概要を添付いたします。ご検討のほど、よろしくお願い申し上げます。

〔署名（§5）〕
```

- 添付：会社概要 PDF（A4・2枚）
- 輸入代理店あての差し替え：「御社の〔商品名〕」→「御社が日本で取り扱われている〔ブランド名〕の〔商品名〕」、「御社の商品の価値とブランドイメージ」→「ブランドの価値とイメージ」
- 卸問屋の行は相手の流通に合わせる：正規販売代理店制の社は「正規販売代理店様」、代理店制の社は「お取引のある代理店様」
- 相手が以前に卸先を限っていた記録がある社は、個別文で「現在、新規のお取引をお受けいただけるか」を先に尋ね、依頼文の頭に「お受けいただける場合は、」を付ける

## 3. フォーム版

フォームは名前・会社名・電話・メールの欄が別にあることが多いので、本文欄には**用件と条件だけ**を入れる。会社名欄は「【屋号】（【氏名】）」。

**よく出る必須欄**：Webサイト URL は当社 HP（`https://satoy-select.com/`・2026-08 公開）を入れる。業種・販売方法の選択肢に「ネット通販」が無いときは「その他」を選び、本文で Amazon と書いてあることで補う。電話番号の必須欄は【電話番号】（§7・実値版 §12-2）。

### 3-1. 800字以内の版（署名込み）

```
商品のご購入（仕入れ）のご相談です。売り込み・ご提案ではございません。

Amazon.co.jp でネットショップ「【屋号】」を営んでおります、【氏名】と申します。
御社の〔商品名〕を仕入れさせていただきたく、ご連絡いたしました。

〔個別文：1〜2文〕

販売先は Amazon.co.jp です。2026年8月に開業したばかりで、販売実績はまだございません。
ですので、初回は5〜10点ほどの少量・前払いでお願いし、売れ行きを見て段階的に増やしてまいります。

本業を別に持っており、売り急いで値下げをする必要がありません。
希望小売価格を尊重し、御社の商品の価値とブランドイメージを下げない売り方をお約束します。

卸価格・最低ロット・お支払い条件・納期をお知らせいただけますでしょうか。
直接のお取引が難しい場合は、卸問屋様のご紹介だけでもありがたく存じます。
会社概要はご返信先にすぐお送りいたします。

〔署名（§5）〕
```

### 3-2. 300字以内の版（入力欄が短いとき）

```
商品のご購入（仕入れ）のご相談です。
Amazon.co.jp でネットショップ「【屋号】」を営む【氏名】と申します。
御社の〔商品名〕を仕入れさせていただきたく、ご連絡いたしました。
〔個別文：1文〕
2026年8月開業で販売実績はまだございませんが、初回は5〜10点・前払いで承ります。
希望小売価格を尊重し、御社のブランドを下げない売り方をお約束します。
卸価格・最低ロット・お支払い条件をお知らせいただけますでしょうか。
```

- 300字版には署名も URL も付けない（名前・連絡先は入力欄で渡る）。フォーム送信は特定電子メール法の対象外（法務10 §6）。実例：本文欄が300字以内に制限されたフォームがあった（2026-10-04）。
- **字数制限は改行も1字に数えるフォームが多い。** 実値を入れた後に必ず数え直す（20社分は送信用シートの「文字数」列で計測済み）。

## 4. 電話の台本

> 電話は**成約率がメールの3〜5倍**（原典 Ch6-03：電話は10社に1社、メールは30〜50社に1社）。HP やフォームがないメーカーは他のセラーが素通りするので、電話の価値が高い。
>
> **使う場面は3つ**：①窓口が電話しかない社（今回の20社では1社。メールが購入者向けしか無い社も含む）、②メール・フォームに**1週間返信がない社への追いかけ**（「メール返信がない場合に可否がすぐ分かる」原典 Ch6-03）、③相手からかかってきたとき（T3）。

### 4-0. かける前に（3分）

- 手元に置くもの：相手の商品ページ（Amazon と公式の両方）、会社概要、メモ用紙、送信用シートのその社の行
- 時間帯：平日の 10:00〜11:30 か 14:00〜16:30。昼休み・月曜の朝・金曜の夕方は避ける
- 番号：【要確認】発信に使う番号（§7 の表「電話番号」の行）。**非通知（184）ではかけない**。非通知は出てもらえず、怪しまれる
- **その場で数量・金額を約束しない。**聞かれたら「検討して、こちらから折り返します」でよい（原典 Ch7-02）

### T1. 発信（初回）

**① 受付**

> お忙しいところ恐れ入ります。わたくし、Amazon でネットショップを営んでおります【屋号】の【氏名】と申します。
> 御社の〔商品名〕を仕入れさせていただきたく、お電話いたしました。
> お取引のご担当の方はいらっしゃいますでしょうか。

| 受付の返事 | 返し |
|---|---|
| 「営業ですか？」 | 「いえ、こちらが御社の商品を買わせていただきたいというご相談です」 |
| 「どういったご用件ですか？」 | 「御社の〔商品名〕を、当店で仕入れて販売させていただけないかというご相談です」 |
| 「担当は不在です」 | → T2 |
| 「メールで送ってください」 | 「承知しました。お送り先のアドレスと、ご担当の方のお名前を伺えますか」→ メール版で送り、件名に「お電話でご案内いただいた件」と足す |

**② 担当者に替わったら（20秒で用件まで）**

> お忙しいところありがとうございます。【屋号】の【氏名】と申します。
> 御社の〔商品名〕を、Amazon.co.jp の当店で販売させていただきたく、仕入れのご相談でお電話しました。
> 〔個別文を口語で1文〕
> 2、3分ほどお時間をいただいてもよろしいでしょうか。

**③ 正直に先に言う**

> 先に申し上げますと、販売先は Amazon です。それから、8月に開業したばかりで、まだ販売実績はございません。
> ですので、初回は5〜10点ほどの少量で、お支払いは前払いでお願いできればと考えております。
> 希望小売価格を守って、御社のブランドを下げない売り方をお約束します。

**④ 聞く**

> もしお取引いただけるようでしたら、卸価格と、最低ロット、お支払いの条件を教えていただけますでしょうか。
> 詳しい資料はメールでお送りしますので、お送り先も伺えますと助かります。

**⑤ よく聞かれること**（原典 Ch7-02。**正直に答える。詰まるほうが印象が悪い**）

| 聞かれること | 答え方 |
|---|---|
| ウチの商品をどうやって知った？ | 「Amazon で拝見しました。〔個別文の中身〕と感じ、お電話しました」 |
| 販路は？ | 「Amazon.co.jp の当店だけです。他のモールやフリマアプリには出しません」 |
| どんな商品を扱っている？ | 「日用品や生活雑貨を中心に、作り手のはっきりした品を選んで扱っております」 |
| 売上規模・事業年数・従業員数は？ | 「8月に開業したばかりで、まだ売上と呼べるものはございません。私一人でやっております。そのぶん、御社の商品を丁寧に扱います」 |
| 何個買う？ | 「最初は5〜10点ほどで売れ行きを見て、段階的に増やしたいと考えております。最低ロットがございましたら教えていただけますか」 |
| Amazon で値崩れしたら何をしてくれる？ | 「当店は値下げの追いかけ合いに加わりません。希望小売価格を守ります。詳しくはご関心があればご説明します」（**聞かれてから話す。一方的に説明しない**＝原典 Ch7-03） |
| 会社概要と販売ページの URL を送って | 「承知しました。本日中にメールでお送りします」 |
| 一度お会いしたい | 「ありがとうございます。差し支えなければ、先にお見積りか掛け率だけでも頂戴できますか」（原典 Ch7-03） |

**⑥ 断られたとき — まず理由を聞く**

> 承知しました。差し支えなければ、理由を伺ってもよろしいでしょうか。今後の参考にさせていただきます。

| 理由 | 返し（1回だけ。2回目は押さない） |
|---|---|
| Amazon・ネット販売はしていない | 「価格が崩れることへのご心配でしょうか。それとも、もう販売される方を決めておられるのでしょうか」→ 前者なら「当店は値下げの追いかけ合いに加わらず、希望小売価格を守ります。一度、資料だけでもお送りしてよろしいでしょうか」／後者なら引く |
| 実店舗がないと取引しない | 「承知しました。Amazon でも価格を守って売る方法がございますので、もしご方針が変わることがあれば、またご相談させてください」で引く |
| 新規の取引先は募集していない | 「一時的なものでしょうか。時期を改めてご連絡してもよろしければ、目安を伺えますか」 |
| 法人でないと取引しない | 「承知しました。法人化した際に、あらためてご相談させてください」で引く |
| 卸問屋を通してほしい | 「ありがとうございます。お取引のある卸問屋様を教えていただけますか」→ 社名・連絡先をメモ（**これは前進**。§3.5「紹介先で続ける」） |

> 断られても、理由が聞けたら成果です。**一度断るメーカーはライバルが少ない**（断られるとすぐ引く人が多いため。原典 Ch7-04）。

**⑦ 終わり方**

> お時間をいただきありがとうございました。本日中に、会社概要をメールでお送りします。〔担当者名〕様あてでよろしいでしょうか。

通話後：送信用シートの「接触ステータス」「接触日」「メモ」に、担当者名・聞けた条件・断られた理由を書く。

### T2. 担当者が不在のとき

> 承知しました。何時ごろお戻りでしょうか。
> （または）では、メールでご案内をお送りしたいので、お送り先と、ご担当の方のお名前を伺えますか。

**留守番電話の場合**

> 【屋号】の【氏名】と申します。御社の〔商品名〕の仕入れについてご相談したく、お電話いたしました。あらためてお電話いたします。失礼いたします。

（**折り返しを求めない。**こちらの都合で時間を使わせないため）

### T3. 相手から電話がかかってきたとき

- **すぐ出なくてよい。**どのメーカーか分からないまま出ると質問に答えられない（原典 Ch7-02）。着信番号を送信用シートで検索し、その行を開いてからかけ直す
- かけ直しの第一声：「先ほどお電話をいただいた、【屋号】の【氏名】です。〔商品名〕の件でご連絡いただいたかと存じます」
- 以降は T1 の ④〜⑦

### 4-4. FAX（1枚・送れる手段ができたとき用）

原典 Ch6-03：国内メーカーは FAX をまだ使っているところが多く、**メールに反応しなくても FAX に反応する**場合がある。当社は FAX 未保有（ネット FAX は導入予定）なので、文面だけ先に用意しておく。

```
〔会社名〕
〔宛名〕
FAX送信：【屋号】（【氏名】）　全1枚

商品の仕入れのご相談

突然のFAXを失礼いたします。
Amazon.co.jp でネットショップ「【屋号】」を営んでおります、【氏名】と申します。
御社の〔商品名〕を仕入れさせていただきたく、ご連絡いたしました。

〔個別文：1文〕

販売先は Amazon.co.jp です。2026年8月に開業したばかりで、販売実績はまだございません。
初回は5〜10点ほどの少量・前払いでお願いし、希望小売価格を尊重して販売いたします。

卸価格・最低ロット・お支払い条件をお知らせいただけましたら幸いです。
ご返信は下記のメールへお願いいたします。

送信者：【屋号】（【氏名】）／【住所】
電話：【電話番号】　メール：【メール】
今後このご案内が不要な場合は、上記メールで「不要」とお知らせください。以後お送りいたしません。
```

- 末尾3行は法務10 §6 の FAX 自主表示（当社に FAX 番号が無いので、拒否の連絡先はメールだけにした）
- 1枚に収めるため、メール版の「価格が崩れる仕組み」「毎月の販売数の報告」「卸問屋の紹介」は削った。返信が来てから伝える

## 5. 署名（メール・800字フォーム）

法務10 §6 の確定版。**メールでは1行も削らない**（特定電子メール法4条の表示義務）。

```
――――――――――――――――
送信者：【屋号】（【氏名】）
住所：【住所】
電話：【電話番号】
メール：【メール】
取引先向けのご案内：https://satoy-select.com/partners
今後このようなご連絡が不要な場合は、本メールに「不要」とご返信ください。以後お送りいたしません。
いただいたご担当者様のお名前・ご連絡先は、本件のお取引のご相談にのみ使用いたします。
――――――――――――――――
```

- 載せる URL は `/partners` の1本だけ（法務10 §6）
- 電話番号が決まるまでは「電話」の行を削ってよい（メール行で表示義務は満たせる）

## 6. 個別文の書き方（型から外れてよい唯一の欄）

原典 Ch6-02：**テンプレの丸写しはダメ。**同じ定型文が何人もの出品者から届けば、メーカーは嫌がる。

| 決まり | 理由 |
|---|---|
| **その会社の公式ページで読んだ事実を1つ入れる**（事業内容・窓口名・製法・ブランドの来歴など） | 「御社のことを調べてから連絡している」が伝わる。Amazon の商品名だけでは誰でも書ける |
| **効能・効果を書かない**（健康食品・化粧品は特に） | 「〜に効く」は薬機法上、売り手が言ってはいけない表現。メーカーの担当者はそこを見ている |
| 「どこで知ったか」を半句入れる（「Amazon で拝見し」） | 電話で必ず聞かれる質問（原典 Ch7-02）を先に消す |

## 9. なぜこの表現にしたか

| 表現 | 理由 |
|---|---|
| 「作り手のはっきりした良い品を選んで扱う」店 | 原典の観点1（想い）。サイトの「ごあいさつ」の選定基準をそのまま1句にした。**相手のメーカーが「選ばれた側」に入る**言い方で、別段落の想いの文より短い |
| 「先に、正直に申し上げます」から Amazon と実績ゼロを続けて言う | 原典 Ch6-02「Amazon 販売であることを正直に伝える。偽ると後の限定化の交渉ができない」。2つの不利を**同じ段落にまとめて一度で言い切る**ほうが、小出しにするより誠実に読める |
| 初回「5〜10点ほど」 | §3.5 のテスト仕入れの量。旧文面（14）の「10点程度」から変えた。「段階的に増やしてまいります」は原典 Ch7-02 の定型（「売上を見ながら購入数量を段階的に増やしたい」） |
| 「Amazon で価格が崩れるのは、出品者どうしが値下げを追いかけ合うときです。当店はこれに加わりません」 | 原典の観点「Amazon の仕組みを分かっている」を**1文だけ**示す。詳しい説明は相手が聞いてきてから（Ch7-03） |
| 「本業を別に持っており、売り急ぐ必要がないためです」 | 原典の観点5（自分の強み）。職業名ではなく**「だから値下げしない」という因果**で書く。職業名は電話で聞かれたら答えればよい |
| 「希望小売価格を尊重し」（「ご指定に従います」としない） | 販売価格をメーカーが指定することは独占禁止法の論点（法務10 §5）。こちらから指定を求める書き方を避けた |
| 「毎月の販売数もご報告いたします」 | 原典の観点3（提供できること）。卸先から返ってこない「売れ方」のデータは、実績ゼロでも約束できる数少ない利益 |
| 「卸問屋様をご紹介いただけるだけでも」 | 原典 Ch7-01「卸問屋・代理店経由でも利益の出る商品は充分ある」。相手に**断る以外の返事の選択肢**を渡す。§3.5「紹介先で続ける」とも一致 |
| 独占・限定の語を書かない | 原典 Ch9-04：限定化は信頼ができてから。初回に書けば売り込みになる |
