# 41 採算列の計算式（メーカー連絡先台帳）

T-20260930-001 / 経理ハジメ / 2026-10-04

**目的**：メーカーに電話・メールする前に「いくらで卸してもらえれば儲かるか」を1行で読めるようにする。
計算は代表ASIN単位。スクリプトは同フォルダ `40_profit_cols.py`、出力は `agent_output/T-20260930-001/40_採算列.csv`（Keepa の値を含むのでリポ外）。

---

## 1. 列と式

すべて 1個あたり・円・**消費税込み**。P＝平時売価。

| # | 列 | 式 | 出典 |
|---|---|---|---|
| 1 | 平時売価 P | 直近90日のカート価格の平均。無ければ新品最安の90日平均。**現在価格は使わない** | 〔Keepa実測〕 |
| 2a | 販売手数料率 | Keepa の率を公式の段（5.0/8.4/10.4/12.4/15.4%）に寄せる。価格で段が変わるカテゴリ（ビューティー・ドラッグ・食品・ペット・ベビー）は P で引き直し、**高い方**を採る。P≦750円は一律5% | 〔Keepa実測〕＋〔公式〕 |
| 2b | 販売手数料（円） | max(P × 率, 30円) × 1.1（率は税抜表示のため） | 〔公式〕 |
| 2c | FBA配送代行 | Keepa の `pickAndPackFee` から公式表のサイズ区分を逆引きし、P が1,000円以下か超かで列を選び直す | 〔Keepa実測〕＋〔公式〕 |
| — | 保管料 | パッケージ実寸の体積 × 10.087円/1,000cm³/月（10〜12月単価）× 計上月数（＝消化月数÷2） | 〔公式〕＋〔実寸〕 |
| 3 | 納品・その他 | §2 の置き値 | 〔推定〕 |
| — | Amazon側コスト計 C | 2b ＋ 2c ＋ 保管料 ＋ 納品・その他 | |
| 4 | 上限（利益率20%） | **P × 0.80 − C**。これ以下の原価なら会社KPIの20%を取れる | |
| 5 | 上限（利益率10%） | **P × 0.90 − C**。初回の妥協ライン（中村本：初回は5〜8%でも可。安全側に10%で置いた） | |
| 6 | 損益分岐 | **P − C**。これを超えると1個売るごとに赤字 | |
| 7 | 20%が取れる掛け（目標） | 列4 ÷ P。「この掛け以下なら20%」と読む | |
| 8 | 想定月販 | 月販下限 ÷（新品出品者数＋1） | 実画面（無ければ Keepa） |
| 9 | 想定月利益 | 想定月販 × P × 0.20（20%で仕入れられた場合） | |
| 10 | 初回仕入れ | 個数＝max(5, 想定月販の1ヶ月分・切り上げ)、金額＝個数 × 4 | |
| 11 | 価格の安定 | 現在価格 ÷ P。0.95未満＝値下がり中、1.05超＝値上がり中 | 〔Keepa実測〕 |
| 12 | 採算メモ | 掛けの判定／単価2,200円未満／値下がり中／取り分が月5個未満／料率補正の有無 | |

- **月販の下限**：実画面の「過去1か月で◯点以上購入」の階級の下限値（100点以上→100）。保守側。
- **新品出品者数**：実画面で数えた数。実画面が「未確認」の36行は Keepa の新品出品数で代用（出典列に明記）。

### 計算例（架空の数字）

P＝5,000円・料率10.4%・FBA標準7（472円）・保管料50円・納品その他150円 の場合

| 項目 | 金額 |
|---|---|
| 販売手数料 5,000 × 10.4% × 1.1 | 572円 |
| Amazon側コスト計 C | 1,244円 |
| 利益率20%の上限 4,000 − 1,244 | 2,756円（5.5掛け） |
| 利益率10%の上限 4,500 − 1,244 | 3,256円 |
| 損益分岐 5,000 − 1,244 | 3,756円 |

## 2. 置き値と根拠

| 費目 | 置き値 | 根拠 | 確度 |
|---|---|---|---|
| FC納品送料 | 1箱608円 ÷ 1箱に入る個数 | FBAパートナーキャリア ヤマト140サイズ（関東→関東）。個数＝min(初回個数, 140サイズに容積70%で入る数) | 〔実測〕送料・〔仮定〕充填率 |
| 段ボール | 1箱250円 ÷ 同上 | 公式値なし | 〔推定〕 |
| 袋など | 4.5円 | OPP袋＋α | 〔推定〕 |
| ラベル | 22円（大型51円） | Amazon 商品ラベル貼付サービス | 〔公式〕 |
| **納品・その他の下限** | **100円** | 上4つの合計が100円を下回っても100円で置く。初回は社長宅から少数の箱で送る（§3.4）ため薄まりにくい | 〔推定〕 |
| 保管料の単価 | 10〜12月の10.087円 | 初回在庫は年内に置かれるため繁忙期単価。1〜9月は5.676円（約0.56倍） | 〔公式〕 |
| 計上月数 | 初回個数 ÷ 想定月販 ÷ 2 | 公式式「保管日数÷当月日数」の平均在庫。月販不明は3ヶ月 | 〔公式〕＋〔仮定〕 |

結果として、納品・その他は199行中107行が下限の100円、最大は大型品で約910円（140サイズに1個しか入らない扱い）。

## 3. 税の扱い

- 当社は**免税事業者**（セラーセントラル「消費税の設定」＝納税義務いいえ・2026-09-09 確認）。仕入れにかかった消費税は控除できない。
- したがって上限は**消費税込みの支払額**で持つ。メーカーの見積りは通常税抜なので、20%の列だけ **税抜換算（÷1.1）** も並べた。見積りと比べるときは税抜換算の列を使う。
- 上限は**着値**（メーカーから社長宅までの送料を含む）として読む。送料が別途なら、その分を差し引いて比べる。
- 税務の個別判断は税理士確認を推奨。

## 4. 読み方の注意

1. **列7の掛けは「Amazon の実売価格」に対する比率。**メーカーが言う掛け率は希望小売価格に対する比率。実売が希望小売価格より安い商品では、メーカー基準の掛けはさらに低く必要になる。
2. 199行の中央値は5.7掛け（20%が取れる掛け）。**6掛けで20%が取れるのは55行（28%）。**メーカー卸の相場（6〜7掛け）では、大半が5掛け台の交渉になる。これは既知の結論（「6掛けでは20%は不可能」）と整合する。
3. 初回仕入れ金額は「想定月販の1ヶ月分」なので、売れ筋の行は1社で数十万〜約100万円になる。**資金100万円の範囲に収まるかは、行ごとではなく合計で見ること。**最初の数社は最小5個から入るのが現実的。
4. 想定月利益の合計は、全社が20%で卸してくれた場合の上限であり、見込みではない。

## 5. 既知の甘さ（入れていないもの）

| 入れていないもの | 向き | 影響の目安 |
|---|---|---|
| 返品・返金 | 甘い | 返品1件で FBA配送代行は戻らない＋返金手数料。再販不可なら原価が丸損 |
| 広告費 | 甘い | 新規出品でカートを取るまで広告が要る場合、売価の5〜15%（推定） |
| 値下がり | 甘い | 参入で価格が下がる。16行は既に値下がり中（現在価格で再計算が要る） |
| 大口出品の月額 | 甘い | 4,900円/月（税抜）。SKU単位では入れず、月次の損益で引く |
| 長期保管・廃棄 | 甘い | 売れ残りは月20円/点（365日超）＋廃棄手数料 |
| 社長宅までの送料 | 甘い | 上限を着値として読むことで吸収（§3） |
| カート価格の取得 | — | 199行すべてカート価格の90日平均が取れた（新品最安への代用は0行） |
| FBA区分 | — | 198行は公式表に逆引きできた。1行は表に無い額のため Keepa の額をそのまま使用 |

**この欄の数字は「交渉の上限」であり、発注の可否ではない。**発注前には CLAUDE.md §3.3 の確認（カート保持者・本体の在庫履歴・出品一覧の実数）と §3.5 のチェックを別途通す。
