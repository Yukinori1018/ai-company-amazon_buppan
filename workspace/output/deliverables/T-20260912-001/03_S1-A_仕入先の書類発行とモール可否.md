# S1-A：ゲートで止まった12件の仕入先は、書類を出すか・Amazon販売を認めているか

T-20260912-001 / リサーチャー サトル / 調査日 2026-09-12（全ページの取得日も同日）

## 結論

1. **ゲート解除の申請に使えそうだと公開情報で言えるサプライヤーは、8社中0社です。**独自の請求書（住所・請求書番号・宛名を指定できるもの）を出すと書いた社はありません。書類に触れていた5社は、どこも「マイページ／注文履歴から自分で出してください」と書いており、NETSEA 標準の PDF を案内しています。オリヒロは「弊社発行の請求書は対応しておりません」と明記しています。**だから S1 の未確認点（卸の住所・宛名の住所・請求書番号が載るか）は、12件すべてで NETSEA 標準 PDF の実物を見ないと決まりません。**サプライヤー側で補える見込みは、公開ページからは立ちません。
2. **Amazon 販売を名指しで禁じているのは2件です。ドクターランドリー（ピンク・ブルー）の商品ページに「Amazon販売NG」とあります。**この2件は A の候補から外れます（事実）。残る10件はどれも「ネット販売：可」の表示です。ただし「可」は NETSEA の汎用フラグです。Amazon を明示的に許可したものではありません。
3. 付随して分かったこと：超立体マスクの仕入先「Drop-カネイシ」は**顧客直送専門のアカウント**で、直送以外の注文は別アカウント（カネイシ株式会社）へ回すよう書いています。FBA 納品向けの仕入れには使えない窓口です（事実）。この商品は Amazon 側でも申請受付が停止中です（T-20260909-002 のログ）。

## スコープと打ち切り

- 対象：12件の仕入先8社（ウェルフェア4件・オリヒロ2件・その他6社は1件ずつ）。ASIN と仕入先の対応は `T-20260909-002/out/04_回転ふるい_全件.csv`、supplier_id は `T-20260831-006/out/suppliers.csv` で確認。
- 読んだページ：1社につき3種類、計28ページ。ショップの商品一覧 `/shop/<id>`、会社情報 `/company/<id>`、該当商品の商品ページ `/shop/<id>/<商品>`（12件）。**すべて非ログインで取得**。
- 読めなかったもの：会社情報のうち「会社名・所在地・電話番号・登録番号・取引条件（一部の社）」は**会員のみ公開**です。ログインが必要なので読んでいません。
- 問い合わせ・連絡は一切していません（§4.1／バイヤー会員規約7条2項5号）。卸値は書いていません。

## 事実と推測

- **事実**
  - 独自の請求書を出すと書いた社は0社。「出さない」と明記したのは2社（オリヒロ・アイオロス）。
  - Amazon 販売NGの明記は2件（ドクターランドリー2色）。
  - ウェルフェアは販路制限の判断をメーカーに委ねている。
  - Drop-カネイシは直送専門。
- **推測（確度：中）**
  - 12件の書類はすべて NETSEA 標準 PDF 1種類に帰着する。だから「使えるか」は 12件共通で、PDF の実物1枚で一括して決まる。根拠は、書類に触れた5社がすべてマイページ・注文履歴からの出力を案内していること。
- **推測（確度：低）**
  - ウェルフェアの ELEKI・メディキュットにも、メーカー側に販路制限があるかもしれない。根拠は、同じ社のドクターランドリーに Amazon NG が付いていること。**書かれていない以上、制限ありとは扱えません。**
- **分からないこと（公開情報では）**
  - NETSEA 標準 PDF に卸の住所・宛名の住所・請求書番号が載るか。
  - オリヒロ・プレザントの「ネットオークション×」が Amazon を含むか。NETSEA がこの2フラグをどう定義しているかは、今回読んでいません（未調査）。

## ここから先はタケシ（プランナー）の領分です

- A の候補は、12件から Amazon NG の2件と直送専門・受付停止の超立体マスクを除くと**9件**になります（事実ベースの引き算）。どれに絞るか、PDF を確かめる手段（少額の試し買い＝§4.1／NETSEA への問い合わせ＝§4.1）を取るかは戦略判断です。
