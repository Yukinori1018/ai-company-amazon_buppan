# S1：NETSEA の請求書は Amazon のゲート解除要件を満たすか

T-20260912-001 / リサーチャー サトル / 調査日 2026-09-12

## イシュー

NETSEA で買ったときに出る書類は、Amazon のゲート解除の4要件を記載として満たすか。4要件は「卸の名称・住所」「出品者の氏名・住所」「180日以内」「10点以上」。

## 結論（3行）

1. **発行者はサプライヤー（出店企業）です。NETSEA 運営ではありません。**PDF はマイページから出せます（事実）。
2. **4要件のうち公式に確認できたのは「卸の名称（法人名）」だけです。**「卸の住所」「宛名に出品者の住所が入るか」「請求書番号」は公式ページに記載がありません（未確認）。**当社に NETSEA の購入実績がなく、実物の PDF で確かめられません。**
3. 事例は通過・却下の両方があります。**「ネット卸の請求書は通りにくい」が2025〜2026年の実務側の一致した見方**です。確実性の序列は memory の整理どおり「メーカー／正規卸 ＞ ネット卸」のままです。

## 1. NETSEA の書類に何が載るか

| 項目 | 状態 | 内容 | 出典 |
|---|---|---|---|
| 書類の種類 | 事実 | 「納品書」「請求書」「領収書」の3種。加えて「請求書（インボイス制度対応）」 | [A][B] |
| 発行のタイミング | 事実 | 「注文した商品が出荷確定されましたら」印刷可 | [A] |
| PDF | 事実 | 「PDFをダウンロードして印刷を行います」 | [A] |
| 発行者 | 事実（根拠2つ） | サプライヤー。①規約16条1項「当社は売買契約等の当事者にはなりません」。②「登録番号をサプライヤーが入力していない場合は、登録番号は表示されません」 | [A][C] |
| 発行者名の表記 | 事実 | 2015年から「商号(店舗名)」ではなく「法人名」で表示 | [D] |
| 発行者の住所 | **未確認** | 公式ページに記載なし | — |
| 宛名（出品者の氏名） | 一部事実 | バイヤー名も「法人名」表示に統一（2015）。**個人事業主の場合に屋号と氏名のどちらが出るかは記載なし** | [D] |
| 宛名（出品者の住所） | **未確認** | 記載なし。直送時の納品書は「送付先の住所は消費者、連絡先はバイヤー」になる（＝パターン3は宛先がバイヤーでなくなる） | [A] |
| 点数 | 事実 | 「商品欄には、商品名と内訳が一緒に表示されます」 | [A] |
| 請求書番号 | **未確認** | 記載なし。**請求書番号が無いことを理由に却下された事例あり（§2 #1）** | [E] |
| 価格の表示 | 事実 | 住所変更した注文の納品書（パターン2・3）は「価格の表記はありません」。Amazon 側も価格は省略可 | [A] |
| 項目の追加・変更 | 事実 | 「項目の追加や変更は行えません」「書式や項目の変更が必要な場合は、各サプライヤーへご相談ください。書類発行を行っていない場合もございます」 | [A] |
| 掛け払いの場合 | 事実 | 請求（払込票）の発行者は **GMOペイメントサービス**。明細は NETSEA の注文履歴で確認する方式。**卸の請求書としては使えない**と見るべき（推測・確度高） | [F] |

**推測（確度：中）**：発行者名は法人名で出るので、「卸の名称」は満たせます。住所・請求書番号は、サプライヤーの登録内容しだいで出たり出なかったりする可能性があります。根拠は、登録番号が「サプライヤーが入力していない場合は表示されない」仕様であることです。住所も同じくサプライヤーの登録に依存する作りだと見ています。

**分かりようがないこと（公開情報では）**：実際の PDF のレイアウト。これは実物を1枚見れば確定します。

## 3. 通らない場合によく使われる代替

| 代替 | 内容 | 当社での注意 | 出典 |
|---|---|---|---|
| サプライヤーに書類を発行してもらう | NETSEA 公式が「書式や項目の変更が必要な場合は、各サプライヤーへ」と案内している | **NETSEA の問い合わせ機能を通すこと。**規約7条2項5号は「当社が提供する機能以外の方法」でサプライヤーと連絡することを禁止している。19条3項（NETSEA外での売買契約の禁止）、27条（違約金200万円＋代金50%）もある。**NETSEA 外で直接頼むと規約違反**。解釈の確認は法務ハルオ | [A][C] |
| メーカー／一次卸から直接仕入れる | 確実性の序列の最上位。ecstarslab も「メーカーや一次問屋との直接取引が確実」と書いている | 本丸（B）の筋と同じ | [J] |
| 地元の実店舗の問屋 | 解除できない場合の代替として紹介されている | 未調査（本件の範囲外） | [I] |
| ワンクリック解除 | 書類不要で即時。在庫ゼロでも押せる | 申請の送信に当たるため §4.1 扱い（T-20260912-001 の社長判断待ち） | memory |
| 家電量販店・Amazon本体の請求書 | 宛名入りで通った実績あり。Amazon本体は2025-07から50点以上 | 本件の12件には該当しない可能性が高い（推測） | memory |

## 4. 事実と推測の区別（まとめ）

- **事実**：
  - 発行者はサプライヤーで、法人名で表示される。
  - PDF は出荷確定後に出せる。
  - 書類に項目を足すことはできない。
  - 掛け払いの請求は GMO が発行する。
  - サプライヤーとは NETSEA の機能を通してしか連絡できない。
- **未確認**：卸の住所、出品者の住所、請求書番号が載るか。
- **推測（確度：中）**：4要件のうち2つ（住所）と請求書番号は、サプライヤーしだいで欠ける可能性があります。欠けたときの手段は、NETSEA の問い合わせ機能を通じてサプライヤーに書類を出してもらうことになります。

## 5. 確度を上げる最短の手（ここから先はカズヨ／タケシの判断）

- **サンプル PDF を1枚見る**：NETSEA マイページで出せる書類のレイアウトを確かめたい。ただし購入実績ゼロのため、既存の注文からは出せません。「購入前に書類見本を見られるか」は NETSEA サポートへの問い合わせになり、第三者連絡として §4.1 に当たります。
- **A の候補のサプライヤーページを見る（0円・社内作業）**：12件の仕入れ元サプライヤーのページに「書類発行」の記載があるか確かめる。NETSEA 公式も「書類発行を行っていない場合もございますので、事前にお確かめ」と書いています。
- A の承認率の前提値は、叩き台の「中央60%」です。**それを支える一次情報は今回見つかっていません**。数値の置き直しはタケシの領分です。
