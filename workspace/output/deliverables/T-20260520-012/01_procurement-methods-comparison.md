# 01. 仕入れ“方法”12分類 比較表

> イシュー: 仕入れ方法は何種類あり、各々の「初期投資・必要スキル・規制リスク」はどう違うか
> 担当: サトル / 2026-05-25 / 一次情報＋WebSearch 確認

**読み方**: 評価軸を縦（12方法）、判断材料を横に取った比較表です。空白は作らず「該当なし」「未調査」を区別。
規制リスクは **🟥赤=初心者は原則回避 / 🟨黄=条件付き可（要許可・要確認）/ 🟩緑=リスク小** の3段階で警告レベルを明示しました（深い法務判断はハルオに引き継ぐ前提の "信号" です）。

---

## A. 全体一覧表（12分類）

| # | 仕入れ方法 | 初期投資（仕入原資除く） | 必要スキル | リードタイム | 規制リスク信号 | 一言で |
|---|---|---|---|---|---|---|
| 1 | **電脳せどり**（ネット仕入れ） | ほぼ0〜（リサーチツール月3千円程度） | リサーチ力・相場感 | 1〜5日 | 🟨 | 在宅完結。新品の出所証明に注意 |
| 2 | **店舗せどり**（実店舗仕入れ） | 交通費＋アプリ月3千円程度 | 目利き・体力・時間 | 即日 | 🟨 | 実物確認できる。地域差・時間が壁 |
| 3 | **メルカリ仕入れ** | ほぼ0 | 相場感・通知速度 | 3〜7日 | 🟥 | **2025/10規約で個人仕入れ禁止・Amazon新品出品も不可** |
| 4 | **ヤフオク仕入れ** | ほぼ0 | 入札判断・相場感 | 5〜10日 | 🟥 | 中古は古物商必須・新品再販はAmazon規約NG |
| 5 | **不要品販売**（自宅の私物） | 0 | なし | 即日 | 🟩 | **唯一ほぼ無リスク。古物商も商標も不要** |
| 6 | **メーカー直取引**（国内卸の上流） | 0〜（名刺・場合により法人格） | 営業力・交渉力 | 2〜14日 | 🟨 | 利益安定。初心者には開拓ハードル高 |
| 7 | **卸サイト**（NETSEA・SDeli等） | 0〜月2千円（SDeli買い手側） | 会員登録のみ | 2〜7日 | 🟩〜🟨 | 在宅完結の王道。新品の出所が明確 |
| 8 | **中国輸入**（1688・タオバオ） | 代行業者登録（月0円業者あり） | 中国語/代行活用・検品 | 14〜30日 | 🟥 | 商標・PSE・技適・関税リスク高 |
| 9 | **韓国輸入**（Qoo10・現地卸） | 0〜（個人輸入可） | 韓国語/代行・薬機/表示確認 | 7〜21日 | 🟥 | コスメ・アパレル人気だが薬機法・表示の壁 |
| 10 | **OEM/ODM**（自社ブランド製造） | 数十万〜（金型・MOQ・ロゴ） | 商品企画・資金・在庫管理 | 30〜60日 | 🟥 | 上級者向け。10万円では原則不可 |
| 11 | **クラファン後続/在庫処分** | 0〜（メーカー個別交渉） | 営業力・目利き | 7〜30日 | 🟨 | 独占販売の入口だが交渉前提 |
| 12 | **その他**（展示会・問屋街・ebay等） | 交通費/年会費 | 方法ごとに異なる | 即日〜21日 | 🟨 | 軸B後の "次の一手" カテゴリ |

## B. 方法ごとの詳細（メリット/デメリット/規制リスク）

### 1. 電脳せどり（ネットで安く仕入れ→Amazonで売る）

| 項目 | 内容 |
|---|---|
| メリット | 在宅完結・地域差なし・隙間時間でリサーチ可・体力不要・リピート仕入れしやすい（出典: ひこーる, ERESA） |
| デメリット | 実物を見ないため不良品リスク・送料が必ず発生し利益計算が複雑・市場飽和で利益率低下 |
| 初期投資 | ほぼ0。リサーチツール（Keepa等 月¥約3千、社内T-003評価済）推奨。仕入れは都度払い |
| 必要スキル | 価格相場のリサーチ力、Keepaグラフ読解、送料込みの損益計算 |
| 規制リスク 🟨 | **「どこで仕入れるか」次第**。量販店・卸の新品なら出所明確で低リスク。フリマ仕入れだと後述#3の問題に直結 |

### 2. 店舗せどり（ドンキ・量販店・アウトレット等を歩く）

| 項目 | 内容 |
|---|---|
| メリット | 実物を見て判断できる・叩き売り品に出会える・出品までのタイムラグが少ない・商品知識ゼロでも棚を片端からリサーチすれば始めやすい（出典: ERESA, j-pug） |
| デメリット | 地域差が致命的・移動と滞在に時間がかかり隙間時間に不向き・体力消耗 |
| 初期投資 | 交通費＋店舗リサーチアプリ（アマサーチ等 月¥約3千） |
| 必要スキル | 目利き、店舗を回る体力と時間、アプリ操作 |
| 規制リスク 🟨 | 店舗購入の新品は **「メーカー正規代理店と同等の保証」が付かない場合 Amazon で新品出品不可**（出典: Amazonコンディションガイドライン）。領収書保管必須 |

### 3. メルカリ仕入れ 🟥【重要・規約変更あり】

| 項目 | 内容 |
|---|---|
| メリット | （従来）スマホ完結で手軽・1点から・全ジャンル |
| デメリット / 規制 | **2025年10月のメルカリ規約変更**で、せどり・転売など不用品販売を目的としない事業者は個人アカウントを利用できなくなった。せどり用途は「メルカリShops」利用が必須に（出典: EC STARs Lab.）。さらに **Amazon側でも、個人から仕入れた商品は新品未開封でも「新品」として出品不可**（出典: Amazonコンディションガイドライン） |
| 初期投資 | ほぼ0 |
| 規制リスク 🟥 | **方法軸では赤信号**。「中古を古物商ありで仕入れ→中古として出品」なら一応道はあるが、初心者の新品せどりルートとしては実質クローズ |

> ※マリエの suppliers-list ではメルカリ初心者向き8/10だが、本書の「仕入れ"方法"」評価では赤信号。これは "仕入れ先としての使いやすさ" と "Amazon転売の仕入れ方法としての可否" を分けた結果。差分の核心。

### 4. ヤフオク仕入れ 🟥

| 項目 | 内容 |
|---|---|
| メリット | 中古・廃番に強い・オークションの波を掴めば安い |
| デメリット | 落札の不確実性・5〜10日のリードタイム |
| 規制リスク 🟥 | 継続的に中古を仕入れ→販売するなら **古物商許可必須**（無許可は3年以下拘禁刑or100万円以下罰金、出典: EC STARs Lab.）。新品再販はメルカリ同様Amazon規約上NG |

### 5. 不要品販売（自宅の私物を売る）🟩【最低リスク】

| 項目 | 内容 |
|---|---|
| メリット | **規制リスクが構造的に最小**。自分の私物の処分は古物営業に当たらず古物商不要。商標・真贋問題も発生しない。原資ゼロで出品〜入金フローを体験できる |
| デメリット | 在庫が自宅にある分しかない（事業としてはスケールしない）・利益目的ではない |
| 初期投資 | 0 |
| 規制リスク 🟩 | ほぼなし（自己所有物の売却のため）。**軸B "1サイクル回す体験" の目的に対しては最適解の一つ** |

### 6. メーカー直取引（国内メーカー・正規問屋の上流）

| 項目 | 内容 |
|---|---|
| メリット | 中間マージン排除で利益率向上・正規仕入れで真贋問題なし・リピート安定 |
| デメリット | 審査・実績・場合により法人格や古物商を求められる・営業力必須 |
| 初期投資 | 0〜（名刺、初回ロット5〜30万円のケースあり） |
| 規制リスク 🟨 | 正規ルートのため出所は明確。ただし扱う商材が規制カテゴリ（家電PSE等）なら別途対応要 |

### 7. 卸サイト（NETSEA・スーパーデリバリー・orosy 等）🟩〜🟨

| 項目 | 内容 |
|---|---|
| メリット | **在宅完結・新品の出所が明確（請求書が出る＝真贋調査に強い）**・会員登録だけで翌日から仕入れ可・小ロット〜1点から可の業者多数 |
| デメリット | 人気商品は競合多数で価格競争・利益率が薄くなりがち（NETSEAは「稼げない」批判もあるが裏返せば初心者の入口として無難） |
| 初期投資 | NETSEA: 登録無料 / SDeli: **買い手（小売）側は月¥約2,000税抜＋審査**（※後述の注意参照） |
| 規制リスク 🟩〜🟨 | 国内卸の新品は出所明確で低リスク。扱う商材が規制カテゴリなら個別対応 |

> **重要な数字の訂正・注意（サトルの確認結果）**: WebSearch で「スーパーデリバリー 月額40,000円＋手数料7%＋3%」という数字が出るが、**これは "出店者（サプライヤ=売る側)" の料金**であり、**社長が使う "バイヤー(小売=買う側)" の料金ではない**。バイヤー側は月¥約2,000税抜（既存 suppliers-list の記載が正しい）。混同しないこと。確度: 高（公式の役割区分による）。

### 8. 中国輸入（1688・タオバオ＋代行業者）🟥

| 項目 | 内容 |
|---|---|
| メリット | 仕入原価が最安・利益率を最も高く取りうる・OEMへの発展性 |
| デメリット | 中国語＋代行業者ほぼ必須・リードタイム14〜30日・検品工数・不良率 |
| 初期投資 | 代行業者登録（誠・転送ネコ等は **月会費0円** の業者あり、出典: 誠/比較ビズ）。MOQは1688で100個〜が多い、タオバオは1点〜 |
| 規制リスク 🟥 | **商標権侵害・PSE（電気用品）・技適（無線）・薬機法（コスメ）・関税** が多発ポイント。初心者が最初に触ると詰みやすい最難関。ハルオ事前レビュー必須エリア |

### 9. 韓国輸入（Qoo10・現地卸・代行）🟥

| 項目 | 内容 |
|---|---|
| メリット | コスメ・アパレル・K-POPグッズが人気で需要が読みやすい・小ロット/1点〜可・日本語対応プラットフォーム有 |
| デメリット | 韓国語/代行・薬機法（コスメ）・**日本語表記シールの貼付が必須**（出典: Qoo10ガイド, corekara） |
| 初期投資 | Qoo10個人輸入は0〜。代行利用時は手数料 |
| 規制リスク 🟥 | 人気のコスメは **薬機法（化粧品製造販売届出・全成分日本語表示）** に直結し、restricted-categories.csv で「非推奨」判定の領域。初心者には壁が高い |

### 10. OEM/ODM（自社ブランド製造）🟥

| 項目 | 内容 |
|---|---|
| メリット | 価格競争から脱却・独占的に売れる・ブランド資産化 |
| デメリット | 金型/ロゴ/MOQで初期数十万円〜・在庫リスク大・商品企画力必須 |
| 初期投資 | **数十万円〜（10万円予算では原則不可）** |
| 規制リスク 🟥 | 製造物責任・各種表示義務・知財。**軸Bのスコープ外**。将来の選択肢として認識のみ |

### 11. クラウドファンディング後続/在庫処分

| 項目 | 内容 |
|---|---|
| メリット | CF成功品の二次流通権で独占販売の入口・廃番プレミア品 |
| デメリット | メーカー個別交渉が前提（営業力）・不良在庫の目利き要 |
| 初期投資 | 0〜（メーカー次第） |
| 規制リスク 🟨 | 仕入ルートが正規なら出所明確。商材依存 |

### 12. その他（展示会・問屋街・ebay 等）

| 項目 | 内容 |
|---|---|
| メリット | 展示会=PB候補発掘 / 問屋街=現金即日 / ebay=廃番コレクター品 |
| デメリット | 事前登録・足を運ぶ時間・ebayは為替/関税計算 |
| 初期投資 | 交通費、ebayは為替コスト |
| 規制リスク 🟨 | 方法ごとに異なる。軸B後の "次の一手" 群 |

## C. サトルの所見（事実の要約。戦略判断ではない）

- **規制リスクが構造的に低い順**: 不要品販売(🟩) ＞ 国内卸サイト(🟩〜🟨) ＞ 電脳/店舗せどり(🟨, 仕入れ先次第) ＞ メーカー直取引(🟨) ＞＞ フリマ仕入れ・海外輸入・OEM(🟥)。
- **「初心者が最初に詰む」2大ポイント**は (a) フリマ/個人仕入れ品のAmazon新品出品不可、(b) 海外輸入の知財/PSE/薬機。この2つを避けるだけで事故率が大きく下がる（事実）。
- 「どの方法が最も儲かるか」は商材とリサーチ精度依存で、本リサーチでは確定できない（=軸Bで実地検証する対象）。
