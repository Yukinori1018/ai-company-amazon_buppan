## イシュー（このリサーチで答えを出す問い）

**「副業初心者が予算10万円で Amazon 物販を1サイクル回すとき、どの仕入れ“方法”を選ぶべきか。その判断に必要な事実は何か。」**

- 補助イシュー1: 仕入れ方法は何種類あり、各々の「初期投資・必要スキル・規制リスク」はどう違うか
- 補助イシュー2: 初心者×10万円で現実的に回せる方法は3〜5案に絞るとどれか（事実ベースの絞り込み材料）
- 補助イシュー3: 戦略を立てるタケシ（プランナー）に渡すべき未解決の問いは何か

**戦略提言はしない。** 「方法を1つ選ぶ」「10万円の配分を決める」はタケシの領分。本書は事実シート＋論点シートまで。

## 打ち切り条件（宣言通り守った）

- 仕入れ方法は **12分類で打ち切り**（チケット指定の10〜12分類の上限）。これ以上の細分化は推測領域に入るため止めた。
- 料金・手数料は **2026年5月時点の推定/公式表示**。1年で変動しうるため各所に取得日を明記。
- 一次情報（公式サイト）を優先。料金が公式に出ていないものは「推測」と明示し確度を添えた。
- 戦略提言には踏み込まず、論点シート（04）でタケシに引き継ぐ材料を提示して完了とした。

## 分かっていること / 分かっていないこと / 分かりようがないこと

- **分かっていること**: 各方法の構造的なメリット・デメリット、規制法令、主要プラットフォームの公式料金体系、メルカリ/Amazon の2025-2026規約。
- **分かっていないこと**: 社長が「在宅完結したいか・外出可か」「商品ジャンルの好み」「リサーチに割ける週次時間」。→ タケシが社長に確認すべき論点（04参照）。
- **分かりようがないこと**: 実際に仕入れた個別SKUが利益を出すか（=実際にやってみる軸Bの目的そのもの）。事前のリサーチでは確率までしか言えない。
