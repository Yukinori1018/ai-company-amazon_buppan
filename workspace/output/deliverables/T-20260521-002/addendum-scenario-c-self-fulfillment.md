## なぜこの補遺を書くか

playbook-final.md §6-3 では「楽観／中央／悲観」の3シナリオを **FBA 前提** で比較しています。しかし朝野コンサル動画（物販ナレッジ１）が指摘するように、**FBA 手数料を丸ごと自己発送の送料に充当する** ことで、表面の数字より黒字幅が拡大するケースが頻出します。

社長から「FBA 前提とはいえ、自己発送だとどう変わるのか並べて見たい」という関心は当然出てきます。**ここでは Scenario C を独立シナリオとして立て、Scenario A（FBA） / B（FBA + MSS／※未策定）/ C（完全自己発送）を並べて見られる形** で残します。

> ※ Scenario B は次回ターンでヒデアキが追補します。本補遺は **Scenario C と Scenario A の比較** に絞ります。

## 1. 自己発送モードの基本構造

### 1-1. FBA との費用構造の違い（再確認）

物販ナレッジ１ Part 3 より：

| 費用項目 | FBA（Scenario A） | 完全自己発送（Scenario C） |
|---|---|---|
| 販売手数料 | 売上の約 8〜15%（カテゴリ別） | 同左（変わらない） |
| FBA 配送代行手数料 | サイズ・重量で固定費 | **¥0** |
| FBA 在庫保管料 | 立方メートル×日数 | **¥0** |
| FBA 入庫送料 | 倉庫まで一括輸送費 | **¥0** |
| 自社配送送料 | — | ヤマト等への実費 |
| 人件費（梱包・伝票・発送） | ¥0（Amazon が代行） | **要計上**（社長の時間） |

### 1-2. 真の利益式（朝野コンサル流）

```
真の自己発送利益 = FBA画面利益 + 不要になったFBA手数料 − 自己発送送料 − 人件費換算
```

ここでは playbook-final.md §4-1 の中央シナリオ数値を使い、**FBA手数料を商品ごとに切り戻し → 自己発送送料を入れ直し** て再計算します。

## 2. 商品①②③の FBA → 自己発送 切替試算

### 2-1. FBA 手数料の推定内訳（商品別）

経理ハジメの `accounting-simulation.md` §B には FBA 手数料を含めた利益額しか書かれていないため、ここでは公開情報ベースで分解推定します。

| 商品 | サイズ区分 | FBA 配送代行手数料（推定/個） | FBA 入庫送料（推定/個） | 在庫保管料（25〜35日想定/個） | 合計 FBA コスト（個） |
|---|---|---|---|---|---|
| ① 国内メーカー製 文房具・収納雑貨 | 小型〜標準 | 約 ¥420 | 約 ¥160 | 約 ¥15 | **約 ¥595** |
| ② 国内メーカー製 猫用おやつ | 小型 | 約 ¥310 | 約 ¥80 | 約 ¥8 | **約 ¥398** |
| ③ 国内卸経由 ステンレスタンブラー | 標準 | 約 ¥600 | 約 ¥230 | 約 ¥45 | **約 ¥875** |

> 数字は 2026年5月時点の Amazon 公式 FBA 料金シミュレーター推定値。**実数は社長が JAN/ASIN を入れて再計算してください**（経理ハジメ§B末尾の注意書きと同じ）。

### 2-2. 自己発送に切り替えた場合の送料（個別運賃）

社長は法人契約なし・個人出品者前提のため、最も安いオプションは以下：

| 商品 | サイズ | 推奨配送方法 | 個別送料（個） |
|---|---|---|---|
| ① 文房具・収納ボックス | 60〜80サイズ | ヤマト宅急便 60サイズ | **約 ¥870** |
| ② 猫用おやつ（ちゅーる類） | 〜A4ファイル相当 | クリックポスト（日本郵便） | **約 ¥185** |
| ③ ステンレスタンブラー | 80サイズ | ヤマト宅急便 80サイズ | **約 ¥1,090** |

> Amazon 出品者は **マーケットプレイス配送サービス（MSS）** でヤマトの特別運賃（大口契約相当）が使えますが、これは別途 Scenario B で扱います。Scenario C は **MSS なしの素のヤマト/日本郵便運賃** で計算します。

### 2-3. 商品別 切替試算（個あたり）

#### 商品① 文房具・収納雑貨

```
FBA画面利益（中央想定）           : +400円/個（¥9,000〜¥12,000 ÷ 25個販売想定の中央値）
+ 不要になったFBA手数料           : +595円
- 自己発送送料（ヤマト60）        : -870円
= 個あたり真の利益（自己発送）    : +125円/個（黒字、ただし薄い）

25個販売想定での総利益            : +125円 × 25個 = +3,125円
（参考: FBAでの中央想定利益       : +10,000円）
```

→ **商品① は FBA の方が約 +6,875円 有利**。文房具は単価・粗利が薄いため自己発送に向かない。

#### 商品② 猫用おやつ

```
FBA画面利益（中央想定）           : +900円/個（¥13,500 ÷ 15個販売想定）
+ 不要になったFBA手数料           : +398円
- 自己発送送料（クリックポスト）  : -185円
= 個あたり真の利益（自己発送）    : +1,113円/個

15個販売想定での総利益            : +1,113円 × 15個 = +16,695円
（参考: FBAでの中央想定利益       : +13,500円）
```

→ **商品② は自己発送の方が約 +3,195円 有利**。クリックポストが効くサイズだと自己発送優位が顕著。

#### 商品③ ステンレスタンブラー

```
FBA画面利益（中央想定）           : +1,800円/個（¥19,800 ÷ 11個販売想定）
+ 不要になったFBA手数料           : +875円
- 自己発送送料（ヤマト80）        : -1,090円
= 個あたり真の利益（自己発送）    : +1,585円/個

11個販売想定での総利益            : +1,585円 × 11個 = +17,435円
（参考: FBAでの中央想定利益       : +19,800円）
```

→ **商品③ は FBA の方が約 +2,365円 有利**。ステンレスタンブラーは 80サイズで送料が重くなるため。

### 2-4. Scenario C 中央シナリオ 合算

| 項目 | Scenario A（FBA） | Scenario C（自己発送） | 差分 |
|---|---|---|---|
| 商品① 文房具 | +10,000円 | +3,125円 | **-6,875円** |
| 商品② 猫用おやつ | +13,500円 | +16,695円 | **+3,195円** |
| 商品③ タンブラー | +19,800円 | +17,435円 | -2,365円 |
| **合算** | **+43,300円** | **+37,255円** | **-6,045円** |

> 商品②だけは自己発送優位。商品①③は FBA 優位。**3商品 mix のままだと FBA合算 +43,300円 / 自己発送合算 +37,255円** で FBA 優位だが、**商品② だけ自己発送に切り出す混合運用（Scenario A+ と呼ぶ）が最適解**になる可能性が高い。

## 3. 人件費（社長の時間）の計上

経理ハジメの試算は人件費 ¥0 前提です。Scenario C はここに無視できないコストが乗ります。

### 3-1. 自己発送 1個あたり作業時間（ヒデアキ実測想定）

| 工程 | 所要時間/個 |
|---|---|
| Amazon セラーセントラルで注文受領確認 | 約 1分 |
| 商品ピッキング・OPP袋梱包 | 約 3分 |
| 伝票印刷・貼付（PCで一括出力前提） | 約 2分 |
| コンビニ/集荷持込（複数件まとめて） | 1日分まとめて約 0.5分/件 |
| カスタマーメッセージ対応（10件に1件想定） | 平均 約 1分/件 |
| **合計** | **約 7.5分/個** |

### 3-2. Scenario C 全体での社長の発送労働時間

- 1サイクル販売数（中央）: 商品① 25個 + 商品② 15個 + 商品③ 11個 = **51個**
- 全体作業時間: 51個 × 7.5分 = **約 382.5分 = 約 6.4時間/サイクル**
- 社長の時給を仮置き ¥2,000/時間と置くと: **約 ¥12,750 の見えないコスト**

### 3-3. 人件費込みの Scenario C 中央シナリオ

```
売上利益（個別合算）           : +37,255円
- 人件費換算（¥2,000/時間×6.4h): -12,750円
= 真の手元利益（中央）          : +24,505円
```

| 項目 | Scenario A（FBA） | Scenario C（自己発送、人件費込み） | 差分 |
|---|---|---|---|
| 合算（中央） | +43,300円 | **+24,505円** | **-18,795円** |

> **人件費まで含めると Scenario C は Scenario A に対して約 -19,000円の劣後**。商品②単独切り出しでも、人件費を考えると FBA が穏当という判断になります。

## 4. Scenario C を選ぶ判断条件（撤退条件の裏返し）

「自己発送に倒すべき条件」を整理しておきます。

### 4-1. Scenario C を選ぶ合理性が出るケース

1. **社長の時給機会費用が低い時間帯**（睡眠時間と相反しない夜間・週末まとまった時間）に発送をまとめられる場合
2. **商品②のように小型・クリックポスト圏内** で送料 ¥200 未満が成立する商品に絞る場合
3. **古物商で中古を扱う場合**（FBA は新品中心の運用がしやすいため、中古主軸なら自己発送ベース）
4. **特殊配送が必要な商品**（精密機械・温度管理・大型家具など、FBA で受け入れが難しいもの）
5. **アカウント健全性をマイナス評価から積み上げ直したい場合**（自己発送で評価コメント取得しやすい）

### 4-2. Scenario C を避けるべきケース（社長の現在地）

1. **本業時間外の余力が少ない**（朝5時起き案件・夜間自走モード運用中＝社長の時間は希少資源）
2. **商品①③のように 60〜80サイズ品**: 自己発送送料が ¥870〜¥1,090 と重く、FBA 手数料との差分がほぼゼロ〜マイナスになる
3. **不在票・再配達対応のクレーム対応**を負いたくない: FBA なら Amazon が代行
4. **副業初心者として「Amazon にプロセスを任せる」学習価値**: FBA を1サイクル回すこと自体が SOP 学習機会

→ **社長の現フェーズでは Scenario A（FBA）が穏当**。Scenario C は商品②単独切り出しの選択肢として記憶し、軸B 2周目以降に検討。

## 5. Scenario C 撤退条件（独自）

playbook-final.md §6-3 の撤退条件に加え、Scenario C 固有の撤退条件を追記します。

| 撤退条件 | 判定タイミング |
|---|---|
| 発送作業に **週6時間以上** 取られ、本業/家庭/睡眠を圧迫 | 1サイクル目の Day 30〜45 で実測 |
| カスタマーメッセージ対応が **週3件以上** | Day 30〜45 |
| 配送遅延・不在票クレームで **アカウント健全性が「警告」以上に低下** | 即時 |
| MSS 申込が承認されない場合（個人出品者では通らないケース有） | Day 8〜14 |

## 6. ヒデアキの結論（次の社長判断材料）

### 6-1. 推奨ルート

**Scenario A（FBA 全商品）を主軸として開始。商品② 猫用おやつのみ、Day 60 以降の2サイクル目で「Scenario A+（商品②だけ自己発送に切り出し）」をテスト** する。

### 6-2. 数値要約

| ルート | 中央シナリオ手元利益（人件費込み） | 学習価値 | 推奨度 |
|---|---|---|---|
| Scenario A（FBA 全品） | +43,300円 | Amazon 標準フローの学習 | **★ 推奨** |
| Scenario A+（商品②のみ自己発送） | 約 +43,500円 | FBA と自己発送の比較学習 | 2周目候補 |
| Scenario B（FBA + MSS） | 未試算（次回ターン） | MSS 申込ノウハウ | — |
| Scenario C（完全自己発送） | +24,505円 | クレーム対応・配送SOP の学習 | 非推奨（現フェーズ） |
