## 0. 結論

1. 実践者 15人を確認しました。月利100万円以上を「利益」として明記しているのは 9人です。残りは「月商」「月収（定義なし）」で、利益とは限りません。
2. 数字はすべて本人かスクール運営者の自己申告です。第三者の監査やセラーセントラル画面の検証はありません。15人中 12人がスクール・コンサル・教材を販売しています（利益相反あり）。
3. 月利100万円に到達した人が共通して取った型は「電脳せどり × リピート商品の積み上げ × 納品外注」です（シバコン系4人、ちゃんやま、リピスタ神）。月利の7〜9割がリピート品という申告です（トシプー8割、柴犬7割、あり9割）。
4. 「その手法に着手してから月利100万円まで」の中央値は 6ヶ月です（N=6、自己申告、生存者のみ）。ただし 6人中 3人は着手前から、せどりで月利20〜100万円を出していました。
5. 母数の数字は2本あります。シバコンは8ヶ月プログラム修了229人のうち43人（18.8%）、物販ONEは受講3,000人超のうち40人超（約1.3%）が月利100万円以上です。どちらも運営者の自己申告です。

### 2-2. リサーチの手順とツール

共通の手順（事実。3つの出典で一致）：
1. 利益の出る商品を1つ見つけ、その商品の出品者から「強いセラー」を選ぶ。条件は評価数 50〜400件［S29］または 100〜1,000件［S24］、出品数100以上、FBA中心、直近30日の販売あり。
2. そのセラーの取扱ASINを Keepa の Product Finder（セラーID指定）で一括出力する［S24］。
3. ASIN/JAN を自動照合ツール（雷神）に入れ、楽天・Yahoo・NETSEA などとの価格差を出す。雷神は販売額・サイズ・出品者数・利益率・回転から S〜C のランクを付ける［S30］。
4. 実質の仕入れ値（ポイント・クーポン込み）を計算し、Keepa で価格の安定と回転を目視確認してから仕入れる［S29］。
5. 利益の出た商品はリスト化し、繰り返し仕入れる（リピート化）［S13］［S31］。

## 3. 推論（公開情報で埋まらない部分）

| 論点 | 推論 | 根拠と確度 |
|---|---|---|
| なぜ到達者はリピート型なのか | 新規商品の判定には毎回誤りのリスクがある。リピート品は一度実売で検証済みなので、判定回数と誤判定が減る | リピート7〜9割の申告（S10・S12・S13）＋「仕入れの8割が値崩れ」（S26）。確度中 |
| 月利100万の月商 | 500〜1,000万円 | 利益率9.4%（S7）〜20%（S19）からの逆算。確度中 |
| 月利100万に必要な資金 | 手元資金とカード枠で500万円以上 | 回転1ヶ月（S7）×仕入れ400〜800万。確度中 |
| 中央値6ヶ月の意味 | 到達者の中央値であり、受講者の中央値ではない。シバコン修了者でも到達は約2割 | S31。確度高（ただし自己申告） |
| 2026年のポイントせどり | 上乗せは月数千ポイントが上限。単体で月利100万は困難 | 楽天公式の上限表（S27）。確度中 |

## 4. 当社が真似できる部分／できない部分

当社の条件：個人事業主、実績ゼロ、PC完結、資金200万円、Amazon日本は大口。2026年8月にKYC連鎖で約5週間停止。Keepa API と NETSEA を契約済み。

| 要素 | 真似 | 理由 |
|---|---|---|
| 店舗せどり（家電量販店・ブックオフ） | できない | PC完結の条件に反する（物理的な店舗巡回が必要） |
| 中古せどり | できない（当面） | 古物商許可が必要。真贋調査で小売・手書き領収書が通らない（S37） |
| 電脳・リピート型（セラーリサーチ→Keepa→価格差→リピート化） | できる | 仕入れも納品もネットで完結する。Keepa は契約済み |
| 仕入れ先を NETSEA などの卸にする | できる（相対的に有利） | 卸の請求書は真贋調査・出品許可の書類になる。小売レシートは無効（S3） |
| 納品代行 | できる | ネットショップの配送先を代行業者にすれば自宅を通さない（既存memoryの単価で試算可能） |
| 楽天ポイント | 部分的 | 上乗せは月数千ポイントが上限（S27）。価格差への上乗せ程度 |
| 月利100万の規模 | 当面できない | 必要資金500万以上（推論）に対し当社は200万 |
| セール・廃盤（プレ値） | 慎重に | 仕入れの8割が値崩れするという申告（S26）。当社の終売品バイアスの記録とも一致 |

当社のホールド理由（AIリサーチの誤りが多く、訂正が重い）を実践者はどう避けているか：

| 当社の問題 | 実践者のやり方 | 出典 |
|---|---|---|
| 判定をAIが推測する（列の意味の誤読など） | 決定論のツール（JAN照合の雷神）で価格差を機械的に出し、S〜Cランクで並べる。最後は人が Keepa を目視する | S30、S29 |
| 新規商品を毎回ゼロから判定する | リピート品を7〜9割にして、新規の判定回数を減らす | S10、S12、S13 |
| 判定基準が曖昧 | セラー選定の条件を数値で固定する（評価数50〜400件など）。マニュアル化してリサーチを外注する | S29、S10 |
| 真贋リスクをあとで知る | セラースケットで事前に危険度A〜Dを判定する | S33 |

推論（確度中）：実践者は、AIではなくルールが固定されたツールと人の目視を使っています。当社がAIを使うなら「照合と計算はツールかコード、最終判定は人」と役割を分ける形が、実践者の型に最も近いと推測します。

ここから先（どの型を採るか・資金配分）はタケシ（プランナー）の領分です。
