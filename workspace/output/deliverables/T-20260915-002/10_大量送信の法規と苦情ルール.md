# 10 大量送信の法規と苦情ルール

- 担当：ハルオ（法務）／2026-09-16
- 対象：06 §2・§3 ①（週70通・メール＋フォーム＋FAX・週1回の一括承認）、07 §4.3（マサルの段階ルール）、08 S-C の法規論点7つ
- 一次情報は すべて 2026-09-16 に取得（出典は §8）

## 0. 結論

| # | 論点 | 判定 |
|---|---|---|
| 1 | 特定電子メール法 | 仕入れのお願いだけなら対象外。ただし会社概要 URL を貼ると対象になる（当社 HP は消費者向けの店の案内）。**週70通の量産では、対象として表示義務を満たして送る**（署名5行で済む） |
| 2 | FAX | 特定電子メール法・特商法12条の5とも対象外。判例・条例は見つからず。残る論点は民法709条・刑法234条（拒否後の反復）と FAX 会社の規約 |
| 3 | 苦情ルール | マサルの段階ルールは採用可。条件は3つ：受信拒否は件数に数えず、その日に会社単位で永久停止／公的な通報は1件で全停止／「拒否」と「苦情」を分けて記録 |
| 4 | 一括承認 | 設計は可。価格・契約・独占・書類・苦情・法的な言及の返信は、1件ごとに社長へ（§5） |
| 5 | 個人情報 | 担当者名を入れた送信先リストは PUBLIC リポに置かない（27条）。HP に取引先情報の利用目的が無いので、初回メールで通知する（21条） |

## 1. 特定電子メール法（08 の論点1〜5）

| # | 論点 | 判定 | 根拠 |
|---|---|---|---|
| 1 | 仕入れのお願いは「広告又は宣伝」か | 単体なら当たらない | 法2条2号「自己又は他人の営業につき広告又は宣伝を行うための手段として」。GL p.2 非該当例ア）取引上の連絡で「広告又は宣伝の内容を含まず…ウェブサイトへの誘導もしない」メール |
| 1' | 例外 | 本文に当店の売り込み（販売実績・拡販の約束など）を書くと、自己の営業の宣伝と読まれうる | 同上。量産の型では混ざりやすい |
| 2 | 会社概要 URL は「誘導」か | 当社 HP では当たる側 | GL p.1 該当例ア）「広告又は宣伝しようとするウェブサイトへ誘導することがその送信目的に含まれる」。当社のトップ・/about・/business は「Amazonストア、まもなく公開します」「お買い物のしくみ」と消費者向けの店の案内。/guide-bottle は Amazon 検索へのリンクあり（2026-09-16 取得） |
| 3 | 「広告メールお断り」表示の先を外す工程 | 要る | 法3条1項4号（公表アドレス宛の例外）＋施行規則3条ただし書（拒否の文言と併せて公表した場合は例外に当たらない）。T-20260904-004 の B1L 判定ルール v1.2 をそのまま全件にかける |
| 4 | 署名の表示 | 要る（下の方針により全件） | 法4条・施行規則7条・9条。項目は §6 |
| 5 | 問い合わせフォーム | 法の対象外 | 法2条1号の「電子メール」は総務省令（平成21年85号）の SMTP 方式・電話番号方式に限る。フォームは HTTP |

### 方針：量産するなら「対象」として送る

- 1社1通の個別の打診なら「対象外」で足りた（T-20260904-004）。今回は同じ型で週70通。法7条の措置命令の要件「一時に多数の者に対してする」送信に近づく。
- 文面の型に売り込みが1行混ざる、URL を1本貼る。それだけで対象に変わる。型を6つ回す運用では、全通を対象外に保つ管理のほうが高くつく。
- 表示義務を満たせば、対象かどうかの争いは実害を持たない。費用は署名5行と拒否リストの運用だけ。
- URL は /partners（取引先向け）1本に限る。トップ・/about・/guide-* は貼らない。
- 違反の効果：法3条・4条違反に直罰は無い。法7条の措置命令に違反すると法34条（1年以下の拘禁刑または100万円以下の罰金）。

### フォーム送信（法の外で効く3点）

1. 相手の規約・フォームの注記。「営業・売り込みお断り」「ツール・自動送信での送信お断り」があれば外す（B1L ルールの窓口単位判定）。
2. AI（カズヨ）の入力と送信は「自動化された手段」に当たる（`knowledge_ai_browser_agent_is_automated_means`）。CAPTCHA は解かない。出たらその社は飛ばす。
3. 前提が1つ変わる。T-20260912-002/02 の判定は「入力はカズヨ、送信クリックは社長」だった。一括承認でカズヨが送るなら、社長名義での代理送信になる（民法99条）。承認の記録（期間・文面の型・リスト・上限件数）を残せば、権限のある代理でありなりすましではない。記録が無い送信は無権限。

## 2. FAX（08 の論点6・eFax）

| 論点 | 判定 | 根拠 |
|---|---|---|
| 特定電子メール法 | 対象外 | FAX は SMTP・電話番号方式のどちらでもない（法2条1号・平成21年総務省令85号） |
| 特商法12条の5（FAX 広告） | 対象外（二重に） | ①主体は通信販売をする販売業者・役務提供事業者、対象は販売条件の広告（12条の5第1項・2条2項）。当社の FAX は買いの申込み。②26条1項1号で、営業のために結ぶ取引は第3節（通信販売）ごと適用除外 |
| 判例・条例 | 見つからず | 検索3回。事業者宛の営業 FAX を違法とした判決・自治体条例は確認できず（確度中。二次情報は「BtoB の FAX DM は特商法の規制外」で一致） |
| 民法709条 | 1通では損害が小さく、現実味は低い | 用紙・トナー代。拒否後の反復で現実味が出る |
| 刑法234条（威力業務妨害） | 拒否後の反復で近づく | 1回の商談申込みでは成立しない |
| ネット FAX 会社の規約 | 一斉送信はしない | eFax は多数宛の一斉送信でアカウント停止ありと明記（08 S-C）。1通ずつ送る。契約前に規約の禁止事項を読む（契約は §4.1・社長の一手） |

FAX の運用ルール：

- 1社1回まで。7日後の追いかけ1回だけで、FAX の再送はしない。
- 送る先は、事業用として公表された FAX 番号だけ。「FAX DM お断り」「営業 FAX お断り」の表示がある先は外す。
- 平日 9〜18 時に送る。
- 表示の義務は無い。それでも §6 の5項目と「今後不要の方は」の1行を必ず入れる。

| 論点 | 判定 | 根拠 |
|---|---|---|
| 担当者名・個人事業主のメーカーの氏名 | 個人情報。リストにすれば個人データ | 個人事業主の屋号＋氏名・住所も同じ。規模要件は無い |
| 取得 | 公開された事業用の連絡先の転記は可 | 20条1項（不正の手段の禁止）。ログイン後の情報・CAPTCHA の回避は不可 |

| 保管 | PUBLIC リポに置かない | 27条（本人の同意なく第三者に提供しない）。リポへの commit は公開＝不特定への提供と同じ。23条（安全管理） |
| 置き場 | 社長の Drive の非公開シート、または `.gitignore` 対象のローカル＋バックアップ | リポ内に置けるのは会社名・法人番号・件数だけ |

## 4. 苦情ルールの判定（07 §4.3）

判定：採用可。ただし下の3条件を足す。

| 区分 | 定義 | 対応 | 件数に数えるか |
|---|---|---|---|
| 受信拒否 | 「不要です」「今後は結構です」。電話・FAX・フォーム・返信のどれで来ても同じ | その日のうちに拒否リストへ入れる。会社単位で、全窓口・全経路を永久に停止。社長へは週次報告でよい | 数えない |
| 苦情 | 「迷惑だ」「どこでアドレスを知った」「二度と送るな」など、怒りや非難を含むもの | その文面の型・その経路を止めて見直す（マサル案）。拒否リストに入れる。社長へ1件ごと | 数える |
| 公的な通報 | 総務省・消費者庁への申出（法8条）、迷惑メール相談センター、プロバイダ・ブラックリストからの通知、弁護士名の書面、措置命令 | 全送信を即停止。社長へ即時 | 1件で全停止 |

足す3条件：

1. 受信拒否は件数の閾値と無関係に、必ず止める。法3条3項は相手ごとの絶対の義務で、「300通で3件まで」の枠の外にある。通知の方法は任意（施行規則5条）なので、メールでなく電話や FAX で来た拒否も同じに扱う。
2. 全停止の線（300通で3件）は法令上の線ではなく、社内の撤退線。参考値として、Gmail の送信者ガイドラインは迷惑報告率0.3%を超えないことを求めている。300通で3件は1%で、その3倍に当たる。相手が迷惑報告ボタンを押しても当社には見えないので、次のどれか1つでも出たら全停止に加える：送信元ドメインのブロック通知、バウンスの急増、Gmail からの配信制限。
3. 苦情が同じ理由で2件出たら、その文面の型は廃止する。見直しでは直らない。

記録の持ち方（非公開の置き場。§3）：

| 台帳 | 列 |
|---|---|
| 拒否リスト（永久保存） | 会社名・法人番号・ドメイン・メール・FAX・フォーム URL・受付日・受付経路・区分（拒否／苦情／公的）・原文の要旨・対応日 |
| 送信ログ | 日時・宛先・経路・文面の型 ID・承認バッチ ID・公表アドレスの確認 URL と確認日 |

送る前に、送信先リストと拒否リストを法人番号とドメインで突き合わせる。社名の表記ゆれで漏らさないため（B1L の `aliases` と同じ）。送信ログの確認 URL は、施行規則3条の「公表」を満たしていた証拠になる。

## 5. 一括承認で「1件ごとに社長へ上げる返信」の線引き

週1回の一括承認で任せてよいのは「承認済みの型・リスト・上限件数の範囲の送信」と「定型の日程調整」だけ。次は1件ごとに上げる。

| 区分 | 例 | 理由 |
|---|---|---|
| 金銭 | 見積・卸値・ロット・送料・支払条件の提示や交渉 | §4.1 金銭 |
| 法的拘束 | 取引基本契約・NDA・取引条件書・規約への同意、「この条件でよければ返信を」 | §4.1 法的拘束。返信1本で合意が成立しうる（民法522条） |
| 独占・販路 | 独占・総代理店・Amazon 以外禁止・販売価格の指定 | 契約上の拘束。価格指定は独禁法の論点を含む |
| 書類・機密 | 請求書・本人確認・反社チェック・口座情報・開業届の写しの要求 | §4.1 機密情報の外部送信。社長の個人情報が出る |
| 苦情・拒否以外の否定的な反応 | §4 の「苦情」「公的な通報」 | 撤退線の判定 |
| 法的な言及 | 「弁護士」「法的措置」「通報」「特定電子メール法」「個人情報」「無断」「商標」「画像の使用」 | 紛争の入口 |
| 範囲外 | 相手が別会社・代理店を紹介／電話を求める／相手が個人（消費者）と判明／承認に無い型・上限超え・2通目以降 | 承認の範囲を超える |

受信拒否は例外。カズヨがその場で拒否リストに入れてから、事後に報告する。承認待ちで再送すれば法3条3項違反になる。

一括承認の書面に必ず書く7項目：期間（月曜〜日曜）・文面の型 ID・送信先リストのファイル名と件数・経路（メール／フォーム／FAX）・上限件数・停止条件（§4）・送信者の名義。§4.1 の運用を変えること自体は社長の判断です。社長の承認の記録が無い週は送らない。

## 6. 文面の必須表示のひな形

〔 〕は差し込み欄。実値はこのリポに書かない。

### メール（全通に付ける。法4条・施行規則7条・9条）

```
――――――――――――――――
送信者：Satoy Select（〔氏名〕）
住所：〔住所〕
電話：〔電話番号〕
メール：info@satoy-select.com
取引先向けのご案内：https://satoy-select.com/partners
今後このようなご連絡が不要な場合は、本メールに「不要」とご返信ください。以後お送りいたしません。
いただいたご担当者様のお名前・ご連絡先は、本件のお取引のご相談にのみ使用いたします。
――――――――――――――――
```

| 行 | 根拠 |
|---|---|
| 送信者 | 法4条1号。個人事業主は屋号だけでなく氏名も入れる |
| 住所 | 施行規則9条2号。リンク先でも可（7条1項3号）だが、HP のソースは PUBLIC リポにあるため、本文に書く。住所は Amazon の出品者情報で既に表示されているので、増えるのは相手先への露出だけ |
| 電話 | 施行規則9条3号は電話・メール・URL のいずれかで足りる。GL p.26 は電話の併記を推奨。社長が載せない判断ならメール行で要件は満たす |
| 返信で拒否できる旨 | 法4条2号・施行規則9条1号。送信元に返信して拒否できるので、表示場所は任意（7条1項2号括弧書） |
| 利用目的 | 個人情報保護法21条1項の通知 |

### FAX（法の義務なし・自主表示）

```
送信者：Satoy Select（〔氏名〕）／〔住所〕
電話：〔電話番号〕　FAX：〔FAX番号〕　メール：info@satoy-select.com

```

### フォーム（法の義務なし）

- 名前欄・会社名欄には「Satoy Select（〔氏名〕）」。本文の末尾にメール用の署名をそのまま付ける。
- 本文の冒頭に「商品のご購入（仕入れ）のご相談です。売り込み・ご提案ではございません」と書く（B1L の C/A 境界の実務）。

## 7. グレー部分の3点セット

グレーは2つ：売り込み混入による特定電子メールへの転化と、AI によるフォーム送信。

| 項目 | 内容 |
|---|---|
| リスクシナリオ | ①型の1行が宣伝と読まれ、「広告メールお断り」の先に届いて申出（法8条）→ 総務省から照会。②送信元ドメインが迷惑メール扱いされ、既存の取引先・Amazon 関連のメールまで届かなくなる（不可逆性が高い）。③フォームの「自動送信お断り」を見落として送信 → 相手からの苦情 |
| 発生時の対応 | ①全停止・照会に回答・型を廃止。②全停止・ドメイン設定（SPF/DKIM/DMARC）の点検は IT へ（秘書経由）・回復まで再開しない。③その社を拒否リストへ・謝罪は社長の承認後 |
| 撤退条件 | §4 の全停止の線。加えて、措置命令か行政指導を1件受けたら型A の大量送信そのものを中止し、1通ごとの承認に戻す |

## 9. 確度と未確認

- 事実（条文・GL・HP の文言）：確度高。
- 推測：量産時に措置命令の要件（一時に多数）に近づくという評価、フォームの代理送信の評価（確度中）。
- 未確認：事業者宛 FAX の判例・自治体条例（検索3回で見つからず）。ネット FAX 各社の禁止事項の全文（契約前に要確認）。
- 本書は判断材料です。送信・契約・§4.1 の運用変更は、社長の承認で決まります。
