## 0. 結論（3行）

1. 実践者12人と参考2件（匿名1・失敗例1）を確認。月利100万以上を公称しているのは4人（寺田・亀井・MARU・こーいち）、月商か年商のみの公称が7人、非開示が1人。12人全員がスクール・コンサル・代行業者を兼ねている（利害あり）。
2. 共通する型は「既製品で需要を確かめる → 売れた物だけ簡易OEM（ロゴ・タグ・箱の変更、10〜100個）→ 当たりに集中して本格OEM」の3段階。1商品目は、出品まで2〜3ヶ月、費用は中央値で約25万円（N=5、範囲6.5万〜75万）。初期費用の回収には6ヶ月以上かかる。
3. 日本語のみ・PC完結は代行業者を使えば成立する（事実：日本語対応・検品・FBA 直納の代行が10社以上）。ただし、中国セラーの価格競争（中国の工場が Amazon 日本に直接出品している）と、小物・軽量ジャンルの飽和は複数の実践者が認めている。

## 4. 当社が真似できる部分／できない部分

当社の条件：個人事業主・実績ゼロ・日本語のみ・PC完結（物理作業は外注）・資金200万・Amazon 日本は大口。

| 要素 | 真似できるか | 根拠 |
|---|---|---|
| 日本語のみ | できる | 日本語対応の代行が10社以上 [#24][#25]。語学を必須とした実践者は0人 |
| PC完結（検品・撮影・納品） | できる（推論） | 代行の検品・FBA 直送 [#24][#25]、撮影代行 [#22]。当社の外注方針と整合 |
| 資金200万 | 簡易OEMなら5〜8本は試せる（推論） | 1本25万（R1）×5〜8本＋予備。本格OEM（1本50万超）なら2〜3本 |
| 既製品で需要を確かめる | できる | 1個から発注できる [#6][#11]。ただし他人の ASIN への相乗りは値崩れリスク [#23][#14] |
| 簡易OEM（ロゴ・タグ・箱の変更、10〜100個） | できる | ロット・費用が当社資金と整合 [#16][#18]。商標は出願中でもブランド登録できる [#26] |
| セラースプライトによる市場測定 | できる（要契約＝§4.1） | 実践者6人中4人が使用。当社は Keepa（API）契約済み。セラースプライトの要否はツール判断 |
| 本格OEM（金型・500個〜） | 1周目は難しい | 1本で数十万〜数百万 [#16]。当たり率 R3 から見て資金200万では分散できない |
| 船原の「デカ重」（大型重量物・自社倉庫） | できない | FBA 規格外で物理倉庫の手配が要る [#14]。PC完結と衝突 |
| 実践者の到達速度 | そのままは真似できない | 公開されているのは成功例とスクールの宣伝のみ（R5）。当社は未経験 |
| 避けるべきジャンル | 真似する | PSE・技適・食品接触・乳幼児玩具・大型重量・季節品（[#3][#15][#5][#27][#28][#32]） |

「日本語のみ・PC完結」で回るか：事実上は回る。代行が交渉・検品・FBA 直送まで日本語で請け負っている。残る当社の作業は、リサーチ・発注の判断・商品ページ・広告運用・商標出願で、全て PC 上でできる。

## 5. 論点シート（ここから先はタケシの領分です）

1. 中国輸入OEMを、当社のどの軸に置くか。memory では③OEMは②国内メーカー仕入れの「後続」になっている。
2. 1周目を「既製品で需要確認 → 簡易OEM」の2段にするか、国内簡易OEM（平井型）と比べるか。国内版は中国セラーとの競合がない。
3. 資金200万のうち OEM に何本・いくら割くか。R3 の当たり率では、1〜2本だけの投入は全滅リスクが高い。
4. セラースプライトの契約要否（§4.1。Keepa との重複度はツール調査が必要）。
5. 輸入消費税の扱い（R6）と、課税事業者を選ぶかどうか（経理ハジメ）。
6. 回転上限6ヶ月の既定と、R2（回収6ヶ月超）の関係。
