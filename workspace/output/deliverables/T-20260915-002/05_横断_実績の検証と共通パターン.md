# 05 横断：月利100万の実績の検証と共通パターン

- チケット：T-20260915-002（サトル⑤・横断）
- 作成：2026-09-15 サトル（リサーチャー）
- 出典の取得日：すべて 2026-09-15（S番号は末尾の出典表）

## イシュー

月利100万円以上の物販実践者は日本に何人規模いて、どの型の到達者が多く、到達者の1年目は月利いくら・資金いくらだったか。スクール生の何%がどこまで届くか。

## 結論（5行）

1. 母数の一次統計は無い。Amazon 公式の最新の閾値データは「年商1億円を初めて超えた日本の中小事業者 500社以上」（2019/6〜2020/5）が最後。推論では、月利100万級は数千〜1万社台（法人込み・確度低）。
2. 実例27件のうち、月利100万到達を公言したのは19件。最初に100万へ届いた型は、せどり・国内転売が6件で最多。ただし8件は単純転売から始めて、後にメーカー直・OEMへ移っている。
3. 到達者の1年目の月利は中央で約50〜80万円（N=12・自称中心・生存者のみ）。一方、元スクール受講者30人の1年目の最多帯は月1〜3万円で、30万円以上は0人だった。
4. スクールの成功率の自称は「月利100万 35.5%」（EC STARs）。独立系に近いデータ（N=30・N=100）では月5万円超が3%、1年目10万円以上が6.7%。同じアパリセでも「半年で10万以上」が90%以上（LP）と約半数（自社 note）で食い違う。
5. 非ログインで見えるM&A公開案件15件のうち、月利100万以上は0件。せどり型の3件は年商がピークから3〜5年で1/3以下に落ちている。

### 1-2. 推論：月利100万級は日本に何社か

- 換算：月利100万円 ＝ 利益率20%なら月商500万（年商6,000万）、10%なら月商1,000万（年商1.2億）。
- 下限側：年商1億超を「初めて」超えた社が年500社以上（c）。数年分が積み上がるので、年商1億超の中小は数千社規模。
- 上限側：14万社（a）× 月商$25k（約375万円）以上の比率11%（g・世界値） ≒ 1.5万社。メーカー・小売の法人を含む。
- 推論：月利100万級のAmazon 販売事業者は数千〜1万社台（確度：低）。個人発の物販専業はその一部で、比率は分からない。
- 社長の言う「ごまんといる」は絶対数としては当たる（数千人規模）。一方で参加者に対する率は低い（i：月5万円超が3%）。

## 8. タケシへの論点（ここから先はタケシの領分です）

1. 到達者の最多ルートは「単純転売で現金と経験を作る → メーカー直・OEMへ移る」の二段階（P1）。当社は最初からメーカー直を本丸にしている。一段目を挟むかどうか。
2. 1年目の計画値を到達者の中央（約50〜80万）で置くか、S1 の分布（1年目30万以上0/30）で置くか。
3. 月利100万の運転資金は推論で450〜600万円。資金200万円との差をどう埋めるか（融資時期・回転）。経理ハジメの検算が要る。
4. 真似の対象を1人に絞るなら、数字の開示が細かいのは H（月別の仕入れ額と月利）、ちび太（月別の売上と純利益）、M・Y（3ヶ月・6ヶ月の月利と取引社数）。
