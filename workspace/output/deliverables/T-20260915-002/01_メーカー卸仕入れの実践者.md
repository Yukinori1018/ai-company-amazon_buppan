# 01 メーカー・卸仕入れで月利100万円以上の実践者（サトル①）

- チケット：T-20260915-002（担当範囲①国内メーカー・卸仕入れ）
- 取得日：すべて 2026-09-15（出典は §7。番号 S1〜S37 で本文から参照）
- 調べ方：公開情報のみ。有料教材・会員登録・問い合わせはしていない
- イシュー：月利100万円に届いた人は、1社目の取引をどう取り（何社当たり・何ヶ月・何と言って）、どう100万まで積んだか。当社がそのまま真似できる手順はどれか

## 0. 結論

1. 月利100万円以上を公言している実践者を10人確認した（参考として100万未満の4人も載せた）。うち9人はスクール・教材の運営者か、その受講生。数字は全員「自称」。書籍・第三者媒体・法人登記で裏が一部取れるのは3人だけ。
2. やり方は3つの型に分かれる。A＝多社・相乗り型（Keepaで探す→メールとFAXを大量に送る→取引60〜120社で月利100万）。B＝少数・独占型（小さなメーカーに独占を条件に新規ページと販促を請け負う→取引1〜6社）。C＝問屋・一次店を使う大規模型（融資と組織化が前提）。
3. 1社目まで：型Aの公称は「メール30〜50社で1社」（S3）と「成約率3〜5%」（S11）。公開事例では、1社目は開始1ヶ月以内に取れている（S2, S7, S23）。ただし公開されているのは成功例だけ。
4. 型Aの利益率は、公開された月商と月利の比で見ると10〜12%（S22, S24）。当社KPIの20%には届かない。20%を超えるのは型Bの独占（純利20〜25%・S28）。
5. 最も手順が公開されていて真似しやすいのは型A（EC STARs Lab. の手順）。ただしこれは推測（§5）。最大の壁は、メーカーへの送信（月300〜2,000通）が社内規程 §4.1 の「第三者連絡」に当たることで、1通ずつ承認していては回らない。

## 5. 当社がそのまま真似できる部分／できない部分

当社の条件：個人事業主・実績ゼロ・日本語のみ・PC完結・資金200万・Amazon日本店は大口。

| 手順 | 真似 | 理由 |
|---|---|---|
| Keepa で条件検索してメーカーをリスト化（型A） | できる | Keepa API は契約済み。条件は社内記録どおり |

| 会社概要・HP・独自ドメインのメール | できる（要確認） | 既存サイトがあるかは別途確認 |
| FAX | できる | ネットFAXならPCで完結する（推測） |
| 電話（初回・フォロー・断られた後） | 条件付き | PC完結の方針の例外になる。社長の声が要る。EC STARs は「電話で成約率が上がった」と言うが、数字は出していない（S12） |
| 固定電話番号・開業届 | 条件付き | IP電話で代用できるとされる（S37）。開業届の状況は要確認 |

## 6. ここから先はタケシ（プランナー）の領分です

事実としてはここまでです。以下の判断は戦略なので渡します。

1. 型Aの利益率10〜12%と、KPI「利益率20%」の関係をどう置くか（型Aだけで月利100万なら、月商は約800〜1,000万）
2. 型Aで数を作ってから型Bの独占へ、という順番を採るか（公開事例はみなこの順番）
3. §4.1 の送信承認の単位（文面テンプレと送信先リストをまとめて承認する等）をどう設計するか。これは秘書・社長の論点
4. 電話を使うかどうか（PC完結の方針との衝突）

最も真似しやすいのは型A（EC STARs Lab. の手順）と見ます（推測）。理由は3点です。
- 手順・KPI・文面・電話台本まで公開度が最も高い
- 必要資金が50〜100万で当社の200万に収まる
- 社長が2026-06-12にこの手法の採用を決めている
