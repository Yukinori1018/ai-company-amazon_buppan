## 4. 「電話に出ない」運用が成り立つか

想定する流れ：着信 → 自動音声「メールでご連絡ください。ご用件を録音いただければ、メールで折り返します」→ 録音を文字にする → 秘書（AI）が読む → メールで折り返す。

| サービス | 自動音声の応答 | 文字にする | メールで受ける | 判定 |
|---|---|---|---|---|
| IVRy | ○ | ○ | ○ | 成り立つ（事実：公式の料金ページ） |
| 03plus＋留守レポ | ○（「端末には着信しない」設定） | ○（外部 API を使い、正確さは保証しない） | ○ | 成り立つ（事実：公式） |
| Zoom Phone | ○（二次） | ○（二次） | ○（二次） | たぶん成り立つ（推測・確度中。公式ページで確認できていない） |
| SUBLINE | ○ | 記載なし | 記載なし（アプリで再生） | 文字で受けられない。AI が音声を直接読めない前提では、成り立たない |
| ナイセンクラウド | ○ | 記載なし | ○（中身の形式は記載なし） | 未確定 |
| モバイルチョイス"050" | 時間外ガイダンスのみ | 該当なし | 該当なし | 成り立たない |

- 事実：03plus の留守レポは、登録した番号（取引先）からの電話だけを端末に鳴らせる（[設定ページ](https://03plus.net/denwadaikou/advanced_setting.html)）。
- 事実：03plus の留守レポの月額は、2023-05 の開始時が2,280円（[お知らせ](https://03plus.net/news/20230515.html)）、今のオプション一覧では3,000円。値上げされている。
- 推測（確度高）：月の着信が数件なら、IVRy のフリー枠（30件）に収まる。月額は番号維持費だけになる。

## 5. 050 と固定番号（03 等）の違い

| 軸 | 050 | 固定番号（クラウド） |
|---|---|---|
| 月額の目安 | 0〜550円（IVRy フリー＋維持費／SUBLINE） | 990円（SUBLINE）〜1,280円（03plus） |
| 取得の条件 | 本人確認のみ（IVRy は即日） | 番号の区域内の住所と、その証明書類。事務所を借りていれば契約書の写し（[03plus のコラム](https://03plus.net/column/landline_phone_app.html)） |
| 信用 | 「代表番号には 03・06 が使われ、050 は避けられる傾向が根強い。市外局番より信用度は劣る」（[03plus のコラム](https://03plus.net/ip/columun/column_10.html)）。「03 に比べると社会的信用度は低くなる」「融資でも 03 が有利」（[クラコール](https://clocall.jp/techlabo/corporate-number/)） | 上の裏返し |
| 着信の印象 | 「050 は迷惑電話」という受け止めがある（[ナイセンテレワークの記事タイトル](https://naisen-telework.jp/business-phone/050-nuisance-calls/)） | 該当なし |

- 分かっていないこと：メーカーの担当者が 050 を見て返信率が変わるか。書き手が利害関係のない調査・データは見つからなかった（検索2回）。上の記事はどれも 03 番号やクラウド PBX を売る会社のもの。
- 事実：S11（松井）の原文は「050 でも可」としている（本チケットの 08）。型A の実践者は 050 を許容している。
- 推測（確度中）：当社はメールと FAX で先に連絡する。電話番号は署名の1行にすぎないので、050 か 03 かより、番号が載っていること自体の効果の方が大きい。

| 案 | 中身 | 月額の目安 | 初期 |
|---|---|---|---|
| A | IVRy フリー（050） | 約500円（二次）。30件を超えたら3,980円（税抜） | 記載なし |

| C | 電話番号を載せない | 0円 | 0円 |

- 番号を載せるかどうか（論点⑥）と、どの案にするか（論点⑤）の判断はタケシの領分です。
- A と B の差は、月約3,800円と「固定番号かどうか」だけです。どちらも留守電を文字にしてメールで受けられます。
- 残る確認：どちらも通知先メールを、秘書が読める受信箱にする必要があります（satoyselect の受信箱はブラウザ経路で読む。reference_business_accounts）。IVRy の番号維持費は、申し込み前に公式の料金シミュレーターで確かめるのが確実です。
