## 0. 結論（先に3行）

1. 初回メールは**3パターン**。主力は①標準版。②は「Amazon で既に困っていると分かった相手」だけ、③は入力欄が短い／大企業の総合窓口向け。
2. 3パターンとも、**当店に商品が1点も並んでいない事実を隠さない**。隠さずに、御社に在庫リスクも与信リスクも負わせない条件（初回10点・前払い・価格は御社指定）とセットで出す。実績ゼロを「リスクゼロ」に翻訳するのがこの文面の設計。
3. **送信はできません。** メーカーへの連絡は CLAUDE.md §4.1（第三者連絡）。本書は下書きです。§6・§7 の返信文は金銭・条件に触れるため、**1通ごとに社長承認**（`10_...md` §5）。

## 1. 送る前に必ず埋める差し込み欄

〔 〕は差し込み欄。**実住所・電話番号・FAX番号はこのリポジトリに書きません**（PUBLIC リポジトリのため）。送信時に差し込みます。

| 欄 | 中身 | どこから取るか |
|---|---|---|
| 〔メーカー名〕〔ご担当者名〕 | 敬称は「御中」／担当者名が分かれば「様」 | メーカーリスト（T-20260920-002） |
| 〔商品名〕 | **メーカー公式サイトの表記を1字まで合わせる**（Amazon の商品名ではない） | メーカー公式サイト |
| 〔この商品のどこが良いと思ったか〕 | **ここだけは1社ごとに書き下ろす。使い回し禁止** | 下の §1-2 |
| 〔氏名〕〔住所〕〔電話番号〕 | 署名の法定表示 | 送信時に差し込む |

### 1-2.「良いと思った理由」の書き方（この文面集で唯一、機械化してはいけない欄）

中村の指摘：**テンプレの丸写しはダメ。複数の出品者から定型文ばかり届けばメーカーは嫌がる。**
実際、同じメーカーに送った2人のうち、文章を作り込んだ側だけ取引が決まった例が原典にあります（Chapter 6 Column）。

書き方の型は1つだけ。**カタログに書いてある性能をなぞらない。「誰のどんな場面で効くか」を1〜2文で書く。**

| 悪い例（カタログの写し） | 良い例（使う人から見た言い方） |
|---|---|
| 「ステンレス真空二重構造で保温力が高い点に魅力を感じました」 | 「飲み口が広く、氷が入る。夏場に車で持ち歩く方には、この一点が効くと思いました」 |
| 「抗菌加工されたまな板とのことで高品質と感じました」 | 「反りにくい厚みで、しかも食洗機に入る。毎日使う道具で、この2つが両立しているものは多くありません」 |
| 「御社の企業理念に共感いたしました」 | （書かない。誰にでも書ける） |

**1社あたり5分以内で書ける量に留める。**書けなければ、その商品は理解できていないということなので、送る商品を変えます。

**「どこで知ったか」を1句だけ混ぜる。** 原典 Chapter 7-02 によると、メーカーが電話で聞いてくる定番の質問に「ウチの商品をどうやって知ったか」があります。メールの段階で「Amazon で拝見し」「〇〇の売り場で見かけ」と半句入れておくと、この質問が消えます。**嘘は書かない**（知った経路が Amazon なら、そう書く）。

## 2. ①標準版（主力）

**件名**

```
【お取引のご相談】〔商品名〕の仕入れについて（Satoy Select・佐藤）
```

> 件名に「お取引のご相談」「仕入れ」を置くのは、開く前に「営業メール」と判定されないため。商品名を入れるのは、担当部署へ転送されやすくするためです。

**本文**

```
〔メーカー名〕御中
〔ご担当者名〕様

突然のご連絡を失礼いたします。
Amazon.co.jp でネットショップ「Satoy Select」を営んでおります、佐藤之則と申します。
本日は売り込みではなく、御社の〔商品名〕を仕入れさせていただきたいというご相談です。

〔この商品のどこが良いと思ったか：1〜2文〕

はじめに、正直に申し上げたいことが2つございます。

1つは、販売先が Amazon.co.jp であることです。Amazon での販売をご懸念なさるメーカー様が
多いことは承知しております。価格が崩れないように売る方法がありますので、
ご関心があればご説明いたします。

もう1つは、当店にまだ1点も商品が並んでいないことです。2026年8月に開業し、
いま最初に並べる商品を選んでいるところです。実績のない相手にご不安を感じられるのは当然ですので、
御社にご負担のかからない形をご提案します。

・初回は10点程度の小ロットで結構です。御社に在庫を持っていただく必要はありません
・お支払いは前払い（銀行振込）で承ります。掛け取引の枠は不要です
・販売価格は御社のご指定に従います。安売りで数を稼ぐことはいたしません

まだ何も抱えていない店ですので、在庫をさばくために値下げをする事情がありません。
本業も続けておりますので、生活のために売り急ぐこともありません。
価格を守るお約束は、そのままお守りできます。

私は普段、東京でタクシーの運転手をしております。毎日いろいろな方を乗せていると、
「買ったけれどすぐ駄目になった」という話をよく聞きます。その一方で、
良いものが知られないままになっているとも感じ、その間をつなぐ店をやりたいと考えました。

お取引の方針は下記に公開しております。
https://satoy-select.com/partners

つきましては、下記をお知らせいただけますでしょうか。

・卸価格（掛け率）
・最低発注ロット
・お支払い条件
・納期の目安

ご検討のほど、よろしくお願い申し上げます。

〔署名（§8）〕
```

## 3. ②メーカー側のメリットを強めた版

①との差分は**2箇所だけ**（「できること4つ」の挿入と、冒頭の理由の具体化）。全文を別に書き起こさず、①の差し替えで運用します。

**使う条件**：送る前に、そのメーカーの商品の Amazon ページを見て、**下の困りごとが実際に確認できたときだけ**。確認できていないのに「お困りではありませんか」と書くと、見当違いの営業になります。

| 画面で見える状態 | 相手の困りごと | 当店が出せる手 |
|---|---|---|
| 出品者が多く、価格が下がっている | 値崩れ・ブランドの毀損 | 価格を下げない。下回っていれば当店から値上げ調整 |
| 商品名・画像・説明が公式と違う | 情報の改変 | 公式情報を基準に整える。変更時は事前相談 |
| レビューの質問・低評価に返答がない | 販売後の手間 | 問い合わせ・レビュー・返品の一次対応は当店が引き受け |
| そもそも Amazon に出ていない | 販路がない／やり方が分からない | 出品・在庫・配送まで当店が担当。御社は卸すだけ |

**差し替え①：冒頭3行目の後に1文を足す**

```
〔商品名〕の Amazon のページを拝見したところ、〔見えた状態を1文。例：複数の出品者で価格が
分かれており、公式サイトの表記と商品名が異なっておりました〕。
差し出がましいのですが、この点で当店がお役に立てるのではないかと考え、ご連絡いたしました。
```

**差し替え②：「価格を守るお約束は〜」の段落の後に、できること4つを足す**

```
取引が始まりましたら、当店で以下をお引き受けします。

・価格を下げません。相場を下回っていれば、当店から値上げの調整をします
・商品名・画像・説明は御社の公式情報を基準に整えます。変更が必要なときは事前にご相談します
・お客様からのお問い合わせ、レビューへの返信、返品・交換の一次対応は当店が担当します
・毎月、どの型番がいくつ・いくらで売れたかを御社にご報告します

最後の販売状況のご報告は、御社が卸先からは受け取りにくい情報だと思います。
売れ筋の把握にお使いいただければ幸いです。
```

> **なぜ「月次の販売報告」を最後に置いたか**：4つのうち3つは「損をさせません」という守りの話で、相手にとっては当たり前の期待値です。**能動的に差し上げられるものは、卸先から返ってこない売れ方のデータだけ**。ここが①との本当の差分なので、最後に置いて1文だけ解説を付けました。

御社の〔商品名〕を仕入れさせていただきたく、ご連絡いたしました。

〔この商品のどこが良いと思ったか：1文〕

2026年8月に開業したばかりで、まだ販売実績はございません。
初回は10点程度・前払いで承りますので、御社にご負担はおかけしません。
販売価格は御社のご指定に従います。

卸価格・最低発注ロット・お支払い条件をお知らせいただけますでしょうか。
お取引の方針は https://satoy-select.com/partners に公開しております。

〔署名（§8）〕
```

> **原典との相違を1点、意図して入れています。** 中村の短文例は Amazon 販売に触れず、返信率を上げる代わりに後のやり取りで確認する作りです。本書の③は**「Amazon.co.jp で」を残しました**。理由は、社長が「Amazon 販売は正直に書く」を既定としているため（原典 Chapter 6-02 も、偽ると後の販売者限定化の交渉ができなくなると書いています）。省略は嘘ではありませんが、後から「実は Amazon です」と言う形になり、同じ不信を招きます。**短くするのは Amazon の説明であって、Amazon の事実ではない**、という切り分けです。

## 5. 使い分けと、期待する返信率

| 版 | どういうメーカーに使うか | 期待する返信率 |
|---|---|---|
| ①標準 | HP と問い合わせ窓口がある中小メーカー。主力。迷ったらこれ | 10〜15%（推測） |
| ②メリット強化 | 自社商品が既に Amazon にあり、値崩れ・情報の乱れ・無返答レビューが**画面で確認できた**メーカー | 15〜20%（推測）。返信の中身が濃くなる分、成約に近い |
| ③短文 | フォームの入力欄が短い／大企業の総合窓口／宛先が部署名しか分からない | 20〜25%（推測）。ただし条件の確認往復が2〜3回増える |

**数字の出どころ（事実と推測の分離）**

- **事実（原典）**：メールでの**成約**は30〜50社に1社（＝2〜3%）。電話は10社に1社（＝10%）。
- **事実（社内）**：`09_真似する計画_改訂.md` の置き値は成約率 2%／1.5%。
- **推測**：上表の「返信率」は原典にも社内にも実測がありません。成約率2〜3%から逆算した見当です（返信のうち条件が合って成約に至るのは1〜2割と置いた）。**最初の100通で実測に置き換えてください。**

**測る2つの数字**（原典 Chapter 7-04 が週次で報告させている項目のうち、当社に要るもの）

1. 送信数に対する返信率（版ごと・経路ごと）
2. 見積りが届いた社数／うち利益が出た社数

## 6. 断られたときの切り返し（4分類）

原典が「ここで差がつく」と強調する箇所です。理由は反直感的ですが明快で、**すぐ見積りが返ってくるメーカーはライバルも多い。一度断るメーカーはライバルが少ない**（断られるとすぐ引く人が多いため）。

> **原典は「切り返しはメールより電話のほうが気持ちが伝わる」と書いています。** 当社は現時点で電話番号が未取得のため、ここではメール文面を主に置き、電話が使えるようになったら同じ内容を口頭で言う想定です（`11_050番号の料金と運用.md`）。
>
> **ここから先の返信は §4.1 です。** 条件・価格に触れるため、1通ごとに社長承認をいただいてから送ります。

### 6-1.「Amazon 販売・オンライン販売はお断りしています」→ **粘る価値あり（最重要）**

原典の見立て：既に販売者を限定済みなら難しいが、**理由が「何となく怖い」「価格破壊が起きやすい」「ブランドイメージが落ちる」と曖昧ならチャンス**。

```
ご検討いただき、ありがとうございました。

差し支えなければ、1点だけ教えていただけますでしょうか。
Amazon での販売をお断りされているのは、価格が崩れることへのご懸念でしょうか。
それとも、すでに販売される方を限定しておられるということでしょうか。

前者でしたら、当店でお役に立てるかもしれません。
Amazon で価格が崩れるのには決まった原因がいくつかあり、それを起こさない売り方があります。
当店はまだ1点も商品を並べておらず、値下げで数を稼ぐ必要がありません。
御社がご指定される価格をそのまま守れる立場にあります。

すでに限定しておられるのであれば、無理にお願いするつもりはございません。
そのときは、その旨だけお知らせいただければ、以後ご連絡は控えます。
```

> **なぜ「理由を聞く」から入るか**：いきなり反論すると押し売りになります。原典も「まず理由を再確認する」としています。**二択で聞くのは、相手が1行で返せるようにするため。**
> **なぜ最後に引き際を置くか**：逃げ道を示した相手のほうが答えやすく、「限定済み」という貴重な情報が取れます。取れれば以後その社に送らずに済みます。
> **価格崩壊の詳細をここで書かない理由**：原典 Chapter 7-03「詳細な説明は相手が興味を持って質問してきたときに。一方的に話すのは逆効果」。**質問が返ってきてから初めて中身を出します。**

### 6-2.「実店舗がないとお取引できません」→ **1往復だけして、引く**

原典の見立て：かなり厳しい。**実店舗や卸業者だと偽って黙って Amazon で売るのは論外**。粘るより「価格を守って販売する方法がある」と伝えたほうがよい。

```
ご事情を承知いたしました。ご検討いただきありがとうございました。

1点だけ申し添えます。
店舗をお持ちの販売先をご指定なさっているのは、販売価格や売り方を管理できることが
理由ではないかと拝察いたします。
当店は Amazon の1店舗のみで、御社のご指定価格を守って販売いたします。
もし将来ご方針が変わることがございましたら、そのときにまたご相談させてください。

今後ともよろしくお願い申し上げます。
```

> **1往復で引く**と決めているのは、この分類の成功確率が低く、粘ると印象だけ悪くなるからです。**「将来方針が変わったら」で終えるのは、名簿に残す作法**。半年後に再送する候補になります。

### 6-3.「現在、新規のお取引先は募集しておりません」→ **理由で分岐。時期を聞く**

原典の見立て：限定化済みなら難しい。**生産が追いついていない等の理由なら、様子を見て再アプローチ**。

```
承知いたしました。ご返信いただきありがとうございます。

差し支えなければ、1点だけ教えていただけますでしょうか。
お取引先を限定されているということでしょうか。それとも、生産の状況などにより
一時的に見合わせておられるということでしょうか。

後者でしたら、時期を改めてご相談させていただければと思います。
「このころにまた」という目安がございましたら、それに合わせてご連絡いたします。

今後ともよろしくお願い申し上げます。
```

> **「一時的ですか」という逃げ道を先に用意する**のがこの文の要点です。断る側は理由を細かく説明したくありません。二択にすれば1語で返せます。
> **運用**：「一時的」の返答が来たら、再送予定日をメーカーリストに記入。目安が無ければ**6ヶ月後**に置きます。

### 6-4.「法人でないとお取引できません」→ **押さない。名簿に残して終わる**

原典の見立て：**「国内メーカー直取引は法人でないとできない」は大きな誤解で、個人事業主でも応じるメーカーは多数ある**。ただし稀にこう言うメーカーがあるのも事実で、その場合は法人化後に再アプローチ。

```
承知いたしました。ご検討いただきありがとうございました。

当方は個人事業主で、2026年8月に開業届を提出しております。
法人化は今後の売上の状況を見ながら判断してまいります。
その際には、あらためてご相談させていただければ幸いです。

今後ともよろしくお願い申し上げます。
```

> **反論しない**理由：これは相手の社内規程であることが多く、担当者に裁量がありません。ここで粘ると、法人化後に再訪したときの心証まで悪くします。
> **「開業届を提出しております」の1行**は、事業者であることの裏付けとして入れています（e-Tax 受信通知あり）。ただし提出を求められたら §4.1（機密情報の外部送信）なので、社長の承認を取ってからお送りします。

## 7. 見積りで利益が出ないときの返し（3切り口）

原典 Chapter 8-05。**10社中1社でも通れば勝ち**（他の人はすぐ諦めるので、ここで差別化できる）。実例では切り返し1つで6掛けが5掛けになったケースがあります。

**3つを1通に全部入れないでください。** 3つ並べると値切りの詰問になります。**①＋②**か、**②＋③**の2つまで。

| 切り口 | 中身 | いつ使うか |
|---|---|---|
| ① 数量を増やしたときの掛け率 | 最初の見積りが7〜8掛けなら、1個単位の条件を提示されている可能性がある | 見積りの掛け率が明らかに高いとき |
| ② 正直に「これでは利益が出ない」と言う | ＋長期取引での改善余地／既存の Amazon 出品者と同条件にする道はあるか | 基本。どの場面でも使える |
| ③ 小売と卸で掛け率が違うか | 商流上、卸業者のほうが掛け率は良い。小売6掛け・卸5掛けと分けているメーカーは実在する | 相手が卸問屋も持っているとき |

**文面（②＋①）**

```
お見積りをお送りいただき、ありがとうございました。

正直に申し上げます。いただいた条件ですと、Amazon の手数料を差し引いたあとに
利益が残らず、このままではお取引を始められない状況です。
御社の商品はぜひ扱わせていただきたいので、条件について3点だけ伺わせてください。

・発注数量を増やした場合、掛け率は変わりますでしょうか
・最初は小さく始めさせていただき、売れ行きを見ながら数量を増やしてまいります。
　継続的にお取引させていただく中で、卸値をご相談できる余地はございますでしょうか
・現在 Amazon で御社商品を販売されている方がいらっしゃいますが、
　その方々と同じ条件にしていただくには、何が必要でしょうか

## 10. なぜこの表現にしたか（設計意図）

**① 出品0件を、文の「弱点」ではなく「構造」に置いた。**
これが本書でいちばん難しいところでした。取れた解は、事実→条件→意味の3段です。

1. 事実：「まだ1点も商品が並んでいません」（ぼかさない。「開店準備中」は逃げ）
2. 条件：初回10点・前払い・価格は御社指定（相手の損失をゼロにする）
3. 意味：「何も抱えていない店ですので、在庫をさばくために値下げをする事情がありません」

3が無ければ、ただの実績ゼロの申告で終わります。**「何も持っていない」を「値下げの動機がない」に読み替える**ことで、初めて相手の関心事（価格が崩れること）に接続します。

**② タクシードライバーを「人柄の話」で終わらせなかった。**
原典は強み（経験・職業・資格）を書けと言いますが、職業を書いただけでは自己紹介です。**本業があること＝生活費を物販に依存していない＝投げ売りしない**、という因果でつないで、①の「値下げの動機がない」を二重に支える位置に置きました。ここは当社固有の材料で、他のセラーには書けません。

**③ 5つのお約束を本文に書かず、URL に逃がした。**
`https://satoy-select.com/partners` には既に5項目が公開されています。**本文で宣言するより、送る前から公開されていた事実のほうが強い**（先に書いたものは後から都合よく変えられないため）。本文が長くなる問題も同時に解けます。

**④ 価格崩壊の対策は「ある」とだけ書いた。**
原典の指示（一方的に話すのは逆効果）に従いました。これは駆け引きではなく、**相手が質問してきた＝その困りごとが実在する**という選別にもなります。

**⑤ 「実績があります」「専門家です」と書かない。**
原典は「Amazon 販売の専門家であること」を伝えよとしていますが、**当社はまだ1点も売っていないので、そう名乗ると虚偽になります**。代わりに「価格が崩れる原因と、それを起こさない売り方を知っている」という、実績に依存しない言い方に置き換えました。

**⑥ 分量は機械で数えました（宛名・署名・差し込み欄を除いた本文の実測値）**

| 版 | 実測 |
|---|---|
| ①標準版 | **785字** |
| ②メリット強化版 | **1,088字**（①＋差し替え303字） |
| ③短文版 | **258字** |
| 署名（全通共通） | 213字 |

原典は「長文になり過ぎるとNG」としており、**①は正直に申し上げて上限ぎりぎり、②は超えています。** ②を「画面で困りごとが確認できた相手だけ」に限っているのは、この長さを相手が読む動機がある場合に限定するためです。

**入力欄に制限があるときや、短くしたいときの削る順**（上から削る）

1. タクシーの段落（人柄の話。削っても条件の提示は壊れない）
2. 「お取引の方針は下記に公開しております」の1文（URL は署名にも入っているため）
3. 「はじめに、正直に申し上げたいことが2つございます」の前置き（本題に直結させる）
4. 「Amazon での販売をご懸念なさるメーカー様が多いことは承知しております」の1文

**削らないもの**：Amazon であることの開示／出品0件の開示／ロット・支払い・価格の3行／署名。**「はい」と言える材料そのもの**だからです。1〜4を全部削ると①は約480字になり、③短文版との中間の長さになります。
