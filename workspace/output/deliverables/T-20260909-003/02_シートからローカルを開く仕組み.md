# シートのセルからローカルの実ファイルを開く仕組み

T-20260909-003 / 2026-09-09 / IT タカシ

社長の指示「今まで通りスプレッドシートで運用。HTML は不要。シート内にリンクを設け、
ローカルのファイルを叩くようにして下さい」を実装したものです。

## 何がどう変わったか

| | 前 | 後 |
|---|---|---|
| 社長の入口 | HTML 版カタログ（`00_成果物カタログ.html`） | **Google スプレッドシート**（従来どおり） |
| リンク | `file://…`（HTML 内） | `=HYPERLINK("http://localhost:17325/…","<ファイル名>")` |
| 開くもの | ローカルの実ファイル | **ローカルの実ファイル**（同じ。経由が変わっただけ） |
| HTML 版 | 毎回生成 | **既定で生成しない**（ファイルは残置。`--html` で復活） |

## なぜサーバを挟むのか

Google スプレッドシートのハイパーリンクは `file://` を開けません。
`=HYPERLINK("file:///Users/…")` は無効扱いになり、通ってもブラウザ側が遮断します。
そこで **127.0.0.1 にだけ bind した小さな HTTP サーバ**を常駐させ、
`http://localhost:17325/<相対パス>` で `deliverables/` の実ファイルを返します。

社長から見た体験は「シートのセルを押すと資料が開く」で、開いているのはローカルの実体です。
ネットワークには一切出ません。

## 使い方（社長）

1. `/amazon_buppan_catalog` でカタログのシートを開く。
2. 「ローカルリンク」列のセルを押す。資料がブラウザで開く（CSV は保存される）。

リンクが反応しないときは、配信サーバが止まっています。以下の自動起動を入れるとこの状態が
起きなくなります。

## 安全側の作り

| 守り | 実装 |
|---|---|
| LAN に出さない | `127.0.0.1` にのみ bind。実測で LAN IP からは接続不可 |
| 配信ルートより上を出さない | `..` 除去＋最終 `realpath` の境界チェック。外を指すシンボリックリンクは 403（実測） |
| 書き込ませない | GET / HEAD のみ |
| インデックスさせない | `X-Robots-Tag: noindex, nofollow` |

配信するのは `workspace/output/deliverables/` の中だけです。リポジトリの他の場所、
`.env`、`CLAUDE.md` などは配信されません（実測で 404 / 403）。
