## 1. 結論（先に4つ）

### ① 公式HP探索は自動化できます。塞がっていません

Google Custom Search JSON API は新規受付停止、Bing Search API は2025-08-11で廃止済み。ですが **Google の正規代替が存在します。**

> **最有力：Gemini API の「Grounding with Google Search」。Gemini 3.x モデルで月5,000リクエストが無料。822社は無料枠に完全に収まります。**
> Google 自身が提供する正規APIで、検索結果のスクレイピングではありません。カード登録も不要（無料枠のみ利用の場合）。

次点として Serper.dev（2,500クエリ無料・カード不要）、Tavily（月1,000クレジット無料・カード不要）があります。詳細は §5-2。

### ② 和名293社と英字526社は、まったく別の問題です

和名側は公的DB（国税庁・gBizINFO）が主戦力。英字側は商号検索なので**原理的に効きません**。

### ③ 英字526社のうち、日本の実体を示すシグナルがあるのは実測145社（27.6%）

残り381社（72.4%）はシグナルゼロ。**この判別は0円・追加申請なしで、すでに手元にあるデータだけで付けられます**（§4）。

### ④ 381社は「取れない」と結論づけるのが合理的です

Amazon経路（出品者の特商法表記・ブランドストア）がハルオの判定で**使用不可**になったため、日本法人を持たない中国系ブランドを辿る道が消えました。深追いしても交渉相手には行き着きません。

**推奨構成の実費：0円。社長の手が要る申請は2件（gBizINFOトークン、Gemini APIキー）。**

## 3. ハルオの判定で消えた道と、その影響

## 4. 英字526社を「日本の実体があるか」で機械的に分ける方法【実測】

タカシの論点「`DUNLOP`（日本法人）と `Gudluky`（中国系）を名前だけでは分けられない」への回答です。
**名前では分けられませんが、名前以外の4つの信号で分けられます。全部0円・手元のデータで完結します。**

### 4-1. 4つの判別信号と、実際に何社に立ったか（N=526）

| # | 信号 | 何を意味するか | 立った社数 | 取得元・費用 |
|---|---|---|---:|---|
| ① | EAN先頭が 45/49（JANコード） | **GS1 Japan が採番＝日本の事業者が登録している** | **91** | Keepa 生データ（取得済み・0円） |
| ② | 推測ドメインが `.jp` / `.co.jp` | 日本向けサイトを持つ | 23 | HTTP実測（0円） |
| ③ | サイトのタイトルに日本語 | 日本語で商売している | 40 | HTTP実測（0円） |
| ④ | Keepa の `manufacturer` に日本語が入る | Amazon上の製造元表記が日本語（例 `ダンロップ(DUNLOP)`、`角川書店`） | **77**（うち法人格つき13） | Keepa 生データ（取得済み・0円） |
| — | **①〜④のいずれか＝「日本シグナルあり」** | — | **145（27.6%）** | **0円** |
| — | **シグナルゼロ** | — | **381（72.4%）** | — |

信号の重なり：JAN∩日本語サイト=17、JANのみ=74、日本語サイトのみ=29、**④だけで拾えた社=25**（`KODAK` `SanDisk` `NETGEAR` `KÄRCHER` `NGK` `Bosch` `INTEX` `LxTek` など）。④は単独で25社を追加しており、入れる価値があります。

### 4-2. この判別の精度（正直に）

- **偽陰性が出ます。** 確認例：`Anker` は EAN が `0194644...`（米国UPC）、サイトは英語 `anker.com` のためシグナルゼロ判定になりますが、アンカー・ジャパン株式会社が実在します。
- **偽陽性は少ない**と見ています（推測・確度中）。JAN 45/49 は GS1 Japan への登録が前提で、日本に登録者がいることの直接証拠だからです。
- **よってこの判別は「足切り」ではなく「優先順位づけ」に使ってください。** シグナルあり145社を先に処理し、シグナルゼロ381社は抽出調査に留めるのが実務的です。

> 出力済み：`agent_output/T-20260831-001/英字ブランド_日本シグナル.csv`（526社 × 4信号 × 推測ドメイン × manufacturer例）

### 4-3. 実測：ブランド名からのドメイン推測は何%当たるか

推測ではなく実際に走らせた結果です（実施日 2026-08-31）。

- 対象：英字526社のうち英数字化して3〜25文字になった **517社**
- 方法：`<brand>.com` → `.jp` → `.co.jp` の順に DNS 解決 → GET し、HTTP<400 をヒットとする（各ホスト1回のみアクセス）

| 段階 | 社数 | 率 |
|---|---:|---:|
| 試行 | 517 | 100% |
| ①いずれかのTLDで生きているサイトに到達 | **321** | 62.1% |
| ②ページ本文/タイトルにブランド名が出現（無関係サイトを除外） | **237** | 45.8% |
| ③うち `.jp` / `.co.jp` | 23 | 4.4% |
| ③うち ページタイトルに日本語 | 40 | 7.7% |
| 参考：ドメインパーキング疑い（売却文言を検出） | 34 | — |

> **事実：英字ブランドの公式HPは0円で237社ぶん候補が出せる。ただし日本語サイトはそのうち40社だけ。**
> **推測（確度：高／根拠＝上記TLD・言語の実測）：残り197社は海外本社サイトで、日本語での仕入れ交渉窓口ではありません。**

## 10. Phase C（ITエンジニア タカシ）への申し送り

実装の順序はこれを推奨します。**最初の2つは「実測して数字を確定させる」タスクで、機能実装ではありません。**

1. **gBizINFO 基本情報の一括CSVを落として `company_url` の非空率を数える。** この数字が Step J-2 の価値を決めます
2. **国税庁 全件データ（全国CSV Unicode / 254MB）を落として、和名293社の実マッチ率を数える。** 完全一致・法人格除去後の前方一致・部分一致の3方式で比較
3. **英字526社の日本シグナルは計算済み。** `英字ブランド_日本シグナル.csv` を取り込めば、シグナルあり145社を優先処理できます
4. **ドメイン推測の237社は公式HP列の初期値にそのまま使えます**（`domain_verify_result.csv`）
5. **公式サイトの取得はハルオ条件を守ること**：robots.txt尊重・**同一ホスト3秒間隔**・UA明示・会社概要/問い合わせ系ページ限定。822ホストは互いに別ホストなので、ホスト単位のキューを並列に回せば3秒間隔でも実時間は伸びません
6. 冪等・再開可能・出典URL必須のスキーマは、チケット本文の「連絡先列の定義」に従ってください
