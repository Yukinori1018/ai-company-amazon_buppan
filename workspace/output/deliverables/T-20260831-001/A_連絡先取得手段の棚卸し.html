1. 結論（先に4つ）

① 公式HP探索は自動化できます。塞がっていません

Google Custom Search JSON API は新規受付停止、Bing Search API は2025-08-11で廃止済み。ですが Google の正規代替が存在します。

最有力：Gemini API の「Grounding with Google Search」。Gemini 3.x モデルで月5,000リクエストが無料。822社は無料枠に完全に収まります。
Google 自身が提供する正規APIで、検索結果のスクレイピングではありません。カード登録も不要（無料枠のみ利用の場合）。

次点として Serper.dev（2,500クエリ無料・カード不要）、Tavily（月1,000クレジット無料・カード不要）があります。詳細は §5-2。

② 和名293社と英字526社は、まったく別の問題です

和名側は公的DB（国税庁・gBizINFO）が主戦力。英字側は商号検索なので原理的に効きません。

③ 英字526社のうち、日本の実体を示すシグナルがあるのは実測145社（27.6%）

残り381社（72.4%）はシグナルゼロ。この判別は0円・追加申請なしで、すでに手元にあるデータだけで付けられます（§4）。

④ 381社は「取れない」と結論づけるのが合理的です

Amazon経路（出品者の特商法表記・ブランドストア）がハルオの判定で使用不可になったため、日本法人を持たない中国系ブランドを辿る道が消えました。深追いしても交渉相手には行き着きません。

推奨構成の実費：0円。社長の手が要る申請は2件（gBizINFOトークン、Gemini APIキー）。

10. Phase C（ITエンジニア タカシ）への申し送り

実装の順序はこれを推奨します。最初の2つは「実測して数字を確定させる」タスクで、機能実装ではありません。

  1. gBizINFO 基本情報の一括CSVを落として company_url の非空率を数える。 この数字が Step J-2 の価値を決めます

  3. 英字526社の日本シグナルは計算済み。 英字ブランド_日本シグナル.csv を取り込めば、シグナルあり145社を優先処理できます
