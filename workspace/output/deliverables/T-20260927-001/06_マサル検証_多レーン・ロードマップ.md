## 2. 「1接触3オファー」は追加時間ゼロか

### 2-1. 結論

| 論点 | 判定 |
|---|---|
| 各オファーの成約率は下がるか | **下がる。**1通1CTA が原則で、3択は焦点がぼける。**返信率に 0.55/0.78/0.95 倍（三角）を置いた**（推定・観測ゼロ・実測日 2026-11-30＝累計700通時点） |

| 返信後の工数は3倍になるか | **送信は共通・後工程は共通化不可。**見積（仕入れ45分）／提案書（代行120分）／ヒアリング＋要件定義（受託180分）は別物。**タケシは織り込んでいない**（05 §2 は「追加時間0」と明記） |
| 後工程を入れるといくら動くか | **中央 −12万**（G0 69.5万 → G2 46.9万 のうち後工程分）。**希釈と同じ重さ** |
| 同じ名簿を3回使うのか | 05 は「1回で3つ提示」なので**名簿の劣化は3倍速にならない**。ここはタケシの設計が正しい。ただし**1通あたりの情報量が3倍になり、個社研究（「御社のどの手作業を止めるか」）が要る**ので、送信工数が 7分/通 → 9分/通に増える |

**うちが1通に3つ載せる → 相手（メーカー）は「何をしに来た人か」を判断できず、最も安全な「見積だけ取る」を選ぶ → 当社は見積を作る（無料の労働）→ 実績ゼロなので失注 → 名簿は消費済み。**
