法務判定：自社出品商品を自分の Amazon アソシエイトリンクで紹介する行為

  • 判定者：法務ハルオ／チケット T-20260927-001
  • 確認日：2026-09-27（一次資料の実読日。規約は随時改定されるため、実行直前に再確認すること）
  • 対象：Satoy Select（個人事業主）が Amazon セラーとして出品中の商品を、自社の Amazon アソシエイトリンクで第三者に紹介し紹介料を得る行為

1. 結論（1行）

条件付き可。 アソシエイト規約に「自社出品商品を紹介してはならない」という明文の禁止は存在しない（一次確認済み）。ただし §4 の4条件の全充足が必要で、うち1つは景品表示法（ステマ規制）上の法的義務である。なお事業判断としては非推奨（§6）。

A参加要件 6(u)「乙は、乙自身の使用またはその他の個人もしくは企業の使用が目的であるかを問わず、特別リンクを経由して直接または間接的に商品を購入したり…してはなりません。乙は、乙の友人、親類もしくは従業員、請負業者または事業関係による利用…のために…商品を購入することを許可、要請または奨励してはなりません。また、乙は、特別リンクを通じた商品の購入もしくは再販売もしくは（あらゆる種類の）商業用途のためにメンバー紹介イベント行為の実施、または再販売もしくは（あらゆる種類の）商業的利用のための乙のサイトでの商品提供をしてはなりません。」禁止の射程は購入者側（誰が・何の目的で買うか）。「自分が売主である商品を紹介すること」自体は射程外。ただし取引先・仕入先・外注先に自リンクで買わせるのは明確に違反（「事業関係」に該当）

3. 日本法：ここが最大の見落としポイント

根拠景品表示法 第5条第3号 ＋ 内閣府告示第19号「一般消費者が事業者の表示であることを判別することが困難である表示」。2023-10-01 施行。出典：消費者庁ステルスマーケティング特設ページ（2026-09-27 確認）
なぜ効くか他社商品の紹介なら当社は「第三者」だが、自社出品商品では当社が「供給する事業者」本人。自分のメディアで自社商品を薦める表示は、そのままでは「事業者の表示であることが判別困難な表示」に当たる
必要な開示「Amazonアソシエイトです」の開示だけでは不足。「この商品は当店（Satoy Select）が販売しています」＝自らが売主である旨の明示が別途必要
規制対象措置命令の対象は事業者（＝当社）。インフルエンサー側は対象外。つまり自社出品の紹介は当社が直接の名宛人になる

4. 「条件付き可」の条件（全て必須。1つでも欠けたら不可）

#条件根拠
1自らが販売者である旨を表示内に明示する（「当店が販売」等）。アソシエイト表記とは別に行う景表法5条3号／告示19号
2Amazon 内（商品ページ・プロフィール・同梱物・Amazon 経由の連絡）に自リンクを一切置かない。導線は「自社メディア → Amazon」の一方向のみ参加要件 2(b)
3自己・家族・友人・従業員・外注先・仕入先・取引先が自リンク経由で購入する事態をゼロにする（家族に URL を教えない運用まで含む）参加要件 6(u)／ヘルプ I
4インセンティブを付けない／オフライン販促に使わない／メール・DM はオプトイン相手のみ参加要件 6(g)・4

付随して守るもの：カスタマーレビュー・星評価の転載不可（6(t)）／価格追跡・価格アラート機能をサイトに持たせない（6(y)）／Amazon 外で売られる商品の宣伝にプログラム・コンテンツを使わない（6(z)）／価格・在庫の表示はリンクまたは Creators API 経由のみ（2(b)）。

6. アカウント停止に至る経路（発生確率 × 影響度 × 不可逆性）

経路内容確率影響不可逆性判定
①アソシエイト側の閉鎖参加要件違反 → 紹介料の留保・没収＋アカウント閉鎖。「違反または悪用に基づき解除された場合、事前承認なく再参加できない」（参加要件1）中小（紹介料は数%）中〜高（再参加は Amazon の事前承認制）許容可
②セラー側の停止（間接）アソシエイト違反がセラーアカウントの停止事由になる旨の明文は一次資料で未確認（サービスビジネスソリューション契約は JS／ログイン必須で本判定時点では実読できず＝未確認）。ただし両アカウントは同一本人・同一銀行口座で紐づくため、「違反により閉鎖」の記録が関連アカウント評価に乗る可能性は否定できない（推測）低甚大（本事業の停止）高社長の停止歴を踏まえ、確率が低くてもアラート対象
③外部からの送客そのもの外部 → Amazon への送客は Amazon 自身が推奨（Amazon Attribution）。これ自体は違反ではない———問題なし
④景表法違反消費者庁の措置命令（事業者名公表）。課徴金の対象は優良誤認・有利誤認のみで3号は対象外だが、公表の信用毀損は不可逆低〜中中高条件1で回避
②が本件の実質的な争点です。 得られるのは紹介料（標準料率は数%）にすぎず、失いうるのはセラーアカウントです。期待値ではなく不可逆性で判断すべき局面であり、私は §7 の代替案を推します。

9. 秘書カズヨへの申し送り

  • 社長判断が必要なのは A / B / E のどれを採るか の1点のみ。私の推奨は A＋B の併用（自社出品は素リンク、他社商品でアソシエイト）。これなら規約論点が消え、収益設計上の「自分のメディアから自分の商品へ送客する」導線は完全に維持できる。
  • E（自社商品×アソシエイト）を採っても増える収入は紹介料の数%です。 販売利益が満額入る A と比べた差分は小さく、対価としてセラーアカウントの不可逆リスクを負う構造になります。
  • 条件1（売主である旨の明示）は A・B・E のどれを選んでも必要です。景表法は規約とは別に効きます。
