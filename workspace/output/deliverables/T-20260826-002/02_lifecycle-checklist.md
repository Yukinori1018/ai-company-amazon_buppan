- [ ] 回転の目安を**ランク上限30万位・月間ドロップ数 ≥10**に置く（ランクでは足切りせず、ドロップ数で切る） `[AI]`

- [ ] ⚠️ **Amazon本体が出品している商品は除外**する（取得率ではなく在／不在で切る。判定は `availabilityAmazon = -1`） `[AI]`

### 3-4. 利益計算の型（推定と実測を分離する）

> 社長フィードバック「仕入れ値・送料・経費が推定で不正確＝最大のボトルネック」に直接対応する節。

- [ ] ⚠️ 計算シートの各費目に **`実測` / `推定`** のフラグ列を持たせる。混ぜない `[AI]`
- [ ] 引く費目を全部並べる：**販売手数料 ＋ FBA配送代行 ＋ FBA保管 ＋ 出品プラン料 ＋ 仕入原価 ＋ 仕入送料 ＋ FBA納品送料 ＋ 納品代行費 ＋ 広告費 ＋ 消費税**（冷凍食品は**1点あたり税込375円**を加算） `[AI]`
- [ ] 概算段階は**経費割合35%**（販売手数料＋FBA送料＋納品送料）で足切りする。ただしこれは**推定であって実測ではない** `[AI]`
- [ ] 発注確定前に、**仕入値・仕入送料は見積書の実額**に、**手数料はFBA料金シミュレーターの実額**に差し替える `[社長+AI]`
- [ ] ROS・ROI を両方出す（**ROS＝利益÷売上 / ROI＝利益÷仕入価格**）。片方だけで判断しない `[AI]`
- [ ] ⚠️ **販売手数料の課税ベースは「商品価格＋配送料＋ギフト包装料＋税の合計」**。商品価格だけに率を掛けると過小見積りになる `[AI]`

- [ ] ⚠️ 出品制限は**機械（Keepa等）で事前除外できない**。ブランド制限リストは**Amazonが非公開と明言**している。1件ずつ実機確認する `[AI]`

- [ ] ⚠️ **発注前にワンクリック解除を試す**（在庫ゼロでも押せる・無料・即時）。ここが順序リスクの防波堤 `[社長]`
- [ ] 危険物該当をチェックする。**リチウム電池含有・液体（化粧品/アルコール/スプレー）・可燃/加圧ガス**。該当は SDS・UN番号が要る `[AI]`
- [ ] 知財リスクを見る（並行輸入・ブランド品・キャラクター意匠）。**知財侵害は180日以内5回で即停止**、**制限商品/出品規約違反は180日以内2回で即停止** `[AI]`

## ここから先はタケシ（プランナー）の領分です

このリストは「やるべきことの全量」であり、**実行順序・優先度・どこに資源を割くかは戦略判断**です。以下は事実として残しておく論点だけ挙げます。

1. **小口 → 大口の切替タイミング** — 損益分岐は月49点だが、カート・広告・一括出品・出品制限申請が全て大口限定。「49点を超えたら」で待つと、カートが取れず49点に届かない循環に入る可能性がある（事実：購入の約8割がカート経由）。
2. **出品制限ありブランドを狙うかどうか** — 当社は書類の質で有利（メーカー直取引）だが、初回ロット10点以上が要り、EC STARs 流の「初回5個」と衝突する（4-2）。
3. **FBA一択にするか、FBMを混ぜるか** — FBAならAHRの3指標が構造的にクリアされる。FBMを1SKUでも混ぜた瞬間にVTR・出荷遅延率・キャンセル率の監視義務が発生する（8-4）。
4. **2027年分からの消費税** — 2割特例が令和8年9月30日を含む課税期間で終わる。売上規模の見通しと合わせて本則/簡易を選ぶ必要がある（8-6）。
