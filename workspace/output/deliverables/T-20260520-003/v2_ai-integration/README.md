## サトル所見（事実から見える論点の核）

事実ベースで3点。**戦略判断はしません**。

1. **SP-API 自社利用は2026年以降も無料継続**。第三者向け開発のみ年$1,400 USD 課金。Sato-Scope が「社長自身のセラーアカウント向け自社ツール」である限り、課金対象外（一次情報：Amazon 公式発表 2025-11-03）。これは仮説 A を**事実として支持する**強い材料。
2. **Keepa / SellerSprite は API 公開済み**、Sato-Scope に直接データ流入可能。一方 **アマサーチには公式 API がなく**、ERESA / MonoTracer 経由か拡張機能の目視に限定。AI 連携前提では**アマサーチの相対優位性は下がる**。
3. **Amazon 公式の Generative AI（Enhance My Listing / 商品説明自動生成）が無料で出品者に提供されている**一方、**「AI が勝手に商品説明を盛る」事故**が2026年に報道された。**人間検品工程**は AI 連携の前提として不可避＝「AI で代替できない作業」が確かに存在する。

詳しい論点（A/B/C 素材）は [05_issues-for-decision.md](05_issues-for-decision.md) を参照。
