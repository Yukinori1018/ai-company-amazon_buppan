# 01. Keepa（キーパ）

## 一行説明

Amazon の **価格・在庫・売れ筋ランキングの履歴**をすべて記録・グラフ化する、物販リサーチの事実上のインフラ。世界中のセラーが「Keepa は必須」と評する標準ツール。

## 開発元・所在

- 開発：Keepa GmbH（ドイツ）
- 公式：https://keepa.com
- 設立：2010年頃〜
- ビジネスモデル：サブスクリプション＋API販売

## 用途（Amazon物販のどこで使うか）

- **仕入れ判断前**：候補商品の過去価格・在庫・ランキング推移を確認 → 「いつでも売れるか／値崩れリスクはあるか」を判断
- **競合分析**：上位セラーの出品履歴・カートボックス獲得率を観察
- **市場サイズ推定**：ランキング推移から月販売数を概算（プロ推定機能）
- **アラート設定**：特定商品の価格が指定値を下回ったら通知

## できること（主要機能）

| 機能 | 説明 |
|---|---|
| **価格履歴グラフ** | 新品／中古／Amazon直販／カートボックス価格を最大5年分グラフ表示 |
| **ランキング履歴** | カテゴリランキング推移＝ざっくり売れ筋判定 |
| **販売数推定（Sales Estimator）** | ランキングから月販売数を推定（精度はカテゴリ依存） |
| **オファー履歴** | 出品セラー数・最安値の推移 |
| **アラート機能** | 価格・在庫・新品中古・特定セラー出品を通知（Email/Telegram/RSS） |
| **データテーブル** | カテゴリ別の売れ筋商品リスト（CSV エクスポート可） |
| **Product Finder** | フィルタ条件で商品検索（売れ筋 ASIN リストの抽出） |
| **API** | 自社ツール開発向け（要 Tokens 購入） |
| **ブラウザ拡張機能** | Chrome/Firefox/Edge で Amazon 商品ページに直接グラフ表示 |

## 料金プラン（2026年1月時点）

| プラン | 月額 | 年額 | 主な制限 |
|---|---|---|---|
| **無料（拡張機能のみ）** | 0円 | 0円 | 価格履歴グラフのみ。販売数推定・データテーブル・Product Finder は使えない |
| **Premium** | €19/月（≒¥3,000）| €189/年（≒¥30,000、≒¥2,500/月） | フル機能 |
| **API（Tokens）** | 都度購入 | — | 1回のクエリで Token を消費。月数千円〜数万円規模で運用可 |

**為替注意**：€1 ≒ ¥165（2026年初時点）。クレジットカード決済時の為替・手数料込みでやや高めになる。

## 無料代替

- **Keepa の拡張機能だけ** — 価格履歴グラフだけなら無料。販売数推定が要らない、目視で判断できる商品ならこれで十分
- **DELTA tracer / ERESA**（後述）— 日本特化、無料プランあり。Keepa よりは精度・データ網羅で劣るが入門用には足りる

## 国内Amazon（amazon.co.jp）対応

- **対応：◯** — JP マーケット完全対応。グローバル標準なので JP セラーの大半が利用
- **日本語UI**：あり（限定的。一部英語のまま）
- **JP特有のデータ**：価格・ランキングは完全に取れる。一部「日本でしか使わない指標」（中古せどり関連）は他ツールが上回ることも

## 学習コスト目安

- **拡張機能のグラフ読み**：30分で読めるようになる
- **販売数推定・Product Finder**：3〜5時間で実用レベル
- **API 連携・データテーブル深掘り**：1週間〜（プログラミング知識があれば）

## 法務・運用上の留意点（ハルオ向け）

- **データ取得元**：Amazon の公開データを Keepa が独自にクロール・蓄積。Amazon 公式の API ではない
  - リスク：Amazon が Keepa のクロールを制限する可能性は理論上ある（過去に他社で前例あり）。ただし Keepa は10年以上運営されており現状安定
- **規約**：欧州GDPR 準拠の事業者
- **データ可搬性**：CSV エクスポート可能。撤退時のロックインは小さい

## カズヨ所見

Amazon物販でこれを使わない選択肢はほぼない、というレベルの標準装備。€19/月（≒¥3,000）は許容範囲。**最初に導入するなら Keepa の Premium 一択**で異論は少ない。

ただし**「軸B 1周（実際に1商品仕入れて売る）を経験する前に契約しても、グラフを読む経験値がなく宝の持ち腐れになる」**点は留意（マサルに仮想 PDCA で評価させたい論点）。
