## 個票の共通項目

各ツールについて以下を整理しました：

- **一行説明** — どんなツールか30秒で分かる要約
- **用途** — Amazon物販のどのフェーズで使うか
- **できること（主要機能）** — 機能リスト
- **料金プラン** — 円換算込み（為替は調査時点）
- **無料代替** — 同等機能の無料／低額代替
- **国内Amazon（amazon.co.jp）対応** — JPセラーが実用できるか
- **学習コスト目安** — 使いこなすまでの時間
- **法務・運用上の留意点** — 規約・データ提供元のリスク（ハルオへの引き継ぎ事項）
