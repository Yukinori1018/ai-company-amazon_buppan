# 06. Helium 10（ヘリウムテン）

## 一行説明

Amazon セラー向け**オールインワン総合ツールの世界最大手**。リサーチ／キーワード／在庫／PPC／逆引き／AI ライティングまで30+モジュールを統合し、米国 Amazon を主戦場とするブランドオーナー / FBA セラーが標準採用。

## 開発元・所在

- 開発：Helium 10 Inc.（米国 Irvine, CA）／親会社 Assembly Inc.
- 公式：https://www.helium10.com/
- 日本語サイト：https://www.helium10.com/ja/（日本語UIあり・サポートは英語/チャット中心）
- ビジネスモデル：サブスクリプション（無料／Starter／Platinum／Diamond）+ アドオン
- データ源：自社クロール+Amazon 公開データ+SP-API 連携

## 用途（Amazon物販のどこで使うか）

- **市場リサーチ**：Black Box で商品アイデアを月販売数・売上・競合数から逆引き探索
- **キーワードリサーチ**：Cerebro（競合ASINからキーワード逆引き）/ Magnet（KWツリー展開）
- **出品最適化**：Listing Builder + Scribbles（KW入れ込み補助）+ AI Listing
- **在庫管理**：Inventory Protector・補充アラート
- **PPC（広告）運用**：Adtomic で広告自動最適化
- **利益分析**：Profits ダッシュボード（FBA手数料・PPC・返品込み）
- **逆輸入/相乗り対策**：Hijacker Alerts / Refund Genie

## できること（主要機能）

| モジュール | 説明 |
|---|---|
| **Black Box** | 月販売数・売上・レビュー数等の閾値で商品リサーチ |
| **Xray (Chrome 拡張)** | Amazon 商品ページに月販売数・収益・FBA手数料を直接重畳 |
| **Cerebro** | 競合 ASIN を入れると、その商品が獲得しているキーワード一覧を逆引き |
| **Magnet** | キーワード起点で関連 KW を網羅的に展開 |
| **Listing Builder + AI** | GPT 連携で見出し・箇条書きを自動生成、KW含有率も可視化 |
| **Adtomic** | スポンサー広告の自動入札・規則ベース最適化 |
| **Profits** | 売上・粗利・PPC・返品を統合した P/L ダッシュボード |
| **Refund Genie** | FBA 紛失・破損商品の返金請求テンプレ生成 |
| **Inventory Protector** | 競合の在庫枯渇買い占めを防ぐ上限設定 |
| **Alerts** | 相乗り・ハイジャック・在庫切れの通知 |
| **Follow-Up (Email)** | 購入者への自動メールフォロー（JPでは規約注意） |

## 無料代替

- **Free プラン** で Xray の月10回程度の試用は可能（本格運用は不可）
- **Jungle Scout 7日返金保証**との比較検討推奨
- 国内特化なら **Keepa+SellerSprite+アマサーチ** の組み合わせの方が初期コスト低

## 国内Amazon（amazon.co.jp）対応

- **対応：◯（部分対応）** — JPストアの ASIN を入れれば動くが、**米国マーケット最適化が前提**
- **日本語UI**：あり（メニュー翻訳済）。ただし詳細ヘルプ・ウェビナーは英語
- **JPデータの精度**：Black Box の販売数推定は US ほど精度高くない（カテゴリ係数が US 基準）
- **PPC自動化（Adtomic）**：JPアカウント対応済

## 学習コスト目安

- **Xray（拡張）の基本操作**：1〜2時間（Keepa とほぼ同等）
- **Black Box / Cerebro リサーチ**：1日〜（フィルタ理解に時間）
- **Listing Builder + AI 活用**：2〜3時間
- **Adtomic（PPC自動化）使いこなし**：2〜4週間（広告運用知識前提）
- **全機能フル活用**：1〜3ヶ月（モジュールが30+あるため）

## AI 連携性（v2 観点での追加評価 ★最重要）

- **公式 API：あり（Platinum 以上）** — SP-API ラッパー＋ Helium 10 独自データの両方を取得可能
- **AI ネイティブ機能**：
  - **AI Listing**（GPT-4 連携）：商品説明・箇条書き・タイトルを KW スコア付きで自動生成
  - **Adtomic AI**：広告入札の機械学習最適化
  - **Demand Analyzer**（β）：需要予測 AI
- **Sato-Scope への統合可能性**：◎
  - API 経由でリサーチデータ・PPCデータを取得可能
  - Webhook で在庫アラート・ハイジャック通知を Sato-Scope に流せる
- v2 カタログでは「**AI ネイティブ × API 公開 × オールインワン**」の3条件を満たす数少ない海外ツール

## 法務・運用上の留意点（ハルオ向け）

- **米国企業との契約**：利用規約は英語版が正本。日本語UIあっても準拠法は米国カリフォルニア州法
- **データ取得元**：自社クロール部分は Amazon TOS とのグレーゾーン。Keepa と同様の論点
- **個人情報（Follow-Up Email）**：JP では特定電子メール法・Amazon コミュニケーションガイドライン抵触リスク高 → **JP では Follow-Up モジュールは原則使用しない**
- **解約・返金**：30日返金保証あり（公式記載）。年払い解約は月割り返金なし

## カズヨ所見

**「米国セラー向けのデファクト・スタンダード」**だが、JP物販には**過剰投資の可能性が高い**。
- **JP 単独運用**：Helium 10 Platinum（年¥147k）の費用対効果は薄い。Keepa+DELTA tracer+Sato-Scope の方が安く、JP に最適化される
- **US 展開を見据える場合**：強力な選択肢。Adtomic の PPC 自動化と Cerebro のキーワード逆引きは他ツール代替困難
- **AI 連携前提（仮説A）**：API 公開＋ AI ネイティブ機能で **Sato-Scope の中核データ源候補**としては **Keepa / SellerSprite と並ぶ筆頭**

**タケシ用バトン**：
- 「軸B 即併走候補」としては**当面見送り**（学習コスト高・JP特化度低・年契約リスク）
- 「中核ツール候補」としては**保留**（Sato-Scope が JP ASIN 中心なら不要、US展開時に再評価）
- 撤退条件：「導入 3 ヶ月で Adtomic か Cerebro のどちらかでも実運用に乗らなければ即解約」
