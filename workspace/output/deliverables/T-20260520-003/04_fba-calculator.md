# 04. FBA計算機（Amazon Revenue Calculator）

## 一行説明

Amazon が公式提供する **FBA手数料・販売手数料を試算する無料ツール**。利益計算の基準。**全セラー必須の標準装備**で、契約不要。

## 開発元・所在

- 開発：Amazon.com, Inc.（公式）
- 公式：https://sellercentral.amazon.co.jp/fba/revenuecalculator/index
- アクセス：Amazonセラーセントラル経由（無料アカウントでも一部利用可）

## 用途（Amazon物販のどこで使うか）

- **仕入れ前の損益試算**：「この商品をいくらで仕入れて、いくらで売れば、いくら利益が残るか」を確定する
- **手数料の最新値の参照基準**：他ツール（Keepa／アマサーチ）の手数料計算がズレた時の正解
- **発送方法の比較**：FBA vs 自己発送（FBM）でどちらが得かを比較

## できること（主要機能）

| 機能 | 説明 |
|---|---|
| **ASIN/JAN/商品名検索** | 既存出品商品の手数料を即座に取得 |
| **販売手数料計算** | カテゴリ別の販売手数料率を自動適用 |
| **FBA手数料計算** | サイズ・重量に基づく配送代行手数料 |
| **在庫保管料試算** | 月間／長期保管料の見積もり |
| **FBA vs FBM 比較** | 配送方法別の収益比較 |
| **利益試算** | 仕入原価を入力すると粗利・利益率を表示 |

## 料金プラン

**完全無料**。Amazonセラーセントラルにログインすれば誰でも使える（無料の出品アカウントでもOK）。

## 無料代替

- **アマサーチの利益計算機能** — Amazon商品ページに直接表示されるので便利
- **Keepa の手数料表示** — 簡易版あり
- **Excel / Googleスプレッドシートで自作** — 手数料率を手入力する手間あり

ただし**「Amazon公式の最新手数料率が反映される」のは FBA計算機だけ**なので、最終確認はこのツールで行うのが鉄則。

## 国内Amazon（amazon.co.jp）対応

- **対応：◎** — Amazon公式なのでJP完全対応。料率も自動でJP用が適用される

## 学習コスト目安

- **基本操作**：15分でマスター可能
- 直感的UIで、Amazon公式のヘルプも日本語で充実

## 法務・運用上の留意点（ハルオ向け）

- **規約**：Amazon利用規約の範囲内。問題なし
- **データの正確性**：Amazon公式の手数料率が反映されるため最も信頼できる。ただし「重量・サイズの実測値」を入れないと FBA手数料がズレる
- **注意点**：表示は税抜き／税込み混在の項目があるため、利益試算時は税区分を必ず確認

## カズヨ所見

**契約不要・無料・公式の信頼性**という3拍子揃った必須ツール。導入判断の議論対象にすらならない、最初に押さえるべきもの。

軸B（T-004）の体験仕入れに着手する際、**最初の1商品を仕入れる前に必ず FBA計算機で利益試算**を社長にしてもらいたい。仕入価格 → 売価 → 手数料 → 粗利の流れを実際に通すことが、物販の収益感覚を作る最短ルート。
