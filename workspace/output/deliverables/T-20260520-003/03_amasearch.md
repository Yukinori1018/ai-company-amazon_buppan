# 03. アマサーチ（Amasearch）

## 一行説明

日本発・国内Amazonに特化した**初心者向けの軽量リサーチ拡張機能**。Keepa の入門版的ポジションで、無料プランで「価格・利益・FBA手数料」を amazon.co.jp 商品ページに直接表示できる。

## 開発元・所在

- 開発：株式会社IDEATECH（日本）
- 公式：https://amasearch.io
- ターゲット：日本の Amazon物販セラー（特に副業初心者〜中級）
- ビジネスモデル：フリーミアム（無料＋有料プラン）

## 用途（Amazon物販のどこで使うか）

- **店舗せどり／電脳せどり**：Amazon商品ページから即座に利益試算
- **新人セラーの最初のツール**：Keepa は重いと感じる人向けの入門
- **モバイル運用**：スマホでも軽快に動くのが強み（店舗での仕入れ判断）

## できること（主要機能）

| 機能 | 説明 |
|---|---|
| **利益計算（FBA / 自己発送）** | 仕入価格を入れると即座に粗利・利益率を表示 |
| **手数料自動計算** | カテゴリ別販売手数料・FBA手数料を自動算出 |
| **価格・ランキング履歴表示** | Keepa よりは簡易だがグラフ表示あり（有料機能含む） |
| **JANコードバーコードリーダー** | スマホで店舗バーコード読み取り → 即Amazon検索（店舗せどり向け） |
| **危険物・要件チェック** | FBA禁止品目・要件審査カテゴリの警告表示 |
| **モノレート風グラフ**（有料）| 旧モノレートを彷彿とさせるUI |

## 料金プラン（2026年1月時点）

| プラン | 月額 | 主な制限 |
|---|---|---|
| **無料** | 0円 | 基本機能のみ。価格履歴グラフは制限あり |
| **スタンダード** | ¥980〜¥1,980/月 | グラフ・履歴フル機能 |
| **プロ** | ¥3,000〜¥5,000/月程度 | 高度な機能・大量ASIN対応 |

> ※ 正確な料金は2025年内に改定された可能性あり。要 WebFetch 確認。

## 無料代替

- **Keepa の無料拡張機能** — 利益計算はないが価格グラフは見られる
- **Amazon 公式 FBA計算機** — 利益計算単体ならこれで足りる（後述）
- **ERESA / DELTA tracer** — 日本特化、無料プランあり

## 国内Amazon（amazon.co.jp）対応

- **対応：◎** — JP特化なので最強。日本語UI・日本円表示・JPセラー視点の指標が揃う
- **海外Amazon対応**：限定的（USなど一部はあるが Keepa の方が強い）

## 学習コスト目安

- **無料版で基本機能**：30分〜1時間（直感的UI）
- **有料版の使いこなし**：3〜5時間
- 日本人セラー向けに作られているため、Keepa より学習が早い

## 法務・運用上の留意点（ハルオ向け）

- **データ取得元**：Amazon公開データのスクレイピング＋自社推定。Amazon公式APIは部分利用
- **日本法人運営**：日本の個人情報保護法・特商法に準拠。リスクは低い
- **規約**：日本語、明文化されている

## カズヨ所見

**「Keepa が重い／英語UIに抵抗がある／店舗せどりが主戦場」のセラー向け**。社長は副業初心者なので、Keepa より先にこれを試すのも合理的な選択肢。

ただし、**長期で物販を本格運用するなら Keepa が標準**。アマサーチは「Keepa を補完する2nd ツール」かつ「店舗せどりの即時判断ツール」の位置付け。

無料版で十分試せるので、**まず無料版を社長アカウントに入れて触ってもらう**のがおすすめ（リスクゼロ・契約不要）。
