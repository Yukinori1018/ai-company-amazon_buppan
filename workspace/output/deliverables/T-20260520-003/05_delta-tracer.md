# 05. DELTA tracer（デルタトレーサー）

## 一行説明

Amazon JP に特化した**価格・ランキング・在庫履歴の追跡ツール**。Keepa とデータ提携している国内主要プレーヤーで、UI と判定指標が日本セラー向けにローカライズされているのが特徴。

## 開発元・所在

- 開発：株式会社 utilly（日本）
- 公式：https://utilly.jp/service/delta-tracer/
- ビジネスモデル：サブスクリプション（個人向け／法人向けプランあり）
- データ源：Amazon 公開データ＋Keepa との提携データ取り込み

## 用途（Amazon物販のどこで使うか）

- **国内せどり前提の仕入れ判断**：価格履歴・ランキング・在庫推移を日本円・JPマーケット基準で読む
- **新品 vs 中古 vs Amazon直販**の入れ替わり履歴を確認
- **Keepa よりとっつきやすい UI**で初心者の入口に
- **ランキング推移から月販売数を推定**（Keepa の Sales Estimator と類似機能）

## できること（主要機能）

| 機能 | 説明 |
|---|---|
| **価格履歴グラフ** | 新品／中古／Amazon／カート価格の推移を日本円表示 |
| **ランキング履歴** | カテゴリ別ランキング推移 |
| **販売個数推定** | ランキング × カテゴリ係数による推定値（精度はカテゴリ依存） |
| **在庫追跡** | FBA 在庫数の推移を可視化 |
| **出品者数推移** | 競合セラーの増減を確認 |
| **CSV エクスポート** | プランにより範囲が制限される |
| **ブラウザ拡張機能** | Chrome 用。Amazon 商品ページに直接グラフ表示 |
| **アラート** | 限定的（Keepa ほどの細かい通知設定はない） |

| プラン | 月額 | 特徴 |
|---|---|---|
| **無料体験** | 0円 / 2週間 | 全機能お試し |

**Keepa との比較**：Keepa Premium（¥3,000/月相当）より安く、日本円固定なので為替変動の影響なし。

## 無料代替

- **Keepa 無料拡張機能** — グラフだけなら無料で見られる。ただし日本特化の指標は弱い
- **ERESA 無料プラン** — 同等の国内特化ツール。詳細は別途 ERESA レポート参照
- **アマサーチ無料版** — 国内せどり向けで無料、ただし履歴データは弱い

## 国内Amazon（amazon.co.jp）対応

- **対応：◎** — JP 完全特化。これが最大の強み
- **日本語UI**：完全日本語
- **JP特有のデータ**：中古せどり・新品せどりの判定が日本セラーの感覚に合わせて作り込まれている

## 学習コスト目安

- **拡張機能のグラフ読み**：30分〜1時間（Keepa より直感的という声多数）
- **販売数推定の使いこなし**：2〜3時間
- **CSV エクスポート活用・データ深掘り**：1日〜（プログラミング不要）

## AI 連携性（v2 観点での追加評価）

- **公式 API：なし（2026-05時点）** — Sato-Scope への直接データ流入は不可
- **CSV エクスポート経由**なら一部データ取り込み可能だが、リアルタイム性は失われる
- **拡張機能のみの設計思想**のため、AI 自動化との相性は Keepa / SellerSprite に劣る
- v2 カタログでも「AI 非搭載・参考扱い」の位置づけ

## 法務・運用上の留意点（ハルオ向け）

- **データ取得元**：Amazon 公開データ + Keepa 提携データ。スクレイピング行為については Keepa と同様の論点（Amazon 規約とのグレーゾーン）
- **規約**：日本法人運営のため日本国内法準拠。利用規約は標準的なサブスクリプション契約
- **データ可搬性**：CSV エクスポート可。撤退ロックインは小さい

## カズヨ所見

**「Keepa を日本語にして JP セラー向けに調整したもの」**という理解で大きく外れない。Keepa との二択になりがちだが、判断軸は次の通り：

- **Keepa 推奨**：API 連携・グローバル販売・Sato-Scope 中核化を見据える場合
- **DELTA tracer 推奨**：JP のみ・初心者・「日本語 UI で安心して使いたい」場合

**軸B（T-20260520-004）の体験フェーズで「まず触ってみる」**には DELTA tracer の方が学習コストが低い可能性。ただし AI 連携前提（仮説 A）では Keepa / SellerSprite の API が優位なので、**Sato-Scope の中核データ源としては候補から外れる**。

タケシ用バトン：**「軸B 即併走候補」としては有力**（日本語 UI、月¥2,200、2週間無料体験）。**「中核ツール」候補からは外す**（API 非提供、AI 連携性低）。
