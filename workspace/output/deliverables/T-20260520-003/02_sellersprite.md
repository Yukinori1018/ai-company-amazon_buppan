# 02. SellerSprite（セラースプライト）

## 一行説明

中国発の総合 Amazon リサーチツール。**キーワード逆引き・競合分析・商品リサーチ**を1パッケージで提供。Helium 10 や Jungle Scout（米国大手）の価格を抑えた中国版アグリゲーター、という立ち位置。

## 開発元・所在

- 開発：杭州市の中国企業（運営：上海冒昧网络科技 / Sellersprite Inc.）
- 公式：https://www.sellersprite.com/jp（日本語版）/ https://www.sellersprite.com（英語版）
- ビジネスモデル：サブスクリプション

## 用途（Amazon物販のどこで使うか）

- **キーワードリサーチ**：「どの検索語で売れているか」を ASIN ⇄ キーワードで双方向に分析
- **商品リサーチ**：売れ筋カテゴリ／ニッチ商品の発掘
- **競合分析**：上位セラーの売上推定・キーワード戦略・在庫動向
- **新商品トラッキング**：競合の新発売SKUの動向監視

## できること（主要機能）

| 機能 | 説明 |
|---|---|
| **キーワードマイニング** | 検索ボリューム・季節性・関連語の網羅 |
| **逆引きASIN** | 指定ASINを購入したユーザーの検索キーワードを推定（独自データ） |
| **商品リサーチ** | カテゴリ・売上・レビュー数等のフィルタで商品検索 |
| **市場リサーチ** | カテゴリ全体の競争度・市場規模を可視化 |
| **競合トラッキング** | 指定セラー／ASIN の売上・在庫・ランキングを継続監視 |
| **リスティング最適化** | タイトル・箇条書きへのキーワード組み込み提案 |
| **PPC（広告）分析** | 競合の広告キーワード推定 |
| **Chrome 拡張機能** | Amazon商品ページに売上推定・販売数を表示 |

## 無料代替

- **Keepa の Product Finder + Data**：商品リサーチ単体なら Keepa で代替可
- **Amazon 公式の Brand Analytics**：Amazonセラーセントラル登録者は「ABA（検索クエリ／市場バスケット分析）」を無料で利用可（ブランド登録が条件）
- **アマサーチ（無料版）**：JP特化なら一部代替可

## 国内Amazon（amazon.co.jp）対応

- **対応：◯** — 日本語UI・JPマーケット対応あり。世界トップクラスでJPデータも揃っている
- **JP独自データの精度**：US データに比べると若干粗いが、実用レベル

## 学習コスト目安

- **基本機能（商品リサーチ・キーワード分析）**：3〜5時間
- **逆引きASIN・市場分析の使いこなし**：1〜2週間
- **PPC連携・APIの応用**：2週間〜（実運用に乗せるなら）

## 法務・運用上の留意点（ハルオ向け・⚠️ 重要）

- **データ取得元**：Amazon 公開データの独自クロール＋推定アルゴリズム。Amazon 公式 API ではない
- **中国企業運営の留意点**：
  - データの取り扱いポリシー（プライバシー・取得データの2次利用）を中国法・国際法の両面で確認すべき
  - 国内セラーの中には「中国系ツールは規約上グレー」と忌避するケースあり
  - 日本の個人情報保護法・経済安全保障法との整合性は要確認
- **規約変更リスク**：海外運営のため、突然の値上げ・サービス終了リスクは国内ツールより高め
- **「セラースプライト」名称の類似ツール**：類似名のフィッシング詐欺サイトに注意（公式URLを必ず確認）

## カズヨ所見

機能・価格バランスは優秀。**Keepa では取れない「キーワード ⇄ ASIN の逆引き」が独自の価値**。

ただし**中国企業運営という事業継続リスクと規約上のグレーゾーン**は社長にきちんと示す必要あり。法務（ハルオ）に **規約確認発注の Yes/No** を社長に決めてもらうのが筋。

導入するなら Standard プラン（≒¥6〜7千/月）から。
