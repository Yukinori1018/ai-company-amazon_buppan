## 一言でいうと

**#1「電気用品」の全面除外は緩められます。**当社は電気用品安全法上「販売の事業を行う者」で、
義務は **法27条1項（表示の確認）1本**だけです。ただし **Amazon 側の書類審査が本当の壁**で、
求められる届出書・自主検査記録は**当社が原理的に持っていません**。

そこで**除外 → 3レーン化**（HARD / REVIEW / PASS）を提案します。
実測で **発注候補まで戻る SKU は 42件・すべて照明系**。ただし42件は「書類が揃うまで発注不可」の保留レーンです。
