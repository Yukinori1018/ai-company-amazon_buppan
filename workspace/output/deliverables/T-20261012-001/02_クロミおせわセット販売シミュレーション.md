## 4. 3手先の読み

## 7. 補完セット案（クロミのぬいぐるみ＋おせわセット）の採算

**採算は合いません。この案はやめた方がよいと読みます（確度80%）。**

1. **おせわセットにはクロミのぬいぐるみがすでに入っています**（約15×9×18.5cm）。ぬいぐるみを足すと「同じキャラが2体」の箱になり、買う理由が説明しにくい。
2. **サンリオのクロミのぬいぐるみで売れている単品が見つからない。**サンリオ・クロミで月50個以上売れている149件の上位50件は、シール・ストラップ・リップ・ボトルなどの小物で、ぬいぐるみの単品はおせわセットだけでした。
3. **セットにしても値上げはできない**（9/20 タカシの実測：セット価格の倍率の中央値1.000）。得をするのは FBA 配送代行が1回で済む分だけで、**1セットあたり300〜350円**。
4. **新しい ASIN は販売実績ゼロから始まる。**検索に出るまで自然には売れず、最初の2か月は月0〜5個と見ます。12月のおもちゃの広告は1件売るのに1,000〜2,000円かかる見込みで、3の節約分を上回ります。
5. サンリオはブランド登録があるので、**新しい ASIN をそもそも作れない**可能性があります（03 でハルオが秘書の実機確認事項に挙げています）。
6. 規約面でも、ぬいぐるみ＋おせわセットはハルオの 03 で**不可**（おせわセットにぬいぐるみが入っていて補完にならない）と判定されています。

| | 単品で2つ売る | 補完セットを新しく作る |
|---|---|---|
| 1回の売上 | おせわセット4,300円＋ぬいぐるみ | 同じ（値上げできない） |
| FBA 配送代行 | 2回分 | 1回分（**300〜350円の得**） |
| 立ち上げの広告費 | 0円 | 1件1,000〜2,000円（推定） |
| 12月に売れる個数 | 取り分で月30〜80個 | 0〜5個 |
| 手残り | 上の表のとおり | **1件あたり▲700〜▲1,700円** |

**ハルオの 03 が条件つき可とした「おせわセット＋おしゃぶり＆おむつセット（クロミ）」も、採算の構造は同じです。**値上げはできず、得をするのは FBA 配送代行1回分だけで、新しい ASIN の立ち上げ費がそれを上回ります。しかも 03 の確認時点では、おしゃぶり＆おむつセットのカートは Amazon 本体が持っていました。お客様は2つとも本体からプライムで買えるので、セットを選ぶ理由が「1回で買える」以外にありません。確度70%で、12月に間に合う形では黒字になりません（価格は未取得なので、作るなら1回 Keepa で単品の価格と月販を引いてから決めます）。

組み合わせで単価を上げたいなら、作るべきは補完セットではなく、**同じ商品の2個パック（例：きょうだい向け）**です。ただし需要の裏付けが無いので、ハルオの判定待ちの間は計算しません。
