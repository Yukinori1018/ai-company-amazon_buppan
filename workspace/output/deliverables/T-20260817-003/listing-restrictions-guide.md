# Amazon 出品制限（ゲート）完全ガイド — ルール・確認方法・解除・当社フローへの組み込み

作成: 2026-08-17 ／ 調査サトル・整理ヒデアキ・統括カズヨ ／ T-20260817-003

---

## 0. 先に結論

1. **社長のご記憶は「点数」が正解、「書類の種類」が違います。** 必要なのは **請求書（invoice）で10点以上・発行180日以内**。**小売店のレシート・領収書は受理されません。**
2. **制限ブランドの一覧は、Amazonが公式に非公開**と明言しています。**事前に機械で除外することはできず、1件ずつセラーセントラルで確認するしかありません。**
3. **これはメーカー仕入れにとって有利な壁です。** メーカー発行の請求書はそのまま解除書類になり、せどり勢は小売レシートしか出せないので**構造的に解除できません**。→ **制限ありは除外理由ではなく「ライバルが少ない」という加点要素**として扱います。
4. **見落としが1つありました。** 本家の「初回ロットは最小5個」と、解除要件の「**10点以上**」が矛盾します。制限ありを狙うなら**初回ロットを10点以上**にする必要があり、消化月数の再計算が要ります。

> **私の反省：** 方針 v1.1 の段3に「出品許可が必要か確認」と1行書いただけで、要件も手順も定義していませんでした。手薄でした。本ガイドで埋めます。

## 1. 制限は3階層＋別枠

| 階層 | 中身 | リストは公開されているか |
|---|---|---|
| **①カテゴリー制限** | ジュエリー・時計など。**2017年11月に多くが撤廃**（ドラッグストア／ビューティー／食品&飲料／服&ファッション／ペット用品／シューズ&バッグ）。ただし**その後 再ゲート化されたものもあり、時期で変動** | 公開されるが**改定が多く鵜呑みにできない** |
| **②ブランド制限** | Nike / adidas / Apple など。**実務で最も遭遇する** | **Amazon公式が「全ブランド名は公開していない」と明言**。実際に商品登録して初めて分かる |
| **③ASIN・コンディション単位** | 同じブランドでも特定ASINだけ制限／新品はOKだが中古はNG など | 非公開 |
| **別枠：法令規制** | 医薬品・酒類（免許）／中古品（古物商）／危険物HAZMAT（SDS・UN番号）／食品衛生法／PSE など。および出品禁止商品 | 法令側で公開 |

**この表からの結論：Keepa などで事前に機械的に除外することはできません。** 候補を絞ってから、1件ずつ実機で確認する運用が唯一正しい。

## 2. 確認方法（確実な順）

| # | 方法 | 使う場面 | 判定 |
|---|---|---|---|
| 1 | **セラーセントラル → カタログ → 商品登録 → ASIN/JANで検索 → コンディション選択** | **これが確定**。PCでのリサーチ時 | 「**出品許可を申請**」ボタン＝**制限あり**／「出品する」＝制限なし |
| 2 | **Amazon Seller アプリのバーコードスキャン** | 実店舗・手元の実物 | 同上を即表示。最速 |
| 3 | Chrome拡張（ショッピングリサーチャー等） | 一次スクリーニング | 判定は出るが**確定はセラーセントラル**で |

> **注意：** Keepa には出品制限の判定機能はありません。Keepa は「売れているか」を見る道具、セラーセントラルは「売れるか（出せるか）」を見る道具です。

## 3. 解除＝出品許可申請の要件【社長のご記憶の正確版】

必要なのは **請求書（invoice）** です。**小売店のレシート・領収書は不可。**

| 要件 | 内容 |
|---|---|
| 書類の種類 | **請求書**（メーカーまたは正規卸が発行したもの） |
| 発行からの期限 | **180日以内** |
| 数量 | **合計10点以上**の購入が記載されていること |
| 記載必須 ① | 出品者（自分）の氏名・住所 → **セラーセントラル登録情報と完全一致** |
| 記載必須 ② | 仕入れ先（メーカー／正規卸）の会社名・住所・電話 |
| 記載必須 ③ | 商品名・型番（申請するASINと一致） |
| 価格 | **伏せてよい（省略可）** |

### 受理されない書類

手書き／**見積書**／**発注書**／**受注書**／**ローラーレシート（小売レシート）**／編集可能なファイル形式（Word・Excel等）。

### 審査期間

| 種類 | 期間 |
|---|---|
| ワンクリック解除（書類不要のもの） | 数十分〜数時間 |
| 書類審査 | **3〜7営業日**（厳しいカテゴリーで最長2週間） |

### 通らない主な原因

1. 請求書のショップ名・住所が**アカウント登録情報と不一致**（最頻出）
2. 画像が判読困難（スキャン品質・見切れ）
3. **アカウントパフォーマンスに問題がある**（ODR等）
4. 購入点数が **10点未満**
5. 発行から **180日を超過**

## 4. ★これは当社にとって「壁」ではなく「味方」です

| | メーカー仕入れ（当社） | せどり・電脳せどり |
|---|---|---|
| 発行される書類 | **メーカー／正規卸の請求書** | 小売店のレシートのみ |
| 解除できるか | **できる**（要件を自然に満たす） | **構造的にできない** |
| 結果 | 制限ブランドを売れる | 制限ブランドに入れない |

**つまり出品制限は「メーカー仕入れ勢だけが越えられる壁」です。** 越えた先はライバルが少ない土俵になります。

**→ 運用ルール：制限ありは「除外」ではなく「加点」。** ただし条件が2つあります。

### 条件1：メーカーが請求書を出してくれること

個人事業主相手でも請求書を発行してくれるかは、問い合わせ時に確認します。メーカー仕入れなら通常は出ます（そもそも請求書がないと支払いができません）。

### 条件2：初回ロットを10点以上にすること ← **見落としがちな衝突**

本家 EC STARs の教えは「**初回は最小5個**、売れてからリピート」。しかし解除要件は「**10点以上**」。

**5個で仕入れると、解除に使える請求書が作れません。**

→ 制限ありブランドを狙う場合は **初回ロット10点以上**が前提になり、**消化月数の再計算が必要**です。

```
消化月数 ＝ 10個 ÷ 自分の想定月販（＝ドロップ数 ÷（出品者数＋1））
```

例：ドロップ12・出品者3人 → 自分の月販 3個 → 10個で **3.3ヶ月**。基準（3ヶ月以内）ギリギリ。
→ **制限ありブランドは、制限なしより高い回転を要求される**ということです。

## 5. 当社の運用ルール（4段ふるいの段3を具体化）

段3の目視で、候補1件ごとに次を実行します。

```
① セラーセントラルで ASIN/JAN 検索 → 制限の有無を判定
        ↓
   ┌─ 制限なし ──→ そのまま候補へ  ★初回1SKUはここから選ぶ
   │
   └─ 制限あり ──→ ② メーカーが請求書を出せるか（問い合わせ時に確認）
                        ↓
                   ┌─ 出る ──→ ★加点（競合が減る）
                   │           ③ 初回ロットを10点以上に設定
                   │           ④ 消化月数を10個で再計算 → 3ヶ月以内なら GO
                   │
                   └─ 出ない ─→ 除外
```

### 順序のルール（重要）

**最初の1SKUは「制限なし」から選びます。** 理由は、解除申請の審査に3〜7営業日かかり、**そこで止まると初回の学習サイクルが遅くなる**からです。制限ありに踏み込むのは**2SKU目以降**。

### 別枠の法令規制は「除外」のまま

医薬品・酒類・中古品・危険物・食品などは、**請求書では解けません**（免許・許可の話）。ここは方針 v1.1 の NG 条件のまま除外を維持します。

## 6. 確度タグ

| 内容 | 確度 |
|---|---|
| 請求書 180日以内・10点以上・出品者情報の完全一致 | **確定**（複数の実務ソースで一致・2026-08-17 確認） |
| 小売レシート・見積書・発注書・手書きは不可 | **確定** |
| 価格情報は伏せてよい | **確定**（「価格情報は省略可」） |
| ブランド制限の全リストは非公開 | **確定**（Amazon公式回答） |
| カテゴリー制限は2017/11に多くが撤廃 | **確定**（Amazon公式回答）。ただし**その後の再ゲート化があり現行の対象は要実機確認** |
| 審査 3〜7営業日（最長2週間） | **目安**（実務ソース） |
| メーカー請求書で解除が通りやすい | **一般則**。個別のメーカー・ブランドで結果は変わる |
| 初回ロット5個では解除書類を作れない | **論理的帰結**（10点要件から） |
