## 0. 先に結論

1. **Amazon公式の文言は「メーカーまたは卸業者が発行した請求書1通以上／180日以内／10点以上」。** 社長のご記憶の「10点以上」は正解です。
2. **ただし実務の判定は「書類の名称」ではなく「記載内容が4要件を満たすか」。** 家電量販店の宛名入り請求書でも通る実績があり、Amazon本体の適格請求書で通った実例もあります（ブランドによって結果は分かれます）。
3. **制限ブランドの一覧は、Amazonが公式に非公開**と明言しています。**事前に機械で除外できず、1件ずつセラーセントラルで確認するしかありません。**
4. **メーカー仕入れは「確実性の序列」の最上位を自然に手に入れられる**ので、制限ありは**除外理由ではなく相対的に有利な土俵＝加点要素**として扱います。
5. **見落としが1つ。** 本家の「初回ロットは最小5個」と解除要件の「**10点以上**」が矛盾します。制限ありを狙うなら**初回ロット10点以上**が必要で、消化月数の再計算が要ります。

## 1. 制限は3階層＋別枠

| 階層 | 中身 | リストは公開されているか |
|---|---|---|
| **①カテゴリー制限** | ジュエリー・時計など。**2017年11月に多くが撤廃**（ドラッグストア／ビューティー／食品&飲料／服&ファッション／ペット用品／シューズ&バッグ）。ただし**その後 再ゲート化されたものもあり、時期で変動** | 公開されるが**改定が多く鵜呑みにできない** |
| **②ブランド制限** | Nike / adidas / Apple など。**実務で最も遭遇する** | **Amazon公式が「全ブランド名は公開していない」と明言**。実際に商品登録して初めて分かる |
| **③ASIN・コンディション単位** | 同じブランドでも特定ASINだけ制限／新品はOKだが中古はNG など | 非公開 |
| **別枠：法令規制** | 医薬品・酒類（免許）／中古品（古物商）／危険物HAZMAT（SDS・UN番号）／食品衛生法／PSE など。および出品禁止商品 | 法令側で公開 |

**この表からの結論：Keepa などで事前に機械的に除外することはできません。** 候補を絞ってから、1件ずつ実機で確認する運用が唯一正しい。

## 2. 確認方法（確実な順）

| # | 方法 | 使う場面 | 判定 |
|---|---|---|---|
| 1 | **セラーセントラル → カタログ → 商品登録 → ASIN/JANで検索 → コンディション選択** | **これが確定**。PCでのリサーチ時 | 「**出品許可を申請**」ボタン＝**制限あり**／「出品する」＝制限なし |
| 2 | **Amazon Seller アプリのバーコードスキャン** | 実店舗・手元の実物 | 同上を即表示。最速 |
| 3 | Chrome拡張（ショッピングリサーチャー等） | 一次スクリーニング | 判定は出るが**確定はセラーセントラル**で |

> **注意：** Keepa には出品制限の判定機能はありません。Keepa は「売れているか」を見る道具、セラーセントラルは「売れるか（出せるか）」を見る道具です。

## 3. 解除＝出品許可申請の要件

### 3-1. Amazon公式の文言（申請画面の原文）

> **「商品の購入に対してメーカーまたは卸業者が発行した請求書1通以上」**
> - 過去 **180日以内**に発行
> - **出品者の名前と住所**が含まれている（＝セラーセントラル登録情報と一致）
> - **メーカーまたは卸業者の名前と住所**が含まれている
> - **合計10点以上**の購入を表示

価格情報は**伏せてよい（省略可）**。

> **一次情報の取得について（正直に）：** 公式ヘルプ本文はログインゲートで直接取得できませんでした。上記は **Amazon自社ドメインのセラーフォーラム（sellercentral-japan.amazon.com）に転載された申請画面の原文**と、複数の実務ソースが一致した内容です。社長がセラーセントラルにログインして申請画面を開けば同じ文言が確認できます。

### 3-2. ★ しかし実務の判定は「書類の名称」ではありません

**社長のご指摘が正しく、私の初版が誤っていました。** 実態は次のとおりです。

| 論点 | 実態 |
|---|---|
| **ロールレシートが落ちる理由** | 名称のせいではなく、**購入者（出品者）の氏名・住所が印字されない**ため4要件を満たせないから |
| **家電量販店** | ビックカメラ／ヨドバシ／ヤマダ電機は**宛名入りの請求書を発行してくれる**。**通る実績あり**（ただし通らない場合もある） |
| **Amazon本体** | 適格請求書（支払い明細書）で**通った実例あり**（SanDisk・ポケモン＝承認／Microsoft＝却下）。ただし **2025年7月から Amazon本体購入は10点→50点以上**に厳格化 |
| **ブランド差** | ブランドごとに審査の厳しさが違う。要求書類が複数選べるブランドは厳しい傾向 |

### 3-3. 確実性の序列（当社の使い分け）

```
メーカー／正規卸          ← 最も確実。当社の本線はここ
  ↓
ネット卸（NETSEA・スーパーデリバリー・卸売りドットコム・カワダオンライン）
  ↓
家電量販店（宛名・住所入りの請求書を発行してもらう）
  ↓
Amazon本体（50点以上・ブランド次第）
  ↓
ロールレシート            ← 記載項目が足りず実質不可
```

### 受理されにくい書類

手書き／**見積書**／**発注書**／**受注書**／**ロールレシート**／編集可能なファイル形式（Word・Excel等）。

### ⚠️ 絶対に採らない手段

**請求書の偽造・改ざん、解除代行業者の利用は、アカウント停止および法的リスクに直結します。** 当社では採用しません。

### 審査期間

| 種類 | 期間 |
|---|---|
| ワンクリック解除（書類不要のもの） | 数十分〜数時間 |
| 書類審査 | **3〜7営業日**（厳しいカテゴリーで最長2週間） |

### 通らない主な原因

1. 請求書のショップ名・住所が**アカウント登録情報と不一致**（最頻出）
2. 画像が判読困難（スキャン品質・見切れ）
3. **アカウントパフォーマンスに問題がある**（ODR等）
4. 購入点数が **10点未満**
5. 発行から **180日を超過**

## 4.【社長のご指摘への回答】なぜ「せどりが成り立っている」のか

**ご指摘は正しいです。** せどらーが制限を突破しているからではなく、主に次の5つの理由です。

| # | 理由 |
|---|---|
| 1 | **そもそも大半のせどらーは「制限のない商品」を扱っている。** 制限商品は避けるのが基本戦略 |
| 2 | **ワンクリック解除（書類不要）で解ける商品がある。**「出品許可を申請」を押すだけで通る場合がある（※一時的で、再度規制がかかることも） |
| 3 | **家電量販店で宛名入りの請求書を発行してもらえる**（ビックカメラ／ヨドバシ／ヤマダ） |
| 4 | **ネット卸を使えば正規の請求書が出る**（NETSEA など。当社も契約済み） |
| 5 | **過去は審査が今より緩く、領収書で通った時期があった** |

つまり「レシートでも大丈夫」というより、**せどらーは①制限のない商品を選ぶか、②要件を満たす書類を別ルートで手に入れている**、というのが実態です。

### 当社（メーカー仕入れ）の位置づけ

| | メーカー仕入れ（当社） | せどり・電脳せどり |
|---|---|---|
| 手に入る書類 | **序列の最上位＝メーカー／正規卸の請求書** | 店舗に依頼すれば量販店の請求書。手元にあるのはロールレシート |
| 解除できるか | **要件を自然に満たす** | **できることもあるが、通らない場合がある／ひと手間かかる** |
| 差の性質 | — | **断絶ではなく「程度の差」**（初版で「構造的に不可能」と書いたのは誤り） |

**→ 運用ルールは変えません：制限ありは「除外」ではなく「加点」。** 当社は書類の質で有利だからです。ただし条件が2つあります。

### 条件0（v1.1で追加）：まず「ワンクリック解除」を試す

「出品許可を申請」を押しただけで解除される商品があります。**書類の準備より先に、まずこれを試す**のが最短です。数十分〜数時間で結果が出ます。
※ただし一時的な解除で、後から再度規制がかかることがあります。在庫を持つ前提では過信しないこと。

### 条件1：メーカーが請求書を出してくれること

個人事業主相手でも請求書を発行してくれるかは、問い合わせ時に確認します。メーカー仕入れなら通常は出ます（そもそも請求書がないと支払いができません）。

### 条件2：初回ロットを10点以上にすること ← **見落としがちな衝突**

本家 EC STARs の教えは「**初回は最小5個**、売れてからリピート」。しかし解除要件は「**10点以上**」。

**5個で仕入れると、解除に使える請求書が作れません。**

→ 制限ありブランドを狙う場合は **初回ロット10点以上**が前提になり、**消化月数の再計算が必要**です。

```
消化月数 ＝ 10個 ÷ 自分の想定月販（＝ドロップ数 ÷（出品者数＋1））
```

例：ドロップ12・出品者3人 → 自分の月販 3個 → 10個で **3.3ヶ月**。基準（3ヶ月以内）ギリギリ。
→ **制限ありブランドは、制限なしより高い回転を要求される**ということです。

## 5. 当社の運用ルール（4段ふるいの段3を具体化）

段3の目視で、候補1件ごとに次を実行します。

```
① セラーセントラルで ASIN/JAN 検索 → 制限の有無を判定
        ↓
   ┌─ 制限なし ──→ そのまま候補へ
   │
   └─ 制限あり ──→ ★加点（当社は書類の質で有利）
                    ↓
                    ② 【発注前・必須】「出品許可を申請」を押す
                    │    在庫ゼロでも押せる。無料・即時。通ればここで完了
                    ↓ 通らなければ
                    ③ メーカーに請求書の記載を発注前に確約させる
                    │    氏名・住所／メーカー社名・住所／商品名・数量10点以上
                    ├─ 確約が取れる ──→ 初回ロット10点以上
                    │                    → 消化月数を10個で再計算 → 3ヶ月以内なら GO
                    └─ 取れない ─────→ 除外
```

### 順序のルール（社長裁可 2026-08-17 で変更）

**「最初の1SKUは制限なしから選ぶ」という縛りは撤廃しました。** 社長のご判断（**商品の幅を狭めるから**）が正しく、これは「母数を広く取る」という仕入れ方針と矛盾していました。制限の有無で候補を絞りません。

### ⚠️ 代わりに潰すべき「順序リスク」

**請求書は仕入れた後にしか出ません。** つまり通常は「**解除できるか分からないまま在庫を買う**」ことになり、解除が通らなければ**売れない在庫**になります。縛りを外した以上、ここを対策で潰します。

| # | 対策 | 効果 |
|---|---|---|
| 1 | **発注前に必ずワンクリック解除を試す**（在庫ゼロでも押せる・無料・即時） | 通ればリスクゼロ。ここで大半が判明する |
| 2 | **メーカーに請求書の記載内容を発注前に確約**（氏名・住所・商品名・数量10点以上） | 却下の最頻出原因（記載不備・不一致）を事前に消す |
| 3 | **初回ロットは10点以上** | 5個では解除書類が作れない |
| 4 | **リードタイムに審査3〜7営業日を織り込む** | 販売開始の遅れを防ぐ |
| 5 | **1・2が取れない制限あり商品は見送る** | 「解除できない在庫」を持たない |

### 別枠の法令規制は「除外」のまま

医薬品・酒類・中古品・危険物・食品などは、**請求書では解けません**（免許・許可の話）。ここは方針 v1.1 の NG 条件のまま除外を維持します。

## 7. 社長裁可（2026-08-17）── 確定した運用

| 論点 | 決定 |
|---|---|
| 制限ありの扱い | **加点扱いで確定** |
| 初回1SKUの縛り | **「制限なしから選ぶ」は撤廃**（商品の幅を狭めるため）。代わりに**発注前のワンクリック解除テスト**と**請求書記載の事前確約**を必須化 |
| 撤退条件 | 金額基準（旧・1SKU損失上限3万円）を撤廃し、**「損益がマイナス、かつ今後利益が見込めない可能性が高いと判断したとき」**へ変更。判断を先送りしないため**レビュー日 90/180/271/365日**のみ固定 |

**→ 方針書 T-20260817-002 を v1.3 に更新済み。** 候補リスト出力時には**「出品制限チェック欄」と「制限ありの場合の10個ベース消化月数」列**を付けます。
