## 1. なぜ「月100個以上」なのか

| 項目 | 月数個の棚（今の NETSEA プール） | 月100個以上の棚 |
|---|---|---|
| 誰が買うか | たまたま検索した人 | その商品を指名して繰り返し買う人（消耗品・定番品） |
| 新規出品者の取り分 | 月1〜3個。1人増えるだけで0に近づく | 出品者5人でも月16個以上 |
| 10点ロットの回転 | 4〜12ヶ月。悲観だと6ヶ月を超える | 1ヶ月未満 |

- 実績ゼロの当社が取り分を確保できるのは、売れる量の大きい棚だけです（社長の読みどおり）。
- 代償: この棚はメーカー本人や Amazon 本体が売っていることが多く、利益率は薄くなりがちです。**利益率は後から工夫できますが、需要は作れません。**だから需要を先に置きます。

## 3. ロットの組み方（A の型）

| 項目 | 決め方 |
|---|---|
| 金額 | 8〜12万円（送料込み） |
| 社数 | 1社（最大2社）。**1社で10点以上・請求書1枚** |
| SKU 数 | 2〜4。同じブランドで揃えればゲート申請1回で済む |
| 1 SKU の数量 | 取り分の3ヶ月分まで |
| 支払い | カード（SD の掛け払いは請求書の発行者が決済会社になり、申請に使えない） |
| 届け先 | 納品代行 → FBA へ1回で納品 |
| 足切り | ①月100個以上（バリエーションの子は子自身の値） ②利益率5%以上（大口・カート価格90日平均） ③悲観でも6ヶ月で売り切れる数量 ④昨年10〜3月の月販が年平均の半分以上（季節） ⑤終売の兆候なし・Amazon 本体なし ⑥ブランドストアなし（持ち主が自分で売っていない） |

- ④はアミノの教訓です。売り始めを10月中旬に置き、冬に売れない商品は落とします。
- ⑥はゲートと価格の両方に効きます。持ち主が売っている棚では当社は競合なので、請求書が通ってもカートは取りにくいです。
- ②と④の線は、タカシの「売れる商品・売れない商品の傾向」分析が出たら差し替えます。

### ゲートと請求書

| 論点 | 設計 |
|---|---|
| 要件 | メーカーか販売業者の発行・180日以内・名前と住所の一致・**合計10点以上** |
| 満たし方 | 1社・同じブランドで合計10点以上を1回で注文する。SKU をまたいで10点でよい（要件の文言は「合計」） |
| 発行者 | SD は出展者（メーカー本人の場合あり）。NETSEA はサプライヤー。どちらもカード払いに限る |
| 残るリスク | 申請は発注の後でないとできず、却下なら在庫が残る。足切りに「ゲートなし、または却下されても売れる経路がある」を足す（S-4 で実機確認） |

## 4. 送料の薄まり（ハジメの置き値・推定）

前提: 納品代行12円/点（公開料金）、代行→FBA は1箱750円・1箱20点（推定）、仕入れ送料1,500円（無料ラインを超えれば0円）。

| 1回の点数 | 1点あたりの固定費（仕入れ送料あり） | 無料ライン超え |
|---:|---:|---:|
| 4点 | 574円 | 200円 |
| 12点 | 200円 | 74円 |
| 20点 | 124円 | 50円 |
| 40点（10万円ロット） | 87円 | 50円 |

- 4点では、固定費だけで1点の利益（数百円）が消えます。**社長の「送料負け」は数字どおりです。**
- 代行→FBA の60〜120サイズの料金は、セラーセントラルの納品プラン画面でしか見られません（S-5）。
- 大口の月額は6ヶ月で32,340円です。10万円ロット1本の利益（期待値2.9万円）では、まだ回収できません。**月1本ペースでロットを出して初めて固定費が薄まります。**これが2周目以降の目標です。
