## 続報が届いたときの手順

```bash
# 1. pool.csv に「現行」と確認できた ASIN の行を足す（供給ステータス列に「現行」）
# 2. 組み直す
cd workspace/output/deliverables/T-20260909-002
python3 order_set.py
```

コードは触りません。`order_set.py` は毎回

1. `all_candidates.csv` の「回転検証＝通過」全件に、回転6ヶ月・最小ロット10万円のふるいを当て、
2. `pool.csv` の「現行」だけを拾い、`candidates.csv` から採算・最小ロット・回転を引き、
3. NETSEA `GET /tariffs` から送料を実額で取り直し（推定しない）、
4. 予算10万円に収まる組み合わせを総当たりし、最大2案を選び直します（手残りでは選びません）。
