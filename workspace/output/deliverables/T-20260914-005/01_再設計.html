0. 結論

  1. 矛盾の軸は「Amazon にいるか」ではなく「Amazon で誰がブランドを持っているか」でした。需要が見えて、かつ当社が競合にならないのは P2（Amazon に商品はあるがブランド未登録・第三者が売っている）だけです。EC STARs の成立率3%は、この P2 の数字でした。
  2. 打診先を P2 に寄せても、12ヶ月の実質現金は中央でプラスになりません。案A 39%・−4万／案B 43%・−3万／案C 47%・−1万（N=1500）。P2 は数が少なく（約230社・推測）、1社から立つ商品も少ない（1.5 SKU）ためです。
  3. 中央を決めているのは固定費です。卸とメーカー直の手取りは12ヶ月で中央+13万、固定費は18万（月15,253円）。Keepa API を12月から Pro に切り替えると、案B は 50%・中央 ±0 になります。これが既定内の最大で、推奨です。確度は5割で、高いとは言えません。
  4. 60%を超える道は4つです。判定を18ヶ月にする（案B 69%・+15万）、P2 の成立率が平均5%と実測で分かる（60%）、既定内の上振れ3つが揃う（63%）、せどり限定再開＋週20通（62%・事故13%）。18ヶ月は事故を増やさず、最初の9ヶ月の動きも変わりません（変わるのは発注を止める月だけ）。
  5. 最初の8週で、P2 の成立率を見分けます。50通で見積3件以上が出る確率は、3%の世界で78%、1.5%の世界で33%です。
  6. 資金は律速ではありません。どの案も使うのは50万前後で、予備25万円は割りません。
