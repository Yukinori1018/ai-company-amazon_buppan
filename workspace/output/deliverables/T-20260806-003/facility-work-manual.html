このマニュアルは、商品（しょうひん）を袋（ふくろ）に入れて、シールを貼（は）って、きれいに仕上（しあ）げる作業の手順書です。

作業はむずかしくありません。「袋に入れる」「シールを貼る」「箱にまとめる」 の3つが中心です。 このマニュアルの通りに進めていただければ大丈夫です。分からないところは、遠慮（えんりょ）なく連絡先（§9）にご質問ください。

1. はじめに（この作業は何か・何のためか）

この作業は何をするもの？

わたしたちは、インターネットの通販サイト「Amazon（アマゾン）」で商品を売っています。

Amazonでは、商品を売る前に、一度「Amazonの大きな倉庫（そうこ）」へ商品を送ります。 その倉庫に商品が届くと、注文が入ったときにAmazonが自動でお客さまへ発送（はっそう）してくれます。 （この仕組みを「FBA＝Amazonの倉庫にまとめて送る仕組み」と呼びます。むずかしい言葉なので、覚えなくて大丈夫です。）

その「Amazonの倉庫へ送る前」に、商品をきれいに袋に入れて、決められたシールを貼る準備が必要です。 この準備の作業を、みなさまにお願いしたいというのが、今回のお願いです。

なぜていねいさが大事なの？

  • Amazonの倉庫では、商品のシール（バーコード）を機械で読み取って管理します。
  • シールがまっすぐ貼れていなかったり、汚（よご）れていたりすると、機械が読めず、商品が受け取ってもらえないことがあります。
  • だから、「シールをきれいに貼ること」「商品を大切にあつかうこと」 がとても大事です。
ひとことで：「商品を袋に入れて、シールをきれいに貼って、箱にまとめる」。これがみなさまのお仕事です。

2. 全体の流れ

作業は、次の順番（じゅんばん）で進みます。左から右へ、1つずつ進めてください。

①受取商品を受け取る
②検品数を数える／傷を見る
③梱包袋に入れて包む
④ラベル貼りシールを貼る
⑤保管種類ごとにまとめる
⑥引き渡し社長へお渡し
  • ① 受取: 届いた商品を受け取ります。
  • ② 検品: 数を数え、傷（きず）や汚れがないか見ます。
  • ③ 梱包: 商品を袋に入れ、必要なら緩衝材（かんしょうざい＝プチプチ）で包みます。
  • ④ ラベル貼り: 決められたシール（バーコード）を貼ります。
  • ⑤ 保管: 作業が終わった商品を、種類ごとに分けて箱にまとめます。
  • ⑥ 引き渡し: まとまったら、社長へお渡しします。

4. 各作業の手順（てじゅん）

写真を入れる場所は、点線（てんせん）のわくで示しています。あとで社長が写真をはめこみます。

② 検品（けんぴん）— 数を数える・傷を見る

写真：検品のようす（商品を数えている場面）
  1. 届いた箱を開けます。
  2. 商品の数を数えます。 指示書（しじしょ）に書いてある数と合っているか確かめます。
  3. 数が合わないときは、作業を止めて、社長に連絡（§9）してください。
  4. 商品を1つずつ見て、次のものがないか確かめます。
    • 傷（きず）・われ・へこみ
    • 汚れ・シール跡（あと）
    • ふたが開いている・中身がもれている
  5. 傷や汚れのある商品は、べつの場所によけておきます。 そのまま袋に入れないでください。
  6. よけた商品の数を、記録表（§8）に書いておきます。
ポイント：「数が合っているか」「きれいな商品か」 の2つを見ます。

③ 梱包（こんぽう）— 袋に入れて包む

写真：袋に入れる手順
写真：緩衝材で包む手順
  1. 手をきれいにします。机（つくえ）の上もふいておきます。
  2. 商品を OPP袋（とうめいな袋） に入れます。
  3. こわれやすい商品は、先に 緩衝材（プチプチ） で包んでから袋に入れます。
    • どの商品を包むかは → 【要記入：緩衝材で包む商品はどれか】
  4. 袋の口（くち）を テープでとめます。 空気（くうき）が入りすぎないように、軽くおさえます。
  5. 袋がやぶれていないか、口がしっかり閉じているか確かめます。
ポイント：商品が袋の中で動かないように、ちょうどよい大きさの袋を使います。袋の口が開いていると、Amazonで受け取ってもらえません。

④ ラベル貼り（らべるはり）— シールを貼る　★いちばん大事★

写真：ラベルを貼る位置
写真：貼る前と貼ったあとの見本

「ラベル」とは、商品につける四角いバーコードのシールです。 Amazonの倉庫で、このシールを機械で読み取って商品を管理します。だから、とても大事な作業です。

手順：

  1. 貼るシールが、その商品用（よう）の正しいシールか確かめます。
  2. シールを まっすぐ、シワにならないように 貼ります。
    • ゆっくり、はしから貼っていくとキレイに貼れます。
    • 定規やヘラで上から軽くこすると、シワになりません。
★ いちばん大事なルール ★

商品にもともと付いている別のバーコードは、あたらしいシールで「かくして」ください。

  • 商品の箱には、もともとバーコードが付いていることがあります。
  • そのままだと、機械がどちらを読めばいいか分からなくなります。
  • だから、もとのバーコードの上に、あたらしいシールをかぶせて隠（かく）します。
  1. バーコードは「1つだけ」見える状態にします。（くわしい理由は §6）
  2. 貼る場所（位置・向き）は → 【要記入：貼る位置・向き。例「箱の右下・横向き」】
ポイント：
・シールは まっすぐ・シワなし・1枚だけ。
・もとのバーコードは必ずかくす。
・まよったら、貼る前に §9 に連絡してください。

⑤ 保管（ほかん）— 種類ごとに分けてまとめる

写真：種類ごとに分けた状態
  1. 作業がおわった商品を、種類（しゅるい）ごとに分けます。 別の商品とまぜないでください。
  2. 同じ商品を、決められた数ずつダンボール箱にまとめます。
    • 1箱に入れる数は → 【要記入：1箱あたりの数】
  3. 箱に、中身が分かるようにメモを貼ります（商品名・数）。
  4. 作業前の商品と、作業後の商品は、置き場所を分けます。（まざると数え間違いのもとになります）
  5. 商品がぬれたり、日に当たったり、汚れたりしない場所に置きます。
ポイント：「作業前」と「作業後」をはっきり分けると、まちがいがへります。

⑥ 引き渡し（ひきわたし）— 社長へお渡しする

  1. まとまった箱を、決められた方法で社長へお渡しします。
    • 受け渡しの方法は → 【要記入：社長が取りに来る／宅配便で送る など】
    • 受け渡しの曜日・時間は → 【要記入：例「毎週金曜の午前」】
  2. その回に作業した数を、記録表（§8）に書いて、いっしょにお渡しします。
  3. 傷などでよけた商品があれば、それも分けてお渡しします。

作業の「合格ライン」です。左（○ OK）が正しい状態、右（× NG）はやり直しが必要な状態です。

○ OK（これでよい）× NG（やり直し）

6. FBAの大事なお約束（バーコードは「1つだけ」）

FBAとは：Amazonの倉庫にまとめて商品を送る仕組みのことです。

なぜバーコードを1つだけにするの？

  • Amazonの倉庫では、機械がバーコードを読み取って、商品を1つずつ管理しています。
  • もし商品に バーコードが2つ以上見えている と、機械がどちらを読めばいいか分からず、まちがった商品として登録されてしまいます。
  • そうなると、お客さまに違う商品が届いたり、商品が迷子（まいご）になったりします。
  • だから、「新しいシール1つだけが見える」「もとのバーコードはかくす」 が絶対のルールです。
かんたんに言うと：「見えるバーコードは、いつも1つだけ」。これだけ覚えてください。
