# 12ヶ月で現金が増えるやり方（統合報告 v2・社長向け）

T-20260912-002／2026-09-14／秘書カズヨ（統合）
差し戻し（9/14）「12ヶ月で現金が増えない事業をやったらダメ。もっと儲かる確度の高いやり方を」への回答です。

## 0. 結論

1. **12ヶ月で現金が増える案は作れました。ただし「確度が高い」とは言えません。** 推奨案で、12ヶ月後の現金がプラスになる確率は62%、中央値は+6万円です。予備の25万円はどの世界でも割りません。
2. **「確度の高い案」が作れない理由は、自社の実測がゼロだからです。** 確率を最も動かす4つ（メーカーとの取引成立率・1商品あたりの売れ方・卸で見つかる商品数・メーカー直の利益率）が、まだ1件も測れていません。
3. **確度を上げる手段は、最初の8週で実際に回すことだけです。** 11/6 に3つの数字を見れば、確率は74%か35%に分かれます（§3）。
4. **前回の案（12ヶ月で−9万）との違いは3つです。** 資金を200万円に置き直したこと、「卸から探す」をやめて「需要の見える商品から探す」に逆転させたこと、在庫を現金に戻す設計を入れたことです。

## 2. 推奨：案B「需要の見える商品を、卸で仕入れる＋メーカーに打診する」

| 項目 | 中身 |
|---|---|
| やり方 | Keepa で「売れていて、Amazon 本体がおらず、出品者が少ない商品」を先に選ぶ → 卸（NETSEA・スーパーデリバリー・卸問屋.com・国分）で同じ商品を探す → 卸に無ければメーカーへ打診（週20通） |
| 在庫の回し方 | 初回は1ヶ月分だけ仕入れ、売れたら補充する。新規の仕入れは2027-06まで |
| 12ヶ月後の現金 | プラスの確率62%。中央+6万・悪い側（下位20%）−8万・良い側（上位20%）+31万 |
| 手元現金の最低額 | 下位10%の世界でも131万円（予備25万円は割らない） |
| 社長の時間 | 週約3時間（打診の送信クリック・返信の一次判断・発注の決済） |
| 弱点 | 最初の売上が遅い。12月末まで売上0の確率36%。初回の入金は中央で2027-01 |
| やらないこと | 電脳せどりの再開・初回ロット2ヶ月分以上・中国輸入・簡易OEM（1年目は回収できない）・PDF の「外れはデータ購入」型のテスト発注 |

### 他の案との比較

| | 案A 打診週10通 | **案B 週20通（推奨）** | 案C 週10通＋電脳せどり再開 |
|---|---|---|---|
| 12ヶ月後の現金がプラスの確率 | 51% | **62%** | 67% |
| 中央値 | +1万 | **+6万** | +9万 |
| 12月末まで売上0の確率 | — | 36% | 6% |
| アカウント停止の確率（年） | 5% | 5% | 12%（うち恒久3%） |
| 社長の時間 | 週1.5時間 | 週3時間 | 週5時間 |
| 既定の変更 | なし | なし | せどりのホールド解除が要る |

案Cは確率が5pt高い代わりに、アカウント停止の確率が倍以上になります。日本店は8月に約5週間止まった経緯があるので、差が小さいなら止まりにくい方（案B）を推します。**ただし「売上0の期間」を最も避けたいなら案Cです。**

## 3. 確度を上げる8週間

| 11/6 に見る数字 | 良い側なら | 悪い側なら |
|---|---|---|
| ① 最初の商品の2週間の売れ方（実売÷読み） | 0.7倍以上 → 確率74% | 0.4倍未満 → 35% |
| ② 出品中の卸・メーカーの商品数 | 1以上 | 12/31 でも0 → 30% |
| ③ 打診の送信（計画比） | 計画どおり → 69% | 2ヶ月続けて半分未満 → 36% |

悪い側に出たら、撤退条件で止まります。

| 判定日 | 条件 | 動き |
|---|---|---|
| 2026-12-31 | 出品中の卸・メーカー商品が0 | 計画を修正（打診先・卸を変える） |
| 2027-03-31 | 累計損益が−8万未満 | 新規ロットを止めて在庫を現金に戻す |
| 2027-06-30 | 累計損益が−5万未満 | 同上（事業の継続を社長判断） |
| 随時 | アカウントの警告・申し立て1件 | 該当の仕入れ経路を即停止 |

## 5. 社長に判断していただくこと（推奨どおりなら「すべて推奨で」の一言で進みます）

| # | 論点 | 推奨 | 他の選択肢 |
|---|---|---|---|
| ① | 「現金が増えた」を何で測るか | 「今やめたら手元に残る額」（口座＋Amazonの未入金＋在庫の8割）で測り、仕入れは止めない。確率65%・2027-09 の月商48万が残る | 口座の現金だけで測り、2027-06で仕入れを止める（確率62%・翌年の立ち上がりが遅れる） |
| ② | 電脳せどりを再開するか | 再開しない（案B） | 再開する（案C・確率67%・停止リスク倍） |
| ③ | 打診の週上限 | 週20通（社長の時間 週約3時間） | 週10通（確率51%） |
| ④ | 卸の登録 | 9/17 スーパーデリバリーの書類提出、卸問屋.com・国分ネット卸にも登録（いずれも規約同意＝社長の一手） | スーパーデリバリーのみ |
| ⑤ | 医薬品・化粧品・食品を照合に戻すか | 除外のまま（出品の許可と表示規制が重い） | 戻す（対象が約1.9倍） |

## 6. 正直にお伝えしたいこと

- 200万円を1年回して、中央値で残るのは+6万円です。期待値でも+11万円です。**「大きく儲かる」案ではありません。** 1年目は、2年目以降に稼ぐための「売れる商品・取引先・自社の実測」を、赤字を出さずに積む年です。
- この結論は、他AIのPDF（Phase 2 で4〜6ヶ月後に月利50万）と大きく違います。PDF の数字は、費用の抜けと、実績ゼロの事例が無い前提の上に立っていました（サトルの突合）。
- それでも「もっと確度を」とお考えなら、変えられるのは前提です。例えば、実店舗の仕入れなど社長の物理作業を許す、アカウント停止のリスクを取ってせどりを大きく回す、Amazon 以外の事業も並べる、などです。どれを検討するかをご指示いただければ、同じ手順で数字を出します。
