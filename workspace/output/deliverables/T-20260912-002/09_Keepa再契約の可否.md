# 09 Keepa の再契約の可否（ハジメ・2026-09-14）

論点③「Keepa を必要な月だけの API 契約にする」の前提確認。公式ページの閲覧だけで確認した（ログイン・解約・契約変更はしていない）。

## 結論

1. **月単位の解約と再契約はできる。** 解約はいつでもでき、支払い済み期間の終わり（当社は 10/3）まで使える。再契約の待機期間と初期費用はどこにも書かれていない。
2. **ただし再契約は「新規契約」になる。** 期限が切れた契約は復活できない。価格は再契約した時点の定価で、請求日は再契約した日になる。
3. **無料版で見えるのは価格の履歴だけ。** 売れ筋ランクの履歴・出品者数の履歴・評価の履歴・Product Finder は使えない。Pro と当社の API 契約は別の商品で、API 契約で Pro の画面は開かない。
4. **「必要な月だけ API」の年額は中央 26,195円（年3回）。** 今のまま（年12回・104,782円）より 78,587円安い。マサルの試算は年1回（8,732円）で置いている。年3回なら、確率は約5pt 下がる（推測）。

## 1. 解約と再契約（公式）

| 論点 | 公式の記載 | 出典 |
|---|---|---|
| 解約の時期 | いつでもできる。ダッシュボードから | A「Cancel」・B §9(2) |
| 解約後の利用 | 支払い済み期間の終わりまで使える。期間内なら解約を取り消せる | A「Cancel」・C 解約画面「You keep full access until then… You can resume the subscription any time before it ends」 |
| 返金 | 法令で必要な場合を除き返金しない。月の途中の日割り返金・クレジットもない | B §9(2)・C 購入画面「all payments are non-refundable」 |
| 期限後の再開 | 復活できない。新しいプランを契約し直す | A「Once the period has ended… it can no longer be reactivated — you then have to subscribe to a new plan」 |
| 待機期間・初期費用 | 記載なし。支払いを受けたら直ちに有効になる | A・B 全文に該当なし／C 購入画面「activated… immediately after we have received the payment」 |
| 再契約時の価格 | その時点の料金表（B §7）。継続中の契約なら値上げは30日前通知・次の請求周期から（B §9(3)）。**解約するとこの保護を失う** | B §7・§9(3) |
| 請求日 | 契約を始めた日と同じ日付で毎月（B §9(1)）。再契約した日が新しい更新日になる | B §9(1) |
| 残っているトークン | 60分で失効する。月をまたいで持ち越せない（解約とは無関係） | A「Unused tokens expire after 60 minutes」 |
| 保存したデータ | 解約後も自社業務で使える（B §11(2)「unlimited right of use」）。文理解釈で、Keepa の公式見解は無い | ハルオ T-20260824-001 |
| 割引 | 無い | A「Keepa does not offer discounts」 |
| **注意** | B §12(1) は「アカウント削除」でも契約を終えられる。**アカウントは消さない。** 解約はダッシュボードの解約ボタンだけで行う | B §12(1) |

**運用の型（推測・公式の文言から組み立てた）：** 再契約したら、その日のうちに解約も入れる。解約しても期間の終わりまで使えるので、自動更新による払い忘れを防げる。再契約（決済）と解約は、どちらも社長の一手（§4.1）。

## 2. 無料版・Pro・当社の API

| 機能（amazon.co.jp） | 無料（非ログイン・無料アカウント・拡張機能） | Pro €29/月 | 当社 API €49/月（20トークン/分） |
|---|---|---|---|
| 価格の履歴（Amazon・新品・中古・カート価格） | ○ | ○ | ○（API で取得） |
| 売れ筋ランクの履歴 | × | ○ | ○（API） |
| 出品者数の履歴（新品・FBA・FBM） | × | ○ | ○（API） |
| 評価・レビュー数の履歴 | × | ○ | ○（API） |
| Product Finder・Product Viewer・ベストセラー・セラー検索 | ×（購入ページへ飛ばされる） | ○（画面） | ○（API の Finder） |
| API | × | 1トークン/分が付く | 20トークン/分 |
| Pro の画面 | — | ○ | ×（API と Pro は別契約） |

- 出典は C。無料の利用者には co.jp の売れ筋ランク・出品者数・評価・レビュー数のグラフを制限する実装（`graphIsRestricted`）と、Finder などを購入ページへ転送する実装を読んだ。**確度は高いが、画面では確かめていない**（ログインしない制約のため）。
- Pro の機能一覧（ランク・出品者数・評価の履歴、Finder、1トークン/分の API）は C の購入画面の文言。「Pro と API は別の契約で、互いを含まない」は二次情報（revenuegeeks・2026-07-22 更新）と当社の領収書（API €49 の1行だけ）で一致する。
- 無料版でも「終売」の気配（価格の線が途切れる）はある程度見える（推測）。ランクが見えないので、売れているかどうかは Amazon の「過去1か月で N 点以上購入」で代える。

## 3. 年間費用（2026-10〜2027-09・1€＝178.2円＝前回の置き値）

仮定：抽出（タカシ T-3 9/21・サトル S-3 9/28）は 9/4 に支払い済みの期間（〜10/3）で終える。10/3 までに解約する（§4.1）。以後は、補充の判断が要る月だけ再契約する。

| シナリオ | API の月数 | 年額 | 月平均 | 今のままとの差（年） |
|---|---|---|---|---|
| 今のまま（API×12） | 12 | €588＝104,782円 | 8,732円 | — |
| 参考：Pro×12 | — | €348＝62,014円 | 5,168円 | −42,768円 |
| 楽観 | 2 | €98＝17,464円 | 1,455円 | −87,318円 |
| **中央（推奨値）** | **3** | **€147＝26,195円** | **2,183円** | **−78,587円** |
| 悲観（4回＋S-3 が 10/3 を越えて10月に1回） | 5 | €245＝43,659円 | 3,638円 | −61,123円 |
| 参考：マサルの置き値 | 1 | €49＝8,732円 | 728円 | −96,050円 |

- **年7回までは Pro×12 より安い**（7回で 61,123円 < 62,014円。8回で逆転）。再契約の回数は数えておく。
- マサルの感度（固定費 月1,000円 ≒ 3.5pt）を当てると、中央の3回は置き値（1回）より月 +1,455円で約 −5pt、悲観の5回で約 −10pt（推測・線形近似）。重みづけ 57% は、中央で約 52%、悲観で約 47% になる（推測）。それでも C（API を続ける・44%）は上回る。API の月が増えれば読みの精度も上がるので、実際の下がり幅はこれより小さい（推測）。
- 数字に入れていないもの：カードの海外利用手数料（推定 1.6〜2.2%＝中央で年 約420〜580円）、再契約時の値上げ（仮定：なし。Keepa は 2026-03 に Pro を €19→€29 に上げている）、20トークン/分プランの廃止（仮定：なし）。

## 4. 会計

- **経費計上：** 請求月に全額を経費にする（1か月の前払いなので按分は要らない）。科目は通信費か支払手数料。円の額はカード明細の円換算額を使う（税理士確認推奨）。
- **消費税（リバースチャージ）：** 申告が要るのは「一般課税で、課税売上割合が95%未満」の事業者だけ。免税事業者は消費税の申告自体が要らないので、関係しない（国税庁 No.6118 注4）。Keepa の価格は税抜き表示で、当社の領収書は €49.00 の1行だけ。課税事業者になるとき（最短 2029年）に見直す。
