## STEP0. 事前準備・登録先（一度きり／仕入れを始める前に）

- [ ] **Amazon出品用アカウント**（大口推奨・月額4,900円）を開設済みにする
- [ ] **Chrome拡張「ショッピングリサーチャー」** を導入（出品可否・利益計算の補助）
- [ ] **リサーチ補助ツール**（Keepa 等）の要否を判断（※有料契約は §4.1 該当＝社長承認が必要）
- [ ] **古物商許可** … 中古（A-6 中古市場）を仕入れるなら必須。新品電脳のみなら不要
- [ ] **主要仕入れ先のアカウント開設**（まず難易度「簡単」から）
  - [ ] NETSEA（国内卸・無料）
  - [ ] ヨドバシ.com / 楽天 / Yahoo!ショッピング（量販・ポイント還元）
  - [ ] ※その他は `suppliers-list.csv` の「初心者向き度」が高い順に
- [ ] **仕入れ記録CSV**（月別ログ）のひな形を用意（列例: 仕入日/ASIN/商品名/仕入先/仕入単価/数量/送料/見込利益/領収書ファイル名）

> 💡 STEP0は「登録の地図」。どこに登録すべきかは仕入れ先リスト（`suppliers-list.csv`）の URL・難易度・支払方法の列を見ながら進めてください。

## STEP1. 出品可否チェック（商品ごとに毎回）

- [ ] セラーセントラル ＞ カタログ ＞ 商品登録 ＞ 検索窓に **ASIN/JAN を入力**
- [ ] **コンディション（新品/中古）を選択**して結果ボタンを確認
- [ ] 表示されたボタンで3分岐を判定：
  - 「**この商品を出品する**」→ 制限なし。**トラップ確認**へ
  - 「**出品を申請**」→ 制限あり。**STEP2（解除）**へ
  - 「**出品情報のコピー**」→ 出品不可。別販路 or 後日再確認 → **候補から外す**
- [ ] **トラップ確認（制限なしでも要チェックの2点）**
  - [ ] 「ノーブランド品」エラーが出ないか（出たら出品不可寄り）
  - [ ] コンディションで「新品」が選べるか（選べないなら見送り）
  - → 両方OKなら **STEP3（利益計算）** へ

## STEP2. 出品制限の解除（制限ありのときだけ・図③）

### まず制限の種類を見る（申請画面の一番上）
- [ ] **カテゴリー制限** → 現物の商品写真を複数枚アップロードで解除（明るい場所・型番くっきり）＝比較的簡単
- [ ] **ブランド制限** → 下の「3段階解除」へ（コストの安い順に試す）

### ブランド制限の3段階（上から順に・通ったら終了）
- [ ] **第1段階：0円解除** … 直近半年の「無関係な領収書」（水・日用品等）で申請。マイナーメーカーは通りやすい
- [ ] **第2段階：1点だけ購入** … 該当メーカーをヨドバシ等で「安い順」検索→最安1点購入→その領収書で申請（数円〜数百円）
- [ ] **第3段階：10点で王道申請** … 同じ商品を9点買い足し計10点の領収書で申請。※高額品は「今後ペイできるか」で判断（無名ならスルー可）

### 承認率を上げる工夫（全段階共通）
- [ ] 領収書PDFに**赤枠＋注記**（注文日/氏名・住所/商品名/JAN/数量）
- [ ] 2ページ目以降に**補足スクショ**を添付

### 解除したのに出品できない3つの落とし穴
- [ ] **①表記違い**（ｶﾀｶﾅ↔英: PANASONIC等）→ 同じ領収書で表記を変えて再申請
- [ ] **②メーカー名の勘違い**（例: PlayStation の権利元は SIE。ソニー名では解除されない）→ 正確なブランド名で
- [ ] **③カテゴリー二重ブロック**（ブランド解除してもカテゴリ制限が残る）→ 現物写真UPで解除
- [ ] ※**トランスペアレンシー（青いT）** が出たら、電脳せどりでは**スルー**が合理的

## STEP3〜4. 利益判定と仕入れ先選定

- [ ] **STEP3 利益計算**：真の利益・**利益率20%以上**か（手数料・送料込み）。NoGo なら候補から外す
- [ ] **STEP4 仕入れ先を選ぶ**：`suppliers-list.csv` を「予算 / 使える時間 / 扱うジャンル / 初心者向き度」で絞り込み

## STEP5. 発注・決済・領収書取得（ここが最重要・解除に効く）

- [ ] 仕入れ先で発注・決済
- [ ] **領収書PDFを取得**し、次の必須条件をすべて満たすか確認：
  - [ ] ①発行が**180日以内**
  - [ ] ②**氏名・住所がアカウントと一致**
  - [ ] ③**仕入先の名前・住所**が記載
  - [ ] ④**10点以上**の購入（王道申請に使う場合）
  - [ ] ⚠️ **Amazonからの仕入れ領収書は絶対NG**（解除申請に使えない）

## STEP6. 記録 → 出品へ

- [ ] 仕入れ記録CSV（月別ログ）に記入
- [ ] → 「6. 出品・カタログ登録」へ進む（全体像①の本流に合流）

### この章の要点（社長メモ）
1. **STEP1の3分岐＋トラップ2点**を間違えなければ、ムダ仕入れの大半は防げる。
2. **解除はコストの安い順（0円→1点→10点）**。いきなり10点買わない。
3. **領収書の4条件**を満たさないと、せっかくの解除申請が無駄になる。とくに**Amazon仕入れNG**は事故が多い。
