## STEP1. 「5点セット」を準備

- [ ] **① 本人確認書類**（最重要・社長の現在の停滞ポイント）
  - 顔写真付き身分証：運転免許証 / パスポート / マイナンバーカード のいずれか1点
  - **過去180日以内**の住所確認書類：クレジットカード明細 / 銀行取引明細 / 各種公共料金・請求書 のいずれか1点
  - ⚠️ **書類の住所と、登録で入力する住所を完全一致**させる（番地・建物名・部屋番号まで）
- [ ] **② 決済用クレジットカード**（→ セゾンカードデジタル：社長保有済 ✅）
- [ ] **③ 売上の受取用 銀行口座**
  - 屋号なしの**個人口座でOK**
  - ⚠️ ネット銀行（住信SBI / 楽天銀行 等）だと明細取得がラクで**確定申告が楽になる**
- [ ] **④ 事業用メールアドレス**（私用と分けると通知管理がラク）
- [ ] **⑤ 携帯電話番号**（SMS認証に使用）

## STEP2. 出品プランを選ぶ

- [ ] **小口プラン**を選択（→ 社長確定済 ✅）
  - 月額0円＋1点売れるごとに100円
  - 月の販売数が **約50個** を超えたら大口（月4,900円）への切替を検討（4,900 ÷ 100 = 49個が損益分岐）

## STEP3. Amazon出品アカウント登録（セラーセントラル）

- [ ] [sell.amazon.co.jp](https://sell.amazon.co.jp/) から登録開始
- [ ] 事業者情報（個人・氏名・住所）を入力 — ⚠️ STEP1の書類と完全一致で
- [ ] 受取口座・決済カードを入力
- [ ] 商品の出品準備（カテゴリ等）はこの時点では仮でOK

## STEP4. 本人確認（KYC）

- [ ] **ビデオ通話**または**書類アップロード**で本人確認審査を受ける
- [ ] ⚠️ **撮影は明るく・反射なし・鮮明に**（暗い/ブレ/反射は差戻しの定番）
- [ ] ⚠️ 氏名のヘボン式ローマ字・漢字のゆれに注意（書類と入力を一致）

## STEP5.（ゲート）アカウントが有効化された？

- [ ] **有効化OK** → STEP6 へ
- [ ] **差戻し** → 指摘箇所（多くは住所不一致・書類の鮮明さ）を直して**再提出**（STEP4へ戻る）

## STEP6. セラーセントラル初期設定

- [ ] 受取口座・決済カードの**最終確認**
- [ ] **返品設定・特定商取引法に基づく表記・各種通知**を設定
- [ ] 通知メールが事業用アドレスに届くか確認

## STEP7. リサーチ環境を整える

- [ ] **リサーチツール導入**（ERESA PRO 等 → 別チケット **T-20260527-001**・§4.1承認案件）
- [ ] 仕入れ先サイトの**会員登録**（ネットショップ・卸サイト等／詳細はフロー②と仕入れ先リスト）

## → 準備完了

- [ ] **フロー①「1. リサーチ」へ進む**（＝T-004 の本番がスタート）

## 【並走】事業形態に応じた届出（任意だが推奨）

メインフローと並行して進めてOK。**仕入れ→出品が始まってからでも間に合う**ものもありますが、早めが安心です。

### 青色申告したい場合
- [ ] **開業届**を税務署へ提出（開業から**1ヶ月以内**が目安）
- [ ] **青色申告承認申請書**を提出（開業から**2ヶ月以内**が期限・⚠️ 遅れると初年度は白色に）
- [ ] → 最大65万円の控除・赤字繰越などの節税メリット

### 中古品を扱う場合
- [ ] **古物商許可**を管轄警察署へ申請（手数料 **約19,000円**・取得まで**約40日**）
- [ ] ⚠️ **新品をメーカー/卸/正規店から仕入れて売るだけなら原則不要**。中古の買取・転売を行うなら必須
- [ ] 判断に迷えば **ハルオ（法務）** に確認（waiting で起票します）

---

### つまずき防止トップ3（社長メモ）

1. **本人確認の差戻し**（住所不一致・撮影不鮮明）→ 書類と入力を完全一致、明るく鮮明に
2. **青色申告承認申請の期限切れ**（開業2ヶ月以内）→ 開業届とセットで早めに
3. **古物商の要否を誤解** → 「新品仕入れのみなら原則不要」。中古を始める前に取得
