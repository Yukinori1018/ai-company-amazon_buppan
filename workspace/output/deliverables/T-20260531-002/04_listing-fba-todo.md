# ④ 出品〜FBA納品 ToDo チェックリスト

> 対象チケット: T-20260531-002 ／ 作成: 秘書カズヨ ／ 2026-05-31
> 対の図解: `04_listing-fba-flow.png`
> 前工程: `02_sourcing-todo.md`（仕入れ）／ 後工程: フロー①「8. 販売」

仕入れた商品をFBA倉庫に届けて販売可能化するまでのToDoです。**事故が起きやすい所**を太字＋⚠️で示しています。

---

## STEP1. 出品登録（既存ASINに相乗り）

- [ ] セラーセントラル ＞ カタログ ＞ 商品登録 ＞ ASIN/JAN検索
- [ ] **コンディション＝新品** を選択
- [ ] **「この商品を出品する」**ボタンで登録（※「出品情報のコピー」が出たら出品不可＝事前に弾けているはずだが念のため確認）

## STEP2. 価格・在庫を設定

- [ ] **現在のカート価格**を Keepa／ショッピングリサーチャーで確認
- [ ] 価格は **±数円〜数十円** で攻める（FBA相乗りはカート争奪が肝）
- [ ] **在庫数を入力**
  - 不足 → 機会損失
  - 過剰 → 長期保管料（180日以降は段階的に課金）

## STEP3. 出品形態＝FBA、納品プラン作成

- [ ] 「FBA」（Amazonからの発送）を選択
- [ ] **梱包要件**を確認
  - 「メーカー梱包そのまま可」か、追加梱包が必要かを判定
- [ ] **⚠️ 危険物該当性チェック**
  - リチウム電池・エアゾール・化粧品（液体）等は要確認
  - 該当時 → FBA禁止 or 専用プラン（**自己発送に切替**が早い場合あり）

## STEP4. 商品ラベル（FNSKU）の印刷・貼付

- [ ] ラベル設定で **「Amazon商品ラベル」** を選択（**⚠️「メーカーバーコード」設定はしない**）
- [ ] FNSKU を印刷し、商品に貼付
- [ ] **⚠️ JAN（既存バーコード）を完全に覆う**ように貼る（二重バーコード→倉庫で別商品と混在事故）
- [ ] **透明OPP袋** で1商品1袋に密封（小物・布物・ポーチ等は必須）

## STEP5. 配送先倉庫の確定

- [ ] 倉庫が**自動分割**されたら統合可否を判断
  - 小ロット → 統合手数料を払う方が送料安い（送料分岐点≒2,000円/箱）
  - 大ロット → 分割のまま発送
- [ ] **パートナーキャリア（ヤマト/日本郵便）** か**自己手配**を選択
  - 初期は**ヤマトパートナーキャリア**が無難（1箱600円〜）

## STEP6. 外装ラベル（配送ラベル）の印刷・貼付

- [ ] 1箱=1ラベル
- [ ] **⚠️ サイズ・重量制限**: 重量 **20kg以内** ／ 三辺合計 **170cm以内**（超過は別途料金）
- [ ] 箱の中身一覧（必要なら）

## STEP7. 集荷依頼 or 持ち込み発送

- [ ] パートナーキャリアなら**集荷依頼**（前日までに）
- [ ] 自己手配なら**営業所持ち込み**で割引

## STEP8. 倉庫到着・受領（数日〜2週間で在庫反映）

- [ ] 配送追跡で**倉庫到着**を確認
- [ ] セラーセントラルで**在庫反映**まで待機（受領まで通常2〜7日、繁忙期は2週間）
- [ ] **⚠️ 数量差異**が出たら「在庫調整リクエスト」で申請（領収書PDFが必要）

## → 完了

- [ ] 販売可能（フロー①「8. 販売」へ）

---

### 事故が多いトップ3（社長メモ）

1. **ラベル設定ミス**（メーカーバーコード設定 or JAN露出）→ 他出品者の在庫に混ざる重大事故
2. **危険物見落とし**（化粧品・電池）→ 倉庫で受領拒否、返送料発生
3. **倉庫分割の放置**→ 想定外の送料増（小ロットほど痛い）
