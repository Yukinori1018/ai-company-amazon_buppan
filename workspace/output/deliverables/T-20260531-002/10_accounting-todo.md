# ⑩ 入金・会計 ToDo チェックリスト（売上回収 → 利益確定 → 記帳 → 申告）

> 対象チケット: T-20260531-002 ／ 作成: 秘書カズヨ ／ 2026-06-03
> 対の図解: `10_accounting-flow.png`
> 前工程: フロー①「9. 受注〜配送」／ 後工程: フロー①「11. 振り返り」
> 関連: 経理ハジメの領域（数字判断は経理に発注）

仕入れて売った後の「お金の流れ」を、社長がそのまま手を動かせる ToDo に落としました。
ポイントは **(1) 入金は仕入れより遅れて入る（資金繰り）**、**(2) 手数料控除後が「真の利益」**、**(3) 記帳を自動化して確定申告を軽くする** の3点です。

---

## STEP0. 事前準備（一度きり／会計の土台づくり）

- [ ] **売上金の受取口座**を確認（ネット銀行＝住信SBI/楽天が明細取得◎）
- [ ] **会計ソフト**の要否を検討（freee／マネーフォワード等。※有料契約は §4.1 該当＝社長承認が必要）
- [ ] **領収書・請求書の保管ルール**を決める（月別フォルダ／PDFファイル名の付け方）
- [ ] **仕入れ記録CSV**（②仕入れToDoのSTEP0で用意したもの）と突き合わせる運用を決める

---

## STEP1〜3. 売上回収〜売上金の確定（Amazon側で自動進行）

- [ ] **売上はいったん「売上金（残高）」にプール**されることを理解する
- [ ] **手数料が自動控除**される内訳を把握：
  - [ ] 販売手数料（カテゴリ別おおむね **8〜15%**）
  - [ ] FBA配送手数料（サイズ・重量で変動）
  - [ ] 在庫保管料（月割／**180日超で長期保管料**が加算）
  - [ ] 返金関連手数料（返品が出たとき）
- [ ] **清算サイクル＝原則14日ごと**に売上金が確定することを把握
- [ ] **⚠️ リザーブ（売上金の保留）**に注意：
  - 新規アカウントは **7〜14日保留**される
  - A-to-Z・チャージバックがあると**引当金が増える**
  - → **入金は遅れる前提**で資金繰り（仕入れ→入金のズレ）を組む

---

## STEP4. レポートを取得・保管（月次）

- [ ] セラーセントラル ＞ レポート ＞ **ペイメント（取引明細）／サマリー**を確認
- [ ] **月次でCSVをダウンロード**して保管（記帳と確定申告の証憑）
- [ ] 売上・手数料・返金・広告費（使う場合）を月別に集計

---

## STEP5. 記帳（仕訳）

- [ ] 月次で次の科目を計上：
  - [ ] **売上**（Amazon入金ベースではなく発生ベースが原則）
  - [ ] **仕入**（仕入記録CSV＋領収書PDFと一致させる）
  - [ ] **支払手数料**（販売手数料・FBA手数料・保管料）
  - [ ] **荷造運賃**（納品送料・自己発送の送料）
  - [ ] **返金・貸倒**（返品分）
- [ ] **会計ソフトのAmazon連携で自動取込**すると大幅に楽（手入力地獄を回避）

---

## STEP6. 月次の採算チェック（KPIに直結）

- [ ] **利益率20%以上**を満たしているか（手数料・送料控除後の「真の利益」で見る）
- [ ] **キャッシュフロー**：仕入れ支出と入金のズレで資金がショートしないか
- [ ] 未達なら → ②仕入れフローの「利益計算」基準やSKU構成を見直す（→ フロー①「11. 振り返り」へ）

---

## 【年次】確定申告の準備（毎年 1/1〜3/15）

- [ ] **棚卸し（12/31時点の在庫）** を計上
  - ⚠️ **売れ残り在庫は当年の経費にならない**（売上原価として翌期へ繰越）
- [ ] **青色申告**で提出（事前に開業届＋青色申告承認申請が必要＝⑤事業準備の並走届出）
  - [ ] 帳簿・領収書・請求書は **7年保管**
  - [ ] **最大65万円の青色申告特別控除**を取りに行く
- [ ] **⚠️ 消費税の分かれ目**を確認：
  - 売上 **1,000万円超** → 2年後に課税事業者
  - インボイス登録の要否は取引先要件で判断
  - → 迷えば **ハジメ（経理）／ハルオ（法務）** に確認

---

### この章の要点（社長メモ）

1. **入金は遅れて入る**（リザーブ＋14日サイクル）。仕入れの資金繰りは「入金待ち」を織り込む。
2. **「真の利益」は手数料控除後**。額面の売上に惑わされない。利益率20%はここで判定。
3. **記帳は自動化**（会計ソフト＋Amazon連携）。証憑（領収書・取引明細）の月次保管が確定申告を救う。
4. 数字の判断（資金繰り・節税・課税事業者化）は **経理ハジメ** に投げてOK。
