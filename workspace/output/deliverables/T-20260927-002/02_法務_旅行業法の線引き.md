# 観光ガイド事業「仕組み化して人を使う」形の法的線引き

法務ハルオ / 2026-09-27 / T-20260927-002
一次情報：e-Gov 法令検索（旅行業法・同施行規則・登録免許税法・通訳案内士法・道路運送法）、観光庁（施行要領・通達・概要ページ）、東京都産業労働局（新規登録申請案内書）、JATA（研修プレスリリース）。確認日はすべて 2026-09-27。

## 0. 結論（3行）

1. **社長がやりたい形（外注ガイドを手配し、客から代金を受け取る）は、運送・宿泊を一切含めない限り、無登録で適法にできます。** 根拠＝旅行業法2条1項の各号が「運送又は宿泊」を起点に組まれており、ガイド（運送等関連サービス）単体は同項1〜8号のどれにも当たらない（観光庁施行要領 第一1-3)②「ガイド等」を明記）。
2. **境目は3つだけ。**①運送・宿泊を商品に入れた瞬間 → 旅行業登録。②旅行会社（海外OTA含む）**のために**無資格ガイドを手配した瞬間 → 旅行サービス手配業登録。③募集型企画旅行にした瞬間 → 第2種以上（拠点区域内に収めれば第3種／地域限定）。
3. **ガイドが自分の車で客を運ぶのは違法（原則NO）。** 例外規定に当たらず、可逆性がありません。

**依頼文の罰条に誤りがあるので先に訂正します。** 道路運送法78条違反の罰則は**97条1号（1年以下の拘禁刑または150万円以下の罰金、併科可）**です。依頼文の「3年以下・300万円以下」は**96条1号＝4条1項違反（無許可で一般旅客自動車運送事業を経営）**の罰則で、条文が別です（両方が問題になり得ます。§4参照）。

## 1. ①6行為 × 登録要否

前提：いずれも「報酬を得て」「事業として（反復継続の意思あり）」行う場合。報酬・事業性が無ければそもそも旅行業に当たりません（施行要領 第一1-1)、観参第957号 4.(1)）。

| # | 行為 | 旅行業登録 | 旅行サービス手配業登録 | 決め手 |
|---|---|---|---|---|
| 1 | 自分がガイドとして客を案内し報酬を受ける | **不要** | **不要** | 運送等関連サービスを**自ら提供**する行為。2条1項1〜8号はすべて運送又は宿泊を起点とする。通訳案内士法の資格も2018-01-04以降は不要（§3） |
| 2 | **外注ガイドを手配し、客から代金を受け取り、ガイドに報酬を払う**（社長の希望形） | **不要**（運送・宿泊を含まない限り） | **不要** | 旅行業＝2条1項各号に限定。ガイドのみの手配・提供は施行要領で明文除外。手配業は「**旅行業を営む者のため**」の行為に限る（2条6項）ので、旅行者から直接受注する形は名宛人でない |
| 3 | 2 に運送（タクシー・バス）や宿泊の手配を加える | **必要** | 不要（旅行業者は34条1項で手配業登録免除） | 2条1項3号（旅行者のため運送等サービスの提供を受けることについて代理・媒介・取次ぎ）に該当。種別は§2・§5 |
| 4 | Viator・GetYourGuide・Klook・Airbnb体験に**事業者として出品**し、そこ経由で 2 を行う | **条件付き**（下記） | **条件付き**（下記） | **プラットフォームが誰と誰の契約を成立させているかで反転する。判定不能ではなく、契約構造を確認すれば決まる** |
| 5 | 自社サイトで**募集型企画旅行**として商品を作って売る | **必要** | 不要 | 2条1項1号＋4項。ただし「企画旅行」は**運送等サービスの提供契約を自己の計算で締結すること**が要件。運送・宿泊を一切含まない体験は法律上「企画旅行」にならない（＝ 2 と同じ扱い） |
| 6 | 海外の旅行会社から依頼を受け、国内手配だけ請ける（ランドオペレーター） | 不要 | **無資格ガイドを手配するなら必要／有資格ガイドのみなら不要** | 2条6項＋施行規則1条2号。§1.2 参照 |

### 1.1 #4 の分岐（条件を書き切ります）

| プラットフォーム上の契約構造 | 判定 |
|---|---|
| **A：社長が旅行者と直接契約し、PFは掲載・決済代行のみ**（PFが「あなたと供給者の契約です」と表示） | #2 と同じ＝**無登録可**（運送・宿泊を含めない限り） |
| **B：PFが旅行者と契約し、社長はPFに体験を卸す（社長＝サービス提供者）** | 社長は運送等関連サービスの**提供者**。手配業2条6項は「サービスを提供する者との間で代理・媒介・取次ぎ」する側にかかる規定なので、提供者本人は該当しない＝**無登録可** |
| **C：PFが旅行者と契約し、社長は PF のために外注ガイドを手配する（＝仲介）** | **旅行サービス手配業の登録が必要**。PFは「外国の法令に準拠して外国において旅行業を営む者」に当たり得る（2条6項かっこ書き）。無資格・有償の通訳案内の手配は除外されない（施行規則1条2号） |

> **社長がやりたい「人を使う」形は、PF上では C に寄ります。** 2のB2Cを自社で持つか、Cを選んで手配業登録（実費42,000円・§2）を取るかの二択です。どちらのモデルかは**PF利用規約の契約当事者条項で確定させてから出品**してください。規約を読まずに出品した場合、判定不能ではなく**無登録営業のリスクを抱えたまま営業している状態**になります。

### 1.2 #6 の分岐（ここが最も実務的に効きます）

施行規則1条2号は、本邦内の運送等関連サービスの手配を手配業の対象から外しつつ、**次の2つだけを除外の対象外（＝登録必要）**にしています。

- 「**全国通訳案内士及び地域通訳案内士以外の者による有償による通訳案内**」の手配
- 輸出物品販売場（消費税免税店）における物品販売の手配

| 手配するガイド | 手配業登録 |
|---|---|
| 無資格者・有償・外国語で外国人を案内 | **必要** |
| 全国通訳案内士／地域通訳案内士（有償） | **不要**（除外される） |
| 無償のボランティアガイド | **不要**（除外される） |
| 日本語のみで日本人客を案内（＝通訳案内でない） | **不要**（通訳案内士法2条1項の定義に当たらない）。ただし「外国人に日本語で案内」は「外国語を用いて」の当てはめに解釈の余地があり**未確認＝グレー。外国人客はグレーに置かず、資格者を使うか登録を取ること** |

### 2.1 旅行業務取扱管理者（社長が取る必要があるか）

| 論点 | 判定 | 根拠 |
|---|---|---|
| 選任義務 | **営業所ごとに1人以上。取扱者が1人の営業所でも免除されない** | 法11条の2第1項・3項 |
| 外部委託できるか | **できません。** 他の営業所の管理者との兼任も不可。東京都は申請案内書で「常勤専任で就業のこと」と明記 | 法11条の2第4項／東京都案内書 |
| 名義貸しで済ませられるか | **絶対に不可。1年以下の拘禁刑若しくは100万円以下の罰金、併科可**（名義利用・他人経営の禁止） | 法14条 → 法74条4号 |
| 試験の頻度 | **年1回**。総合＝10月下旬の日曜/祝日、国内＝9月上旬〜下旬のCBT、地域限定＝9月下旬の日曜 | 観光庁「旅行業務取扱管理者」ページ |
| 受験手数料 | 総合13,000円／国内8,000円／地域限定5,500円 | 同上 |
| 定期研修 | 選任後、**5年ごと**に協会の定期研修を受講させる義務 | 法11条の2第7項 |
| **旅行サービス手配業の管理者** | **試験が要らない。**研修修了で可。JATAは2026-01-26からオンライン・通年随時受付、**初回研修27,000円（税込）**。修了後5年経過なら継続研修14,300円＋システム利用料660円 | 法28条5項／JATA 25-018（2026-01-22） |

> **結論：社長本人が取るのが唯一現実的です。** ただし手配業なら「年1回の試験」を待たずに**通年・オンラインで27,000円**で資格が揃います。旅行業に進むと、9〜10月の年1回の試験が事実上のスケジュール律速になります。

## 3. ③通訳案内士法との関係

**当社の理解は正しく、「他人を使ってガイドさせる」場合にも当てはまります。**

| 論点 | 判定 | 根拠 |
|---|---|---|
| 無資格者に有償の通訳ガイドをさせられるか | **できます。** 2018-01-04 施行の改正法（平成29年法律第50号）で業務独占規定が削除され、現行法に**業務独占を定める条文は存在しません**（条文を全文検索して不存在を確認） | 通訳案内士法（現行）全条 |
| 残っている規制 | **名称独占のみ。**「全国通訳案内士」「地域通訳案内士」およびこれに**類似する名称**を無資格者に使わせてはいけません | 52条・60条 |
| 名称違反の罰則 | **30万円以下の罰金** | 64条4号・7号 |
| 手配する側への影響 | **通訳案内士法は自由化されたが、旅行業法側で代償措置が入っている。**「全国通訳案内士及び地域通訳案内士以外の者による有償による通訳案内」の**手配**は旅行サービス手配業の登録対象（§1.2） | 施行規則1条2号／施行要領 第二1-4)ロ) |

**実務上の注意（外注ガイドを募集・掲載するとき）**

- 募集要項・商品ページ・ガイド紹介欄で、無資格ガイドに「通訳案内士」「通訳ガイド」等の資格を想起させる肩書を付けない。**社長が「使わせた」形でも52条・60条の違反は成立し得ます**（行為者は名称を用いた本人、社長は業務主体としての管理責任）。
- 有資格者を使う場合、**地域通訳案内士は資格を得た業務区域を明示し、区域外を表示してはならない**（58条、違反30万円＝64条6号）。
- 安全側の表記例：「英語対応ガイド」「英語ガイド（全国通訳案内士◯◯）」。NG例：「通訳ガイド」「認定ガイド」「公認ガイド」。

## 4. ④白タク規制との線引き

| 形 | 判定 | 根拠・罰則 |
|---|---|---|
| **ガイドが自分の車で客を運ぶ** | **違法。原則NO。** 自家用自動車の有償運送は78条で原則禁止。例外は①災害緊急時②市町村・NPO等の自家用有償旅客運送（79条の登録が必要で、**個人事業者は主体になれない**）③公共の福祉のための国交大臣許可、の3つのみ。社長・外注ガイドはどれにも当たらない | 78条違反 → **97条1号：1年以下の拘禁刑または150万円以下の罰金（併科可）**。さらに事業として反復継続すれば4条1項違反 → **96条1号：3年以下の拘禁刑または300万円以下の罰金（併科可）**。法人にも罰金（99条2号） |
| ツアー代金に運送分を明示しない／「送迎は無料」とする | **NO。**「有償」の判定は名目ではなく実態。観光庁は旅行業法側でも「行為と収入の間に相当程度の関係があれば報酬に該当する」としており、同じ発想で運送対価の切り出しは通りません | 施行要領 第一1-2)(2)／施行要領Q&A 問4 |
| 社長が現役タクシードライバーである点 | **無関係。**許可は**事業者**に対するもの（4条1項「経営しようとする者」）。二種免許があっても、車両が許可事業者の事業用自動車でなければ自家用＝78条。勤務先車両が使えない前提なら、社長個人の運送は全部違法側 | 4条1項・78条 |
| **運送をタクシー会社／貸切バス事業者に発注する** | **道路運送法上は適法。ただし旅行業法が起動します。**旅行者のために運送サービスの提供を受ける契約を代理・媒介・取次ぎする行為＝旅行業2条1項3号 → **旅行業登録が必要** | 旅行業法2条1項3号・3条 |
| 客が自分でタクシーを呼び、社長は一切関与しない | **適法・無登録可。**ただし遅くとも予約確認画面に移る前までに「旅行者と運送事業者の間の取引である」と明確に表示され、システム上もそうなっている必要があります | 観参第957号 4.(5) |
| 徒歩・公共交通（客が自分で切符を買う）だけのツアー | **適法・無登録可。**観光庁は「ウォーキングツアー等の観光アクティビティは運送サービスではなく運送等関連サービス」と明示 | 観参第957号 1. |

**適法な代替（運送を諦めない場合の3案）**

| 案 | 内容 | コスト・条件 |
|---|---|---|
| A | 徒歩＋公共交通に限定し、切符は客が自分で買う | 0円・無登録可。**まずこれ** |
| B | 客自身がタクシー/配車アプリで手配。社長は同乗ガイドのみ | 0円・無登録可。**予約画面の契約主体表示が条件** |
| C | 社長が運送を手配する（貸切バス・観光タクシー） | 旅行業登録が必要。地域限定なら基準資産100万＋分担金3万＋手数料9万＋試験5,500円 |

## 5. ⑤社長の条件での実行順序（0円で始まる入口は存在します）

| 段 | やること | 登録 | 実費 | 境目 |
|---|---|---|---|---|
| **0** | 社長本人がガイド（徒歩／公共交通、運送・宿泊なし） | **不要** | **0円** | — |
| **1** | **外注ガイドを手配し、自社サイト・自社SNSで旅行者と直接契約**（＝社長の希望形） | **不要** | **0円**（決済手数料のみ） | 運送・宿泊を1つでも商品に入れたら段3へ |
| **2** | PFに出品。**契約構造がA/Bなら無登録可、Cなら手配業登録** | A/B：不要 / C：手配業 | A/B：0円 / C：**42,000円**（東京都15,000＋研修27,000） | **境目①**：PF利用規約の契約当事者条項。出品前に必読 |
| **3** | 海外旅行会社からランドオペレーターとして受注（無資格ガイドを手配） | **手配業** | **42,000円**＋標準60日 | **境目②**：有資格ガイドのみに限れば段2のまま（§1.2） |
| **4** | 運送（送迎・貸切バス）や宿泊を商品に入れる | **旅行業（地域限定 or 第3種）** | 地域限定：基準資産100万＋分担金3万＋手数料9万＋試験5,500円 / 第3種：基準資産300万＋分担金60万＋手数料9万＋試験8,000円 | **境目③**：拠点区域を越えるか、企画旅行を作るか |
| **5** | 募集型企画旅行を全国で、または海外客向けパッケージを販売 | 第2種／第1種 | 第2種：基準資産700万＋分担金220万 / 第1種：3,000万＋1,400万＋登録免許税9万 | 現条件（資金100万）では射程外 |

**この順序の要点**

1. **段1までは0円・無登録で、社長の希望する「人を使う」形が完成します。** 制約は「運送・宿泊を扱わない」の1点だけ。
2. **段2以降で最初に必要になる登録は、旅行業ではなく旅行サービス手配業（実費42,000円・財産要件ゼロ・試験なし・通年オンライン）です。** 資金100万円という条件下で、ここが最も費用対効果の高い一手です。
3. **試験が律速になるのは段4以降。**地域限定管理者試験は年1回・9月下旬。**2026年分はもう受付が終わっています**（受付期限7月下旬）。段4を2027年に想定するなら、2027年7月の願書を逃さないこと。
4. **段を飛ばさないこと。**「とりあえず送迎を付ける」が最も起きやすい事故で、段1から段4へ無登録で飛ぶ行為＝無登録営業です。

## 8. グレーゾーンとして残したもの（3点セット付き）

当職は「グレーは原則NO」を採りますが、社長条件（0円開始）で切り捨てると案が成り立たないものが1つあります。

**論点：外国人客に日本語のみで案内する無資格ガイドの手配（§1.2 の4行目）**

| 項目 | 内容 |
|---|---|
| リスクシナリオ | 「外国語を用いて」に当たらないので手配業登録は不要、と解釈して運用。行政が「実質的に通訳案内である」と認定 → 無登録営業（74条6号）→ 罰金 → **5年間登録不可（6条1項2号）** |
| 発生確率 × 影響度 × 不可逆性 | 確率＝低〜中（解釈の争いであり明文違反ではない）／影響＝大（刑罰）／**不可逆性＝最大（5年の登録禁止）**。3軸評価では**アラート水準** |
| 発生時の対応策 | ①開始前に**主たる営業所所在地の都道府県の旅行業担当課へ書面照会**し、回答を保存（観光庁は第2〜3種・地域限定・手配業の質問先を都道府県と案内）②照会中は有資格ガイドか日本人客に限定 |
| 撤退条件 | 都道府県から「該当し得る」と示唆された時点で即停止し、**42,000円で手配業登録を取ってから再開**（この額なら撤退より登録が安い） |

> **当職の推奨：この論点でグレーを踏む合理性はありません。**手配業の登録実費は42,000円・財産要件ゼロ・試験なし・通年受講可。5年の登録禁止リスクと引き換えにする額ではありません。**段2・段3に進む判断が出たら、解釈で回避せず登録を取ってください。**
