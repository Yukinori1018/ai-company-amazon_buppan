結論

  • 今すぐ要る登録 … 2件（＋ERESA無料試用） — 受取口座の確認 / NETSEA登録 / ERESA 7日無料試用
  • 任意・余力があれば … 2件（スーパーデリバリー / orosy）
  • C案に進むとき … 量販店アカウント数件（すべて無料）
  • 将来の届出（並走OK）… 2件（開業届＋青色申告 / 古物商）
今あなたが新たに手を動かすのは実質 「受取口座の確認 → NETSEA登録 → ERESA試用開始」の3つだけ。
お金が動く（=承認が要る）のは ERESA本契約・スーパーデリバリー・orosy有料・古物商 のみ。無料登録・試用は承認不要で進めます。

凡例: 🟢 済 完了 ／ ⬜ 未 これから ／ 🔶 要確認 Amazon登録時に設定済みかも ／ ⚠️ 要承認 金銭が動く新規契約（社内ルール§4.1）

#名称何のためか必須/任意料金承認現状入口・補足（つまずき注意）
2-1売上の受取用 銀行口座Amazon売上金の振込先。無いと入金されない必須無料—🔶 要確認セラーセントラルの出金設定で登録済みか確認。未登録なら個人口座でOK。ネット銀行（住信SBI/楽天）だと確定申告がラク。名義＝登録氏名を一致
2-2事業用メールアドレス注文・在庫・入金の通知受信準必須無料—🔶 要確認Amazon登録が私用兼用なら別途用意してもよい（Gmail等で十分）
2-3携帯電話番号（SMS認証）各サイトの本人確認・2段階認証必須無料—🟢 済新規取得不要。同じ番号を各サイトで使う
2-4NETSEA（ネッシー）会員登録B案の主力仕入れ先。新品を小ロット卸価格で必須（B案の起点）無料—⬜ 未netsea.jp ／ 買い手として無料登録。一部メーカーは取引審査あり。日用品・文具・収納を眺める
2-5ERESA PRO 7日無料試用「利益が出て売れる商品」を見分ける主軸ツール。Keepa内包準必須試用無料（後 月¥4,980）⚠️ 本契約は要承認⬜ 未eresa.jp ／ 試用開始は無料・承認不要。7日経過で自動課金に移行する設計が一般的。本契約前にカズヨ経由で承認
つまずき防止トップ3: ① 受取口座の未設定に気づかず出品 → 先に2-1を確認。② ERESA試用の自動課金 → 開始日をメモし7日以内に判断。③ NETSEAで規制カテゴリに手を出す → 日用品・文具・収納に限定。

B案で型を覚えてから。量販店の購入アカウント＋ポイント会員を作るだけで、すべて無料。

#名称何のためか必須/任意料金承認現状入口・補足
4-1ヨドバシ.com アカウントポイント還元込み実質価格で新品仕入れ（主力）C案で必須無料—⬜ 未yodobashi.com ／ ポイントは現金でなく次回値引き。実質仕入値で損益を見る
4-2ビックカメラ.com アカウントヨドバシの代替・比較C案で任意無料—⬜ 未biccamera.com

4-4（家電等に踏み込む場合）法務確認PSE・技適など規制カテゴリのリスク確認条件付き必須無料（社内）—⬜ 未カズヨ経由で法務ハルオへ。日用品・文具に絞れば不要

#名称何のためか必須/任意料金承認現状入口・補足（期限注意）

最短ルート（①→②→③で仕入れ開始）

【①受取口座の確認】 セラーセントラルで売上の振込先口座が登録済みか確認 │ （未登録なら個人口座を登録。ネット銀行が確定申告ラク） ▼ 【②NETSEA に無料登録】 買い手として登録 → 日用品・文具・収納を眺める │ （ここまで承認不要・お金ゼロ） ▼ 【③ERESA PRO 7日無料試用を開始】 NETSEAで気になった商品を ERESA で検索し │ 「利益が出て・売れる」か判定する練習（試用は無料） ▼ ＝ここまでで「仕入れ→出品→販売→入金」を回す準備が完了＝ │ ▼ （試用後に本契約したくなったら）ERESA PRO 月¥4,980 を ⚠️カズヨ経由で承認 → 契約

①②③はすべて無料・承認不要で今日着手できます。お金が動く（=承認が要る）のは ERESA本契約・スーパーデリバリー・orosy有料・古物商。進める段でカズヨが A/B/C＋推奨でお伺いします。

用語ミニ補足（初心者向け）
・セラーセントラル … Amazon出品者の管理画面。出品・在庫・出金設定を行う場所。
・KYC … 本人確認。アカウント有効化の審査。社長は通過済み。
・小口/大口プラン … 小口=月0円＋成約100円/点、大口=月4,900円。
・卸サイト（NETSEA等） … 小売店向けに新品を卸価格で売る仕入れ先。請求書が出るので出所が明確。
・ERESA / Keepa … 価格・売れ行き・競合を見るリサーチツール。ERESA PROはKeepaを内包。
