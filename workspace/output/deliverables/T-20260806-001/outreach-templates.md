# 打診テンプレート — 就労支援施設への梱包・ラベル貼り委託の問い合わせ

> 作成: サトル（リサーチャー） / 2026-08-06 / 対象チケット: T-20260806-001
> 使い方: ［　］は社長が状況に応じて埋める差し込み欄（個人情報・具体条件）。まずは「作業を受けてもらえるか」を確認し、見学アポにつなげるのが目的。
> 準拠: セミナー第2章①外注化・§8.5（作業可否確認→アポ→訪問説明→約1ヶ月テスト梱包の動線）。

---

## 0. 最初にかける先の順番（おさらい）

1. **共同受注窓口（おおた生産連）** … TEL 03-3734-0763 ／ 担当・鶴田氏 070-8336-5649 → テンプレ【A】
2. **個別施設（鵜の木から近い順）** … でじるみ／プレスト池上／明日楽 等 → テンプレ【B】（電話）・【C】（メール/フォーム）

> ポイント: いきなり「契約したい」ではなく **「継続的に委託できる施設を探している。まず作業を受けてもらえるか確認したい」** から入る。単価・数量・見学は、可否のあとに詰める。

## A. 電話台本 ①：共同受注窓口（おおた生産連）向け

> 狙い: 1本で「対応可能な施設の紹介」までもらう。個別に10施設回る手間を省く入口。

```
【名乗り】
お忙しいところ恐れ入ります。私、Amazonでの物販事業を営んでおります
［社長氏名／屋号：例 Satoy Select 佐藤］と申します。
おおた生産連さんが、区内の事業所さんへの共同受注の窓口とうかがってお電話しました。

【用件】
Amazonで販売する商品の「梱包」と「商品ラベル（バーコードシール）貼り」の軽作業を、
継続的にお願いできる就労支援施設さんを探しております。
月あたり［数量の目安：例 100〜300個程度］を想定していて、
まずは1ヶ月ほどのお試しから始めたいと考えています。
こうした軽作業を受けていただける施設さんを、ご紹介いただくことは可能でしょうか。

【確認したいこと（先方の反応を見て順に）】
・梱包・シール貼りのような軽作業を受託できる施設は、区内にありますか。
・A型・B型どちらでも、お受けいただける所を紹介いただけますか。
・作業単価（1個あたり）の相場観は、どのくらいでしょうか。
・私（発注側）が次にすべき手続き・進め方を教えていただけますか。

【クロージング】
ご紹介いただける施設があれば、直接ご連絡してご相談させてください。
本日はありがとうございました。
（連絡先：電話［　　　］／メール［　　　］）
```

## B. 電話台本 ②：個別施設 向け（A型・B型 共通）

> 狙い: ①作業を受けてもらえるか ②見学のアポ、の2つを取る。

```
【名乗り】
お忙しいところ恐れ入ります。
Amazonで物販事業をしております［社長氏名／屋号］と申します。
そちらで軽作業の受託（内職・下請け作業）を行っていらっしゃると拝見し、お電話しました。

【用件】
Amazonで販売する商品の「梱包（袋詰め・緩衝材での包装）」と
「商品ラベル（バーコードシール）貼り」を、継続的に委託できる施設を探しております。
作業自体はシンプルで、手順書をこちらでご用意します。
月あたり［数量の目安：例 100〜300個程度］、まずは1ヶ月のお試しから、と考えています。

【確認事項（チェックリスト）】
□ こうした梱包・シール貼りの軽作業は、お受けいただけますか？
□ 受けていただける場合、1個あたりの作業単価の目安は？
□ 最低ロット（1回あたり／月あたりの最小数量）はありますか？
□ 商品の受け渡し方法は？（こちらから納品／取りに来ていただく／宅配便着 など）
□ 納期の目安は？（例：週1回まとめて／◯日以内 など）
□ 作業に必要な資材（OPP袋・緩衝材・ラベル）は、こちらで支給する形でよいですか？
□ 一度、作業内容のご説明も兼ねて、施設を見学させていただくことは可能ですか？

【クロージング（見学アポ）】
もし前向きにご検討いただけるようでしたら、
一度ご訪問して作業のご説明とご相談をさせていただきたいのですが、
［候補日：例 来週の火・水・木の午前］あたりでご都合いかがでしょうか。
連絡先は 電話［　　　］／メール［　　　］です。よろしくお願いいたします。
```

> 電話が難しい施設・不在の場合は、下のメール／フォーム文面【C】へ。

## C. メール／問い合わせフォーム 文面（個別施設 向け）

> 施設公式サイトの問い合わせフォーム、またはメールにそのまま貼れる形。フォームで文字数制限がある場合は【短縮版】を使用。

### 【標準版】

```
件名：Amazon物販の梱包・ラベル貼り作業の委託について（ご相談）

［施設名］ ご担当者様

はじめてご連絡いたします。
Amazonで物販事業を営んでおります［社長氏名／屋号：例 Satoy Select 佐藤］と申します。

貴施設で軽作業の受託（内職・下請け作業）を行っていらっしゃると拝見し、
ご相談したくご連絡いたしました。

【ご相談内容】
Amazonで販売する商品の「梱包（袋詰め・緩衝材での包装）」および
「商品ラベル（バーコードシール）貼り」を、継続的に委託できる施設を探しております。
作業はシンプルで、手順書はこちらでご用意します。
まずは1ヶ月ほどのお試しから始め、問題なければ継続でお願いしたいと考えています。

・想定数量：月あたり［数量の目安：例 100〜300個程度］
・作業内容：袋詰め／緩衝材梱包／バーコードシール貼り／簡単な検品
・資材（袋・緩衝材・ラベル）：こちらで支給予定
・受け渡し：［こちらから納品／宅配便着／お引き取り］でご相談

【お伺いしたいこと】
1. 上記のような梱包・シール貼りの軽作業は、お受けいただけますでしょうか。
2. お受けいただける場合、1個あたりの作業単価の目安をお教えください。
3. 最低ロット（最小数量）や納期の目安はございますか。
4. 一度、作業内容のご説明を兼ねて見学させていただくことは可能でしょうか。

お忙しいところ恐れ入りますが、ご検討のほどよろしくお願いいたします。

──────────────
［社長氏名／屋号］
電話：［　　　　　　］
メール：［　　　　　　］
（Amazon店舗名：Satoy Select）
──────────────
```

### 【短縮版】（フォームの文字数が限られる場合）

```

販売商品の「梱包」と「バーコードシール貼り」の軽作業を、継続的に委託できる施設を探しております。
```

## 注意（CLAUDE.md §4.1 に関わる点）

- **本テンプレの送信・架電は「第三者連絡」に当たるため、実行は社長ご自身の判断・操作で**お願いします（当社ルール上、エージェントは外部発信を代行しません）。カズヨは文面整備・記録支援まで。
- 契約・有料委託の合意は「金銭が動く／法的拘束」に当たるため、条件が固まった段階で改めて経理（ハジメ）・法務（ハルオ）のチェックを挟むのが安全です。
