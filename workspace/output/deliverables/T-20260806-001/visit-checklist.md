## Part 1. 訪問時の作業説明チェックリスト（施設で説明・すり合わせる項目）

セミナーが挙げた5工程 **「受取 → 保管 → 梱包 → ラベル貼り → 引き渡し」** の順に、施設側と認識を合わせます。

### ① 受取（商品の受け取り）
- [ ] 商品はどうやって施設に届くか（こちらから納品／宅配便着／施設が引き取り）
- [ ] 受け取り可能な曜日・時間帯（施設の営業日：土日祝の扱い）
- [ ] 1回あたり受け入れられる数量・箱数の上限
- [ ] 到着時の**個数チェック（検品）**を誰がやるか、数量差異の連絡ルール
- [ ] 破損・不良品を見つけたときの取り扱い（よけておく／連絡する）
- [ ] 納品書・指示書の渡し方（紙／メール／管理表）

### ② 保管（作業前後の置き場所）
- [ ] 作業前の商品を置くスペースが確保できるか（**置き場所＝§8.5の要チェック項目**）
- [ ] 作業済み（梱包完了）商品の一時保管スペース
- [ ] 保管期間の目安（何日分まで置けるか）
- [ ] 資材（OPP袋・緩衝材・ラベル）の保管場所
- [ ] 湿気・直射日光・汚れなど、商品品質を損なわない環境か
- [ ] 保管に追加料金がかかるか

### ③ 梱包（袋詰め・緩衝材）
- [ ] 梱包手順を**手順書（写真つき）**で説明（こちらで用意）
- [ ] 使用資材の支給方法（袋・緩衝材はこちら支給か施設調達か）
- [ ] 1個あたりの標準作業（例：検品→袋入れ→緩衝材→封）を実演して見せる
- [ ] Amazon FBA/配送の**梱包要件**（袋の口を閉じる・商品が動かない等）を共有
- [ ] 商品ごとの注意点（割れ物・型崩れ・におい移り等）
- [ ] 見本（完成イメージの現物）を1つ渡せるか

### ④ ラベル貼り（バーコード／商品ラベル）
- [ ] 貼るラベルの種類（Amazonの商品ラベル＝FNSKUバーコード等）を説明
- [ ] **貼る位置・向き**の指定（既存バーコードを隠す等のルール）
- [ ] ラベルの支給方法（こちらで印刷して支給／データ渡し）
- [ ] 1商品に複数ラベルがある場合の貼り分け
- [ ] 貼り間違い・剥がれ時の対処
- [ ] スキャン確認（バーコードが読めるか）を施設側で行えるか

### ⑤ 引き渡し（完成品の返送・出荷）
- [ ] 完成品の受け渡し方法（こちらが引き取り／施設が発送／宅配便手配）
- [ ] 引き渡しの頻度（週1回まとめて／◯個たまったら 等）
- [ ] 完成数の報告方法（数量・作業日）
- [ ] 送り先（自宅／FBA代行倉庫／Amazon倉庫 等）の指定
- [ ] 出荷書類（納品書・送り状）の扱い

### ⑥ 全体の取り決め（契約前の確認）
- [ ] **単価（1個あたり）** と 最低ロット（§セミナー相場観：1商品5〜10円）
- [ ] 支払い方法・締め日・支払サイト
- [ ] 連絡窓口（担当者名・電話・メール）と、日々のやり取り手段
- [ ] 数量が増減したときの対応余地（キャパの上限）
- [ ] 情報の取り扱い（商品情報・数量などの守秘）
- [ ] トラブル時（ミス・破損・遅延）の連絡と補償の考え方

## Part 2. 約1ヶ月のテスト梱包 評価シート（§8.5の4項目で採点）

セミナー§8.5が示した4つの評価軸 **「置き場所・スピード・品質・ミス頻度」** を、1ヶ月のお試し期間で実測します。本採用（継続委託）の可否判断はこのシートで行います。

- **継続委託する / しない / 条件付きで継続（　　　　）**：［　　　　　　　　　］

> セミナーの流儀: **A型・B型の両方を試して比較**し、「安さ（B型）」と「安定性（A型）」のどちらが自事業の商品・数量に合うかを実地で見極める。代行業者は高コスト・融通が利かない・紛失リスクがあるため、施設委託が回り出せば単位コストで有利。
> 成功事例（池田さん）は委託マニュアルを自作・配布して品質を安定させた。テストで見えた注意点を**手順書に反映**していくと、本採用後の品質が上がる。
