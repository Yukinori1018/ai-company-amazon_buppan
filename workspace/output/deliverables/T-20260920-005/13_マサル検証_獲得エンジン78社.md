## 4. 指定論点 A〜G への回答

### A. 成約率の上昇曲線（2.0→3.3→5.0→6.7%）

**置き値を使うこと自体は否定しません**（社長の既定どおり）。問題は3点です。

| # | 指摘 | 確度 |
|---|---|---|
| **A-1** | **「当社の実測は1.16%」は実測ではありません。** 1.16% は私の04の**モデル出力**（2% × 劣化係数0.58）です。03 v3 の表でも出典は「マサル04」。**当社の成約率の観測値は現時点でゼロ件です。** モデル出力を実測として次の計画の土台に置くのは、過去に指摘のあった失敗型そのものです | **確実**（04・03 を照合） |
| **A-2** | **中村の 2.0%／3.3% は分母と分子の定義が当社と違う可能性が高い。** 彼の「成約」は取引口座の開設まで、当社の「成約」は初回発注（＝在庫と現金が動く）を指しています。口座開設まで進んで初回発注に至らない先は必ず出ます。私は**0.6〜0.8倍の目減り**を見ます | 推測・60% |
| **A-3** | **上がらなかった場合に何が起きるか。** 2.0% 据え置き（劣化なし）で必要接触は4,600通。**劣化を入れると 5,500通で、現行名簿2,425社の2.3倍**。名簿が尽きるので、上昇しない世界は「接触を増やして挽回する」ことができません。**率が上がらないことは、母数の問題に化けます** | 確実（計算） |

> **A の要点：上昇曲線そのものより、「上がらなかったときに名簿が残っていない」ことが怖い。** 保険（母数拡張）の発動を2027Q3に置く §0-2 は、**遅すぎます**（§6 で前倒しを提案）。

### B. 名簿劣化の扱い — **タケシの判断は誤りです**

| | |
|---|---|
| タケシの主張 | 劣化を上昇曲線に吸収させた。別建てにすると二重計上 |
| **私の判定** | **二重計上ではありません。別建てが正しい。** |

理由は、**2つが別の主語の話だから**です。

- **劣化**は**名簿**の性質。上位から撃つので、残りは適合度の低い先になる。送信者が上手くなっても、相手が変わるわけではない。
- **上昇**は**送信者**の性質。文面・道具・切り返しが良くなる。

両者は同じ時間軸を**逆向き**に走り、**掛け算**になります。

| | 24ヶ月の合成 |
|---|---|
| 技能の上昇 | ×3.35（2.0% → 6.7%） |
| 名簿の劣化（f が 0 → 0.84 まで進む） | **×0.37**（終盤） |
| **24ヶ月末の実効成約率** | 2.0 × 3.35 × 0.37 ＝ **2.5%** |

**結果、累計成約は 92社ではなく 53社**（接触2,037通は同じ）。**11 の出発点である「2,035通で92社」は 1.7倍の過大です。**

> タケシが「二重計上」と感じた理由は分かります。**出発点の 2.0% を、劣化込みの 1.16% と混同したから**です。1.16% は f を母数平均まで進めた後の値、2.0% は f=0 の値。**2.0% から始めるなら、劣化は必ず別建てで乗せます。**

**接触必要量は 1.3〜1.5倍ではなく、1.7倍（92社基準で 5,500通）に膨らみます。** タケシの見立てより悪い側です。
