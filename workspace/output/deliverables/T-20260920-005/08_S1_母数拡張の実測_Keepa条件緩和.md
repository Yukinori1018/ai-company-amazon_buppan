# S-1 母数拡張の実測 — Keepa の抽出条件を緩めると送信先は何社になるか

T-20260920-005 / タカシ / 2026-09-21。親: 03 2年ロードマップ §律速＝打診できるメーカーの母数 / 04 マサル検証。
現行の母数 2,425社の出典: T-20260914-006 S-A。

## 結論

| | 社数 | 80%区間 | 24ヶ月7,000通に対し |
|---|---:|---:|---:|
| **A 現行**（ランク5万・FBA2人以上） | **2,425** | 1,896〜2,984 | 35% |
| B ランク10万・FBA2人以上 | 2,818 | 1,896〜3,770 | 40% |
| C ランク20万・FBA2人以上 | 3,530 | 2,133〜4,957 | 50% |
| D ランク30万・FBA2人以上 | 4,270 | 2,532〜6,039 | 61% |
| **D＋規制3カテゴリを戻す（推奨）** | **5,842** | 3,529〜8,179 | 83% |
| E ランク5万・FBA**1人**以上 | 5,173 | 3,383〜7,043 | 74% |
| F ランク30万・FBA1人以上 | 21,232 | 8,893〜35,397 | 303% |

1. **ランクを6倍（5万→30万）に緩めても、母数は1.76倍（2,425→4,270）にしかなりません。** ASIN は2.06倍に増えますが、**増えた商品の82〜90%は「すでに名簿にいる会社」の別商品**だからです。母数を ASIN 数で語ると2倍近く過大に見えます。
2. **いちばん効くのは、いま除外している規制3カテゴリ（ドラッグ／ビューティー／食品）を戻すことです。** +1,572社（現行比+65%）を、**ランクを一切緩めずに**得られます。しかも質は現行より良い（後述）。薬機法・食品表示の確認が要るので、実行はハルオ判断とセットです。
3. **FBA を1人以上まで緩めるのは勧めません。** 社数は跳ねますが、その層は**61%が中国系OEM疑い**で、かつ「どの転売業者も二重に在庫を持っていない商品」＝型Aが前提にしている**転売需要の実証が無い**会社です。数字の精度も低く（80%区間が3倍幅）、意思決定には使えません。
4. **D＋規制3（5,842社）でも、24ヶ月の送信能力7,000通の83%止まりです。** 母数だけで送信能力を埋めるなら F まで行く必要がありますが、それは質を捨てることと同義です。**「母数を増やす」より「1通あたりの成約率を上げる」ほうに、このロードマップの余地は残っています。**

| 5万（現行） | 80,700 | 1,701,100 | 17,400 |
| 10万 | 111,200 | 2,316,000 | 25,200 |
| 20万 | 145,500 | 3,016,000 | 34,400 |

- FBA ちょうど1本は 1,618,900（＝1,701,100 − 80,800）。`offerCountFBA_lte` が効いていることを引き算で突き合わせて確認済み。`offerCountFBA_gte=999999` で0件になることも確認（Finder は知らないキーを黙って無視するため）。
- **ホーム＆キッチンはランク緩和で1件も増えません。** Keepa の root rank が全ランク合計で41,200件しかなく、5万位で尽きます。**「5万位以内」の意味はカテゴリごとに別物です。**
- 車＆バイクはランク5万超に11万件ありますが、本体なし＋FBA2人以上を掛けるとほぼ0になります。

ある社が新規かどうかは、**一段内側（より厳しい）条件でその社のブランドを Finder に引いて0件か**で判定しています。

## 3. 緩めると質はどうなるか

### 3-1. どんな会社が混じるか（標本 ASIN の判定内訳）

| 層 | 国内中小・ストアなし＝送信先 | 中国系OEM疑い | 大手 | 単品率 |
|---|---:|---:|---:|---:|
| S0 現行 | 18.3% | 22.2% | 32.3% | 29% |
| S1 ランク5万→10万 | **25.7%** | 8.0% | 36.9% | 52% |
| S2 ランク10万→20万 | **28.6%** | 8.9% | 33.7% | 59% |
| S3 ランク20万→30万 | 24.7% | 11.3% | 32.3% | 62% |
| R0 規制3・ランク5万以内 | **32.0%** | 6.4% | 10.0% | 50% |
| F0 FBA1人・ランク5万以内 | 14.5% | **61.4%** | 2.3% | 6% |
| F3 FBA1人・ランク5万→30万 | 11.5% | **56.4%** | 2.2% | 26% |

**ランク緩和は「どんな会社か」の軸ではむしろ改善します。** 中国系OEMはランク5万以内に集中しており（22%）、深いランク帯は国内ニッチメーカーの裾（8〜11%）です。ご依頼時の想定（緩めた分だけ質が落ちる）は、この軸では逆でした。

**質が落ちるのは FBA の緩和のほうです。** FBA1人だけの層は6割が中国系OEM疑い。しかも「FBA在庫を二重に持つ転売業者がいない」＝型Aが拠って立つ**転売需要の実証が無い**商品群です。

### 3-2. 売れているか（Amazon 公表の月間販売数 monthlySold）

社長の既定は「候補は月100個以上売れている商品とその類似品に絞る／入口は monthlySold で見る」（memory `feedback_volume_sellers_only`）。標本でその成立率を数えました。

| 層 | monthlySold が付いている | うち月100個以上 |
|---|---:|---:|
| S0 現行 | 20.5% | 9.5% |
| S1 ランク5万→10万 | 0.3% | 0% |
| S2 ランク10万→20万 | **0%** | 0% |
| S3 ランク20万→30万 | 0.3% | 0.3% |
| F0 FBA1人・ランク5万以内 | 5.2% | 1.4% |
| F3 FBA1人・ランク5万→30万 | 0.2% | 0% |
| **R0 規制3・ランク5万以内** | **56.0%** | **31.2%** |

**ランク5万位を超えると、公表販売数が付いた商品は事実上ゼロになります。** Amazon がバッジを出す閾値が5万位あたりにあるためです。つまり**ランク緩和は「月100個以上で入口を切る」という既定と原理的に両立しません**。

一方で**規制3カテゴリは、ランクを一切緩めないまま、現行より条件が良い**（公表販売数あり56%・月100個以上31%）。既定に最も素直に合う拡張先です。

### 3-3. どこまで緩めるかの目安

| 緩和 | 母数への効き | 会社の質 | 売れ行きの実証 | 判定 |
|---|---|---|---|---|
| 規制3カテゴリを戻す | +1,572社（+65%） | 現行より良い | 現行より良い | **推奨**（法務確認が前提） |
| ランク10万まで | +393社（+16%） | 良い | 失われる | 条件付き |
| ランク20万まで | 累計+1,105社（+46%） | 良い | 失われる | 条件付き |
| ランク30万まで | 累計+1,845社（+76%） | 良い | 失われる | 条件付き |
| FBA1人以上 | 大きい（数千〜数万） | 悪い（6割が中国系OEM） | 無い | **非推奨** |

**「条件付き」の条件**: ランク緩和で入る会社は、打診先としては良質ですが、**見つけたその商品は仕入れ候補になりません**（売れていないため）。使い方は「深いランクの商品を手がかりにメーカーを見つけ、**そのメーカーの売れ筋のほうを扱わせてもらう**」に限られます。83〜90%は既知の会社なので、実際に新しく会える社は思ったより少ないことも織り込んでください。

事前見積り約8,000 token / 約6.5時間に対し、実績は下表。**Keepa の解約期限 2026-10-03 まで12日あり、余裕をもって完了しています。**
