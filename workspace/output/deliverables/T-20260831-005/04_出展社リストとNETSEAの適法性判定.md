### 1-1. 段階1：PDF から CSV へ変換して社内で使う → **可（条件付き）**

**根拠**

| 論点 | 判断 | 条文・理由 |
|---|---|---|
| 社名そのものに著作権があるか | **無い** | 著作権法2条1項1号「思想又は感情を**創作的に表現**したもの」。会社名は事実であり、短い語句に創作性は認められない |
| PDF 全体は著作物か | **著作物と扱うべき** | 12条（編集著作物）。素材の選択・配列＋地図・レイアウトに創作性がある。ここは争わない |
| ではCSV化は複製にあたるか | **抽出物は編集著作物の「素材」部分のみ**。創作性のある配列・レイアウトを再現していない | 12条は「素材の選択又は配列」を保護する規定であり、素材そのもの（＝事実）には及ばない（12条2項も素材側の権利を別扱いする建付け） |
| ダウンロード・解析のための一時複製 | **30条の4第2号で説明可能** | 「情報解析（多数の著作物その他の大量の情報から…比較、分類その他の解析を行う）の用に供する場合」。当社の用途は仕入れ先候補の分類・突合であり、表現を享受する利用ではない |
| 30条の4のただし書（利益を不当に害する）に当たるか | **社内利用に留まる限り、当たらない** | 主催者はこの PDF を無償で公開しており、社内解析が主催者の市場を代替しない |
| 「無断掲載及び加工の禁止」に契約としての拘束力はあるか | **無い** | 民法522条の申込み・承諾がない。ダウンロード前に条件を提示され承諾する手続き（クリックラップ）が一切存在しないことを実測で確認済み。**PDF を開いた後に初めて読める一方的表示は、契約条項ではなく利用者への要望・警告**。ブラウズラップ型の拘束力は日本の裁判例でも一般に否定的 |

**ただし、契約でないからといって著作権法上の許諾範囲まで自由になるわけではありません。**この表示は「著作権者が許諾していない利用態様の宣言」としては有効に読めます。したがって**表現の複製・公開に近づくほど危険になる**、という構造です。段階2が危ない理由がここにあります。

**遵守条件（これを外すと判定が変わります）**

1. CSV の保管先は `workspace/output/agent_output/T-20260831-005/`（`.gitignore` 対象）に限定する
2. 社外の誰にも配布しない。限定共有スプレッドシートに載せる場合も閲覧者を社長のみに限定する
3. 出典（URL・取得日時・元PDFのハッシュ）を CSV と同フォルダに残す
4. 元PDFのレイアウト・地図・デザインは複製・公開しない
5. **主催者から削除要請が来たら、争わず即時に削除する**（争う実益がない）

### 1-2. 段階2：PUBLIC の GitHub リポジトリに commit → **不可（NO）**

グレーではありません。**黒です。**

| 理由 | 内容 |
|---|---|
| **行為の性質が変わる** | リポに置く＝21条（複製）、公開状態にする＝23条1項・2条1項9号の5（送信可能化）。**誰もダウンロードしていないは抗弁になりません。**アップした時点で送信可能化は完成します |
| **30条の4は使えない** | 同条は「享受を目的としない利用」に限り、しかも「**その必要と認められる限度において**」。全件を第三者が読める形で公開する行為は、情報解析に必要な限度を明らかに超えます |
| **47条の5（軽微利用）も使えない** | 「**軽微なもの**に限る」が要件。2,353社の全件掲載は軽微ではありません |
| **編集著作物性を否定しきれない** | 「第102回に出展する2,353社」という集合は、主催者の営業投資と選別の成果です。全件をそのまま公開する態様は、主催者データベースの市場代替に最も近い。タウンページDB事件（東京地判平12.3.17）は職業別分類の体系に創作性を認めています。**社内で分類に使うのと、集合をそのまま再公開するのとでは、評価が別物になります** |
| **著作権が白でも不法行為が残る** | 民法709条。読売オンライン見出し事件（知財高判平17.10.6）の枠組み。**「無断加工禁止」と明示されている以上、相手の意思に反することは明白**で、故意が認定されやすい |
| **個人情報保護法27条** | CSV には「深田養蜂」「茶師 木村」「越田鮮魚店」など**屋号のみの個人事業主が多数混ざっています**。個人事業主の事業情報は個人情報です。PUBLIC commit ＝ 不特定多数への提供＝第三者提供に当たり得ます。本人同意はありません |
| **不可逆性が最悪** | 一度 push すれば Git 履歴に残ります。履歴からの除去は `filter-repo` ＋ force push ＝ **CLAUDE.md §4.1（不可逆な削除）で社長承認が必要**。さらに成果物カタログの blob URL が一斉に切れます |
| **DMCA が最速の脅威** | 権利者は訴訟より先に GitHub に通報します。**被害は当該ファイルに留まらず、リポジトリごと止まります**（30分ごとの自動同期も道連れ） |

**リスク3軸**

| 軸 | 評価 |
|---|---|
| 発生確率 | 中（主催者は毎回リストを出す事業者であり、無断転載の監視インセンティブがある） |
| 影響度 | 大（リポジトリ停止＝全事業の作業基盤が止まる） |
| **不可逆性** | **最大（履歴に残る／除去に社長承認と副作用）** |

→ **3軸すべてで悪い。議論の余地なし。**

**代替（サトルの現在の措置は正しい。そのまま維持）**

| 置くもの | 場所 |
|---|---|
| 再現スクリプト（`02_出展社リスト抽出.py`） | deliverables（公開可）※スクリプトは当社の著作物 |
| 件数・国内外比率・カテゴリ分布などの**統計** | deliverables（公開可）※事実の統計に主催者の権利は及ばない |
| CSV 実データ | `agent_output/`（Git除外）＋必要なら限定共有スプレッドシート |

### 1-3. 段階3：社名を手がかりに各社公式サイトを自分で調べる → **可（最も安全な線）**

| 論点 | 判断 |
|---|---|
| 社名という事実の利用 | **白。**事実に著作権は発生しません（2条1項1号）。「知ってしまった事実を使うな」という権利は著作権法に存在しません |
| 出展社名は秘密か | **秘密ではありません。**出展社は会場で社名を掲示し、来場者に知られることを目的に出展しています。公知情報です |
| 各社公式サイトへのアクセス | **条件付き可**（既判定：`knowledge_scraping_and_public_db_2026`）。低速クロール・robots.txt尊重・UA詐称なし・連絡先を名乗る |
| 営業メール送信 | **特定電子メール法3条1項4号**で、自らアドレスを公表している事業者には同意なく送れます。**ただし施行規則3条ただし書：サイトに「営業メールお断り」の表示があるアドレスには送れません。**収集時点で判定して記録すること（立証責任は送信者側） |
| 個人事業主の連絡先の扱い | 個人情報。**PUBLIC リポへは出さない**（段階2と同じ） |

### 1-4. 線引き（これが答えです）

```
白 ── 社名という「事実」を知り、それを手がかりに各社公式サイトから自分で情報を取る
   ── PDF を社内で解析し、分類・突合に使う（agent_output 限定・非公開）
   ── 件数・比率などの統計を公開する
────────────────────────────────────────────────
黒 ── 抽出した全件リストを PUBLIC リポに commit する
   ── 第三者に配布・販売する
   ── PDF のレイアウト・地図をそのまま再掲する
```

**判断基準は一つです。「主催者のリストの代わりになるか」。**代わりになる形で外に出せば黒、社内で消費するだけなら白。

## ③ 展示会への事前登録

### 3-1. まず事実。**招待状請求は既に終了しています**

| 事実 | 根拠（2026-08-31 当職確認） |
|---|---|

### 3-2. 秘書の §4.1 判断について

**判断は正しい。**オンライン事前登録は Gift Net の利用登録であり、その利用規約 第1条2項に「**第3条の利用登録が完了したことをもって、本規約の全ての条項に同意をしたものとみなされます**」とあります。これは §4.1「法的拘束（契約・利用規約への同意）」そのものです。

**ただし本件では、締切済みのため実行の余地がありません。**したがって §4.1 の承認案件は消滅します。

### 3-3. 【重要】むしろ登録しない方が有利です

Gift Net 利用規約（https://giftnet.jp/terms/ ・2026-08-31取得）第5条（禁止事項）に、**当社の計画と正面衝突する条項**があります。

> ・**出展社情報を，本サービス利用以外の目的で利用する行為**
> ・**他のお客様，出展社に関する個人情報等を収集または蓄積する行為**
> ・当社が許諾しない本サービス上での宣伝，広告，勧誘，または営業行為

**登録すればこれらが契約上の義務になります。**当社がやろうとしていること（出展社情報を集めて蓄積し、営業する）は、この条項の下では実行できません。

対して、**当日登録（名刺持参）は Gift Net の利用登録ではなく、この規約に同意する行為ではありません。**

→ **法務としての推奨：Gift Net には登録せず、当日登録で入場する。**これは費用ゼロ・手続きゼロで、契約上の制約を丸ごと回避できます。

※ 当日登録票に記載される条件（記入項目・同意文言）は会場でしか読めず、**現物は未確認です**。当日、記入前に文面を読んでください。「出展社への情報提供に同意」等の記載があれば、その範囲は把握して記入すること。
