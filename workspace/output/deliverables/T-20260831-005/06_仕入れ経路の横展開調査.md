## 0. 結論（先に4行）

1. **NETSEA の完全な代替が1つ見つかりました。`orosy バイヤーAPI` です。** 公開 OpenAPI・**JAN から卸価格を直接引ける**・**サプライヤーごとの承認制の壁が構造的に存在しない**・初期0円/月額0円/API利用料0円。NETSEA が持っていた「API はあるが承認済みサプライヤーの商品しか返さない」という制約が、この経路には**設計上ありません**（orosy 自身が売主になるため）。
2. **社長の最大のボトルネック「仕入れ値が推定で不正確」に、この経路は直接効きます。** orosy API は `jan` `buyer_price`（卸価格・税抜円）`retail_price`（上代）`stock_qty` `order_unit` を返します。**推定ではなく実測値です。**
3. **スーパーデリバリーは、非ログインで JAN が読めます（実測）。** 商品ページに `JAN：4982642102594` が出ており、サイトマップは100ファイル（1ファイルあたり最大5万URL）。**卸価格は会員のみ**ですが、「JAN を集めて Keepa で売れ行きを見る」までは登録前に成立します。
4. **除外が2つ確定しました。** J-GoodTech は **BtoC 事業者が登録対象外**（公式FAQ）。卸の達人は会員規約第6条で**法人のみ**（個人事業主は規約上不可）。

**注意（事実と推測を分けます）**

## 5. 「NETSEA が使えなかった場合の代替」として成立するもの

NETSEA が持っていた機能を4つに分解し、代替が成立するかを判定しました。

| NETSEA の機能 | 代替が成立するもの | 判定の根拠 |
|---|---|---|
| **① API で商品データを機械取得** | **orosy バイヤーAPI**（唯一） | 公開 OpenAPI 3.1・22エンドポイント・実測で 401 認証まで確認 |
| **② 卸価格を数値で取得（＝仕入れ値の実測）** | **orosy バイヤーAPI**（唯一） | `buyer_price` を返す。他の4サービスは**画面表示のみ or 会員限定** |
| **③ 大量のカタログ母数** | **スーパーデリバリー**（2,198,629商品／3,413社）＞ TopSeller（最大279,666商品）＞ orosy（約20万点）＞ ザッカネット（1,495社） | 各サービスの公式表示値 |
| **④ その場で発注できる** | orosy／スーパーデリバリー／ザッカネット／TopSeller／卸の達人 の**全部** | いずれもサイト内発注が可能 |

**結論（事実として）**

- **①②を同時に満たす代替は `orosy バイヤーAPI` の1本だけです。** しかも NETSEA が抱えていた「API が承認済みサプライヤーの商品しか返さない」という制約を、**設計上持ちません**（orosy が売主のため）。

- **この2本は排他ではありません。** 「orosy で仕入れ値を実測し、スーパーデリバリーで母数を稼ぐ」は費用0円で両立します。
