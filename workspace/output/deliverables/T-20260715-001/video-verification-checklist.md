# Amazon 本人確認ビデオ通話 事前準備チェックリスト
（Satoy Select / T-20260715-001 / 2026-07-15 カズヨ作成）

## 0. まず状況の整理（安心材料）
- 今回の無効化は **本人確認（KYC）の再検証** が理由。**販売不正の認定ではない**。
- 「虚偽・詐欺・違法の可能性」は Amazon が本人確認を再要求するときの **定型文**。
- ビデオ通話で「登録通りの実在人物」と示せれば復活の道がある、**最も回復しやすい類型**。
- 過去に開設時パスポート番号の不一致で差戻し履歴あり → **登録情報と提示書類の完全一致が最重要**。

## 1. 予約の手順（本筋）
1. Seller Central →「**パフォーマンス通知**」を開く（購入者メッセージ受信箱ではない。📣アイコン or 左メニュー≡→パフォーマンス→アカウント健全性）。
2. 「本人確認の面接日時を予約」リンク/手順に従い、**都合の良い枠を予約**。
3. ⚠️ 再有効化ページの自由記述欄＋「提出する」は「**予約できない/本人確認したくない場合の例外窓口**」。復活したいなら使わない（本筋はビデオ通話）。

## 2. 当日までに用意するもの
- [ ] **顔写真付き身分証（政府発行）** = Amazonに登録したものと同一。基本は **パスポート**（差戻し履歴があるため、登録に使った現物を用意）。
- [ ] 登録情報の控え：**氏名（ローマ字表記含む）/生年月日/住所/パスポート番号** が Seller Central 登録と一字一句一致しているか事前確認。
- [ ] 銀行口座・クレジットカード情報（求められる場合に備え手元に。※番号の口頭読み上げは慎重に）。
- [ ] 予約確認メール/リンク（当日すぐ入れるように）。

## 3. 環境準備（no-show と技術トラブルが最大の失点）
- [ ] **予約枠に絶対に遅れない/欠席しない**（no-show は再開を大きく遠ざける）。
- [ ] 静かで**明るい**部屋、顔と身分証がはっきり映る照明。
- [ ] 安定したネット回線（できれば有線/強Wi-Fi）、カメラ・マイク動作確認。
- [ ] 使用ブラウザ・デバイスを事前テスト。通知メールに指定ツールがあればインストール済に。
- [ ] **言語オプション**があれば日本語を選択（このアカウントは米国マーケットだが、日本居住者向けに日本語/通訳が用意される場合あり）。

## 4. 面接で聞かれること（想定）
- 本人確認：氏名・生年月日・住所を口頭で確認。
- **身分証をカメラに提示**（パスポートの顔写真ページを見せるよう指示されることが多い）。
- 出品者本人であること、登録情報が正しいことの確認。
- 所要時間の目安：15〜30分程度。

## 5. やってはいけないこと（重要）
- ❌ **新しいアカウントを作り直す**（規約違反・紐付け検知で完全閉鎖リスク）。
- ❌ 面接をすっぽかす/予約を放置する。
- ❌ 再有効化ページの自由記述欄に、焦って弁明文を書いて提出する（本筋を外す）。
- ❌ 登録と異なる名義・書類を提示する（不一致は一発アウトの原因）。

## 6. 面接後
- 本人確認が完了 → Amazon がアカウントを審査し再開可否を判断（通知はパフォーマンス通知に届く）。
- 併発の「**入金方法の追加/更新（致命的）**」も、復活後/指示に沿って対応（銀行・入金情報のverification）。
- 進捗はカズヨへ共有 → 本チケット T-20260715-001 に記録。
