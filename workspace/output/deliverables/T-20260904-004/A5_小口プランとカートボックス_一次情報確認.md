# A-5 小口出品プランとカートボックス（おすすめ出品）— 一次情報確認

**結論：命題は正しい。小口出品ではカートボックス（おすすめ出品）を獲得できない。Amazon.co.jp 公式が「ショッピングカートボックスの利用資格の獲得」を大口出品プランの機能として明記している（一次情報・2026-09-04 取得）。**

イシュー：「小口プランではカートを取れない」を Amazon の一次情報で確定できるか。
スコープ：Amazon 公式ドメイン（amazon.co.jp / sell.amazon.co.jp / sellercentral / sell.amazon.com）のみ。二次情報は根拠にしない。打ち切り＝ログイン必須ページに突き当たった時点（実際に突き当たった。下記「未確認」参照）。

## 4. カートを取れない場合、商品ページ上でどう見えるか

- 一次（出典3・原文ママ）:
  > they can visit the “Other sellers on Amazon” widget below the Offer Display to view more options
  > If you see “See options” instead of a Featured Offer, there might not be any available offers that are eligible to be featured.
- **事実**：おすすめ出品に選ばれない出品は、購入ボタン直下の「他の出品者」一覧に並ぶ。購入者が**自分でその一覧を開いて選ぶ**必要がある。誰もおすすめ出品資格を満たさない商品では、購入ボタンの代わりに選択肢一覧（`See options`）が出る。
- **推測（確度：中）**：日本の商品ページでの表示は「新品 (n)件の出品」「Amazonの他の出品者」等のリンク。日本語UIの正確なラベルは公式で未確認。
- **推測（確度：高／根拠＝上記一次＋購買の約8割がカート経由という業界通説）**：小口のまま既存の相乗り出品をしても、購入導線は「一覧から探して選ぶ」経路のみになり、販売数は大きく落ちる。※「8割」は**二次情報**で、Amazon 公式の数字ではありません。
