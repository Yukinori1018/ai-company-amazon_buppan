# 04 FAX運用の法務判定（3論点）

- 担当：ハルオ（法務）／2026-09-20
- 対象：`03_FAXと電話番号の月額.md` §5 でサトルが「ハルオ判定要」として残した3点
- 前提として引き継ぐ既判定（再調査しない）：特商法12条の5 は対象外（`03` §5）／メール側の送信ルール（`T-20260915-002/10`）
- 契約・無料お試し・アカウント作成・FAXの実送信はしていない（§4.1）

## 1. 結論

| 論点 | 判定 |
|---|---|
| ① 原稿に当社紹介が混ざる | **条件付きOK**。特商法12条の5 には傾かない（主体要件と26条1項1号で二重に外れる）。傾くのは別の3つ＝虚偽・誇張の実績記載／同一原稿をメールに流用したときの特定電子メール法／相手が実質消費者の場合。§2のチェックリストを守ること |
| ② FAX→電話の重ね打ち | **条件付きOK**。反復・執拗な勧誘を禁じる明文は BtoB には及ばない（迷惑防止条例は「悪意の感情を充足する目的」が条文上の要件）。**初回FAX＋7日後に電話1回の計2回まで**、拒否後は全経路恒久停止。§3の8条件 |
| ③ 各社規約の一般条項 | **条件付きOK**。faximo・IVRy とも FAX-DM や大量発信を名指しで禁じる条項はない。ただし faximo は「月間上限枚数が契約ごとに設定」「履歴60日で消滅」、IVRy は「送信データを無償・無制限に利用できる」条項がある。§4の条件付き |

## 2. 論点① 原稿に売り込みが混ざった場合

### 2-1. 特商法12条の5 には傾きません（根拠）

条文は3つの要件を全部満たす場合にだけ働きます（e-Gov 特定商取引に関する法律・2026-09-20 取得）。

| 要件 | 条文 | 当社 |
|---|---|---|
| 主体が「販売業者又は役務提供事業者」 | 12条の5第1項 | 当社は買主。相手に何かを売る申込みをしていない限り主体でない |
| 「通信販売をする場合の商品…の販売条件又は役務の提供条件について」の広告 | 同項 | 買いの申込みは販売条件の広告ではない |
| 適用除外に当たらないこと | 26条1項1号「購入者若しくは役務の提供を受ける者が**営業のために若しくは営業として**締結するもの」 | 相手はメーカー＝営業として。**第2章第3節（通信販売）ごと適用されない** |

重要なのは3番目です。**仮に原稿に当社の役務（販売代行・コンサル等）の売り込みを書いてしまっても、相手が事業者である限り 26条1項1号 で節ごと外れます。**したがって「当社紹介が入ったら12条の5に該当する」という心配は、法文上は生じません。

ただし26条1項1号は形式ではなく実態で判断されます。**相手が名目上は事業者でも実質は消費者と変わらない先（個人の作家・ハンドメイド作家・副業規模の個人）には、除外が外れる可能性が残ります。**該当しそうな先には §2-2 の「書くな」を1つも踏まないこと。

### 2-2. 実際に傾くのは別の3つ

| # | 何が起きるか | 根拠 | 対処 |
|---|---|---|---|
| 1 | 実績の数字を盛ると、取引が取り消される／賠償を負う | 民法96条（詐欺取消）・95条（錯誤）・709条。悪質なら刑法246条 | 裏付けのある数字だけ書く。無ければ書かない |
| 2 | 同じ原稿をメールにも流用すると、**メール版は特定電子メールに転化する** | 特定電子メール法2条2号、総務省GL p.1 該当例ア）（`10` §1） | FAX原稿とメール原稿を別IDで管理する。共通化しない |
| 3 | 返信用FAX用紙・申込書を付けると、相手の返信1枚で合意が成立しうる | 民法522条 | 様式の同封は禁止（§4.1 法的拘束をカズヨが踏む） |

なお景品表示法は「自己の供給する商品又は役務の取引」が対象（2条4項）で、当社は相手に供給しないため対象外です。

## 3. 論点② FAX→電話の重ね打ち

### 3-1. 及ぶ／及ばないの切り分け

| 法令 | 当社への適用 | 根拠 |
|---|---|---|
| 特商法・電話勧誘販売（2条3項・16条以下） | **及ばない** | 主体は「販売業者又は役務提供事業者」。当社は買主。加えて26条1項1号で節ごと適用除外 |
| 特商法・訪問購入（58条の4以下） | 及ばない | 58条の17第1号で営業目的の売買は除外 |
| 迷惑防止条例（東京都5条の2） | **及ばない** | 条文が「専ら、特定の者に対する**妬み、恨みその他の悪意の感情を充足する目的で**」を要件にしている。営業目的の連絡はこの目的要件を欠く。※4号は「拒まれたにもかかわらず、連続して、電話をかけ、…ファクシミリ装置を用いて送信し」を挙げており、**行為の形は当社の重ね打ちと同じ**。目的要件だけで外れている状態＝余白は小さい。罰則は1年以下の拘禁刑または100万円以下の罰金（8条2項2号） |
| ストーカー規制法 | 及ばない | 恋愛感情等の目的要件（2条1項）。法人相手では成立しない |
| 独禁法（優越的地位の濫用 2条9項5号） | 及ばない | 当社に優越的地位がない（実績ゼロ・取引前） |
| 取適法（旧下請法／2026-01-01 施行） | 及ばない | 対象は製造委託等の「委託事業者」で資本金1,000万円超または従業員300人超。当社は個人事業主。加えて通常の仕入れ（売買）は製造委託に当たらない。※型③OEMに進む場合は再判定が必要 |
| **刑法234条（威力業務妨害）** | **拒否後の反復で近づく** | 1〜2回の通常の商談申込みでは成立しない（`knowledge_tokutei_denshi_mail_sourcing_outreach` §8） |
| **民法709条（不法行為）** | **拒否後の反復で現実味** | 用紙・トナー代＋対応工数。1回分の損害は小さいが、拒否後の継続は故意が立つ |

**BtoBだから安全なのは「業法（特商法・特電法）」まで。**刑法・民法・各社規約は相手が事業者でも一切減免されません。ここが分かれ目です。

### 3-2. 運用ルール（`10` §2 と整合させた数字）

`10` の既定は「1社1回まで。7日後の追いかけ1回だけ」。**電話はこの"追いかけ1回"の枠に入れます（FAXの追加ではなく、追いかけ経路の置き換え）。**

| # | ルール | 理由 |
|---|---|---|
| 1 | 同一社への接触は **初回FAX 1回＋追いかけ1回の計2回まで**。電話はこの追いかけ枠を使う | `10` §2 の既定を変えずに電話を組み込む |
| 2 | FAX送信から電話までは **中7日（前後3営業日の幅を許容、最短3営業日・最長10営業日）** | `10` の「7日後」。3営業日未満は押し売りの印象、10日超は原稿が捨てられている |
| 3 | **電話は1社1日1回まで。同日中の再架電は不可** | 条例4号「連続して電話をかけ」の形に近づけない |
| 4 | **不在・留守電も接触1回に数える。**折り返し依頼のメッセージは通算1回だけ残す | 留守電の連続が最も「連続して電話をかけ」に見える |
| 5 | 「今は担当が不在」「後日かけ直して」は拒否ではない。**相手が日時を指定したときだけ、その日時に1回**。指定がなければ枠を使い切ったものとして終了 | 拒否と保留を混同しない |
| 6 | **断られたら会社単位で全経路（FAX・電話・メール・フォーム）を即日・恒久停止。再接触禁止期間は無期限** | `10` §4。法3条3項（メール）は相手ごとの絶対の義務。FAXと電話に法的義務はないが、同じ扱いに揃える |
| 7 | 停止のキーは **法人番号・ドメイン・FAX番号・電話番号の4つ**。社名変更・担当者交代でも停止は維持 | 表記ゆれで再送する事故を防ぐ |
| 8 | 架電は **平日10:00〜12:00 / 13:00〜17:00**。始業直後・昼休み・終業前1時間は避ける。FAXは平日9〜18時 | `10` §2 のFAX時間帯に電話を合わせた |

「3回目を打つと成約率が上がる」という議論が出たら、**上限を上げるのは社長の判断事項**として `waiting/` に出してください。法務としては、拒否前の3回目そのものは違法ではありませんが、条例4号の行為類型に形が一致していくため推奨しません。

**運用条件（これを守れば8条に触れないと判断します）**

1. 一斉送信機能を使わない。**メール1通＝宛先1件**で送る（TO欄に複数番号を入れない）。
2. 1日の送信を **20通以内**・**1通の投入間隔を60秒以上**空ける（17条1項4号「過大な負荷」の回避。数字は社内基準であり規約上の線ではない）。
3. 契約直後に管理画面TOPで**月間上限枚数を確認**し、その8割を月間の自社上限にする。上限引き上げの問い合わせは §4.1（契約条件の変更）なので社長へ。
4. **同一原稿を無変更で連投しない。**宛名・相手商品名を1社ずつ差し込む（DM判定を受けにくくする実務。規約上の要件ではない）。
5. **毎月1日に前月の送受信履歴CSVをダウンロードし、社外（社長のDrive非公開フォルダ）へ退避**する。60日で消え、停止・退会後は閲覧できない。`10` §4 の送信ログ・拒否リストの裏付けがこれで消える。
6. 苦情が来たら：その社を即日拒否リストへ／同じ理由の苦情が2件出たらその原稿IDを廃止（`10` §4）／**faximo から照会が来たら返信前に社長へ上げる**（19条2項の即解約に直結する。自己判断で回答しない）。

**停止された場合の影響（1行）**：貸与されている03番号を失い（4条2項・5条1項＝移転も不可）、原稿・名刺に刷った番号が死にます。送受信履歴は60日保存・延長不可で、停止後は閲覧できません（＝退避していない分の送信記録は失われます）。
