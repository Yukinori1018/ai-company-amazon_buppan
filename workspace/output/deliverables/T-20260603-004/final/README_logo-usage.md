## どれを使えばいい？（迷ったら）
- **Amazonの出品者プロフィール / SNSのアイコン** → `png/icon_navy_512.png`
- **納品書・帳票・書類のヘッダー** → `png/full_white_1280x520.png`
- **スライドや色付き背景に載せる** → `png/full_transparent_1280x520.png`
- **将来ロゴを拡大・加工したい / 印刷業者へ渡す** → `.svg`（原本。劣化しない）

## メモ
- SVGが「原本（マスター）」。PNGはSVGから書き出した派生物。色や文字を直すときはSVGを編集して再書き出しします。
- 追加サイズ・別カラー（白抜き等）・帯付きバナー版が必要なら、ヒデアキ（コンテンツ制作）が即対応します。
