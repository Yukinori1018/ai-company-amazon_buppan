### 購入日の欄の書き方（画面の形によって3通り）

| 画面の形 | 書き方 |
|---|---|
| 文字を自由に入れられる | **該当なし（お取引のご相談のため）** |
| 日付しか入らない（カレンダー選択など） | **送信する日の日付**を入れる。本文の末尾に注記を1行足す（下記） |

日付しか入らない場合に本文の末尾へ足す1行：

```
※購入日の欄は入力が必須のため、送信日を記入しております。
```

理由：うその購入日を書くと、相手が購入記録を探して時間を無駄にします。送信日を入れて、そのことを本文で断れば、誤解は生まれません。

## 2. 本文（コピーして貼る部分。469字）

```
株式会社ジョイパレット
ご担当者様

突然のご連絡にて失礼いたします。Satoy Select（個人事業）の佐藤之則と申します。

本件は、購入した商品についてのお問い合わせではなく、貴社商品のお取引（卸）に関するご相談です。お客様向けの窓口へのご連絡となり恐縮ですが、ご担当の部署が別にございましたら、ご連絡先をお教えいただけますと幸いです。

当方は、Amazonでの玩具などの販売に向けて仕入れ先を探している個人事業者です。現時点で販売実績はまだございませんが、貴社の【商品名】を継続して取り扱わせていただきたいと考えております。

つきましては、次の点についてご案内いただけますでしょうか。
・新規のお取引が可能かどうか
・取引条件（掛率、最低発注ロット、発注・お支払いの方法）

貴社のブランドや商品の取り扱いに関するご方針がございましたら、それに沿って販売いたします。

お手数をおかけいたしますが、ご検討のほどよろしくお願い申し上げます。

――――――――――
Satoy Select　佐藤之則
メール：【返信先メール】
電話：【電話番号】
――――――――――
```

用語の補足：
- **卸（おろし）**：メーカーから、販売店向けの価格でまとめて仕入れる取引。
- **掛率（かけりつ）**：定価に対する仕入れ値の割合。定価1,000円で掛率60%なら、仕入れ値は600円。
- **最低発注ロット**：1回の注文で最低限買う必要がある数量。

## 3. なぜこう書いたか（表現の意図）

| 箇所 | 意図 |
|---|---|
| 2段落目の冒頭「購入した商品についてのお問い合わせではなく」 | 受け取るのはお客様相談室の担当者。最初の1文で「クレームではない」と分かれば、読む構えが変わり、取引の担当へ回してもらいやすくなる |
| 「ご担当の部署が別にございましたら、ご連絡先をお教えください」 | 窓口違いを先にわびて、相手に**転送か案内のどちらか**を選んでもらう。どちらに転んでも次の一手につながる |
| 「現時点で販売実績はまだございません」 | **依頼の「Amazon で玩具等を販売する事業者」から意図して変えました。** 社内資料（handover.md）では販売実績はまだゼロです。法務の打診ルール（B1L 3-4 の5番）は「実績があるかのような誇張は絶対に書かない」と定めています。取引が始まってから誇張が分かると、信用を失い契約解除の原因になる。正直に書いたうえで「継続して取り扱いたい」で前向きさを出した |
| 「売り込みではなく」とは書かない | 法務ルールは「売り込みではない」と冒頭で宣言する型だが、今回は「購入品の問い合わせではない」のほうが受け手の誤解に合っている。どちらも「何の連絡か」を最初に示すという目的は同じ |
| 希望を箇条書き2行に絞った | 相手が返信を書くとき、そのまま項目ごとに答えられる。質問が多いと後回しにされる |
| 「ブランドや商品の取り扱いに関するご方針に沿って販売」 | メーカーが Amazon 販売者に感じる不安（安売り・勝手な商品ページ）を先に打ち消す。**「販売価格に関する方針に沿う」とは書かない。** 価格の指定に従うと書くと、メーカー側に独占禁止法上の問題（再販売価格の拘束）を連想させるため |
| ASIN を本文に書かない | ASIN は Amazon の商品管理番号で、メーカーの担当者には通じないことが多い。商品名だけで十分 |
| 署名に住所を書かない | フォームの必須欄で住所を渡しているため。重複を避けて短くした |
| URL を一切書かない | 社内ルール（法務 B1L）：本文・署名に URL を貼ると、法律上の「広告メール」扱いに変わるおそれがある。Satoy Select のサイトや Amazon ストアの URL も書かない |

## 5. 電話で窓口を聞く場合のトークスクリプト（約30秒）

フォームの返事がない場合や、窓口を先に確かめたい場合に使います。かける先はお客様相談室（平日 10–12時、13–17時。調査資料 §2）。

### 本題（読み上げ部分・約30秒）

> お忙しいところ恐れ入ります。Satoy Select という屋号で個人事業をしております、佐藤と申します。
> 購入した商品のお問い合わせではなく、貴社の商品を仕入れさせていただく、卸のお取引についてご相談したくお電話いたしました。
> お取引のご担当の部署か、ご連絡先を教えていただけますでしょうか。

### 相手の返事ごとの返し方

| 相手の返事 | 返し方 |
|---|---|
| 連絡先（メール・電話）を教えてくれた | 「復唱いたします。〇〇でよろしいでしょうか。ありがとうございます。改めてそちらへご連絡いたします」（その場で必ずメモ） |
| 「問い合わせフォームから送ってください」 | 「承知いたしました。種別は『その他』でお送りいたします。ありがとうございました」 |
| 「担当から折り返します」 | 名前・電話番号を伝え、「平日の日中であればつながります」と添える |
| 「新規のお取引は受けていない」 | 「承知いたしました。お時間をいただきありがとうございました」で**すぐに終える**。食い下がらない、後日かけ直さない（法務ルール：断られたら即終了・再接触しない） |

理由：電話は相手の時間を直接もらう手段なので、「何の電話か」を最初の2文で言い切り、お願いは「窓口を教えてください」の1つだけにしました。条件の交渉は電話でしない。担当につながってから書面で行います。
