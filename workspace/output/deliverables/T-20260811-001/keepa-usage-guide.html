Keepa（Chrome拡張）の使い方ガイド

社長共有のスクショ（AirPods Pro 第3世代・整備済み品ページ／keepa.com 出品者概要）に沿った実画面ベースの解説 ／ 2026-08-11 初版・2026-08-21 §6「出品者概要」を追補 ／ 制作ヒデアキ

Keepaとは：Amazonの商品ページに「価格と売れ行きの履歴グラフ」を差し込んでくれる無料のChrome拡張です。「今の値段は高いのか安いのか」「この商品は本当に売れているのか」を、感覚ではなく過去データで判断するための道具です。仕入れ判断の土台になります。
まず大前提 ── Keepaの画面は、Amazon商品ページの中に「Keepa Box」という小さな枠として埋め込まれて表示されます。単独アプリではありません。商品ページを開くたびに、価格の上あたりに自動で出てきます。上部に 価格履歴 / 商品のトラッキング / Data / バリエーション / 設定 の5つのタブがあり、これを切り替えて使います。
なお Keepa には、この拡張（Box）とは別に keepa.com というサイト本体があります。本ガイドの §1〜§5 は拡張の5タブ、§6「出品者概要」はサイト本体側の画面です。入口が2つある、と覚えてください。

1価格履歴タブ（いちばん使う画面）

Keepa Boxを開いた時に最初に出るメイン画面。折れ線グラフで価格の推移が読めます。縦軸が価格（例：¥30,000〜¥40,000）、横軸が日付です。

💡 グラフの右側にこの凡例（色の一覧）が出ています。凡例の項目をクリックすると、その線の表示/非表示を切り替えできます。見たい線だけ残すと読みやすくなります。

操作のコツ（実画面の注記どおり）

  • 期間切替：右下の 1日 / 1週間 / 1ヶ月 / 全期間 で表示範囲を変える。相場感は「全期間」、直近の動きは「1ヶ月」。
  • ズーム：グラフ上で見たい範囲をドラッグ選択すると拡大。ダブルクリックで元に戻る。
  • クローズアップビュー：ONにすると、価格が動いている範囲に縦軸を寄せて、小さな変動を見やすくする。
  • 統計：クリックで最安値・最高値・平均価格などの数値サマリーが出る。
  • 「◯人のユーザがこの商品をトラッキングしています」：ウォッチしている人数。多いほど注目商品の目安。
物販での読みどころ（ここが本番）
  • 価格の底と天井：ピンク（Buy Box）の帯を見て「いくらまで下がる／上がるか」を把握。底値で仕入れ、高値で売るの判断材料。
  • 値動きの激しさ：ギザギザが激しい＝値崩れリスク。平坦＝安定して利益計算しやすい。
  • 売れ行き（後述の売れ筋ランキング線）：ランキングがガクッと下がる回数＝売れた回数の目安。線が頻繁に落ちている＝よく売れている。

2商品のトラッキングタブ（値下がりアラート）

「この価格まで下がったら教えて」を設定する画面。登録不要・無料で、メール／ウェブプッシュ／Telegram／RSSで通知が届きます。

  1. 目標価格を入れる：Buy Box / Amazon / 新品 / 中古 それぞれに「◯円以下になったら通知」を設定できる（スクショでは Buy Box=¥30,381 以下）。
  2. トラッキング対象（期間）を選ぶ：2週〜10年。通常は1年でOK。
  3. トラッキング開始 ボタンを押すと監視スタート。

💡 モードは ベーシック / アドバンスド / プロ の3段階。最初はベーシックで十分。仕入れ候補を「安くなったら買う」リストとして貯めるのに便利です。

上部にサブタブ 製品詳細 / オファー / Buy Box統計情報 / Buy Box 中古統計情報。中でも重要なのが Buy Box統計情報 です。

4バリエーションタブ（色・サイズ違いを横並び比較）

同じ商品の色・容量などのバリエーションを、Buy Box / 新品 / 中古 の現在価格と履歴グラフで一覧比較できます。右端の 「先月の購入」（例：200+）は直近の販売数の目安で、需要の強さを測るのに使えます。「どのバリエが一番売れて、値持ちが良いか」を選ぶのに便利です。

5設定タブ（最初に整えると快適）

Keepa Boxの見た目や既定値を調整。副業初心者としては下の3つだけ触れば十分です。

  • デフォルト期間：初期表示を 3か月 などにしておくと毎回ちょうど良い範囲で開く。
  • デフォルトの目標価格：トラッキング時の初期値（例 5%）。よく使う値下げ幅にしておくと設定が速い。
  • 単位系：日本なら メートル法（cm, g）。言語も日本語（🇯🇵）に。

その他「極端な価格を無視」「クローズアップビューON」「Keepa Boxの高さ200px」などは既定のままで問題ありません。

6出品者概要（セラー分析）— 競合の正体を逆引きする

※ この節は 2026-08-21 追補。画面は 2026-08 時点のものです（Keepa は仕様変更が入るため、見た目が変わっていたらこの節の記述を疑ってください）。

§1〜§5 は「商品を見る」画面でした。この節は「売っている業者を見る」画面です。
Amazonで勝てるかどうかは、商品の良し悪しと同じくらい「その棚に誰がいるか」で決まります。カートを57%握っている相手が、老舗の大手なのか・直近で評価を落として弱っているのか・Amazon本体と組んでいるのか。それがこの1画面で分かります。

どこから開くか（入口は2つ）

  • 入口①（おすすめ）：§3 の Data → Buy Box統計情報 の表で、販売者名をクリック。今見ている商品の競合をそのまま調べられるので、実務ではこちらが速い。
  • 入口②：keepa.com を直接開き、上部メニュー プロ → 出品者検索。セラーIDや店名から探す時はこちら。
有料プラン前提の可能性が高い画面です。この「出品者検索」は上部メニューの 「プロ」タブの中にあり、スクショの右上にも「プロ」バッジが表示されています（＝社長のアカウントは Keepa 有料プランで開いた状態）。無料のままで同じ画面が開けるかは、この画面からは判断できません（要確認）。
補足：画面右上の Quota: 100% は、有料プランに付いているデータ利用枠の残量表示です（使うと減り、時間経過で回復）。重い画面を連発すると減るので、頭の片隅に。
取り扱い注意（第三者の情報です）
この画面には、相手業者の商号・住所・電話番号・代表者名・許可番号がそのまま表示されます。Amazonの「特定商取引法に基づく表示」由来の公開情報ですが、社外への転載・スクショ共有・名指しでの言及はしないでください。本ガイドでも実名はすべて セラーA〜X に置き換えています。

読み方：「ライフタイム96%の優良店」は嘘ではないが、今の姿ではない。
  • 直近90日は63%。この業者は今まさに評価を崩している局面です。累計の数字だけ見て「強敵だ」と引き下がると判断を誤ります。

6-4. カタログ「重複の多い主なセラー」— 競合マップ

この業者と品揃えが被っている業者のランキングです（％＝カタログの重複度）。

販売者重複読み方
セラーD85%品揃えがほぼ同じ双子の競合。値下げ合戦が起きるならまずこの2社の間で起きる
Amazon.co.jp37%取扱の約4割でAmazon本体と鉢合わせしている。本体がいる棚はカートを取りづらく、当社は原則避ける領域

💡 使い方：ここに出てきた同業を1社ずつ開いて Keepaで出品を閲覧 を押すと、その業者の棚が丸ごと見えます。「儲かっている業者が何を仕入れているか」から逆算するのが、この画面の一番の使い道です。

6-6. 当社での使い方は、この3つに絞る

① 参入前の「相手チェック」
§3でカートを握っている相手を開き、(a) 直近90日の評価／(b) Amazon本体との重複率／(c) そのカテゴリの平均順位の3点だけ見る。本体と重なる領域なら見送り、相手の評価が崩れているなら検討。
② 仕入れ候補の芋づる探索
「重複の多い主なセラー」→ 各社の Keepaで出品を閲覧 で棚を丸ごと確認。②メーカー仕入れで「そのメーカーの品を今どこが扱っているか」を逆引きする用途は相性が良さそうですが、当社では未検証です。
③ 中古を扱うなら許可の裏取り
基本情報カードの商業番号で、相手が古物商許可を持って中古を扱っているかを確認。自社が中古に踏み込む時の「そもそも許可が要る商売か」の感覚合わせにも使える。
この画面の限界（過信しないために）
  • 数字はKeepaが追跡できている範囲のもので、その業者の全量ではありません。
  • 意味を断定できないラベルが複数あります（6-2の「要確認」印）。分からない数字は使わないのが正解です。
  • 画面は2026-08 時点。Keepaの仕様変更で項目名・配置は変わります。

✓これだけ覚えれば回る：3ステップ

① 価格履歴タブ
ピンク線（Buy Box）で「今は高い？安い？」を判断。全期間で相場、1ヶ月で直近を見る。
② 売れ行き確認
売れ筋ランキング線のギザギザ（下落回数）＋バリエーションタブの「先月の購入」で、本当に売れているか確認。
③ 競合チェック
Data→Buy Box統計情報で、セラー数とカート獲得率を見て「入っても勝てるか」を判断。迷ったら販売者名をクリックして §6（出品者概要）まで踏み込む ── 相手の直近評価とAmazon本体との重複率で、行くか引くかが決まります。
注意：Keepaは過去の事実を見せてくれる道具で、未来を保証はしません。仕入れ判断は必ず「仕入れ値＋送料＋Amazon手数料＋外注費」を差し引いた手元利益と合わせて計算してください（当社は損益を外注費込みで計算する方針）。
