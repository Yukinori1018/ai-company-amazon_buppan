# Keepa（Chrome拡張）の使い方ガイド

社長共有のスクショ（AirPods Pro 第3世代・整備済み品ページ／keepa.com 出品者概要）に沿った実画面ベースの解説
2026-08-11 初版 ／ **2026-08-21 §6「出品者概要」を追補** ／ 制作ヒデアキ

> **Keepaとは：** Amazonの商品ページに「価格と売れ行きの履歴グラフ」を差し込んでくれる無料のChrome拡張です。
> 「今の値段は高いのか安いのか」「この商品は本当に売れているのか」を、感覚ではなく**過去データ**で判断するための道具です。仕入れ判断の土台になります。

**まず大前提** ── Keepaの画面は、Amazon商品ページの中に「Keepa Box」という小さな枠として**埋め込まれて**表示されます。単独アプリではありません。商品ページを開くたびに、価格の上あたりに自動で出てきます。上部に **価格履歴 / 商品のトラッキング / Data / バリエーション / 設定** の5つのタブがあり、これを切り替えて使います。

なお Keepa には、この拡張（Box）とは別に **keepa.com というサイト本体**があります。本ガイドの §1〜§5 は拡張の5タブ、**§6「出品者概要」はサイト本体側の画面**です。入口が2つある、と覚えてください。

## 1. 価格履歴タブ（いちばん使う画面）

Keepa Boxを開いた時に最初に出るメイン画面。折れ線グラフで**価格の推移**が読めます。縦軸が価格（例：¥30,000〜¥40,000）、横軸が日付です。

### 線の色の見分け方

| 色 | 意味 | 物販での読み方 |
|---|---|---|
| ピンク＝**Buy Box** | 今カートに入る価格（送料込み・最有力オファー） | **実際に売れている価格帯。最重要。** 仕入れ後にいくらで売れるかの基準 |
| 紫＝**新品** | 新品オファーの最安値 | 新品相場の下限 |
| 新しい第三者FBA | Amazon倉庫発送のセラー価格 | FBA競合の価格 |
| 新品 第三者FBM（破線） | セラー自己発送の価格 | 自己発送競合の価格 |
| 黒＝**中古** | 中古・整備済みの価格 | 中古/整備済みを扱う時の相場 |
| リファビッシュ | メーカー整備済み品 | 今回のAirPods Proはこれ |

> グラフの右側に**凡例（色の一覧）**が出ています。凡例の項目をクリックすると、その線の表示/非表示を切り替えできます。見たい線だけ残すと読みやすくなります。

### 操作のコツ（実画面の注記どおり）

- **期間切替：** 右下の `1日 / 1週間 / 1ヶ月 / 全期間` で表示範囲を変える。相場感は「全期間」、直近の動きは「1ヶ月」。
- **ズーム：** グラフ上で見たい範囲をドラッグ選択すると拡大。ダブルクリックで元に戻る。
- **クローズアップビュー：** ONにすると、価格が動いている範囲に縦軸を寄せて、小さな変動を見やすくする。
- **統計：** クリックで最安値・最高値・平均価格などの数値サマリーが出る。
- **「◯人のユーザがこの商品をトラッキングしています」：** ウォッチしている人数。多いほど注目商品の目安。

**物販での読みどころ（ここが本番）**

- **価格の底と天井：** ピンク（Buy Box）の帯を見て「いくらまで下がる／上がるか」を把握。底値で仕入れ、高値で売るの判断材料。
- **値動きの激しさ：** ギザギザが激しい＝値崩れリスク。平坦＝安定して利益計算しやすい。
- **売れ行き：** 売れ筋ランキング線が**ガクッと下がる回数＝売れた回数**の目安。線が頻繁に落ちている＝よく売れている。

## 2. 商品のトラッキングタブ（値下がりアラート）

「この価格まで下がったら教えて」を設定する画面。**登録不要・無料**で、メール／ウェブプッシュ／Telegram／RSSで通知が届きます。

1. **目標価格を入れる：** Buy Box / Amazon / 新品 / 中古 それぞれに「◯円**以下**になったら通知」を設定できる（スクショでは Buy Box=¥30,381 以下）。
2. **トラッキング対象（期間）を選ぶ：** 2週〜10年。通常は**1年**でOK。
3. **「トラッキング開始」ボタンを押す**と監視スタート。

> モードは ベーシック / アドバンスド / プロ の3段階。最初は**ベーシック**で十分。仕入れ候補を「安くなったら買う」リストとして貯めるのに便利です。

## 3. Dataタブ（セラー競合の実態を見る）

上部にサブタブ **製品詳細 / オファー / Buy Box統計情報 / Buy Box 中古統計情報**。中でも重要なのが **Buy Box統計情報** です。

**Buy Box統計情報＝「カートを誰がどれだけ取っているか」の表**

スクショの例：Buy Box対象オファー数 → 新品FBA:22 / 新品FBM:6 / 中古FBA:3（＝それだけ競合セラーがいる）

| %獲得 | 平均価格 | 販売者 | FBA | 評価（過去12ヶ月） |
|---|---|---|---|---|
| **57%** | ¥35,554 | セラーA | ✔ | -1% |
| 23% | ¥37,792 | セラーB | ✔ | 92% |
| 6% | ¥40,549 | セラーC |  | 60% |
| 4% | ¥40,045 | **セラーX** ← §6 で分解します |  | 82% |

- **%獲得＝そのセラーがカートを取っている割合。** 1社が過半を握っている商品は、後から入っても価格競争になりやすい＝旨みが薄い、という判断に使えます。FBA列・評価列で競合の強さも読めます。
- 評価列の **-1%** は「データなし」を示す表示とみられます（画面からは断定できないため**要確認**）。
- **販売者名はリンクです。** クリックすると、その業者1社だけを丸裸にする「出品者概要」画面（**§6**）に飛びます。競合が強くて迷った時は必ずここまで見てください。
- 実在の事業者名は「セラーA/B/C/X」に置き換えています（理由は §6 冒頭の注意書き）。

## 4. バリエーションタブ（色・サイズ違いを横並び比較）

同じ商品の色・容量などのバリエーションを、**Buy Box / 新品 / 中古 の現在価格と履歴グラフ**で一覧比較できます。右端の**「先月の購入」**（例：200+）は**直近の販売数の目安**で、需要の強さを測るのに使えます。「どのバリエが一番売れて、値持ちが良いか」を選ぶのに便利です。

---

## 5. 設定タブ（最初に整えると快適）

Keepa Boxの見た目や既定値を調整。副業初心者としては下の3つだけ触れば十分です。

- **デフォルト期間：** 初期表示を `3か月` などにしておくと毎回ちょうど良い範囲で開く。
- **デフォルトの目標価格：** トラッキング時の初期値（例 5%）。よく使う値下げ幅にしておくと設定が速い。
- **単位系：** 日本なら メートル法（cm, g）。言語も日本語に。

> その他「極端な価格を無視」「クローズアップビューON」「Keepa Boxの高さ200px」などは既定のままで問題ありません。

## 6. 出品者概要（セラー分析）— 競合の正体を逆引きする

> ※ この節は 2026-08-21 追補。画面は **2026-08 時点**のものです（Keepa は仕様変更が入るため、見た目が変わっていたらこの節の記述を疑ってください）。

§1〜§5 は「**商品**を見る」画面でした。この節は「**売っている業者**を見る」画面です。
Amazonで勝てるかどうかは、商品の良し悪しと同じくらい**「その棚に誰がいるか」**で決まります。カートを57%握っている相手が、老舗の大手なのか・直近で評価を落として弱っているのか・Amazon本体と組んでいるのか。それがこの1画面で分かります。

### どこから開くか（入口は2つ）

- **入口①（おすすめ）：** §3 の `Data → Buy Box統計情報` の表で、**販売者名をクリック**。今見ている商品の競合をそのまま調べられるので、実務ではこちらが速い。
- **入口②：** `keepa.com` を直接開き、上部メニュー `プロ` → `出品者検索`。セラーIDや店名から探す時はこちら。

**有料プラン前提の可能性が高い画面です。** この「出品者検索」は上部メニューの**「プロ」タブの中**にあり、スクショの右上にも**「プロ」バッジ**が表示されています（＝社長のアカウントは Keepa 有料プランで開いた状態）。**無料のままで同じ画面が開けるかは、この画面からは判断できません（要確認）。**
補足：画面右上の `Quota: 100%` は、有料プランに付いているデータ利用枠の残量表示です（使うと減り、時間経過で回復）。重い画面を連発すると減るので、頭の片隅に。

> **取り扱い注意（第三者の情報です）**
> この画面には、相手業者の**商号・住所・電話番号・代表者名・許可番号**がそのまま表示されます。Amazonの「特定商取引法に基づく表示」由来の公開情報ですが、**社外への転載・スクショ共有・名指しでの言及はしないでください。** 本ガイドでも実名はすべて セラーA〜X に置き換えています。

### 6-1. 基本情報カード — 「相手が何屋か」を確定させる

| 画面の項目 | 中身 | 仕入れ判断での使いどころ |
|---|---|---|
| セラーID | A1Z…（マスク） | Amazon内で業者を一意に指すID。**店名を変えても変わらない**ので、同じ相手を追跡する時の目印になる |
| 出品者（店名） | セラーX（店名に「お盆休み 8/12〜8/16」と休業告知） | 店名で発送体制の告知をしている＝**手動運用の色が濃い**。休業期間はカートが空きやすい（※これは読み取りではなく**仮説**。検証していません） |
| 住所 / 電話番号 / 代表者 | （マスク） | 法人か個人事業か、倉庫がどこか。**相手の規模感**を掴む |
| **商業番号** | ◯◯公安委員会 第30…号（12桁・マスク） | **古物商許可番号の体裁と一致**します。中古・整備済みを扱う競合の裏取りに使えます（Keepaがこの欄を何の番号として取得しているかは画面から断定できないため、正確には要確認） |
| 「表示するアマゾン」ボタン | Amazon側の出品者ページへ | ストアフロント・返品条件・レビュー本文を読みに行く |
| 「Keepaで出品を閲覧」ボタン | **その業者の取扱商品を一覧表示** | **この節で一番使えるボタン。**「強い競合が何を仕入れているか」を丸ごと覗ける＝仕入れ候補の逆引き |

> 用語補足：**古物商許可**＝一度消費者の手に渡った物（中古品）を仕入れて売るのに必要な許可。当社では②メーカー仕入れ・③OEMなら不要、①電脳せどり・④無在庫でメルカリ等から仕入れる場合は必須です。

### 6-2. パフォーマンス — 8つの数字（読めるものだけ読む）

| 画面表記（そのまま） | 例の値 | 意味と読み方 |
|---|---|---|
| **え** | 96%（ライフタイム） | **「評価」の誤訳です。** Keepaの日本語UIは機械翻訳が混ざっています。開店以来の高評価率 |
| 評価ブロック | 4,721（ライフタイム） | 評価が付いた**件数**の累計。多い＝販売量が多い老舗 |
| 確認済みリスト | 167（2026年8月11日時点） | Keepaが確認できている**出品点数**。当社のSKU100目標と直接比べられる数字 |
| FBAリストが見つかりました | はい | **FBA（Amazon倉庫発送）を使っている。** カート獲得で有利な相手だと分かる |
| 購入ボックス切り替えの所有者 | 4% | 新品カートの保有割合とみられます（**要確認**） |
| ボックスを購入する 中古の所有者 | 1% | 同・中古カートの保有割合とみられます（**要確認**） |
| BUY BOX の平均売上数 | 8.83 | **単位も母数も画面に出ておらず、意味を断定できません（要確認）。** 数字が独り歩きすると危険なので、現時点では判断に使わないでください |

> 意味の取れないラベルに出くわしたら、画面右上の**「言語」**を English に切り替えてください。**原語のラベル名が読めます。** 推測で使うより、原語を見てから判断するほうが安全です。

### 6-3. 期間別の評価 — この節で一番おいしいところ

| | ライフタイム | 30日 | 90日 | 365日 |
|---|---|---|---|---|
| 評価（画面表記は「え」） | **96%** | 86% | **63%** | 82% |
| 評価ブロック（件数） | 4,721 | 7 | 16 | 93 |

**読み方：「ライフタイム96%の優良店」は嘘ではないが、今の姿ではない。**

- 直近**90日は63%**。この業者は**今まさに評価を崩している**局面です。累計の数字だけ見て「強敵だ」と引き下がると判断を誤ります。
- 逆に自分が売る側なら、**直近評価が崩れている競合がいる棚は入り込む余地がある**（発送遅延・在庫切れが起きている可能性）。
- その下の**「最新のお客様フィードバック」**には直近の星と日付が並びます（例では★1が1件混じる）。**いつから崩れたか**の起点を特定できます。
- 30日の評価件数が7件、というように**評価が付くペース**も分かります。※ここから販売個数を逆算する手法もありますが、換算率は画面に出ないため本ガイドでは数値化しません。

### 6-4. カタログ「重複の多い主なセラー」— 競合マップ

この業者と**品揃えが被っている業者**のランキングです（％＝カタログの重複度）。

| 販売者 | 重複 | 読み方 |
|---|---|---|
| セラーD | **85%** | 品揃えがほぼ同じ**双子の競合**。値下げ合戦が起きるならまずこの2社の間で起きる |
| **Amazon.co.jp** | **37%** | **取扱の約4割でAmazon本体と鉢合わせ**している。本体がいる棚はカートを取りづらく、当社は原則避ける領域 |
| セラーE / F / G … | 18% / 17% / 10% … | 同じジャンルを回している同業リスト。**ここが仕入れ候補の芋づるになる** |

> 使い方：ここに出てきた同業を1社ずつ開いて「Keepaで出品を閲覧」を押すと、その業者の棚が丸ごと見えます。**「儲かっている業者が何を仕入れているか」から逆算する**のが、この画面の一番の使い道です。

### 6-5. カテゴリー／ブランド別リスティング統計 — 相手の稼ぎ頭を当てる

「リスティング」＝出品のこと。**その業者の出品が、どのカテゴリ／ブランドに何％あるか**の内訳表です。列は3つだけ覚えれば十分です。

| 列 | 意味 | 判断への変換 |
|---|---|---|
| リスト | 出品全体に占める構成比 | 相手の**主戦場**はどこか |
| Amazonオファーがあるリスト | そのうち**Amazon本体も出している**商品の割合 | 高い＝本体と真っ向勝負。**0%＝本体が不在の隙間**で稼いでいる |
| 30日間の平均順位 | 売れ筋ランキングの平均（**数字が小さいほど売れている**） | 構成比が小さくても順位が良ければ、そこが**回転の速い稼ぎ頭** |

**実例の読み（セラーX）**

| カテゴリ | リスト | Amazon本体あり | 30日平均順位 |
|---|---|---|---|
| 家電＆カメラ | 52.69% | 28.41% | #31,133 |
| **ゲーム** | 16.77% | 67.86% | **#641** |
| パソコン・周辺機器 | 10.18% | 5.88% | #53,216 |

| ブランド | リスト | Amazon本体あり | 30日平均順位 |
|---|---|---|---|
| **アップル** | 30.89% | **0.00%** | #36,660 |
| パナソニック | 15.45% | 89.47% | #32,724 |
| **任天堂** | 14.63% | 72.22% | **#795** |

- **看板と稼ぎ頭は違う。** 出品数の半分は家電＆カメラ（#31,133＝そこそこ）。一方**ゲームは16.77%しかないのに平均#641**＝圧倒的に回っている。この業者の実際の収益源はゲーム系だと読めます。
- **アップル30.89%で、Amazon本体のオファーは0%。** 本体が出していない領域（整備済み品など）を狙い撃ちしている構図。§1のAirPods Pro整備済み品も、まさにこの戦い方の中にあります。
- パナソニックは本体オファー89.47%＝ほぼ全面で本体と競合。**当社が真似すべきでないのはこちら側**です。

### 6-6. 当社での使い方は、この3つに絞る

1. **参入前の「相手チェック」** — §3でカートを握っている相手を開き、(a) 直近90日の評価／(b) Amazon本体との重複率／(c) そのカテゴリの平均順位 の3点だけ見る。本体と重なる領域なら見送り、相手の評価が崩れているなら検討。
2. **仕入れ候補の芋づる探索** — 「重複の多い主なセラー」→ 各社の「Keepaで出品を閲覧」で棚を丸ごと確認。②メーカー仕入れで「そのメーカーの品を今どこが扱っているか」を逆引きする用途は相性が良さそうですが、**当社では未検証**です。
3. **中古を扱うなら許可の裏取り** — 基本情報カードの**商業番号**で、相手が古物商許可を持って中古を扱っているかを確認。自社が中古に踏み込む時の「そもそも許可が要る商売か」の感覚合わせにも使える。

**この画面の限界（過信しないために）**

- 数字は**Keepaが追跡できている範囲**のもので、その業者の全量ではありません。
- 意味を断定できないラベルが複数あります（6-2の「要確認」印）。**分からない数字は使わない**のが正解です。
- 画面は**2026-08 時点**。Keepaの仕様変更で項目名・配置は変わります。

## ✓ これだけ覚えれば回る：3ステップ

1. **価格履歴タブ** — ピンク線（Buy Box）で「今は高い？安い？」を判断。全期間で相場、1ヶ月で直近を見る。
2. **売れ行き確認** — 売れ筋ランキング線のギザギザ（下落回数）＋バリエーションタブの「先月の購入」で、本当に売れているか確認。
3. **競合チェック** — Data→Buy Box統計情報で、セラー数とカート獲得率を見て「入っても勝てるか」を判断。**迷ったら販売者名をクリックして §6（出品者概要）まで踏み込む** ── 相手の直近評価とAmazon本体との重複率で、行くか引くかが決まります。

> **注意：** Keepaは**過去の事実**を見せてくれる道具で、未来を保証はしません。仕入れ判断は必ず「仕入れ値＋送料＋Amazon手数料＋外注費」を差し引いた**手元利益**と合わせて計算してください（当社は損益を外注費込みで計算する方針）。
