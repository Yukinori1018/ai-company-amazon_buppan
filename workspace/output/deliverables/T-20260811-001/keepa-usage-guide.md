# Keepa（Chrome拡張）の使い方ガイド

社長共有のスクショ（AirPods Pro 第3世代・整備済み品ページ／keepa.com 出品者概要）に沿った実画面ベースの解説
2026-08-11 初版 ／ 2026-08-21 第2版（§6「出品者概要」を追補）／ **2026-08-24 第3版（Keepa公式ドキュメントで用語を確定）** ／ 制作ヒデアキ

---

## 【第3版で直したところ】第2版を読んだ方は、ここだけ先に

第2版では、Keepaの日本語画面に出てくるいくつかのラベルについて「**意味を断定できません（要確認）**」と書き、判断に使わないよう釘を刺していました。
2026-08-24、Keepa の**公式APIドキュメント**（keepa.com/api-docs/）を全ページ精読した調査（チケット T-20260824-001）で、そのうちの多くに**公式の定義**が付きました。第3版はその結果を反映したものです。

> **結論から：ガイドの使い方（3ステップ）は変わりません。変わったのは「一部の数字の意味」です。**
> そして**そのうち1つは、日本語画面の翻訳が完全に間違っており、推測で埋めていたら真逆に読んでいました。**

### 最重要 ── 「BUY BOX の平均売上数」は誤訳です。売上ではありません

| | 内容 |
|---|---|
| 画面の日本語表記 | **BUY BOX の平均売上数**（出品者概要のパフォーマンス欄。例：8.83） |
| 公式の英語原語 | `avgBuyBoxCompetitors` |
| **公式定義（訳）** | **「この出品者が扱う商品の Buy Box を争っている出品者数の平均（この出品者自身を含む）」** |
| **正しい読み方** | **「この業者は平均8.83社と、カートを取り合っている」。売れた数とは一切関係ありません。** |
| **数字の向き** | **大きいほど競合が多い＝不利。** 日本語表記のまま読むと「売上が多い＝強い／おいしい」と、**意味が真逆に伝わります。** |
| 第2版での扱い | 「意味を断定できません（要確認）。判断に使わないでください」→ **この指示は正しかった。** 第3版で意味が確定したので、**読み方を反転させた上で**使えるようになりました |
| 出典 | `https://keepa.com/api-docs/seller-object.html`（最終確認 2026-08-24） |

**日本語UIだけを見て判断しないでください。** Keepaの日本語表示には機械翻訳が混ざっており、これは「訳がぎこちない」レベルではなく**意味が反対になる誤訳**です（同じ画面の「え」＝Rating の誤訳も同種の事故です）。

### 第3版の訂正一覧（この6件だけです）

| 場所 | 第2版の書き方 | 公式定義でどうなったか |
|---|---|---|
| §6-2 **BUY BOX の平均売上数** | 「意味を断定できません（要確認）」 | **✅確定：Buy Boxを争う平均競合出品者数。売上ではない**（上の表） |
| §6-2 **購入ボックス切り替えの所有者／ボックスを購入する 中古の所有者** | 「カートの保有割合とみられます（**要確認**）」 | **✅確定：新品／中古 Buy Box の平均獲得率（%）。当社の推定どおりでした**（`buyBoxNewOwnershipRate` / `buyBoxUsedOwnershipRate`）。「要確認」を外しました |
| §1 **売れ筋ランキングの下落** | 「ガクッと下がる回数**＝売れた回数**の目安」 | ⚠**言い過ぎでした。**公式は「ランキング下落の**回数**。**販売を示すものとみなされる**」までしか言っていません。**代理指標**に書き換え |
| §4 **先月の購入（200+ など）** | 「直近の販売数の**目安**」 | ⚠**「目安」ではなく実測値**（公式明記：*It is not an estimate*）。ただし "200+" という**粗い区切り**でしか出ず、**大半の商品ではそもそも表示されません** |
| §3 **Buy Box対象オファー数** | 「＝それだけ競合セラーがいる」 | ⚠**「オファーの数」であって「出品者の数」ではない。**かつ「**Buy Box に適格な**オファー」に限った数。**当社が2026年8月に実際に事故を起こした論点**（仕入れ候補リスト上位100件の35%が汚染）のため、**「大前提その4」に格上げしました** |
| §3 **%獲得** | 「カートを取っている割合」 | ⚠公式は「Buy Box を獲得していた**時間**の割合。**非プライム客に対して**」。**プライム客向けの獲得率とは異なりえます** |

### 逆に、第3版でも「分からないまま」にしたもの

| 項目 | 状態 |
|---|---|
| §3 Buy Box統計の **評価 -1%** | **❌未解決。公式に定義がありません。**（公式の `buyBoxStats` に評価の項目自体が存在しない）「データなし」という当社の見立ては**推測のまま**です。**判断に使わないでください** |
| §6-1 **商業番号** | ❌未解決。公式の出品者データに該当項目なし。近いのは `tradeNumber`（＝商業登記番号）ですが、**日本の古物商許可番号を指すとは公式に書かれていません** |
| §6 **無料プランでも出品者概要が開けるか** | ❌未解決。公式ドキュメントに記載なし。**社長の実機で1クリック確認していただく必要が残ります** |
| §6 画面右上の **Quota: 100%** | ❌未解決。公式APIドキュメントに定義が見つかりませんでした（Pro契約側の概念とみられる） |

> **分からないものを推測で埋めない方針は、第3版でも維持します。** 今回、埋めなかったおかげで誤った意味での運用を回避できました（「平均売上数」を素直に売上と読んでいたら、競合の多い商品ほど良く見えていたはずです）。

> **Keepaとは：** Amazonの商品ページに「価格と売れ行きの履歴グラフ」を差し込んでくれる無料のChrome拡張です。
> 「今の値段は高いのか安いのか」「この商品は本当に売れているのか」を、感覚ではなく**過去データ**で判断するための道具です。仕入れ判断の土台になります。

**まず大前提** ── Keepaの画面は、Amazon商品ページの中に「Keepa Box」という小さな枠として**埋め込まれて**表示されます。単独アプリではありません。商品ページを開くたびに、価格の上あたりに自動で出てきます。上部に **価格履歴 / 商品のトラッキング / Data / バリエーション / 設定** の5つのタブがあり、これを切り替えて使います。

なお Keepa には、この拡張（Box）とは別に **keepa.com というサイト本体**があります。本ガイドの §1〜§5 は拡張の5タブ、**§6「出品者概要」はサイト本体側の画面**です。入口が2つある、と覚えてください。

**大前提その2 ── Keepaの数字はリアルタイムではありません。**

- 公式FAQ：**誰かがその商品をトラッキング（ウォッチ）していれば1時間に1回、していなければ1日1回**しか更新されません。ニッチな商品ほど「1日1回」側です。
- Keepa自身が「**価格は厳密には僅かに古い**」と認め、**購入時は Amazon の実価格を必ず確認するよう公式に注意喚起**しています。
- **したがって Keepa は「候補を絞る道具」であって、「発注直前の値段を確定する道具」ではありません。** 最後の1クリック前は必ずAmazonの実画面を見てください。
- （社内向けの注記）これは**画面で見るときの話**です。当社の夜間スキャンのように **Keepa API 経由で取りに行く場合は別ルール**で、リクエスト時に自動更新が走るため最大約1時間の鮮度になります（公式 `product.html`）。「Keepaは24時間古い」と一般化しないでください。

**大前提その3 ── 日本語表示は機械翻訳です。** 意味が反対になる誤訳が実在します（冒頭の「BUY BOX の平均売上数」）。**意味の取れないラベルに出くわしたら、画面右上の「言語」を English に切り替えて原語を確認する**のが唯一確実な方法です。

**大前提その4 ── Keepaに「出品者数」という数字は存在しません。あるのは「オファー（出品）の本数」です。**

これは本ガイドで**いちばん覚えていただきたい一点**です。

- 画面に出てくる「**Buy Box対象オファー数**」「**新品アイテム数**」は、すべて**出品の本数**であって、**何社いるか**ではありません。
- **1社が FBA と FBM の両方に出せば、それだけで「2」と数えられます。**
- **当社は2026年8月、実際にこれで事故を起こしました。** ASIN `B0DWMPV656` は新品オファー数が「2」でしたが、**実際の出品者は1社だけ**（しかもその商品のメーカー自身）でした。「出品者が2社以上いる＝そのメーカーは外部に卸している証拠」という当社の条件が、**正反対のもの（メーカー直販の独占商品）を通していた**わけです。この読み違いで、仕入れ候補リスト上位100件の**35%が汚染**されていました。
- **「競合が実際に何社いるか」を知りたいときは、Keepaの数字を使わないでください。** Amazon の商品ページで「新品の出品（◯件）」の一覧を開き、**販売者名の重複を除いて数える**のが確実です。

> 用語補足：**オファー**＝1つの商品ページに対して、1人の出品者が出している「売り物1本」のこと。同じ商品を同じ人がFBAと自己発送で2通り出せば、オファーは2本になります。

## 1. 価格履歴タブ（いちばん使う画面）

Keepa Boxを開いた時に最初に出るメイン画面。折れ線グラフで**価格の推移**が読めます。縦軸が価格（例：¥30,000〜¥40,000）、横軸が日付です。

### 線の色の見分け方

| 色 | 意味 | 物販での読み方 |
|---|---|---|
| ピンク＝**Buy Box** | 今カートに入る価格（送料込み・最有力オファー） | **実際に売れている価格帯。最重要。** 仕入れ後にいくらで売れるかの基準 |
| 紫＝**新品** | 新品オファーの最安値（**Amazon本体の出品も含みます**） | 新品相場の下限。本体が最安の時は、この線＝Amazonの線になります |
| 新しい第三者FBA | Amazon倉庫発送のセラー価格 | FBA競合の価格 |
| 新品 第三者FBM（破線） | セラー自己発送の価格（送料込み） | 自己発送競合の価格 |
| 黒＝**中古** | 中古・整備済みの価格 | 中古/整備済みを扱う時の相場 |
| リファビッシュ | メーカー整備済み品 | 今回のAirPods Proはこれ |

> グラフの右側に**凡例（色の一覧）**が出ています。凡例の項目をクリックすると、その線の表示/非表示を切り替えできます。見たい線だけ残すと読みやすくなります（公式FAQにも「各グラフ横のラベルをクリックすると系列を個別にON/OFFできる」と記載）。
> **色は当てにせず、必ず凡例のラベルで判断してください。** 色は設定で変えられるため、色だけで覚えると事故ります。

> **【第3版で追記】新品・中古の線は、2026年2月23日を境に意味が変わっています。**
> 公式ドキュメントによると、それ以前の記録は「**最安の出品価格**（送料抜き）」、それ以降は「**最安の着地価格**（出品価格＋送料）」です。
> FBA品やプライム品は送料0なので実害は小さいのですが、**送料が乗る安価な自己発送（FBM）中心の商品では、2026年2月より前と後を単純比較できません。** 「全期間」で昔の最安値を見るときはご注意ください。

### 操作のコツ（実画面の注記どおり）

- **期間切替：** 右下の `1日 / 1週間 / 1ヶ月 / 全期間` で表示範囲を変える。相場感は「全期間」、直近の動きは「1ヶ月」。
- **ズーム：** グラフ上で見たい範囲をドラッグ選択すると拡大。ダブルクリックで元に戻る。
- **クローズアップビュー：** ONにすると、価格が動いている範囲に縦軸を寄せて、小さな変動を見やすくする。
- **統計：** クリックで最安値・最高値・平均価格などの数値サマリーが出る。
- **「◯人のユーザがこの商品をトラッキングしています」：** ウォッチしている人数。多いほど注目商品の目安。**加えて実務上の意味がひとつあります**──**この人数が1人以上いる商品は1時間に1回更新され、0人の商品は1日1回**です（大前提その2）。**トラッキング人数0の商品ほど、表示価格が古い可能性があります。**

**物販での読みどころ（ここが本番）**

- **価格の底と天井：** ピンク（Buy Box）の帯を見て「いくらまで下がる／上がるか」を把握。底値で仕入れ、高値で売るの判断材料。
- **値動きの激しさ：** ギザギザが激しい＝値崩れリスク。平坦＝安定して利益計算しやすい。
- **売れ行き（売れ筋ランキング線）：** ランキングが**ガクッと下がる回数**が多い＝よく売れている、と読みます。
  **【第3版で訂正】第2版では「下がる回数＝売れた回数」と書いていましたが、これは言い過ぎでした。**
  公式の定義は「**ランキングが下落した回数**であり、**販売を示すものとみなされる**」までです。**個数と等しいとは公式は言っていません**（1回のランク更新の裏で複数個売れていれば1回としか数えられないため、**構造的に少なめに出ます**）。
  → **「売れた回数そのもの」ではなく「売れ行きの代理指標」として使ってください。**
  用語補足：**代理指標**＝直接は測れないもの（実売個数）を、測れる別の数字（ランクの下落回数）で代用すること。傾向の比較には使えますが、個数として計算に入れてはいけません。

## 2. 商品のトラッキングタブ（値下がりアラート）

「この価格まで下がったら教えて」を設定する画面。**登録不要・無料**で通知が届きます（公式FAQでも「アカウント無しでも利用可能」と明記。無料登録すると端末間の設定同期などが使えます）。

1. **目標価格を入れる：** Buy Box / Amazon / 新品 / 中古 それぞれに「◯円**以下**になったら通知」を設定できる（スクショでは Buy Box=¥30,381 以下）。
2. **トラッキング対象（期間）を選ぶ：** 2週〜10年。通常は**1年**でOK。
3. **「トラッキング開始」ボタンを押す**と監視スタート。

> モードは ベーシック / アドバンスド / プロ の3段階。最初は**ベーシック**で十分。仕入れ候補を「安くなったら買う」リストとして貯めるのに便利です。

> **通知の届き先：** 画面には メール／ウェブプッシュ／Telegram／RSS が並びます。公式FAQが挙げているのは **Eメール／Telegram／Webプッシュ／iOS・Androidアプリ**の4つです。まずはメールで十分です。

> **【第3版で追記】一度通知が来た後、しばらく再通知が来ないのは仕様です。**
> 「再開タイマー（Rearm Timer）」の**公式デフォルトは7日間**。希望価格に到達すると、そのアラートは7日間休止してから再び有効になります（`しない` を選ぶと、到達後は希望価格を変更するまで二度と鳴りません）。
> 再通知される条件は3つ：①前回より価格がさらに下がった ②在庫切れ品が再入荷して希望価格を下回った ③一度希望価格を上回ってから再び到達した。
> **「アラートが鳴らない＝値下がりしていない」ではありません。** 出典＝公式FAQ（2026-08-24 確認）。

## 3. Dataタブ（セラー競合の実態を見る）

上部にサブタブ **製品詳細 / オファー / Buy Box統計情報 / Buy Box 中古統計情報**。中でも重要なのが **Buy Box統計情報** です。

**Buy Box統計情報＝「カートを誰がどれだけ取っているか」の表**

スクショの例：Buy Box対象オファー数 → 新品FBA:22 / 新品FBM:6 / 中古FBA:3

> **【第3版で訂正】この数字は「競合セラーの数」ではありません（大前提その4）。**
> 公式フィールドは `buyBoxEligibleOfferCounts`。定義は「**Buy Box に適格な**オファーの数」で、**新品FBA／新品FBM／中古FBA／中古FBM／コレクター品FBA／コレクター品FBM／再生品FBA／再生品FBM の8種類**に分かれています。抜けていたのは次の2点です。
> ① 数えているのは**オファー（出品）の件数**であって**出品者の数ではありません**（同じ1社がFBAとFBMの両方に出していれば2件と数えます）。
> ② **Buy Box を取る資格のないオファーは含まれていません**（実際の出品件数はもっと多い場合があります）。
> → 「新品FBAで22件の出品と競り合う棚」くらいの受け取り方が正確です。**「22社と競う」ではありません。**
>
> **この読み違いは、当社が2026年8月に実際に踏んだ地雷です**（大前提その4の `B0DWMPV656` の例）。仕入れ候補リストの上位100件の35%が汚染されました。**「何社いるか」は、Amazonの出品一覧で販売者名を数えて確かめてください。**

| %獲得 | 平均価格 | 販売者 | FBA | 評価（過去12ヶ月） |
|---|---|---|---|---|
| **57%** | ¥35,554 | セラーA | ✔ | -1% |
| 23% | ¥37,792 | セラーB | ✔ | 92% |
| 6% | ¥40,549 | セラーC |  | 60% |
| 4% | ¥40,045 | **セラーX** ← §6 で分解します |  | 82% |

- **%獲得＝そのセラーが Buy Box（カート）を獲得していた「時間」の割合です。**1社が過半を握っている商品は、後から入っても価格競争になりやすい＝旨みが薄い、という判断に使えます。
  **【第3版で追記】公式定義には「非プライム客に対して」という限定が付いています。** つまりこの数字は**非プライム会員に表示されていたカートの取り合い**の結果で、**プライム客向けの獲得率とは異なりえます**。Amazonの購入者はプライム会員比率が高いため、**「57%」を全購入者に対する支配率と読むと過大／過小のどちらにもズレます。** 順位付け（誰が強いか）には使えますが、**売上シェアの代用にはしないでください。**
- 「平均価格」は、そのセラーの **Buy Box オファーの平均価格**です（公式定義と一致。第2版から変更ありません）。
- 評価列の **-1%** は「データなし」を示す表示とみられます。**【第3版でも未解決】公式ドキュメントを全ページ当たりましたが、この列の定義は見つかりませんでした**（公式のBuy Box統計に評価の項目自体が存在しません）。**推測のままなので、判断に使わないでください。**
- **販売者名はリンクです。** クリックすると、その業者1社だけを丸裸にする「出品者概要」画面（**§6**）に飛びます。競合が強くて迷った時は必ずここまで見てください。
- 実在の事業者名は「セラーA/B/C/X」に置き換えています（理由は §6 冒頭の注意書き）。

## 4. バリエーションタブ（色・サイズ違いを横並び比較）

同じ商品の色・容量などのバリエーションを、**Buy Box / 新品 / 中古 の現在価格と履歴グラフ**で一覧比較できます。「どのバリエが一番売れて、値持ちが良いか」を選ぶのに便利です。

右端の**「先月の購入」**（例：200+）は、**この節でいちばん強い数字**です。

> **【第3版で訂正】「販売数の目安（推定）」ではありません。実測値です。**
> 公式定義は「**過去1か月にこの商品が購入された回数**。Amazonの検索結果に出る "bought past month" の値そのもの。**推定値ではない（It is not an estimate）**」。
> ただし使う上での制約が3つあります。
> 1. **Amazonは "10+" "100+" のような区切られた範囲でしか出しません。** 「200+」は「**少なくとも**200回買われた」の意味で、上限は分かりません（1,000かもしれません）。
> 2. **大半の商品にはそもそもこの値がありません。** 空欄＝売れていない、ではありません。「Amazonが出していない」だけです。
> 3. **バリエーション単位の数字**です（色違い全部の合計ではありません）。
>
> → **値が出ている商品では、ドロップ回数（§1）よりこちらを信用してください。**実測だからです。ただし「+」の意味を忘れて利益計算の個数に入れないこと。

## 6. 出品者概要（セラー分析）— 競合の正体を逆引きする

### 6-3. 期間別の評価 — この節で一番おいしいところ

| | ライフタイム | 30日 | 90日 | 365日 |

### 6-5. カテゴリー／ブランド別リスティング統計 — 相手の稼ぎ頭を当てる

「リスティング」＝出品のこと。**その業者の出品が、どのカテゴリ／ブランドに何％あるか**の内訳表です。列は3つだけ覚えれば十分です。

| 列 | 意味 | 判断への変換 |
|---|---|---|
| リスト | 出品全体に占める構成比 | 相手の**主戦場**はどこか |
| Amazonオファーがあるリスト | そのうち**Amazon本体も出している**商品の割合 | 高い＝本体と真っ向勝負。**0%＝本体が不在の隙間**で稼いでいる |
| 30日間の平均順位 | 売れ筋ランキングの平均（**数字が小さいほど売れている**） | 構成比が小さくても順位が良ければ、そこが**回転の速い稼ぎ頭** |

> **【第3版で追記】この表の精度について、公式が自ら「Keepa のしばしば不完全で古い出品データに基づく」と明記しています。**
> 傾向（どのジャンルが主戦場か・本体と当たっているか）を掴む用途には使えますが、**％を1桁まで信じないでください。**

**実例の読み（セラーX）**

| カテゴリ | リスト | Amazon本体あり | 30日平均順位 |
|---|---|---|---|
| 家電＆カメラ | 52.69% | 28.41% | #31,133 |
| **ゲーム** | 16.77% | 67.86% | **#641** |
| パソコン・周辺機器 | 10.18% | 5.88% | #53,216 |

| ブランド | リスト | Amazon本体あり | 30日平均順位 |
|---|---|---|---|
| **アップル** | 30.89% | **0.00%** | #36,660 |
| パナソニック | 15.45% | 89.47% | #32,724 |
| **任天堂** | 14.63% | 72.22% | **#795** |

- **看板と稼ぎ頭は違う。** 出品数の半分は家電＆カメラ（#31,133＝そこそこ）。一方**ゲームは16.77%しかないのに平均#641**＝圧倒的に回っている。この業者の実際の収益源はゲーム系だと読めます。
- **アップル30.89%で、Amazon本体のオファーは0%。** 本体が出していない領域（整備済み品など）を狙い撃ちしている構図。§1のAirPods Pro整備済み品も、まさにこの戦い方の中にあります。

### 6-6. 当社での使い方は、この3つに絞る

1. **参入前の「相手チェック」** — §3でカートを握っている相手を開き、(a) 直近90日の評価／(b) Amazon本体との重複率／(c) そのカテゴリの平均順位 の3点だけ見る。本体と重なる領域なら見送り、相手の評価が崩れているなら検討。
   **【第3版で追加】4つ目に「BUY BOX の平均売上数（＝平均競合出品者数）」も見てください。** ただし読み違えやすいので注意点を1つ。**この数字は「今見ている1商品の混み具合」ではなく、「その業者が扱う商品全体の平均」です**（公式定義：この出品者の**商品群**の Buy Box を争う出品者数の平均）。
   → **使い方は「相手が普段どれくらい混んだ棚で戦っているか」の把握**です。数字が小さい業者は、競合の少ない棚を選べている＝**仕入れルートに独自性がある**可能性があり、②メーカー仕入れの参考になります。逆に大きい業者は、誰でも仕入れられる商品を大人数で取り合っている＝**真似しても消耗戦になりやすい**。目の前の1商品が混んでいるかは、§3の「Buy Box対象オファー数」で見てください。
2. **仕入れ候補の芋づる探索** — 「重複の多い主なセラー」（上位5社）→ 各社の「Keepaで出品を閲覧」で棚を丸ごと確認。②メーカー仕入れで「そのメーカーの品を今どこが扱っているか」を逆引きする用途は相性が良さそうですが、**当社では未検証**です。
3. **中古を扱うなら許可の裏取り（※確度が落ちました）** — 基本情報カードの**商業番号**は古物商許可番号の体裁と一致しますが、**公式の裏付けが取れていません**（6-1）。**単独の根拠にはせず、Amazon側の出品者ページ（特定商取引法に基づく表示）で確認してください。**

**この画面の限界（過信しないために）**

- 数字は**Keepaが追跡できている範囲**のもので、その業者の全量ではありません。**公式自身がカテゴリ／ブランド統計について「しばしば不完全で古い」と認めています**（6-5）。
- **「FBAリストが見つかりました：いいえ」は信用できません**（6-2）。「はい」だけが信頼できます。
- 意味を確定できないラベルがまだ2つ残っています（**商業番号**／画面右上の **Quota**）。**分からない数字は使わない**のが正解です。
- 画面は**2026-08 時点**。Keepaの仕様変更で項目名・配置は変わります（実際、価格の定義が2026年2月に、オファー数の項目が2026年3月に変わっています）。

## ✓ これだけ覚えれば回る：3ステップ

1. **価格履歴タブ** — ピンク線（Buy Box）で「今は高い？安い？」を判断。全期間で相場、1ヶ月で直近を見る。
2. **売れ行き確認** — **まずバリエーションタブの「先月の購入」**（実測値。あれば最優先）。**無ければ**売れ筋ランキング線の下落回数（代理指標）で代用する。この優先順位が第3版で変わった点です。
3. **競合チェック** — Data→Buy Box統計情報で、**Buy Box適格オファー数**（＝出品者数ではなくオファー数）とカート獲得率を見て「入っても勝てるか」を判断。**迷ったら販売者名をクリックして §6（出品者概要）まで踏み込む** ── 相手の**直近90日の評価**と **Amazon本体との重複率**で、行くか引くかが決まります。あわせて「**BUY BOX の平均売上数**」（＝その業者が普段争っている**平均競合出品者数**。売上ではありません）を見ると、**その相手を真似すべきか**の判断材料になります。

> **注意：** Keepaは**過去の事実**を見せてくれる道具で、未来を保証はしません。しかもその過去の事実は**リアルタイムではなく、最短でも1時間前・多くは1日前**のものです（大前提その2）。**発注を確定する直前は、必ずAmazonの実画面で価格と在庫を見てください**（Keepa公式自身がそう注意喚起しています）。
