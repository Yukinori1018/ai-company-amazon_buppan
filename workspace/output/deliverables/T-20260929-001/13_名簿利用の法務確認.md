# 13 名簿利用の法務確認（12 §7 論点5）

T-20260929-001 ／ 2026-10-05 ／ 法務 ハルオ
対象：12_名簿拡張の見積り の4経路を、メーカーへの仕入れ打診（メール・フォーム・電話）に使ってよいか。
方法：規約・robots.txt・ページ表示・法令の原文を当職が自分で取得した（取得日はすべて 2026-10-05）。主催者・事務局への問い合わせはしていない。

## 0. 結論

1. **ギフトショー・RX・ものづくり補助金の3経路は、仕入れ打診に使えます**（ギフトショーと RX は条件付き、補助金は共通条件のみ）。12 の名簿倍率 約4.4〜4.6倍はそのまま使えます。
2. **ザ・ビジネスモールは NG です。**ページの注記は「売り込み・テレマーケティング禁止」だけですが、利用規約 第17条は「掲載情報を自社の営業活動**その他の理由**で利用する行為」まで禁じています。買い手の打診も文言に入ります。使い道は「商談モールに買いたい案件を出す」ことです。
3. 4経路とも、送る側の法令（特定電子メール法・個人情報保護法）の条件は同じです。量が数千社になるので、**仕入れ打診でも特定電子メールとして表示義務を満たして送る**（9/16 判定の維持）。

## 1. 経路別の検討

### 1-1. ① ギフトショー出展社PDF — 条件付き OK

**実測した事実**

| 項目 | 結果 |
|---|---|
| PDF | `giftshow.co.jp/tigs/102tigs/pdf/list.pdf` HTTP 200。ログイン・同意画面なし |
| PDF の表示 | フッタに1回「（C）2026 BUSINESS GUIDE-SHA,INC. 無断掲載及び他のメディアへの加工を禁止します。」 |
| サイトの利用規約 | トップから辿れるのは個人情報保護方針だけ。サイトの利用規約は無い |
| robots.txt | 404（拒否の意思表示が無い。許可でもない） |

**判定の理由**

- PDF の表示は**契約ではありません**。取得前に同意する手続きが無いからです（民法522条の申込み・承諾がない）。8/31 判定（T-20260831-005/04）と同じです。
- 表示が禁じているのは「掲載」と「他のメディアへの加工」です。**営業・仕入れへの利用は禁じていません。**
- 社名は事実です。著作物ではありません（著作権法2条1項1号）。社内での分類・突合は30条の4第2号で説明できます。
- 出展社は、小売・通販の買い手と商談するために出展しています。買い手からの仕入れ打診は**名簿の公表目的に合っています**。

**条件**

1. 名簿（社名の一覧）を PUBLIC リポに置かない。置き場は `agent_output/`、社長所有の非公開シートまで（著作権法21条・23条、個人情報保護法27条。屋号だけの個人事業主が混ざる）。
2. **Gift Net（オンライン事前登録）に登録したら、この判定をやり直す。**Gift Net 利用規約 第5条は「出展社情報を本サービス利用以外の目的で利用する行為」を禁じています。来場は当日登録（名刺持参・無料）にすれば、この規約に同意せずに済みます。
3. 連絡先（メール・フォーム・電話）は、PDF ではなく**各社の公式サイトから取る**。
4. 打診文で接点を偽らない。「展示会でお見かけした」は来場していなければ書かない。「出展社一覧で拝見しました」は事実なので書いてよい。

**リスク3軸**：発生確率 低／影響度 小（主催者から削除を求められる程度）／不可逆性 低。

### 1-2. ② RX ライフスタイルWeek — 条件付き OK

**実測した事実**

| 項目 | 結果 |
|---|---|
| サイトの「ご利用条件」 | フッタのリンク先は「RX NOW 利用規約」（最終更新 2026-05-12） |
| RX NOW の範囲 | 定義集（2026-02-19 更新）で「Customer Profile/Directories」＝**出展社ディレクトリを含む** |
| 合意の作り方 | 1.1「RX NOWへの登録、アクセス、ログイン、および／または利用…を行うことにより…同意したものとみなされます」 |
| 禁止事項 | 3.2(iii)「RX NOWの全部または一部を複製すること」／3.2(v)「自動化ツール、ボット、またはスクレイピング技術を使用して、RX NOWからデータを抽出すること」 |
| 利用の仕方 | 3.3「適用されるスパム防止法および迷惑メッセージ防止法」の遵守。「本来の目的以外の目的で利用してはなりません」 |
| アクセス方法 | 6.1「RX NOWには参加者のみアクセスできます」（メール認証かバッジ） |
| robots.txt | 200。`/*.pdf$`・`/*exhibitor-hub` などを Disallow。**出展社詳細ページと sitemap は Disallow されていない**。`Sitemap:` 行で sitemap.xml を案内している |

**判定の理由**

- 非登録者がログインなしで見る出展社ページに、この規約が契約として及ぶかは**はっきりしません**。6.1 は「参加者のみアクセスできる」と書いており、ログイン不要の公開ページは想定していない読み方もできます。ただし、フッタで「ご利用条件」として示されているので、**及ぶ前提で動きます**（明文主義）。
- sitemap.xml は、robots.txt が機械に読ませるために案内しているファイルです。1展1回取るのは、3.2(v) の「スクレイピング」の典型（詳細ページを巡回して中身を抜く）とは違います。ただし**グレーは残ります**。だから詳細ページの機械巡回はしない、を条件にします。
- 出展社に商談を申し込むのは、ディレクトリの本来の目的（3.3）に合います。
- 来場登録（事前登録）をすると、展示会・セミナー参加ポリシーと RX NOW 規約に**明確に同意したことになります**。その後は 3.2 違反が契約違反として効きます。

**条件**

1. 取るのは sitemap.xml（`<展>/ja-jp.exhibitors-sitemap.xml`）だけ。1展1回。社名は URL から読む。
2. 出展社詳細ページを機械で巡回しない。プロフィール文・画像・連絡先を写さない（3.2(iii)(v)）。
3. PDF は取らない（robots.txt で Disallow）。
4. 連絡先は各社の公式サイトから取る。
5. 名簿を PUBLIC リポに置かない。

**リスク3軸**：発生確率 低／影響度 小〜中（規約違反と判断されると、RX のアカウント・入場バッジの停止＝4.2(v)。RX の展示会に来場できなくなる）／不可逆性 中。条件1〜2を守れば確率はさらに下がる。

### 1-3. ③ ものづくり補助金 採択一覧 — OK（共通条件のみ）

**問題ない根拠**

| robots.txt | 404 |

- 公表の目的は補助事業の透明性です。営業・仕入れへの利用を禁じる記載はありません。

**より安全な取り方（任意）**：gBizINFO にも補助金の交付情報が載っています。gBizINFO は「CC BY と互換」「商用利用も可能」と明記されています（9/20 判定済み）。ものづくり補助金の分がどこまで載っているかは未確認です。

**リスク3軸**：発生確率 低／影響度 小／不可逆性 低。

### 1-4. ④ ザ・ビジネスモール — NG

**ご質問への答え**：企業詳細ページの注記「売り込みやテレマーケティングに利用することは禁止します」だけを読めば、買い手からの仕入れ打診は文言に入りません（「売り込み」は売る行為）。**しかし利用規約の禁止は注記よりずっと広い。**判定は規約で決まります。

**利用規約（`b-mall.ne.jp/memberyakkan/`・平成16年施行・令和6年4月19日改定）第17条**

柱書：「本サービスにアクセスする**全ての利用者**について、本サービス上ならびにその後の商談において…行うことはできません」

| 号 | 原文 | 仕入れ打診への当たり方 |
|---|---|---|
| (12) | 「『ザ・商談モール』における『質問』や『応募』を除き、本サービスに掲載されている企業に対する広告・宣伝・PR・**勧誘**等の電話、FAX、電子メールを送信する行為」 | 「当社と取引しませんか」は取引の勧誘と読める。グレー |
| (13) | 「本人または事務局および登録団体の同意を得ることなく…他者の企業情報を収集する行為」 | 名簿化＝収集。**該当** |
| (14) | 「本サービスに掲載されている情報を自社の営業活動**またはその他の理由を含め**利用する行為」 | 仕入れは自社の営業活動。「その他の理由」まで含む。**該当** |
| (16) | 「本サービスを本来の趣旨から逸脱して利用する行為」 | 名簿として使うのは趣旨外 |
| (17)(カ) | 「自動化された手段（ロボット、スクレイピング等…）を用いて本サービスにアクセスする行為（robot.txtファイルの定めによる場合を除く）」 | 機械取得は原則禁止 |

あわせて第16条（入手したデータ等を私的利用の範囲を超えて利用しない）。robots.txt は電話番号の表示 API（`/telno/api/`・`/link/CompanyTelNoApi.aspx`）を Disallow しています。電話番号は「表示する」ボタンの奥にあり、その横に例の注記があります。

**判定の理由**

- 非会員には同意の手続きが無いので、規約が契約として及ぶかは弱いです（民法548条の2の定型約款の合意も、非会員の閲覧には当てはめにくい）。**それでも NG にします。**理由は3つです。
  1. 運営者の意思が明文で示されている。注記を読んだうえで使えば、故意と評価されます。
  2. 規約に反した取得は、個人情報保護法20条1項「偽りその他不正の手段」による取得と評価される余地があります（個人事業主の情報について）。
  3. **不可逆性が高い。**本当の制裁は訴訟ではなく、第9条（利用の不承認）・第25条（利用取消）です。商工会議所の会員になっても、ザ・ビジネスモールの本命である「商談モールへの案件投稿」（12 §4：1案件で提案5.1件）を使えなくなるおそれがあります。地元の商工会議所との関係にも響きます（推測）。

**リスク3軸**：発生確率 中（「ビジネスモールで見た」と書く、電話番号を機械で取る、で発覚する）／影響度 中（商談モールの経路を失う）／不可逆性 高。

## 2. 4経路に共通する法令

### 2-1. 特定電子メール法 — 表示義務を満たして送る

**仕入れ打診は「広告・宣伝」に当たるか**

- **原則は当たりません。**法2条2号の特定電子メールは「自己又は他人の営業につき広告又は宣伝を行うための手段として送信をする電子メール」です。買う申込みは自社の営業の宣伝ではありません。総務省ガイドライン p.2 の非該当例ア）（取引上の条件を案内する事務連絡で、広告宣伝を含まず、サイトへ誘導もしないもの）とも合います（9/4 判定）。
- **ただし、次のどれかが入ると当たります。**自社サイト・Amazon ストアの URL（GL p.1 該当例ア）の「誘導」）／「当社なら貴社商品の売上を伸ばせます」など自社の販売力の売り込み。数千通の型で全通をこの外に保つのは難しい。
- **だから量産では、当たる前提で義務を満たします**（9/16 判定 T-20260915-002/10 の維持）。費用は署名の5行だけです。

**守ること**

| # | 条件 | 根拠 |
|---|---|---|
| 1 | 送り先のアドレスは、**相手企業が自社サイトで公表しているもの**に限る。展示会・DB の画面に載ったアドレスは使わない | 法3条1項4号、施行規則3条本文（「自己の電子メールアドレスをインターネットを利用して公衆が閲覧することができる状態に置く」） |
| 2 | アドレスの近くに「広告メールお断り」等の表示がある会社には、**メールで送らない**。フォームか電話に回す | 施行規則3条ただし書（表示があると4号の例外が消える） |
| 3 | 本文に、送信者の氏名又は名称・受信拒否の連絡先・住所・苦情や問い合わせの受付先を書く | 法4条1号・2号・3号、施行規則 |
| 4 | 受信拒否・「不要」の返信が来たら、**その会社には全経路で即日、永久に送らない** | 法3条3項 |
| 5 | URL は貼らない。貼るなら取引先向けの `satoy-select.com/partners` 1本だけ | GL p.1 該当例ア） |

**特定電子メール法がかからない手段**：問い合わせフォーム（HTTP 送信は同法の「電子メール」でない。平成21年総務省令85号）・電話（特商法の電話勧誘販売は売る側の規制で、当社は買う側）・FAX（同法の対象外）。ただし拒否された後の繰り返しは、民法709条・刑法234条（業務妨害）に近づきます。**断られたら二度と連絡しない**で足ります。

### 2-2. 個人情報保護法

| 論点 | 結論 | 根拠 |
|---|---|---|
| 法人の社名・代表番号・代表アドレス | 個人情報ではない | 法2条1項（生存する個人に関する情報） |
| 個人事業主の屋号・氏名、担当者名入りのアドレス、補助金PDFの個人名 | **個人情報** | 同上 |
| 当社は義務を負うか | 負う。名簿をシートで検索できる形にした時点で「個人情報データベース等」を事業に使っている | 法16条 |
| 公開情報を取ってよいか | よい。ただし規約に反した取得は「不正の手段」と言われる余地がある（④を NG にした理由の1つ） | 法20条1項 |
| 利用目的の通知・公表 | 当社サイトに個人情報の方針が無い（`/privacy` 404・2026-10-05 確認）。**初回の連絡文に1行入れる**（例：「頂いたご連絡先は、仕入れのご相談にのみ使います」） | 法21条1項。同条4項4号（取得の状況から目的が明らか）でも足りる余地はあるが、1行で済むので書く |
| PUBLIC リポへの commit | しない。個人事業主の一覧を公開＝第三者提供にあたり得る | 法27条1項 |
| 利用停止の求め | 応じる。2-1 の4と同じ運用で足りる | 法35条 |

### 2-3. 著作権・PUBLIC リポ

4経路とも、**社名の一覧（名簿そのもの）は PUBLIC リポに置かない**。成果物に書くのは件数・割合などの集計だけ。12 はこの形になっている（会社名入りの一覧は `agent_output/` のみ）。2-2 と合わせ、現在の運用で満たしています。

## 3. 共通の遵守条件（チェックリスト）

送信の担当（マリエ／ヒデアキ／タカシ）は、次の8点を満たしてから送る。

1. 名簿は `agent_output/` と社長所有の非公開シートだけに置く。PUBLIC リポに入れない
2. 連絡先は各社の公式サイトから取る（展示会・DB の画面から取らない）
3. メールの宛先は、自社サイトで公表されたアドレスだけ。「広告メールお断り」併記の会社はフォームか電話へ
4. 署名に、名称・住所・受信拒否の連絡先・問い合わせ先の4点
5. URL は貼らない（貼るなら /partners だけ）。自社の販売力の売り込みを書かない
6. 初回の文面に、連絡先の利用目的を1行
7. 断り・受信拒否は会社単位・全経路で即日停止。再連絡しない
8. 接点を偽らない（来場していない展示会を「お会いした」と書かない）。Amazon での販売状況も事実どおりに書く

## 4. ザ・ビジネスモールの代わり（NG だが選択肢から外さない）

| 案 | 中身 | 規約上 | 費用・手間 | 推奨 |
|---|---|---|---|---|
