## 6. この文面で決めたこと（なぜこう書いたか）

| 判断 | 理由 |
|---|---|
| **1行目で「個人事業主・販売実績なし・初回12点」を全部出す** | 隠して後で断られるのが最も損。**相手が断る材料を先に渡すと、受けると言われた答えの確度が上がる。**びーぷらす・おりおんは福祉事業所で、工賃を生む仕事として受けるかの判断がある。規模を隠すのは相手に対しても不誠実 |
| **件名に「Amazon大口出品者・初回12点」を入れた** | 福祉事業所の共通フォームは**見学・営業・仕事依頼が同じ箱に入る**。件名で分類が決まる。「初回12点」まで入れると、一次受けが**規模の判断ができる担当へ回せる** |
| **Q2 に「差出人が当社名ではない荷物」を明文で入れた** | 各社の公式は「**受取人**に会員名」しか書いていない。差出人は誰も書いていない。ここが通らないと**荷物が受取拒否になり、商品ごと失う**。4軸で唯一、失敗が物理的に不可逆 |
| **Q3 で「納品書」と「送り状」を分けて書いた** | 納品書は**箱の中**、送り状は**箱の外**に貼られている。「書類を送ってください」だけでは作業者が中身しか見ない。**どこにある紙を指しているかまで書く**のが現場に届く書き方 |
| **Q3 で「画像または PDF」と手段を指定した** | 「納品書を送ってもらえますか」だと郵送で返事が来る（FBA代行センターの公式サービスは現物郵送500円）。**郵送＝出品許可の申請が数日遅れる。**欲しいのは紙ではなく読める画像、と先に言い切る |
| **Q3 に「郵送では数日遅れるため」と理由を書いた** | 理由のない要望は断られる。**無理めの依頼は、理由をつけると代案が返ってくる**（「撮影ならできます」など） |
| **Q4 に「3〜7営業日、長い場合は2週間」と日数を書いた** | 「しばらく預かってもらえますか」では見積もれない。**期間を数字で出すと、無料期間内か否かを相手が即答できる** |
| **質問を番号付き・1問1行にした** | 番号で返信が来る＝**社間の比較に照合作業が要らない。**3社の回答を同じ表に並べるのが次の工程（タケシの主力差し替え判断） |
| **値引き交渉を1語も書かない** | 実績ゼロの客が値段を言うと、**受けるか否かの判断が「面倒な客か」に変わる。**料金は公開されているので交渉の余地を探る段階ではない |
| **「比較のため、ほかにも同じ内容をお伺いしている」を末尾に1行だけ** | 隠すと、後で「他社にも出していた」が不信になる。**冒頭に置くと値引き圧力に読める**ので末尾。1行で、社名は書かない |
| **FBA代行センターだけ「拝見しました」型に書き換えた** | 公式Q&Aに答えがある4問を素で聞くと、**Q&Aの URL を貼った定型文**が返る。読んだ上での不明点だけ聞く形にすると、個別回答の確率が上がる（memory `knowledge_platform_operator_inquiry_letter` §7 と同じ原理） |
| **短縮版を先に作った** | フォームの文字数上限は外から見えない。**上限に当たったとき、カズヨにその場で削らせないため。**削る順も決めてある（memory 同 §8） |
