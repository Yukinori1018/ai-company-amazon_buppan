## 1. 結論サマリ（最初の1画面）

**勝ち筋はここです: 「不要品販売(A) で1周完走 → 国内卸サイト(B) で本番2周目」の2段構成。**

理由は1つ。このStep2のゴールは「利益」ではなく**「事故ゼロで、出品→販売→入金の全工程を、自分の手で1周し切る」体験**だからです（T-004で「学習が主目的、利益は副次」と明記）。であれば、最初の1周は**規制リスクが構造的にゼロに近い不要品販売(A案)**で仕組みを完走させ、仕組みを体で覚えた直後に**国内卸サイト(B案)で「仕入れて売る」本番**に進むのが、期待値・学習効率・事故率のすべてで最良です。

- **最初の一歩（今日〜数日でできる）**: 自宅の不用品から **状態の良い書籍・ゲーム・未使用ガジェット等を3〜5点**ピックアップし、Amazonの商品ページに「相乗り出品」する。**原資ゼロ・古物商不要・10万円は1円も使わない**。
- **10万円の出番は2周目（B案）**から。1周目で仕組みを完走してから、初めてお金を賭けます。
- **やらないこと（捨てる戦略）**: 1周目から「儲かる商品探し（電脳せどりC案）」に飛びつかない。リサーチ・損益計算・規制判断を**同時に**初心者に負わせると、完走前に止まる確率が高い。**学ぶ順番を分解する**のが今回の戦略の核心です。

> ひとことで: **「お金を賭ける前に、仕組みを1周させる」。** これが副業初心者の事故率を最も下げる順番です。

## 2. 仕入れ手法 A/B/C ＋推奨

リサーチで12方法→3案に絞り込み済（02参照）。体験1周に適した3案を、戦略の目線で評価します。

### A案: 不要品販売（自宅の私物を売る）

| 観点 | 内容 |
|---|---|
| 何を | 自宅の不用品（書籍・ゲーム・CD/DVD・未使用ガジェット・ホビー等） |
| どこで | 仕入れ先なし＝自宅。Amazonの既存商品ページに「相乗り出品」 |
| 初期費用 | **0円**（仕入原資も実質0。10万円は使わない） |
| 難易度 | ★☆☆（最も易しい） |
| 学べること | 出品登録 → 価格設定 → 梱包・発送（または FBA 納品）→ 入金 の**全工程を最小リスクで1周** |
| 想定リスク | 🟩 構造的に最小。自己所有物の処分は古物営業に当たらず**古物商不要**、真贋・商標問題も発生しない（01・02） |
| 体験1周への向き | **最適**。「仕組みを事故なく1周する」目的に最も忠実 |

### B案: 国内卸サイト（NETSEA 等で小ロット新品仕入れ）

| 観点 | 内容 |
|---|---|
| 何を | 卸サイトの新品を小ロット仕入れ（日用品雑貨・文具・収納等の規制低カテゴリ推奨） |
| どこで | NETSEA（登録無料）/ スーパーデリバリー（買い手側 月¥約2,000税抜＋審査）/ orosy 等（03の#1〜#5） |
| 初期費用 | NETSEA は0円。仕入原資は10万円から拠出（小ロット運用） |
| 難易度 | ★★☆ |
| 学べること | 「**仕入れて売る**」本来のフロー・損益計算（仕入値＋送料＋FBA手数料）・卸の最小ロット運用 |
| 想定リスク | 🟩〜🟨 国内卸の新品は**請求書が出る＝真贋調査に強い**。出所が明確で事故りにくい（01・03 B-5） |
| 体験1周への向き | **本番体験に最適**。フリマ仕入れがNGになった今、初心者が新品を正規ルートで小ロット仕入れできる現実的な在宅手段 |

### C案: 電脳せどり（量販店ネットのポイント還元仕入れ）

| 観点 | 内容 |
|---|---|
| 何を | ヨドバシ等で還元込み実質10〜16%引きの新品を仕入れ |
| どこで | ヨドバシ#9 / ビック#10 / 楽天#12 等（03） |
| 初期費用 | 0〜。リサーチツール（Keepa 等 月¥約3千）推奨 |
| 難易度 | ★★★（最も高い） |
| 学べること | 相場リサーチ・ポイント設計・送料込み損益計算（**せどりの基礎力は最も付く**） |
| 想定リスク | 🟨 量販店新品は「メーカー同等保証」が無いと**Amazon新品出品不可**・領収書保管必須。家電(PSE)等の規制カテゴリに触れやすい（01・03 B-5） |
| 体験1周への向き | △ 学びは深いが、リサーチ＋規制判断＋損益計算を初心者に同時に課すため、**初回完走の難度が高い** |

### 推奨: A → B の2段構成（C は3周目以降の選択肢）

**推奨理由3点:**

1. **目的適合度が最も高い** — Step2のゴールは「完走体験」（T-004明記）。A案は規制リスクが構造的にゼロに近く（01）、**お金を賭けずに全工程を1周**できる。完走確率が最大。
2. **学習が階段状に積み上がる** — 1周目(A)で「出品〜入金の仕組み」を体で覚えた状態で2周目(B)の「仕入れ→販売の損益」に進めば、新しく学ぶ変数が毎回1つに絞られる。**初心者が1度に背負う認知負荷を最小化**できる（＝挫折率を下げる最も効く打ち手）。
3. **予算を守りながら本番も体験できる** — A案は0円。B案も小ロットなら10万円の枠内で十分。**「儲け」を焦らず「学び」を最大化**しつつ、Bで実際にお金を賭ける本番の緊張感も得られる。

**捨てるもの（やらないこと）:** 初回からのC案（電脳せどり）。リサーチ力・規制判断・損益計算を同時に要求するため、**「完走」より先に「リサーチ沼」で止まるリスク**が高い。C案で身につく基礎力は価値が高いので、**A→B完走後の3周目で取りに行く**。永久除外ではなく「順番を後ろにする」判断。

> 補足: 店舗せどり（02の次点）は外出・地域差が前提。在宅完結のB/Cを優先。社長が「外出仕入れもやってみたい」場合のみ昇格を検討（要確認＝論点2の社長生活情報）。

## 3. 最初に狙う商品ジャンル / 具体例

「規制リスク低 × 低単価 × 初心者でも良し悪しを判断しやすい」で選びます。restricted-categories の推奨（国内正規ルートの日用品＝文具・清掃・収納、中古本）と整合（04 論点4）。

### A案（不要品販売）で出す具体例 — 自宅にあるものから

| ジャンル | 商品イメージ | なぜ初心者向きか |
|---|---|---|
| **本・雑誌** | 読み終えた書籍、専門書、コミック | Amazonに既存ページが必ずあり相乗りが容易。価格相場が一目で分かる。低単価で失敗してもダメージ小 |
| **ゲーム・ソフト** | 遊び終えたゲームソフト/周辺機器 | 型番で同定しやすく、状態ランクの基準が明確 |
| **CD / DVD / Blu-ray** | 視聴済みメディア | 同上。バーコードで一発検索でき出品が速い |
| **未使用ガジェット小物** | もらい物の充電器・ケーブル類（未開封） | 状態判断が容易。送料が安く損益が読みやすい |

> A案のコツ: **まず「状態が良く・型番がはっきりし・Amazonに既存ページがある」もの**を選ぶ。これが「相乗り出品」を最速で体験する近道。

### B案（国内卸）で狙うジャンル — 規制低カテゴリに限定

| ジャンル | 商品イメージ | なぜ初心者向きか |
|---|---|---|
| **生活日用品・雑貨** | キッチン小物、収納グッズ、掃除用品 | 出所が請求書で明確・規制リスク🟩・需要が安定（生活必需）。B案×日用品は相性最良（04 論点4） |
| **文具・事務用品** | ノート、ペン、デスク周り | 季節変動が小さく回転が読みやすい。低単価で1点あたりの賭け金が小さい |
| **ペット用品（消耗品系）** | トイレシート、食器等（食品・薬品は除く） | リピート需要・規制低。ただし**ペットフード/サプリは食品扱いで要注意（避ける）** |

### 避けるべきジャンル（初回は触らない）

- 🟥 **健康食品・サプリ・化粧品・美容機器**（薬機法・成分表示・社長方針で除外）
- 🟥 **家電・電気製品**（PSE）/ **無線機器**（技適）— C案で触れやすいので特に注意
- 🟥 **ブランド品・キャラクター商品**（商標・真贋調査リスク）
- 🟥 **フリマ・個人からの仕入れ品の新品出品**（メルカリ2025/10規約＋Amazon規約でNG。01・02）
- 🟥 **海外輸入品**（中国・韓国。知財/PSE/薬機/関税。初手スコープ外）

## 4. 初手の具体アクション（今日〜数日）

### Phase 0: 1周目=A案（今日〜3日）— お金を使わず完走する

1. **不用品の棚卸し（30分）**: 自宅から「状態が良く・型番が明確・Amazonに既存ページがありそう」な品を**3〜5点**集める（本・ゲーム・DVD・未使用小物）。
2. **相場チェック（各5分）**: Amazonアプリで商品名/バーコード検索 → 既存ページの中古/新品価格を見る。「**この値段なら手放してOK**」を即決できる品を優先。
3. **最初の1〜2点を出品（小口プラン）**:
   - 既存ページの「**出品する（コンディションを選んで相乗り）**」から出品。
   - **発送方法は最初は「自己発送（出品者出荷）」を推奨**。FBA（Amazon倉庫に送る）は工程が増えるので、まず最小工程で1周する。FBAは2周目(B案)で体験すればよい（要確認＝社長がFBA手数料体験も初回でやりたいなら初回FBAに変更可）。
   - 価格は相場の中央〜やや安めに設定（売れる確度を上げる＝完走優先）。
4. **売れたら**: 梱包→発送→購入者評価→**入金確認**まで見届ける。**ここで1周完走**。学びをメモ（後のStep7振り返りの素材）。

### Phase 1: 2周目=B案（A案完走後、数日〜2週間）— 10万円の出番

5. **NETSEA に無料会員登録**（買い手として）。日用品雑貨カテゴリを眺める。
6. **最初の本命を1〜2 SKU選ぶ**（10万円配分は下記）。Amazonで同等品の販売価格を確認し、**仕入値＋送料＋Amazon手数料 < 販売価格** になる品を選ぶ（簡易損益）。経理ハジメの損益シミュレーション（T-20260521-002）と突合すると精度が上がる。
7. **小ロット仕入れ→出品→販売→入金**で本番1周。請求書は必ず保管（真贋調査対策・03 B-5）。

### 10万円の配分設計（論点3への回答）

- **推奨: 本命1〜2 SKU に 3〜5万円、残りは予備**。1万円×多数SKUの分散は「リサーチ工数 × 初心者」で破綻しやすい。**最初は集中で1サイクルの損益を綺麗に観測**する方が学びが濃い。
- 1点あたりの賭け金が小さい**低単価品（数百〜千円台）**を選べば、5万円でも複数個×複数SKUの練習ができる。
- ※FBA手数料・回転率込みの精緻な損益は経理ハジメに別途依頼可（要すり合わせ）。

## 5. 撤退 / 見直し条件 と「成功の定義」

体験1周なので、撤退条件は「損失額」ではなく**「学べたか」**で定義します。

### 成功の定義（これが達成できたら1周は成功）

- ✅ **A案**: 出品→販売→**入金まで自分の手で1周**し、各工程で「何が起きるか」を体感した。
- ✅ **B案**: 「仕入値＋送料＋手数料 vs 販売価格」の**損益を自分で計算**し、仕入れ→販売→入金を1周した。
- ✅ 規制・コンディション・真贋（請求書保管）の**実務上の注意点を体で理解**した。

> 利益が出れば理想だが、**赤字でも上記が達成できれば「学習＝成功」**。T-004の目的（学習主目的・利益副次）に忠実。

### 見直し / 撤退条件（KPI×期限）

| 条件 | 判定 | アクション |
|---|---|---|
| A案で**2週間**経っても1点も出品できない | 行動が止まっている | 出品手順でつまずいた箇所を特定しカズヨが手順支援。商品選定をさらに易しい品（本1冊）に下げる |
| A案で出品したが**3週間**売れない | 価格設定の問題 | 相場の最安付近まで値下げ（完走優先。利益度外視で「売れる→入金」を体験する） |
| B案で**良い仕入れ候補が10日探しても見つからない** | リサーチ難度が高すぎ | SKUを最も低単価・高回転の日用品に限定。または1周目Aの学びで満足ならStep完了として振り返りへ |
| B案の仕入れで**損益計算が合う商品が無い** | 卸の利益が薄い市場 | 「薄利の現実を学んだ」事実を振り返りに記録し、C案（電脳）または次フェーズへ論点を送る |

### 北極星 / 先行 / 行動 指標（3階層）

- **北極星（最終目標）**: 出品→販売→入金を**1周完走し、学びを言語化**できた。
- **先行指標**: A案で初出品が完了 / B案で初仕入れが完了。
- **行動指標**: 不用品の棚卸し点数、相場チェック数、NETSEAで損益が合う候補の発見数。

### 法務エスカレーションの線引き（論点5への回答）

- **A案・B案（日用品雑貨中心）なら法務エスカレ不要レベル**（04 論点5、サトル線引きと整合）。
- **C案で家電(PSE)・玩具・ブランド品に踏み込む場合のみ、法務ハルオへ事前レビューチケットを起票**。今回の推奨（A→B日用品）はこのラインを踏まないので、まずは法務発注不要で進められる。
