## このガイドのゴール（最初に読む1画面）

**ゴール: 社長がERESAを開いて、このガイド通りに手を動かせば「価格差があって、かつ売れる商品」を自分で見分けて『仕入れる/見送る』を判断できるようになること。**

副業初心者が最初にやりがちな失敗は、**「Amazonで高く売れてる！仕入値より安い！だから仕入れる」** です。これは**半分しか見ていません**。価格差があっても**売れなければ在庫の山**になり、現金が在庫に化けたまま戻ってきません。

だから、このガイドは最初から **「価格差」だけでなく「売れ行き・競合・価格の安定」も同時に見る**型を教えます。具体的には次の **4つの目** です。

| 見る目 | 何を確認するか | これを見ないと起きる事故 |
|---|---|---|
| ① 利益（額/率） | 仕入総コスト vs 販売価格。手数料を全部引いて残るか | 手数料を忘れて「儲かるはず」が赤字 |
| ② 回転（売れ行き） | 月に何個売れているか／ランキングが動いているか | 価格差はあるが売れず、在庫の山 |
| ③ 競合（出品者数） | 同じ商品を何人が売っているか／Amazon本体やメーカーがいるか | 値下げ合戦に巻き込まれ利益消滅 |
| ④ 価格推移の安定 | 過去の価格が乱高下していないか | 仕入れた直後に相場が暴落 |

> ひとことで: **「安く買えて高く売れる」だけでは不十分。「安く買えて・高く売れて・ちゃんと売れて・競合が荒れていない」の4つが揃って初めて『仕入れる』。** これがこのガイドの背骨です。

## 1. そもそも「価格差リサーチ」とは

「価格差リサーチ」とは、**仕入れ先での値段（仕入値）とAmazonでの販売価格の差（＝粗利の元）を確認し、そこから手数料を引いても利益が残るか、かつその商品がちゃんと売れるかを見極める作業**です。

初心者がまず腹落ちさせるべきは次の2点です。

- **価格差 ≠ 利益。** 「Amazonで2,000円、仕入値1,000円、差1,000円ある！」と思っても、販売手数料・FBA手数料・送料を引くと利益は数百円、悪くすると赤字になります（§4で実例計算）。
- **利益が出ても、売れなければ意味がない。** 利益率30%の商品でも、月に1個しか売れないなら現金が3ヶ月戻ってきません。**「回転（売れ行き）」は利益率と同じくらい重要**です。

したがって価格差リサーチの本質は、**「価格差・利益・回転・競合・安定」をツールで一度に見て、賭けて良い商品か判断する作業**です。闇雲な仕入れを避けたい社長の希望に、この型がそのまま答えになります。

## 2. 使うツールと役割

### 2.1 ERESA PRO（主軸）— 1画面で4つの目が揃う

ERESAは **Amazon SPN（公認）リサーチ・分析ツール**で、ASIN/JAN/商品名で検索すると、その商品について以下が見られます（出典: knowledge_eresa_research_report.md）。

| 見たいもの（§0の4つの目） | ERESAで見える機能 |
|---|---|
| ① 利益 | **損益分岐点の自動計算**（販売手数料・FBA手数料を見込んで「いくらで仕入れれば黒字か」を出す） |
| ② 回転 | **ランキング推移グラフ・ランキング降下回数**（降下＝1個売れたサイン）、**売上個数予測**（PRO限定） |

## 3. 仕入れ可否チェックリスト（初心者の練習用・目安つき）

下記は**「まずこの基準で練習する」ための初心者向けの一般的な目安**です。断定的な正解ではなく、**慣れてきたら自分のカテゴリに合わせて調整する出発点**として使ってください。**1つでも🟥に当たれば原則『見送る』**。

| # | チェック項目 | 練習用の目安 | どこで見る | 判定 |
|---|---|---|---|---|
| 1 | **利益額** | 1個あたり **利益 ≥ 300〜500円** 残るか | §4の計算 / ERESA損益計算 | 下回る→🟥 |
| 2 | **利益率** | **利益率 ≥ 15%**（学習段階は10%超でも可、本番は20%目標） | 同上 | 下回る→🟨 |
| 3 | **回転（ランキング）** | カテゴリ内ランキングが **上位5〜10%以内**（目安: 主要カテゴリで概ね **3万位以内**）。【要確認: カテゴリにより母数が違うので試用時にランキング降下の頻度も併せて見る】 | ERESAランキング推移・降下回数 | 入らない→🟨〜🟥 |
| 4 | **売れ行きの実数** | Keepaグラフのランキング線が**月に何度もギザギザ下降**している（＝売れているサイン）。**月10個以上売れていそう**が目安 | ERESA内Keepaグラフ / 売上個数予測(PRO) | 動かない→🟥 |
| 5 | **競合（出品者数）** | 新品出品者が **2〜8人** 程度。**1人だけ(独占)も多すぎ(10人超)も避ける** | ERESA出品者数 | 範囲外→🟨 |
| 6 | **Amazon本体・メーカー** | 出品者に **Amazon.co.jp本体やメーカー公式がいない**こと | ERESA出品者欄 / カート取得率(PRO) | いる→🟥 |
| 7 | **価格推移の安定** | 過去90〜180日の価格が**乱高下していない**（直近で急落していない） | ERESA内Keepa価格グラフ | 乱高下→🟥 |
| 8 | **規制カテゴリでない** | 日用品雑貨・文具など規制低カテゴリ。**家電(PSE)/サプリ/化粧品/ブランド品/食品/酒は避ける** | restricted-categories（§8地雷集） | 該当→🟥 |
| 9 | **真贋・出所** | Bは請求書が出る正規卸か。Cは領収書を保管できるか | 仕入れ先の条件 | 不明→🟨 |

> 補足（用語）:
> - **カート取得率（PRO限定）**: その商品の「カートに入れる」ボタンを誰がどれだけ獲得しているか。特定セラーが80%以上独占している商品は、自分が出しても売れにくいので避ける（出典: ERESAレポート稼ぎテク5）。
> - **ランキング降下回数**: ランキングは商品が1個売れると一時的に上位へ「降下（=数字が小さくなる方向に動く）」します。この回数が多い＝よく売れている、と読みます。

## 4. 損益計算の型（手数料を全部引く）

### 4.1 基本の式

```
1個あたり利益 = 販売価格
              −（仕入値 + 仕入送料/個）
              − 販売手数料（販売価格 × カテゴリ料率）
              − FBA配送代行料（FBAを使う場合のみ・1個あたり定額）
              − FBA入庫送料/個・在庫保管料/個（FBAの場合・少額）

利益率 = 1個あたり利益 ÷ 販売価格
```

- **自己発送（出品者出荷）の場合:** FBA配送代行料・在庫保管料は不要。代わりに**自分が送る配送料・梱包資材費**がかかる。
- **販売手数料のカテゴリ料率（2026年5月時点・出典: accounting-simulation.md）:** ペット用品 **8%** / ヘルス&ビューティー **10%** / ホーム&キッチン **15%** / 文具・ホビー等は概ね**8〜15%**。【要確認: 料率は変わるため、ERESAの損益計算か公式FBA料金シミュレーターで都度確認】
- **FBA配送代行料の目安（同出典・推定）:** 小型288円 / 標準サイズ20=413円 / 標準サイズ40=455円 / 大型は520〜603円。

### 4.2 具体例で1件計算してみる（ホーム&キッチン小物・FBA）

ステンレスタンブラーを想定（accounting-simulationの代表商品③・中央シナリオの数字を使用）。

| 項目 | 値 |
|---|---|
| 販売価格（Amazon） | 2,780円 |
| 仕入値 | 1,400円 |
| 仕入送料（1個あたり按分） | 約130円 |
| 販売手数料（15%） | 417円 |
| FBA配送代行料（標準40） | 455円 |
| 在庫保管料（1ヶ月） | 16円 |
| **1個あたり利益** | 2,780 −1,400 −130 −417 −455 −16 = **約362円** |
| **利益率** | 362 ÷ 2,780 = **約13.0%** |

→ チェックリストでは「利益額 ≥300円 ◯」「利益率 ≥15% △（学習段階なら可）」。**回転（35日でやや遅い）と競合次第で『仕入れる/見送る』を判断**、という読み方になります。これが「価格差だけでは決められない」の実例です。

### 4.3 ERESAの損益計算機能の使い方（型）

1. ERESAで対象商品をASIN/JANで検索。
2. **損益分岐点計算欄に「想定仕入値」を入力**すると、手数料込みで利益・利益率が自動算出される（無料版でも可）。
3. その数字を**§4.1の手計算と突き合わせ**て、ズレがないか確認する（最初の数件は必ず手計算も並走→ツールを信頼できるか自分で検証）。
4. 【要確認: 入力欄の位置・FBA/自己発送の切替・送料を含めるかの扱いは、試用開始後に画面で確認】

> 初心者のコツ: **最初の5件は必ず手計算とツールの両方で出し、答えが合うことを確認**してください。これで「ツールの数字を信じてよい」と腹落ちし、以降はツール任せで高速化できます。

## 5. B（国内卸）でのリサーチ手順

**Bの起点 = 卸サイトの仕入値**。卸で「この値段で買える」を見つけ、ERESAで「Amazonで売れて利益が出るか」を逆算する流れです。

1. **NETSEA等に無料会員登録**し、規制低カテゴリ（生活日用品・雑貨・文具・収納）を眺める。
2. 気になる商品の **仕入値・最小ロット・JANコード（あれば）** をメモ。
3. **ERESAでJAN or 商品名検索** → Amazonの販売価格・ランキング・出品者数を確認。
   - JANが無い卸商品は商品名・型番で検索。同一商品が特定できない場合は判断保留（無理に相乗りしない）。
4. **§3チェックリストを上から順に判定** → §4で1個あたり利益を計算。
5. **ロット全部を消化できるか**を回転（チェック#3・#4）から逆算。例: 最小ロット20個で月10個しか売れない商品は、2ヶ月在庫になる。学習段階は**最小ロットが小さい品**を優先。
6. すべて◯なら『**仕入れる候補**』としてメモ。1つでも🟥なら『見送る』。
7. 仕入れたら**請求書を必ず保管**（真贋調査対策）。

> Bの利点: 新品・正規ルートで請求書が出るため出所が明確で事故りにくい（出典: step2-procurement-decision §2 B案）。初心者の本番デビューに向く。

## 6. C（電脳せどり）でのリサーチ手順

**Cの起点 = 量販店ネットの「ポイント還元込み実質価格」**。表示価格そのものではなく、**ポイント分を引いた実質仕入値**で損益を見るのがCの肝です。

1. ヨドバシ・ビックカメラ・楽天等のネット店舗で、規制低カテゴリの商品を見る。
2. **実質仕入値を計算**: `表示価格 −（表示価格 × ポイント還元率）`。
   - 例: 表示2,000円・ポイント13%還元 → 実質 2,000 − 260 = **1,740円**。
   - 【注意】ポイントは現金ではなく次回買い物で使える点。**利益計算上はポイントを値引きとみなすが、実際の出金は2,000円**である点を理解しておく（資金繰り感覚）。
3. **ERESAでその商品をJAN/型番検索** → §3チェックリスト＋§4損益計算。**実質仕入値を仕入値として入力**する。
4. **規制チェックを特に厳重に**: 量販店ネットは家電(PSE)・無線(技適)・玩具など**規制カテゴリに触れやすい**。日用品・文具に絞る（§8地雷）。
5. **新品出品の可否に注意**: 量販店仕入れの新品は「メーカー同等保証」が無いとAmazon新品出品で問題になる場合がある。**領収書を必ず保管**（出典: step2-procurement-decision §2 C案）。
6. すべて◯なら『仕入れる候補』、1つでも🟥なら『見送る』。

> Cの注意: 学びは深いが、リサーチ＋規制判断＋ポイント計算を同時にこなすため難度が高い。**Bで型を体得してからCに進む**のが安全（出典: step2-procurement-decision 推奨）。

## 7. 練習メニュー（手を動かして慣れる順番）

ERESA 7日無料お試しの初日から、以下の順で**「判断する練習」**を積みます。利益を出すのが目的ではなく、**判断の型を体に入れるのが目的**です。

### ステップA: まず10商品を判定してみる（1〜2日目）

1. B（NETSEA等）またはC（ヨドバシ等）から**気になる商品を10個**ピックアップ。
2. 各商品をERESAで検索し、**§3チェックリストで「仕入れる/見送る」を判定**。
3. **理由を1行ずつメモ**（例:「見送り＝利益率8%・出品者12人で価格競争」「仕入れ候補＝利益率18%・月20個・出品者4人」）。
4. 10個中、何個が「仕入れる候補」に残るか見る。**初心者は10個中1〜2個残れば上出来**。「ほとんど見送りになる」のが正常で、それがリサーチの価値です。

### ステップB: 候補を1〜2商品に絞る（3〜4日目）

5. 残った候補を**§4で精緻に損益計算**し、回転（売れ行き）も見比べる。
6. **最も自信が持てる1〜2商品**に絞る。「利益が薄くても回転が速い」か「回転は遅いが利益率が高い」かを意識して選ぶ。

### ステップC: 判断を記録して振り返る（継続）

7. 仕入れ判定の理由メモを残し、**実際に売れたら「予測と実績のズレ」を記録**（回転日数・実利益）。
8. このズレが次回のリサーチ精度を上げる最大の教材になります。

> 慣れの段階: **1日目=ツールに触れる → 2〜3日目=10個判定が30分で回せる → 1週間後=チェックリストを見なくても4つの目で見られる**、が習熟の目安です。

## 8. 地雷集（初心者がはまりやすい罠）

| 地雷 | どういう罠か | 回避法 |
|---|---|---|
| **高利益に見えて売れない罠** | 利益率40%でも月1個しか売れない。現金が在庫に化けて戻らない | 利益率と**同時に回転（§3 #3#4）**を必ず見る。「売れてから利益を喜ぶ」 |
| **価格競争に巻き込まれる罠** | 出品者が10人超／カートを1セラーが独占。値下げ合戦で利益消滅 | 出品者2〜8人・カート分散の商品のみ（§3 #5#6） |
| **Amazon本体・メーカー出品の罠** | Amazon本体やメーカー公式が同じ商品を出している。価格でも在庫でも勝てない | 出品者にAmazon本体/メーカーがいたら見送り（§3 #6） |
| **規制品の罠** | 家電(PSE)・無線(技適)・サプリ・化粧品・食品・酒・ブランド品・中古は許可や届出が必要、または出品不可 | restricted-categoriesの「非推奨」は触らない。日用品雑貨・文具に限定（§8末尾） |
| **ニセの価格差の罠** | 「セット品 vs 単品」「並行輸入 vs 正規」「型落ち vs 現行」を見間違え、別物を比較している | JAN/ASINで**同一商品**であることを必ず確認。中身・容量・型番が一致するか |
| **手数料忘れの罠** | 価格差だけ見て手数料を引き忘れ、黒字のつもりが赤字 | §4で**手数料を全部引いた利益**で判断。ERESA損益計算を必ず通す |
| **過去の高値を見て喜ぶ罠** | Keepaグラフで一時的な高騰時の価格を「相場」と勘違い | 直近90〜180日の**安定した価格帯**で利益が出るかを見る（§3 #7） |
| **ポイントを現金と錯覚する罠（C）** | ポイント還元を引いた実質価格で利益を計算したが、出金は満額。資金繰りが苦しくなる | 実質価格で損益判断しつつ、**現金は満額出る**ことを資金管理上は別で意識 |

### 触ってはいけないカテゴリ（出典: restricted-categories.csv）

🟥 **非推奨（許可・届出・出品不可）:** 化粧品・医薬部外品・医薬品・医療機器・サプリ/健康食品・食品/飲料・酒類・タバコ・ブランド時計/ジュエリー・**家電/電気製品(PSE)**・**無線機器(技適)**・銃刀類・危険物(スプレー/リチウム電池単体)・ブランド品・農薬・コンタクト/度入りメガネ。

🟨 **慎重（条件付き）:** 玩具・新品DVD/CD・中古品全般（古物商必要）・繊維製品(品質表示義務)・自動車/バイク用品。

🟩 **推奨（規制最小）:** **国内メーカー直販・正規問屋経由の日用品（文房具・清掃用品・収納用品等）**、中古本（＋古物商）。**まずはここだけで練習する。**
