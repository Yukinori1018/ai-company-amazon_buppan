初心者が最初にやりがちな失敗は「Amazonで高く売れてる！仕入値より安い！だから仕入れる」。これは半分しか見ていません。価格差があっても売れなければ在庫の山になり、現金が在庫に化けたまま戻りません。だから最初から次の4つの目を同時に見ます。
見る目何を確認するか見ないと起きる事故
① 利益（額/率）仕入総コスト vs 販売価格。手数料を全部引いて残るか手数料を忘れて「儲かるはず」が赤字
② 回転（売れ行き）月に何個売れているか／ランキングが動いているか価格差はあるが売れず、在庫の山
③ 競合（出品者数）同じ商品を何人が売っているか／Amazon本体・メーカーがいるか値下げ合戦に巻き込まれ利益消滅
④ 価格推移の安定過去の価格が乱高下していないか仕入れた直後に相場が暴落
ひとことで: 「安く買えて高く売れる」だけでは不十分。「安く買えて・高く売れて・ちゃんと売れて・競合が荒れていない」の4つが揃って初めて『仕入れる』。

1. そもそも「価格差リサーチ」とは

仕入れ先での値段（仕入値）とAmazonの販売価格の差（＝粗利の元）を確認し、そこから手数料を引いても利益が残るか、かつその商品がちゃんと売れるかを見極める作業です。腹落ちさせるべきは2点。

  • 価格差 ≠ 利益。「Amazon2,000円・仕入値1,000円・差1,000円！」でも、販売手数料・FBA手数料・送料を引くと利益は数百円、悪くすると赤字（§4で実例）。
  • 利益が出ても、売れなければ意味がない。利益率30%でも月1個なら現金が3ヶ月戻らない。「回転」は利益率と同じくらい重要。

本質は「価格差・利益・回転・競合・安定」をツールで一度に見て、賭けて良い商品か判断する作業。闇雲な仕入れを避けたいという希望にそのまま答える型です。

2. 使うツールと役割

2.1 ERESA PRO（主軸）— 1画面で4つの目が揃う

ERESAはAmazon SPN（公認）リサーチ・分析ツール。ASIN/JAN/商品名で検索すると以下が見られます（出典: knowledge_eresa_research_report.md）。

4つの目ERESAで見える機能
① 利益損益分岐点の自動計算（販売手数料・FBA手数料を見込み「いくらで仕入れれば黒字か」を出す）
② 回転ランキング推移グラフ・ランキング降下回数（降下＝1個売れたサイン）、売上個数予測（PRO限定）
③ 競合コンディション別最安値・出品者数、Amazon本体の有無・カート取得率（PRO限定）
④ 安定Keepaの価格推移グラフ（30/90/180/365日）を内包

「Keepa内包」の意味: 価格推移を本格的に見るには通常Keepaを月約€19（約3,000円）で契約します。ERESA PROはそのKeepaグラフをERESA内で見られるので別契約が不要。これが主軸にする最大の理由です。

4. 損益計算の型（手数料を全部引く）

4.1 基本の式

1個あたり利益 = 販売価格
              −（仕入値 + 仕入送料/個）
              − 販売手数料（販売価格 × カテゴリ料率）
              − FBA配送代行料（FBAを使う場合のみ・1個あたり定額）
              − FBA入庫送料/個・在庫保管料/個（FBAの場合・少額）

利益率 = 1個あたり利益 ÷ 販売価格
  • 自己発送の場合: FBA配送代行料・保管料は不要。代わりに自分が送る配送料・梱包資材費がかかる。
  • 販売手数料率（2026/5・出典: accounting-simulation）: ペット8% / ヘルス&ビューティー10% / ホーム&キッチン15% / 文具・ホビー等は概ね8〜15%。【要確認: ERESA損益計算か公式FBAシミュレーターで都度確認】
  • FBA配送代行料の目安: 小型288円 / 標準20=413円 / 標準40=455円 / 大型520〜603円。

4.2 具体例で1件計算（ホーム&キッチン小物・FBA）

項目値
販売価格（Amazon）2,780円
仕入値1,400円
仕入送料（1個按分）約130円
販売手数料（15%）417円
FBA配送代行料（標準40）455円
在庫保管料（1ヶ月）16円
1個あたり利益2,780 −1,400 −130 −417 −455 −16 = 約362円
利益率362 ÷ 2,780 = 約13.0%

→ 「利益額 ≥300円 ◯」「利益率 ≥15% △（学習段階なら可）」。回転（35日でやや遅い）と競合次第で判断、という読み方。「価格差だけでは決められない」の実例です。

4.3 ERESAの損益計算機能の使い方（型）

  1. ERESAで対象商品をASIN/JANで検索。
  2. 損益分岐点計算欄に想定仕入値を入力すると手数料込みで利益・利益率が自動算出（無料版可）。
  3. その数字を§4.1の手計算と突き合わせ、ズレを確認（最初の数件は手計算も並走）。
  4. 【要確認: 入力欄の位置・FBA/自己発送の切替・送料の扱いは試用開始後に画面で確認】
初心者のコツ: 最初の5件は手計算とツールの両方で出し、答えが合うことを確認。これで「ツールの数字を信じてよい」と腹落ちし、以降は高速化できます。

5. B（国内卸）でのリサーチ手順

起点 = 卸サイトの仕入値。卸で「この値段で買える」を見つけ、ERESAで「Amazonで売れて利益が出るか」を逆算。

  1. NETSEA等に無料会員登録し、規制低カテゴリ（生活日用品・雑貨・文具・収納）を眺める。
  2. 商品の仕入値・最小ロット・JANをメモ。
  3. ERESAでJAN/商品名検索 → 販売価格・ランキング・出品者数を確認。JANが無ければ型番検索。同一商品が特定できなければ判断保留。
  4. §3チェックリストを上から判定 → §4で1個利益を計算。
  5. ロット全部を消化できるかを回転から逆算（例: ロット20個で月10個なら2ヶ月在庫）。学習段階は最小ロットが小さい品優先。
  6. すべて◯なら『仕入れる候補』、1つでも🟥なら『見送る』。
  7. 仕入れたら請求書を必ず保管（真贋調査対策）。
Bの利点: 新品・正規ルートで請求書が出て出所が明確、事故りにくい（出典: step2-procurement-decision §2 B案）。本番デビューに向く。

6. C（電脳せどり）でのリサーチ手順

起点 = 量販店ネットの「ポイント還元込み実質価格」。表示価格ではなくポイント分を引いた実質仕入値で損益を見るのが肝。

  1. ヨドバシ・ビック・楽天等で規制低カテゴリの商品を見る。
  2. 実質仕入値 = 表示価格 −（表示価格 × ポイント還元率）。例: 2,000円・13%還元 → 実質1,740円。【注意】ポイントは現金ではなく次回使える点。出金は満額2,000円。
  3. ERESAでJAN/型番検索 → §3＋§4。実質仕入値を仕入値として入力。
  4. 規制チェックを特に厳重に: 量販店ネットは家電(PSE)・無線(技適)・玩具に触れやすい。日用品・文具に絞る。
  5. 新品出品の可否に注意: メーカー同等保証が無いと新品出品で問題になる場合あり。領収書を必ず保管。
  6. すべて◯なら『仕入れる候補』、1つでも🟥なら『見送る』。
Cの注意: 学びは深いが難度が高い。Bで型を体得してからCへ進むのが安全（出典: step2-procurement-decision 推奨）。

7. 練習メニュー（手を動かして慣れる順番）

7日無料お試しの初日から、「判断する練習」を積みます。利益を出すのが目的ではなく、判断の型を体に入れるのが目的。

ステップA: まず10商品を判定（1〜2日目）

  1. B/Cから気になる商品を10個ピックアップ。
  2. 各商品をERESAで検索し§3チェックリストで仕入れる/見送るを判定。
  3. 理由を1行ずつメモ（例:「見送り＝利益率8%・出品者12人」「候補＝利益率18%・月20個・出品者4人」）。
  4. 10個中何個残るか見る。初心者は1〜2個残れば上出来。ほとんど見送りが正常で、それがリサーチの価値。

ステップB: 候補を1〜2商品に絞る（3〜4日目）

  1. 残った候補を§4で精緻に損益計算し回転も見比べる。
  2. 最も自信が持てる1〜2商品に絞る。「薄利だが速回転」か「低回転だが高利益率」かを意識。

ステップC: 判断を記録して振り返る（継続）

  1. 判定理由を残し、売れたら予測と実績のズレ（回転日数・実利益）を記録。
  2. このズレが次回のリサーチ精度を上げる最大の教材。
習熟の目安: 1日目=ツールに触れる → 2〜3日目=10個判定が30分で回せる → 1週間後=チェックリスト無しでも4つの目で見られる。

8. 地雷集（初心者がはまりやすい罠）

地雷どういう罠か回避法
高利益に見えて売れない利益率40%でも月1個。現金が在庫に化けて戻らない利益率と同時に回転を見る。「売れてから喜ぶ」
価格競争に巻き込まれる出品者10人超／1セラーがカート独占。値下げ合戦で利益消滅出品者2〜8人・カート分散のみ（§3 #5#6）
Amazon本体・メーカー出品本体/公式が同じ商品を出している。価格でも在庫でも勝てないいたら見送り（§3 #6）
規制品家電/無線/サプリ/化粧品/食品/酒/ブランド/中古は許可・届出要 or 出品不可「非推奨」は触らない。日用品雑貨・文具に限定
ニセの価格差「セット品vs単品」「並行輸入vs正規」「型落ちvs現行」を見間違え別物比較JAN/ASINで同一商品を必ず確認。中身・容量・型番一致
手数料忘れ価格差だけ見て手数料を引き忘れ、黒字のつもりが赤字§4で手数料を全部引いた利益で判断
過去の高値で喜ぶKeepaの一時高騰時を「相場」と勘違い直近90〜180日の安定価格帯で利益が出るか（§3 #7）
ポイントを現金と錯覚（C）実質価格で計算したが出金は満額。資金繰りが苦しくなる実質価格で損益判断しつつ現金は満額出ると別で意識
