電脳せどり PDCA 一周・実績サマリ

実施日 2026-07-03 ／ 担当 カズヨ(司令塔)＋サトル(調査)・タケシ(Plan/Act)・マサル(仮想Do)
対象商品 エポック社 シルバニアファミリー「赤い屋根の大きなお家」ハ-48（おもちゃ・大型FBA）
Doの扱い 実購入はせず「実物を仕入れ→FBAで売る体」で仮想実行（金銭が動く実決済は社長承認事項のため未実行）。数値は社内の利益計算エンジン＋実相場に接地。
結論：初回テスト5個は基準シナリオで＋3,096円の黒字。ただし利益率11.6%で全社目標20%に未達。 原因は利益率の低さより「値下げ耐性の薄さ」。リピートは条件付き可 —— 仕入値を下げるか需要期に絞れば勝てる商品。

差異主因＝①実売価下振れ ▲600円/個（相乗り）②回転不足 5→3個（季節）③想定外コスト＋200円/個。在庫2個=11,460円が未回収拘束。

A ｜ Act（次に効く改善）

タケシ：この一周から抽出した恒久ルール
  1. 仕入基準に「値下げ耐性」を追加。利益率18.3%でも分岐点まで約2,000円しかなく相乗り1回で利益消失。今後は実売想定を1割引いて判定し、それでも黒字の物だけ買う。
  2. 季節性を回転に織り込む。7月の玩具は鈍い→テストは平常期、本番仕込みは需要期(11〜12月)。
  3. テスト5個は正解。軽傷で学べる。次も「まず5個で再現性確認」を標準化。
  4. リピートは条件付き可。①仕入値4,800円以下で分岐点を下げる ②カート取得率と実売価を記録、のどちらか達成で増量。未達なら同条件リピート非推奨。

撤退・損切りライン（今回設定）

  • カート価格が 7,800円を継続割れ → 値下げ追随を停止（分岐点まで余裕350円）
  • 14日で0個→黄信号 / 21日で1個以下→赤信号
  • 30日で2個以上残り → FBAで寝かせず別チャネル(メルカリ等)で現金化

プレモーテム（失敗要因TOP3）

  • カート喪失→値下げ連鎖で分岐点割れ（「売れてるのに損」状態）
  • 大型玩具の返品・箱毀損で再出品原価が焦げる
  • 回転せずキャッシュ拘束＋長期保管手数料の入口

この一周で確立した“型”（次回そのまま流用可）

実相場リサーチ(サトル) → 利益計算エンジンで判定(原石/あやしい/はずれ) → 仮想Do3シナリオ(マサル) → エンジンで計画対実績を検算(カズヨ) → 基準見直し(タケシ)。 全数値が社内エンジン＋実相場に接地。次回は候補と仕入値を差し替えるだけで同じ精度で回せる。
