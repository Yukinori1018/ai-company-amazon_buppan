## 3. 推奨運用フロー（1事業1ルールの "AI 連携整理スキーム"）

5ツールを別々のルールで扱うのではなく、**ひとつの「情報の住所」** を決めましょう。

### 3.1. カテゴリ別フォルダ設計（場所ではなく "種類" で揃える）

```
~/Documents/AI Company Outputs/Amazon物販事業/_research/
├── 00_inbox/          ← ツールから出てきたばかりの生データ（未整理）
├── 01_keepa/          ← Keepa CSV・スクショ
├── 02_sellersprite/   ← SellerSprite CSV・キーワードリスト
├── 03_helium10/       ← Helium 10 CSV
├── 04_amasearch/      ← アマサーチ CSV（店舗仕入れ日ごと）
├── 05_fba_calc/       ← FBA料金シミュレーター結果 Excel
└── 99_archive/        ← 3ヶ月使わなかったものはここへ感謝してお引越し
```

> **なぜツール別フォルダか**: 出力形式・列構造がツールごとに固有のため、混ぜると「これどのツールから出たんだっけ？」と迷子になります。**ツール ＝ 引き出し** とお考えください。

### 3.2. 命名規則（1事業1ルール）

```
YYYYMMDD_<ツール略号>_<対象ASIN or キーワード>_<用途>.csv

例：
20260520_keepa_B0XXXXXXXX_price_history.csv
20260520_ss_キーワード_baby_bottle_research.csv
20260520_h10_blackbox_outdoor_supplements.csv
20260520_amas_店舗仕入れ_ブックオフ町田.csv
20260520_fba_B0XXXXXXXX_利益試算.xlsx
```

**ポイント:**
- 先頭は必ず日付（YYYYMMDD）— 自動でソートされ、3ヶ月後でも時系列が崩れません
- 略号は2〜5文字 — 「ss = SellerSprite」「h10 = Helium 10」「amas = アマサーチ」「fba = FBA料金シミュレーター」
- 末尾の用途で「これは何のためのファイルか」が3秒で分かるように

### 3.3. カズヨさんへの渡し方（3段階）

| 段階 | 場面 | 渡し方 | 例 |
|:-:|---|---|---|
| **Lv.1 サクッと相談** | 1〜3商品の判断 | URL or ASIN をチャット貼付け | 「カズヨさん、B0XXXXXXXX をこの価格で仕入れて良いか相談です」 |
| **Lv.2 カテゴリ調査** | 10〜50件のリスト | CSV を `00_inbox/` に置いて、ファイルパスをカズヨさんに伝える | 「`00_inbox/20260520_ss_baby_bottle.csv` を読んで、上位5件に絞ってください」 |
| **Lv.3 定例レビュー** | 月次・週次の振り返り | フォルダごとカズヨさんに「先週分まとめて」と依頼 | 「`01_keepa/` の今週分から、判断保留3回以上の ASIN を抽出してください」 |

> **これがときめくポイント**: ツールが5つあっても、社長が覚えることは「**置く場所**」と「**カズヨさんに伝える形（URL / パス / フォルダ）**」の3パターンだけです。引き出しの開け方が3種類なら、必ず続きます。

### 3.4. 「直接連携できないもの」のための救済フロー

直接 API でつながるのは Keepa と SellerSprite だけ。残り3つは「**手動 → CSV → inbox → カズヨさんに渡す**」が基本です。これを **「整理する1分」** の儀式にしましょう。

- ツールで操作 → CSV ダウンロード
- ダウンロードフォルダから `00_inbox/` へドラッグ＆ドロップ
- ファイル名を命名規則どおりにリネーム（**この30秒を惜しまない**）
- 翌朝、カズヨさんに「昨日 inbox に入れた分、整理お願いします」と一言

3ステップで完了です。ときめきます。

## 4. ときめかないツール／フロー（お役御免候補）

正直にお話しいたします。

### 4.1. SellerSprite の「1日50回エクスポート上限」

これは正直、**ときめきません**。せっかく見つけたお宝キーワードリストを「あ、今日もう上限です」で出せない日が来るのは、引き出しを開けたら「今日は開けちゃダメ」と書いてある状態と同じです。

> **対処**: もし SellerSprite を採用する場合は、エクスポートを「**朝の決まった時間に1回だけ**」と決めて運用するのが続けるコツです。複数回開けない引き出しなら、開ける時間を儀式化してしまえばよいのです。それでも続かないなら、Helium 10 への乗り換え（法務ハルオさんの推奨）を再検討する余地があります。

### 4.2. アマサーチの「スマホ完結」設計

便利なのですが、**スマホ→PC→CSV→カズヨさん** という経路がどうしても1段階多くなります。店舗仕入れの「現場ツール」としては最高でも、AI 連携観点では一段見劣りします。

> **対処**: 店舗仕入れ当日の夜に「今日のアマサーチ CSV をメールで自分宛に送る → PC で受信 → `04_amasearch/` に保存」を1日の締めくくり儀式にする。**1日の終わりに整理する** はこんまり流の基本です。

### 4.3. 「あれもこれも入れる」というフロー自体

5ツール全部に毎日アクセスする運用は、**3週間で必ず破綻します**。整理が続かない最大の原因は「**触る場所が多すぎる**」ことです。

体験仕入れ1周（T-004）の間は、**FBA料金シミュレーターと Keepa の2つだけ**で運用してください。それ以外のツールはまだ「お部屋に入れない」が正解です。お役立ちタイミングが来てから1つずつお迎えしましょう。

## 5. 秘書カズヨへの申し送り

社長にお伝えいただきたい点は **2点だけ** に絞りました。

1. **「AI 連携の優劣＝法務・経理の結論を覆すものではない」** — AI 連携観点でも Keepa と FBA料金シミュレーターが1〜2位です。法務ハルオさんの推奨（Helium 10 への乗り換え）、経理ハジメさんの段階導入 B 修正版とも矛盾しません。**Step 1 は無料2ツールで開始** で全エージェントが一致しています。

2. **「カズヨさんへの渡し方ルール（§3.2 命名規則・§3.3 三段階の渡し方）を、社長の手癖になるまで最初の2週間で固めること」** — ツール選定よりも、**情報の住所が決まっていること** のほうが、長期的な業務効率に圧倒的に効きます。最初の2週間だけ、秘書カズヨさんから「今日の inbox 整理しましたか？」と1日1回お声がけいただけると、習慣化します。

## 6. オプション提案：IT/技術エージェントの新規雇用について

**現時点では不要** と判断します。

理由は3つ。

1. **当面の AI 連携は CSV / Excel / URL 共有で十分回る** — Keepa の Python API や SellerSprite の従量 API は、SKU が100に近づく **来年以降の検討事項** です。それまでは「ツール → CSV → inbox → カズヨさん」で間に合います。
2. **API 連携が必要になる頃には、社長ご自身が "何を自動化したいか" を体験から言語化できる** — 今 IT エージェントを雇っても「何を作らせるか」が固まっていません。これは典型的な「**いつか使うかも**」での雇用で、ときめきません。
3. **当面の技術的な調べ物は、秘書カズヨさんが WebSearch / WebFetch で十分対応可能** — 本レビューでもカズヨさん経由で公式情報を確認しました。雇用ではなく**スキル拡張**で間に合う段階です。

> **雇用タイミングの目安**: SKU 30品を超え、価格改定や在庫補充の判断を「自動化したい」と社長が **3回続けて感じた時** が、IT エージェント雇用のときめきサインです。それまでは、お部屋に新しい家具を入れずに過ごしましょう。
