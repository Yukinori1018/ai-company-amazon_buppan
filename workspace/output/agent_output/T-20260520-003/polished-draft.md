## はじめに読む用語ミニ辞典（初心者向け補足）

> 本書に頻出する語を、ここで一度だけ説明します。本文内の専門用語には注釈を付けず、ここに戻れば分かる構成にしてあります。

| 用語 | 1行で言うと |
|---|---|
| **SKU**（エス・ケー・ユー） | 自分が扱う商品の最小管理単位。「色違い・サイズ違いも別 SKU」と数える |
| **ASIN**（エイシン） | Amazon が商品ごとに振る10桁の ID。`B0XXXXXXXX` の形 |
| **JAN コード** | 商品パッケージに印刷されたバーコード（13桁の数字） |
| **FBA** | Amazon の倉庫に商品を預け、保管・梱包・発送を代行してもらう仕組み |
| **FBM（自己配送）** | 自分で在庫を持ち、自分で発送する方式 |
| **大口出品 / 小口出品** | 大口＝月額4,900円・出品数無制限・広告や API が使える。小口＝月額0円・1件売れるごとに100円・機能制限あり |
| **カートボックス** | Amazon 商品ページ右側の「カートに入れる」ボタンの権利。同じ商品を複数セラーが出品している場合、ここを取れたセラーが大半の売上を取る |
| **相乗り出品** | 既に Amazon にある商品ページに、自分も出品者として相乗りする方式 |
| **セラーセントラル** | Amazon 出品者用の管理画面（ログイン制） |
| **電脳せどり / 店舗仕入れ** | 電脳＝ネット上で仕入れる方式。店舗＝実店舗を回って仕入れる方式 |

## 1. Keepa（キーパ）

### 30秒サマリ
- **役割**: Amazon 商品の「過去の価格と売上ランキング」をグラフで見るツール。Amazon 物販の **心電図** に相当します。
- **誰向け**: 仕入れ判断をする全員。電脳・店舗どちらでも必須。
- **入れる時期**: **今日**。無料プランで開始 → 必要になったら Pro へ。
- **月額**: 無料 / Pro €19（約 3,500円・為替で変動）

### できること（主機能）

| 機能 | 何ができるか | 初心者にとっての意味 |
|---|---|---|
| 価格履歴チャート | 過去数年の価格推移をグラフ表示 | 「いまの価格が高いのか安いのか」が一目で分かる |
| 売上ランク履歴 | ランクの「ギザギザ」がそのまま販売イベント | 「月に何個売れているか」を推測する根拠になる |
| Product Finder | カテゴリ・ランク・レビュー数で絞り込み | 売れ筋商品を機械的に発掘できる |
| 価格アラート | 指定価格まで下がったら通知 | 仕入れ機会を取りこぼさない |
| データ更新 | 15分ごとに更新 | タイムセールに反応できる |
| API | データを自社プログラムから取得 | 将来、自社ツールを作る時の足場 |

### 料金（2026年5月時点）
- **無料プラン**: チャート閲覧は無制限。価格アラートは 5,000 商品まで。**売上ランク履歴の一部は見られない**（ここが Pro との実質的な差）。
- **Pro プラン**: **€19/月**（約 3,200〜3,500 円）／年払い €189（17% OFF）
- **API プラン**: €49/月〜（自社開発する時のみ検討）

### 画面イメージ（スクショ準備時の構成メモ）
- **商品ページに自動でグラフが埋め込まれる**: Amazon の商品ページを開くと、Keepa のグラフが追加で表示される。色分けは緑＝Amazon 本体、青＝新品セラー、橙＝中古、紫＝カート価格、黒の点線＝売上ランク。
- **Product Finder 画面**: 左にフィルタ（カテゴリ・ランク帯・レビュー数・価格帯）、右に該当商品のリスト。
- **Deals 画面**: 直近で価格が下がった商品が一覧表示。仕入れ機会探しに使う。

### 代替ツール
- **DELTA tracer / ERESA** — 日本特化。無料で使えるが、過去履歴の長さで Keepa に劣る。
- **CamelCamelCamel** — 米国向け。日本市場では使えない。

### 推奨採用タイミング
- **今日、無料プランから開始**。Amazon 商品ページを見るたびにグラフを見る習慣を作るのが目的。
- 売上ランク履歴が「もっと見たい」と感じた瞬間に Pro に切り替え。早くて1〜2週間後。

### 注意点
- 売上ランクのギザギザは **推定**。複数同時購入などで実数とズレることがあります。「絶対値」ではなく「相対比較」で使ってください。
- 月額が €建てなので為替で変動します（年払いだとリスク低減）。
- Chrome 拡張は最新版を保たないと表示が崩れます。

## 2. SellerSprite（セラースプライト）

### 30秒サマリ
- **役割**: Amazon に特化したリサーチ SaaS。「**この商品を買った人は何で検索したか？**」を逆引きできるのが最大の武器。
- **誰向け**: カテゴリを絞って攻める段階／SKU を10品以上扱うセラー。
- **入れる時期**: **当面不要**。最初の1サイクルでは出番なし。
- **月額**: 約 9,800 円（30%OFFクーポン適用後）／クーポン無しだと約 13,998 円

### できること（主機能）

| 機能 | 何ができるか | 初心者にとっての意味 |
|---|---|---|
| キーワード逆引き | ASIN を入れると、その商品に流入している検索語と検索回数が出る | 自分の出品ページのタイトル・キーワードに転用できる |
| 商品リサーチ | カテゴリ・売上・レビュー数で有望商品を絞り込み | Keepa の Product Finder の上位互換に近い |
| キーワードマイニング | 検索回数・競合度・成約率の推定値付きキーワードリスト | 広告（スポンサープロダクト）出稿時の参考になる |
| 競合トラッキング | 競合 ASIN の価格・ランク・レビューを時系列で監視 | 真似すべき相手と差別化すべき相手が見える |
| 市場分析 | カテゴリ全体の市場規模・成長率を推定 | 参入すべきカテゴリの判断に使う |
| Chrome 拡張 | Amazon 商品ページに「月販推定 XX 個」を表示 | Keepa のランク推定の代わりに数字で見える |

### 料金（2026年5月時点）
- **スタンダード**: 月額 約 **13,998 円**（中国元レートで変動）
- **30%OFF クーポン**（コード `IQX622` 永年）適用後: 約 **9,800 円／月**
- **アドバンス／VIP**: チーム利用・API・大量リサーチ向け上位プラン
- 無料お試し枠あり（時期で内容変動）

### 画面イメージ（スクショ準備時の構成メモ）
- **キーワード逆引き画面**: ASIN 入力欄 → 結果テーブルにキーワード一覧／検索回数／成約率推定が並ぶ。
- **商品リサーチ画面**: 左にフィルタ、右に商品グリッド（売上推定・販売数・レビュー数）。
- **Chrome 拡張**: Amazon 商品ページの右上に「月販推定 XX 個 / 月売上 XX 万円」のバッジが重なる。

### 代替ツール
- **Helium 10** — 米国発・機能網羅性が最も高い。日本特化度は SellerSprite に劣る。月額 $39〜。
- **Jungle Scout** — 老舗。UI は最も綺麗。日本データの精度は SellerSprite と Helium 10 が優位。
- **AMZScout** — 安価（月額 $30 前後）、機能限定。

### 推奨採用タイミング
- **SKU が10品を超え、カテゴリを絞って攻略する段階**で導入。
- 初回1サイクル（T-004）には **不要**。今入れても、データを読み解く土台がないため宝の持ち腐れになります。

### 注意点（重要）
- **中国・深圳発の SaaS** です。事業データ・出品情報を入力するため、利用規約・データ取扱・送金経路は**法務確認を推奨**しています（社長判断: Yes/No 待ち）。
- 月販数・売上は **機械学習による推定値**。誤差がある前提で扱ってください。
- 30%OFF クーポンは公式・代理店経由で配布されており、コードの有効性は時期で変わります。

## 3. アマサーチ（Amasearch）

### 30秒サマリ
- **役割**: スマホでバーコードをかざすと、Amazon の価格・手数料・想定利益が即出るアプリ。
- **誰向け**: **店舗仕入れ**（ブックオフ・ゲオなど）をする人 **限定**。電脳せどり中心なら出番なし。
- **入れる時期**: 店舗仕入れを試すと決めた時。それ以前は不要。
- **月額**: 無料 / 有料 2,980 円

### できること（主機能）

| 機能 | 無料 | 有料 | 補足 |
|---|:-:|:-:|---|
| バーコード／JAN 高速スキャン | ◯ | ◯ | 1〜2秒で結果表示 |
| 利益計算（FBA／自己配送） | ◯ | ◯ | 仕入値を入れると利益額・利益率 |
| 出品制限の事前判定 | ◯ | ◯ | 「これは出せない」を店頭で即判定 |
| Keepa グラフ表示 | — | ◯ | 有料の主要価値 |
| カート価格表示 | — | ◯ | 相乗り判断に必要 |
| 危険物アラート | — | ◯ | リチウム電池等の不可商品検知 |
| カスタムショートカット | — | ◯ | 利益額しきい値などの自動振り分け |
| BOOKOFF / GEO / TSUTAYA 店内コード対応 | ◯ | ◯ | 店内独自バーコードも読める |

### 料金（2026年5月時点）
- **無料プラン**: 基本機能のみ。最初の店舗訪問なら無料でも回せます。
- **有料プラン**: **2,980 円／月**
- **前提**: Amazon 大口出品プラン（4,900円/月）との連携を前提とした機能あり。**社長は小口で開始予定**のため、利益計算など主要機能は問題ないが、在庫連動など一部は使えない可能性。店舗仕入れ着手時に再確認します。

### 画面イメージ（スクショ準備時の構成メモ）
- **スキャン画面**: カメラ起動 → バーコードに合わせる → 1〜2秒で結果カード表示（販売価格 / 手数料 / 利益 / 利益率）。
- **詳細画面**: 価格履歴グラフ（有料時）、ライバル数、出品制限の有無。
- **設定画面**: 利益額・利益率のしきい値をカスタム可。条件未満は赤、満たせば緑などのアラート表示。

### 代替ツール
- **セドリスト** — Web ベース・PC 寄り。店頭即時判断には不向き。
- **プライスター** — 価格改定と出品管理が主。リサーチは補助機能。
- **モノトレーサー** — Web リサーチ寄り。店舗仕入れには弱い。

### 推奨採用タイミング
- **店舗仕入れに踏み切ると決めた時のみ**。
- 電脳せどり中心なら Keepa＋ブラウザで完結します。アマサーチは入れない判断が正解です。

### 注意点
- 個人開発（Kenzu さん）。法人プロダクトと比べてサポート速度・継続性に若干の不安は残ります。
- Amazon 出品アカウントとの連携で API キーを渡します。パスワード相当の取り扱いを徹底してください。

## 4. FBA料金シミュレーター（Amazon 公式）

### 30秒サマリ
- **役割**: Amazon が公式提供する **無料** の利益計算ツール。仕入れ判断の最後の砦。
- **誰向け**: 出品する全員。例外なし。
- **入れる時期**: **今日**。アカウント開設前でも「ゲスト利用」で操作感を試せます。
- **月額**: **無料**

### できること（主機能）

| 機能 | 何ができるか | 初心者にとっての意味 |
|---|---|---|
| 商品検索 | ASIN／JAN／商品名で対象商品を呼び出し | 既存ページに相乗りする場合の試算が即できる |
| 新規商品定義 | サイズ・重量を手入力して試算 | まだ Amazon に無い商品でも事前に利益計算可能 |
| 一括見積もり | CSV で複数商品を同時計算 | セラーセントラル機能。多 SKU 時に使う |
| FBA／自己配送の比較 | 同一商品で両パターンの利益を並べる | 「FBA に預けるか自分で送るか」の判断材料 |
| 消費税込み計算 | セラーセントラルログイン時のみ正確 | ゲスト利用だと税抜き表示になる点に注意 |

### 料金
- **完全無料**。Amazon 出品アカウントが無くてもゲスト利用可。

### 画面イメージ（スクショ準備時の構成メモ）
- **左ペイン**: 商品検索 or 新規定義の入力フォーム
- **中央**: 商品サムネイル＋現在の販売価格
- **右ペイン**: 入力フィールド（販売価格・仕入原価・FBA 倉庫への送料）と、計算結果（手数料内訳・純利益・利益率）

### 代替ツール
- **自作スプレッドシート** — 一括処理は速い。ただし手数料テーブルの更新が手間。
- **プライスター／マカドの利益計算機能** — 既に出品済み SKU の利益管理用。

### 推奨採用タイミング
- **今すぐ・無料**。アカウント開設待ちの今この瞬間でも、興味のある商品を入れて感触をつかむのに最適です。

### 注意点
- 一度に1商品のみ。多 SKU を扱うようになったらスプレッドシート併用。
- 表示される配送料は概算。FBA 倉庫への入庫送料・段ボール費等は別途加算してください。
- カテゴリ・サイズ区分の判定は Amazon 側で随時変更されます。

# 秘書推奨（A/B/C＋推奨）

> 3案の違いは「**いつ・どこまで投資するか**」だけです。やる内容は同じ。

### A. 即フルセット導入

- **構成**: Keepa Pro ＋ SellerSprite ＋ アマサーチ ＋ FBA計算機
- **月額**: 約 **14,000 円**（クーポン適用後）
- **長所**: 初日から本気で攻められる
- **短所**: 体験がない状態で導入するため、機能を使いこなせず**月1.4万円を寝かせる**リスクが高い。SellerSprite の法務確認も未済。

### B. 段階導入【推奨】

- **Step 1（今日〜）**: FBA料金シミュレーター（無料）＋ Keepa 無料プラン → 体験仕入れ1周（T-004）を走る
- **Step 2（1周後）**: Keepa を Pro へ（約3,500円）。店舗仕入れに進むならアマサーチ追加（2,980円）
- **Step 3（カテゴリ攻略期）**: 法務確認の上で SellerSprite 導入（9,800円）
- **月額（最終形）**: 約 **14,000〜16,400 円**（段階的に積み上げ）
- **長所**: すべての投資が体験の裏付けを持つ。**無駄打ちゼロ**。社長の「座学より体験」方針と整合。
- **短所**: 立ち上がり1〜2週間は機能不足を感じる可能性。

### C. 無料のみで完走

- **構成**: FBA計算機 ＋ Keepa 無料プラン のみ
- **月額**: **0 円**
- **長所**: ノーリスク
- **短所**: 売上ランク履歴の一部が取れず、仕入れ精度が下がる。1サイクル目はこれでも回るが、2サイクル目で限界が来る。

#### 主な修正点（Before → After）

1. **【最上段】用語ミニ辞典を新設**
   - Before: 専門用語が本文中で初出時に説明される（例: カートボックス、ASIN、JAN、FBA／FBM、大口・小口など）。説明場所がバラついて、初心者は読みながら戻る必要があった。
