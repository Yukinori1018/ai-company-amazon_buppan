## 1. Keepa — Amazon Price Tracker

### 概要
Amazon 全11マーケットプレイス（日本含む）の **過去価格・売上ランキング・カートボックス保有率** を秒で確認できる、Amazon 物販の "心電図" のような必須ツール。Chrome 拡張＋Web＋モバイルアプリ。

### 用途
- 「この商品、本当に売れているのか？」を **売上ランクのギザギザ（＝販売されたタイミング）** で判定
- 「いまの価格は安いのか高いのか？」を過去◯ヶ月のチャートで判定
- 価格下落アラートの自動受信（仕入れ機会の検知）
- カートボックス（購入ボタン）の保有率＝相乗り出品でのライバル状況を確認

### できること（主機能）
| 機能 | 説明 |
|---|---|
| 価格履歴チャート | 過去数年分の価格推移をグラフ表示。新品・中古・カート価格を色分け |
| 売上ランク履歴 | ランクのギザギザ＝販売イベント。 "月に何個売れているか" の推定根拠 |
| 売れ筋商品ファインダー（Product Finder） | カテゴリ／ランク／レビュー数などで絞り込み、有望商品をリストアップ |
| カートボックス統計 | 誰がいつカートを取っていたか（Pro 限定） |
| 価格アラート | メール / ブラウザ通知 / Telegram / Facebook で価格下落を通知 |
| データ更新間隔 | 15分ごと（タイムセール検知が可能） |
| API | 自社実装でデータ取得（Pro 上位 or API 専用プラン） |

### 料金（2026年5月時点）
- **無料プラン**: チャート閲覧無制限、価格アラート 5,000 商品まで、ランク履歴は一部閲覧不可
- **Pro プラン**: **€19／月**（≒ 約 3,200〜3,500 円。為替依存）／年払い €189（17% OFF）
- **API プラン**: €49／月〜（自社実装する場合のみ）

### 画面構成（スクショ説明）
- **商品ページ拡張表示**: Amazon の商品ページに Keepa が自動でグラフを埋め込む（緑＝Amazon、青＝新品、橙＝中古、紫＝カート、黒の点線＝売上ランク）
- **Product Finder**: 左ペインでフィルタ（カテゴリ / ランク帯 / レビュー数 / 価格帯）、右ペインで該当商品リスト
- **Deals ページ**: 直近の価格下落商品が一覧で並ぶ。仕入れ機会探しに使う

### 代替ツール
- **DELTA tracer** / **ERESA** / **モノレート系後継** — 日本特化、無料で使えるが Keepa ほど履歴が長くない
- **CamelCamelCamel** — 米 Amazon 向け。日本では Keepa が事実上の標準

### 推奨採用タイミング
**仕入れ判断を始める時点で必須**。無料プランで開始 → 売上ランク履歴が必要になったら Pro へ。

### 注意点
- 売上ランクの "ギザギザ" は推定であり、必ずしも個数と一致しない（複数同時購入のケースなど）
- 為替変動で月額が変わる（€建て）
- Chrome 拡張は最新版を維持しないと表示が崩れることがある

## 2. SellerSprite（セラースプライト）— Amazon リサーチ専門 SaaS

### 概要
中国・深圳発の Amazon 専用リサーチ SaaS。**キーワード逆引き（ASIN → どの検索語で流入したか）** を強みとし、海外で広く使われている。日本含む9マーケットプレイスに対応。

### 用途
- "この商品を買った人は何で検索したか？" を可視化し、自社出品の **タイトル／キーワード SEO** に流用
- 競合 ASIN を入力 → 月間販売数推定／売上推定／レビュー推移を取得
- カテゴリ全体の需要マップ作成（ロングテール SKU 発掘）

### できること（主機能）
| 機能 | 説明 |
|---|---|
| キーワード逆引きリサーチ | 競合 ASIN → その商品が検索された全キーワードと月間検索回数 |
| 商品リサーチ | カテゴリ／売上／レビュー数などで有望商品を絞り込み |
| キーワードマイニング | 月間検索回数・競合度・コンバージョン推定値付きキーワードリスト |
| 競合トラッキング | 競合 ASIN の価格・ランク・レビュー数を時系列で監視 |
| 市場分析 | カテゴリ全体の市場規模・成長率を推定 |
| Chrome 拡張 | 商品ページに月販推定／売上推定をオーバーレイ表示 |

### 料金（2026年5月時点）
- **スタンダード**: 月額 **約 13,998 円**（中華系のため為替・元レートで変動）
- 30%OFF クーポン（コード `IQX622` 永年）適用後: **約 9,800 円／月**
- **アドバンス／VIP**: 用途別の上位プラン（チーム利用・API・大規模リサーチ向け）
- 無料お試し: ある程度の試用枠あり（プランや時期で変動）

### 画面構成（スクショ説明）
- **キーワード逆引き画面**: ASIN 入力欄 → 結果テーブルにキーワード一覧・検索回数・コンバージョン推定が並ぶ
- **商品リサーチ画面**: 左にフィルタ、右に商品グリッド（売上推定・販売数・レビュー数）
- **Chrome 拡張**: Amazon 商品ページの右上に "月販推定 XX 個 / 月売上 XX 万円" バッジを重ねる

### 代替ツール
- **Helium 10** — 米国発、機能網羅性が高いが日本特化度は SellerSprite より低い。月額 $39〜
- **Jungle Scout** — 老舗、UI が綺麗。日本データの精度は SellerSprite と Helium 10 が優位
- **AMZScout** — 価格が安め（月額 $30 前後）、機能は限定的

### 推奨採用タイミング
**カテゴリを絞って攻略するフェーズ／SKU を横展開して10品以上扱う段階**で導入。初回1サイクル（T-004）には不要。

### 注意点（重要）
- **中国発 SaaS のため、利用規約・データ取扱・送金経路は法務確認推奨**。秘書 → 法務に発注するか社長判断が必要（このチケットでは保留中）
- 推定値（月販数・売上）は機械学習ベース。誤差はある前提で使う
- 30%OFF クーポンは公式・代理店経由で配布されているが、コードの有効性は時期で変わる

## 3. アマサーチ（Amasearch）— スマホ店舗仕入れアプリ

### 概要
個人開発（Kenzu さん）の **モバイル特化** Amazon 仕入れリサーチアプリ。バーコードスキャン → 即時利益計算で、**店舗仕入れ（ブックオフ・ゲオなど）** の主力ツール。iOS／Android 両対応。

### 用途
- 店舗で商品のバーコードを読み取り、**Amazon の販売価格・FBA 手数料・想定利益** を瞬時に表示
- 出品制限カテゴリの警告（「これは出せない」を即判定）
- Keepa グラフをアプリ内で表示（有料プランのみ）

### できること（主機能）
| 機能 | 無料 | 有料 |
|---|:-::|:-:|
| JAN コード／バーコード高速スキャン | ✅ | ✅ |
| 利益計算（FBA／自己配送） | ✅ | ✅ |
| 出品制限の事前判定 | ✅ | ✅ |
| Keepa グラフ表示 | — | ✅ |
| カート価格表示 | — | ✅ |
| 危険物アラート | — | ✅ |
| カスタムショートカット | — | ✅ |
| BOOKOFF / GEO / TSUTAYA 店内コード対応 | ✅ | ✅ |

### 料金（2026年5月時点）
- **無料プラン**: あり（基本機能は使える）
- **有料プラン**: **2,980 円／月**
- 別途、Amazon 出品アカウントの大口プラン（**4,900 円／月**）が必要 ＊小口プランでも基本機能は使えるとの情報もあるが、API 連携前提の機能は大口前提
- 注: 社長は **小口** で開始予定 → アマサーチの一部機能（在庫連携など）は使えない可能性。店舗仕入れに踏み切る時に再確認

### 画面構成（スクショ説明）
- **メインスキャン画面**: カメラ起動 → バーコードに合わせる → 1〜2秒で結果カード（販売価格／手数料／利益／利益率）
- **詳細画面**: 価格履歴グラフ（有料時）、ライバル数、出品制限有無
- **設定**: アラート条件（利益額／利益率しきい値）をカスタム可能

### 代替ツール
- **セドリスト** — Web ベース、PC 寄り
- **プライスター** — 価格改定＋出品管理が主機能、リサーチは補助
- **モノトレーサー** — Web リサーチ寄り、店舗仕入れには弱い

### 推奨採用タイミング
**店舗仕入れ手法を選んだ時のみ**。電脳せどり中心なら不要（Keepa＋ブラウザで十分）。

### 注意点
- 個人開発のため、サポート対応のスピードや継続性は法人プロダクトより不安定
- Amazon 出品アカウント連携で API キーを渡すため、**取り扱いに注意**（パスワード代わりに保管）

## 4. Amazon FBA料金シミュレーター（公式）

### 概要
Amazon が **公式** で提供する **無料** の利益計算ツール。FBA を使った場合と自己配送（FBM）の場合の手数料・純利益を1商品単位で計算できる。セラーセントラルにログインすれば消費税込みで正確に試算可能。

### 用途
- 仕入れ判断の最後の砦：「この仕入れ値で本当に利益が出るか？」をクリックで確認
- FBA 利用時の保管料・配送料を含めた **手取り** を算出
- カテゴリ別の販売手数料（8%／15%等）を自動適用

### できること（主機能）
| 機能 | 説明 |
|---|---|
| 商品検索 | ASIN／JAN／商品名で対象商品を呼び出し |
| 商品を新規定義 | 既存 ASIN がない場合でも、サイズ・重量を入力して試算可能 |
| 一括見積もり | CSV アップロードで複数商品を同時計算（セラーセントラル機能） |
| FBA／自己配送の比較 | 同じ商品で両パターンの利益を並べて確認 |
| 消費税込み計算 | セラーセントラルログイン時のみ。ゲスト利用だと税抜き |

### 料金
- **完全無料**（Amazon 出品アカウント不要、ゲスト利用可）

### 画面構成（スクショ説明）
- **左ペイン**: 商品検索 or 新規定義の入力フォーム
- **中央**: 商品サムネイル＋現在の販売価格
- **右ペイン**: 入力フィールド（販売価格・仕入原価・FBA 倉庫への送料）と、計算結果（手数料内訳・純利益・利益率）

### 代替ツール
- **自作スプレッドシート** — 一括処理は速いが、手数料テーブルの更新が手間
- **プライスター／マカドの利益計算機能** — 出品済み SKU の利益管理用

### 推奨採用タイミング
**いますぐ／無料**。仕入れの第一歩。社長が出品アカウント開設待ち（T-004 Step 1）の間でも、**ゲスト利用** で操作感を確認可能。

### 注意点
- 一度に1商品のみ → 多数 SKU を扱うようになったらスプレッドシート併用
- 配送料は概算。実際の FBA 入庫送料・段ボール費等は別途加算が必要
- カテゴリ・サイズ区分の判定は Amazon 側で随時変更される

## 秘書推奨（A/B/C＋推奨）

### A. 即フルセット導入（Keepa＋SellerSprite＋アマサーチ＋FBA計算機）
- 月額: ≈ **14,000 円**（クーポン適用後）
- メリット: 1日目から本気で攻められる
- デメリット: 体験前なので "使いこなせない投資" になりやすい。SellerSprite の法務確認が未済

### B. 段階導入（推奨）★
- **Step 1（いま）**: FBA料金シミュレーター（無料）＋ Keepa 無料プラン → 体験仕入れ1周（T-004）
- **Step 2（1周後）**: Keepa Pro へ移行（≒3,500円）、店舗仕入れに進むならアマサーチ追加（2,980円）
- **Step 3（カテゴリ攻略期）**: SellerSprite を法務確認の上で導入（9,800円）
- 月額（最終形）: ≈ **14,000〜16,400 円** ＊段階的に積み上げ
- メリット: 投資が体験に裏付けられる、無駄打ちゼロ
- デメリット: 立ち上がりが遅く感じる可能性

### C. 公式・無料のみで完走
- 月額: **0 円**
- メリット: ノーリスク
- デメリット: 売上ランク履歴が取れず、仕入れ精度が大きく落ちる

**秘書推奨: B**。理由は「副業初心者・座学より体験を優先」という社長の方針と整合し、ツール費用を体験での気付きに紐付けられるため。
