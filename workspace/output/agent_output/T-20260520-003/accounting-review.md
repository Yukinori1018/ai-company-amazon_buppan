## 1. 結論（推奨シナリオ）

### 推奨: **シナリオ B（段階導入）／ ただし開始ラインを秘書案より一段引き締める**

**根拠（数字）:**
1. **シナリオA（即フル）の年間中央値 168,168円**は、利益率20%基準でブレークイーブン売上 **月70,070円／年84.1万円** が必要。SKU 0 個の現状で投下するのは期待値マイナス。
2. **シナリオB（段階導入）の年間中央値 約 95,500円**（フル展開期間を年7ヶ月と仮定）。同基準で BE **月39,792円**。**T-004 体験仕入れの初回 1〜3 周（=2〜3 ヶ月）で1 SKU 単月3〜4万円の粗利が出れば回収可能**。
3. **シナリオC（無料のみ）の年間中央値 0円**。コストはゼロだが、Keepa の売上ランク履歴が無料では一部閲覧不可 → 推定**仕入れ判断精度の劣化により機会損失が月3〜10万円相当**（後述§3.3）。
4. **5年累計コスト（機会費用込み・中央値）**: A=914千円、B=519千円、C=0円。差額 A−B＝**約395千円／5年**。この差額は B 採用時の保険として十分に正当化される。

**結論を一言で:** **B を採用し、ただし Keepa Pro は無料プランを最大限使い切る／SellerSprite は単月粗利が安定して10万円超えた月から導入、という二段絞り込みを推奨します。** 秘書案より1〜2ヶ月分の Pro 課金を後ろ倒しできます。

### 3.2 SKU 経済性での読み替え（KPI: SKU100で月商800万円 → SKU当り月商8万円）

- 1 SKU 月商8万円・利益率20% → **1 SKU 月粗利 1.6万円**
- 即ち、シナリオB 定常コスト 13,210円 は **約 0.83 SKU 分**で回収可能。SKU 1個でほぼ賄える計算。
- シナリオA は **約 0.88 SKU 分**。差は小さい。

### 3.3 シナリオC の機会損失コスト（数値推定）

> 推定：Keepa 無料プランでは売上ランク履歴の一部が閲覧不可。仕入れ判断ミス（売れない商品を仕入れる確率）が**有料比+15〜25%**増加すると仮定。
> 仮定：1回の仕入れ判断ミスの平均損失 = 仕入原価 5,000円 × 在庫滞留率20% = 1,000円／件。月10件判断するなら月の追加損失 **1,500〜2,500円**。
> 楽観・中央・悲観で機会損失を **月1,000円／月2,000円／月5,000円** とおくと、年 12,000円／24,000円／60,000円。

中央値で **C は「コスト0、隠れ損失24,000円／年」** → 実質コストは B の方が安いか拮抗する場面が出る。

## 6. 数字で見たリスク（失敗シナリオでの最大損失額）

### 6.1 最悪ケース：1年で撤退判断、その間ツールはフル稼働していた場合

| シナリオ | 12ヶ月コスト | 体験仕入れ赤字（仮定：月-2万円×12） | **総損失額（円）** |
|---|---:|---:|---:|
| A 即フル | 189,002 | 240,000 | **429,002** |
| B 段階導入 | 99,432 | 240,000 | **339,432** |
| C 無料のみ | 0 | 240,000 | **240,000** |

### 6.2 A→B の差額 89,570円／年 が何を意味するか

- 社長の本業所得を仮に月50万円とすると、**1.5日分の手取り**に相当。
- 撤退判断時の心理的負担：A だと「ツール代だけで19万円が水の泡」となり、再挑戦時のハードルが上がる。Bは10万円弱で「授業料」として吸収しやすい。**感情を排した経済合理性ではAB差額は小さいが、再挑戦オプション価値を加味するとBが優位**。

### 6.3 SellerSprite 個別リスク

- 中国発SaaSへの**送金経路リスク**（カード決済停止、暗号資産経由要求等）= 推定発生確率 5〜10%／年、発生時の代替コスト＝月額相当の機会損失2〜3ヶ月分 = **2〜3万円**。
- データ取扱規約の変更により**個人情報・出品ASIN流出リスク** = 定量化困難、法務確認必須事項。
- → SellerSprite 導入は **法務承認＋ EUR/CNY 決済可能なカード準備** がコスト前提条件。

### 6.4 為替リスク

- Keepa は €建て。円安20%（1€=214円）が1年続いた場合、年額は **40,446円**（中央比 +6,804円）。
- インパクトは年7千円程度であり、ヘッジコスト（外貨建てカード手数料2%程度）と比較してヘッジ不要と判断。

## 7. 小口プラン制約のコスト影響

社長は**小口プラン確定**。アマサーチの API 連携前提機能（在庫連携・自動価格改定）は使えない可能性が高い。

| 観点 | 数値判断 |
|---|---|
| アマサーチ有料 2,980円／月の **基本機能（バーコードスキャン・利益計算）は小口でも利用可** | コスト見合いは維持 |
| API 連携機能が使えないことで失う機能価値 | 月1,000〜1,500円相当（推定）。**実質コスパは 1,480〜1,980円／月相当** |
| 大口（4,900円／月）切替の BE 件数 | (4,900 − 0)÷100 = **49件／月** が損益分岐 |
| 現実的判断 | **月販49件を超えるまでは小口を維持。アマサーチ有料も "店舗仕入れに本格参入した月" 以降のみ** |

→ 小口のままアマサーチ有料は**割高**。**店舗仕入れ自体を「やる」と決めた月までは無料プランで十分**。

## 9. 秘書への申し送り（社長に必ず伝えるべき2点）

### (1) 「シナリオBで進めるが、Keepa Pro 開始を最低2ヶ月遅らせて構いません」

- 経理判断: 体験仕入れ1〜2周（=6月いっぱい）は **Keepa 無料プランで完走可能**。秘書原案では「Step 2＝1周後」だが、判断件数が週3件超えるまでは Pro 不要。
- 数値根拠: 7月開始なら年額が中央 **99,432円 → 約 79,000円**（−20,000円）。5年で約100,000円の節約。
- アクション: 「Pro 切替の発火条件＝週3件以上の仕入れ判断 or 売上ランク履歴で判断保留が3回」を社長と合意してください。

### (2) 「SellerSprite は粗利10万円／月を2ヶ月連続で出してから、です」

- 経理判断: 月額9,800円のSellerSprite が回収可能となるには月商49,000円（≒粗利9,800円）必要。**まだ売上ゼロの段階で投下するのは数値合理性なし**。
- 数値根拠: 粗利10万円継続＝既にKPIへの道筋が見える状態。そこから先のレバレッジツールとして導入が正しい順序。
- 追加: 中国発SaaSへの送金は §4.1 承認必須＋法務確認 → **「ツール代月9,800円」だけでなく「法務工数＋送金経路整備」のフルコストで判断**してください。
