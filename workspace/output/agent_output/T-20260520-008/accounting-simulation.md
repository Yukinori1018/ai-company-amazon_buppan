| 軸 | 説明 | 重み |

| 月間販売規模 | カテゴリ全体の Amazon 月間流通額の推定（公開情報＋Keepa 月販推定の積み上げ） | 中 |
| 平均販売価格帯 | 副業初心者が扱いやすいレンジ（1,000〜5,000円が理想） | 高 |

## ハジメの結論

1. **初手は「ペット消耗品×H&K小物×H&B消耗品」の3商品同時起動**。回転×利益率×規制リスクのバランスで最適解。
2. **中央シナリオで1サイクル（2.5ヶ月）+44,460円、リスク調整後 +37,960円**。年間換算 約 +18万円（再投資なしの場合）、再投資ありなら **年間 +45〜60万円** が射程。
3. **最大損失は -23,200円**。10万円の予算枠内で必ず収まる設計。
4. **損益分岐は商品③（H&K）が最も緩く 67%消化**。**商品①（H&B）が最も厳しく 77%消化**。商品①は「練習用」と割り切るのが合理的。
5. **キャッシュフロー上、W1〜W3 で約7万円が先払いで消える点**は素人が最も驚くポイント。社長には「**現金が10万円から3万円に減るが、これは消えたのではなく在庫に変わっただけ**」という解説が必須。
6. **長期合理性の観点**: 1サイクル目は利益最大化より「販売プロセスの体験」が目的。データ取得（実回転日数・実消化率・実FBA手数料）を最優先し、2サイクル目以降で**商品選定の精度を上げて利益率20%目標に近づける**。
7. 仕入れ先網羅は庶務マリエ、規制チェック（特に H&B 商品①、ペットフード商品②）は法務ハルオに**並行発注を推奨**。社長の最終判断材料が揃います。
