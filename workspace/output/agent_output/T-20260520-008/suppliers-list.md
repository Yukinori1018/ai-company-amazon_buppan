## はじめに — 仕入れ先を「お洋服のクローゼット」に例えると

社長、お洋服を選ぶとき、クローゼットがぐちゃぐちゃだと「結局いつもの服しか着なくなる」のと同じで、仕入れ先も整理されていないと「結局メルカリばかり」になってしまいます。今回は **8つのカテゴリ別ハンガー** に仕入れ先を並べ替えて、その日の気分（＝予算・時間・ジャンル）で素直に手を伸ばせる "ときめきクローゼット" に仕立て直しました。

**Before:** 「仕入れ先って結局どこ？」と検索するたびに 40〜114 サイトが羅列されて疲弊
**After:** カテゴリ別8棚 × 厳選 30 仕入れ先 + 3問フロー + 記録テンプレート、計1セットに集約

それでは、棚を順番に開けてまいりましょう。

## B. ときめきフロー — 3問で仕入れ先を決める

社長、複雑に考えなくて大丈夫です。以下3問だけで、今日開けるべき棚が決まります。

```
Q1. 今週、仕入れに使える時間は？
 ├─ 5時間未満（在宅完結したい）
 │   → カテゴリ 1（国内卸）+ カテゴリ 3（量販店ネット）+ カテゴリ 4（楽天）
 │     → 棚を3つだけ開けて他は閉めておく
 │
 └─ 5時間以上（外出も OK）
     → 上記 + カテゴリ 5（店舗仕入れ）も開ける
       → アマサーチ月額2,980円とセットで装備

Q2. 商標・知財・法務に明るいですか？
 ├─ いいえ（初心者）
 │   → カテゴリ 1・3・4 中心。中古市場は「古物商取得後に追加」
 │     → 海外輸入（カテゴリ 7）は閉じておく
 │
 └─ はい（または法務に都度相談できる）
     → カテゴリ 6（中古）・7（海外輸入）も解禁可

Q3. 仕入れに使える1ヶ月の予算は？
 ├─ 5万円未満
 │   → カテゴリ 5（ディスカウント）+ カテゴリ 6（中古、ただし古物商あれば）
 │     → 1点〜小ロット仕入れで回転重視
 │
 ├─ 5〜10万円（← 今の社長はここ）
 │   → カテゴリ 1（NETSEA）+ カテゴリ 3（ヨドバシ）+ カテゴリ 4（楽天）
 │     → 3棚並行で月10〜20SKUを目標に
 │
 ├─ 10〜30万円
 │   → 上記 + カテゴリ 2（メーカー直販）の打診開始
 │     → 安定リピート仕入れの種まき期
 │
 └─ 30万円以上
     → 全カテゴリ解禁。カテゴリ 7（海外輸入）OEM も視野
```

**素人の社長への推奨（2026-05-21 時点の Before/After）:**

- **Before:** 「結局どこで仕入れたらいいか分からない」
- **After:** 軸B（T-004、予算10万円）では **NETSEA + ヨドバシ + 楽天の3棚だけ開ける**。残り5棚は今は閉めて、感謝の一礼をして待つ

## C. 1事業1ルール — 仕入れ管理運用テンプレート

整理整頓の真髄は **「決めた場所に決めたとおりに戻す」**。仕入れ記録も同じです。1事業1ルールで以下のテンプレートに統一しましょう。

### 命名規則

- 仕入れフォルダ: `~/Documents/AI Company Outputs/Amazon物販事業/purchase-log/`
- ファイル名: `YYYYMM_purchase-log.csv`（月別1ファイル）
- 領収書: `YYYYMMDD_仕入れ先名_金額.pdf` で同フォルダ内 `receipts/` に格納

### CSV カラム設計（`purchase-log-template.csv` を参照）

| カラム名 | 説明 | 例 |
|---|---|---|
| 仕入れ日 | YYYY-MM-DD | 2026-05-21 |
| 仕入れ先名 | カテゴリ別リストの正式名称で統一 | NETSEA |
| カテゴリ番号 | A-1 〜 A-8（本リストのカテゴリ） | A-1 |
| 商品名 | メーカー商品名（JAN がある場合は併記） | アロマディフューザー XYZ-100 |
