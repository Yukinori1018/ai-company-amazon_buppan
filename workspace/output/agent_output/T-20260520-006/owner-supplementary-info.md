## 2. 独自ツール「ADD×ONE PROJECT」の存在

カズくんの会社（=株式会社JACKALL推定）が独自開発した、Ama-Jack とは別のツール。社長提供スクショから読み取れる実態:

- **UI**: ゲーム風（RPG調・「冒険をはじめる」「商店街で稼ぐ」「未開のダンジョンで荒稼ぎ」等のロック階層）
- **名称**: ADD×ONE PROJECT
- **機能**:
  - 「宝の地図1〜15」= カテゴリ別検索プリセット（例: 宝の地図1 = ホビーおもちゃゲーム Amazon急騰商品）
  - **API キー設定が必要**（Keepa API を別途用意する設計と推測）
  - 「採掘量の調整」= 一度に検索する商品数、再表示の使い回し設定
  - **判定結果カラム**: 判定（原石 / あやしい / はずれ）/ ASIN / タイトル / 売値 / 仕入れ値 / 利益 / 利益率 / 月販 / Drop30 / 仕入れ元 / 経過時間
  - スクショ例: 22件鑑定（はずれ15 / 原石4 / あやしい3）
  - 仕入れ元 列の値: 全て **yahoo**（Yahoo!ショッピング想定）

## 3. データ取得方法（推定）

- **Keepa API 連携**: Amazon 側の価格・順位データ取得
- **Yahoo!ショッピング等からスクレイピング**: 安値商品リストを取得
- **Yahoo がメイン、他サイトもあり**（社長口頭）

## 4. 法務リスク再評価（要追加判定）

ADD×ONE PROJECT は **Yahoo!ショッピングの利用規約・Amazon ToS 双方への抵触リスク** が高い：
- Yahoo!ショッピング ToS は自動スクレイピングを禁止する条項あり（一般的）
- Amazon ToS（T-008 法務マトリクスで整理済）= 自動データ収集・第三者経由のデータ流用を禁止
- → ユーザー（=社長）が「自分でスクレイピングしている」わけではないが、結果を仕入れ判断に流用する構造は、法務ハルオが T-003 で指摘した SellerSprite と同じ R-1（出品アカウント停止リスク）に該当

## 6. ADD×ONE PROJECT を使ってみたい場合の追加注意点

- このツールは **150万円コース付属** の可能性が極めて高い。単独購入は不可能と推定
- 無料コミュニティだけ参加しても **このツールには触れない** ため、社長の「ADD×ONE 触ってみたい」目的では入会価値が薄い
- 仮に入会して使えたとしても、Yahoo / Amazon ToS 抵触リスクあり → 当社の SKU 100・月商800万 目標に対し **アカウント停止リスクは致命的**
