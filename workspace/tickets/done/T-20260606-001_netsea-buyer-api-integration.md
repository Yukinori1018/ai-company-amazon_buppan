## 要件

社長依頼（2026-06-06）:「NETSEAも登録したんだから、NETSEAからも情報を入手してください」。
Sato-Scope の仕入元に **NETSEA（卸）を Yahoo・楽天に次ぐ第3の仕入元** として追加する。卸価格は小売より安く、原石歩留まりの向上が見込める。

## 合法データ経路（調査済み・2026-06-06 カズヨ）

- **NETSEA公式「バイヤーAPI」が存在**（ToS安全。スクレイピング不要）。
  - 利用方法: https://www.netsea.jp/help/manual/api.html
  - APIマニュアル: https://api.netsea.jp/docs/buyer/
- 取得可能: 取引可能サプライヤーID／商品カテゴリ一覧／サプライヤー商品情報／指定商品の在庫有無／送料一覧。
- **重要な利用条件**: 「消費者直送可能かつ、取引申請が承認されているサプライヤーの商品に限る」＝社長が取得済みの承認10社以上が対象。
- 認証: **トークン認証**（マイページ→登録情報管理→API登録情報→利用規約同意→申請→トークン認証→ログイン→許可→トークン発行）。

- 料金記載なし（無料の見込みだが、申込画面で要確認）。
