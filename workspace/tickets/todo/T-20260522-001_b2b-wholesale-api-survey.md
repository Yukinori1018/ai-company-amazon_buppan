## 各プラットフォームで確認したいこと

| 確認項目 | 期待する出力 |
|---|---|
| 会員登録要件 | 個人 OK / 法人のみ |
| 月額費用 | 無料 / ¥◯◯ |
| API 提供有無 | 商品検索 API、価格 API、在庫 API |
| API 利用料 | 無料 / 別途課金 |
| ToS 上の二次利用範囲 | 仕入れ判断ツール内で価格表示 OK か |
| 取扱カテゴリ | 家電/日用品/コスメ等 |
| 副業初心者の参入難度 | 高/中/低 |

## 打ち切り条件

- N=8社の調査で、API 提供あり 2社以上 / 提供なし 6社の段階で打ち切り
- 各社について 30分以内（公式 FAQ + 開発者ドキュメント確認まで）
