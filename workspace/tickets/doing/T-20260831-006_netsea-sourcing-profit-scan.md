### 判定サマリ

| # | 論点 | 判定 |
|---|---|---|
| ① | NETSEA 品を Amazon で転売してよいか | **条件付き可。**会員規約に販路制限なし（全文検索7語で0件）。**ただしサプライヤーが商品単位で「ネット販売 不可」を掛けられる仕組みが実在**。`deal_net_shop_flag=="Y"` での機械フィルタ＋発注前の販売条件目視、の二段確認が必須 |

### タカシの設計に効く事実（要反映）

1. **API の取得範囲は「消費者直送可能 かつ 取引申請が承認済みのサプライヤーの商品」に限られる**（公式ヘルプ明記）。
   「NETSEA 全体をスキャンして宝を探す」設計は成立しない。スクレイピングでの代替も不可（robots.txt＋規約7条1項3号）。
2. **サプライヤーの自由記述「販売条件」は API では取れない**（商品スキーマに該当フィールドなし）。
   ここに「Amazon不可」「売価厳守」が書かれる。**発注前の人的確認が必須**。
3. `deal_net_shop_flag == "N"` の商品は**利益が出ても候補リストに載せない**（フィルタではなく除外）。
4. NETSEA の納品書は公式に**「社内管理用」**と明記。**Amazon のゲート解除用の請求書として通る保証はない。**
   ブランド品を扱うなら「正式請求書を出すか」を取引申請の段階で確認すること。
5. API 利用規約 8条2（加工に書面承諾）はグレー。**NETSEA 由来データを deliverables に出さない**運用ガードを推奨。
