## 依頼（社長・2026-09-06）

> 「あらゆる方法で商品を探してほしい。理想的な形としては、**地元では有名な商品（食材も含む）をメーカーから独占的に仕入れてネットで販売する**。**SNSで有名になりかけている商品を仕入れてAmazonで販売する（その際は全力でカートを取りに行って、先行逃げ切り作戦）**などです。なのでSNSの情報を取りに行くスキームをあなたに考えてもらって実行してほしい。私でも分かる話だと、バズった有名人の動画の中で、食べている食材が売れたりしているのは良く聞く。**まずはいろんなアイデアを列挙してほしい。**」

## この依頼の位置づけ

社長の二段構え（2026-08-31）で言うと、本件は**両方にまたがる**。

| 社長のアイデア | 二段構えでの位置 | 別チケット |
|---|---|---|
| 地元で有名な商品をメーカーから独占仕入れ | **【本丸】そのもの** | T-20260906-005 で並走 |
| SNSで有名になりかけの商品を先行逃げ切り | **第3の軸**（速度勝負・在庫リスク最大） | 本チケット |

## 先に潰すべき壁（着手前提の確認事項）

1. **法務**: 2026-08-31 のハルオ判定で **YouTube Data API / X / TikTok / Instagram は現時点すべて NO**（Developer Policies の "Do not aggregate API Data"・30暦日保存制限・制裁が Google アカウント単位に及ぶ）。ただしこの判定は **API 経由の機械的収集・保存**についてのもの。**人が見る／公開ランキング・公開集計サービス／RSS・検索経由**まで否定しているかは未判定 → **ハルオへ再照会（本チケットの前提条件）**
2. **販売口**: **日本店（Satoy Select）は停止中**（T-20260826-004・2026-09-06 時点でケース 21912948521 が Work in progress）。**「全力でカートを取りに行く」は復活しないと物理的に実行できない。**
3. **プラン**: 小口プランはカートが取れない（memory `project_amazon_plan_koguchi`）。先行逃げ切りには大口が前提。切替タイミングは初回FBA納品プランの直前。
4. **食材を扱う場合**: 食品衛生法・食品表示法、FBA の要期限管理商品（賞味期限60日・45日で販売不可／memory `knowledge_fba_shipment_playbook`）。**食品は難度が一段上がる** → 別途ハルオ判定

→ 上記2〜3のため、**本チケットの成果物は「今すぐ売る」ではなく「アカウント復活までに仕込みを終える」ことを目的とする。** 調査・リスト化・仕入れ交渉の準備は今できる。

## 依頼内容（サトル）

**Phase 1：アイデアの全方位列挙（最優先・これを先に納品する）**

「SNS/トレンドの兆しから、Amazonで売れる商品を先回りして見つける」方法を、**手段を限定せず列挙**する。各案について以下を必ず付ける。

| 項目 | 内容 |
|---|---|
| 経路名 | 何を情報源にするか |
| 兆しの捉え方 | どの指標がどう動いたら「有名になりかけ」と判定するか（主観語で終わらせない） |
| 仕入れの実在性 | **その商品を社長が実際に仕入れられるか。**メーカー直／卸／小売の別。ここが空欄の案は価値が低い |
| リードタイム | 兆し検知 → 仕入れ → FBA着荷 まで何日か。**先行逃げ切りはここで勝負が決まる** |
| 適法性の懸念 | API規約・著作権・スクレイピング可否。判定はハルオに回す前提で論点だけ挙げる |
| 費用 | 無料／有料（有料は §4.1 で社長承認） |
| 難易度 | 社長＝個人事業主・物販実績ゼロ・日本語のみ、を前提に |

**列挙の視野（これに縛られず広げてよい）**
- 公開のランキング/急上昇（Amazon急上昇ランキング、楽天/Yahoo、Googleトレンド、各SNSの公式トレンド表示）
- テレビ・YouTube・TikTok での言及（バズった動画で紹介された食材、という社長の実例）
- クラウドファンディング（Makuake/CAMPFIRE）＝**一般販売前の商品**。独占交渉の余地が最も大きい可能性
- 地域物産・道の駅・アンテナショップ・ふるさと納税返礼品（**「地元で有名」の機械的な代理指標**）
- 展示会・商談会（T-20260831-005 のギフトショー2,353社と接続）
- 海外で流行→日本未上陸
- 既存の有料トレンド検知サービス（自作の前に必ず既存を調べる／memory `feedback_research_existing_before_build`）

**Phase 2：上位3案の実行設計**（Phase 1 納品後、社長が選んだものだけ）
