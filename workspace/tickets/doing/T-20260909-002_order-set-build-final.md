### 1. 納品代行の作業費は「欠落」していませんでした

  同日の commit `bf44b59` で `pipeline/config.py` に `prep_service_yen = 12.0` が入り、
  `evaluate.py` が `納品送料 = FBA納品送料37.5 + 納品代行12 + NETSEA按分` として純利益から引いています

  （ファブリーズ「93円→81円」は二重計上です）
