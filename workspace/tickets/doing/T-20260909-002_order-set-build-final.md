**依頼文の前提のうち3つが、実データで否定された。**

1. **アイオロス3SKU 同時は予算に入らない。**最小発注数の合計が予算の1.5倍。同時に買えるのは最大2SKU
2. **アイオロスに寄せても送料は安くならない。**`/tariffs` 実額で「定額・段階設定なし」＝積んでも変わらない
3. **そもそも4SKU が組めない。**最も安い4件を最小ロットで買うだけで予算超過。上限は3SKU

**一番の発見:** 5件のうち3件は、**卸の最小ロットを1回買うだけで26〜47ヶ月分の在庫**になる。
回転が遅い商品を選んだのではなく、卸が小さく売ってくれない。
「回転検証＝通過」のフィルタは「売れているか」しか見ておらず、**最小ロットが何ヶ月分かを見ていない。**
選定条件に `最小ロット ÷ 月販見込 ≦ N ヶ月` を足すべきだが、**N は社長が決める数字**なので実装せず論点として残した。

続報（13〜25位）は `pool.csv` に「現行」の行を足して `python3 order_set.py` を再実行するだけで組み直せる。コードは触らない。
