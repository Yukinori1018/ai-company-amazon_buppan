### 最重要の結論3つ

1. **公式HP探索は塞がっていません。実費0円で自動化できます。**
   Google Custom Search は新規受付終了、Bing Search API は2025-08-11に廃止済み。ですが **Gemini API の「Grounding with Google Search」が Gemini 3.x で月5,000リクエスト無料**（超過 $14/1,000）。822社は無料枠内。Google 正規APIであり検索スクレイピングではありません。次点＝Serper.dev（2,500クエリ無料・カード不要）、Tavily（月1,000クレジット無料・カード不要）。
2. **英字526社は、名前以外の4信号で「日本の実体があるか」を0円で機械判別できます。**
   ①JAN 45/49（91社） ②`.jp/.co.jp`ドメイン（23社） ③サイトタイトルが日本語（40社） ④Keepa `manufacturer` に日本語（77社）→ **いずれか＝145社（27.6%）／シグナルゼロ 381社（72.4%）**。判定済みCSVを納品済み。
3. **シグナルゼロ381社は「日本の連絡先は取得できない」で確定させるのが合理的。**
   ハルオ判定で Amazon 出品者の特商法表記が使用不可になり、日本の輸入者/販売者を辿る唯一の自動経路が閉じたため。
