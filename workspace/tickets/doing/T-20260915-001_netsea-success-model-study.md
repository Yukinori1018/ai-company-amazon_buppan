## 背景

T-20260909-002 で、NETSEA の卸値で Amazon の既存 ASIN に相乗りすると、ほぼ利益が出ないことが確定した（月100個以上の商品から10万円ロットが組めず、組めたのは約2万円だけ）。

2026-09-15 の社長の指示：

> 「常にあらゆる方向性で商品仕入れを考えて下さい。そして、その計画を検証（実行）し、評価、改善を行うPDCAを回して下さい。」
> 「最初の本線は"1周目の10万円ロットは、スーパーデリバリーとメーカー直の2本で組みます。"で大筋OKです。」
> 「NETSEAに関しては、こちらから仕入れて、成り立っているところの事情を考察し、どうやって売っていくのかを見出して下さい。」

## やること

- [ ] 1〔リサーチャー サトル〕NETSEA 仕入れで成り立っている事業者の実態を調べる（事実の収集）
- [ ] 2〔プランナー タケシ〕当社の売り方の仮説を立てる（複数案）
- [ ] 3〔シミュレーター マサル〕仮想の Do（プレモーテムと3シナリオ）
- [ ] 4〔カズヨ〕評価し、社長へ A/B/C＋推奨の形で上げる

## 現在地

- **イシュー（サトル）**：NETSEA の卸値で利益を出している事業者は、どの売り場・どの売り方で「価格決定権」と「競合の少なさ」を得ているのか（Amazon 既存 ASIN への相乗り以外に何があるのか）。
- **スコープ**：事業者タイプ6種 × 利益構造（価格決定権・競合数・手数料）／Amazon に無い NETSEA 商品の割合（JAN サンプル）／公式コンテンツと二次情報／規約上の制約。
- **打ち切り条件**：出典は一次（NETSEA 公式・規約・各モール公式の手数料）を優先、二次（ブログ・動画）は最大10本。JAN サンプルは NETSEA API ＋ Keepa で最大300件。NETSEA のログイン画面・サプライヤーへの連絡は行わない。成功事業者の利益率・件数は一次情報が無ければ「無い」と書き、推定で埋めない。
- 状態：調査中（サトル）
