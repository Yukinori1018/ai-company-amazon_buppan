## イシュー

> アフィリエイト ASP の商品データ API を、**「商品紹介」目的を超えて「仕入れ判断ツール内の価格表示」に使うことが ToS 上 OK か**を法務観点で確認する。

## 確認対象 ASP

1. 楽天アフィリエイト（楽天 API と統合済み・要再確認）
2. A8.net 商品データ API / データフィード
3. もしもアフィリエイト データフィード
4. バリューコマース DataLink
5. afb 商品データ
6. アクセストレード

## 各 ASP で確認したいこと

| 確認項目 | 期待する出力 |
|---|---|
| 商品データ API/フィード提供有無 | あり/なし |
| 二次利用範囲（ToS 明文） | 紹介サイト掲載のみ OK / 内部ツール利用可 / 不可 |
| 価格を仕入れ判断材料に使うことの可否 | 明文/グレー/明確に NG |
| 「個人専用ツール内表示」の扱い | 私的利用としてセーフ / アウト |
| 各社の事例（過去にアウトと判定された運用） | あれば列挙 |

## 打ち切り条件

- 6社のうち 3社で「明確に OK」または「明確に NG」が判明した時点で十分
- 各社 ToS の該当条文を抜粋して残す

## バトン

ハルオが「Sato-Scope で使ってよい ASP / 使うとリスクある ASP」を判定。タケシが調査結果を踏まえて v0.2 への組み込み可否を決定。
