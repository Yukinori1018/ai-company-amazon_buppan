## 要件

社長（2026-10-12）：「スーパーデリバリーにサンリオなど IP の強い商品がある。利益は取れなかったのか。これまでの評価を探し出し、どう評価して GO に至らなかったかを分析して。組み合わせて単価を上げれば可能性はある気がする。鵜呑みにせず可能性を探って」

## これまでの評価（秘書の読み合わせ・T-20260920-003 より）

- 9/20 サトル 04：サンリオ月販100以上350件のうち本体不在8件（2.3%）。知財（画像の著作権削除）を理由に「サンリオは取らない」
- 9/20 ハジメ 10：B0FQDWCGQD 売値1,100円・卸率67%で営業利益 △20.6%。真因＝粗利363円 < FBA 415円
- 9/20 タカシ 11：セット単価倍率の中央値 1.000（値上げは成立しない）。効くのは FBA の分散だけ。入数3〜5なら黒字化
- 9/20 ハルオ：キャラ違い・色違いの組み合わせセットは規約上不可（バリエーション条項）。同一品 N 個パックは条件付き可。丸進の「ブランドイメージ」条項に抵触の恐れ
- 9/21 サトル 14：本体不在かつ月100以上の7件、利益の取れる0件。卸率63.6%超は売価をいくら上げても利益率20%不可

## 前提が変わった点（再評価の理由）

- 原価モデルの修正（10/4）：固定費821円のうち470円が架空。750円以下は販売手数料5%、1,000円以下は FBA 222/252円
- 等級は利益率 OR 利益額400円（§3.5）、実績枠（手残り0円以上）も新設（10/12）
- 日本ストアは 9/20 に復活（「停止中の今は取れない」の前提が消えた）
- 10/11 の SD 照会キューにサンリオ系が新たに入り、B 等級の卸上限が計算済み（例：クロミ おせわセット 売価4,322円・B 上限2,263円）
