## 背景

2026-09-20、統合報告 v4 の3つのお願いに対して社長から回答があり、3件の宿題になった。

> 1. Keepa — 今のところ Keepa API を使う必要性はあまりないが、まずその必要性を検討したい。結論だけでいいので、止めるか止めないか判断してほしい。最初は電脳せどり用と思ったが、Keepa API を使っても Claude で利益の出る商品を探すことがあまりできなそうに思えた。私の考えつくところでは利用価値が見出せないので、そちらで利用価値を見出してほしい。**これも自分で考えるのではなく、世の中をリサーチして実績のある人を真似て**考えること。

## 完了報告（S-A / サトル → カズヨ）

**結論: 止めてよい。推奨は ③ いったん解約 → 必要な月だけ再契約。**

- 型A（メーカー大量連絡→独占）を回している実践者に **API 課金者は0件**。実績を公表している5件（FBA Mogul 7桁ドル・Gのすけ年商1億・EC STARs Lab. ほか）は全員ウェブ版 Pro €29。**当社の型Aの原典である EC STARs Lab. は「必ず有料版（Pro）」と書き、API に一言も触れていない。**
- 当社の工程8つのうち API が無いと止まるのは「補給月の大量抽出（T-1型）」1つだけ。母数は 2,425社＝週70通で35週分あり、8ヶ月は再抽出不要。
- 年10.4万円（8,732円/月）の固定費削減。マサルの感度では月8,000円差＝約28pt（線形近似の外挿なので位置づけとして読む）。
- 条件2つ: **10/2 までに T-3・S-3 の抽出を終える**／再契約は新規契約で **Keepa は理由なしに断れる（T&C §3(3)）**ことを撤退条件に織り込む。

**妥協点・確度**: 「実践者が API を使っていない」は出典付きの事実。「当社が止めても詰まらない」は工程を並べた判定＝推測（確度 高）。Pro €29 の画面は未契約のため未検証で、brandStoreName の出力可否は未確認。tooledbuppan・Medium・有料Substack は本文取得できず（付録Bに明記）。

**社長判断が必要な論点（§4.1 金銭）**: ①解約の実行 ②Pro €29 を契約するか（実践者の型に最も近い）③Seller Assistant $13〜30/月（卸価格表の一括判定）。戦略としての選択はタケシ／社長の領分なので、サトルは事実と論点シート（本文 §8）までで止めています。

## 完了報告（S-C / サトル → カズヨ）

**結論: 推奨は案② faximo（FAX・03番号）＋ IVRy フリー（050電話）。固定費 月1,584円（税込）、月150枚で月3,894円、年額47,916円（初期1,188円込み）。**

- 最安は案①（秒速FAX送信＋IVRy）で固定費 月550円・月150枚で2,350円。ただし**FAXを受信できない**（送信専用）。
- 案③（03plus で電話とFAXを1本化）は月6,849円。**最低3ヶ月＋解約は申請の2ヶ月後成立＝実質5ヶ月分のコミット**で、返信率が読めない段階では固定費リスクが大きい。
- 案②を推す理由は3つ：03のFAX番号を自社で持てる／違約金なし・最低契約期間の記載なしで1ヶ月で止められる／枚数が50→300枚に振れても月2,354→6,204円で壊れない。
- 法規：特商法12条の5（FAX広告オプトイン）は**一次条文で対象外を確認**。オプトアウトの法的義務もなし。ただし①売り込み混入時の扱い②FAX→電話の重ね打ち③各社規約の一般条項、の3点は**ハルオ判定要**として論点のまま残した。
- 副産物：T-20260915-002 の 11 で「二次情報」としていた IVRy 番号維持費 月500円を**公式で確定**（税抜）。同時に従量スロット（30円/スロット・税抜）の存在が判明。フリープランの30着電が従量分を含むかは公式に記載なし。

**妥協点・確度**: 金額は全て公式ページの一次情報（取得2026-09-20）。eFax の送信元表示番号・jFax の税区分と一斉送信上限・メッセージプラスの個人事業主可否は「未調査／記載なし」のまま残した（各社1〜2ページ追えば埋まるが、推奨に影響しないため打ち切り）。黒字確率の換算（1,000円=3.5pt）は依頼文にあった社内試算の置き値で、本書では検証していない。

**社長判断が必要な論点**: 契約は §4.1（金銭）なので申し込みは社長の一手。どの案にするか・FAX番号を文面に載せるかの戦略判断はタケシの領分です。
