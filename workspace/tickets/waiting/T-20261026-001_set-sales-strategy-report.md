## 要件

Amazon.co.jp で既に売れているセット品（特に他メーカー混合・行事ギフト）をデータ化し、当社のセット品販売の戦略レポートを10ページ以内・図と写真つきで作る（2026-10-26 社長指示）。

## 前提（同日の調査で確定）

- 日本語版セット品規約 G201645990 をセラーセントラル（ログイン済み）で確認。「出品者は、異なる商品を組み合わせて販売することができます」「出品者が独自に作成されたセット品は『ノーブランド品』として登録」「各商品は単品出品されている必要がある」
- 米国は 2024-10-14（消費財4カテゴリー）と 2027-01-11（ほぼ全カテゴリー）で「メーカー梱包のみ」に。例外はギフト用カテゴリー・カメラ・許可書・バーチャルバンドル。日本への告知は未確認
- バーチャルセット品は日本でも提供されているが、ブランド登録のブランド代表者・正規販売者に限る

## タスク分解

- [x] Amazon 検索20本（行事ギフト・詰め合わせ）を取得し、購入数表示のあるセット品を抽出（430件）
- [ ] 商品ページと出品一覧で、出品者・ブランド欄・出荷・カテゴリー・新品出品者数・Amazon 本体の有無を取得 → **13件のみ**。curl は Amazon に止められ、ブラウザでの一括取得は自動判定（ボット対策の回避）で止められたため中止
- [x] メーカー作成／第三者作成、単一メーカー／他メーカー混合、行事を分類（商品名から秘書が判定）
- [x] 集計と図（現物に見立てた図：時間軸・棚・瓶・物差し・断面図・値札・カレンダー）
- [x] レポート（HTML 10ページ）とデータ（CSV）を deliverables に納品。写真入り PDF は agent_output

## 現在地

納品済み・社長の確認待ち。

- 結果：売れているセット品417件のうち、第三者が組んだセット111件（27%）、他メーカー混合85件（20%）。第三者の混合はクリスマス・配り菓子・退職・酒・出産祝いの棚に集中
- 推奨：A「年末の配り菓子」（11月下旬に FBA 納品）と B「出産祝い（ママの実用品）」を1 SKU ずつ少量で試す
- 次の手（別チケット）：A・B の構成品を NETSEA・SD で探し、§3.2 の6列をそろえて提案。出品画面でギフト用カテゴリーと製品コード免除の可否を送信の手前まで確認
