「支払情報 →『クレジットカード情報(Amazon出品サービス)』からカードを変更したい。設定を順番通りに進めたいので忘れないようにしたい。」

## 担当宣言

- カズヨの役割＝**やり残しの記録とリマインド管理**（＝忘れない仕組みを引き受ける）。§4.1該当なし（既存カードの変更・新規決済ではない）。

## 現状（なぜ保留か）
- ログイン・LINE連携は解決済（別途メモリ更新済 [[project-amazon-login-entrypoint]]）。ストア＝日本／アカウント健全性＝🟢健全。
- 支払情報ページ `sellercentral.amazon.co.jp/global-dashboard/payment-information` は開ける。
- が、「クレジットカード情報(Amazon出品サービス)」リンクを踏むと `sellercentral.amazon.co.jp/ap/signin` の再認証へ飛ばされ、**赤枠エラー「内部エラー。後でもう一度お試しください。」**が出て進めない（2026-07-26 23:24 / 23:26 の2回で再現）。
- 文言どおり**Amazon側の一時障害**の可能性が高い（＝当方の設定ミスではない）。連打はロックリスクありのため中断。

## 次アクション（Amazonエラー復旧後・社長本人）
1. [ ] シークレット窓 → `sellercentral.amazon.com` → 手入力ログイン → 電話SMSで2FA → 上部で「日本」に切替（[[project-amazon-login-entrypoint]] の確定手順）。
2. [ ] 歯車（設定）→ 出品用アカウント情報 → 支払情報 →「クレジットカード情報(Amazon出品サービス)」。
3. [ ] 再認証を求められたら**同じタブで**完了（パスワード＋2FA）。飛ばされてエラーなら、そのURLを同じタブに貼り直して踏む。
4. [ ] 変更したい新カード情報を入力・保存（社長本人）。
5. [ ] ⚠️「登録」＝新規アカウント作成ボタンは絶対押さない（二重アカウント＝BSA違反リスク）。

## カズヨの管理
- **忘れ防止はカズヨが担保**。next_check_at で翌日以降リマインド。エラーが直っていれば社長へ「今なら1分で終わります」と一声。
- 復旧しても数日続くようなら、Seller Central 右上「?」ヘルプ → 問い合わせ（内部エラーの再現URL・時刻・NCIDを添えて）へエスカレーション案内。

## 確認事項（社長）
- 変更後に登録したいカードは決まっているか（決まっていれば復旧後すぐ完了できる）。

## 診断確定（2026-07-26 夜）
- **銀行口座情報ページも同じ「内部エラー」**（カードだけの問題ではない＝支払情報系ページ全般）。
- 機密ページは**ログイン済みでもステップアップ再認証（パスワード＋2FA）が必須仕様**（＝再ログインを求められるのは正常。カズヨの初期説明「同じタブなら聞かれない」は誤りで訂正済み）。
- 社長が **Authenticatorコード／電話SMSコードの両方**を入力 → **両方とも同じ内部エラー**。
  - → 当初の「重複アカウントで2FAが別系統に飛ぶ」説は**外れ**。2FAは2方式とも通っており認証は正常。**原因はAmazon側の決済ページ自体の不具合**。ブラウザ操作・2FA切替では解決不能。
- 対応方針を更新: **①時間を置いて再試行 → ②直らなければAmazonセラーサポート案件**（特定ページのシステムエラーとして報告）。次回エラー時に**NCID**をスクショ確保 → カズヨが報告文面作成。
