# 知見: waiting 継続のまま社長タスクを差し替える同期（T-20260904-005 / 2026-09-15）

## 依頼
SD から e-Tax 受信通知の追加提出依頼。社長の手元の受信通知は別書類（青色申告承認申請）だった。Status は waiting のまま、社長タスクを「e-Tax から開業届の受信通知を PDF 保存（期限 9/17）」へ差し替え。

## 手順（再利用可）
1. Notion カードは `notion-search` を data_source_url=`collection://366b0a40-44fa-81ec-8342-000b6d0a25e0` で TicketID 検索すると一発で page id が取れる。
2. `update_properties`（Status・UpdatedAt）と `insert_content`（末尾に日付節）は並列で投げてよい。
3. 投入後に fetch で確認する。**Description が古い推奨（9/12 の C版推奨）のまま残っていた**ので最新に差し替えた。依頼文に Description の指示がなくても、カードの一行目が古い推奨だと社長が誤読する。
4. owner-tasks.md は2000行超。Read が 25k トークン超で失敗するので、`python3 -c` で `repr(L[k])` を見て行インデックスを確かめてから Python で差し込む。**見出し上の `---` の位置を目測で決め打ちして assert が落ちた**（1行ずれ）。assert を置いておいたので誤書き込みはゼロ。
5. 古い社長タスク（「SD への返信の送信」）は消さず、打ち消し線＋「更新㉟で差し替え」と書いて最上段へ誘導。
