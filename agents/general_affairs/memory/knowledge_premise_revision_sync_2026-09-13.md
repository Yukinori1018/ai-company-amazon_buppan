## 落とし穴（今回踏んだもの）

- **Notion は `04_法務NO経路の再検討….md` のような「日本語＋.md」を勝手にリンク化する**。読み返すと `04_[法務NO…md](http://法務NO…md)` という偽リンクになっていた。ファイル名を素で書くときは**バックティックで包む**（`` `04_….md` ``）。配信URLを付けた `[表示名](http://localhost:…)` 形式なら起きない。
- 書き込みレスポンス `{"page_id":…}` は成功の証拠にならない。**4枚とも `notion-fetch` で読み返し**、この偽リンクはそこで見つけた。
- `git status` が clean でも、私が書く数秒の間に他エージェント（サトル③）の編集が乗ることがある。`git diff --stat` の行数が自分の編集（挿入1＋frontmatter 1）より多ければ他人の hunk。`knowledge_parallel_ticket_edit_stage_own_hunk.md` の cacheinfo 方式で自分の行だけ index に載せる。
