# 社長タスクの「条件待ち保留」の書き方（2026-10-07 / T-20260929-001 更新88）

- 社長が「先にAを確かめ、結果でB/Cを決める」と答えたら、Aを①（最優先）に上げ、B/Cは消さずに「⏸ ＋〔Aの回答待ち：可→◯／不可→◯〕」と注記して残す。期限は据え置く。
- 消さない理由：Aの結果次第で即復活するため。消すと再起票の手間と見落としが出る。
- 🔴件数は変えない（保留も社長の番として数える）。「✅ 変えたこと」表で旧番号→新番号の対応を書く。
- 同じ turn で：チケットの現在地（先頭に追記）＋ログ追記、Notion の Description と本文「残る社長判断」を置換、commit。
