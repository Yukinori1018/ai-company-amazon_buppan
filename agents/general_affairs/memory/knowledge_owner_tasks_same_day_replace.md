# 同日中に社長依頼が解消・差し替えになった時は、更新番号を増やさず同じ節を差し替える

- 事例: 2026-09-27 T-20260927-003。更新66で「Amazon にログイン」を追加 → 同日、社長が自分でカードを変更し米国復活 → ログイン依頼は解消、「カナダ旧ケースを閉じて新ケースで出し直す方針の承認（§4.1）」へ差し替え。
- 手順（再利用可）:
  1. owner-tasks.md の該当「## 🆕 更新NN」節を丸ごと置換（見出しに「同日差し替え」と明記、旧依頼は「解消」と1行残す）。
  2. 冒頭「最終更新」行の先頭（更新NN〔...〕）だけ書き換え、「／前:」以降は触らない。
  3. 🔴件数は増減を確認して明記（今回は 4 のまま）。
  4. Notion カードは「結果要約」節を update_content で置換＋ Description / UpdatedAt を update_properties。Status は秘書の指示が無ければ動かさない。
  5. コミットは対象ファイルのみ `git add <path>` で個別指定（他チケットの未コミット変更・作成中 deliverables を巻き込まない）。
- 理由: 番号を増やすと社長が「新しいお願いが増えた」と誤読する。差し替えは差し替えとして見せる。
