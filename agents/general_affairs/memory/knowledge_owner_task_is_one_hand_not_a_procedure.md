# 社長タスクは「一手」で書く — 手順ではなく、社長にしかできない1操作だけを切り出す

初出: 2026-09-04 / T-20260904-004（セラーセントラルへのログイン依頼）

## 今回の型（そのまま再利用できる）

未裁定の論点が3件あり、原因はすべて「Amazon 公式ヘルプが JS ＋ログイン必須で機械取得できない」の1つだった。
このとき owner-tasks へ書くのは **「ヘルプを読んで確認してください」ではない**。書いたのはこう：

> カズヨがシークレットウィンドウで `https://sellercentral.amazon.com` を開きます。
> 社長にお願いするのは **ID・パスワード・2FA コードの入力だけ**です。入ったらカズヨが操作を引き取ります。

CLAUDE.md §4.4 の「ブラウザ操作は秘書が実行する／社長に頼むのは本人にしかできない一手だけ」を、
**owner-tasks の文面レベルで守る**とこうなる。手順を渡した時点でルール違反になる。

## 社長タスクを1件書くときに必ず入れる4点

| # | 入れるもの | 今回の書き方 |
|---|---|---|
| 1 | **所要時間** | 「5〜10分」 |
| 2 | **社長がする操作だけを名指し** | 「ID・パスワード・2FA の入力だけ」 |
| 3 | **なぜ必要か＝この一手で何が解けるか** | 未裁定3件が同時に解ける（表で3件を明示） |
| 4 | **やらないことの明示** | 「設定は一切触りません。ヘルプの閲覧だけ」 |

4 が効く。今回は「カナダの違反1件が消えるまで Amazon の設定を凍結する」という方針〔T-20260826-004〕が
先に立っていたので、**ログインという行為がその凍結を破るように見える**。破らないと先に書かないと、
社長は依頼そのものを保留せざるを得ない。**先行する方針と衝突して見える依頼には、非衝突の一文を必ず添える。**

## 急がせない

「急ぎません。お時間のあるときで結構です」を書いた。期限のあるタスク（T-20260904-005 の 9/17 など）と
同じ強さで並べると、本当に期限のあるほうが埋もれる。**期限の無いタスクには、無いと書く。**

## 確定事項は社長タスクにしない

同時に確定した6件（古物商許可は不要／小口ではカート獲得不可 ほか）は**社長のアクションが要らない**ので、
🔴 ではなく **🟡 情報共有・ご判断待ち**へ `【ご判断不要・情報共有】` と明記して置いた。
ここを混ぜると「🔴 の件数＝社長がやること」という owner-tasks の一番の価値が壊れる。
