# ナレッジ: Git まわりの「削除せずに片付ける」手筋（マリエ）

初出: 2026-08-24 / T-20260817-005 の `.bak` 整理（カズヨ発注・A案採用）

## 前提となる会社ルール

- **不可逆な削除は CLAUDE.md §4.1**。ファイル削除・`git push --force`・branch 削除・`reset --hard` は自分で実行しない。
- 整理は**必ずアーカイブ経由**。庶務の行動原則5。
- 「リポジトリを汚しているファイル」を見つけても、**汚れ＝削除の理由にはならない**。

## 手筋1: 追跡対象から外す ≠ 削除する

作業中バックアップ（`*.bak`）や巨大な生データを片付けたいとき、**削除ではなく `.gitignore` で追跡から外す**。
ファイルはディスクに残るので §4.1 に該当しない。今回はこれで社長承認なしに完結できた。

**実行前に必ず確認する2点:**

1. **対象がすでに追跡されていないか。** `git ls-files '<dir>/*.bak' | wc -l` が 0 なら、`.gitignore` を足すだけで完了。
   **0 でなければ `git rm --cached` が必要**になるが、これは**インデックスからの削除＝§4.1 の判断が要る**ので、
   自分で実行せずカズヨに差し戻す。今回は 0 件だったので純粋な追加だけで済んだ。
2. **意図せず巻き込む他ファイルが無いか。** `git check-ignore -v <path>` を、
   **除外したいファイルと、除外したくないファイルの両方**に対して打つ。
   今回 `seller_count.py` は `*.bak` に該当せず未追跡のまま残ることを確認してから commit した。

**完了後の証拠取り:** `ls -l` でファイルが現存すること（バイト数まで）を確認し、報告に書く。
「削除していません」と言葉で言うより、`26,970 bytes` と出したほうが早い。

## 手筋2: 他担当の未コミット変更を巻き込まずに commit する

**状況**: 自分が編集したいファイルに、**別チケットの担当者による未コミットの変更がすでに乗っている**。
`git add <file>` するとその変更ごとコミットしてしまう（＝越権・他チケットの履歴汚染）。
`git add -p` は当社環境で対話フラグが使えない。

**使った手順（インデックス経由の分離）:**

```
cp <file> $SCRATCH/worktree.bak          # 作業ツリーの現状を退避
git show HEAD:<file> > $SCRATCH/head     # HEAD 版を取り出す
cp $SCRATCH/head <file>                  # いったん HEAD 版に戻し
<自分の変更だけを追記>                     # 自分の差分だけを乗せる
git add <file>                           # ← インデックス = HEAD + 自分の変更 だけ
cp $SCRATCH/worktree.bak <file>          # 作業ツリーを元に戻す（他担当の変更が復活）
git commit                               # 自分の差分だけがコミットされる
```

**結果**: commit には自分の hunk だけ。他担当の変更は**未ステージのまま作業ツリーに残る**。
`git diff --cached` と `git diff` の両方を commit 前に出して、**入るもの／残るものを目視確認**してから実行すること。

**注意**: 他担当のファイルを一時的に書き換えるので、**必ず退避 → 復元をセットで書く**（途中で止まると相手の作業を壊す）。
コマンドは `&&` で連結し、途中失敗で復元前に止まらないようにする。commit メッセージにも「巻き込まないよう意図的に除外した」と明記する。

## 判断のポイント（再利用可）

- **スコープは依頼どおりに絞る。** 今回カズヨから「リポジトリ全体の `.gitignore` は触らない／T-20260817-005 配下限定」と
  明示があった。全体に効くルールのほうが「きれい」に見えるが、**他チケットへの影響が読めない変更は、きれいでも越権**。
- **「置いてある理由が分からないファイル」は触らない。** `seller_count.py` は担当が意図して置いた可能性があり、
  追跡対象に入れる／外すのはどちらも越権。**判断できないものは現状維持が正解**で、報告に書いて担当へ返す。
