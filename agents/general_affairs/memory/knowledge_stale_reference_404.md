## 教訓（これが本体）

1. **廃止した実体は、それを指す参照を全部潰すまで廃止し終えていない。**
   「§6 に廃止と書いた」だけでは、フックと定型文が古い動作を再生産し続ける。
   実体の削除・アーカイブは、**参照の grep → 全消し**とセットで1タスク。
2. **固有名詞を含まない不備は grep で見つからない。**
   「まとめカード」「§着手前の可視化」のような社内語は、Amazon/Keepa のような固有名詞と違って
   横断検索の網に掛からない。**雛形リポへの転用（T-20260904-002）のような「全部読み直す作業」が
   唯一の検知手段**だった。定期的に他所へ写す作業には、この副次効果がある。
3. **同じエラーを2回踏んだら、自分の手順ではなくルール文を疑う。**
   1回目は自分のミス、2回目は環境の疑い、3回目は**確実にルール側の欠陥**。
   3回目でようやく起票に至ったのは遅い。2回目で「参照元を読み直す」に切り替えるべきだった。
