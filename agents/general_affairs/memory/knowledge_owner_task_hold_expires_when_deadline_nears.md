# 社長の「様子見」は無期限ではない — 外部の期限が近づいたら🔴へ戻す

初出：2026-09-27 / T-20260927-001（Amazon 本人確認書類の送信を最優先へ復帰）

## 判定

社長が「数日様子を見ます」と言って 🔴 から外した社長タスクは、**保留であって取り下げではない**。
次の2つが揃ったら、こちらから 🔴 へ戻して再提案する。

1. **社長が言った「数日」を明らかに超えた**（今回は 9/21 → 9/27 の6日）
2. **自社で動かせない外部の期限が近づいている**（今回は 11/30 でスーパーデリバリーが利用停止）

戻すときは「もう一度どうですか」ではなく、**戻す理由を2行で書く**。
「6日が経ちました」＋「11/30 を過ぎると◯◯を失います」。
期限のない催促は社長の判断を増やすだけで、こちらの怠慢と変わらない。

## 一緒に戻さないもの

**依存関係で順序が決まっているものは、保留のまま据え置く。**
今回、カナダストアの催促送信は 🔴 に戻さなかった。CA→JP の順でしか直せないので、
日本ストアの本人確認が通る前に催促を出すと手戻りになる。
**「2件まとめて様子見にしたから2件まとめて戻す」は誤り。**保留の理由が違えば解除の条件も違う。
