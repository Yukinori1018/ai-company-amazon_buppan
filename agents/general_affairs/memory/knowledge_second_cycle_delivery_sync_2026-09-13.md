## 落とし穴・学び

- **配信URLの疎通と git 追跡を書き込み前に一括で見る**：`urllib.parse.quote` → curl 200 → `git ls-files --error-unmatch`。10本を1回の Python で回せば、Notion 書き込みと並行できる。
- percent-encode は既存カードの文字列から手で組み立てず、**必ず `quote()` の出力を使う**（`社別`＝`%E7%A4%BE%E5%88%A5` のように既存に無い語が混じる）。
- 秘書が自分で作った成果物（-002 の 01）も**カタログ行の担当は `secretary`**。既存の担当語彙にある。
- -002（親）のローカル `.md` の `## 成果物` 節は秘書の持ち物なので触らず、Notion 側だけ 01 を載せた。ローカル側にリンクが無い点は報告で秘書に返す（「置いただけではチケットから辿れない」ルール）。
