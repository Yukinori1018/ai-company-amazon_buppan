# 冪等なシート同期の型（2026-10-01 / T-20260930-001）

社長指示「途中でも定期的にリストを作成して」に対し、台帳シートを**何度実行しても同じ結果**になる同期にした。
実装：`workspace/output/deliverables/T-20260930-001/sync_ledger.py`（実体は agent_output 側で実行）。

## 型（他の台帳にも流用できる）
1. 入力は「既存の確定CSV＋追記中CSV＋glob で増える CSV」。無いファイルは飛ばす＝途中でも走る
2. 重複キーは正式社名（無ければ抽出名）。**先に読んだ行が勝つ**＝後続の採取で確定行を上書きしない
3. 全置換の前にシートを `FORMULA` で読み、**社長入力列（接触ステータス・接触日・メモ）と HYPERLINK 式をキーで引き当てて戻す**
4. ヘッダーが想定と違えば中止（列ずれで社長入力を壊さない）
5. 書式は消さない：値だけ `batch_clear`→`update`。条件付き書式・プルダウン・フィルタの範囲を行数に追従させる
6. 初回は必ず実行前にシートを CSV バックアップ（agent_output/sheet_backup_before_sync_20261001.csv）し、実行後に全セル比較

## 落とし穴
- gspread の `value_render_option='FORMULA'` は数値を **int で返す**。バックアップ CSV（文字列）と比べると全行「差分あり」に見える。`str()` してから比較する
- §3.2 必須列（販売数・出品者数・本体の有無）は新規行で空欄にしない。実画面値が無ければ「Keepa値（実画面未確認）」と出典つきで埋める
- 判定の新規既定は「接触候補」。規模欄・備考に大手/上場/東証があれば「大手・上場（中小条件外・後回し）」、印は判定の後ろに「（印：ドラッグ）」
