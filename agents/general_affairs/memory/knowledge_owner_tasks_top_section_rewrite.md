## 手順（再利用可能）

1. チケット末尾の日付付きセクションを全文読む。`grep -n "^## "` だけでは `###` 見出しの追記を取りこぼす。**必ず末尾を `sed -n` で直接読む**。
2. `grep -n "^## \|^---$" workspace/owner-tasks.md` で最上段🚨🚨セクションの行範囲を確定（今回は 16〜108、次の `---` が終端）。
3. 新セクションを scratchpad に書き、Python で行範囲を差し替える。461行超のファイルを Edit の文字列一致で触るのは非効率かつ危険。
4. 冒頭 `> **最終更新: ...` 行は**先頭に新しい要約を足し、旧文を「／前: 」でぶら下げる**追記形式。過去の履歴は消さない。
5. Notion は `notion-update-page` の `insert_content` + `position:{"type":"end"}` で末尾に節を追加。あわせて `Description` と `date:UpdatedAt:start` を更新。**Status を触らない指示のときは properties に Status を同値で入れておくと事故が分かりやすい**。
6. ローカル `.md` の frontmatter `updated_at` も同日に揃える（Notion 側だけ更新すると次回リコンサイルで差分に見える）。

## 内容の畳み方

- **決着した A/B/C は消さずに「決着済み・ご返事不要」と明記して畳む。** 消すと社長が「まだ答えていない」と思い続ける。

- 社長タスクが1つに絞れたときは、見出しに「社長がやることは1つだけ：〜」と書いてしまう。表や本文を読ませない。

## 公開リポジトリの扱い

- 記載可：「パスポート欄に水道料金請求書を誤ってアップロードした」という**事実関係**。
- 記載不可：住所・電話番号・旅券番号・口座番号。今回は電話を「（+81）」、メールは業務用アドレスのみに留めた。
