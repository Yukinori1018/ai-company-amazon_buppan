## 学び

1. **done 化は「閉じる」だけでは足りない。** 残作業がある場合、カードの冒頭枠に「以降は T-XXXX へ」と明示する。これをしないと社長が done カードを見て次の一手を探す。
2. **冒頭の「最新」枠は必ず日付ごと差し替える。** 旧枠を残すときは見出しに「〜の記録（現在の状況ではありません）」を付ける（`knowledge_notion_stale_summary_top_frame` と同じ運用）。
3. **Labels の未定義オプションは `create_pages` と同時に渡すと落ちる可能性がある。** 今回は既知3件で作成 → 直後に `update_properties` で `sourcing` を足す2段で通した（`knowledge_notion_label_option_must_be_added_first` の回避策として有効）。
4. **他チケットの期限に効く条件は、そのチケットの行にも1行で書く。** SD の「11/30 までにサイトオープン」は T-20260920-001（本人確認書類・9/22）の行に補足した。別カードに書いただけでは社長の目に入らない。
