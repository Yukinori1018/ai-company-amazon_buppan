# 社長判断が「恒常ルール化」で解消されたときの同期手順（2026-09-30 / T-20260929-001）

## 事例
T-20260929-001 の社長判断①「初回燕三12点を 1a'/1d のどちらで受けるか」が、個別回答ではなく
恒常ルール（CLAUDE.md §3.4：初回は自宅検品・2回目以降 FBA 外注）として決着した。

## 手順（再利用可）
1. チケット：現在地を上書き（解消＝何で決着したか＋commit、残る判断だけを列挙）。ログに1行追記。status・requires_approval・next_check_at は残る判断に合わせて据え置き判断
2. owner-tasks.md：最新更新ブロックを複製して新ブロック（更新N+1）を先頭に置き、🔴 を振り直す。「今日決まったこと」に恒常ルールを1行。最終更新行の先頭にも追記
3. Notion：Description と本文「社長判断」行を差し替え（取り消し線＋解消）。Status は動かさない
4. カタログ：**暫定結果列はチケット単位の文言が全行（01〜04・README・HTML版）にコピーされている**。03 行だけ直すと他7行が古いまま残る → チケットID で全行置換してから sync
5. 無関係な未追跡ファイル（他チケットの作業中フォルダ）は commit に含めない。パス指定で add

## 学び
- 「対象の成果物の行だけ更新」と指示されても、判断待ち文言はチケット全行に波及している。grep で件数を数えてから置換する（今回 9 件ヒット＝03×2 と他 7）
