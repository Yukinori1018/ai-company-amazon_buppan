# 知見: 社長タスクの「保留」は `[x]` でも `[ ]` でもない（T-20260909-001 更新⑬ / 2026-09-12）

## この回の依頼
カナダに「無効な課金方法」ゲート。社長の次の一手が「A/B/C を選ぶ」→「カードを更新する」に差し替わり。
件数は差し引き0、Status は waiting のまま（T-20260909-001 / T-20260726-003 とも）。

## 型：差し替え（同件数・同列）の書き方
1. 旧タスクは `- [ ]` を外し `- ⏸ **保留（日付）：…** — 〇〇後に改めて` と書く。
   - `[x]` にすると「解消済み」と読まれ、再提示時に「もう答えたはず」になる
   - `[ ]` のままだと社長タスクが2件に見える（件数の嘘）
2. 見出しに「差し替わりました（差し引き0）」。入れ替わり表は「⏸ 保留／🆕 新規」の2行。
3. 旧ブロックは `<details>` に畳み、中の `###` を `####` に下げる（TOC で新旧が同格に並ばないように）。
4. 同じ根の別チケット（今回 T-20260726-003）は owner-tasks に別タスクを立てず、「一元管理先」を1行書くだけ。

## PUBLIC リポでの支払い系の書き方
- 書いてよい：エラー種別（CREDIT_CARD_INVALID）、日付、「海外で使えるカードに替える」等の一般的注意
- 書かない：カード番号・名義・請求先住所・カード会社名（どのカードかが特定される）
- 追加行に対し `[0-9]{4}[- ]?[0-9]{4}…` / `〒` / 電話番号パターンで機械スキャンしてから commit
