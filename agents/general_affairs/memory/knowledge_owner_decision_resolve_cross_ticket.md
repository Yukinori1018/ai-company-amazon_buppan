# 社長判断の解消は「同じ答えで消える他チケットのお願い」まで拾う（2026-10-05）

- 事例：T-20260930-001 の「電話番号は携帯でよいか」が承認 → T-20260929-001 の「電話番号をお知らせください」も同じ番号で解消。
- 解消扱いにしてよいかの判定：そのチケットで**残っていた不足が番号だけか**を本文で確認（T-20260929-001 は送信承認を 10/04 に取得済み・フォーム必須欄だけが空だった → 解消）。
- 手順：owner-tasks.md に新しい「更新N」節（残りのお願い表＋解消した表）を先頭に足し、最終更新行を書き換える → チケットのログ1行・updated_at → Notion カードは結果要約の🔴行を1行の解消文に置換＋UpdatedAt。
- 電話番号そのものは memory reference_business_accounts のみ。リポ・Notion には「社長の携帯」とだけ書く（PUBLIC リポ）。
