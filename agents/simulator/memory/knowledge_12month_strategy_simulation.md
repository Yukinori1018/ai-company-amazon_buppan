# 12ヶ月戦略案（複合戦略）を読むときの型 — T-20260912-005 / 2026-09-13

タケシの案B（卸→ゲート解除→本丸→独占/OEM）を12ヶ月モンテカルロで仮想実行した記録。タケシ 12ヶ月中央 月商120万 → マサル 20万。以後、複数レーンの12ヶ月案はこの順で読む。

## 1. 見落としやすい穴（今回、全部叩き台にあった）

| 穴 | 実例 | 確かめ方 |
|---|---|---|
| **月商の内訳が、自分の置いた成立率と送信数から派生していない** | 内訳「独占4 SKU×10万＋OEM 4 SKU×8万＝72万」は成立10社超の前提。置き値（送信110社・成立率3%）では成立2〜3社 | 成立社数＝送信数×成立率×（ゲート/確約の脱落を引く）を先に出し、独占・OEM はそこから派生させる。派生していない内訳は「願望」 |
| **律速の誤認（資本 vs 成立数）** | 「800万に届かないのは資本が理由」と書いていたが、12ヶ月では資本の感応度ゼロ。現金の中央113万＝資本のほとんどが遊ぶ | 感応度表で「資本」を振る。効かないなら律速は別。資本の判断は成立数に条件付けする |
| **撤退条件が中央シナリオで踏まれる** | 1/15 初回入金0（89%）・9/12 月商30万未満（82%）は中央そのもの | 各判定日の条件を MC で「中央で踏む確率」に翻訳する。50%超なら撤退条件ではなく予測 |
| **固定費が利益率の判定を壊す** | 大口＋Keepa＋セラースプライト＝月28k。月商20万×10%では構造的に赤字 → 「利益率5%未満」条件を中央で踏む | 利益率の撤退条件は固定費を除いたレーン利益率で置く。有料ツールの契約は「相手ができてから」に条件付け |
| **返信率を先行 KPI にしている** | 返信率は成立に直結しない（見積到達率・断られた理由の方が先行指標） | 先行 KPI は「分母が大きく、成立に因果がある」指標だけ |
| **12/15 の判定が評価不能で終わる** | 「累計14社で見積0」の前に「12/15 までに14社送れない」が57% | 判定条件の前提（送信数）が満たされる確率を先に出す |
| **独占の前提（メーカーのブランド登録）を見ていない** | 独占を取っても、メーカーが未登録なら卸店経由の相乗りで3手目に崩れる（確度40%） | 独占提案の前に、相手のブランド登録の有無を判定する（閲覧のみ・0円） |

## 2. この会社の置き値（12ヶ月モデル。次回も流用可）

- 段の所要日数は `T-20260912-001/07_mc_最終版.py` と同じ三角分布（送信→初回入金 中央93日）
- 社長の §4.1 の滞留は「月次の独立な滞留20%」ではなく「**12ヶ月を通した低稼働レジーム30%**（消化率×0.35・滞留50%）」で置く。前科＝4ヶ月で送信0通。月次の滞留は遅れにしかならず中央値に効かない
- 本丸のゲートあり70%×確約されず20%＝成立の14%が「成立しても売れない」で脱落
- 資本キャップ＝在庫に回せる資本×1.2（在庫1.5ヶ月・原価率0.65）。固定費は別枠（社長が月額として払う）
- 相乗り: 価格年−5%、6ヶ月で競合+1（取り分×0.8）
- OEM: 3割は月0〜1個で終わる。ロット3〜10万
- 計算: `deliverables/T-20260912-005/01_mc_案B.py`（約3分）

## 3. 感応度の順位（案B・12ヶ月）

取り分（幅23万）＞成立率（14万）≒SKU/社（14万）＞アミノのゲート（4万）＞消化率・独占率（2万）＞事故（1万）＞OEM・資本・返信率（0）。

## 4. 社長ルールとの照合で効いたもの

- 「あらゆる方法を検討」（9/13）への答え方: 捨てた選択肢を**採用推奨ではなくオプション価値の表**で出す（中央への影響／悲観の裾への影響／社長の一手・費用／読み）。「負」の選択肢も、社長指示への回答としては書く。案の候補として並べるのとは別
- 「ありえない案を並べない」との両立: 表の見出しに「採用推奨ではない」を明記し、§7 で照合を示す
- 12ヶ月で現金が増えないことは、承認前に明示する（楽観でも+4万）。「稼ぐ期間」でなく「成立率と取り分の実測を買う期間」と言い換える
