タケシの案B（卸→ゲート解除→本丸→独占/OEM）を12ヶ月モンテカルロで仮想実行した記録。タケシ 12ヶ月中央 月商120万 → マサル 20万。以後、複数レーンの12ヶ月案はこの順で読む。

## 1. 見落としやすい穴（今回、全部叩き台にあった）

| 穴 | 実例 | 確かめ方 |
|---|---|---|
| **月商の内訳が、自分の置いた成立率と送信数から派生していない** | 内訳「独占4 SKU×10万＋OEM 4 SKU×8万＝72万」は成立10社超の前提。置き値（送信110社・成立率3%）では成立2〜3社 | 成立社数＝送信数×成立率×（ゲート/確約の脱落を引く）を先に出し、独占・OEM はそこから派生させる。派生していない内訳は「願望」 |
| **律速の誤認（資本 vs 成立数）** | 「800万に届かないのは資本が理由」と書いていたが、12ヶ月では資本の感応度ゼロ。現金の中央113万＝資本のほとんどが遊ぶ | 感応度表で「資本」を振る。効かないなら律速は別。資本の判断は成立数に条件付けする |
| **撤退条件が中央シナリオで踏まれる** | 1/15 初回入金0（89%）・9/12 月商30万未満（82%）は中央そのもの | 各判定日の条件を MC で「中央で踏む確率」に翻訳する。50%超なら撤退条件ではなく予測 |
| **固定費が利益率の判定を壊す** | 大口＋Keepa＋セラースプライト＝月28k。月商20万×10%では構造的に赤字 → 「利益率5%未満」条件を中央で踏む | 利益率の撤退条件は固定費を除いたレーン利益率で置く。有料ツールの契約は「相手ができてから」に条件付け |
| **返信率を先行 KPI にしている** | 返信率は成立に直結しない（見積到達率・断られた理由の方が先行指標） | 先行 KPI は「分母が大きく、成立に因果がある」指標だけ |
| **12/15 の判定が評価不能で終わる** | 「累計14社で見積0」の前に「12/15 までに14社送れない」が57% | 判定条件の前提（送信数）が満たされる確率を先に出す |
| **独占の前提（メーカーのブランド登録）を見ていない** | 独占を取っても、メーカーが未登録なら卸店経由の相乗りで3手目に崩れる（確度40%） | 独占提案の前に、相手のブランド登録の有無を判定する（閲覧のみ・0円） |

## 7. 2周目（2026-09-13）— 収束 Yes に至った型と、次から使う数字

タケシ2周目（週10通・成立社数から引き直し・撤退条件13本）を検証し、**収束 Yes（条件付き・確度70%）**。1周目20万→2周目44万の差は全部「波」（105→343通）。私とタケシのモデル差（卸拡張+7万 vs 低稼働20%+5万）は相殺した。

| 学び | 次から |
|---|---|
| **収束判定は「仮想で詰められる不確実性が残っているか」で切る** | 残った脆弱性（社長の週1ブロック・週60社ライン）は実 Do の最初の8週でしか分からず、外れても A に縮退できる＝致命傷でない。この状態なら3周目を回さず「収束 Yes・統合時の反映事項 R1〜R5」で閉じる。差し戻しは「タケシの再作業が要るか」で分け、要らないものは反映事項として秘書に渡す |
| **実測分布を投入しても中央は動かない。動くのは裾** | 取り分の経験分布（中央0.8〜1.1・平均1.3〜2.0）は右の裾（×6〜16）が平均を押し上げるだけ。裾の出所は「公表月販なし→25個の置き値」と「現在オファーなし」の行。**社長に見せる中央は固定1.0倍、実測分布は上振れの併記**。経験分布を使うときは「現在オファーあり」に絞った変種を必ず並べる |
| **成立が少ない世界では取り分は効かない** | 成立率1.5%では取り分の置き方 A〜C で 22〜24万に収束。感応度は「成立率 ≫ 取り分」に順位が入れ替わる（1周目は送信105で成立2社だったので取り分が1位に見えた）。律速の順位は波の大きさで変わる |
| **北極星の3条件同時は44〜48%＝コイン** | 達成目標にしてよいのは「うちの手で動く数字」（累計送信）だけ。成立数・取り分は測定値。同時達成をKPIにすると、正しい世界（3%）の4割が失敗扱いになる |
| **撤退条件の誤発動率を「通常レジームのみ」で出す** | Z-3「各月<50%が2ヶ月連続」は通常レジームでも40%誤発動（月次の独立滞留20%の積）。「3ヶ月合計<50%」なら33%／低稼働100%。撤退でなく計画修正のトリガーなら誤発動の害は小さいが、名前を「撤退」にしないこと |
| **累計送信数と成立率の判別力はポアソンで先に出す** | 120通では1.5%と3%は区別不能（成立≤1: 54% vs 19%）。300通で3段階（1%台／3%前後／5%以上）。「Nで測れるか」は毎回この表から |
| **ブランド登録の実測は独占の「崩れる筋」に直結** | 20社中登録済み1社 → 崩れる筋 24→34%。A5（代理運用）先行で13%だが+3ヶ月遅れ＝12ヶ月内の独占は36→20%。独占は24ヶ月の変数なので「12ヶ月を削って崩れない独占」を選ぶ。**A5 の前提「相手が商標を持つ」は J-PlatPat（0円）で先に確認** |
| **条件付き資本は中央に効かず、現金の床を動かす** | 資本を「成立3社」条件にすると、成立前の固定費を資本が吸えず最小現金 P10 が +6万→−20万。ツールも条件付きにして −10万。「固定費は資本10万と別枠で12ヶ月20〜30万」を承認前に明示する |

### 2周目の並行担当（ハルオ 02）で動いた事実

- **Amazon ブランド登録は商標「出願中」で可**（brandservices・2026-09-13）。A5（代理運用）の遅れは登録完了（6〜10ヶ月）ではなく出願（+2〜4ヶ月）で読む。メーカー名義で出願が必須（当社名義は商標法4条で不可・取引を壊す）

- 今回も commit 直後に着いた。**commit 前に `git status` で並列担当の未追跡ファイルを見て、着いていれば grep で自分の変数名（ブランド登録・商標・SP-API 等）を引いてから出す**。補記1節で済んだ（2回目の再発）
