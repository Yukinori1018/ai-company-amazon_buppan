## 3. 単位採算の型（アパレル・相乗り）

- **原価上限は k から逆算される**ので、「k が下がると赤字」は**上限ちょうどで買った場合だけ**の話。
  **損益分岐 k は買値で動く：上限×1.00 → 0.685／×0.90 → 0.637／×0.80 → 0.589。**
  → タケシの「上限の80%以下なら点数を増やす」ルールは、実は**点数の話ではなく k 耐性の話**だった。
- **2,500円の崖（8.4%→12.4%）には「置いてはいけない価格帯」がある：2,500〜2,627円。** 2,500円と同じ手残りになるのが2,627円。
  → **現在価格が2,630円超の ASIN は相乗りの候補から外す**（崖の下に置くと自分が相場を10-16%下げる）。
- **パック品（4枚組・3枚組）は卸率で構造的に落ちる。** 原価上限は**パックの上代**と比べる。卸率67%で必要な「現在価格÷上代」は単品1.82倍・4枚組1.71倍。パックは1枚あたりが安く売られるので届かない。**単品/パックを見分けずに候補表に混ぜると柱が折れる。**

## 4. 「点数」の読み方（今回の再発見）

12点は**10点要件からの逆算**で、売れる量からは出ていない。取り分推定（月67個）の**25%でも12点は完売**＝取り分の推定値がモデルに効いていない。
**5日で切れる在庫では価格も回転も測れない。在庫切れは観測ではなく空白。**
→ **要件から出た点数と、売れる量から出た点数を必ず両方書く。** 一致しないときは「予算で決まっている」と明記する。

## 5. 確率の重心がずれる典型

タケシは**価格崩れを過大（30%）、出品不能を過小（5%）**に置いていた。実勢は 12〜17% と 41%。
**4SKU に分散していると1SKU の価格崩れでは全体が赤字にならない**（出品できた世界の黒字確率99.7%）。
→ **分散している案では「価格」より「そもそも売り場に立てるか」を先に確率化する。**

## 6. 手続きの学び

- **他部門が確定させた事実を、前提としてそのまま使う。**今回は請求書名義（SD＝ラクーンコマース）が 01 で確定済みで、タケシの撤退条件 9/24 は判定前から結論が出ていた。**「未確認事項」の表を受け取ったら、他の成果物で既に確定していないかを先に照合する**（`feedback_check_ledger_before_reporting` の自分版）。
- **社長の直近判断でタケシの前提が壊れていないかを必ず確認する。** 今回は 2026-09-21「本人確認は数日様子見」で §6 第0週①が無効化されていた。**タケシの文書は前日の世界で書かれている。**
- 社長の既決（9/20 SD 照会は見送り）に逆らう推奨を出すときは、**「決定の再考をお願いする形になります」と明記**し、下振れ（藪蛇・確度15-20%）と代替（別販路の届け出）まで並べる。判断材料を揃えずに再考を求めない。
