## 2. 手配型（自分は現場に立たない型）の律速は「レビュー」

- 鶏と卵は**ガイドではなくレビューで詰まる**。ガイドは月10件の打診で1人立つ（段1到達62%・タケシの55%は妥当）。**詰まるのは需要**：レビュー0件の新規出品に予約が入らない → 催行がない → レビューが増えない。

## 3. 「他社が検品した人だけを母集団にする」の効き方

- 条件自体は正しい（★3以下の発生 34% vs 無名ガイド 47%＝13pt改善）が、**決定的ではない**。
- **応じるのは「レビューはあるが予約が埋まっていないガイド」**＝他社の客付けで選ばれていない側。**検品の信号が弱い方向に選択が掛かる。**
- **母数は有限で撃つほど劣化する**（メーカー名簿と同型）。標的都市で80〜300人。月10件×24ヶ月=240件で尽きる。→ **有限資源を前提にしたレーンは「母数を増やす手」を同時に設計させる。**
