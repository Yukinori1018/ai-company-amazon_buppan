## 学び（次回も使う）

1. **「倍率」で名簿拡張を語る案は、何で割り引いたかを分解する。** v2.1 は②③の効き目を成約率だけで割り引いた（0.5〜1.5倍）。抜けていたのは①売れ続ける率（自分で0.7倍と置いていた）②1社あたりの売れる量（①b は月20〜49個の棚・②③は未出店）。**社数の倍率4.3 → 売れる量で測ると約3倍。**
2. **相手の補間は、まず同じ計算器で再現する。** 線形補間の世界を作ると 88.5/46.0万で一致 → 争点は計算でなく前提（質と時期）だけ、と言えた。区分に分けると61.6/29.1万。**差のほぼ全部が1つの置き値（②③の売れる量）** → その置き値を直接測る判定線（G2c）を作るのが正しい応手。
3. **判定線は「測る変数が最大の不確かさと一致しているか」を見る。** G2b は成約率を絶対値「2社」で測った。①の成約率が1〜4%と振れるので、②③の良し悪しと①の良し悪しが混ざり検出9%。**比率（②③÷①）で測り、売れる量は別の線で測る。**
4. **判定時期は相手自身の送信順で計算し直す。** 「中央2027-01〜02」は、②③を①aの後に回す送信順と矛盾（実際は2027-08ごろ）。
5. **同じ案に中央値が2つ並ぶのは最優先の修正点。** v2.1 は §0 に23万（1周目の仮置き）、§3-0 に89万（補間）を並べていた。社長は大きい方を読む。
