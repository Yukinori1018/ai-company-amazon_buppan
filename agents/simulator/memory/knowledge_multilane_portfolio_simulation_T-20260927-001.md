## 2. 「同じ接触に複数オファーを載せれば追加時間0」の潰し方（再発する主張）

| 分解 | 結果 |
|---|---|
| 希釈（1通3択で返信率が落ちる） | ▲11万 |
| **後工程（見積45分／提案書120分／要件定義180分は共通化できない）** | **▲12万** |

- **送信は共通・後工程は別物**。「追加時間0」は送信工程だけを見た主張。**必ず後工程を種類別に積む。**
- **希釈と後工程は効き方が違う**：時間が余っている世界では希釈が主犯、**時間が詰まっている世界では後工程が主犯**（送れないので返信率はそもそも効かない）。切り分けて出す。
- 代替案は否定ではなく**2段化**（本文は1オファー／署名に1行）。これで希釈は消え、後工程は反応した相手だけに絞れる。

## 3. 「観測値ゼロの単価」は中央値ではなく上側を作る（重要）

②代行・③受託は**単価を半分にしても中央値がほとんど動かない**（44.4 → 43.7万）。理由＝**中央世界では1社も立っていない**（P50 0社）。
→ **中央世界で社数0のレーンは、主力に置けない。** 単価の妥当性を議論する前に「中央で何社立つか」を見る。
→ 逆に言うと、この種のレーンは **P90 を作る道具**としては正しい。計画書では「中央／P90」の2列で書かせる。

## 4. 相手の置き値をそのまま入れると、相手の結論より大きく出ることがある

## 5. 判定線の同型失敗は今回で4回目

- 「2027-06 段3が0社」＝**発動82%・偽陽性73%**。T-20260912-005／04／13 と合わせて**4回目**。

  → **判定線は「その後に設計が変わったら再測定する」。** 線は世界に固定されていない（05 §8-3 の再確認）。

  → 代替は**受注より6〜10倍多く出る中間指標（商談化率）**。早期警戒は「件数×速度×定義の固さ」（15 の型）。
