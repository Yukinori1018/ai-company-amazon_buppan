# 脇線（別の売り場）の案を読む型 — NETSEA×メルカリShops（T-20260915-001・2026-09-15）

タケシ推奨の案3（JAN なし雑貨をメルカリShops で5 SKU×20個）を仮想実行した。判定は差し戻しで、方向は残した。タケシの見立ては黒字70%・期待値+0.4万。私の読みは黒字 約40%（置き値の世界の重み付け）。

## 1. 見落としやすい穴（今回、全部叩き台にあった）

| 穴 | 実例 | 確かめ方 |
|---|---|---|
| **売価を卸値の倍率で置いている** | 卸×2.5。JAN なし品の参考上代は卸×1.56（中央）＝上代の1.6倍で売る前提 | `out/` の行データで「参考上代÷卸値」を、案の対象の母集団（JAN なし・条件を満たす品）に絞って出す（1分）。売価は「同じ品の売れ値」で置き直させる |
| **フリマの売れ値は送料込み** | 上代＋送料が送料込みの売れ値の中心になる。卸×2.0前後 | 売れ値の中心＝(上代倍率×卸＋送料)÷卸。卸値が高いほど倍率は下がる。定数で置かない |
| **需要の証拠が強いほど棚は混んでいる** | 売り切れ件数110件以上＝同じ NETSEA 品の出品者が多い。取り分5%は高め | 足切りの値と取り分の置き値を別々に信じない。セットで悲観を置く |
| **足切りの値が、悲観で回転6ヶ月を破る** | 110件×1.5%＝月1.7個→20個に12ヶ月 | 足切り×悲観の取り分×6ヶ月 ≥ 1 SKU の数量 になっているかを確かめる |
| **損益を決める変数の取り違え** | 依頼の論点は代行費だったが、効くのは売価とサイズ（ネコポスに入るか） | 損益分岐の表を「売価の倍率×費用」の2軸で作る。1軸で見ると取り違える |
| **§4.1 一覧の抜け** | 発送代行の契約（規約同意）が社長の §4.1 に無かった | 新しい売り場・新しい業者＝規約同意が1つ増える。一覧を数え直す |
| **代替案の入口確率を見ていない** | 案2を案3の代替に置いていたが、案2は大手ブランド品で L1-c・ゲートにより入口で止まる確率が55% | 「通らなければ案Xへ」の案Xの入口確率を必ず出す。低ければ代替は「休止」 |
| **倍率で置く売価は、失敗の原因を分けられなくする** | 需要の読みの外れと値付けの高さが混ざる | 検証の設計は「60日で測る係数を1つにする」 |

## 2. 手順（別の売り場の脇線を読むとき。次回も流用）
1. 母集団の実測（`out/`）で、売価の前提（上代比）と卸値の帯の分布を先に出す
2. 1点の損益を「売価倍率×出荷費用」の格子で出し、代行費の損益分岐を倍率で示す
3. MC は「証拠が普通の世界／弱い世界」を分けて、現金ベース（6ヶ月の残在庫は0評価）で回す。重み付けは最後に
4. 社長ルール（月数個・6ヶ月・ありえない・成功する気・12ヶ月キャッシュ）を表で照合する
5. 社長の手を段ごとに数え、本線の §4.1 と時期が重ならないか見る
6. 直した案を同じ乱数で回し、ゲートの通過率（揃う SKU 数）を別に出す

## 3. 学び
- 私の最初の MC は、競合の値下げを入れず、残在庫を原価で評価していたため、全世界で黒字100%と出た。**P が100%と出たら、下振れの経路が入っていないと疑う。** 値下げ（確率50%）と現金ベースを入れたら、弱い世界は6%まで落ちた
- 修正案のモデル値（99%）は、置き値の取り分をそのまま使っている。モデル外の下振れ（新しいショップの転換率など）を加えて70%と読み、本文でも2つを分けて書いた
- 公開版（PUBLIC）は比率だけにし、代行費の損益分岐も「置き値に対する倍率」で書いた。金額は out/ に置いた
