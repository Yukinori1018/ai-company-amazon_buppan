## 2. 学び

- **実践者の率を借りても、母数は借りられない。** 成約率・1社月利は実践者の数字で埋まるが、母数は当社のリストの実数でしか決まらない。実践者の率（4%・1万）でも母数994なら12ヶ月目の月利は中央16.5万（06 は母数4,000で38万）
- **母数が小さいとき、送信を遅らせるのは逆効果。** 994社で 週70通 65%／週30通 42%。12ヶ月の窓では早く送った方が良い。効くのは名簿の補充（条件を広げる）。「母数が少なければ週40通」は直す
- **2通目・補充は P を0〜3pt しか戻さない。** 遅い成約はテスト費と在庫を積むだけで窓の中で売れない（12ヶ月に効く送信は最初の5〜6ヶ月＝約1,500通、の再確認）
- **「苦情1件で全停止」は、ほぼ確実に踏む線。** 苦情率0.1〜0.5%/通なら1,000通で1件以上 63〜99%。安全ルールの閾値も base rate に翻訳してから置く（撤退線と同じ作法）。段階（1件＝その文面・経路を止める／300通で3件・公的通報＝全停止）に替えた
- **運転資金の倍率は計画の在庫前提から組み直す。** 06 の r=7.5 は自身の「在庫1.35ヶ月」と矛盾（組み直すと10.7）。この差で「発注継続の実質現金>0」6%→0%
- **利益率10%の相乗りは、値崩れの感応度が10倍。** 売価−2%で利益−20%。離脱率（取引が切れる）とは別に、続いている取引の目減りを置く
- **物差しの変更は、言い換えずに並べる。** 清算価値＝社長条件の緩和。社長に見せる1行は「現金は中央で約50万減って在庫に変わる／現金を増やすなら夏に発注停止で55〜64%／在庫込みなら56〜65%」の形（9/14 の却下の教訓の再適用）
- **母集団の割り引きは率と母数のどちらかにしか掛けられない。** ブランドストア持ちを外す＝母数が約1/4（994→約240）、外さない＝率が下がる。両方に掛けると二重、どちらにも掛けないと楽観
