# バリエーション同士のセット化は明文で不可／キャラクター品セットの権利者リスク／GS1 の住所公開

## 1. 再利用できる結論

| 論点 | 結論 | 決め手（逐語・Product Bundling Policy SG 版） |
|---|---|---|
| **バリエーション同士（キャラ違い・色違い・サイズ違い）のセット化** | **不可（明文違反）** | "**If an item is a variation of a parent product, list it as a variation within the parent product's family and not as a bundle.**" 直前に multi-pack 条項が同じ構造で並ぶ＝**「セットで扱ってはいけない類型」の列挙** |
| complementary 要件を主根拠にすること | **弱い。やってはいけない** | 定義の後段 "**or provide convenience to the buyer by purchasing them together**" が広く、「2キャラまとめて買えて便利」で反論されて終わる。**争いの余地がない変奏条項で決着させる**のが正しい構成。complementary は補強に回す |
| 出品者独自セットのブランド欄（JP） | **「ノーブランド品」登録**（二次・確度中） | セラーフォーラムの出品者が G201645990 から引用「出品者が独自に作成されたセット品は、『ノーブランド品』として登録して下さい」。SG 版の "branded according to the highest priced item" と食い違う＝**JP 実務はノーブランド**（前回メモリの推測が裏付いた） |
| キャラクター品のセット自作 | **「新しい商品の体裁を作った」と見られる。認定はカタログの外形だけで成立する** | ノーブランド品として登録された、キャラが写った当社名義のページ＝**正規品なのに出所表示が消えた状態**。権利者の監視が最も強く反応する形 |
| 真正品の素売りとの差（法的な分かれ目） | **譲渡権は消尽するが複製権は消尽しない** | 著作権法26条の2第2項1号（譲渡権の消尽）。外装にキャラ図柄・ロゴを印刷＝21条の複製／商標法2条3項1号「包装に標章を付する行為」。**開封の有無とは無関係の軸** |
| セットの画像 | **自前撮影が規約上必須**＝知財リスクが相乗りより上がる | "Images of representative or similar products are not permitted." 自分が公衆送信の主体になる |
| 同一キャラ N 個パック | **条件付き可。ただし既存 ASIN に相乗りする形に限る** | multi-pack 条項で単品（IPQ）扱い。**該当シリーズは N 個パック ASIN が既存**（B0HF7QRC5N 等）＝新規カタログ・固有 JAN・GS1 が全部不要。相乗り時の固有リスクは「包装仕様の相違」申立て |
| 「メーカー包装を開けず外箱＋固有 JAN」 | **セット可否を変えない** | 開封の有無が効くのは PL 2条3項1号・薬機法13条・品質保証機能。**セット可否の決め手は「バリエーションか」「誰のブランドか」**。むしろ不透明な外箱は印刷の誘引を生んで危険を増やす → **外装は透明に限る** |
| 制裁の明文 | 通告なしの削除／アカウント停止 | "may result in **removal without notice**... **account suspension, or both**" |

## 2. GS1 事業者コード（一次・2026-09-20）

出典：https://www.gs1jp.org/code/jan/jan_apply.html ／ https://www.gs1jp.org/code/jan/important_notes.html ／ https://www.gs1jp.org/code/jan/gtin_rules/

- **費用（年商1億円未満＝区分Ⅶ・税込）**：3年払い 11,000＋16,500＝**27,500円** ／ 1年払い 11,000＋6,050＝**17,050円**。有効期間は初回利用月の翌月から1年or3年・更新必要
- **期間**：入金確認後**3営業日以内**にメール通知。実務1週間
- **個人事業主で申請可**（「事業者単位（法人または個人）で貸与」）
- 🔴 **登録情報は GS1 サイトで公開される**：①コード ②事業者名（個人事業主名・屋号）③**本社所在地** ④基本GLN ⑤URL → GS1 Japan Data Bank / JICFS/IFDB / Verified by GS1 / GLN検索。**個人事業＝自宅住所が公開**。社長の本人特定情報除外方針（CLAUDE.md §6）と正面衝突 → **§4.1 に準ずる論点として社長判断へ上げる**
- **GTIN が変更になる10の基準**：基準1（新商品）・**基準9（あらかじめ決められた組み合わせ商品の中身を変更）**＝新しい GTIN。Amazon の「構成変更不可・変更なら新 JAN」と一致
- 🔴 **GS1 は GTIN を振る主体を「ブランドオーナー」と書く。**当社コードで振ると GS1 の DB に事業者名 Satoy Select が載る＝**「サンリオ商品の新しい組み合わせ」を自社名義で定義する立場に立つ**。これが「新しい商品の体裁」の技術的裏付け
- **回避策の候補（未確認・サトルへ）**：Amazon の**製品コード免除（UPC免除）申請**が通れば費用と住所公開が同時に消える。優先確認

## 3. 取引条件の読み方（丸進の事例）

- 「**ブランドイメージ保持にご協力頂ける小売店様のみ**」＝**定義のない裁量条項＝相手方が自由に解釈できる条項**として読む。当社に反論の足場はない
- 「貴店の販売展開によっては…お取引出来兼ねる」＝**解除条項で、発動条件が当社の行為そのもの**
- 丸進は仕入先に「（株）サンリオ」を明記する総代理店＝**当社の一手が丸進のサンリオ取引に跳ねる**。仕入れ先を失うと「**ゲート解除用の請求書を出せる相手**」も同時に失う（代替が最も難しい）→ 発生確率中×影響大×不可逆大＝**最上位アラート**
- 得られる対価は FBA 配送代行 415 円の分散だけ（値上げは実測で中央値1.000）。**対価が釣り合わない**

## 5. 型として固定したもの

1. **「セットにしてよいか」は complementary から入らない。まず「バリエーションか」「マルチパックか」を見る。**規約は最初に類型の振り分けをしていて、そこに入れば議論は終わる。解釈条項（complementary）は最後の補強。
2. **カズヨの暫定見解は「結論○・根拠の主従が逆」というパターンが出る。**結論が合っていても根拠が弱い場合は**明言して差し替える**（今回そうした）。「正しい」で済ませると次に押し返されたときに崩れる。
3. **開封の有無で切れる論点と切れない論点を混ぜない。**開封＝PL・薬機法・品質保証機能。セット可否＝カタログ構造と出所表示。社長・秘書は前者で後者を解決しようとしがち。
4. **既存 ASIN があるなら相乗りが最も安い。**新規カタログ作成は「固有 JAN ＋ GS1 27,500円 ＋ 自宅住所公開 ＋ 自前撮影 ＋ ノーブランド登録」を全部呼ぶ。**規約判定の前に「その ASIN は既にあるか」を確認すると、論点が半分消えることがある。**
5. **可逆性を確保できる案を優先する。**①（開封せず束ねるだけ）は在庫を単品に戻せる。②（別商品の組み合わせ）は戻せない。**同じ「条件付き可」でも、撤退時に現金が戻るかで順位が変わる。**
6. **権利者の強さで「型の検証をするブランド」を選ぶ。**サンリオ（登録商標2万件超・専任法務・テイクダウン実績）で新しい型を試すのは最も高い授業料。**型はグンゼ等の緩い相手で検証してからサンリオに持ち込む。**
7. **個人事業の登録・公開系は「自宅住所が出るか」を必ず確認する。**GS1 がそうだった。古物商・インボイス・GS1 と、住所公開を伴う登録が続くので、以後は登録系の依頼で定型チェックにする。
