# Amazon Section 3（ABSA違反）／KYC 停止 — 法務の型

初出：T-20260826-004（2026-08-28 ハルオ）。当社の**事業存続に直結する最重要案件**。同種の通知を見たら真っ先にここを読む。

## 1. 「ABSA 違反」通知は不正の認定ではない（が、安心材料でもない）

- ABSA **Section 3(b)** 原文：`your account has been, or our controls identify that it may be used for deceptive or fraudulent, or illegal activity`
- 画面の日本語「〜に関与するために**使用された可能性があります**」は、この "our controls identify that it **may** be used" の訳。
  → **Amazon が事実認定した文ではなく、自動検知がフラグを立てたという条文の引き写し。**
- **一次情報は取れない。**2026-08-28 に 5 経路（amazon.com / amazon.ca の nodeId=1161302、sellercentral の G1791 / G521、amazon.ca ヘルプ）を試して全滅（503 またはログイン必須）。
  → 二次情報3件（amazonsellerslawyer / riverbendconsulting / e-cabilly）で文言一致を確認して代用した。**この壁は既存メモ `knowledge_amazon_agent_policy_2026.md` と同じ。Amazon 規約はログイン済みブラウザでしか読めない。**
- 実務上の特徴：**理由が開示されない／書面の弁明が効きにくい／appeal path が不明瞭。**「無実だから通る」で臨むと落ちる。防御は行為の潔白の主張ではなく、**身元証明の一字一句の整合**に絞る。

## 2. 新規・無販売アカウントでも Section 3 は立つ

セラーフォーラムに、出品 0・販売 0 の新規アカウントへ同一文言の Section 3 ＋ビデオ面接要求が出た報告が複数ある。
→ **「うちは何もしていないのに」は珍しい事態ではない。** 当社は出品 0 / 販売 0 / 違反 0 / 未払い 0 でこの通知を受けた。

## 3. 却下理由が開示されない時の攻め方（成果物1で採用した型）

「書類を再提出してください」の一般回答で終わらせないため、照会文は次の構造にする。

1. **不備箇所の特定を明示的に要求**（「どの書類の・どの項目が」）＋**開示できないなら理由を明記せよ**と書く
2. **再提出の導線**（URL / 画面 / ケース添付の可否 / 書類仕様）
3. **Amazon 側の不履行を事実として記録**（案内メール未着・72h 超過。感情を書かず日時と画面表示だけ）
4. **期限の起算日と、待機期間が算入されるかを聞く**（相手都合の待機で期限が切れる事故を防ぐ）
5. **未回答の再質問は「◯月◯日に伺った件の再掲」と明示**（重複送信＝審査列の最後尾、を避ける保険）

各項に番号を振り「番号を付けて個別に回答せよ」と締める。これが回答の取りこぼしを最小化する。

## 4. 日本の個人事業主に固有の詰み所

| 論点 | 内容 |
|---|---|
| 会社登記書類 | Amazon は必要書類に挙げるが、**個人事業主には存在しない**。開業届の控え（e-Tax 受信通知）で代替できるかを**事前に書面で確定させる**。無確認で面接に臨むと書類不備で落ちる |
| 銀行明細 180 日 | 「**出品用アカウントに登録されている口座**」の明細が必要。口座を変更した直後は、新口座に 180 日分の履歴が無いという衝突が起きる。変更前に確認すべき |
| 住所の分割 | 日本式住所を Address line 1/2 に割る際に建物名・部屋番号が落ちるのが最頻出の不一致 |
| 氏名 | ローマ字/漢字、姓名順、ヘボン式の綴り（OH/O, TSU/TU）で 1 文字ずれる |

## 5. 面接で絶対にやらせないこと

- **事実と違う説明をさせない。**未出品・無販売は「まだ 1 点も出品していません」とそのまま答えさせる。実績があるかのように答えると、**Section 3 の疑いを自ら裏づける証拠になる。**
- 代理人・通訳業者に代行させない（アカウント共有を疑わせる）。
- 関連アカウントの存在を隠さない。Section 3 で最も重く扱われる。
- 焦って 2 つ目の出品用アカウントを作らない（連鎖停止・不可逆）。
- 謝罪・生活困窮の訴えを入れない。判定材料にならない。

## 6. 不可逆な選択肢の扱い

「北米アカウントを閉じて日本店だけ残す」は**現時点で NO**。サポートが「CA 復元が先」と明言しており、統合アカウントの閉鎖で日本店ごと失う可能性がある。
→ 検討するなら **事前にサポートへ「北米のみ閉鎖した場合に日本ストアは存続するか」を書面で取る**こと。無確認の実行は不可（グレーは原則 NO ＋ 不可逆性最高）。
