## 2. 判定の型（第三者由来ファイルが出てきたら、この順で潰す）

1. **著作物性を争わない。**文章・スライド・PDF はまず著作物（2条1項1号・10条1項1号）だと置く。争点はそこではない。
2. **当社の行為を条文に落とす。**リポに置く＝**21条（複製）**／公開状態にする＝**23条1項・2条1項9号の5（送信可能化）**。**「誰もダウンロードしていない」は抗弁にならない**（送信可能化はアップした時点で完成する）。
3. **私的複製（30条1項）を潰す。**「限られた範囲」ではないので不適用。さらに **49条1項1号** で、私的複製として作った物を公衆提示すると免罪符が遡って消える。**ここを言えると議論が一発で終わる。**
4. **引用（32条1項）を要件ごとに落とす。**公表性 ／ 明瞭区別性 ／ 主従関係 ／ 目的上正当な範囲 ／ 公正な慣行 ／ 出所明示（48条1項1号）。**ファイル丸ごとは主従関係が無い時点で終わり。**出所明示は 32条を満たす場合の付随義務であって、**単独の許諾根拠ではない**。
5. **要約・メモは別枠で考える。**最判平13.6.28（江差追分）— **アイデア・事実・創作性のない部分の同一性は翻案にあたらない**。ノウハウや数値を自分の言葉で書いたメモは原則白。**危ないのは「録画から機械的に復元した表現」「プロンプト全文」「価格表」のような、要点の摘示でなく表現の複製**。
6. **著作権で白でも、そこで止めない。**①契約違反（再配布禁止条項・録画禁止アナウンス）②不法行為（民法709条／知財高判平17.10.6 読売オンライン見出し事件の枠組み）③プライバシー・実名 ④相手の営業を直接害する情報（**限定価格・限定特典は「限定であること」に価値がある**）。**実際にクレームが来る確率が最も高いのは④。**

## 3. 技術的に必ず押さえる事実（法律より先に効く）

- **`.gitignore` に移しても Git 履歴に blob として残り、公開され続ける。**「最新版から消えた」≠「公開が止まった」。
- **履歴除去（filter-repo＋force push）は §4.1。法務は実行しない。**加えて当社は**成果物カタログが GitHub blob URL を使っている**ため、ハッシュが変わるとカタログのリンクが一斉に切れる。この副作用を必ず先に提示する。
- **Private 化は1操作・5分・完全に可逆で、HEAD も全履歴もまとめて閉じられる。**当社は GitHub Pages 未使用（2026-08-24 確認）なので対外影響ゼロ。**「可逆な手段で不可逆なリスクを消せる時は迷わずそれを選ぶ」の教科書的な場面。**
- **DMCA が最速の脅威。**権利者は訴訟より先に GitHub へ通報する。**リポジトリごと無効化されうるので、被害は当該ファイルに留まらない。**

## 4. 証拠の取り方（次回15分短縮できる）

| 目的 | コマンド |
|---|---|
| 本当に公開されているかの実証 | `curl -sS -o /dev/null -w "%{http_code} %{size_download}" -L https://raw.githubusercontent.com/<owner>/<repo>/main/<path>` — **未認証で 200 が返れば動かぬ証拠** |
| 公開期間の確定 | `git log --oneline --follow -- <path>` ＋ `git show -s --format=%ad <sha>`。**チケット本文の日付は信用しない**（本件は「2026-05月」と書かれていたが実際は 06-09） |
| **外部ミラーの有無**（＝履歴除去に意味があるかの分水嶺） | `curl "https://archive.softwareheritage.org/api/1/origin/search/<repo>/?limit=10"` が `[]` なら未収録。加えて `gh api repos/... --jq '{forks_count,stargazers_count}'` |
| PDF の正体（有料本編か配布サンプルか） | `mdls -name kMDItemTitle -name kMDItemAuthors <file>` ＋ `pdftotext -f 1 -l 6 <file> -`。**内部タイトルに「申込配布用」等の配布条件が書かれていることがある** |
| 横断洗い出し | `git ls-files <dir>` → 拡張子別集計 → **第三者の氏名・団体名で `git grep -l`**。ファイル名だけ見ても見つからない |
