## 1. 再利用できる結論

| 論点 | 結論 |
|---|---|
| 「親が違えば組める」か | **親（カタログ上の位置）ではなく商品の実体で決まる。**同じ物のキャラ違いは別の親に登録されていてもバリエーション扱い |
| complementary を一番固く満たす方法 | **メーカーの商品ページに「別売りの○○に付けられる」とある2点を組む。**解釈の余地がない（例：サンリオ おしゃぶり＆おむつセット 199460「別売りのぬいぐるみおせわセット（ベビー）のぬいぐるみに付けられる」） |
| 組む前に中身を読む | 「ぬいぐるみ＋おせわセット」はおせわセットに**ぬいぐるみ本体が同梱**で前提が崩れた。**秘書・社長の想定する中身は商品ページの箇条書きで必ず確かめる** |
| ブランド欄（JP） | Amazon.co.jp 自身が「サンリオ品＋サンリオのラッピング袋【セット】」をブランド欄サンリオで販売（確認2本・検索1ページで同型10本）。SG 版「最高額の構成品のブランド」と一致。**ノーブランド登録はやめる**。システムがブランド承認を求めたらそこで止める |
| 商品名の型（JP） | Amazon 自身：「A ＋ B【セット】」 |
| 米国の消費財セット改定 | News_Amazon：2024-10-14 施行、**米国ストア・食品/ペット/ベビー用品/H&B のみ**、メーカー作成のセットだけ可・Generic/自社ブランド不可。日本・玩具には及ばないが方向性として撤退条件に入れる |
| 自前撮影写真の著作権 | 著作権法47条の2（譲渡の申出のための複製・公衆送信）。施行規則4条の2＝32,400画素以下／コピー防止付き90,000画素以下、**または**「必要最小限度・公正な慣行」。Amazon 画像は画素数を超える＝**残る足場は解釈のみ**。未開封パッケージ正面を加工なしで撮る |
| JAN | GTIN 免除は「ブランド×カテゴリー」単位（二次）で、JAN を持つブランドは通らない見込み。利用資格の確認だけ先に見る→だめなら GS1 1年 17,050円（住所公開は社長方針で可） |
| 撤退時の可逆性 | 開封しなければ単品に戻せるが、**単品の棚が Amazon 本体のカートなら戻しても売れない**。可逆性は「物理的に戻せるか」だけでなく「戻した先で売れるか」で評価する |

## 2. 前回判定の訂正（自分の誤りの記録）

1. **バリエーション条項を「明文違反」と書いたのは強すぎた。**条文の主語は「バリエーションである商品（an item）」で、組み合わせを名指ししていない。正確には「明文の趣旨（重複出品の防止）からの解釈・強」。結論は同じでも**根拠の強さの表示を盛らない**
2. **「JP はノーブランド品で登録」は出品者の引用（二次）1本だった。**Amazon 自身の JP ページという反証が非ログイン curl で取れた。**二次の規約引用は、Amazon 自身の出品の実例で必ず照合する**

## 3. 型として固定したもの

1. **「違う親なら」系の問いには、まず「2点が一緒に使う物か／同じ物の色・キャラ違いか」に言い換えて答える**
2. **補完セットの候補は、メーカー商品ページの「別売り」「対応」「付けられる」「使える」で探す。**検索語：「〈シリーズ名〉 別売り」。メーカーの一文が規約の前段要件の証拠になる
3. **非ログインの Amazon curl で取れるもの**：商品ページ箇条書き（`id="feature-bullets"`）・販売元欄・ブランド欄・売れ筋ランク・検索結果（`/s?k=`、`data-asin` と `<h2>`）。1件3〜4秒空けて数件まで。カート保持者はスナップショット扱い（§3.3 の3点確認の代わりにしない）
4. **件数を書くときは「確認した数」と「見えた数」を分ける**（今回「15本以上」と書きかけ、実際は10本・確認2本だった）
5. グレー判定でも §3.1 に従い「やるならこの形で」を必ず付ける。リスクシナリオ表は**確率・影響・不可逆性・対応**の4列で書くと3点セットが1表で済む
