# 蛍光ランプ（水銀含有）を仕入れて FBA で売るときの法務チェック

初出: 2026-10-04 / T-20261004-001 タスク5（DNライティング FLR1212T6EXD・B008FIPMP2）。判定は**条件つき可**。
成果物: workspace/output/agent_output/T-20261004-001/legal_fluorescent.md

## 1. 水銀規制は「販売」を止めない（一次：環境省 https://www.env.go.jp/chemi/tmms/lamp.html ）
- 一般照明用の蛍光ランプは、2024年の水銀汚染防止法施行令の改正で全て「特定水銀使用製品」になった。禁止されるのは**製造と輸出入だけ**
- 直管形は **2028-01-01** から禁止。**ハロりん酸塩系だけ 2027-01-01** から（＝三波長形かどうかで1年違う。型番の EX- は三波長形。メーカーの製品ページで確認する）
- 原文：「蛍光ランプの使用・販売・購入は禁止されません」→ 国内の在庫を国内で売るのは、禁止開始の後でも適法
- 経産省の特設ページ（meti.go.jp/policy/chemical_management/mercury/fltokusetu.html）は**404になっていた**。環境省のページを一次情報にする

## 2. 照明は PSE を必ず当てる（依頼に無くても）
- 施行令 別表第二（九）「蛍光ランプ（定格消費電力が40W以下）」＝丸PSE。販売者には27条1項がかかる（knowledge_pse_denan_reseller.md）
- e-Gov 法令API `https://laws.e-gov.go.jp/api/1/lawdata/337CO0000000324` で原文が取れる（METI の品目一覧ページも404だった）

## 3. Amazon 側：名指しの禁止は無いが、包括条項と廃棄のリスク
- FBA禁止商品 G201730840：「有害物質を含有している、あらゆる商品」という包括条項がある。蛍光ランプの名指しは無い
- 危険物確認ガイド G201003400：分類は商品タイプで決まっていない。確認は ASIN チェック。**確認せずに送ると返金なしで廃棄**になりうる → 不可逆なので**ASIN チェックが済むまで納品しない**を条件にする
- 適用除外シートは「有害な化学薬品を含まない」商品が前提。**水銀入りに使うと虚偽申告**
- 輸送規則上は、UN モデル規則 1.1.1.9 のランプ除外（1本1g以下・1梱包30g以下）に入る見込み。ただし Amazon の分類の根拠にはしない

## 4. 長尺のガラス管
- 最長辺が45cmを超えると「大型」。大型は最長辺の上限なし・3辺合計200cm・40kgまで（G201105770）。1212mm の管は大型5（140cm以下）＝**配送代行 1,020円/954円**。採算に直撃するので経理に回す
- 割れ物 G200280160：6面を覆う、80cm落下を5方向。梱包要件 G200141500：納品時の梱包のまま購入者へ届く

## 5. 再利用できる手順
- **セラーセントラルのヘルプは curl では本文が空（JSで描画）。WebFetch も不可。**ローカルの Chrome を `--headless=new --dump-dom --virtual-time-budget=15000 --user-data-dir=<scratch>` で起動すれば、**ログインせずに本文が取れる**（2026-10-04 実績。上のヘルプ6ページを取得）。ページ下部の関連記事リンクから G 番号をたどれる
- 商品ページを見るときは、**「ユニット数」と「パッケージ商品数」「重量」の矛盾**を見る（本件は「25本」と表示されていたが、0.16kg＝1本）。誤認されると返品と ODR に効くので、法務からも単位ずれを指摘する
- 製造終了が近い商品は、「製造禁止で入手困難」といった煽り文言に景品表示法のリスクがあることを添える

## 6. 出品フォームの「危険物規制の種類」は「廃棄物」（2026-10-04 追記）
- 蛍光ランプは廃棄物処理法施行規則7条の2の4・**別表第四 三号**で名指しされた「水銀使用製品産業廃棄物」（e-Gov 346M50000100035）
- Amazon のヘルプ G201371860 は、この欄を「輸送、保管、廃棄のいずれか」の規制と定義している → **「該当なし」は虚偽申告**。優先順位（保管→輸送→廃棄）で、保管（消防法）と輸送（UN 1.1.1.9 のランプ除外）は該当しないので「廃棄物」
- UN 番号を作って入れない（UN3506 を入れると輸送上の危険物になる）。適用除外シートは使わない。SDS はメーカーの公開資料から。問い合わせは §4.1 の第三者連絡
- 一般化：**フォームの選択肢に迷ったら、Amazon がその欄をどう定義しているか（ヘルプの原文）を法令に当てる。**「審査に回らない方」を選ぶ発想は採らない
