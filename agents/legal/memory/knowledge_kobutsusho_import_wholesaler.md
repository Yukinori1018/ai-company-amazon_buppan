# 古物商許可：卸が輸入した新品を国内で仕入れる形態は「古物」に非該当（許可不要）

作成 2026-09-04 / ハルオ / T-20260904-004 escalation #3

## 結論

**卸自身が海外から輸入し国内在庫として保有している新品を仕入れて売る → 古物商許可は不要。**
「誰が輸入したか」は判定要素ではない。判定要素は**一般消費者の手に渡ったか**の一点。

## 決定打（これを毎回引く）

警察庁「古物営業法等の解釈運用基準について」（令和6年制定通達）第2 1(2)
https://www.npa.go.jp/laws/notification/seian/seiki/2024kobutsukaisyaku.pdf

> 「使用のために取引されたもの」とは、自己が使用し、又は他人に使用させる目的で購入等されたものをいう。
> したがって、**小売店等から一度でも一般消費者の手に渡った物品**は、それが未だ使用されていない物品であっても「古物」に該当する。

法2条1項の「使用されない物品で使用のために取引されたもの」を警察庁自身が定義している。
**県警Q&Aの文言解釈に立ち入る前に、まずこのPDFに当たれ。** e-Gov条文だけでは切れない論点が、これで切れる。

## 論理の型（3段。他の古物論点でも使える）

1. 3条の許可義務は2条2項1号の「**古物を**売買する営業」にしか及ばない → 争点は「古物か否か」だけ
2. 2条1項で新品は①非該当。争点は②「使用のために取引されたもの」だけ
3. ②は警察庁通達で「一般消費者の手に渡ったか」と定義済み → 流通過程の新品は非該当

## 県警Q&Aの読み方（重要な教訓）

**愛知県警Q5「他の業者が輸入したものを日本国内で買い取って売る場合は許可が必要」は、中古品を前提にした記載。**
根拠4点：
1. 設問が「外国に行って雑貨などを買ってきて」＝現地買い付けの文脈
2. 理由が「**国内の被害品（盗品）が混在する可能性**」＝法1条の目的。盗品が混ざるのは消費者の手を経た物の買取局面
3. 「**買い取って**」という古物営業法固有の語を使っている
4. 同じ愛知Q6が「製造・販売メーカーから直に新品を購入してレンタルする場合は、必要ありません」と明言

**検算（帰謬法）：** 文字どおり読むと輸入商社から新品を仕入れる家電量販店・ドラッグストアが全員古物商許可を要する。あり得ない。
→ **県警Q&Aは「古物であること」を前提にした例外列挙であって、古物の定義を拡張するものではない。**

## リサーチの誤りを1件検出（要注意パターン）

サトルの notes.md #123「新潟県警が『メーカー・卸・小売から直接仕入れた新品』を許可不要ケースとして明記」は**誤り**。
2026-09-04 に HTML 全文を取得して検索したが、当該記載は存在しない。新潟ページに「新品」が出るのは古物の定義欄1箇所のみ。
**escalation として上がってきた「矛盾」の片側が、そもそも存在しなかった。**

→ 教訓：**escalation を受けたら、まず両側の一次情報を自分で取り直す。**
WebFetch の要約は「無い記述を有るように読ませる」ことがある。`curl` で HTML を落として grep するのが確実。

## 許可が要る側に反転する条件（社長に必ずセットで渡す）

1. 中古・USED・ヴィンテージ・リユース・買取品・消費者返品の再販品・開封済アウトレットを1点でも扱う
2. C2C（メルカリ・ヤフオク・ラクマ）から仕入れる ← ①電脳せどり再開の日が反転日
3. NETSEA には中古品が実在（2026-08-31 実測212件）。**プラットフォームの性質ではなく個々の商品の来歴で決まる**

**反転タイミングの警告文言：** 「まだ買っていないから大丈夫」ではなく「買った瞬間にアウト」。
審査に日数を要するため、**C2C再開を決めた時点ではなく、その40日以上前に申請**が必要。

## 数字の確度

- 手数料19,000円 = **一次**（警視庁 https://www.keishicho.metro.tokyo.lg.jp/tetsuzuki/kobutsu/tetsuzuki/kyoka.html ・2026-09-04確認）
- 審査40日 = **二次のまま**。警視庁ページに標準処理期間の記載なし。断定しないこと
- 罰則 = 3年以下の**拘禁刑**又は100万円以下の罰金（31条1号）。＋4条2号で**5年間許可を取得できない**（不可逆性の根拠）
