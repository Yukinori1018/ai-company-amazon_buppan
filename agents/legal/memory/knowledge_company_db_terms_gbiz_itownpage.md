# 企業DBの規約 — gBizINFO（CC BY 互換）と iタウンページ（社内限定・違約金3倍）／Cloudflare 403 は Zendesk API で抜ける（2026-09-20）

## 1. 取得ノウハウ — Cloudflare の「Just a moment...」は Zendesk API で回避できる

サトルが2回「Cloudflare により取得できず」で止まっていた gBizINFO の利用規約は、**ヘルプセンターが Zendesk なら公開 API が通る**。

```
403 → https://help.info.gbiz.go.jp/hc/ja/articles/<ID>
200 → https://help.info.gbiz.go.jp/api/v2/help_center/ja/articles/<ID>.json   ← 本文が body に全文入る
```
Makuake ヘルプ（mkhelp.makuake.com）で使ったのと同じ手口。**ヘルプが Zendesk かは `hitachi5190.zendesk.com` のような url フィールドで分かる。**
「規約が取得できず＝判定不能」で止める前に、①Zendesk API ②`curl` ＋ブラウザUA ③別ロケール（`?mons_sel_locale=en_CA`）を順に試すこと。

## 3. iタウンページDB — 二次情報の「1件1円」は誤り。実価格は約10倍

規約全文：`https://www.ntttp-db.com/online-quote-terms/`（2025-10-01 実施）。注意事項：`https://www.ntttp-db.com/online-quote-notice`。FAQ：`https://tpdb.jp/townpage/faq/`（EUC-JP）。

| **第18条** | 違反時 **使用料金の3倍**。しかも**「疎明」で請求できる**（証明でなく疎明＝請求のハードルが低い） |

**判定は「条件付きOK（社内限定）、ただし購入は推奨しない」。** 推奨しない理由は規約ではなく費用対効果（12万円で埋まるのは電話番号だけ・HPと規模は埋まらない・人が15〜25時間かければ0円で両方埋まる）。**規約がOKでも経済性で落とす結論を書いてよい。**

## 4. 型として残すこと

- **有料DBを検討するときに最初に見る5点**：①社外提供の禁止条項（PUBLIC リポ運用との衝突）②違約金の額と立証の程度（疎明か証明か）③削除要請への追従義務④契約終了時の消去義務⑤輸出・越境保存の制限。**料金は最後**。
- 二次情報の単価（まとめ記事の「1件1円」等）は**必ず販売元の料金表で裏を取る**。今回は約10倍ずれていて、A/B/C の選択が逆転した。
