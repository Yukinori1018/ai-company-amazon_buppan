# FAX＋電話の重ね打ちと、ネットFAX規約の読み方 — 業法で外れても刑法・民法・規約は残る

前提：`knowledge_mass_outreach_email_fax_rules_2026-09.md`（メール側の確定ルール）／`knowledge_tokutei_denshi_mail_sourcing_outreach.md`（1社1通の一般則）。

## 1. 一番の学び：26条1項1号は「原稿の中身」を無効化する

特商法12条の5 を心配する依頼が来たら、**原稿に何が書いてあるかを読む前に26条1項1号を見る。**

> 26条1項1号「…**購入者若しくは役務の提供を受ける者が営業のために若しくは営業として締結するもの**に係る販売又は役務の提供」→ 前三節（訪問販売・通信販売・電話勧誘販売）ごと適用しない

相手が事業者である限り、**当社が原稿に自社の役務の売り込みを書いてしまっても12条の5は働かない。**「売り込みが混ざったら該当に傾くか」という問いは、条文上は空振り。
ただし26条1項1号は実態判断。**名目だけ事業者の先（個人作家・副業規模）には除外が外れる余地**が残る＝そこだけ厳しく書く。

## 2. 迷惑防止条例は「目的要件」で外れる（形は同じ）

東京都条例5条の2第1項：「専ら、特定の者に対する**妬み、恨みその他の悪意の感情を充足する目的で**…**反復して**行つてはならない」。
第4号が「**拒まれたにもかかわらず、連続して、電話をかけ、文書を送付し、ファクシミリ装置を用いて送信し**」。

→ **行為の形は当社のFAX→電話の重ね打ちと完全に一致している。外れているのは目的要件だけ。**罰則は1年以下の拘禁刑／100万円以下の罰金（8条2項2号）。
だから「断られたら二度としない」は礼儀ではなく、条文に接している線。ここは緩めない。
出典：https://www.reiki.metro.tokyo.lg.jp/reiki/reiki_honbun/g101RG00002212.html ／全国横並びの確認は法務省 https://www.moj.go.jp/content/001329117.pdf

## 3. 切り分けの型（次も使う）

**BtoBで減免されるのは業法（特商法・特定電子メール法）まで。刑法234条・民法709条・各社規約は相手が事業者でも一切減らない。**
取適法（旧下請法・2026-01-01 施行）は委託事業者側に資本金1,000万円超 or 従業員300人超が要る＝個人事業主の当社は対象外。ただし**型③OEMに進んだら再判定**（製造委託に化ける）。

## 4. 接触回数は「経路の追加」ではなく「枠の置き換え」で整合させた

既定（`10` §2）は「1社1回＋7日後の追いかけ1回」。社長方針で電話が増えたが、**電話を追いかけ枠に入れる**ことで既定を変えずに済んだ。
`feedback_standing_decisions_are_not_re_decided` の型：**新しい要求が来たら、既定を書き換える前に既定の枠に収まらないかを先に試す。**

## 5. ネットFAX規約で必ず見る6点（faximo で実証）

| 見る場所 | faximo の実際 |
|---|---|
| 禁止事項に FAX-DM の名指しがあるか | 無い（8条は一般条項7号のみ）。IVRy 6条も同じ |
| **通信内容を事業者が閲覧できるか** | できる（9条1項②「禁止事項への該否判断のため」）。**原稿に第三者の秘密や個人情報を盛らない根拠になる** |
| 事業者側の解約権 | 19条1項「**理由のいかんを問わず**通知により翌月末日をもって解約」＋19条2項4号（8条該当で催告なし即解約） |
| 停止中の課金 | 16条3項「停止期間に発生する利用料金を支払う義務」 |
| **番号の法的性質** | 4条2項「**貸与**」＋5条1項で譲渡・移転不可。＝停止で番号を失い、持ち出せない |
| **ログの保存期間** | 60日・延長不可（FAQ ctr0009）。CSVは過去60日分のみ（ctr0008）。**送信の証拠が自動で消える** |

→ **一般条項に触れるかより、「切られたとき何を失うか」を先に数える方が実務的。**faximo は番号と60日超のログ、IVRy は番号と記録情報（23条で予告なく削除可）。
faximo には**契約ごとの月間上限枚数**がある（FAQ sfx0016・管理画面TOPにしか出ない＝契約前は未確認）。週70通の前にここを見る。

## 6. IVRy 9条2項は赤線（見落としやすい）

> 登録ユーザーが投稿その他送信を行った文章、画像、動画その他のデータについては、当社において、**無償で自由に利用（複製、複写、改変、第三者への再許諾その他のあらゆる利用を含みます。）**することができる

通話録音・文字起こしがここに入りうる。**卸値・独占条件の商談を IVRy 上で話さない**という運用条件を出した。
加えて10条1項4号「**3ヶ月以上本サービスの利用がなく、当社からの連絡に応答がない場合**」で登録取消＝フリープランを寝かせると番号が消える。無料プランは「放置で失効」条項を必ず探すこと。
