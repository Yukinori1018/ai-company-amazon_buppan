# 「営業お断り」表示企業への仕入れ打診 — 特定電子メール法の一般則

初出：T-20260904-004 タスクB-1派生（2026-09-04 ハルオ／451社のメーカー直取引候補）
併読：`knowledge_thirdparty_list_reuse_3steps.md`（同型：サイト上の一方的表示の法的性質）

---

## 1. 結論（次に同じ依頼が来たらここだけ読めば足りる）

**仕入れ打診（買う側からの取引申込み）は「特定電子メール」に当たらない。**したがって「営業お断り」表示があっても、特定電子メール法上は送信できる。

論証は3段：

| # | 論点 | 根拠 |
|---|---|---|
| 1 | 定義に当たらない | 法2条2号「**自己又は他人の営業につき広告又は宣伝を行うための手段として**送信をする電子メール」。買う打診は自己の営業の広告宣伝ではない |
| 2 | 官庁も明示 | GL p.2 非該当例ア）「取引上の条件を案内する事務連絡…**広告又は宣伝の内容を含まず、広告又は宣伝のウェブサイトへの誘導もしない**電子メール」 |
| 3 | 表示の効力範囲 | GL p.19「**このような表示をした場合であっても、単なる私信等の特定電子メールに該当しない電子メールの送信まで行えなくなるものではない**」 |

## 2. 「営業お断り」表示の法的正体（この理解が核心）

施行規則3条ただし書：

> 自己の電子メールアドレスと併せて特定電子メールの送信をしないように求める旨の文言を…公衆が閲覧することができる状態に置いたときは、この限りではない。

つまりこの表示は「**法3条1項4号のオプトイン例外（公表アドレス宛なら広告メール可）を打ち消すスイッチ**」。打ち消す対象は**特定電子メールだけ**。契約ではないので民事上の拘束力もない。

さらに GL p.19 は拒否表示に使うべき語を例示している。**これがそのまま機械判定の語彙になる**：
「特定電子メール／広告メール／宣伝メール／迷惑メール」×「拒否／お断り／送信しない」。

## 3. 最重要の実務ルール — URL を貼った瞬間に白が黒になる

GL p.1 の該当例ア）：「**営業上のサービス・商品等に関する情報を広告又は宣伝しようとするウェブサイトへ誘導することがその送信目的に含まれる電子メール**」

→ 打診メールの署名に **Amazonストア URL・自社サイト URL を貼ると特定電子メールに転化する**。転化した瞬間、相手の「営業お断り」表示が法的効力を持つ。
**この1点だけは何度でも言う価値がある。**

## 4. 罰則の構造（誤解が多い）

法3条違反に**直罰なし** → 法7条 措置命令 → **命令違反**で法34条2号（1年以下の拘禁刑／100万円以下の罰金）、法人は37条で3,000万円。
かつ法7条は「**一時に多数の者に対してする**」送信が要件。1社1通の個別打診は条文の想定外。
「1通送ったら逮捕」式の説明は誤り。ただし**送信可＝送ってよい、ではない**（次項）。

## 5. 判定は「法の可否」ではなく「通報誘発確率」で切る — 一番の学び

法的にはほぼ全件送れてしまう。だから法だけで判定すると「全件GO」という無意味な答えになる。
**切り口を変えた：送信ドメインのレピュテーションは451社すべてへの到達を支える共有資産であり、1社の通報で残り450社を巻き添えにする。**可逆性が低い。
→ **通報を明示している企業（例：愛知電線）だけは、法的に適法でも触らない。**

3軸評価の「不可逆性」が効いた事例。**母数が大きい施策では、1社あたりの損得ではなく共有資産の毀損で判定する。**この型は他の一斉施策（DM・電話・SNS DM）にも流用できる。

## 6. 判定は「会社単位」でなく「窓口単位」

リッチェルで実証：一般消費者向けフォームではなく**法人向けフォームの側に**「売り込みお断り」があった。逆に、消費者フォームだけに表示があり法人窓口には無い構成も普通にある。
→ `optout_source_url` を**窓口URLで**記録し、最も緩い有効な窓口を採用する。

## 7. 「売る」拒絶と「買う」打診は文言上べつもの（明文主義）

「商品やサービスの**売り込み**、製品アイデア等の**ご提案**はご遠慮ください」が禁じるのは、こちらが**売る**行為と**提案**行為。「貴社商品を仕入れたい」は文言に含まれない。
ただし相手の真意が「未取引先からの一方的接触の抑制」である可能性は消えない＝**グレー**。
→ グレーは原則NOだが、母数451社なので**除外せず「優先度最下位で保留」**という第3の選択肢を作った。3点セット（リスクシナリオ／対応策／撤退条件）を必ず添える。

**除外／実行の二択にしないこと。母数が大きい案件では「後回し」が最適解になりうる。**

## 8. 隣接論点の結論（再調査不要）

| 論点 | 結論 | 根拠 |
|---|---|---|
| 問い合わせフォーム | **特定電子メール法の適用なし** | 法2条1号＋平成21年総務省令85号（SMTP または 携帯電話番号方式のみが「電子メール」）。フォームはHTTP。加えてSMTP送信をするのは相手方サーバ |
| SMS | 適用あり | 同省令2号。**B2B打診には使わない** |
| 電話での仕入れ打診 | **特商法の規制は及ばない** | 電話勧誘販売（2条3項）は「**販売業者又は役務提供事業者**」が主体。当社は買主。加えて26条1項1号で事業者間取引は章ごと適用除外 |
| 訪問購入 | 適用外 | 「**営業所等以外の場所において**」の場所要件。加えて58条の17第1号で営業目的の売買は除外 |
| 執拗な再架電 | 威力業務妨害（刑法234条）に近づく | 1〜2回の通常の商談申込みでは成立しない。**断られたら二度としない**で足りる |

## 9. 一次情報の取り方（時短メモ）

- e-Gov API v1 が使える：`https://laws.e-gov.go.jp/api/1/lawdata/<LawId>` → XMLタグを剥げば全文。**WebFetch はSPAで本文が取れない**（今回1回無駄にした）

- 総務省GLは PDF。`pdftotext -layout` が入っている
- v2 API のキーワード検索：`https://laws.e-gov.go.jp/api/2/keyword?keyword=...`
