## 1. 再販売価格の拘束 — 小売側の言い回しの判定基準
- 一次：公取委「流通・取引慣行に関する独占禁止法上の指針」**最新は令和8年(2026)7月8日改正**。PDF `jftc.go.jp/dk/guideline/unyoukijun/ryutsutorihiki_files/ryutsutorihikigl_2026.pdf`。改正は第1部第1の2(7)（実質メーカー販売＝危険・費用をメーカーが負う場合の例外）に③と注5の2・5の3を追加しただけ。**原則違法は不変**（報道発表 houdou/pressrelease/2026/jul/260708_soushi_ryutori.html・2026-10-12確認）。
- 違反主体は供給者（独禁法2条9項4号）。小売側が問題になるのは、**メーカーの「示した価格」に従う合意・同意の材料を差し出すとき**（GL 2(3)①a〜d。同意書・取引条件として受諾）。
- 判定：
  - OK「販売価格は当店が判断して決めます」「値下げ競争に頼った販売はしません」＝一方的な方針の表明。メーカーの示す価格を受け入れていない
  - NG「希望小売価格・下限価格のご指定に従います」「希望小売価格を守ります」＝2(3)①b/c の同意・受諾そのもの。2(5)の「下限」「○%引き以内」「事前承認」も同じ
  - 要注意「（価格について）お取引の前にお約束します」＝**相手（供給者）への約束の形式**。後でメーカーが下限を示すと合意の文脈になる。「販売方針としています」に直した
- 運用：**メーカーの返信に価格の指定が来たら同意しない**。「参考として承ります」と返す（GL 1(2)：希望小売価格は参考として示される限り問題なし）。これは一括承認の外＝1件ごとに上げる（knowledge_mass_outreach §5 の「価格指定」）。

## 2. 特定電子メール法 — 受信拒否の一文
- 仕入れ打診そのものは特定電子メールに当たらない（knowledge_tokutei_denshi_mail_sourcing_outreach）。/partners の URL を貼るので**グレー→表示義務を満たして送る**（量産時は遵守が安い）。
- 施行規則7条1項2号：返信で拒否できるなら「拒否できる旨」はメール内の任意の場所でよい。**ただし法4条2号は通知先アドレスそのものの表示を要求**。「その旨ご返信ください」だけだと From ヘッダ頼みになる → 「**info@satoy-select.com 宛にその旨お知らせください**」と明記した。
- 住所（規則9条2号）は〔住所〕のプレースホルダ。**埋めずに送ると欠格**。問い合わせ先（9条3号）は電話・メールで充足。
- 法令の改正：法の最終改正 令和4年法68号（刑法改正の整理）、施行規則 令和2年内閣府・総務省令10号。2026年の改正なし（e-Gov API v1 の AmendLawNum で確認）。

## 3. 取扱い範囲の書き方（46 との整合）
- 「品目ごとに確認して取り扱う：常温包装食品・化粧品・医薬部外品…表示・出品要件・書類を確認できたものに限る」は許認可の断定ではなく、46（区分A＝販売業許可・届出不要）と整合。
- 「電気用品の届出書類」は**当社が届出をするように読める**（届出は製造・輸入事業者＝電安法3条）。「電気用品安全法〔PSE〕に関する書類」に直した。
- 残課題：医療機器（管理医療機器は販売業の届出、特定管理以上は許可）がどの段にも書かれていない。範囲の追加は方針判断なので秘書に推奨として返した。
