# 「公的っぽいサイト」の罠 — 指定するのが国でも、運営が民間なら政府標準利用規約は効かない

初出: T-20260831-005 Phase B（2026-08-31 ハルオ・kougeihin.jp の判定）
併読: `knowledge_thirdparty_list_reuse_3steps.md` / `knowledge_scraping_and_public_db_2026.md`

---

## 1. 一番の学び

**`kougeihin.jp`（伝統工芸 青山スクエア）は「経産大臣が指定した244品目」を扱うが、運営は一般財団法人 伝統的工芸品産業振興協会＝民間法人。**
→ **政府標準利用規約2.0 も 公共データ利用規約1.0（PDL1.0）も適用されない。**

> **指定しているのが国であることと、サイトを運営しているのが誰かは別の話。**
> 判定の一手目は必ず **`/privacy/` か `/about/` で運営主体の法人格を確認すること。**「◯◯省指定」という言葉に引きずられない。

---

## 2. 判定の実際（3段階の型をそのまま適用）

| 段階 | 判定 | 根拠 |
|---|---|---|
| 1 取得して社内保持 | **可** | 抽出対象を**組合名・〒・住所・TEL・FAX・品目名・分類・地域・指定年月日**に限定。すべて事実＝著作権法2条1項1号の著作物でない。クロール時の一時複製は30条の4第2号 |
| 2 PUBLIC リポ・外部公開 | **不可** | ①21条・23条1項（「特徴」「作り方」は言語の著作物）②サイトポリシーの明示的な不許諾宣言 ③**個人情報保護法27条**（屋号のみの個人経営工房が混じる） |
| 3 そこで知った組合を手がかりに一次情報を取り直す | **可・推奨** | 事実に著作権なし |

### 使った論証パーツ

- **サイトポリシーは契約ではない**（ログイン不要・クリック同意なし・開いた後にしか読めない一方的表示）。**が、著作権者の不許諾宣言としては有効。**「契約じゃないから自由」は誤り。
- **「私的使用のための複製を除き」という留保に飛びつかない。** 著作権法30条1項は「個人的に又は家庭内その他これに準ずる限られた範囲内において使用する」。**事業目的は該当しない。この抜け道は使えない。**
- **編集著作物（12条）の否定：244品目という選択は伝産法に基づく大臣指定で決まっており、協会の創作的選択ではない。**（確度：中。判例原文は未確認と明記した）

## 3. 副産物 — 公的な代替ソースを必ず探す

METI 側に**商用利用可・再公開可**のファイルが2本あった。**判定を出す前にこれを探すと、成果物の価値が跳ね上がる。**

| ファイル | 内容 |
|---|---|
| `https://www.meti.go.jp/policy/mono_info_service/mono/nichiyo-densan/xlsx/list_20251027.xlsx` | 244品目一覧（品目名・よみ・都道府県・指定年月日）。**住所TELは無い** |
| `https://www.meti.go.jp/policy/mono_info_service/mono/nichiyo-densan/xlsx/planlist.xlsx` | 伝産法の認定計画一覧。**「作成主体」列に組合名・企業名**（例：京都青窯会協同組合、新潟漆器製造株式会社） |

**経済産業省 利用規約**（`https://www.meti.go.jp/main/rules.html`）
> 権利表記の記載がない限り「**公共データ利用規約（第1.0版）**」（PDL1.0）に準拠した利用条件の下で、利用することができます。（出典記載例）出典：経済産業省ウェブサイト（当該ページのURL）

→ **PDL1.0 は CC BY 4.0 互換。商用可・改変可・再公開可。条件は出典明記のみ。**

### そこで出した設計（横展開可）

```
公開できる列（METI 由来）  : 品目名・都道府県・組合名／企業名   → 社内可・PUBLIC 公開も可（出典明記）
公開できない列（民間サイト由来）: 住所・TEL・FAX               → 社内のみ
```
**列の由来をファイルレベルで分けておけば、後から「これは出していいのか」で迷わない。事故が起きない。**

## 4. クロール速度の指定は「数字」で出す（毎回これを貼る）

| 項目 | 値 |
|---|---|
| 間隔 | **同一ホスト3秒以上・同時1**（相手が明示的に `Crawl-delay: N` を書いていれば**その値に合わせる** — SD は10） |
| UA | **自社名＋連絡先を明示。** UA詐称は個人情報保護法20条1項「偽りその他不正の手段」に寄る |
| 停止 | **403 / 429 / 5xx が1回でも出たら即時・永久打ち切り。再開しない** |
| 時間帯 | **平日日中**（先方が異常に気づいて連絡できる時間）。深夜の無人大量アクセスは心証が最悪 |
| 回数 | 原則1回。再取得は年1回まで |
| 全レコード | `source_url` と `fetched_at` を必ず持たせる |
| 根拠 | 岡崎市立中央図書館事件（2010）。1秒1回・1日1時間で**逮捕・21日勾留・起訴猶予**。真因は図書館側の不具合でも身柄は飛んだ |

**275ページ×3秒＝約14分。「1回で終わる。分割・並列にする理由がない」と明記すると、エンジニアが余計な最適化をしない。**

## 5. 第三者への連絡（§4.1）を許可するときに毎回つける3点

| # | 内容 |
|---|---|
| 1 | **電話**は事業者間なら特商法の規制対象外。**法的障害なし** |
| 2 | **メール**は特定電子メール法3条1項4号で同意不要。**ただし施行規則3条ただし書** —「営業メールお断り」表示があるアドレスには送れない。**収集時に判定してレコードに記録する。後から遡れない（立証責任は送信者側）** |
| 3 | **個人情報保護法21条1項**の利用目的の通知**または公表**。数百件に個別通知は非現実的 → **「公表の場」を先に用意**（自社サイトに1ページ）。連絡開始より前に |

## 6. グレーを進める時の3点セット（今回の記載例）

kougeihin.jp のクロールは**不可逆性が低い（社内データを消せば原状回復できる）から進めてよい**と判断した。**この理由づけを明示的に書いたのが良かった。**

| 項目 | 記載 |
|---|---|
| リスクシナリオ | 協会から「サイトポリシー違反、削除せよ」と連絡が来る |
| 発生確率 / 影響度 / **不可逆性** | 低 / 小〜中 / **低 ← ここが判断を決めた** |
| 対応策 | 争わず即時全削除。段階3で取り直した一次情報だけ残す |
| 撤退条件 | ①403/429/5xx が1回 ②協会から連絡 ③robots.txt に `/craft/` の Disallow 追加 — **いずれか1つで即時永久停止** |

**対比：公開（段階2）は不可逆性が高いので、確率が低くても許可しない。** この非対称を毎回はっきり書く。
