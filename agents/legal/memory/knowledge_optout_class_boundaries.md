# 「営業お断り」判定のクラス境界（迷いやすい4つ）

T-20260904-004 / v1.1 で確定。`B1L_optout_rules.json` の `class_boundaries` に格納済み。

| 境界 | 判定基準 |
|---|---|
| **D か E か** | 拒絶が**属性と無関係に全方位**なら D（営業お断り／通報／新規取引を一切受けない）。**条件付きで、当社がその条件を満たさないため引っかかる**なら E（実店舗必須・法人のみ・WEB専売お断り）。E は必ず `recheck_condition` を持つ |
| **C か A か** | 拒絶対象に**売り込み・営業・セールス・勧誘**の語があるなら C。**アイデア・企画・製品提案の持ち込みだけ**を断るなら **A**（未承諾アイデア受領拒否＝知財防衛条項。取引拒絶ではない） |
| **E か A か** | 「**一般**のお客様／一般消費者／エンドユーザーへの直販なし」＝販路の説明で小売事業者は排除されていない → A。「**個人**のお客様／個人の方／**法人様以外**とは取引しない」＝個人事業主の当社に直撃 → E（recheck=法人化時）。**「一般」と「個人」を読み分ける** |
| **A_PLUS か D か** | 取引窓口語は**直後が否定なら A_PLUS ではなく D** |

## 判定の実例（覚えておく型）

- **ハイメス**（WEB販売のみの企業とは新規取引しない）= E。すごろくや（実店舗必須）と**同じ構造の裏返し**。
  要件で書くか欠格事由で書くかの違いだけなので、片方の語彙では絶対に拾えない。両方の書き方を語彙に持つ。
- **BUNDOK**（法人様以外のお取引を控える）= E。個人事業主は法人格を持たない＝明文上「法人様以外」。
- **SBクリエイティブ**（個人とは取引しない／書店・ネット書店とはする）= E。
  「当社はネット書店に当たるか」→ **当たらない**。出版社の直取引は取次口座・書店口座が前提で当社は持たない。
  持たないまま名乗るのは**事実と異なる申告**（＝実績を誇張しないのと同じ理由で不可）。
- **パール金属**（アイデア提案のみお断り）= **A**。リッチェル（C）との違いは「**売り込み**」の語の有無**だけ**。
  ただし文面で「購入の相談であり企画提案ではない」と冒頭宣言し、商品提案を一切書かないこと。

## 実務の骨（v1.0 から維持）

- 判定軸は法の可否ではなく**通報誘発確率**。送信ドメインの評判は全社への到達を支える共有資産で、
  1社の通報が残り全社を巻き添えにする（不可逆性が高い）
- **打診メールの本文・署名に URL を一切貼らない。**貼ると特定電子メールに転化し、相手の表示が法的効力を持つ
- 窓口単位で判定し最も緩い窓口を採用。**ただし E は会社単位**（窓口単位だとすごろくやが A に化ける）
- 適用順は **E → D → B → C → A_PLUS → A**（v1.1 で E を先に）。D と E はどちらも exclude なので
  順序を入れ替えても「打診してしまう」事故は原理的に起きない。E を先にすると条件付き拒絶が D に吸われない
