# 自社出品商品を自分の Amazon アソシエイトリンクで紹介する行為（一次確認済み）

- 初版：2026-09-27 / T-20260927-001 / 判定者：ハルオ
- 一次資料の実読日：2026-09-27。**規約は随時改定されるため、実行直前に再確認する**

## 結論（再利用可）

**条件付き可。** アソシエイト規約に「自社出品商品を紹介してはならない」明文は**ない**（全文検索で「出品」「販売者」「自社」の言及0件）。ただし事業判断としては非推奨（得るのは紹介料数%、失いうるのはセラーアカウント＝不可逆）。

## 法務としての最重要の付加価値（規約だけ読むと落とす）

**景表法ステマ規制（5条3号＋内閣府告示19号・2023-10-01 施行）。**
自社出品商品では当社が「供給する事業者」本人なので、**「Amazonアソシエイトです」の開示だけでは足りず、「当店が販売しています」＝売主である旨の明示が別途必要**。措置命令の名宛人は事業者（＝当社）で、インフルエンサー側は対象外。
→ **この条件は案A・B・Eのどれを選んでも必要**。規約と法令は別の軸で効く、という型は他案件にも使える。

## 提示した代替案（feedback_legal_no_is_not_a_prefilter 対応）

- **A（最推奨）**：自社出品は**素の URL（タグなし）**で送る。論点が完全に消滅し、販売利益は満額。
- B：他社 ASIN のみアソシエイト。当社は第三者の立場に戻る。
- C：Amazon Attribution（無料・公認）で計測だけ行う。
- D：Brand Referral Bonus は**米国セラー＋ブランド登録**要件で当社不適用。日本ストア提供は未確認。

## 未確認として残したもの（次回ここから）

- **サービスビジネスソリューション契約（G1791）は JS レンダリング＋要ログインで curl/WebFetch では本文が取れない。** セラー側の明文は未確認のまま。→ 次回は秘書にブラウザで開いてもらう（ログイン後の画面）ルートを検討する。
- アソシエイト違反がセラー側の関連アカウント評価に乗るかは**推測**。一次の裏付けなし。

## 手順の型（同種依頼の再利用）

1. `curl` で規約ページを取得 → python で `<script>/<style>` 除去 → タグを改行化して plain text 化（**affiliate.amazon.co.jp はこの方法で全文が取れる。WebFetch は要約されて条項番号が落ちるので使わない**）。
2. 「禁止の明文があるか」は**肯定側の語**（出品・販売者・自社）で全文 grep し、**0件であることを確認方法ごと成果物に書く**。「見つからなかった」だけでは根拠にならない。
3. 抽出した原文は `agent_output/<ticket>/` に残す（改定後に差分を取るため）。
4. 規約 → 日本法（景表法・特商法）→ 停止経路 → 代替案 の順で組む。**停止経路は「アソシエイト側／セラー側／両方」に分けて書く**（社長の最大の恐怖はセラー側の不可逆停止）。
