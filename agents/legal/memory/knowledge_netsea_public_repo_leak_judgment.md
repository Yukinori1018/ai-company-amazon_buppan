## 2. 効く条文（NETSEA。条番号は毎回これ）

| 文書 | 条 | 効き方 |
|---|---|---|
| **API 利用規約 15条1項** | 「相手方の**一切の情報を秘密として保持**し、事前に開示者の書面による承諾を得ることなく、第三者に開示または漏洩してはなりません」 | **直撃。**公開リポ push＝第三者開示 |
| API 利用規約 8条2項 | 情報の**加工に事前書面承諾** | グレー。社内利用は2条（自身の便益をはかる商用目的）で可、**公開は不可** |
| API 利用規約 12条1号 | 違反時＝**催告なく API 提供解除** | 制裁は金銭でなく**停止** |
| **会員規約 7条2項3号** | 事前承諾なく「**利用者の権利の行使の範囲を超えて、本サービスの情報を利用**」禁止 | 会員限定情報の一般公開はここに当たる |
| 会員規約 8条2項1号 | 違反時＝**催告なく会員登録取消** | 同上 |

- **API 利用規約は全16条。19条は存在しない。**7条は「無保証」で項は2つ。
  → **「API 規約 第7条2項5号／第19条3項」は誤引用。**これは**会員規約**の条番号で、中身は「サプライヤーへの直接連絡禁止」「NETSEA 外での売買契約禁止」＝**公開可否と無関係**。
- **会員規約27条4項の違約金200万円は 19条3項違反にしか発動しない。**データ公開では発動しない。誤引用を放置すると次に読む者が200万円と誤解する。
- **会員規約にバイヤー側の秘密保持条項は無い**（「秘密」全文検索で該当0）。会員規約側の根拠は 7条2項3号1本。

### 取得方法（毎回同じ）

- 会員規約：`curl https://www.netsea.jp/agreement/statement` → タグ除去。静的。

## 3. スーパーデリバリー（T-20260831-005）との違い — 同じ結論にはならない

| | 条項の型 | 帰結 |
|---|---|---|
| SD 第17条1項 | 「**一切の情報**を…他のサイトに複製・転用又は**発信**することを禁じます」＝**一般的発信禁止** | 社名だろうが商品名だろうが**一律アウト** |
| NETSEA | 秘密保持＋範囲外利用の禁止＝**その情報が会員限定であることが前提** | **卸値だけアウト。**公開情報部分はセーフ |

**教訓：「卸サイトだから同じ」で横展開しない。禁止条項が「一般的発信禁止型」か「秘密保持型」かで結論が反転する。**

## 4. force push の評価（毎回同じ結論を書けるようにしておく）

**「force push すれば消える」は誤り。効果は『これから見に来る人が見つけにくくなる』まで。**

1. GitHub はダングリングコミットを即座に消さない。`/commit/<sha>` の直接 URL で当分アクセスできる。確実に消すには **GitHub Support への依頼＝第三者連絡（§4.1）**。
2. クローン・コード検索インデックス・アーカイブに取り込まれていれば回収不能。**fork 0 は有利材料だが保証ではない。**
3. **`.claude/scripts/github-sync.sh` は分岐(diverge)を検知したら何もせず終了する設計。→ force push すると30分ごとの自動同期が止まる。**同期停止は成果物消失という別の事故を招く。

> **不可逆性が既に確定している事案では、A（履歴書き換え）を選んでもリスクは減らず、新たなコストだけが確定する。**
> **可逆な手段で不可逆なリスクを消せる時は迷わずそれを選ぶ（＝Private 化）が、既に消せない時は「これ以上増やさない」に切り替える。**

## 6. 再発防止の型（`git add -A` 前提でも手はある）

現行は**既定＝載せる／例外＝除外を書く**。書き忘れが危険側に倒れる。**反転させるのが本筋。**

- **① `deliverables/<ticket_id>/.gitignore` の冒頭を `*` にしてホワイトリスト運用**（`!` で明示追跡）。1行で、書き忘れが安全側に倒れる。**最有力**
- **② pre-commit フックで機械的ゲート**（`netsea.jp/shop/`・`卸値`・`仕入れ先:` 等のシグネチャ検知で commit 中止）。`github-sync.sh` は `git commit` を呼ぶので**自動同期にも効く**。実装は IT エンジニア案件
- ③ sync の add 範囲を絞る＝①と併用が前提。単独不可
- ④ 行データを `agent_output/` へ＝CLAUDE.md §6 の消失対策と正面衝突。**採らない**
