# 期限に間に合わない時の申し立て — 「延長要求」ではなく「事実の記録」

法務ハルオ／初版 2026-09-02（T-20260826-004・成果物06）
プラットフォーム相手（Amazon 等）で**自分に落ち度なく期限を守れない**時の定型。次に同種の依頼が来たらこの型をそのまま使う。

## 1. 結論：延長を求めない

| 立て付け | 何が起きるか | 判定 |
|---|---|---|
| 期限の延長を要求 | 延長は相手の**裁量事項**。**「求めて断られた」記録が残り、次の申し立ての出発点が悪くなる** | **NO** |
| 「この日程は期限内扱いか」と質問 | **質問の形をした延長要求。**「いいえ」が返れば上と同じ不利な記録 | **NO** |
| 何も送らず待つ | 期限徒過の事実だけが残り、こちらの事情がゼロ。**沈黙は不作為と区別できない** | **NO** |
| **事実の記録＋履行の申し出** | 断る対象が存在しない。上振れの導線が1本残る | **採用** |

**核心：断られる対象を作らない。**裁量を求めた瞬間、相手に「否」と書く機会を与える。事実の通知には否も応もない。

## 2. ただし「事実だけ」では動かない — 履行の申し出を1文足す

純粋な事実通知は、受け手に**やることがない**。「返信不要」で閉じられ、記録には残るが事態は動かない。

→ **「◯◯を再開してもらえれば24時間以内に△△を提出します」**を1文だけ足す。

- これは**裁量のお願いではない**。「こちらは即座に履行できる状態にある」という**事実の表明**
- 断られても不利にならない（相手は何も判定していない）
- 相手に**期限を待たずに解決できる導線**を渡せる。**上振れの余地はここにしかない**

## 3. 本文の構成（1画面・250語以内）

1. 冒頭に **"I am not asking for a decision or an exception."**（立て付けの明示。これが全体を守る）
2. 事実を**3点まで**。各点は「観測した事象 → 画面表示との一致 → だから物理的に不可能」の順
3. 「この間の時間が**不作為として記録されないよう**、いま事実を記録する」＝**記録の趣旨として書く**（要求文にしない）
4. 履行の申し出（§2）
5. "Please attach this message to my record." ＋ こちらの可用性（いつでも対応可能）

## 4. 書いてはいけないもの（すべて意図的に不記載）

| 不記載 | 理由 |
|---|---|
| 謝罪（"I apologize"） | 判定材料にならない。**過失の自認を独立して繰り返す**ことになる |
| 却下・不備の原因の再説明 | 説明済みなら **1行の参照に留める**（"already been explained in my previous submissions"）。繰り返すと弁明に見える |
| 生活困窮・事業への影響 | 本人確認・審査の判定材料にならない |
| プラットフォーム批判（画面が分かりにくい等） | **過失の説明が責任転嫁に見え、心証を悪くする** |
| 不確かな期限・数字 | **自分から書いた誤りは、こちらの記載ミスとして扱われる。**原文未確認なら削る |

## 5. 送信前に必ず潰す（今回2点残した）

- **数字・期限の根拠を原文で確認する。**チケットログ由来の数字を本文に書かない。確認できないなら**削れる作りにしておく**（角括弧の任意文にする）
- **送信先を法務が指定しない。**画面を見ていないなら指定してはいけない。原則は「**その通知が届いた導線に返す**」。**新規ケースを立てない**（重複送信＝審査列の最後尾）
- 添付の可否を通知本文で確認（Amazon は「セラーセントラルから直接アップロードした書類のみ承認。メール添付は不可」）
- 送信は §4.1（外部発信）。**法務も秘書も押さない**

## 6. 英文＋日本語対訳を必ず併記する（社長の要求・2026-09-02）

> 「社長が内容を理解しないまま送信するのは避けたい」（カズヨ経由）

英文を納品する時は**全文の対訳を付ける**。要約ではなく逐語に近い訳。送信するのは英語である旨を明記する。

## 7. 依頼の型として再利用できる形

「期限に間に合わない／相手都合で待たされている」→ 成果物の構成は毎回これでよい。
