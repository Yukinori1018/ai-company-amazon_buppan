## 判定の手順（再利用できる型）

1. **税番を当てる → 関務署の稅則オープンデータで「輸入規定」欄を見る。**これで TFDA と BSMI の対象かが機械的に分かる
   - CSV：https://opendata.customs.gov.tw/data/80871/csv.csv （data.gov.tw/dataset/80871。約1.2万行。python の csv で読む。awk の `","` 区切りは列がずれる）
   - **F01**＝品目そのものが TFDA 査験の対象／**F02**＝食品用途なら対象／**C02**＝BSMI の検査対象が「一部」含まれる（範囲は BSMI の品目明細表の［限檢驗…］で確認）
2. **F が付いていれば、個人使用の免除に収まるかを見る**：衛授食字第1081300310號（2019-05-01 施行）。食品容器・器具＝「報單單一項次 US$1,000 以下・同規格4件以下」（DH000000000005）。食品＝US$1,000・6kg。販売用でないことが前提
3. **C02 なら BSMI の品目表で範囲を確認**。範囲外なら関係ない。範囲内でも、自用品で US$1,000 以下の郵便小包は商品免驗辦法 第5・6条で免除され、税関がそのまま通す
4. **関税・営業税**：郵便小包は完税価格（商品＋運賃＋保険）NT$2,000 以下なら免除。**同じ受取人が半年に7回目から免除されない**。少額の免税と輸入規定（査験）は**別の話**（財政部 etax の「海外網購注意事項」2026-09-11 更新）
5. **Shopee 台湾の規約**（help.shopee.tw/portal/4/article/77273・2025-06-13 版）：禁止44類・制限13類＋**包括条項「買い手・売り手の法域で進出口法規管制がある品」も制限品**。F01/F02 が付いた品はこの条項に形式上かかる
6. **日本側**：郵便物で20万円以下なら輸出申告は不要（関税法76条）。外為法は家庭用品なら関係ない。輸出免税は当社が免税事業者なので関係ない

## 今回の結論（2026-10-12）

- ステンレス鍋 7323.93＝**C02 のみ・F なし**。BSMI の C02 は家庭用圧力鍋だけ → 普通の鍋は台湾の輸入規制の対象外。**意外だったので記録**（金属の食器・調理器具は TFDA の事前査験ではなく、市場に出た後の抜き取り検査で管理されている。2026-05 の「黒心不鏽鋼」騒ぎでも事後の稽查）
- 紙・樹脂・プラスチックの食品容器（4823.69／3924.10／3923）は F01/F02 → 個人使用の免除に頼ることになる。**「同規格4件」の「件」を袋で数えるか1枚で数えるかは公告に書いていない＝グレー**。まだ注文していなかったので差し替えを推奨した
- 鍋の出品文「免關稅及營業稅」と言い切るのは誤り（半年6回の制限）→ 「原則免稅＋第7次起不適用」に直させた。2個買いは NT$2,000 を超えて買い手に課税されるので1注文1個

## 失敗しかけたこと・気づき

- 🔴 **依頼文の品目名を信じない。**「アルミ製お弁当カップ」は**メーカー公式では紙＋PBT**（東洋アルミという社名に引っぱられた）。「メラミンスポンジ」も実際の候補は**あみたわし（ズビズバ サラッシュ）**だった。**材質で税番が変わり、判定が変わる。**まずメーカーの公式ページで材質を確かめる
- 台湾の官庁サイトの検索要約は「瓷製（陶磁器）のみ」と読める版と「食品容器・器具全般」と読める版が食い違っていた。**公告の原本（スキャン PDF）を画像で読んで確定した**（pdftotext で空になったら pdftoppm で PNG にして読む）
- 輸入手続の**法律上の義務は買い手（受取人）**にある。ただし止められたら返金と罰点は当社に来るし、Shopee の包括条項は当社への契約上の制限になる。「義務は誰か」と「損は誰か」を分けて書くと、秘書と社長に伝わりやすい
- TFDA への照会は外部への連絡（§4.1）にあたり、CLAUDE.md §3.3-15 の「自分から申告しない」とも衝突しうる。**差し替えで論点が消えるなら、照会を提案しない**
