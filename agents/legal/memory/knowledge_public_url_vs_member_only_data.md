## 1. 結論（NETSEA・再利用可）

- **商品URL単体は公開可。**ただし条件2つ：①価格・原価・利益の数値を同一行に置かない ②サプライヤーの名簿化に至らない少数掲載
- **卸値と同じ行に並べたら行ごと不可。**URL は出典ではなく「どのサプライヤーのどの取引条件か」を確定させる**識別子**になる
- 非ログインで卸値は見えない（2026-09-06 再実測。商品3ページ＋検索一覧60件＋独立クライアント2系統）。**希望小売価格は見える。**卸値と混同しないこと

## 2. 「公開情報だから白」を3本足で立てる（1本足にしない）

E は「非ログインで見えるか」の1本足だった。**次からは必ず3本引く。**

1. **実測**：非ログインで当該情報が表示されるか
2. **相手方の意思表示**：`<meta name="robots" content="index,follow">` ／ `robots.txt` が当該パスを Disallow していないか ／ `Sitemap:` の公示 ／ JSON-LD に canonical URL を自ら記載しているか
   → **「自ら検索エンジンに公開を要求している URL」の転記が『開示・漏洩』に当たる解釈は成り立たない。**これが一番強い
3. **条文の限定を読む**：NETSEA API 15条1項は「一切の情報」ではなく「**本規約において提供された**相手方の一切の情報」。会員規約7条2項3号は「**利用者の権利の行使の範囲を超えて**」。
   → **非会員でも同じことができる行為は、会員としての権利行使に依拠していない＝範囲を超えない。**

**残存リスクは必ず書く：両規約とも「公知情報は対象外」の除外規定を置いていない（起草上の欠陥）。**だから条件付き Yes に留める。

## 3. E に無かった2つの危険（今回追加）

- **逆算リスク**：URL と同じ行に「Amazon価格＋利益率／損益分岐仕入れ値／想定仕入れ額」があると、FBA 手数料が公開されている以上**卸値は復元できる**。数値そのものを消す運用では防げない
- **名簿化リスク**：会員規約**第7条1項3号**「本サービスを利用する他の者の情報の収集を目的とする行為」は**1項＝事前承諾の例外なし＝絶対禁止**。**サプライヤーの一覧は価格が1件も無くてもアウト。**件数が独立の判定軸になる

## 4. 機械ガードの誤検知は「法務論点」である

社長・秘書から「誤検知も害だ」と提起された。**当職はこれを法務判断に含める立場を採る。**

> **保護効果ゼロの印は、安全側ではなく危険側の設定である。**バイパス（`--no-verify` / `ALLOW_WHOLESALE_DATA=1`）はフックのメッセージ自身が案内しており、誤検知が続けば必ず常態化する。そのとき本物が来ても止まらない。

**「印が守りたいものと一致しているか」を必ず検算する。**今回 `netsea.jp/shop/` は卸値の代理指標として選ばれていたが、卸値は非ログインで見えず URL は見える＝**代理指標として逆**だった。

**保護効果ゼロの実証のしかた（強力）**：同一内容の md 版が同じURLを含んだまま**既に公開済み**（コミット `99593dc`）だった。**同じものが既に公開されているなら、片方を止めても公開状態は変わらない＝その検知は純粋な誤検知。**

## 5. 印の設計指針（次の卸サイトでも使える）

| ダメな印 | 良い印 |
|---|---|
| 公開ページのURL | **ラベル＋直後に数字**（`(卸値\|仕入値\|wholesale_price)…[:=,\|]…[0-9]`）。散文の「卸値は載せない」は数字が続かないので通る |
| 単語単独 | **共起**（URL × 卸/仕入の列見出し）、**逆算共起**（URL × 利益率/損益分岐）、**件数**（ユニークsupplier_id ≥5） |

## 6. 手順メモ（毎回同じ）

- API 規約：`curl https://api.netsea.jp/docs/buyer/openapi.json` → `info.description`。**`json.loads(..., strict=False)`**（制御文字で素の `json.load` は落ちる）。全16条・19条は無い
- 会員規約：`curl https://www.netsea.jp/agreement/statement` → タグ除去
- 商品ページ：`curl -A "<普通のUA>"`。価格は**サーバ側描画**で、非同期の価格エンドポイントは無い（`url: "…price…"` の一致0）＝JS を実行しても値は出ない
- **1ページで結論を出さない。**別サプライヤー2件＋検索一覧＋別実装クライアント（WebFetch）で裏を取る
