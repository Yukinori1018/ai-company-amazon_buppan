## 1. 一番の学び — ページの注記で判定しない。規約全文まで読む

ザ・ビジネスモールの企業ページの注記は「売り込みやテレマーケティングに利用することは禁止」だけ。明文主義で読めば買い手の打診は入らない。**ところが利用規約 第17条は (14)「掲載されている情報を自社の営業活動またはその他の理由を含め利用する行為」・(13) 同意のない企業情報の収集 まで禁じていた。**注記は禁止の一部を目立つ所に出しただけ。
→ 「注記の文言に入らない」は結論にしない。**禁止の本体はどこか（規約・約款）を必ず探す。**NETSEA で「禁止条項→制裁条項まで読め」と学んだのと同型（knowledge_netsea_and_exhibition_terms）。

規約の探し方：b-mall はフッタに規約リンクが無く、`/kiyaku/` `/terms/` 等は全部404。**WebSearch「<サイト名> 利用規約 <ドメイン>」で `/memberyakkan/` が出た。**推測URLを叩くより検索が速い。

## 3. NG の理由づけの型 — 非会員に契約が及ばなくても NG にできる

非会員には同意手続きが無く、規約の契約的拘束は弱い（民法548条の2）。それでも NG にした理由：①明文の意思表示を読んだうえでの利用＝故意 ②規約違反の取得は個情法20条1項「不正の手段」の余地 ③**本当の制裁は訴訟でなく不承認（9条）・利用取消（25条）＝本命の正規経路（商談モール）を将来失う。不可逆性が高い。**
→ 「契約が及ぶか」で止まらず、**相手が実際に持っている制裁手段は何か、それで何を失うか**で3軸を評価する。

## 4. 送る側の共通条件（どの名簿でも同じ。次回はこれを貼る）

1. 名簿は agent_output・非公開シートのみ（PUBLIC リポ不可：著作権21/23条・個情法27条）
2. 連絡先は各社の公式サイトから（展示会・DB の画面から取らない）
3. メール宛先は自社サイトで公表されたアドレスだけ（特電法3条1項4号・施行規則3条本文）。「広告メールお断り」併記ならフォーム/電話へ（同ただし書）
4. 署名に名称・住所・受信拒否の連絡先・問い合わせ先（法4条）
5. URL を貼らない（貼るなら /partners）・自社の販売力の売り込みを書かない
6. 初回に利用目的1行（個情法21条1項。当社サイト `/privacy` は2026-10-05時点でも404）
7. 断り・受信拒否は会社単位・全経路で即日永久停止（法3条3項）
8. 接点を偽らない（来場していない展示会を「お会いした」と書かない）

## 5. この依頼の処理手順（ルーチン化）

1. 経路ごとに：robots.txt → ページ/PDF の表示 → サイトの利用規約（フッタ→無ければ検索）→ 定義集（適用範囲）を原文取得
2. 表示と規約を「取得」「保存・公開」「連絡に使う」の3行為に分けて当てる
3. 法令（特電法・個情法）は経路に依存しないので共通条件として1回だけ書く
4. NG 経路は A/B/C（正規の使い方／運営者の同意／同じ会社を別経路で拾う）＋3点セットを付ける（社長方針：NG でも選択肢から外さない）
5. 上流の計算（名簿倍率など）に影響があるかを1行で書く。今回は NG の b-mall が元々数に入っておらず倍率不変
