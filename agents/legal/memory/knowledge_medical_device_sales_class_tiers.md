# 医療機器の販売要件は「クラス」ではなく「区分」で決まる（2026-09-14 / T-20260914-004）

## 訂正（9/13 白地図 B5 の粗さ）
9/13 は「クラス1は届出不要、クラス2は届出＋営業所管理者（実務経験）で実質不可」とした。この二分は粗い。クラス2（管理医療機器）は次の3つに分かれる。

| 区分 | 手続き | 管理者 | 個人・実務なし |
|---|---|---|---|
| 特定保守管理医療機器（告示297号。パルスオキシメータ・電動式吸引用ポンプ等） | 許可（法39条・6年更新） | 高度管理等3年＋基礎講習（規則162条） | 不可 |
| 特定管理医療機器（家庭用指定以外の管理） | 届出（法39条の3） | 高度管理等1年 or 特定管理3年＋基礎講習（規則175条） | 不可 |
| 家庭用管理医療機器（大臣指定27品目：家庭用マッサージ器・家庭用超音波吸入器・家庭用電動式吸入器・温灸器・電解水生成器等） | 届出のみ | 不要 | 届出すれば可 |

- クラス1（一般医療機器）は許可も届出も要らない。残る義務は規則178条3項が準用するもの（品質確保・苦情・回収・教育訓練・中古通知・不具合協力）と、記録の努力義務。
- 家庭用27品目は「届出だけで扱えるクラス2」。白地図 B5 の射程は、この分だけ広い。
- 見かけはクラス2でも、特定保守に当たれば一段上の「許可」になる。パルスオキシメータは家庭用の小型品でも特定保守。

## 判定の手順（再利用可）
1. 商品の一般的名称を取る。メーカーの製品ページか、PMDA 添付文書の冒頭行（例「管理医療機器／特定保守管理医療機器 パルスオキシメータ(17148010)」）で取れる。
2. 告示298号（mhlw t_doc 81aa6500、9ページ）で別表第1／2／3のどれに載っているかを見る。見出しは「別表第N (平17厚労告…」の形。
3. 告示297号（81aa6499、3ページ）に載っていれば特定保守。
4. クラス2なら家庭用27品目（福岡県ページが一覧化）にあるかを見る。
5. 医療機器番号の形式でクラスが分かる。…B1X/B2X…＝届出（一般）、…BZX…＝認証（管理）、…BZX…承認は高度。

## 取得の技術メモ
- PMDA 添付文書の検索画面（PmdaSearch/kikiSearch）は JS 必須で、curl の POST では結果が返らない。
- PDF は GET で取れる：`https://www.pmda.go.jp/PmdaSearch/kikiDetail/ResultDataSetPDF/<企業コード6桁>_<医療機器番号>_A_01_0N`。N は版で、_01 が無ければ _02 を試す。企業コードは Web 検索で同社の別 PDF を見つけて拾う（KAEI＝202630）。
- 告示は mhlw t_doc を curl で全ページ取って grep する。WebFetch の要約は「別表のどこか」を落とすので使わない。
- e-Gov 法令API：lawdata/335AC0000000145（薬機法）、336M50000100001（施行規則・45MB）。Article の Num が「39_3」の形なので XML で抽出する。
- JMDN 基準DB（std.pmda.go.jp）の名称検索はフレーム経由で、GET では結果リンクが取れなかった。

## 広告の落とし穴
一般医療機器の体動センサ（E-202）を「無呼吸アラーム」と書くと、別表第1（クラス3）の一般的名称の効能を名乗ることになる。既存の Amazon タイトルにある語でも、そのまま流用しない。

## 今回の判定
- KAEI：対象外。売上の大半がパルスオキシメータ（特定保守）。
- シースター：E-202（一般）と E-401（医療機器でない）に絞れば打診可。鼻水吸引器（特定管理）と S-130（特定保守）は外す。
