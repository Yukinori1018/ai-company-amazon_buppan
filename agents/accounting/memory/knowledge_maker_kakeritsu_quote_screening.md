# メーカーの掛け率提示を「見積りを頼む商品」に絞る型（T-20260930-001 かめびし / 2026-10-19）

メーカーから「掛け率◯〜◯%・送料別・価格設定は当社任せ」と条件が来て、「どの商品なら採算が立つか」を問われた回。
メーカー直取引の打診が月300社ペースで回っているので、**同じ依頼は今後も来る**。手順と、効いた指標を残す。

## 1. いちばん効いた指標 ―「5%に必要な Amazon 売価 ÷ 掛け率の基準価格」

商品ごとに利益を出す前に、**「利益率5%に必要な Amazon 売価が、基準価格の何倍か」**を出すと、1行で振り分けられる。

```
必要倍率 ＝ 5%を取れる Amazon 売価 ÷ 掛け率の基準価格（希望小売 or 公式通販）
実際の倍率 ＝ Amazon の平時売価 ÷ 基準価格
実際 ≧ 必要 なら見積りへ、届かなければ見送り
```

かめびし（掛け率80%・おりおん経由・ガラス瓶）の実例：単品900mlは**必要1.53倍に対して実際1.14〜1.39倍**で全滅、三年醸造500mlだけ**必要1.47倍・実際1.50倍**で通った。
**交渉で掛け率を下げられない相手（先方が利益が薄いと明言）では、売価側の倍率しか動かせない**ので、この指標がそのまま結論になる。

目安（掛け率80%・おりおん・2,000円台の重量物）：**単品はAmazonが基準の約1.5倍、掛け率90%なら約1.65倍ないと5%に届かない。**

## 2. 重いガラス瓶は「物流費が売価の約3割」

1本あたりの固まり（三年醸造500ml・2,580円の例）：ケース送料92円＋決済17円＋おりおん（ラベル・検品・箱・FC送料・割れ物梱包）181円＋FBA配送代行420円＋保管13円＝**約722円＝売価の28%**。
- 掛け率を5pt下げても86円。**物流費の方が掛け率より大きい**。
- 瓶1本ごとにほぼ定額でかかるので、**安い・小さい瓶ほど必要倍率が上がる**（500ml 1,145円の商品は1.72倍）。**単価の高い大容量（1.8L）が最も有利（1.32倍）**。
- **おりおんの料金表に緩衝材（割れ物梱包）の項目がない。** 液体・ガラスは推定で置くしかない（55円/本で置いた）。次回おりおんに確認する価値あり（秘書経由）。

## 3. 掛け率の「基準」を必ず疑う

先方は「掛け率80〜90%」とだけ言う。基準が**希望小売価格か公式通販の価格か**で卸値が変わる。
かめびしでは、ヨドバシが「希望小売1,933円」、公式通販が「1,577円」と**22.6%も違った**（二次情報）。
希望小売が基準なら、通った1商品も赤字になる。→ **見積り依頼の質問の1番目に必ず入れる。**

## 4. 自宅受けとの比較は「現金の差 − 社長の時間」で出す

おりおん→自宅にすると現金で1本約100〜113円浮くが、社長の作業（1ケース40分と推定）を時給1,100円（仮定）で換算すると約61円。**実質40〜50円の差で、判定を変えるほどではない。**
§3.4（自宅では受けない）を崩す提案は、この差で判定が反転する商品があるときだけにする。

## 5. 調査環境の制約（今回の失敗とリカバリ）

- このクラウド環境は **Keepa の API キーなし／WebFetch が全ドメインで名前解決失敗／curl はプロキシ403**。使えたのは WebSearch の要約だけ。
- → **価格はすべて「二次（日付不明）」**で、§3.5 #13 の90日中央値を満たせない。判定は「暫定」と明記し、**Mac 側で取るべき ASIN（5件・5トークン）を名指しで残した**。
- 次回：作業前に `ls ~/.config/ai-company-amazon-buppan/` と WebFetch 1回で環境を確かめ、届かないと分かったら最初から「二次・暫定」で設計する（あとから確度を書き直す手間が消える）。
