# SaaS の「必要な月だけ契約」を確かめる手順と Keepa の結果（T-20260912-002 / 2026-09-14）

論点③「Keepa を必要な月だけの API 契約にする」の前提確認。成果物は `workspace/output/deliverables/T-20260912-002/09_Keepa再契約の可否.md`。

## Keepa の確定事実（公式・2026-09-14）

| 論点 | 結果 | 出典 |
|---|---|---|
| 月単位の解約 | いつでも可。支払い済み期間の終わりまで使える。期間内なら取り消せる | api-docs/plans-tokens・API T&C §9(2) |
| 返金 | 無し（日割りも無し） | API T&C §9(2) |
| 期限後 | 復活不可＝新規契約。待機期間・初期費用の記載は無い。支払い後すぐ有効 | plans-tokens・keepa.js 購入画面 |
| 再契約の価格 | その時点の定価（§7）。値上げの30日前通知（§9(3)）は継続中の契約だけの保護 | API T&C |
| 請求日 | 再契約した日が新しい更新日（§9(1)） | API T&C |
| 無料版 | co.jp では売れ筋ランク・出品者数・評価・レビュー数のグラフが制限される。Finder 等は購入ページへ転送 | keepa.js `graphIsRestricted` |
| Pro | ランク・出品者数の履歴・Finder＋API 1トークン/分が付く。API 契約（20/分）では Pro 画面は開かない | keepa.js |

- **アカウント削除でも契約は終わる（API T&C §12(1)）。解約はダッシュボードの解約ボタンだけ。** 社長への手順に必ず書く。
- 運用の型：再契約した当日に解約も入れる（期間末まで使えるので払い忘れを防げる）。どちらも §4.1 の社長の一手。
- 年額（1€=178.2円）：年12回 104,782円／Pro×12 62,014円／必要な月だけ 年3回 26,195円（中央）。**年7回までは Pro より安い。**

## 気づき（次に効く）

1. **シミュレーションの置き値と運用の回数がずれていた。** マサルは「補給月は年1回」で 72%（重みづけ57%）を出していたが、依頼文の例は年3〜4回。固定費の感度（月1,000円≒3.5pt）で年3回は約 −5pt。**「必要な月だけ」系の案を見るときは、置いた回数を必ず確かめる。**
2. **SPA で読めない公式は、サイト自身が読み込む JS と cdn の規約テキストで読める。** keepa.com 本体は Cloudflare で 403 だが、`keepa.com/cdn/termsAPI.txt`・`termsSubscriptions.txt`・`keepa.com/cdn/<build>/keepa.js` は curl（通常の UA）で取れる。購入画面・解約画面の文言や、無料版の制限の実装まで読める。回避ではなく公開配信物の単純 GET。WebFetch は api-docs にも 403 を返したが、curl は 200 だった。
3. **海外 SaaS の消費税：** リバースチャージの申告は「一般課税かつ課税売上割合95%未満」だけ。免税事業者は無関係（国税庁 No.6118 注4）。課税事業者化（最短2029年）で見直す。

## 手順（同種の依頼＝「サブスクを必要な月だけにできるか」）

1. 公式の料金・規約で、①解約の時期と期間末までの利用、②返金、③期限後の復活可否、④再契約の待機期間・初期費用・価格、⑤請求日の扱い、⑥削除など「やってはいけない終わらせ方」を表にする
2. 無料版・下位版で何が失われるかを、機能ごとに ○× の表にする（実装や公式の機能一覧で。二次情報は補強だけ）
3. 年額を回数の3シナリオで出し、**上位の代替（Pro 等）との損益分岐の回数**を必ず添える
4. 既存のシミュレーションが置いた回数と照合し、ずれを pt で示す
5. 会計（計上時期・科目・消費税）は1〜2行。税理士確認推奨を付ける
