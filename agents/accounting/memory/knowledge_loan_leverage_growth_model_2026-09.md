## 1. いちばん効いた発見：融資は「資金の天井」しか外さない

月商は **min(資金の上限, 社数の上限)**。融資は前者だけを上げる。
- 社数28社（マサルの生涯上限）で必要運転資金は **361万**。自己200万＋借入800万＝1,000万を持つと **639万が遊休**、
  遊休分の利息だけで **年24.9万**。月返済10.9万が何も生まずに出ていく。
- **同じ28社でも借入300万なら月返済4.09万。差は月6.8万・2年で163万。**
→ 結論は1行：**借入は社数の実績に後追いさせる**（「手元資金 < 必要運転資金」が3ヶ月連続で成立してから増額）。
「融資を取れば伸びる」という案が来たら、必ず社数の天井を並べて見せること。

## 5. 単価の下限（10 の要点・実装に渡した値）

式：`最低売価 = 1個あたり固定費 ÷ (1 − 利益率 − 1.1×掛け率 − 1.1×カテゴリ料率)`
分母が0以下＝**価格をいくら上げても到達不能**。ここが表の主役。

- **既定の足切り 2,200円**（標準区分3・10.4%・6掛けの損益分岐2,163円）。**実用下限3,900円**（利益率10%）。
- **6掛けでは利益率20%はカテゴリ料率12.7%未満でしか成立しない** → ホーム&キッチン/文房具/DIY（15.4%）は**不可能**。
  **KPI20%を守るなら「5掛け以下」が必須条件。**
- **掛け率を1段階（6→5掛け）下げる効果 ≒ 売価を倍にする効果**（標準3・10.4%で 3,884→2,071円）。交渉の価値はここ。
- 1個あたり固定費：小型340 / 標準1 396 / **標準3 488** / 標準6 650 / 標準8 1,254 / 大型4 1,921円。
  **重い・かさばる品は送料が二重に効く**（仕入送料＋FBA納品送料）。標準8以降は送料 > 配送代行手数料。
- **最大の落とし穴：掛け率を「上代基準」で判定すること。** Amazon実売が上代の80%なら実効掛け率は6→7.5掛けで、
  標準区分3の損益分岐が 2,163円 → **8,053円** に跳ね、利益率10%は到達不能になる。
  **採算判定は必ず実売基準に直す。** 交渉は上代基準で話すので、ここを混ぜると全件が甘く出る。
