# 免税事業者セラーの納税情報・インボイス（T-20260726-002 / 2026-07-26）

社長＝個人・副業・**免税事業者・インボイス未登録**（T+13桁なし）・日本店B2C中心。

## 確定事実
- Seller Central「VAT/GST登録番号」ページ（/tax/jpregistrations）= 適格請求書発行事業者登録番号（T+13桁）欄。**課税事業者のみ取得可**。免税は**空欄でOK・任意・罰則なし**。
- Amazon手数料は消費税課税対象だが、**仕入税額控除は課税事業者だけ**。免税は控除場面なし → 番号有無で控除可否が変わるのは「課税事業者化後」の話。今の社長に番号入力メリットなし。
- 別物: 基本の「納税情報」（設定→出品用アカウント情報→納税情報）は**免税でも必須**（売上金受取の前提。住所/氏名は本人確認書類と完全一致）。
- B2C=一般消費者はインボイス不要（控除しない）→ 免税セラーが任意登録する主目的が薄い。

## 現段階の推奨
- **任意インボイス登録は非推奨**（課税事業者化で売上消費税の納税義務発生／B2Cでメリット活きない）。
- 再検討トリガー: ①課税売上が1,000万円ライン接近（どのみち課税化なら登録デメリット消える）／②B2B・法人顧客がインボイス要求。

## 2026税制の最新（要更新注意）
- **2割特例**: 個人は令和8年分（2026年分）が最後。令和8年度税制改正で個人限定・令和9/10年（2027/2028）は**3割特例**に移行して2年延長。法人は延長なし。
- **免税事業者からの仕入経過措置**: 2026/9/30まで80%控除 → 2026/10/1以降50%控除（社長の"顧客が事業者"の場合の話。B2Cなら無関係）。

## 運用ルール
- ハジメもカズヨも税理士資格なし → 断定的税務助言・個別税額計算はしない。**税理士確認推奨を必ず明記**。フォーム入力・送信は社長本人（代行不可）。
