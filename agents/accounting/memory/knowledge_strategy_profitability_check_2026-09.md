# 戦略案の採算チェックの型 — 固定費3段階・利益率3定義・キャッシュ最薄月（T-20260912-002 / 2026-09-13）

タケシ（案B・週10通・月商45万・+7%）とマサル（月商20万・−4%）の分布を「数字の構造」で検算した回。
シミュレーションの乱数が変わっても壊れない部分（固定費・利益率の定義・損益分岐・在庫原価の算出過程）だけを担当した。
成果物: `workspace/output/deliverables/T-20260912-002/03_複合戦略_採算チェック.md` ＋ `03_calc_採算チェック.py`。

## 1. 「利益率」は3つ混在する。差が出たらまず定義を揃える

| 記号 | 名前 | 社内で使っている場所 |
|---|---|---|
| A 粗利率 | （売価−仕入）÷売価 | EC STARs の掛け率の裏返し。社内では未使用 |
| B SKU利益率（レーン利益率） | 三層＋外注＋送料＋返品引当を引いた後・固定費の前 | v1.3 の5%下限、アミノの8%、タケシ・マサルの MARGIN |
| C 営業利益率（固定費込み） | Σ SKU利益−固定費 | タケシ+7%・マサル−4% |

- タケシとマサルの差は定義の差でなく月商の差だった。C＝B−固定費÷月商 で ±1pt に収まる。
- 会社KPI「利益率20%」は B で定義する提案を出した（社長の8/31「5%でも数を打つ」と 08 の「8%前後」が B で話しているため）。固定費は800万で0.4ptなので、大きくなれば A と C は同じ値に収束する。
- 月商30万未満で C を判定に使うと構造的に赤字に見える。固定費29,151円は月商20万で14.6%、45万で6.5%、800万で0.4%。

## 2. 固定費は「無条件／条件付き」で分け、3段階で出す

| 段階 | 月額 | 中身 |
|---|---:|---|
| 1 今 | 14,253円 | 大口5,390＋Keepa API €49（8,732・1€=178.2円）＋ドメイン131 |
| 2 成立2〜3社 | 29,151円＋商標44,900円（一回） | ＋セラースプライト13,998＋会計ソフト900 |
| 3 成立6社 | 30,572円＋GS1 17,050円/年 | ＋GS1 |

- 他エージェントのモデルは固定費14,000円で置いていて妥当。ただし **商標が本文に書いてあるのにコードに無い**（タケシ）、会計ソフト・GS1・ドメインが両モデルに無い。12ヶ月の月商中央には効かず累計損益を5〜6万押し下げるだけなので、差し戻しでなく「明記」で済ませた。
- **固定費は両モデルとも資本枠（10→30→100万）の外＝社長の別財布**。悲観では資本30万・100万が発動しないので、固定費・商標の28万を誰が出すかが計画に無い。これは必ず1行明記させる。

## 3. 損益分岐月商と逆算は1行で出る

- 損益分岐月商 ＝ 固定費 ÷ レーン利益率。段階2・12%で24.3万、9%で32.4万、20%で14.6万。
- 「月商45万・営業利益率+7%」に要るレーン利益率 ＝ 7%＋29,151÷450,000 ＝ 13.5%。相乗り12%・卸6〜8%では届かず、独占・OEM（25〜30%）が月商の2割要る。タケシの+7%は1〜2pt甘い（経理の中央 +4〜6%）。
- **モデルの出力値「レーン利益率+9%」は、コードが FIXED（14,000）だけ戻してスプライト分を戻していないため3pt低く出ていた。** 他人の出力値を使うときはその計算式（`lane_pr`）まで読む。

## 4. キャッシュ最薄月は決定論の月次表で出せる（乱数不要）

- 必要現金 ＝ 固定費累計＋一回払い＋在庫拘束（翌月月商×原価率0.53×在庫倍率1.5）−回収済み SKU利益。月別に並べて最小を取る。
- 結果: 中央 2027-08・52万／楽観 2027-08・108万／悲観 2027-09・38万。
- 楽観だけ資本が律速に戻る（2027-05 に47万不足）。「成立3社かつ月商30万超かつ在庫日数90日以内なら100万を前倒し」の分岐を提案した。
- 融資は「累計売上100万」到達（中央 2027-08）の後。タケシの「2027-06 申請」は中央で2〜4ヶ月早い。

## 5. 800万の在庫原価は「原価率×在庫倍率」で幅を持たせる

- タケシの580〜720万 ＝ 0.6×1.2〜1.5 は算術として正しい。ただし原価率は利益率12%なら0.53・20%なら0.45で、在庫倍率1.2〜1.5は月次補充の前提（EC STARs・二次）。当社の消化月数3ヶ月・最低ロットでは2.0〜3.0が現実的。幅は430〜1,270万。
- **同じ文書の §0（480〜600万）と §1-3（580〜720万）で原価率が0.5と0.6でずれていた。** 数字の不一致は検算の第一発見物になりやすい。

## 6. 税・会計で今回整理した点（税理士確認推奨を必ず付ける）

- **インボイスは売り手が発行する。買い手（当社）の登録番号は仕入れ取引の要件にならない。**「インボイス未登録だからメーカーに断られる」は誤解。効くのは Amazon Business の法人購入者側（未登録セラーからの仕入れは控除50%・2026-10〜）。
- 商標44,900円は10万円未満なので一括経費。弁理士込みで10万円超なら商標権として10年償却。出願方法で税務処理が変わる。
- **在庫は経費にならない**（売上原価＝期首＋仕入−期末）。「仕入れ先行で初年度赤字」は現金の話であって所得の話ではない。廃棄した在庫だけ損失。
- 開業前（2026-08-20 以前）の Keepa 等は開業費（繰延資産・任意償却）。
- 会計ソフト（MF パーソナル 900〜1,280円/月）の契約有無が未確認。青色65万円控除は複式簿記が条件なので、これは「条件付き」でなく実質「無条件」の固定費として扱った。

## 7. 月次KPIの提案（3つに絞った）

固定費カバー率（SKU利益÷固定費・100%が損益分岐）／在庫日数（上限180日）／売上加重 SKU利益率（KPI 20%の測定単位）。
月商が小さい期間でも判定に使える数字だけを選ぶ。営業利益率・粗利率・手残りは置かない。

## 手順（次に同種の依頼が来たら）

1. 他エージェントの計算コードを開き、FIXED・MARGIN・cash の定義を読む（出力値でなく式を見る）
2. 固定費を「無条件／条件付き」に分け、発動条件付きで3段階の表にする
3. 利益率の定義を A/B/C で仕分け、どの数字がどの定義かを対応表にする
4. 損益分岐月商と「目標が成り立つレーン利益率」を逆算（算術）
5. 決定論の月次キャッシュ表で最薄月を出す（乱数は使わない。3シナリオは経路を変える）
6. 一回払い（商標・GS1）と資本枠外の固定費を「誰の財布か」まで書く
7. 税は論点表にして、税理士確認推奨と確度を全行に付ける
8. 社長判断は A/B/C＋推奨で5つ以内。§4.1（課金）該当は試算に留める
