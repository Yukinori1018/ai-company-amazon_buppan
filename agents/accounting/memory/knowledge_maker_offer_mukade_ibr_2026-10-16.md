返信の条件は「卸＝Amazon・Yahoo・楽天での販売価格の50%（消費税・運賃込み）、最低ロットは粒剤10箱・補強剤12個」。
成果物は `agent_output/T-20260930-001/80_ムカデ博士_採算.md`（非公開・卸値の実額入り）。計算は同じフォルダの `80_work/calc80.py`。

## 1. 手順（次にメーカーから条件が来たら、この順で進める）

1. **カートの持ち主を Keepa の出品者 API で引く**（`/seller?seller=ID1,ID2`、1社1トークン）。会社名・住所・電話が返るので、メーカー本人かどうかが一発で分かる。365日のカート獲得率は `stats.buyBoxStats[sellerId].percentageWon` で見る。
2. **「販売価格の◯%」の基準は、公式の特商法ページの価格と、Keepa のカート価格の365日を突き合わせる。**メーカーが価格を固定している場合（今回は365日一度も変わらず）は、どちらの基準で読んでも同じ額になる。「定価か Amazon 価格か」で迷ったら、まず両方を取って比べる。
3. **取り分は「月販÷(FBA＋1)」だけで置かない。**メーカー本人が同じ価格で出していると、カートはほとんどメーカーに行く（今回は87%）。中央の取り分には、既にいる第三者セラーの実際のカート獲得率（今回は12%）を使う。式の値は楽観として残す。
4. 3シナリオ × 2ルート（おりおん経由と、メーカーが FBA へ直送）で計算し、損益分岐の卸率（0%・5%・20%）を二分法で出す。
5. ランクの12か月履歴を暦月ごとの中央値に直し、ピークと底を書く。§3.3-20 を字面どおりに当てた結果と、中央の売り切り月数を並べる（売り切りが短ければ「半年寝る」には当たらない、と書き分ける）。

## 2. 効いた発見

- **重い商品（10kg）は FC 納品送料が1個の手残りを支配する。**粒剤の場合、おりおん経由は中央300円、メーカー直送なら919円。差の大半が608円/箱（推定）。**メーカー自身が FBA に納品している会社なら、直送を頼むのが一番効く交渉になる**（卸率を5ポイント下げてもらうより効く）。
- 価格を固定するメーカーでも、プライム感謝祭のようなセールでは値下げする。2026-10-16 の実画面は「5%割引で5,748円」で、Keepa のカート履歴には出ていなかった。メーカーと同じ棚に並ぶと、**メーカーのセールがこちらの採算を消す**（中央の手残り300円 → 52円）。並行出品の可否と、セールの予定はセットで聞く。
- §3.3-16 のキーゾン相当の式は、月50個前後の商品では1/4程度に小さく出た（3か月で10・14・10個、monthlySold は50）。月13個を超えるときは、中央を両者の間に仮定で置き、仮定だと明記する。
- 大型（9kg 超）の保管料は1〜9月3.278円・10〜12月6.984円（いずれも1,000cm³・1か月あたり）。小型・標準より安いが、10〜12月の料金は2.1倍になる。
