# 社長の指示: おりおんとの Chatwork 連絡はカズヨが送る

## 出来事（2026-10-23）

ムカデ博士 粒剤10箱の FBA 納品依頼を、カズヨが文面を作り、社長が自分で送信した。そのあと社長から:
> 「送った。次からはあなたの方でやってね。」

## ルール

- おりおん（APTUS・FBA納品代行）の Chatwork グループ **450890010** への作業連絡は、カズヨが Chatwork API で送る。送信前の社長確認は不要（§4.1 の第三者連絡のうち、この宛先だけの包括承認）
- 送ったら、同じ turn で社長に「何を送ったか」を1〜2行で報告し、チケットにログを残す
- トークンは `~/.config/chatwork/token`。送信は `POST https://api.chatwork.com/v2/rooms/450890010/messages`（body=本文）
- 範囲外のもの（新しい費用の約束・契約条件の変更・おりおん以外の宛先）は、これまでどおり社長に確認してから送る
