# 気づき: Sato-Scope と ERESA は「代替」ではなく「補完」（別レイヤー）

- **記録日**: 2026-05-25
- **記録者**: 秘書カズヨ
- **種類**: 分析統合時の失敗 ＋ 社長のこだわり

## 何が起きたか

T-20260520-003 v2（サトルの AI 連携ツール再調査）で、ERESA と Sato-Scope が同じ
「AI リサーチツール」の比較表に並んだ。これを私（カズヨ）が統合する際、
**「ERESA で代替できる＝ Sato-Scope の機会損失リスク」**と誤って扱った。
ハジメの ROI 試算でも「案C＝ERESA のみ」を Sato-Scope の代替候補として並べてしまった。

社長が自分で ERESA を調べ、「同じものではない」と感じて指摘 → 誤りが判明。

## 正しい理解（社長と一致）

| | Sato-Scope | ERESA AI |
|---|---|---|
| レイヤー | **仕入れ発見**（楽天/Yahoo! ⇄ Amazon の価格差） | **Amazon 内 分析・出品支援**（ランキング/履歴/キーワード/AI 文章・画像生成） |
| 答える問い | 「どこから仕入れて Amazon で売れば儲かるか」 | 「Amazon の中でどう戦うか」 |
| 仕入れ元の価格差 | **主役** | 見ない |

→ 機能が重ならない。**代替ではなく補完**。将来は両方併用もありうる
（仕入れ候補=Sato-Scope、出品文磨き=ERESA）。

## 教訓（次回以降）

1. **「同じカテゴリの表に並ぶ」≠「代替可能」**。比較表を統合する時は、
   各ツールが「答える問い」「見る方向」が同じか必ず確認する。
   見る方向が違えば補完。
2. ROI 比較で代替案を並べる前に、**それが本当に同じ仕事を置き換えるか**を検証する。
3. サトル（リサーチャー）への次回発注時は、**「代替/補完」の区別を明示**するよう指示する
   （単なる機能比較表だと代替と誤読されやすい）。

## 派生する判断

- 「ERESA があるから Sato-Scope 不要」論は**取り下げ**。
- Sato-Scope は仕入れ発見を担う**唯一の自社資産**（ERESA に置換不可）→ 自社開発の意義は維持。
- ただし「軸B 0周問題」（社長の販売実行力が支配変数）は本訂正後も有効。ツール種別と無関係。
