# 段（取引先の深さ）が拘束条件であって、社数ではない — 11 v2 の学び（2026-09-21）

## 一言
**社数は工数から決まる従属変数。利益を決めるのは段構成。** 「◯社作れば月◯万」という設計は、段進行率を素直に通すと必ず壊れる。

## 何が起きたか
成果物11 v1 で「78社 → 月営業利益229万」と書いた。マサル13 が算数だけで内部矛盾3件を指摘し差し戻し。
- §4-1 に段進行率（段1→2=40%、段2→3=20%）を書きながら、§4-3 の内訳では段3以上を42%（33社）にしていた。**40%×20%=8%（6.2社）で5.3倍の開き。**
- その率で通すと 78社＝月商710万・粗利率17.8%・**月営業利益86万**（▲143万）。200万には169社。
- 12ヶ月キャッシュ+24万は、ヒアリングにない「本業から月10万注入（24ヶ月240万）」で立っていた。

## 再発防止（チェックリスト）
1. **率を書いたら、その率から内訳を機械生成する。** 率と内訳を人手で別々に書いた文書は必ず食い違う。コホートモデルを1本持って、表は全部そこから出す。
2. **「必要条件」と書いた数字（78社）を、いつのまにか「十分条件」として扱わない。**
3. **資金計画に入れた入金は、全部「誰が承認したか」を付記する。** 社長が承認したのは運転資金100万と「引き出しなし」まで。注入は別物。
4. **確率の話に入る前に、自分の文書内で閉じる算数を検算する。** 差し戻しの3件は全部それだった。

## v2 で得た構造的な発見（再利用可能）
- **1社あたり月商＝段構成の従属変数。** マサルの「難しいのは1社あたり（2.8%）」と「最危険の置き値は段2→段3」は同じことの2回言い。並列に置くと優先順位を誤る。
- **段3には取引開始から6ヶ月要るので、「段3以上の比率」は時間の関数。** ゼロから始めて成約率が後半ほど上がる（＝獲得が後ろに寄る）設計では、24ヶ月後の段3比率は最大でも26%。**42%は率ではなく期間が足りない。**
- **獲得（量）と段上げ（率）は、社長の週20時間の上でほぼ排他。** 交渉45分/社にすると71社で週20.2時間。両立させたいなら「段上げを1社15分/月で回せる型」を作るしかなく、そこが唯一の到達経路になる。
- **成長期は運転資金が利益より速く膨らむ。** 「12ヶ月累計キャッシュ>0」を注入も借入もなしで守ると、12ヶ月後の上限は月商100万・14社。**設計条件と成長目標は、資金を足さない限り両立しない。** これは目標が高すぎるのではなく、条件が両立していないという報告の仕方をする。
- **名簿劣化と技能上昇は掛け算（別建て）。** 劣化＝名簿の性質／上昇＝送信者の性質で主語が違う。「吸収させた」は誤り。出発点の率（f=0）と劣化込みの率（母数平均）を同じものと見たのが混同の原因。

## マサルの叩きの使い方
- 彼の「階段法」（前提を1つずつ剥がして各段の差を出す）は、どの前提がいくらの値段かを教えてくれる。**差し戻しを受けたら、まず彼の階段表のどの段が自分の打ち手で埋められるかを見る。**
- 中央値の差は「悲観 vs 楽観」ではなく、たいてい**打ち手の有無**。v2 では母数拡張（41→71社）と段上げ（32→99万）の2つで説明でき、そう書いたら読み手が納得しやすい。
