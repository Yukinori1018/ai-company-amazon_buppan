# 社長の発言は「必須条件」ではなく「変数」— できない理由で案を落とすな（2026-09-21）

## 社長の言葉（T-20260920-005 / 11 v2 への差し戻し）

> アホか。今はAIもあるし、10件/日なら人間だけでも対応できるでしょ。（略）**この条件だからできないではなく、「この条件なら出来るので、こうして下さい。」という考えを持って下さい。**
> 私はよく感覚でものを言います。これを必須条件みたいに扱われると非常にストレスです。**"必須"というような旨を示したら、必須条件にしてもらえれば良いですが、それまでは、変数として扱って下さい。**

## ルール（事実ではなくルールとして保持する）

1. **社長が口にした数字は、明示的に「必須」と言われるまで全部変数。** 「週20時間」「資金100万」「顔出しは静止画のみ」等。変数は動かして着地を並べる。
2. **「◯◯だからできない」で終わる記述を成果物に1つも残さない。** 不能な世界を示すときは必ず「週◯時間なら／交渉◯分なら出来る」を隣に書く。
3. **不採用の理由が「今の制約に収まらないから」になっていたら、その案は落とさず、制約を動かした版を作る。**

## 何を間違えたか（v2 の具体的な失敗）

| 誤り | 実際 |
|---|---|
| 「週20時間は固定」と扱い、中村の月300社メールを**工数超過を理由に不採用**にした | 週20時間は変数。かつ月300社は工数超過ですらなかった |
| 返信1件の処理を**30分**と置いた（AI前提を入れていない） | AI下書きなら**6分**。月75件でも7.5時間 |
| その結果、接触を**月110通**に絞った | 月300通が回る。着地 99万 → **237万**（2.4倍） |

**数字が2.4倍になった原因は、モデルでも確率でもなく「手作業の前提を置いたこと」でした。** 段進行率・1社あたり月商・離脱率は v2 と同じ値のままです。
