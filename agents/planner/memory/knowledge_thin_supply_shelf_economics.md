# 供給が薄い棚の採算構造（グンゼ56ASIN で確定した型）

- 初出: T-20260920-003 / 13_初回仕入れ実行計画（2026-09-21）

## 一番大事な1行

**「Amazon 本体不在・出品者1〜2社」の棚で利益が出るのは、供給が薄いことで価格が上代を超えているから。**
つまり**儲かる理由と壊れやすい理由が同一**。自分の在庫を厚く入れると、利益の源泉を自分で壊す。

- 肌着・靴下は通常 Amazon 実売 < 上代。卸率67%（上代比・税抜＝税込73.7%）の相手から買って利益率20%を出す必要条件は
  **「Amazon の想定売値が上代の1.56倍以上」**。定価割れの棚では原理的に満たせない。
- だから通るのは「薄い供給で定価超えしている棚」だけ。候補18件の現在価格は直近の相場水準を **10〜30% 上回っていた**。
- 対策として置いた3つ：①**中央想定売値＝現在価格×0.85**（0.7だと中央でも赤字＝最大の感度）②1SKU は30〜60日取り分まで
  ③**服&ファッション小物は2,500円を超えて出品しない**（手数料の崖）。

## 手数料の確定事実（2026-09-21 一次取得）

- **販売手数料は税抜表示**。「販売手数料のみが税抜きで計算され、その他のすべての手数料には適用される税金が含まれます」（`sell.amazon.co.jp/pricing`）。
  免税事業者は **×1.1** して費用計上する。成果物 10 はここを引いていなかった（1点15〜35円の差）。
- **服&ファッション小物**：750円以下5% / 750超〜2,500以下 **8.4%** / 2,500超〜3,000以下 **12.4%** / 3,000超は3,000までを12.4%＋超過8.4%。
  → **2,500円の崖は1点あたり約115円（税込）**。2,533円で売るより2,500円の方が手残りが多い。
- **ホーム&キッチン／文房具・オフィス／ガーデニングは15.4%**、おもちゃ&ホビー・ホーム家電は10.4%、テレビゲーム&アクセサリは15.4%（下限なし）。
  低単価のホーム／文房具品は配送代行と合わせて粗利が消える＝**入口で落とせる**。
- **FBA配送代行の区分は薄さで決まる**。標準1（35×30×3.3cm・1kg以下）=318円、三辺合計40〜50cm=425円、〜60cm=430円。
  **薄型に入るかどうかで107円**＝原価上限の5%。実寸は FBA 料金シミュレーター（無料）で潰す。

## 原価上限式（そのまま再利用可）

```
原価上限(税込) = min( 中央想定売値×0.80 − 販売手数料(税込) − FBA配送代行 − 62 , 中央想定売値 − 500 )
中央想定売値 = 現在価格 × 0.85
```
実測：グンゼ候補10件の「原価上限÷中央想定売値」は **42〜51%**。つまり**卸が売値の半分を超えたら通らない**。
