# 2年ロードマップ（月営業利益200万）を組んだときの型 — 律速は資金ではなく「仕入れ先の獲得速度」

## 学び（再利用できる形）

1. **静的な天井（資金÷倍率）は、成長する事業では下限にしかならない。** 同じ誤りを T-20260915-002 でも踏んでいる（`knowledge_copy_practitioner_plan_2026-09`）。**2回目**なので、以後「天井」という語を見たら必ず複利で引き直す。
   - 成長式：W の月次増分 ＝ W×(g−0.04)/(c×1.5＋0.325) − 固定費（c＝1−g−0.273）
   - g=15% → 月4.5%成長（150万→1,000万に32ヶ月）／g=25% → 15.4%（12ヶ月）／g=35% → 21.6%（9ヶ月）
2. **資金の所要月数と、仕入れ先獲得の所要月数を「別々に」計算して長い方を律速と呼ぶ。** 今回は資金12ヶ月 vs 獲得48ヶ月（286社 ÷ 月6社）。48ヶ月は到達者16人の実績年数（4〜5年）と一致した。**外部の実績年数とモデルの律速が一致したら、その律速は正しい。**
3. **必要社数は結果であって目標ではない。** 200万 ÷ 1社あたり月利。0.7万なら286社（不可能）、5万なら40社（射程内）。**主変数は常に「1社あたり」に置く**。社数を先行指標に置くと計画が48ヶ月コースに戻る。
4. **本業の給与は資金調達である。** 辞めない＝生活費20万を事業から引き出さない＝24ヶ月で480万の温存。ハジメの必要融資445万とほぼ同額。**「辞める時期の設計＝資金計画」**という言い換えが社長に最も伝わる形。
5. **A/B/C は「分岐点の日付」を先に決めると短くなる。** 今回3案は2027Q3まで動きが同一。したがって「いま決めるのは案ではなく、1社あたり月利を上げる打ち手の開始日（2027年1月）」と書けた。
6. **段ごとに「変えてはいけないもの」を書く。** 10万→50万は粗利率を上げる段なので**社数を増やさない**、50万→200万は在庫と販路を変える段なので**粗利率をこれ以上追わない**（A13 の実数：粗利50%でも営業利益率16.7%＝販管費が粗利の2/3）。
7. **期限が目標を不可能にしている場合は、期限を論点に出す。** 目標額を勝手に下げない。2028-09 で15% / 2029-09 で40% / 月100万なら60% を並べ、**推奨は「いまは期限維持、2027-09-30 の判定で切り替え」**。先に下げると打ち手が緩む。
8. **クラウドファンディングは「月利」ではなく「前受による資金調達」として扱う。** 単発スパイクを月次期待値に入れない（サトルの警告）。無在庫との区別（受注生産＝自社が在庫を持つ）も明記しないと既定と衝突する。

## 何を間違えたか（v1 の致命傷）

1. **母数の上限を計算せずに目標社数を置いた。** 2,400社 × 実効成約率1.16%（劣化込み）＝ **生涯28社が上限**。私の目標40社は上限の143%で、最初から存在しない数字だった。P(200万) は 15% ではなく 2%、中央は 95万 ではなく 8万。
2. **成約率の劣化を入れなかった。** 名簿は上から撃つので実効成約率は逓減する（2%×exp(−1.2f)、母数平均0.58倍）。しかも母数を9ヶ月で撃ち切るので、**劣化は期間に薄まらず最初の9ヶ月に凝縮する**。社数▲45%・月利▲38%。
3. **「1社あたり0.7万→5万」を平均値で置いた。** 1社単位では起きる（倍率中央4倍）が、40社の平均としては起きない。**独占は成功率から派生させる**（提案12件×8%＝中央1件）。派生していない内訳は願望。
4. **判定線に「全体で踏む率」を付けなかった。** 私の判定3（2028-03 月利40万未満）は全体98%で発動＝情報量ゼロ。判定1も51%＝中央そのもの。**偽陽性だけ見ても足りない。発動率が9割を超える線は撤退線として機能しない**（投入ゲートなら可）。
5. **融資と退職を中央に組み込んだ。** 2回目融資の到達率7.5%。退職閾値35万は、本業5,460円/h vs 外注1,800円/h＝3倍の損で P10 ▲244万。

## 再利用できる手順（母数がある計画は必ずこの順）

1. **母数 × 実効成約率 ＝ 生涯の獲得数**を最初に出す。目標がこれを超えていたら、それ以外の議論は全部無意味。
2. **送信能力（期間 × 週あたり通数）も出す。** 今回は24ヶ月で約7,000通に対し名簿2,400社＝能力の34%しか使えていなかった。**母数の目標は「送信能力と同数」で打ち止め**（それ以上は撃てない）。
3. **律速は入れ替わる。** 母数を外すと次は資金（母数7,000社の世界は月商370万＝運転資金430万を要求し、自己150万＋再投資では月商260万で頭打ち）。**「AとBのどちらが律速か」で意見が割れたら、たいてい両者は違う世界を見ている**（ハジメ「融資必須」＝母数を外した後の世界／マサル「資金は律速でない」＝母数が残っている現状。どちらも正しかった）。
4. **中央が単一イベント（独占の成否）に依存する案を推奨にしない。** 推奨案は「独占0件の世界（31%）でも成立する」ことを内訳で示す。
5. **母数が未実測なら、推定で埋めずにサトルへ S 番号で発注する**（今回 S-1〜S-5）。案の数字は「仮置き」と明記し、空振り時にどの案へ縮退するか（今回は案A→案B、中央28万→18万）と、その検知日（G1 2027-06-30）まで書く。
