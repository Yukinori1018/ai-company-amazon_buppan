# 仮想 Act の型 — 差し戻しを受けて経路を1本に絞り直す

初出: T-20260912-001（2026-09-12）／1周目の経路の改訂（叩き台 T-20260909-002/05 → マサル差し戻し → 事実確認4本 → 改訂版）

## 何が起きたか
- 叩き台は「A（NETSEA ゲート解除）＋B（本丸メーカー直）同時・9週完走58%」。マサルは11%と読み、推奨は「1周目は A で締め、B は2周目」。
- 改訂作業中に、**マサルの推奨そのものが組めない**と分かった。A は除外3件で9件に減り、物差しを公表値に替えると公表値ありは1件。その1件は10点で予算超過 → 0件。
- 結論: B 一本。9週以内は0%なので、1周目の締めを初回入金12/31目標・1/15撤退判定に置き直した。

## 学び
1. **物差しを替えたら、推奨を出した側の結論も再計算する。** マサルは「公表値に替えれば1ブランド残る」と書いた。その1ブランドは後から「Amazon販売NG」と分かった。**除外と物差し変更は掛け算で効く**。差し戻しの推奨をそのまま採らず、最新の事実に当て直す
2. **期限が誰のルールかを確かめる。** 「11/15（9週）」は私が叩き台で置いた値で、社長ルールではなかった（親チケットに該当の記載なし）。自分で置いた期限は動かせる。社長ルールは動かせない。この区別を書いてから期限を動かす
3. **足切りはロットの関数にする。** 「取り分≥6」は10点ロット専用の値だった。一般形は「取り分の中央値 ≥ ロット÷1.8」（悲観0.3倍で回転6ヶ月）。メーカー直ではロットが交渉で決まるので、固定値では判定できない
4. **送る判断と買う判断で物差しを分ける。** 送るのは0円なので ②総量（市場の有無）で選ぶ。買うのは §4.1 なので自分の取り分で切る。①だけで送る相手を切ると3社しか残らず、成立率を測る標本にならない。②だけで買うと社長ルール「市場は自分の取り分で見る」に反する
5. **成立率は独立試行で掛けない。** 「個人事業主・実績0」は全社に共通の要因。楽観/中央/悲観の倍率を全社共通で掛ける。独立として扱うと楽観側に振れる（10社・p5%で P(≥1) が同じでも分布の裾が変わる）
6. **§4.1 の一手は週単位の表で上限を置く。** 送信を波に分け、連休の前に波1を置いて返信待ちを連休に重ねる。今回は最大25件/週 → 6件/週に下がった

## 手順（再利用できる形）
1. 差し戻しの各点に、新しい事実を当て直す（差し戻しの推奨を前提にしない）
2. 経路ごとに候補数を「除外 → 物差し → 予算」の漏斗で出す。0になれば「組めない」と書く
3. 期限を分解する（社長ルールか自分の置き値か）。自分の置き値ならモンテカルロの分布から置き直す
4. 足切りを「送る」「買う」の2段にし、買う方をロットの関数にする
5. モンテカルロは共通の倍率＋共通の事故（アカウント）で相関を入れる。スクリプトを deliverables に置く
6. §4.1 の週別表（件数・分）、撤退条件の統合表（送信前／発注前／返信／販売後／全体）、事実待ち表（確定したら何が変わるか）を必ず付ける

## 3周目（最終版 07・2026-09-12）で足した学び

1. **送り先を絞ったら、差し戻し側の「開拓の確率」も再計算する。** マサルの「前向き返信90%」は10社送信の値。5社→73%、4社→67%。絞る判断は正しくても、社長への約束（二段の①）の数字が変わる。差し戻しの数字を転記しない
2. **決まったルールは、新しい経路にも適用範囲をまず確かめる。** 食品 #8 は NETSEA 用に作ったが、裁定の文言は「初回から外す」＝経路を問わない。しかも北陸製菓は、裁定理由（食品カテゴリ審査の矛盾）そのものの二重ゲート。社長判断に上げず「適用した」と書き、代償（成立24→19%）を添えた。論点を増やさない
3. **「戻す計算をするか」は、上限で先に判定する。** 区分3の5社は、子の取り分（兄弟合計の上限）の最大値が3.0〜4.67で、閾値5.6に届かない。割り方を定義する前に、上限が閾値未満なら計算は不要。定義作業そのものを「やらないこと」にできる
4. **「今作れ」と言われたものは、既存データで作れるかを先に数える。** 976社のうち販売データは24社だけ。作れないと書き、担当・規模（歩留まり17%→約60社・約1,200 token）・期限（10/9）まで落として秘書に返した
5. **社長の週別表は、他チケットの期限と合わせて組む。** SD の9/17期限がある週に電話案件（河野）を入れない。入金の中央値は1日しか違わない
6. **社長判断は「決めていないこと」だけ。** 経路・大口月額・電話可否の3つ。大口月額は SD 判断（9/16）と同じお金なので、同日に決めてもらうよう束ねた
