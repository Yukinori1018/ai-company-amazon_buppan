# 抽出リストのゲート設計 — 弱い根拠をゲートにすると本命が死ぬ

初出: T-20260831-004（2026-08-31）/ 対象: メーカー仕入れの候補抽出

## 一番の学び

**除外条件は「強い証拠」だけをゲートにする。弱い証拠は階層かスコアに落とし、列で警告する。**

T-20260831-004 で、弱い根拠をゲートにした結果、独立検証セットでの再現率が 59.4% しか出ませんでした。
1件ずつ降格させて **96.9%** まで戻した記録：

| 修正 | 再現率 |
|---|---:|
| 初版（弱い根拠もゲート） | 59.4% |
| 規模の手判定をゲートから外す（「誰でも知る大企業」だけ除外） | 81.2% |
| セラー名未解決を「直営店」と同一視しない（判定保留の階層Eへ） | 93.8% |
| 国内セラー判定にかなだけでなく漢字も採用 | **96.9%** |

適合率は 82.6% → 72.1% に下がりましたが、F1 は 0.691 → 0.827 に改善。
**「拾いすぎて列で警告する」ほうが「捨てて気づかない」より安い**、というのがこの領域の非対称性です。

## 判定材料は「判定力」と「コスト」で表にしてから採用する

推測で列を足さない。必ず既存データに当てて件数を出す。T-20260831-004 で不採用にしたもの：

| 材料 | 落とした理由 |
|---|---|
| 商品タイトルが日本語 | 89.1%が該当。中国系ブランドも日本語で出品する＝判定力ほぼゼロ |
| EAN 690-699（中国） | **製造地であって企業の所在ではない**。Logitech・INTEX が該当 |
| ブランド名の母音率で「無意味な英字列」判定 | KÄRCHER・TP-Link を誤検出 |
| セラー名が12文字以上の小文字連続＝中国系 | 250件中207件が誤検出（`thebookcommunity` `thurmanbooks` は英語圏の書店） |

**採用したのは「ピンイン語基（keji/maoyi/youxiangongsi/中国地名）」だけ。27社に立って誤検出ゼロ。**
語基は意味を持つので精度が高い。文字の統計量（母音率・長さ）は精度が出ない。

## 自分のルールは必ず回帰サンプルで確かめる

`Anker`（アンカー・ジャパンが実在）のような**既知の日本法人あり企業を固定リストにして、毎回落ちないか確認する**。
T-20260831-004 では26社の固定サンプルを作った。12社が落ちたが、**全て従業員300人超で規模ゲートでどのみち除外される会社**だったので実害ゼロと評価した。
→ **偽陰性は「率」でなく「実害」で評価する。** 落ちた相手が元々ターゲット外なら、その偽陰性はコストではない。

## 精度を上げることは母数を増やすこと（社長の言葉の実装）

社長「いらない情報も含んで母数を増やしたら、リスト化の意味がないでしょ」

これを工学に落とすと**ゲートの適用順**になる。安い判定を先に、高い判定を後に置く。

- Keepa の `product`（1トークン）で brand / manufacturer / eanList / categoryTree が全部取れる
- `offers`（6.5トークン）が要るのは「実セラー数」だけ
- 日本実体判定とカテゴリ判定を offers の前に置くと **62.6% を offers 前に落とせ、同じ予算で商品2.19倍**

**「除外すると件数が減る」という書き方をしない。減るのはノイズで、増えるのは母数。**

## 「卸している証拠」の落とし穴

`distinct sellerId >= 2` は卸の証拠にならない。**ブランド自身が別名ストアを複数出している**（実測401件）。

```
Ailewu  実セラー4 → AilewuDirect / AILEWU メーカー直営店 / AILEWU 直営店 / Ailewu Direct
Tibnozt 実セラー3 → Tibnozt（ティブノズト）公式ストア / Tibnozt OFFICIAL / Tibnozt Shop
```

正しくは**独立セラー数**＝(全セラー) −(ブランド名を冠する店) −(直営/公式/正規販売店を名乗る店) −(名前未解決)。
さらに**そのうち国内事業者が1社以上**を要求する。独立2社でも両方海外なら社長は同じ商流に入れない。

国内事業者の判定に効いたのは **「適格請求書」「インボイス」の表記**。日本の課税事業者である直接証拠で、283社に立った。

## データの欠損を「否定」と読まない

Keepa がセラー名を解決できず sellerId のまま返す行が **2.8%（8,713件中242件）、45社は全商品で未解決**。
これを「直営店しかいない」と同じ扱いにすると、曙産業・筒井時正商店・PACPAK のような国内SMEを捨てる。
**欠損は「判定保留」という独立した階層にする。** 同じ罠は EAN 欠損（21.7%）にもある。
