# 差し戻しの型：率と内訳を人手で別々に書くな（2026-09-21 / T-20260920-005）

## 指摘の出どころ
マサル13 → タケシ 11 の差し戻し。秘書カズヨ経由。**「壊れているのは思想ではなく3つの数字だけ。1周で戻せる（確度75%）」**という評価つきだった。

## 学んだ運用
- **成果物に率（進行率・歩留まり・成約率）と内訳表（社数の段別分布）の両方を載せるときは、必ず片方からもう片方を生成する。** 手で置いた内訳は、願望が混入して率と矛盾する。
- **推奨する方向：率を残して内訳を作り直す。** 率のほうが出典（今回は中村の記述）に近い。内訳は自分の願望が入りやすい。
- **根拠のない上方修正は不可。** 率を上げたいなら「上げるための打ち手（交渉45分/社）」と「実測日（2027Q2）」と「上がらなかった場合の着地（65万）」をセットで書く。そうすれば率の変更は主張ではなく設計になる。
- **自分の見立てが外部検算より甘い側に出たら、そのまま外部の値を採る。** 今回は劣化の影響を1.3〜1.5倍と見たが実際は1.7倍。甘い側の誤りは積み上がる。

## 報告の形（今回採用され機能した型）
1. 冒頭に修正後の着地（月営業利益・社数・12ヶ月累計）
2. **検証者の中央値との差がどこから来るかを1行で**（「悲観vs楽観」ではなく「打ち手◯個分」と言う）
3. 自己検証の表（v1 の記述 / 検算 / v2 での扱い）を §1 に置く。言い訳を書かない
4. やらないこと5件（うち3件はv1からの入れ替え＝何を撤回したかが見える）
5. A/B/C＋推奨を末尾。丸投げの質問は書かない
