# 「メーカーが困っている度合い」スコアの設計と、その限界

初出: T-20260831-004（2026-08-31）/ 対象: メーカー仕入れの独占提案（EC STARs 第5章）

## 一番の学び（これを忘れると必ず外す）

**本命ほど困っていない。** 手作業ラベル200社の商品で実測した困り度の中央値：

| 区分 | 困り度中央値 | 「相乗り+1以上」の割合 |
|---|---:|---:|
| **A1 日本の小規模メーカー（本命）** | **24.4** | **10.8%** |
| B 大企業 | 31.2 | 35.2% |
| C 版元 | 32.4 | 36.4% |
| D 中国系OEM | 28.7 | 44.4% |

**相乗りが増えるのは大企業・版元・中国系であって、日本の小規模メーカーではない。**
→ 困り度を母集団全体の並べ替えに使うと、**前工程で潰したノイズがそのまま浮いてくる。**
**使い方は1つだけ：適格性フィルタを通した後の並べ替え。** 順番を逆にしてはいけない。

## スコアの中身（Keepa の生レスポンスだけで作れる。追加トークン0）

| 成分 | 出所 | 実測分布（中央 / 上位10%） |
|---|---|---|
| D1 下方向の値幅 (中央値−p10)/中央値 | `csv[1]` NEW 価格履歴180日 | 9.3% / 40%超 |
| D2 価格改定回数（±1%超）/180日 | 同上 | 20回 / 89回 |
| D3 直近30日の下落率（30日中央値 vs 180日中央値） | 同上 | 0% / 13% |
| D4 新品オファー数の増分（直近30日 − 90〜180日前） | `csv[11]` COUNT_NEW | 0 / +2 |

4成分を p90 で正規化して平均×100。成分間の相関は最大 D1×D3=+0.43 で重複なし。
交絡チェック済み：困り度 × オファー数 r=+0.18 / × ランク r=+0.02 / × 価格 r=+0.07。
**「人気商品を言い換えているだけ」ではない。**

### 落とした材料と理由

- **上方向の値幅（値上がり）** → 転売プレミア（MEDICOM TOY 13,820→19,800円）を「困っている」と誤判定する
- **BuyBox 奪取回数 `csv[18]`** → `offers` を付けた回しか更新されないので時系列が歯抜け。比較できない
- **Amazon本体の在庫率 `csv[0]`** → 候補の90%が0%。差がつかないのでゲートに回す

## 一番鋭い切り口は「メーカー直販の有無」との掛け算

| 区分 | 262社中 | 提案の刺さり方 |
|---|---:|---|
| **直販あり × 値崩れ × 相乗り増** | **10** | 「あなたの公式ストアの価格が崩されています」＝最強 |
| 直販あり × 静か | 26 | 既に管理できている。独占の話は不要 |
| 直販なし × 値崩れ × 相乗り増 | 24 | 「知らないところで安売りされています」＝情報提供 |
| 静か | 191 | 「初対面で結婚を申し込むな」。まず仕入れだけ |

## 目視で分かった不都合（必ず報告に書くこと）

Q1（困り度45以上 × 期待月利1万円以上）21社のうち **5社（24%）が不適格または既に対処済み**：

- **ワコーズ・BURTLE** = 正規販売店制度で**既に管理している側**。値崩れは実在するが新規取引は通らない
- **ブシロード** = 上場（gBizINFO 259人・資本金57.8億）
- **SoundPEATS・ラブホーム美家** = 前チケットで名指し済みの「日本語ブランド名の中国系OEM」残存誤検出

**「困っている」と「取引できる」は別。** 機械的に分けたいなら「オファー数が減っている」が管理側のサインだが、
**「売れなくなった」と区別がつかない**ので、除外せず列で警告するに留める（弱い根拠をゲートにすると本命が死ぬ）。

## 検証の型（次も同じ手順で）

1. 成分の分布を先に出す。閾値を勘で置かない（正規化上限は実測 p90）
2. **既存のラベルに当てて、区分別の中央値を出す**。ここで負の結果が出るかどうかが最重要
3. 交絡（人気度・価格・履歴の長さ）との相関を出す
4. 成分間の相関を出す（重複していないか）
5. **上位を1社ずつ目視し、誤検出の割合を数える。** 「効くはず」では出さない
