# 社長のこだわり — リストの質について

初出: T-20260831-004（2026-08-31）

## 引用（そのまま覚えておく）

> 「私が連絡すべきメーカーの一覧が欲しいのだから、**いらない情報も含んで母数を増やしたら、リスト化の意味がないでしょ。母数を増やすのが第一目的でない。欲しい情報の母数を増やすのが目的。**」

> 「これは私が手動でKeepaで絞り込むのと、あまり変わらない気がします。私が求めているのは、**私でも仕入れられそうなメーカーに問い合わせたい**」

## ここから読み取るべきこと

1. **付加価値は「社長が手作業でできないこと」にしかない。**
   Keepa の数値条件（ランク・価格・セラー数）を自動化しただけの成果物は、社長にとって価値がありません。
   Keepa で絞れない軸 ＝ **取引先としての適格性**（国内実体・規模・卸の有無）を埋めるのが仕事です。

2. **KPI は必ず「社長が次に取れる行動の数」で置く。** 総件数ではありません。
   T-20260831-004 では北極星を「取引が開始したメーカー数」、先行指標を「連絡候補メーカー数」にしました。

3. **「除外すると件数が減る」という書き方をしない。** 減るのはノイズです。
   §3 の feedback_maximize_pool_not_ranking（2026-08-24「母数最大」）と矛盾しません。
   社長が求めているのは**「欲しい情報の」母数**であって、行数ではありません。両方とも同じことを言っています。

4. **表現がくどいのを嫌う。** 前置きなし・一文短く・表にする。太字を減らす。

5. **推測で埋めない。** 「効くはず」は成果物に入れない。
   提案した判定ロジックは必ず既存データに当てて、件数と誤検出例を出す。
   分からないものは「未確認」と明記し、**何を調べれば分かるか**を書く。

## 社長が確定させた抽出条件（2026-08-31）

| 軸 | 条件 |
|---|---|
| 規模 | 従業員300人以下 |
| 取引の成立性 | 日本国内に事業実体があり、日本語で商談でき、国内から仕入れられること |
| カテゴリ | DVD/CD/本/ゲーム/音楽は今回は母集団から外す |
| 卸の証拠 | 転売業者同士の並びを「卸ルートあり」と誤認しない |
| KPI | 社長が連絡できるメーカー数 |

## 「単純除外にしない」という指示の意味

> 「個人事業主でなく、法人になったらおろしてくれると言うのなら法人化を考える」

社長は**除外の理由を投資判断の材料として見ています**。だから：

- 「個人事業主だから無理」と「規模的に無理」を**分けて記録する**
- 外したものは捨てずに**別台帳に退避**する（後から復活できる形で）
- **法人化で開く母数は既存データに存在しない**。断られた理由を1周目から記録する列を先に作る
- 推測で「◯社開きます」と書かない。上限だけ示して「未確認」と明記する

## 除外の書き方（表現）

「日本語で商談できない出品者を除く」は差別ではなく**実務判断**です。
成果物では **「日本に窓口が無く、国内から仕入れられない」** という機能的な記述に統一する。
国籍そのものを理由に書かない。判定根拠も「セラー名に中国企業表記（有限公司等）がある」という**観測可能な事実**で書く。
