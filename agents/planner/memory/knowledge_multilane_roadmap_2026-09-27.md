# 多レーン・ロードマップの設計（2026-09-27 / T-20260927-001）— 単線で「届かない」と締めない型

## 差し戻しの本質

社長の差し戻しは「確率が甘い」ではなく「**で、明日なにをするの**」だった。07 は確率・感度・律速の入れ替わりを精緻に書いたが、行動が1つも書かれていなかった。加えて単線（Amazon物販のみ）で「届きません」と締めたので行き止まりの報告に見えた。

**確率は秘書の品質保証の道具で、社長の行動を決める道具ではない。** 確率と感度は注釈（§8）へ落とし、§0 に「2年後こうなります」を置いた。

## 今回の設計で効いた3つの発想

1. **1接触3オファー** — AI受託と運用代行は「同じBtoB営業の時間を食う」とサトルが指摘した衝突を、**同じ1通に3つのオファー（仕入れさせて／売らせて／自動化させて）を載せる**ことで消した。母数は同じ名簿2,425社、接触通数も同じ、追加時間0。**時間の衝突は「配分」ではなく「同一行動に載せる」で解けることがある。**
2. **在庫ゼロのレーンを主力に混ぜると利益率KPIが救われる** — 物販単独は6掛けで粗利率19.4%＝KPI20%に永久に届かない。運用代行・AI受託は粗利ほぼ100%なので、**合計で22〜24%に乗る**。利益率KPIの達成手段は「安く買う」だけではない。
3. **「捨てる」は実質の理由で書く** — eBay を落とした理由は社長の制約（無在庫NG等）ではなく「2026年ルール下の成功事例が0件」「物販と完全に同じ時間帯を食う」。制約を理由に落とすと `feedback_constraints_are_variables_not_walls` を踏む。

## マサルの差し戻し（06・同日）— 154万は撤回。正は57万

**自分の最大の誤りは「引き算の場所」だった。** 自分の置き値では222万が出ていて、そこから3割引いて154万として出した（正直な操作のつもりだった）。**だが引くべきは合計ではなく「受託と補助レーンの単価」**だった。マサルの階段：E1 222万 → E5（受託の単価と勝率を置き換え）**110万（▲81万）** → E6（④⑤⑥も置き換え）**44万（▲66万）**。混合の中央 **57万**・P(200万)=5%。

### ルール化（次に同じ型を出すとき）

1. **合計から割り引くのは検算ではない。** 不確実なのは合計ではなく個々の単価。**観測値ゼロの単価を含むレーンは、そのレーン単位で置き値を悲観側へ振る。**「全体から3割引いた」は品質確認になっていない。
2. **「中央値が0のレーン」を主力に置いてはいけない。** ②代行・③受託・⑥動画は P50 で1社も立たない＝**上側（P90）を作るレーン**。主力／補助の分類基準は期待値ではなく**中央値が立つかどうか**。
3. **週の時間が共有制約なら、レーンを足すほど中央値は下がる。** 物販単線74万 → 全レーン44万。**レーン別の時間単価を必ず出す**（物販5,200円/h／ガイド1,200円/h／動画1,400円/h／コンサル2,900円/h）。**安い時間に自分の時間を移す案を「多レーン化」と呼んではいけない。**
4. **「追加時間0」と書いたら、後工程を数えたかを確認する。** 1接触3オファーは送信は共通でも**見積45分／代行提案120分／受託要件180分は共通化不可**。希釈▲11万＋後工程▲12万 vs 代行+9.4万＝**差し引き▲16万**。→ **2段化（本文は仕入れ1本・署名に1行）で直した。設計の骨（名簿を3倍速で焼かない）は正しかったので、壊れていたのは後工程だけ。**
5. **週次プランには返信対応の時間を必ず入れる。** 入れ忘れてW4以降が週18〜31hになった。**返信対応を先に時間予約し、余った時間で送信する（順序を逆にする）。** 送信60通→30通。
6. **判定線は「発動率」を計算してから書く。** 出した3本は全部80%超発動＝情報量ゼロ（3回目の同型指摘）。採用値：返信率15%（2段化前提／3オファーなら10%）・M4 2027-09 段2<8社（偽陽性12%）・受託は**商談化率**（受注0/11件は偽陰性52%で90日では原理的に判定不能）。
7. **期限ものの判定日は「その日に答えられるか」で置く。** 補助金 第20回の Go 条件（75万を自腹で先出しできるか）は、どのメーカーがどのロットで売るかが決まる前には答えられない → **今 NoGo・第21回へ**。ガイド検定も「客の予約次第」＝自分で制御できない事象を条件にしていた → 2027-01 上旬へ。**0円で情報が2ヶ月増えるなら、判定は遅らせる方が強い。**
8. **現金の谷の位置を四半期末で見ない（2回目の同型）。** 自分は2027-10〜2028-02、正は**2027-03**（7ヶ月早い・借入実行の前）。**申込が谷と同月に来る計画を書いていた** → 申込を2027-01へ前倒し。**借入なしで退職すると66%の世界で現金が尽きる**（順序は融資実行→退職）。
9. **退職時期を断定しない。** 「2028年3月に辞められます」→ 満たす確率は約35%（53.4万線）／12%（95万線）。**日付は判定日として書き、確率を添える。**
