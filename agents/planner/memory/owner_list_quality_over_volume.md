# 社長のこだわり：リストは「欲しい情報の母数」を増やすもの

## 発言（2026-08-31 / T-20260831-004）

> 「これは私が手動でKeepaで絞り込むのと、あまり変わらない気がします。私が求めているのは、**私でも仕入れられそうなメーカーに問い合わせたい**、というのがこのリストを作ってもらう最大の目的です。」

> 「私が連絡すべきメーカーの一覧が欲しいのだから、**いらない情報も含んで母数を増やしたら、リスト化の意味がないでしょ。母数を増やすのが第一目的でない。欲しい情報の母数を増やすのが目的。**」

## 読み解き（外さないための原則）

1. **「社長が手作業でもできること」を自動化しただけの成果物は、価値ゼロと判定される。**
   Keepa の数値条件（ランク・セラー数・利益率・サイズ）は社長が自分でできる。
   **付加価値は必ず「その道具では絞れない軸」に置く。** 今回で言えば取引先としての適格性（規模・国籍・卸の意思）
2. **2026-08-24「厳選top100は的外れ。母数最大の長いリストを」と矛盾しない。**
   増やす対象が「行数」から「**社長が連絡できるメーカー数**」に定義され直しただけ。
   **KPI を件数で置くと必ず叱られる。「使える件数」で置く。**
3. **社長は自分で判定基準を出せる方。** 曖昧なまま憶測で埋めず、聞けば
   「従業員300人以下」「DVD/CD/本/ゲームは今は外す」のように**公的定義に乗る形で返ってくる**。
   ただし単純な二値では答えない（「**法人になったらおろしてくれるなら法人化を考える**」）。
   → **除外は「捨てる」ではなく「条件付きで開く区分」として保存する**こと。捨てると選択肢を奪うことになる

## 報告の作法（今回守ったこと）

- 「ゼロに近いならそう書け」と明示指示された → **84%がノイズ、本命は16%** と先に書いた
- **「効くはず」を書かない。** 提案したルールは全て手作業ラベル200社に当てて適合率／再現率を出した
- **負の実測を隠さない**（屋号型セラーは適合率を下げる／中国系判定は再現率38%が上限）。
  むしろこれが一番喜ばれる情報になる
