# 1件目の SKU の売り方（価格・出口・ロードマップ）の型

初出: T-20260909-002 / 08_アミノボディの売り方（2026-09-13）

## 社長の指示（ルールとして覚える）
> 「次につながる動きを心がけて下さい。ロードマップが描けた上でやらないと意味のないことに時間を使うことになります。」（2026-09-13）

→ 1件の商品の売り方を頼まれても、**「この1件で何を確かめ、結果ごとに次の一手がどう分岐するか」の表を必ず付ける。** 利益が小さい1件目の価値は情報（ゲート通過・実務コスト・新規のカート）にある。

## 学び
1. **価格より季節が効くことがある。** アミノボディは、下限まで下げても悲観シナリオでは1.2セット（本来は4セット）しか売れない。価格案を比べる前に「売れない期間の理由（在庫切れか需要なしか）」を確かめる依頼を最優先で出す
2. **カートを取っている出品者より安いのに、カートを取れていない出品者がいたら、「安さでは取れない」の証拠。** 評価0件の新規がカート同額で待つ案は捨てる。最安の Prime 出品で「その他の出品者」欄から売る
3. **FBM の価格には合わせない。** FBM はカートを取れていないので、競争相手は FBA だけ
4. **利益の式を2点で検算してから価格表を作る。** 今回は内訳の合計と純利益が59円ずれていた。安全側に含め、原因を IT に返した。販売手数料の傾き（1−料率×1.1）で2つの既知の値が合えば式は正しい
5. **PUBLIC リポでは、利益の数字から卸値を逆算できる。** 本体の md には売値・確率・価格ルールだけを書き、利益表は `out/`（追跡外）に分ける
6. **既存の ASIN にセット組みで相乗りするときは、ASIN の JAN が単品の JAN かを出品前に確かめる。** メーカーの3本入りが別にあれば、内容の不一致になる
7. **推奨は「期待値最大の案で入り、期限で速い案に切り替える」形が作りやすい。** B（期待値最大）→ 1/15 に C（完売確率最大）

## 手順（再利用できる形）
1. 利益式を作って既知の2点で検算する → 価格別の利益表（金額は out/）
2. 需要3シナリオ×取り分3案をポアソンで回す（`agent_output/T-20260909-002/08_calc.py` を流用）
3. 価格ルールは「出品時／毎週／下限割れ／30日／中間期限／6ヶ月」の表にする
4. 出口は「損益ゼロまで下げる → 残れば社長判断（持ち越し or 現金化）」の2段
5. ゲート却下時の代替を「出し直し → 兄弟 ASIN → Amazon 以外」の順に。儲ける道か現金回収の道かを書き分ける
6. 確かめること×結果×次の一手の表と、会社 KPI への寄与（正直にほぼゼロと書く）を付ける

## 答え合わせ（2027-03-15 に照合）
- 推奨（B→C）で4セット完売 約50%、1セット目が売れる確率 84%、6ヶ月で売れる数の期待値 2.5セット
- 悲観シナリオ（昨冬と同じ）の重み30%。S-a の結果で更新する
