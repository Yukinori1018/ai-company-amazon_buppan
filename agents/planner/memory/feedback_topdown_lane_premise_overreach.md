# レーンの定常月商を上から置くと確率が膨らむ — 74%が67%（書面どおりなら47%）に下がった理由

初出: T-20260914-002 2周目（2026-09-14）／マサル T-20260914-003 の収束 No を受けた仮想 Act

## 何が起きたか

1周目の案C（推奨）は P(12ヶ月実質現金>0) 74%・中央 +18万と出した。マサルの独立再計算では、書面どおりで 47%・中央 −1万。差 −27pt のうち −21pt が「せどりの定常月商50万」という前提1つから来ていた。

| 段 | 何を置いたか | 何が正しかったか |
|---|---|---|
| せどりの月商 | 定常50万を上から置いた（原石密度×ゲートなし率×ロット1万円を掛けた推測） | 照合件数（週40〜60件）×採用率（実測 JAN あたり3.0%）×原石の寿命（中央2ヶ月）で下から積むと中央約10万（80%区間3〜23万） |
| 採用率 | 逆算すると1件あたり15〜24%を置いていた | 実測の真値3.0%（T-20260705-001 v2）。誤突合込みの生値8.5%と比べても2〜3倍 |
| 撤退条件 S-2 | 「2週で採用ロット10件未満なら停止」 | 実測密度の世界で99%発動。自分の中央と撤退条件が矛盾していた |
| 寄与 | 案B比 +15pt | +5pt（中央 +3万） |

実測値（原石密度 3.0%/JAN）を手元に持っていたのに、月商の置き値に使わなかった。

## 学び（次に同じ型の案を出すとき）

1. **月商は「行動×率×寿命」で下から積む。** 「定常◯万」を上から置いたら、必ず行動指標（週の照合件数）まで逆算し、要る採用率を実測と比べる。2倍以上離れていたら置き値を捨てる
2. **撤退条件は、自分の中央と実測の世界の両方で「踏む確率」を計算してから書く。** 中央で踏む条件は撤退ではなく予測。止めたい世界の値に閾値を置くと、その世界でも半分は見逃す（S-1：10%の世界で44%）
3. **発注停止には崖がある。** 新規ロット2027-06・補充2027-07なら P 66%、補充を2027-08まで延ばすと 35%。停止の月は1ヶ月ずれるだけで30pt動く。停止を案に入れるなら、崖の位置を本文に書く
4. **既定を緩める案が僅差（+5pt 程度）なら、既定を守る案を推奨にする。** 上乗せの小ささに対して、店の健全性（事故 年5%→12%・恒久停止 1%→3%）と社長の時間（+2時間/週）が釣り合わない。本丸（メーカー独占）は店が生きていることが前提
5. **5〜7割の帯を「確度が高い」と書かない。** 社長の「確度の高いやり方」への正直な答えは「どの案も実測ゼロで5〜7割。上げる手段は最初の8週の実測だけ」
6. **測り方を固定する前に、測り方ごとの P を並べる。** 実質現金は発注停止を強制し、年2の利益を約11万削る。清算価値（在庫×0.8＋未入金を含む）なら止めずに同程度の P が出る

## 手順（仮想 Act の処理の型）

1. マサルの差し戻し R を1点ずつ「採用／修正採用／不採用＋理由」の表にする
2. 推奨を差し戻し後の数字で決め直す（上乗せ pt・中央・事故率・社長の時間・既定を並べる）
3. マサルが出していない組み合わせ（例：案B の継続＋清算価値、案B の撤退条件の較正）だけ、マサルの `01_mc.py` を import して n=1500 で追加計算。自分でモデルを作り直さない
4. 冒頭に「確度の正直な答え」と「W8 に見る数字3つ」を置く

## 数字（答え合わせ用・2027-09-30 に照合）

- 1周目 案C 書面どおり: 47%・−1万（マサル）。私の74%は外れ側
- 2周目 最終形: 案B 62%・+6万（P20 −8万）／案C 67%・+9万（P20 −6万）。P10 は −13万／−12万
- 案B 最終形・発注継続: 手仕舞い値 P 65%（+7万）・月12の月商 中央48万（私の n=1500 追加計算）
- 期待値（実質現金・発注停止・n=1500）: 案A +5万／案B +11万／案C +13万。清算価値・発注継続: +7万／+14万／+17万
- 案B の較正済み撤退条件: E-2（2027-03-31 累計損益 −8万未満）踏む19%・踏んだ世界 P 12%／踏まない 71%。E-5（2027-06-30 −5万未満）25%・1%／80%
- 案B の W8: 最初の商品が読みの0.7倍以上（58%）→ P 74%。12月までに商品0（17%）→ 30%

## 推奨をどう決め直したか（2周目）

- 案C +5pt・+3万に対し、事故 5%→12%・恒久 1%→3%・社長 +2時間/週。既定を守る案Bが僅差なので案Bを推奨（確度55%程度）
- ただし案Bの初回売上の遅さ（12月末まで売上0 36%、案C 6%）は社長の既知の恐れ「出品0件による停止」に当たる。黙って決めずに論点②の判断材料として前面に出した
- 測り方は「清算価値＋発注継続」を推奨。発注停止は P がほぼ同じで、崖と年2の損失（利益 −12万）を背負うため
