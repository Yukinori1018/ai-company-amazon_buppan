# カテゴリで落とすな、数字で落とせ（2026-09-21 社長指示）

## 社長の言葉

> 「キャラ品も含んでください。理由は**利益が取れるなら売れない理由はない**からです。規約を守れば、問題やリスクは限りなく少ないと考えています。」

作業中に前提が差し替わった。「キャラクター品は今期対象外」という除外条件は**撤回**。
判定は他の商材と同じ（購入数/月100以上・Amazon 本体不在・粗利額500円以上・卸率55%以下・回転6ヶ月以内）。

## 学び（型として残す）

1. **カテゴリ単位の除外は戦略ではなく手抜き。** 「キャラは知財が怖い」は判定基準ではない。
   実際に数字を当てたらサンリオ8件のうち**5件は基準で落ち、3件は残った**。落ちた理由は低単価・手数料15.4%・
   オファーゼロ・出品者過多で、**キャラであることは一度も理由にならなかった**。
   → **「全滅なら数字で書けばよく、それも答え」**（社長）。除外リストを作る前に計算する。
2. **リスクは「扱う／扱わない」ではなく「1SKU あたりの在庫量」で管理する。** これが社長の指示の核心。
   キャラ品固有のリスク＝カタログ画像への知財申立てでページごと消滅（実例2件が404）＋年度更新でASIN寿命1年。
   → 置いた数字：**1SKU は30日取り分以内・12,000円以内・キャラ合計は予算の1/3以内**。定番品（グンゼ）は60〜90日取り分。
   **在庫量は連続量なので、二値の可否判断より情報が多い。** 以後リスクはできるだけ量で管理する。
3. **法務の NO の射程を広げるな。** ハルオ 12 で不可が確定したのは**キャラ違いのセット品組成**だけ。
   **キャラ品の単品相乗りは規約上問題なし**。NO の対象を勝手に一般化すると、社長の選択肢を無断で削ることになる
   （`feedback_legal_no_is_not_a_prefilter` と同型）。
