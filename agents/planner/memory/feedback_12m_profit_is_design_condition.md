# 12ヶ月黒字は「設計条件」。実測を買う期間という位置づけは却下された

初出: T-20260914-002（2026-09-14）／親 T-20260912-002

## 何が起きたか

前回の私の案B（T-20260912-004 2周目）は「12ヶ月中央 月商44〜52万・累計損益 −6〜−9万」を
「成立率と取り分の実測を買う期間」と位置づけて出した。社長の差し戻し（2026-09-14 原文）:

> 「12ヶ月で現金が増えない事業をやったらダメでしょ。この規模で赤字出してたらやる意味がない。もっと儲かる確度の高いやり方を編み出して。」

## 却下された理由（自分の読み）

1. **目的関数を勝手に「情報」に置き換えた。** 社長の目的は現金。私は「実測が取れれば24ヶ月の幅が縮む」という自分の都合（予測精度）を目的に据え、赤字を正当化した。**KPI を実測に置き換えるのは、社長が赤字を許容したときだけ**。
2. **資本10万円という前提の下で、資本キャップが月商を抑えていたのに「律速は資本でない」と書いた。** 前回モデルは資本10万のとき売上上限12万/月（成立3社まで）。200万に変わると、同じメーカー直レーンが累計 −6万 → ±0（単独）に動く。**前提（資金）が変わったら、律速の主張も引き直す。**
3. **「全部を同時にやる」ほど良いと思い込んでいた。** 12ヶ月の黒字確率では、固定費がかかるレーン（外注の目視 月3万・OEM のツール月1.4万＋商標）を足すと確率が下がる（71%→41%・40%）。1年目に回収できない費用を持つ手は、良い手でも1年目に置かない。

## 手順（再利用できる形）

1. 社長の「儲かる」を**2つの定義で**計算する：累計損益（在庫は原価で資産）と現金ベース（在庫0円）。在庫を持つ物販は、12ヶ月目に在庫（月商の約1.2ヶ月分）が残るので、現金ベースはほぼ必ずマイナスになる。**どちらで判定するかを社長論点に出す**（黙って甘い方を使わない）。参考に「手仕舞い値（在庫を原価の80%で回収）」も出す
2. **レーン単独 → 組み合わせ**の順で P(累計>0) を出す。単独では固定費を全部背負うので低く出る。組み合わせで固定費を分け合う効果と、1年目に回収できないレーンの足を引く効果を分けて見る
3. 推奨は **P 最大**。月商では選ばない。既定内の最大と、既定を緩めた場合の最大を分けて出す
4. 社長の時間に依存するレーン（送信・目視）は、**「続かない」レジーム**を必ず入れる。前科（4ヶ月で送信0通、8/10 の電脳せどりホールド）を置き値に反映する
5. モデルは**恒等式（現金−開始＝累計損益−在庫）で検算**してから数字を使う。今回1回目は評価損の扱いで43万ずれていた。月12だけ補充を止めるバグも、現金を良く見せる方向に効いていた

## 実質現金と発注停止（ハジメ T-20260914-003 を受けて）

- 「現金が増える」をハジメは実質現金（月末現金−未払−200万。在庫と Amazon 未入金は数えない）で測る。社長の言葉に最も近い
- 需要に上限がある世界では、発注を続ける限りどの案も実質現金はプラスにならない（P≈0%）。12ヶ月目に在庫が月商の約1.2ヶ月分残るため
- 解は「発注停止の月」を設計に入れること。月10が最適（月11は在庫が残り P 26%、月9は売上を捨てすぎ累計損益 P 61%）。代償は月11〜12の月商低下と年2の立ち上がり
- 以後、12ヶ月の現金を問われたら最初に「実質現金・発注停止の月」を置く。累計損益だけで答えない

## 推奨を決めるときの自分の癖

- 最初は既定内の案Bを推奨にしかけた。基準（P最大）に照らすと案C（電脳せどり限定再開）が上だった。「既定を緩める案は推奨しない」を暗黙に置いていた。**推奨は基準どおりに出し、既定を緩める部分は緩和表で社長に判断を仰ぐ**。黙って組み込まないことと、推奨から外すことは別
- 既定を緩める案を推奨にするときは、弱い仮定を1つずつ悪くしても残るか（81〜85%）、重ねると負けるか（74% < 80%）を必ず出す
