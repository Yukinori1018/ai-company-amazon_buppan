# 「類似商品から売上を予想する」の限界 — 桁までしか当たらない

初出: T-20260831-004（2026-08-31）/ 非Amazon起点（Amazonに無い商品）の需要推定

## 結論（実測）

**中央値で「月30個」と言ったら、実際は10〜130個。80%区間で 0.3〜4.3倍（13倍の幅）。**
n=587・交差検証。予測式は「コホート中央値 ÷（出品者数+1）」＝キーゾンの式のコホート版。

## 「類似」の定義は、細かくするほど悪くなる

被説明変数＝Keepa の月間販売数（monthlySold・階級値）。Leave-One-Out で測った説明力：

| 定義 | R²(LOO) |
|---|---:|
| **① 大カテゴリのみ** | **15.8%** |
| ② 中カテゴリ | 5.8% |
| ③ 小カテゴリ | 11.2% |
| ④ 中カテゴリ × 価格帯 | 9.9% |
| ⑤ 小カテゴリ × 価格帯 | 5.8% |

**過学習込みの見かけのR²は⑤が60%で最良に見える。交差検証すると最悪になる。**
群あたりの件数が1〜2件に落ちるため。**分割を細かくしたくなったら、必ずLOOで確かめる。**

## キーワード一致は効かない（実測）

同じ中カテゴリ内のペアで、タイトル語の重なり（Jaccard）15%以上 vs 未満：

| | n | 月間販売数の差の中央値 |
|---|---:|---:|
| 重なり15%以上 | 190 | **2.00倍** |
| 15%未満 | 3,794 | **2.00倍** |

**完全に同じ。**「同用途／キーワード一致で類似を定義する」実装はしない。

## 参考：ランクが分かる場合との差

```
log10(月間販売数) = 4.302 − 0.598 × log10(ランク)   R² = 0.395
→ 1万位で月82個 / 5万位で月31個 / 15万位で月16個
```

**Amazonに既にある商品（39.5%）と、無い商品（15.8%）で情報量が2.5倍違う。**
これが「Amazon起点 対 非Amazon起点」の資源配分の根拠になる。

## だから設計をこう変える（森岡的な処方）

**予測精度を上げようとしない。上げられないことが実測で分かっている。**
代わりに**外れても死なない発注量**にする＝初回ロット5個固定（セミナーと同じ結論）。

| 場面 | 使う / 使わない |
|---|---|
| 連絡するかどうかの足切り | **使う**（コホート中央値が月10個未満なら連絡しない） |
| 初回の仕入れ数量 | **使わない**（5個固定） |
| リピート判断 | **使わない**（実売2週間の実測に切り替える） |
