## 一行結論

**「NETSEA だけ」は道具の都合だった。**NETSEA Buyer API は `jan_code` 単独で 400、`supplier_ids` 必須＝**機械検索が承認済み220社（出店企業622社の35%）に閉じていた**。母集団の1/3を見て「無い」と言っていた。

## 「SD＝メーカー直販／NETSEA＝転売業者混在」の検証

- **NETSEA 側は裏が取れた。**NETSEA 自身の「業態」で当社の承認済み210社を数えると **メーカー25社=11.9% / 卸専業73社=34.8% / 卸および小売業98社=46.7%**。**約半数が小売を兼ねる＝同じ棚の競合になりうる。**
- **SD 側は言い過ぎ。**SD の出展募集LPは「**メーカー・卸事業者向け**」。SD 出展企業 N=40 の公開「事業内容」に製造/企画/デザイン/生産/OEM/開発を含むのは62.5%、NETSEA の「事業内容／商品PR」で同じ語を含むのは50%。**差12.5ポイント・しかも尺度が違う**（SDは事実欄、NETSEAは自由PR欄）。**この数字で断定してはいけない。**
- **入口の差が構造差を生んでいる（推測・確度中）**：SD は**システム利用料 取引金額の10〜15%＋契約締結・販売開始まで約1ヶ月**。NETSEA は**個人事業主でも規約同意で出展可・審査約10営業日**で、公式に「楽天やAmazonで約10店舗運営するEC事業者の卸出展事例」を掲載している。
