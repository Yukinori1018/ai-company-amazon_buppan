## 何が起きたか

2026-10-09、Shopee 台湾の想定売価を **NT$766** と置いて比較表に入れた。
これは「原価＋国際送料＋手数料から逆算した損益分岐」であって、相場ではなかった。

カズヨが社長の Chrome で `shopee.tw` を開いたら、
**和平フレイズ（＝同じメーカー）の燕三條 槌目 寿喜鍋 26/30cm が NT$1,070 で実売中**。
同カテゴリーの帯は **NT$850〜1,860**、中央 NT$1,070〜1,250。
**私の置き値は、実勢の最安すら下回っていた。**

実勢で再計算すると、Shopee 台湾は**通常期の料率でも12点 +7,128円の黒字**（私の表では「通常期は▲96円」になっていた）。
**比較表の結論が逆になるほどの誤りだった。**同じことを eBay の $34 でもしていた。

## ルール

1. 🔴 **損益分岐から逆算した数字を「想定売価」の欄に入れない。** 入れるなら列名を「**損益分岐の売価**」にする。「想定売価」と「分岐点」は別の列である
2. 🔴 **実勢が取れないときは「取れていない」と書いて秘書に回す。** 403 で止まったら、そこで止めてよい。**秘書はブラウザで取れる**（`shopee.tw` はスクリプトから403でも、ブラウザでは普通に見える）
3. **「何を・どこで・どの検索語で見るか」の一覧を成果物に必ず入れる。** 秘書が代わりに取れる形で渡す。サイト名・検索語・見る項目（価格／Sold件数／日付）の3点セット
4. **逆算値を使った行は、結論に使わない。** 推奨の根拠にせず、「未確定」と書く
5. **同じメーカー・同じシリーズの商品を先に探す。** 今回の実勢は「和平フレイズの燕三條 槌目 寿喜鍋」＝**同一メーカー・同一シリーズ・同一用途**だった。型番が一致しなくても、ここまで近いものは探せば出てくる。私は「22cm・同型番」で0件と確認して止めていた（検索語の広げ方が1段足りなかった）
