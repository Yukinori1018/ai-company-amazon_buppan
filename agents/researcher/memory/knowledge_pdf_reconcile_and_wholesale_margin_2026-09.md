# 他AI資料の突合と「利益率20%の卸レーン」の探し方（2026-09-14 / T-20260914-001 サトル）

## 依頼パターン

社長が別の AI で作った戦略資料（PDF）を「参考」として持ち込み、数値・主張の裏を取る依頼。同時に「利益率◯%が出る仕入れレーンは実在するか」「◯ヶ月で月商◯万の公開事例はあるか」を聞かれる。

## 処理手順（再利用できる形）

1. PDF は Read の `pages` 指定で全ページ画像を読む（15p なら 1-8 / 9-15 の2回）。主張を**1行1件**に割り、「PDF の出典」列を必ず作る（出典の種別で信頼度が決まる）。
2. 評価は3値だけ（一致／訂正／未確認）。**冒頭の件数と表の行数を機械的に一致させる**（今回1回ずれて直した）。
3. 一次は「公式告知の原文引用」まで取る。セラーセントラルのヘルプ（`/gp/help/external/G…`）は非ログインで **161KB のシェル**しか返らない（curl で size を見れば判別できる）。**セラーフォーラムの公式告知スレッドは 300KB 超で本文が読める**＝手数料改定の一次はこちら。
4. 利益モデルは**必ず再計算**する。今回、PDF の③だけ売価3,500円で計算されていた（販売手数料364円÷10.4%＝3,500 で逆算できた）。「率」を見る前に「手数料額÷率＝売価」で前提を逆算する。
5. 「◯ヶ月で月商◯万」の事例は、**発信者の商用目的（スクール／コンサル／輸入支援）・開始資金・利益率・母数**の4列で表にする。4列のどれかが空なら〔二次・低〕。条件を満たす独立事例が無ければ「0件」と書く。
6. ベースレートは「独立した数字の本数」で答える（`knowledge_share_reestimation_and_base_rates` と同じ）。国内一次は 2021 年の Amazon 発表（16万社・平均1,200万円）以降無い。

## 失敗と注意

- SD の `faq.superdelivery.com/data/helpdata.json` は 2026-09-14 に 0 バイト応答（9/4 は 8.3MB 取れた）。Referer を付けても不可。**取れた日の結果を memory に残しておいたのが効いた**（「Amazon 0件」を再利用）。
- 「4ヶ月で月利55万」型の事例は検索要約が「複数確認できます」とまとめてくるが、開くと全部スクール発信で資金・利益率が無い。**要約を信じず必ず原典を開く**。
- 検索要約が「法人価格が設定された商品は3,000万点以上」と返したが原典を特定できなかった。原典未特定の数字は本文に入れない（今回は「検索要約のみ・原典未特定」と明記）。
- HTML は pandoc も python-markdown も無い環境。`agent_output/T-20260914-001/satoru/md2html.py`（表・見出し・リスト対応の最小変換）を置いた。次回はこれを使う。
