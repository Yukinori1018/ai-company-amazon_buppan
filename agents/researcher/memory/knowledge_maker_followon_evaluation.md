# メーカーの「2周目につながるか」評価の型（2026-09-12 / T-20260909-002）

社長の基準（2026-09-12）: 「単品の利益が薄くても、メーカーの他商品が魅力的なら意味がある。つながらないメーカーなら入れる意味はない」。
ゲートなしの薄利SKUは、**SKU単体ではなくメーカー単位**で評価される。

## 手順（30分で済む）
1. JANの先頭10桁（事業者コード）で `T-20260831-006/out/candidates.csv`・`rejected_by_screen.csv`・`netsea_items.jsonl` を検索する。**ブランド名の部分一致だけで拾うと、ASINの中の文字列（例: FLF）が誤ヒットする**
2. 公式サイトの会社概要で資本金・事業・自社EC/楽天の有無を見る（自社ECがあれば本丸＝ネットに疎いメーカーではない）
3. Keepa API `/search?domain=5&type=product&term=<ブランド>&stats=90` を1〜2語で叩く（10トークン/回。**応答はgzipなので解凍が要る**）。brand/manufacturerでフィルタし、Amazon本体の有無(current[0])・新品オファー数(current[11])・ランクを表にする
4. **セット品ASINは単品とランクを共有する**。単品のほうにAmazon本体がいないかを必ず見る（今回、当社候補の×2セットはAmazon本体なしだが、単品にはAmazon本体がいた）
5. NETSEAでは、同じ会社の「Drop-」直送アカウントと通常アカウントを別々に検索する（`search?keyword=..&supplier_id=`は非ログインで読める。卸値と販売条件タブはログインが必要）

## FLF（プリジア）の結果
No。品目は次亜塩素酸水1系統を容量違いで並べたもの。売れ筋上位3品にはAmazon本体がいる。当社データの2品は利益率0.2%と除外。カネイシの通常アカウント（shop/5984）なら1個からFBA向けに仕入れられるが、Amazon販売の可否は未確認。
