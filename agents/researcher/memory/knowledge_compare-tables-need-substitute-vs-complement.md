# 気づき: 比較表は「代替/補完」を必ず明示する

- **記録日**: 2026-05-25
- **記録者**: サトル（リサーチャー）※カズヨ経由で記録
- **種類**: 調査アウトプットの構造化ミス

## 何が起きたか

T-20260520-003 v2 で AI 連携ツール17本を「AI リサーチツール」という横軸で
比較表に並べた。その結果、**ERESA（Amazon 内分析・出品支援）と Sato-Scope
（仕入れ元⇄Amazon の価格差発見）が同じ箱に入り、秘書カズヨが「代替可能」と
誤読**してしまった。社長指摘で「両者は別物」と判明。

## 教訓

1. ツールを比較表に並べる時、**「同じ問いに答えるか（=代替）」「違う問いに答えるか
   （=補完）」を列として明示する**。機能の表面的な近さで同じ箱に入れない。
2. 各ツールに「**答える問い**」「**見る方向（縦/横/レイヤー）**」を必ず付記する。
   - 例: ERESA=「Amazon の中でどう戦うか」（縦・Amazon 内）
   - 例: Sato-Scope=「どこから仕入れて Amazon で売るか」（横・チャネル横断）
3. 「このツールで○○が代替できる」と書く時は、**代替先の仕事内容を1行で定義**して
   から書く。定義しないと読み手が過大に代替と捉える。

## 安宅流の自戒

「網羅は目的ではない」— 並べることより、**軸の切り方が読み手の判断を誘導する**。
比較軸の設計こそイシュー。表に入れる前に「この軸で並べると何と何が同列に見えるか」を
点検する。
