# 越境販路の構造 — 代行型と直販型のトレードオフ

🔴 **「社長の作業を減らす」と「日本製プレミアムを取る」は両立しにくい。**

| 型 | 価格が決まる場所 | 作業/件 | 該当 |
|---|---|---|---|
| **代行型** | **日本の相場に固定**（代行手数料と国際送料は買い手が上乗せするが、**出品者の手取りは増えない**） | 0〜10分 | メルカリ×Buyee／BASE（want.jp） |
| **直販型** | **現地価格**（プレミアムが**出品者に入る**） | 40〜53分 | Shopee／eBay |
| 🔴 **両取り** | **現地価格** | **約10分** | **Lazada（LazGlobal）** |

実例：台湾の実勢 NT$1,070＝**5,309円**。同じ鍋の国内フリマ相場は**2,480円**。**代行型を選ぶとこの差は出品者に入らない。**

## メルカリ×Buyee（公式 `jp-news.mercari.com/info/6283` `contents/2351`）

- 世界**100か国以上**から購入可能。Buyee（BEENOS子会社 tenso）が代理購入
- 🔴 **出品者に追加手数料は発生しない。販売価格の10%の販売手数料のみ**
- 売れたら **Buyee の国内倉庫へ国内発送するだけ**。海外配送・通関は Buyee
- 🔴 **出品者が特別な手続きをする必要はない**（既存の出品が自動的に海外対象。一部商品は自動除外）
- **出店リードタイム0日・追加作業0分**。ただし**単価は国内相場のまま**
- 2026年春に米国での提供開始予定

## BASE かんたん海外販売（公式 `thebase.com` `thebase.com/global-selling/`）

- スタンダード 月額0円／決済3.6%+40円／サービス3%／**かんたん海外販売利用料 +5%** ＝ **11.6%+40円**
- 2026-03-18 から**全ショップで標準機能化（自動で有効）**
- **海外発送は want.jp が代行。出品者は「いつも通り国内配送するだけ」。国内送料・海外送料とも海外購入者が負担**
- 🔴 弱点は**集客が自力**。埋める手は①既存モールとの併用（**0円**）②SNS（0円＋時間）③広告（実額未調査）。**売上ゼロの段階で③は打たない**
- 対象国は公式に記載なし（未調査）

## Lazada（LazGlobal）（公式 `lazada.jp/` `lazada.jp/onboard` ＋公式ニュース2022-11-11）

| 項目 | 値 |
|---|---|
| 対応 | **東南アジア6か国（SG/MY/TH/VN/PH/ID）。1契約・1回の商品登録で6カ国同時掲載** |
| 出店条件 | 🔴 **①法人 or 個人事業主である ②日本or香港からの発送が可能である** |
| 承認 | **約1週間** |
| コミッション | **開設90日間 免除 → 91日目以降 6〜7%** |
| 決済手数料 | (商品価格−割引＋購入者が支払う配送料) × **2%** × (1+現地VAT) |
| 現地VAT | MY 6%／TH 7%／PH 12%／ID 10%／VN 10%／**SG なし** → **SG が最有利** |
| 出金 | Payoneer で 入金1%＋出金2%＝**3%**。計算式は (商品代金−国際配送料)×3% |
| **合計（SG）** | **約11〜12%（90日中は約5%）** |
| 入金 | 🔴 **1週間サイクル** |
| 物流 | **オーダーが入ったら日本国内の Lazada 仕分けセンター（千葉県船橋市）へ送るだけ**。🔴 **国際物流コストはセラー負担**（混載方式・公式料金表を梱包重量で参照）／**ローカル送料（各国仕分け→購入者）は購入者負担** |
| 発送期限 | 受注後**2営業日以内**に発送（遅れるとキャンセル）／5〜6営業日以内に仕分けセンター着（確度：中・二次） |
| 言語 | **英語で1回登録 → 各現地語に自動翻訳**。チャットも自動翻訳。日本語サポートあり |
| 推奨カテゴリー | **Beauty / Health / Toys & Games / Watch Sunglasses / Audio**（キッチン用品は推奨外） |

🔴 **未取得：LGS の国際送料の実額**（会員ログイン後のセラーセンターのみ）。これが取れるまで採算は確定しない。
🔴 **公式サイトの「6〜7%」と公式ニュース2022年版の「1%/4%」が食い違う。Shopee と同じ「公式の古い記事」問題。**

## eBay（公式 `ebay.co.jp/start/business/business-fee/`）

- 実効 **約17.6%＋$0.40**（FVF13.25〜15%＋$0.40／国際1.35%／為替3%）。月250品まで出品無料
- 🔴 **eIS（eBay International Shipping）は米国在庫のセラー向けで、日本セラーは使えない。** 日本セラーは 日本郵便／eBay SpeedPAK／eLogi（FedEx・DHL 割引）／個別契約
- 🔴 **2025-10-17 から 日韓発→米国 $2,500未満は DDP 必須**（セラーが関税を前払い）
- 1件40分超・出店2〜4週間（販売リミット）。**低単価の嵩物には最も不向き**

## 越境ではないもの（間違えやすい）

| | 実態 |
|---|---|
| **Qoo10** | 🔴 **eBay Japan 合同会社が運営する日本国内向けモール。越境ではない。** 初期費用・月額0円の完全成果報酬、販売手数料 カテゴリ別6〜10%（一般セラーは10〜12%）。**国内の第2販路としては意味がある** |
| **Temu 日本セラー** | 🔴 **「国内販売事業者の募集」＝日本国内在庫→日本国内消費者。越境ではない。** 2025-06 から**招待不要**・法人／個人事業主／個人いずれも可。**販売手数料0%・固定費無料**。「厳格なルールと独特の商慣習」との指摘あり |
| **Amazon 海外ストア** | 出品制限は `marketplaceId` 単位なので**構造上は別判定**で、日本固有 JAN の商品は他マーケットのカタログに無い（`ASIN_NOT_FOUND`）＝新規登録で出せる余地がある。🔴 **ただし北米3ストアは停止中で、停止中アカウントへのマーケット追加は現実的でなく、別アカウント作成は複数アカウント違反。「開くか」は Yes、「やれるか」は No** |

## 国際送料（日本郵便 国際エアパケット・公式）

制限：**3辺合計90cm以内・長辺60cm以内・2kg以内**。国際特定記録料370円込み。国際郵便マイページでラベル印刷が必須。

| 重量 | 第1（中国・韓国・**台湾**） | 第2（アジアその他＝**SG/MY/TH/PH/VN**） | 第3（欧州・オセアニア） | 第4（**米国**） |
|---|---|---|---|---|
| 700gまで | **1,320円** | **1,470円** | 1,960円 | **2,460円** |
| 800gまで | **1,420円** | **1,590円** | 2,140円 | **2,670円** |

**重量は梱包後の実測で出す。** 2026-10-09 の鍋は箱込み**635g**（社長実測）で、外装＋緩衝材を足すと700g枠を超える可能性が高い。**700g前提と800g前提の両方を出す。**

## 判定の勘どころ

- **嵩張る低単価品は、代行型（海外送料を買い手が払う）でないと成立しにくい。** ただし代行型は単価が国内相場に固定されるので、**利益は「国内で売るのと同じ」になる**
- **軽量・高単価（コスメ・サプリ・衛生・文具）なら直販型が効く。** 現地価格のプレミアムが取れ、送料も小さい
- **入金サイクルを必ず表に入れる。** Lazada 1週間 ／ Shopee 1〜2ヶ月。**運転資金が薄い当社では回収速度が採算と同じ重みを持つ**
- **「出店要件」は障害ではなく1手で外せることが多い。** Lazada の「法人 or 個人事業主」は開業届で満たせる（**当社は2026-08-20 に提出済み。資産台帳を見てから「持っていない」と書く**）
