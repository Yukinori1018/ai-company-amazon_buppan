**「電話のみ」とされた社の過半（20/38）に文章窓口があった。** 前回の採取は通販サイト（特商法・ショップ）だけを見て止まっていた社が多い。

## 効いた順（次回は最初にやる）

1. **通販サイトと会社サイトは別ドメインのことがある。** バイコム（bicom-shop.jp → bicom.co.jp に法人ページ）、JUN（jun-co.net → jun-co.com）、まるはら（maruhara.jp → soysauce.co.jp）。通販の特商法から「ホームページ」欄・フッターの外部リンクを必ず辿る
2. **JS描画のフォームは headless Chrome で読める**（Y&S・カネソ22・formrun・Wix/Squarespace）。普通の Chrome を `--headless --dump-dom` で使うだけ。Cloudflare の確認画面（ルミカの Zendesk）は回避しない→「未確認・社長の Chrome で確認」と書く
3. **埋め込みフォームが死んでいることがある。** ユニコの smoothcontact は描画すると「フォームが見つかりませんでした」。iframe の存在だけで A にしない
4. **難読化メール**（シンカテックの charCode+1）は JS を読んで復号できる。フォームのリンクが HTML コメントで無効化されている例もあった
5. **必須項目の注記を読む。** リアル化学の「サロン名」は「サロン様以外の方は『一般』と入力」＝埋められる。台帳の「埋められないので電話」は誤りだった
6. フォームの注意書き：ペンギン食堂「URLの送信ができなくなっております」→打診文にURLを入れると送れない

## 判定ルール（今回こう処理した）

- A を2つに分けた：取引用（区分・専用窓口あり）と総合窓口（「その他」区分・用途限定なし）。件数はA合計で報告し内訳も添える
- 通販ショップのフォーム／特商法メールだけ＝B（購入者向け）。ただし会社概要に「営業」等の会社アドレスが載っていれば A（桝田屋の eigyo@）
- C でも取引用フォームが実在する社（パシフィック・アルボース・アスタリール・メイフラワー）は「（参考）」として窓口URLを残した。送るかは秘書判断
- 「一般消費者の方への販売はご遠慮」（ティアーズ）は「個人に直販しない」の意味もありうるが、ページ全体が美容室向けで代表商品が店販用のため C。推測の確度を書いた
- 専売の明記が無い流通偏り（PKB＝動物病院中心、シンカテック＝店頭小売と直接取引しない）は A のまま断りの欄に原文を残した

## ハマりどころ
- Python 3.9 で長い日本語行を含むスクリプトが「Non-UTF-8 code」で落ちた（compile() は通る）。先頭に `# -*- coding: utf-8 -*-` で解消
- `timeout` コマンドは macOS に無い。バックグラウンド起動＋ kill で打ち切る（dom.sh）
