## 手順（次に同型の「成功者の真似」調査を受けたとき）

1. 社内 memory を先に読む（今回は knowledge_ebay_export_takapiro と knowledge_mujaiko_risks）。
2. 検索は「手法＋月利100万＋達成／期間」で型ごとに1本ずつ。スクールの成果報告ページが最も数字（月次推移）を出している。ただし宣伝ページなので必ず「自称」と書く。
3. 到達者だけでなく「届かなかった例」を同じ型から最低1件拾う。期間の中央が楽観側に偏るのを示すため。
4. 検証可能性は A（第三者の記録）/B（本人のキャプチャ・時系列）/C（自称）の3段で付ける。
5. 期間の中央は「開始（または型の切替）から100万まで」を月数にそろえてから取る。前歴（転売経験・受講前の月利）は必ず併記する。
