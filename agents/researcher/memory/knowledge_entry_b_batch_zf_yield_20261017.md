## 手順で足したこと（再利用）
1. **推定ドメインは「社名ローマ字」より「商品名・ブランド名・運営会社の別名」が当たる**：小田原屋＝sennyogurume.com（看板商品「仙女キムチ」）、宮﨑本店＝miyanoyuki.co.jp（清酒「宮の雪」）、新日本機能食品＝kenko064.jp、36チャンバーズ＝36cos.com。社名ドメインは同名の別業種に当たる（miyazakihonten.co.jp＝葬儀社、odawaraya.jp＝料亭、yoshimi-inc.com＝吉見製作所）
2. **Web検索は「製造元」を聞くと当たる**：「◯◯ 製造元」で鈴木油脂工業（カビとり一発）・メイダイ（MOMI×2）・ジュモン化粧品本舗が出た。「◯◯ 公式 会社概要」は外れが多い
3. **並行の担当（ZG）が同じ社を拾っている**ことがある。xdup が `24_連絡先_batchZG.csv` を読むので、組み上げ後に必ず流す（今回 YOSHIMI を ZG 側が公式つきで特定していた＝その情報で自分の行を埋め直した）
4. build は recs.py に全行そろってから1回で出した（25社ごとの保存は、公式巡回を全社まとめて先に終えたため不要だった）

## 判定で足した型
- **公式通販に「転売目的の購入・転売を禁止・法的手段」**（えがお）＝除外（公式の取引方針）。大手判定より先にこれで落ちる
- **規模の線の読み方**：「従業員300人超・資本金3億円超」は中小企業基本法では「両方超えたら大手」。社員344人・資本金8,000万円（日の出屋製菓）／パート込み843名・資本金1,000万円（YOSHIMI）は中小として接触候補に置き、秘書判断に上げた（ZG と同じ扱い）
- **Amazon のメーカー欄が商品名になっている行**（カビとり一発・奥能登の塩）は Web検索で製造元を引けば公式に届くことがある
- **公式の商品一覧の JAN が代表ASINの JAN と一致**（讃岐物産）＝紐付け「一致」の最強の根拠
- 海外ブランドのカートを国内の輸入販売会社が持つ行（Uncle Bubble・TECH）は本人カート扱いで除外

## 公開版の漏れ防止
- 備考に海外セラーの社名（台湾の会社名）を書きかけた → 「台湾・台中の会社」に伏せた。leak.py の逆照合で引っかかるのは本人カート除外行のメーカー名だけ＝許容

## 論点（タケシ・秘書へ）
- 規模の線を「AND（両方超）」で統一するか。統一すると過去に大手へ落とした社（社員300人超・資本金3億円以下）が戻る可能性
- 要確認「公式未特定」19行は Web検索の歩留まりが低い（約2割）。電話・FAX 打診への切替は ZA・ZC・ZE と同じ論点
