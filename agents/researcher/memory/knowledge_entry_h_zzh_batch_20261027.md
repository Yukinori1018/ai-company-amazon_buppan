## 今回効いた型
1. **重複は「キューを作った後」にも残る。ov.py＋xdup.py＋シート退避の全列照合の3本を回す**。タカシの build で「既存台帳と同社」352社を落とした後でも、56社中10社が重複だった（社名表記が違う＝22印付きの三基商事、Keepa のメーカー欄が型番様の文字列＝持田ヘルスケア）。xdup は推測の社名（コロナ・持田）でも拾える
2. **推定ドメインが外れたら、ブランド名・製品シリーズ名で2回目を引く**：キンボシ＝golden-star.co.jp、日本薬興＝nihonyakkou.net（「薬興」の読みは yakkou）。社名のローマ字だけでは届かない
3. **製品サイトの英語版・フッターに会社サイトへのリンクがある**：エアースペンサー（airspencer.com/en/ → eikosha.kyoto）。製品サイトに会社概要が無いときは英語版を見る
4. **JAN の9桁事業者コードがカート店の扱う別ブランドと同じ＝カート店側の採番**（SAKURA エンジンオイルと MAHLE が 458062969）。7桁で見ると共有が多すぎて使えない。9桁で見る
5. **公式の「新規取引」ページは取引できる業態まで読む**：プロラボはサロン・クリニック等に限定（EC 小売の記載なし）。打診可否は秘書判断の論点として要確認に置く
6. **商品サイトが落ちている（503）なら紐付けは未確認のまま**。会社サイトの事業説明（日本語版製造販売）だけで一致にしない（アークライト）

## 道具の注意
- Python 3.9 で、日本語を含む長い1行（RETAIL の dict）を置くと「Non-UTF-8 code」の SyntaxError が出た（ファイルは正しい UTF-8）。先頭に `# -*- coding: utf-8 -*-` を入れ、dict を行で分けたら通った。stdin のヒアドキュメントでも同じ症状が出たので、長いスクリプトはファイルに書いて実行する
- 新設 `batchZZH/sheetdup.py`：最新の「メーカー連絡先」タブを持つ退避（sheet_backup_before_*.json）を選んで語で照合。sakamoto_phone のように形の違う退避が最新になることがあるので、キーの有無で選ぶ
