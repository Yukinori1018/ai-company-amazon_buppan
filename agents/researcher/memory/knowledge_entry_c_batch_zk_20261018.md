## 🔴 失敗とリカバリ（次回は必ず手順に入れる）
- **サクラカネヨ（吉村醸造）を一度「接触候補」にした**。「企業・新規お取引」フォームを見て窓口ありと判定したが、フォームの上の「新規お取引をご希望の方は、はじめにこちら」のリンク先 `/new-transactions/` に「通販のみでの新規取引は受け付けておりません」と書いてあった。並行の ZM（4555 位・同社）が先に見つけ、xdup で気づいた
- **わかさ生活も同じ**：コーポレートサイトには何もなく、通販サイトの特商法（wakasa.jp/info/tokusho）に「転売やオークションサイト等での出品・販売を固く禁止」
- 是正＝`batchZK/scan.py`：接触候補の公式ドメインのキャッシュ全ページ＋「取引・卸・新規・販売店・代理店・通信販売・法人」リンクを1段たどり、「転売・通販のみ・ネット販売・Amazon・楽天・新規取引」の近くに「お断り・受け付けておりません・禁止・できかねます」があるかを機械で走査する。**組み上げた直後、公開版を作る前に必ず回す**（25社で2件＝8%が落ちた）
- 窓口ページを見たら、その中の「はじめにこちら」「ご案内」リンクを必ず開く。窓口があることと、その窓口が当社を受けることは別
