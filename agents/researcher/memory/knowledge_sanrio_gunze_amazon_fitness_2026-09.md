## 🔴 SD の出展企業は、非ログインで「企業情報」まで読める

- 取引条件・送料：`https://www.superdelivery.com/p/do/dpsl/dcc/<企業コード>/`
- **企業情報（設立・資本金・年商・従業員・事業内容・仕入先・販売先）：`.../dpsl/di/<企業コード>/`** ← 成果物01では未把握だった導線。ここに**仕入先メーカー名が実名で載る**（丸進＝グンゼ株式会社・株式会社サンリオ・西川産業 等）。
- 商品一覧：`.../dpsl/<企業コード>/`（絞り込み欄に取扱ブランドが列挙される）
- **送料も非ログインで確定値が取れる**（丸進＝本州 税抜2万円以上で無料／未満800円）。社長の「送料が推定で不正確」への直接の回答材料。**卸の採算を詰めるときは必ず dcc と di の2ページを先に取る。**

## 知財の切り分け（この型は他ブランドでも使える）

- サンリオ公式（一次）：世界150カ国以上で**登録商標20,000件超**（2025/9）、**約60カ国で行政・刑事摘発／民事訴訟／水際／オンラインテイクダウン**、法務部が専任。「権利行使が厳しい」は通説でなく**権利者自身の開示で裏が取れる**。
- ただし**権利行使の対象は侵害品（模倣品）**。真正品の再販を禁じる記載は公開文書に無い。
- **当社に効くのは「商品画像の著作権」。** Amazon セラーフォーラム（Amazon 自社ドメイン＝一次）に、**正規ルート（製造発売元→卸→出品者）で仕入れたキャラクターグッズが「著作権画像の不正使用」で削除され、Amazon が「ライセンス契約書・販売許可証」を要求 → 小売は保有し得ず解決不能**という事例が複数。違反5件でアカウント健全性が黄色になった例あり。
- → **キャラクター商品は「仕入れの正当性」では守れない。**画像を自分で撮っても、申立てが来た後に覆す書類を持てない構造。**停止リスクを抱えている時期に取る選択ではない。**
- 対照的に**グンゼ公式には模倣品・転売・正規取扱店の注意喚起が無い**（FAQ「販売について」N=10問・該当0）。不在の確認も事実として書く。

## 採算の早見（今後も使える形）

利益率20%を満たす最低売価 P ＝ （FBA + 仕入税込）÷ 0.716（服＆ファッション小物 750〜2,500円は販売手数料 **8.4%**、FBA 小型288／標準318〜532円。出典 sell.amazon.co.jp/pricing）。
→ **「Amazon の実売価格が卸値（税込）の 1.7〜2.3倍あるか」**が1行フィルタになる（卸値が高いほど必要倍率は下がる）。
[[feedback_volume_sellers_only]] の「卸値がAmazon価格の70%以上なら計算前に落とす」の、卸側から見た裏返し。

## バリエーション品の減点を数字にする

月販100（=バリエーション家族の合計）÷ バリエーション12 ÷（出品者2+1）≒ **月2.7個**。初回10点（ゲート解除の要件）で**消化3.7ヶ月**。
回転上限6ヶ月の内側だが余裕なし。**どのサイズ・色が売れているかは Amazon 側から見えない**ので、卸に聞くしかない（＝§4.1 第三者連絡）。
**アパレル卸を評価するときは「バリエーション数」を必ず1列取る。** 取らないと月販の数字を12倍甘く読む。

## 手順として再利用できること

1. 卸の企業コード → dcc / di / 商品一覧の3ページを curl（ログイン不要・ここで送料と仕入先メーカーが確定する）
2. 取扱ブランド → Keepa で正準ブランド文字列を確定（候補を一括 probe）
3. ブランドごとに「総数／月販100以上／うち本体不在」の3数字だけ先に出す。**ここで入口の有無が決まる**（サンリオは8件＝この時点で終わり）
4. 本体不在の集合だけ /product で価格・出品者数・バリエーション数を取る
5. ゲートは机上で決着しない。**候補ASINのCSVを作って秘書に渡す**のが正解（セラセン実機確認は1件3秒）

## 正直に書いた穴

丸進の1,343商品と Keepa 候補68件の**SKU 単位の対応は取れていない**（非ログインのため）。採算は「卸価格の分布」×「Amazon 価格の分布」の照合であり特定 SKU の実額ではない、と成果物に明記した。
→ [[feedback_research_accuracy_blocker]]。**分布同士の掛け合わせを「実測」と呼ばない。**決着手順（JAN→ASIN 引き当て。SD は JAN 記載率71%）まで書いて渡す。
