# 低単価在庫の処分は、売価より先に「1口の送料」を見る

2026-10-09、Amazon で出品不可と確定した12点（1,646円/個）の現金化案を作った。
最初に売価を調べたが、**結論を決めたのは売価ではなく送料850円だった。**

## 手順（次も同じ順でやる）

1. **荷姿を先に決める。** 箱の3辺合計を測り、「80サイズ（850円）に何個入るか」を数える。
   28.1×27.7×7.4cm なら 1個=63.2／2個=70.6／**3個=78.0cm まで80サイズ**／4個=85.4cmで100サイズ。
   12個は2列×6段で 56.2×28.1×44.4＝128.7cm → 140サイズ（1,400円）
2. **損益分岐の売価を出す。** `(原価 + 送料 + 集荷料) ÷ (1 − 手数料率)`
   - 単品：(1,646+850+50)/0.95 = **2,680円**
   - 3個セット：(1,646×3+850+50)/0.95 = 6,145円/口＝**2,048円/個**
   - 12点1口：(19,756+1,400+50)/0.95 = 22,322円＝**1,860円/個**
3. **相場（SOLD実績）と分岐点の比を見る。** 1.0倍に近いものだけが候補。
   - 単品 2,680 ÷ 相場2,480 = **1.08倍（届く）**
   - 3個 2,048 ÷ まとめ相場1,600 = 1.28倍（届かない）
   - 12点 1,860 ÷ まとめ相場1,233 = 1.51倍（届かない）
4. **その上で作業時間を分で出す。**

## 学んだこと

- 🔴 **「まとめ売りにすれば送料が節約できる」は半分しか正しい。** 送料は1/12になるが、まとめ売りの実SOLDは **1,100〜1,200円/点**（N=3・ラクマ）で単価が25〜50%落ちる。**節約額より下落額が大きいと分岐点は遠のく。** 今回は12点一括の方が損失が3倍（▲7,146円 vs ▲2,284円）
- 🔴 **「黒字になりうる案が1つしかない」なら、作業時間の議論より先にそれを言う。** 3案を並べてから「どれも赤字です」と書くと、社長が読み解く手間を負う（memory `feedback_dont_present_absurd_options`）
- **損益分岐の売価が新品の市場最安とほぼ同値になったら、それは「仕入値が高すぎた」という診断である。** 今回：分岐2,680円 vs 価格.com最安2,690円。CLAUDE.md §3.3-6「仕入れが実在することを確認する」の前に、**その価格で売れる棚か**を見るべきだった
- **集荷の有無で作業時間が1.5倍変わる。** 持込前提だと12回×15分＝180分、ヤマト集荷（50円/取引）なら12分。**「社長が12回コンビニに行く」を既定にして案を不利に評価しない**（条件は変数・CLAUDE.md §3.1）

## 社長の条件との接続

- 社長は**労働集約を嫌う**（memory `owner_not_labor_intensive_build_systems`）。作業時間は必ず**分**で出し、案ごとに「時間を何円/時で売る/買う取引か」を計算して添える。今回：単品→3個セットは 2,900円/時、3個セット→12点一括は 4,400円/時
- **手残りを目的関数にしない**（memory `feedback_dont_present_absurd_options`）。数千円の差より「売り切れるか（＝現金化できるか）」を上に置く
