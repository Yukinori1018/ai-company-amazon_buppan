## 効いた手順
1. `11g_追加候補_入口f.csv` の `代表商品名` を先に全行出す（キューには商品名が無い）
2. 推定ドメインを複数周（社名のローマ字→ブランド名→検索で分かった運営会社名）。今回は6周で約35社に到達
3. 楽天：検索結果から**ブランドの直営店らしい店**（店名にブランド名・「公式」）を選んで商品ページの「発売元／販売元／メーカー」を読む。上位の店を機械的に取ると無関係な商品を読む（rk.py の上位5件は検索語と関係ない品が混ざる）
4. 楽天の「販売元」がカート保持店の特商法の販売業者と一致したら本人カート→既存台帳の重複に落ちることがある（5448 ファスティングメイト＝エクセレントメディカル）

## 判定の型（今回足したもの）
- サロン専売で「ネット通販は正規ルート外」「インターネット販売なし」を公式に明記 → **後回し**（Z4 の前例）。「直接のお取引は行っておりません」「Amazon 等は正規外」まで書いてある → **除外**（eyez）
- 公式の問い合わせページの電話・メール欄が JS で空 → 窓口未取得の**要確認**（菊星）。`include.js` を curl しても値は出なかった
- くじの景品が代表商品（ちいかわくじ C賞）→ 会社と窓口が分かっても**要確認**（卸で仕入れられる商品か不明）
- 酒類（ワイン）は検索を使わず要確認（打診第1弾の対象外の品目）
