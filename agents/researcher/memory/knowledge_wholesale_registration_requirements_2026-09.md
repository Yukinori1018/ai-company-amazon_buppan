## 二度と間違えないための注意（今回の学び）

| 罠 | 正解 |
|---|---|
| **規約に書いていない＝OK、ではない** | **入口の審査基準はヘルプセンター側にあることが多い。**orosy は API 規約全35条に Amazon 禁止条項が無いが、公式ヘルプの「バイヤーの利用審査基準」に「ご利用頂けません：ネットショップのうち…**モール**…」と明記。2026-08-31 の「orosy 可（条件付き）」判定は**この取りこぼしで誤り**だった。**規約とヘルプセンターの両方を見る** |

## 決定的な事実：`satoy-select.com` に販売機能はない（2026-09-04 実測）

12,334バイトの静的1ページ。`cart` `カート` `購入` `特定商取引` の出現**すべて0回**。Shopify/BASE/STORES/WooCommerce/EC-CUBE の痕跡なし。
本文に「販売・配送は Amazon.co.jp のストア『Satoy Select』で行います」「**Amazonストア、まもなく公開します**」。

→ **「販売サイトURL」を求める卸（orosy／TEN TO TEN／卸売ドットコム／スーパーデリバリー）に出すと、「オープン前」または「モール」と読まれる。**
→ T-20260904-005 の B案（自社ECで書類#1を満たす）は、**現状のサイトのままでは成立しない**。

## Amazon の出品プラン要件について

**今回調べた12社中、大口/小口を入会要件に明記していたのは 0社。**
スーパーデリバリーの「Amazonの場合、小口出品でのご利用はご遠慮いただいております」は**SD固有の運用**と見てよい。
参照点：**NETSEA は小口のまま登録できている**（社長の実績）。
→ 「卸に登録するために大口へ戻す」という論拠は、少なくとも公開要件からは出てこない。

## 再利用できる手順（次に同じ依頼が来たら）

1. 候補の発見だけ二次記事で行う（「仕入れサイト◯◯選」）。URL を控える
2. `curl` で `href` を抜き、`term|kiyaku|law|tokusho|guide|faq|regist|entry|member` を含むURLを列挙
3. 各ページを HTML→テキスト化し、`Amazon|大口|小口|審査|入会|個人事業主|法人のみ|開業|固定電話|実店舗|販売サイト|最低|ロット|送料|無料|転売|モール|禁止` で grep
4. **登録フォームの `<label>` と `name=` を抜く**（要件が確定する。§4.1 に触れない）
5. ヘルプセンターが Cloudflare 403 なら **Zendesk API** に切り替える
6. 「規約に無い」で終わらせず、**必ずヘルプセンターの審査基準を探す**
