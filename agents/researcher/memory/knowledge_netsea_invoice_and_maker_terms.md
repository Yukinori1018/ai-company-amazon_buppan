# NETSEA の請求書でゲート解除できるか／メーカーの取引条件はどこまで公開されているか（2026-09-12 / T-20260912-001）

## NETSEA の書類（公式で確定した事実）

- 発行者は**サプライヤー**。NETSEA 運営ではない。根拠は2つ：規約16条1項「当社は売買契約等の当事者にはなりません」、請求書の登録番号は「サプライヤーが入力していない場合は表示されない」。
- 表示は法人名（2015-08-03 から。商号・店舗名ではない）。PDF は出荷確定後にマイページから出せる。**項目の追加・変更は不可。**変更したいときはサプライヤーへ相談（NETSEA 公式の案内）。
- **掛け払いの請求は GMO ペイメントサービスが発行**＝卸の請求書として使えない。ゲート解除に使うなら掛け払いは避ける。
- 直送（住所変更）した注文の納品書は、宛先が消費者になり、価格も出ない。
- **公式に書かれていないこと**：卸の住所、宛名の住所、請求書番号。いずれも「請求書番号が無い」で却下された事例（2022年頃）がある。**確定させる唯一の手段は実物の PDF**。当社は 2026-09-12 時点で NETSEA の購入実績ゼロ。

## 罠（次に同じ依頼が来たら）

- 「サプライヤーに直接請求書を頼む」は一般的な代替だが、**NETSEA では NETSEA の機能を通さない連絡が規約7条2項5号で禁止**（違約金200万円＋代金50%）。代替を提案するときは必ず「NETSEA の問い合わせ機能経由」と書く。
- sedori-hero.jp は DNS 解決不可。web.archive.org は WebFetch 不可。この2つに時間を使わない。
- セラーフォーラムの日付は相対表示（「4年前」）。年は推測と明記する。

## メーカーの取引条件は公開されていない（実測 N=20）

- 展示会出展メーカー20社で、個人事業主の可否を公開していたのは **0社**。Amazon 販売の可否も **0社**。最小ロットの数字を書いていたのは4社（うち完成品の卸は2社）。
- → **「公開情報で取引条件を埋める」依頼は、ほぼ全セルが「記載なし」になると先に宣言してよい。**取れるのは「窓口の型」（取引専用の選択肢があるか）と、たまに書いてあるロットだけ。
- 手順：会社概要／取引・法人ページ／問い合わせフォームの選択肢の3点を読む。**フォームの選択肢の文言が一番情報量が多い**（「新規お取引条件の案内を希望」「お取引について」の有無）。
- 例外の型：卸の入口があっても**飲食店専用**のことがある（木村硝子店 zizi Pro）。「卸会員制度あり」だけで可と書かない。
- EUC-JP の古いサイト（池本刷子）は、https が接続拒否されることがある。WebFetch は http を https に上げてしまうので、**curl + iconv -f EUC-JP** で読む。
