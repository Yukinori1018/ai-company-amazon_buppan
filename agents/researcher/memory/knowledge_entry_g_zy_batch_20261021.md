- **次回の手順**：特商法を取った直後に、販売業者名（＝正式社名に近い）も ov.py に投げる。検索で社名が分かったら、窓口を取りに行く前に ov.py にもう一度投げる

## 🔴 上場列の同名別会社の取り違え（3件目）
- 5672「CAC化粧品＝CAC Holdings（IT・4725）の子会社の疑い」は誤り。実体は株式会社ＣＡＣ（千葉県流山市・61名）。トミタ・LOGOS に続く3件目。キューの上場列が「子会社の疑い」の行は、親の業種と商品の業種が合うかを最初に見る

## 判定の型（今回足したもの）
- ライセンス品（EDWIN の靴）は、カート店の販売業者＝ライセンスを持つ企画元（フェアストーン）なら本人カートとして除外。ブランド元（EDWIN）で大手にしない
- カート店の特商法の所在地が、ブランド会社の公式の所在地と同じ（Ecotone とコスメカンパニー）→ 同じグループ＝本人カート（推測）
- 公式トップに商品名が無い会社（デイワン）は、同社のプレスリリースの所在地が公式の会社概要と一致すれば紐付け「一致（ブランド単位）」にし、理由に書く
- 同名の別会社に注意：dayone.co.jp（人材）≠ day-one.jp（サプリのデイワン）、hokuto-net.com（建設）≠ 北斗ネット（ボディソープ）
- 酒類は検索を使わず要確認（前例どおり）

## 道具のメモ
- recs.py の ok() に渡す「紐付けの判定」は mk67.py の許可リスト（一致／一致（ブランド単位）／一致（表記ゆれ）等／未確認）の値だけ。自由文を入れると assert で止まる
- 行を差し替えるときは recs.py の末尾で `del R[k]` してから dupE する（d() は同じ順位の二重登録を assert で止める）
- 公開版の販売店名は build.py の RETAIL 辞書（順位→語のリスト）で伏せる。leak.py はカート店名しか見ないので、備考に書いた販売店名は自分で grep する
