# Keepa API を実務で使っているのは誰か（T-20260920-002 S-A・2026-09-20）

## 一番の発見：API 課金者と高実績実践者は別の集団

実例21件（日本・海外・GitHub・学術）を集めた結果、はっきり分かれた。

| 集団 | 使うもの | 具体例 |
|---|---|---|
| **API €49 を払う人** | API | ツールを作って配る人（ツールドブッパン・amznlog の monoPeak/AsinKeeper）、SaaS（Seller Assistant は Keepa API + SP-API を統合して $13〜30/月で売る）、学術（Jürgensmeier & Skiera, Journal of Marketing 2025・11市場を一括取得）、物販以外の価格ウォッチ（GPU 価格追跡） |
| **月商/年商の数字を出している実践者** | **ウェブ版 Pro €29** | FBA Mogul（自称7桁ドル）・BowTied Slinger・Gのすけ（年商1億）・**EC STARs Lab.（当社の型Aの原典。「必ず有料版」と明記し API に一切言及しない）** |

**「自分の仕入れ判断のためだけに API を払っている実践者」は0件。** 社長の見立て（API で利益商品を探すのは微妙）は実態と一致していた。

## 型A（ブランド名 → Amazon上の商品 → 営業担当に連絡）の手順は Pro ウェブに書かれている

- FBA Mogul / BowTied Slinger：「仕入れ先のブランドリストを Product Finder に貼って全商品を洗い出し、勝ち筋商品を特定して営業担当にメールで特別発注を依頼」。これは**当社の型Aとほぼ同じ手順で、API ではなく Pro の画面**。
- ECセラーラボ（メーカー仕入れ）：Chrome拡張＋Amazon画面＋スプレッドシートだけ。**セラーリサーチ＝メーカー仕入れをしている他セラーの出品商品からメーカーを逆引き**する型。
- 一方、**brandStoreName 空欄で「自社出品していないメーカー」を炙り出す手（当社 T-20260914-006 の 2,425社）は実例が見つからなかった＝当社独自**。

## Pro €29 に付くもの（当社は未契約・画面を1度も見ていない）

Product Finder（1検索でクオータ5%・1%/時回復＝1日20〜24検索・結果は1画面最大5,000件を CSV/Excel 出力）／Product Viewer（1回 最大10,000 ASIN 投入・クオータ100%で1日 最大36,000件の入出力）／Seller Lookup（セラーの出品ASIN全件＋CSV）／Best Sellers／ランク・出品者数・評価の履歴／**API 1トークン/分**。
→ **取れるデータの種類はほぼ同じで、違うのは速度（20/分 → 1/分＝1/20）。** 当社の夜間スキャン（1回1〜2万トークン）は「7時間 → 約1週間」になる。
→ **未確認**: Pro の1トークン/分で Product Finder エンドポイントが使えるか／Product Viewer の出力列に brandStoreName があるか。

## 手順として再利用できること

1. **「API か Pro か」を必ず区別して読む。** 日本語のせどり記事は「Keepa 有料版」「Keepa の機能」と書き、API と Pro を混ぜる。書き手が API キーを持っているかは、トークン・エンドポイント名・プログラムの記述があるかで判別する。
2. **ツール調査は「誰が払っているか」で分類すると答えが出る。** 機能比較表より、課金者の職業分布（開発者/SaaS/研究者/実践者）の方が継続判断に効いた。
3. **不在証明の限界を明記する。** 「言及が無い」は「使っていない」の証明ではない。今回も推測と明記した。
