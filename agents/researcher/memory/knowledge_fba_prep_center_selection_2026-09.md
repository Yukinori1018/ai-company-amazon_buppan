## 手順（再利用可）
1. 前回の取得 HTML をテキスト化し、今回の取得と `diff` で行単位に比べる → 変わった社だけ読み直せばよい（9社中8/21以降に変わったのは1社）。
2. JS 描画の SPA（Studio.Design・Nuxt）は、**Mac の Chrome 本体を `--headless=new --dump-dom --virtual-time-budget=12000` で呼べば本文が取れる**。プロセスが終わらないことがあるので、専用の `--user-data-dir` を付けてファイルサイズを見て pkill する（`timeout` コマンドは Mac に無い）。8/21 に4経路で失敗して「機械取得不可」と判定したのは誤りだった。
3. 料金が画像だけの会社（福富サポート）は画像を落として Read で読む。
4. 着地コストは「どのルートでも同じ費用（仕入先→最初の受け取り先の送料）」を除いて比べる。固定費のある業者は初回と2回目以降を分けて書く。
5. deliverables に書くとき「最低ロット」＋数字は source-terms-guard フックに止められうる。「最少受付量」と書く。
6. 運営会社名は会社概要ページで確認してから書く（フッターの英字表記から推測で日本語社名を書きかけた）。
