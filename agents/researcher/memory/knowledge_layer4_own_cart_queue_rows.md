1. キューのカート保持セラー名を**全文**で出す（20字で切ると「…みの屋直販店」のような決め手が消える）
2. 既存台帳と ov.py でキーワード照合 → 同社は重複（若い順位が正）
3. セラー名とメーカー・ブランド名が**別名の行だけ**を拾い、公式とカート保持店の特商法を見る。今回は5行（2212・2256・2258・2266・2268）

4. 残りは recs.py を機械生成（理由2種：公式/直営/メーカーを名乗る＝確度高、名前一致だけ＝推測）。備考に「落とす基準＝§3.3-5・実画面未確認」
5. 組み上げ後に xdup.py（担当文字を引数で受ける版：`python3 xdup.py W`）で並行担当と再照合
6. 公開版は leak.py で検査。**備考にカート保持店の名義を書くと build の置換で消えない**（「【公式】タイガ株式会社を名乗る」→ 名義だけが残った）。名義と根拠URLは agent_output の sources_private.md に分けた

### 手順の更新（再利用可）
1. **カート保持店が別会社かは、Amazon 出品者プロフィールの特商法で直接見る**：`raw/seller_names.json`（seller ID→店名）を逆引きして `https://www.amazon.co.jp/sp?seller=<ID>` を1件ずつ取得（間隔4秒・13件で拒否なし）。「特定商取引法に基づく表記 販売業者:」を読む。W のように楽天店や自社サイトを探すより速く、確度が高い。名義は sources_private.md へ
2. 本人カートの見分け：販売業者＝メーカー名（確度高）／**住所がブランド公式通販の返品先・発送拠点と同じ番地**（推測・確度高）
3. 層5（大手）は gBizINFO（gz.py）で従業員→公式の会社概要（auto.py → company/outline 等を pg.py で「従業員|資本金」）で確認。上場はキューの上場列。**上場列は社名一致の機械判定で、同名の別会社が入る**（やまや）
4. **xdup.py の再照合で同社を拾える**：くうきれいはブランド欄（ショーワグローブ）では引けず、正式社名の部分一致（ショーワ）で C267 が出た。ヒットは必ず中身を開いて別会社か確かめる（トーヨー／トーヨ、ユニカフェ／ユニカは別）
5. **公開版の漏れ**：Amazon のブランド欄そのものが販売店名の行がある（あたご小西・オフィスエッジ）。build.py に「ブランド欄がセラー名の一部なら伏せる」を足した。leak.py はセラー名→公開版の向きしか見ないので、**値がセラー名に含まれる向き**も検査する
