## 事実の要点（再利用用）

- 公開情報で見つかる「月利100万の中国輸入実践者」は、12人全員がスクール・コンサル・代行業者を兼ねていた。手法だけを無償公開している本業の販売者は0人。数字は全部「自称」と書くこと。
- 共通の型：既製品で需要を確かめる → 売れた物だけ簡易OEM（ロゴ・タグ・箱の変更、10〜100個、3万〜25万）→ 当たりに本格OEM（300〜500個以上、数十万〜）。
- 1商品目：出品まで2〜3ヶ月。費用の中央値は約25万（N=5、推論）。初期費用の回収は6ヶ月超。
- 失敗の基準率として最も信頼できたのは、赤字月まで月次表で公開している「ひゆん」（hiyun.jp）の 3/20＝15%。成功例しか出さない発信者より、赤字を開示している発信者の方が基準率に使える。
- 日本は、自国セラーが多数派の最後の Amazon 大型マーケット（54%、Marketplace Pulse）。一方で中国の工場が Amazon 日本の FBA に直接出品しており、小型軽量品は値崩れ（3,200円→1,200円の例）。
- Amazon ブランド登録は日本でも出願中の商標で申請できる（sell.amazon.co.jp 公式）。検索結果には「日本は登録番号が必要」とする古い情報も混ざるので、公式ページで確認すること。
- 当社は免税事業者のため、輸入消費税10%が原価に乗る（推論・要ハジメ確認）。実践者の利益率30〜40%は課税事業者で、かつ円安前の数字が混ざっている。
