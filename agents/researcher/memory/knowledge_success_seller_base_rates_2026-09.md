# 「月利100万の成功者」を横断で検証する型（T-20260915-002 サトル⑤・2026-09-15）

## 依頼パターン

社長「成功者（月利100万以上）はごまんといる。真似しろ」。手法別の担当とは別に、横断で「何人いて・どの型が多く・1年目はどうだったか・スクールの成功率は」を問われる。

## 手順（再利用できる形）

1. 母数 → 実例 → 1年目 → スクール率 → M&A → 推論 の順で、層ごとに出典の種別（公的／公式／調査会社／事業者調査／媒体／自称／M&A）を付ける。
2. 実例は「到達」と「未到達（対照）」を分けて表にする。未到達の対照がないと成功談の分布しか見えない。
3. 「1年目の月利」は到達者（生存者）の中央と、一般受講者の分布（Earth Ship N=30）を並べる。片方だけ出さない。
4. スクールの公表値は、同じスクールの別ページと突き合わせる（アパリセは LP 90%超 vs 自社 note 約半数で食い違った）。
5. M&A は非ログイン公開分だけ。年商の推移が出ている案件がいちばん価値が高い（ピーク後の減衰が見える）。

## 分かったこと

- 月利100万級は日本に数千〜1万社台（推論・確度低）。「ごまんといる」は絶対数としては当たるが、参加者に対する率は数%以下。
- 到達者の最初の100万は、せどり・国内転売が最多（19件中6件）。27件中8件は単純転売から始めてメーカー直・OEMへ移った。
- 到達者の1年目の中央は約50〜80万（自称・生存者）。一般受講者の1年目は1〜3万円が最多帯。
- 卸・せどり系の M&A 案件は、年商がピークから2〜3年で1/3〜ほぼ0に落ちる（3件）。

## 注意

- WebFetch の要約は同じページでも回ごとに数が変わる（EC STARs 体験談の「月利100万以上」が1回目12件、2回目17件）。**件数は見出しを列挙させて数え直す**。
- 成功談の媒体は赤字期を書かない。「1年目赤字の記載0件」は「赤字が無かった」ではない。
- 出典の大半がスクールの自社媒体なので、型の分布は母集団推定に使えないと必ず書く。
- 作業途中でチケット番号が 001→002 に振り直された（番号重複）。成果物パスは発注メッセージの最新指示を正とする。
