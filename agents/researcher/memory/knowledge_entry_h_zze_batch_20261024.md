## 次の担当向け：今回の型
1. **キューのカート保持セラー名で範囲外まで grep する**。同じ店名が複数ブランドに出れば販売店（今回「【公式】A2ショップ」が7行）。特商法の販売業者が個人なら、その行は全部「別会社」として深掘りに回す
2. **会社名の漢字の異体字に注意**：報道は「河辺商会」、登記と楽天店は「河邊商会」。gBizINFO は「河辺商会」では東京の別会社しか出ず、「河邊商会」で堺の本体（従業員38人）が出た。**gBiz で所在地が合わないときは異体字（辺/邊/邉、斉/齋、沢/澤、高/髙）で引き直す**
3. **コーポレートサイトが無いメーカーは、自社の楽天店の info.html が窓口の出典になる**（CHOPLATE：店の説明に「はじめての自社商品…を製造しております」＝メーカー本人の店と言える）
4. **推定ドメインは「地名＋社名」まで振る**：井上商店は同名82社で、hagi＋inoue を連結した hagiinoue.co.jp で当たった（検索3回では公式が出なかった）
5. **輸入ブランドは「日本総代理店」を検索1回で引く**（HOTO→セキド）。🔴同名の別会社に注意：セキドは「西新橋・ドローン（sekidocorp.com）」と「新宿・化粧品（上場・sekido.com）」の2社。推定ドメインの sekido.com は別会社だった。HOTO JAPAN 公式ストアの特商法の住所で確定した
6. **公式の問い合わせフォームの種別に「卸売販売について」がある会社は、それだけで卸窓口の根拠になる**（CHANT）。HTML の select の選択肢は auto.py の DIST 行に出る
7. leak.py は「公式ストア」のような一般語を拾う。公式サイト名（HOTO JAPAN 公式ストア）なら誤検知として報告に書いて終える。本人カートの行でも、カート店の店名（「STRI 公式ストア」など）は備考に書かない

## 判定の線
- セキドはメーカーではなく輸入総代理店。公式ストアのフッターから Amazon の HOTO ブランドストアにリンクあり＝総代理店側も Amazon で売っている可能性（推測）。それでも今のカートは販売店なので接触候補に残し、備考に明記した
- ハトプラ（6137）：カート店の販売業者（ティーアイエス）とメーカー欄（アウトビジョン）が違うが、ブランド公式が「Amazon のドラッグストアカテゴリで販売」と自社販売を案内しているのでブランド側のカート（推測）で除外。商材はアダルトグッズ
- 景品パラダイス（6147）：販売店がディズニーペアチケットなどを組んだ景品セット＝メーカーが居ない棚。除外
- 大手と本人カートが重なったツインバードは、既存台帳（L1169）と同社なので「重複」を優先した（ZZB の「本人カート優先」より重複の方が先に決まる）
