# ブルーオーシャン調査の型：「カテゴリ」ではなく「壁の型」で切る（2026-09-12 / T-20260912-003 サトル②）

## 依頼パターン

「ブルーオーシャンを探して」「競合が少ない場所は」系の依頼。網羅（手法×カテゴリ×経路）を求められる。

## 今回の処理手順（再利用できる形）

1. 社長の制約を**母集団条件**として最初に表にする（個人・実績ゼロ・日本語・PC完結・10万円・6ヶ月・食品除外・古物商なし・法務NO）。緩和候補は別枠。
2. 「ブルーオーシャンである根拠」を**壁の型10種**（手間・ゲート・ロット・言語・地域・資格・資本・時間・知識・規約）に分類する。「誰もやっていないから」は根拠にしない。
3. 各案に9項目（手法・根拠・競合密度の証拠・制約適合・資金期間・利益構造・適法性論点・事例・既存手法との接続）。空欄は「未調査／未確認／該当なし」を書き分ける。
4. 最後に「壁の型×案」のマトリクスを置く。**壁が2つ重なる案ほど競合は減るが1件目までの期間が延びる**——これがタケシに渡す一番の構造。
5. 出典は S番号で一覧表。一次/二次/二次・低（商材系）を書き分け、取れなかった一次情報（ログイン必須・403/503）を末尾に列挙する。

## 分かったこと（次回はここから始める）

- **日本の個人セラーのベースレート（1年生存率・撤退理由・月商分布）は一次情報が無い。** Amazon公式は2021-10-05の「中小事業者約16万社」が最後。Jungle Scout は日本を分離しない。探しても出ないので「無い」と書く。
- Marketplace Pulse が日本のセラー構成の唯一のまとまった二次情報。54%国内（2025-04-03）／新規登録は中国系50%超（2024）／年商10万ドル超到達率 日本31%（2025-07-24）。
- **Amazon Handmade は日本で提供されていない**（公式プログラム一覧に無し）。Amazon Custom も日本は未確認。「日本に無いプログラム」は該当なしとして明記する価値がある。
- Makuake の実行者規約（申込書遵守事項16・17条）は Zendesk API（`/api/v2/help_center/ja/articles/<id>.json`）で全文が取れる。WebFetch は403。代理店の場合は**メーカーとの日本市場独占契約書の提出が義務**＝規約が独占を強制する珍しい経路。
- 特許庁の料金ページは403だが、料金一覧PDF（`industrial_pcharge.pdf`）は curl で取れる。商標：出願3,400円＋区分×8,600円／登録 区分×32,900円（10年）。
- 経産省 伝統的工芸品 事務局資料（2026-03-09）は WebFetch 403・curl 200。EC対応2割・1社平均5.2人・従業者4.8万人。
- Amazon 公式ヘルプ（危険物・要期限・定期おトク便・Renewed・Vine）は全部ログイン必須で本文0件。要件の数字は二次で埋め「二次」と明記した。社長のログイン1手で埋まる穴として残す。
- sell.amazon.co.jp/pricing は WebFetch で数値が取れる（FBA 小型222/288・標準318〜532・大型589〜1,756・特大2,755〜5,625円）。
- Yahoo!ショッピング 2026-09-01 有料化（月1万円＋2.5%）は複数二次で一致。公式ページは未取得。

## 失敗と注意

- 二次情報の「発表日」がブログの公開日と混ざる（sukeneko は2025-07-02表示、実際の発表は2026-02-27）。発表日は報道媒体（ECzine等）で取る。
- 出品者数を数えたい誘惑が強いが、Amazon本体の機械取得は法務NO。**「数えていない」と書く方が、推定で埋めるより価値がある**（社長の既定：推定と実測の分離）。
- 商材系ブログ（せどりブログ）は「大型商品は儲かる」等の主張の出典として弱い。使うときは「二次・低」と明記し、公式の数字（FBA大型料金）で裏を取る。
