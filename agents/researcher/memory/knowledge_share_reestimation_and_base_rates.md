## 3. 成立率 base rate は「独立した数字が何本あるか」で答える

- 公的統計（中小企業庁・JETRO・商工会議所）に「打診→返信→成立」の率は無い（JETRO は商談件数・成約金額まで。東商は事例の定性記述のみ）。
- 独立した実測は2本だけ: Amazon セラーフォーラム（個人事業主・14社→返信3・成立0・一次）、okinawanomadlife「98社」（返信55・取引OK16・検討10・断り29・無返信43・**原典 DNS 不通で検索要約のみ＝二次**）。
- EC STARs の「返信3割・見積5%・30〜50社に1社」は目安で、実測記述なし。HIRAI 本（技術評論社2024）に「返信率と成約率の基準」章があるが Web 上に数字なし。
- 業種横断の BtoB コールドメール返信率 3〜5%（Reachoutly・海外）は対象が違うので参考値どまり。
- **結論の書き方**: 「裏づける独立データは無いが、否定するデータも無い（N が小さい）」。1周目の送信結果が最良の base rate になる、と引き渡す。

## 4. Amazon ページからブランド登録を推定する（閲覧のみ・1社1ページ）

- WebFetch は Amazon の商品ページで骨組みしか返さない。**curl＋ブラウザUA＋Accept-Language: ja** なら 2MB の本体が返る（4秒間隔・20ページで robot check なし・2026-09-13）。
- byline `id="bylineInfo"` の href が3種: `/stores/`（ブランドストア＝ブランド登録の機能。公式 sell.amazon.co.jp/brand-registry）／`/<brand>/b/?node=…&field-lbr_brands_browse-bin=`（Amazon 側の browse ノード。登録の証拠にならない）／`/s?field-keywords=`（検索＝ストアなし）。
- 「透明性」は HTML 全体の文字列で検知（17ページとも0）。「ノーブランド品」は brand 欄が空の出品。
- 製造元一致だけの社（宇野刷毛→SOMOTO）は「自社ブランド出品なし」。**OEM 先ブランドが登録済みでも、そのメーカーが登録済みではない**。
- 20社の内訳: ストアあり1（田中帽子店＝窓口会社 BESPOKE が販売）・browse ノード6・検索リンク7・ノーブランド2・Amazon 上に商品なし4。
- 販売元も同時に読む: メーカー自身がカートを持つのは金野タオル・河野製紙・田中帽子店の3社、Amazon.co.jp 本体が販売元は廣田・池本・朝倉。
