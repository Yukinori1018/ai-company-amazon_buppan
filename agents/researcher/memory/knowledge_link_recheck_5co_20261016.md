## 効いた手（10/11・10/14 の手順への追加）
1. **actibook（電子カタログ）は原本PDFが取れる**：`saas.actibookone.com/content/detail?param=<base64 {"contentNum":"N"}>` の HTML に `files.actibookone.com/.../original.pdf?...` の署名付きURLがある（`&amp;` を `&` に直す）。pdftotext で JAN・商品CD・入数まで出る。10/11 は「本文取得できず」で未確認にしていた
2. **Amazon の「商品の説明」に産地・水・工場の地名が出る**：地名＋業種で gBizINFO の名前検索（`rc4/gz.py`）を引くと製造元が割れる（ヤマカノ→味噌平）。ブランド名（ヤマコノ）がそのまま公式ドメインのことがある（yamakono.co.jp。https は 403、http で開く）
3. Amazon 商品ページの取得：curl＋普通の UA で通る（4秒間隔・7回）。出品一覧は `/gp/product/ajax/aodAjaxMain/?asin=<ASIN>&pc=dp&filters={"all":true,"new":true}` で販売元・出荷元が並ぶ。販売業者の住所は `/sp?seller=<ID>`
4. 製造元が別会社と分かったら、**判定は「未確認」のまま**にして理由欄に本当の製造元と窓口を書く。67 で「一致」にすると、台帳の行（社名・窓口は元の会社のまま）が第1弾に入り、**別の会社に打診が飛ぶ**

## ハマりどころ
- **sync は glob の名前順で「後のファイルが勝つ」**。`65_カート確認_20261016.csv` は `65_カート確認_JKL_...` より前に並び、10/11 の古い値に負けた。既存ファイルに同じ ASIN があるときは、後ろに並ぶ名前（例 `_ZZ_`）にする。67 も同じ（今回は他に同じ ASIN が無いことを grep で確かめた）
- オフライン測定スクリプトで除外する文字列に1文字（"X"）を使ったら batchX まで消えて行数が変わった。除外は日付など一意の文字列で
- Python 3.9 で日本語の長い heredoc を `python3 -` に流すと「Non-UTF-8 code」で止まる → ファイルに書いて先頭に `# -*- coding: utf-8 -*-`
- 65 の確認者欄は sync 側で「（日付実画面確認・カズヨ）」と固定表記になる。サトルの取得でもカズヨ名義になる（報告に書く）
- パスワード保護の PDF は解除しない（読めないと書いて止める）
