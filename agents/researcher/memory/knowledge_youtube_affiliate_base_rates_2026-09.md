## 今回見つけた「探し方」（次回そのまま使える）

1. **顔出しなしYouTubeの実収益は、M&A案件一覧で取れる。**
   `https://rakkoma.com/project/list?sale_subtype[]=201`（ラッコM&A／YouTubeアカウント）に、登録者数×月収益×希望価格×体制（AI台本/外注/顔出しなし）が**実数で並ぶ**。
   個人の「月◯万稼いだ」note は全部自称だが、**売却案件は買い手に見せる数字なのでまだマシ**。
   **選択バイアスは必ず明記する**（売りたい人のサンプル＝伸び悩みと高値換金が混在）。
   → 同種の使い方：UREBA（`ureba.jp/projects/youtube/`）も同じ構造。

2. **業界のベースレートは2団体あり、値が約2倍ずれる。両方出して理由を書く。**
   - **AMA（NPO法人アフィリエイトマーケティング協会）** `affiliate-marketing.jp/release/202506.pdf` … n=1,374、**ASPを現に使っている人**が母集団（歴5年以上が35%）＝生存者バイアス。月20万以上 20.7%。
   - **JAO（日本アフィリエイト協議会）** `japan-affiliate.org/news/survey2025/` … 一般人21,054名スクリーニング→n=1,000＝**全参入者に近い**。月3万円以上 **12.4%**、月1,000円未満 **52.5%**。
   → **「新規参入した自分がどうなるか」は JAO 側、「続けた人の到達点」は AMA 側。** 混ぜると桁を間違える。
   → AMA の PDF は WebFetch で読めない（FlatDecode）。**`pdftotext -layout` でローカル抽出すれば表の数字が全部取れる**（今回これで分布を復元）。

3. **プラットフォームのポリシーは「禁止/許可」の二値で読まない。**
   YouTube の 2025-07-15 改称（繰り返しの多いコンテンツ → **量産型のコンテンツ**）は、日本語公式 `support.google.com/youtube/answer/1311392?hl=ja` に**原文が載っている**。専用ページ（answer/16354172）は 404。
   **AI利用は禁止されていない。**禁止は「独自の洞察のないテンプレ量産」。2026-07-16 の明確化で非収益化は3分類＝①テンプレ反復 ②感情操作 ③**金融/法律/医療のAIペルソナ**。③は設計レベルで潰れるので、会社員向け「副業・節約・クレカ・保険」をAI音声のバーチャル人格で語る案は**提案してはいけない**。

## 社長に出すときの型（今回これで通した）

- **結論表を §0 に置く**（「乗るか／乗らないか」を先に断言する）。社長は「視座が高く結局何をやるか分からない」を嫌う。
- **「明日からの3手」は全部 0円で書く。** 登録者0・売上0の段階で有料ツール・ドメイン・外注を1行でも書くと `owner_privacy_ok_but_no_wasted_cost` に触れる。ElevenLabs は「無料のVOICEVOXで足りるので今は不要」と**落とす理由まで書いた**。
- **制約でレーンを落とさない。** 顔出しNGは阻害要因でないことを実例（サラタメ・顔出しなし案件19件）で先に潰し、落としたのは「広告収益で200万」という**目標設定の置き方だけ**にした。
- **週次の動きは「打ち切り条件」まで書く。**（例：20本で平均視聴3分未満かつ登録100人未満なら題材を替える／3ヶ月でASP発生0なら凍結）
