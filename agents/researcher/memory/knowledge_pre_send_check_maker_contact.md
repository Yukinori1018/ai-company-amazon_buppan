## 一番効いた確認（次回は最初に見る）

1. **取引用フォームの「注意書き」を全文読む。** アニマル・ワンは業務用フォームの中に「楽天やAmazon等のプラットフォームでの新規のお取り扱いは現在お断り（実店舗併売は応相談）」と書いていた。会社概要・お問い合わせ一覧には出てこない。**フォーム本体まで開かないと見えない**
2. **トップの「お知らせ」一覧で「転売」を grep。** SAIO（2017年「正規販売店1社以外への卸販売は一切行っていない」）と第一酵母（「転売禁止について」損害賠償・法的措置）はここで見つかった
3. **フォームの選択肢が流通方針を語る。** 健康フーズ「販売方法：ネット販売」、EM生活「販売希望」＋パートナー種別「WEB」、ケイエムテイ「正規代理店をご希望の方」、アビオス（ジャンルにネット通販が無い）
4. **取扱店一覧にネット店舗が載っているか**（ビット・トレード・ワン、ケイエムテイ）＝ネット販売を受け入れている事実の根拠になる
5. **会社概要の「主要株主」「沿革」末尾**：ナチュラルウェーブは2026-02に上場企業の100%子会社になっていた

## ハマりどころ

- **HTMLコメント内の文字列を拾う。** エレキットの「取扱店募集」は `<!-- -->` 内で画面に出ていなかった。キーワード抽出の前にコメントを除去するか、生HTMLで `<!--` を確認
- **JavaScript描画のフォーム**（kintone・Wix・独自JS・POST遷移）は項目を静的に取れない：川ばた乃エキス・サンソリット・古賀製茶本舗・アークトレーディング。「未確認」と書き、ブラウザ確認に回す
- **Googleフォームは静的に取れる**（`FB_PUBLIC_LOAD_DATA_` の JSON。項目名・必須・選択肢）
- **文字数制限は maxlength を見る**（ビット・トレード・ワン本文300字）。打診文の長さに直結する
- 「LINEでお問い合わせ」ボタンがリンク切れ（自サイトへ戻る）のことがある（埜辺刷子）
- 依頼途中で対象が差し替わる（メーカー本人カート判明で2社除外→2社追加）。送信順の列は「差替A（旧3の枠）」のように元の枠を明示した

## 判定ルール（今回こう処理した）

- 送らない＝**当社の販売形態（実店舗なし・Amazon）を明示的に断っている**ときだけ
- 要注意＝卸先限定・正規代理店制で法的措置を明記・流通の中心が医療機関・窓口が電話のみ／ブランドが公式に見当たらない、のいずれか。理由を1行で書く
- 「親会社が変わった直後」は推測扱いで送ってよいに残し、判定理由に推測（確度低）と書く
- 送る／送らないの最終判断と、要注意社への文面の変え方は秘書・プランナーの領分（ここで止める）
