## 手順（ZJ からの差分だけ）
1. sid は raw/prodbb_* を mtime 新しい順に読んで 80/80。rank_sid.json は自分で作る（mkview.py が読む）
2. 25_対象 を切ったら、**統合先が範囲外の行（→ N位）を先に数える**（今回 4495→ZK の 4367位）
3. 並行組（ZK）の出力が未作成でも、キューのメーカー名・ブランドを主要語で突き合わせれば同社判定はできる（今回0件）

## 判定で足した型
- **公式が「Amazon でもご購入いただけます」と書くメーカー**（バイオ科学 熊一目散）＝いまのカートは販売店でも、在庫復帰後は本人カートになる可能性 → 要確認に置き秘書判断へ
- **味千汐路**：公式の問い合わせに「ECサイト（Amazon等）での販売を目的とした新規お取引はお受けしておりません」＝除外。**問い合わせページの注記まで読まないと見落とす**（会社概要だけでは出ない）
- 同名の別会社が多い：グリーンハウス（3社）・フューチャーゲート（千代田区IT／渋谷区広尾＝NOCOR）・グッドウィル（BTOパソコン）・二鶴堂（岡山の印刷会社）・ダイヤス（京都の漬物店）。**ドメインが当たっても商品で照合するまで決めない**
- サロン専売（CHRISTINA・FROM EARTH）は要確認：サロン専売で残す（第2弾の機械除外で落ちる型）
- 長谷川工業（資本金9,000万・294名・売上110億）は中小企業基本法では中小＝接触候補に置き、実態中堅と備考に書いた
