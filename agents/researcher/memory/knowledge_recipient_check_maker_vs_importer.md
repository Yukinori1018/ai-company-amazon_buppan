# 打診の宛先確認（製造元か・正規輸入元か）の手順と、JAN の頭で別会社を疑う型（T-20260930-001 / 2026-10-14）

用途：打診メールの宛先が「販売会社」「ブランドを出している会社」になっていて、製造元・正規輸入元に直すべきか聞かれたとき。

## 手順（今回こう処理した・2社で検索15回・連絡ゼロ）
1. **gBizINFO で両社の法人番号と登記住所を取る**（`deliverables/T-20260831-004/30_gbizinfo.py` の `GBizInfo._get(BASE+"?name=..")`）。製造会社の登記住所が販売会社の営業所と同番地なら同一グループの強い事実
2. **公式の「沿革」「会社概要」「FAQ」を読む**。「製造会社として◯◯設立」「従業員数（A、B合算）」の書き方が同一グループの根拠になる
3. **お問い合わせページのフォームを全部開いて題名を読む**（送信しない）。公式が卸の相談をフォームに振り分けていれば、info@ より卸フォームが正規の窓口。info@ が「個人情報の窓口」として載っているだけのことがある（グラント・イーワンズ）
4. **輸入品は商品表示の「製造販売元／輸入元」を探す**：楽天の商品ページ・Amazon 画像（`"large"` キーで画像URLを取る。`hiRes` が無いページがある）。表面しか写っていないことが多い
5. **JAN の頭（GS1 事業者コード）を、その会社の他商品と比べる**。楽天で社名検索 → 商品番号に入っている JAN の頭を集める。頭が違えば、JAN を登録したのは別会社（輸入元・企画会社）の可能性。GS1 の検索（Verified by GS1）は 403 で引けない＝回避しない

## 今回の結果
- プライムケイズ＝さかい企画の製造会社（沿革・同番地・従業員合算）。宛先は会社据え置き、手段は卸販売希望専用フォームが主
- HARITHOTH＝韓国のブランド元・日本の輸入元とも見つからない。グラント・イーワンズの他商品は JAN 4580444…、HARITHOTH は 458975639…（別の頭）。会員サイトに「実績計算」＝会員を通じて売る販売形態の疑い（推測）

## 型として残すこと
- **「自社サイトにブランドが載っている」は「輸入元である」の証拠にならない。**JAN の頭と商品表示で裏を取る
- **会員の実績計算・注文書シミュレーションがある会社は、Amazon 出品を認めない方針の可能性**がある。打診の前に論点として秘書に上げる（判定は秘書・タケシ）
- 検索の要約は小さい会社・海外ブランドの社名をほぼ返さない（今回 15回中、決め手はゼロ）。一次情報（法人番号・公式の沿革・フォーム題名・JAN）の方が速い
