## 再利用できる手順（検索待ちの片付けの型）
1. sid.json × sp_all.txt で現在のカート店の特商法を全行引き直す（ZI の教訓。今回は16行とも販売店）
2. guess.py を社名・ブランドのローマ字で回す（HIT が出たら auto.py で会社概要・問い合わせ）
3. **Web検索の前に楽天を引く**：`https://search.rakuten.co.jp/search/mall/<語>/` を pk.fetch → `item.rakuten.co.jp/<店>/` を数えて最多の店の商品ページを読む。「発売元、製造元、輸入元又は販売元」「輸入者」「◯◯は株式会社△△の商標登録です」が出る。店名がブランド名（「LINOR公式」「しょうねんスリーブのヒカリH.S.」）なら `rakuten.co.jp/<店>/info.html` の住所を Amazon カート店の特商法と突き合わせる＝本人カートの判定に直結
4. Web検索は「固有のブランド名＋会社」型だけ。一般名・JAN 単独・中国系の無名ブランドは当たらない（今回 JAN 検索は0件）
5. 型番が切れた Amazon 商品名（「EPM ス…」）は、公式に同シリーズがあっても `一致（ブランド単位）`。4値以外を書かない
