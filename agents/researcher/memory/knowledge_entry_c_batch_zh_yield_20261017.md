## 手順で足したこと（再利用）
1. **rank_sid は prodbb を優先して作る**：prod_wideC の stats.buyBoxSellerId は None。prod_wideC を先に読むと全行 None で埋まる（今回一度踏んだ）
2. **xdup の大手ヒットは「重複」に寄せ直す**：大手ブランドは既存台帳にほぼ必ずある。大手として書いた後に xdup で14件が既出と分かった＝ov.py の段階で大手ブランド名も照合語に入れると手戻りがない
3. **既存行が「別ASINの本人カート除外」の社**（Milim・Direct Tech）は、本行の代表ASINのカートが販売店なら接触候補のまま注記する（小川生薬の統合行も同じ型）
4. **備考に販売店の社名を書かない**：build.py の伏せ字はキューのカート保持セラー列の文字列だけ。特商法から引いた社名を備考に書くと公開版に漏れる→「東京の販売店」等の地域名に置換した
5. 推定ドメインは「看板商品名・別ブランド名」が当たる（ZF と同じ）：golflite.co.jp（ライト）・kanzenshoku-tokyo.com→milim.co.jp（JAKS）・stisanyo.com（三洋食品の現社名）

## 判定で足した型
- **国内輸入元が公式で取扱終了を告知**（シーエフシージャパンの A&W）＝除外（仕入れ元が無い）
- **公式に「新規取引は承っておりません」**（石屋製菓）＝除外。「回答できない場合もある」（エンスカイ）は接触候補に置いて注記
- **カラーコンタクト**＝高度管理医療機器（販売許可が必要）で除外。コンドーム（管理医療機器）は届出で足りる（推測）ので落とさず注記
- **海外ブランドの国内代理店が複数社**（TePe：3社）＝キューのメーカー欄と一致する1社を打診先に置き、3社ある旨を備考に
- 公式の問い合わせ受付が「一時停止中」（マグレイン）＝要確認（窓口が実質ない）
