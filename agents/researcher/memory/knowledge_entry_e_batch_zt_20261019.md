## 🔴 気づき（次回の手順に入れる）
- **楽天を先に引くと Web検索がいらない行が多い**（ZP 検索待ちの片付けで見つけた型を本番の採取に前倒しした）。道具は batchZT/ に3本：
  - `rk.py "語"`＝search.rakuten.co.jp の結果から店を数えて上位の商品 URL
  - `ri.py URL…`＝商品ページの「発売元／製造者／販売者／輸入者／メーカー」の前後を抜く
  - `rinfo.py 店ID…`＝`rakuten.co.jp/<店>/info.html` の会社概要（会社名・住所・TEL・FAX）
  - 当たった型：「製造者 株式会社◯◯ 住所 TEL」（ハニー・マルタケ・仙葉）、メーカーの直営店（フソー化成・ナカムラマッチ・エーワン・サンフレッシュ・まぐろ処一条・函館吉兆堂・KIS）
- **楽天の直営店しか無いメーカーは、直営店の会社概要を窓口にして接触候補にできる**（ZP 松岡製菓・ZQ 渡辺教具と同じ扱い）。紐付けは直営店の同じ商品ページで「一致」
- **キューのメーカー名は Keepa の manufacturer 欄。ブランドの本当の持ち主と食い違う**：PLOTTER（表記ノックスカンパニー→持ち主デザインフィル）、東京カラメリゼ（→上野風月堂）、パンチレモンシロップ（→ポッカサッポロ）。商品名で楽天を1回引けば分かる
- **Amazon のブランド欄＝楽天の店名なら、その運営会社の住所をカート保持店の特商法と突き合わせる**→本人カートが確定（5189 日本海珍味店さとも屋＝アマールトレードグループ）
- **「大手判定を保留」の4行は4行とも本当にその大手だった**（ZR の 5035・5036 のような誤分類は無し）。それでも商品名で公式を1回見る手順は残す（30秒）
- 公式に「小売店と直接取引しない」「通販店お断り」「Amazon の取扱いの問い合わせ不可」と書くメーカーは、中小でも除外。**`scan.py` は楽天ドメインの行でノイズしか出ない**（楽天全体を拾う）ので、直営店の行は info.html だけ目で見る
