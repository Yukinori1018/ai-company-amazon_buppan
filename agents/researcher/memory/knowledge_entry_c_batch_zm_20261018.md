## 手順（ZJ からの差分だけ）
1. 範囲を切り出したら、まず queue の `規模`・`上場` と Keepa raw の brand/manufacturer/title を1画面に並べ、**ov.py で既存台帳と照合してから**推定ドメインに進む。キュー末尾は大手ブランドの再登場が多く、80行中18行が重複で即決できた
2. 推定ドメインは2〜3周。1周目で外れた社は**社名の短縮形（open-k・naganekinoko・totsukawa-farm）**を足すと当たる
3. **紐付けの判定欄に「一致（まとめ売り）」を入れかけた**。4値（一致／表記ゆれ／ブランド単位／未確認）以外は sync で落ちる＝組み上げ後に一覧で目視（memory feedback_link_vocab_four_values_only の通り）
4. **sync_ledger.py の流通形態の機械分類（DIST_RULES）に当たる語を、接触候補の注記に書かない**。「代理店の可能性」「販売代理店募集」と書くと代理店制（段2）に落ちる。逆に「お取引きはしておりません」の引用でも『お取引』で直販に分類される（アクア工房）＝機械分類は語で決まるので、引用した行は秘書判断に上げる

## 判定で足した型
- **「通販のみでの新規取引は受け付けておりません」（サクラカネヨ）＝ネット販売店お断りの明記→除外**。公式の「企業・新規お取引」フォームの手前に案内ページがある型。フォームだけ見て接触候補にしない
- **「商品はすべて美容室専売品」（アルバコスメティックス）＝流通制限の明記→除外**
- **「販売店様との直接のお取引きはしておりません。取引先卸業者をご案内」（アクア工房）**＝直取引不可だが卸の紹介はある→接触候補に置き秘書判断（中村本の「紹介先の卸問屋で続ける」型）
- **法人専用の仕入れサイト（菊正宗Web仕入・新規会員登録）**＝窓口として強い。推定ドメインの .net 側で見つかった
- 正規販売店制度＋「正規店以外は保証外」（TKS）＝注意喚起なので落とさない（メイスイと同型）
- 店名＝ブランド欄で商品は他社製（CENFILL＝カシオ純正電池、スペシャルギフト＝AdBlue）＝販売店ブランド→除外。公開版では店名を伏せる（build.py の RETAIL）
- 公式が Amazon のメーカー欄と別名（フクバデンタル→アイオニック、パナックス→エイアイ企画）＝公式の商品・CONTACT 導線で結べれば接触候補（表記ゆれ／ブランド単位）

## Web検索の歩留まり（N=34）
- 当たった型：ブランド固有語＋「販売元」（LOCABO→forty-four・バスセンターのカレー→新潟交通商事・KISS YOU→アイオニック）／規模の裏取り（菊正宗・榮太樓・粧美堂は求人・有報集計で即答）
- 外れた型：gBiz で所在地まで分かる中小（津村鋼業・宇都宮製作・アドミラル産業・美訓物産）は2回検索しても公式に届かない＝**電話・FAX 打診の候補として引き継ぐ方が早い**
- 規模の裏取りに検索を使うのは有効（1回で確定）。公式に記載が無い社の「中小か」はこれで埋める
