# 商品単位の紐付け確認と、要確認の長い尾の片付け方（T-20260930-001 / 2026-10-14 夜間）

用途：「接触候補が紐付け未確認で第1弾に入らない」「要確認がN行残っている」と言われたら読む。手順の正は [[knowledge_brand_field_vs_maker_linkage]]・[[knowledge_link_check_vocabulary_and_recheck_20261011]]、語彙のルールは [[feedback_link_vocab_four_values_only]]。

## 1. 「会社がそのブランドを持つ」と「代表ASINがその会社の品」は別（Z1〜Z6 の10社で実測）
- 採取時の紐付け欄は10社とも「確認済み：会社概要にブランド名」＝会社とブランドの紐付けだけだった。商品単位（品名・型番・容量・JAN）で照らし直したら 一致5／一致（ブランド単位）3／一致（表記ゆれ）1／**未確認1**
- **Fujikon（UDAP 熊撃退スプレー）**：同社が正規輸入するのは 225g（7.9oz）。代表ASINは 9.2oz で、Keepa の listedSince=2025-05-31＝同社の輸入開始（2026-05・PR TIMES）より約1年早い。**ブランドが合っていても、代表ASINの輸入元は別**（推測・確度中〜高）。検索の要約は「9.2oz の輸入元は Fujikon」と書いたが、一次（同社通販の容量表記）で否定できた
- **イース・コーポレーション（レアルシルト）**：代表ASINの JAN 事業者コードが、カート保持の販売店自身のブランド品と同じ＝**販売店が切り分け・詰め直して自社 JAN を付けた品**の可能性が高い。メーカーから同じ形では仕入れられない
- 型：**容量・サイズが公式の現行ラインナップに無い**（トレンツ ソープD 1L・ペプチドリップ 500g・イース ハーフサイズ）は「一致（ブランド単位）」に倒し、理由に「公式は◯◯のみ」と書く。業務用か旧規格か販売店の組成かは別の論点
- 打診に効く事実も同時に拾える：いずも八山椒の自社通販に「再販売目的の注文はお断り」／トレンツは「認定外のECの品は保証しない」／東京ハンガーは製品ページから自社 Amazon 店へリンク

## 2. 要確認の長い尾（RC2 の残り171行）— 手段別の歩留まり
| 手段 | 投入 | 結果 |
|---|---|---|
| **Keepa raw の JAN 事業者コード兄弟**（0 token・0検索） | 171行に一括 | 重複8・除外5を確定、社名の手がかり6件。兄弟 ASIN の `manufacturer` に会社名が出る |
| **推定ドメイン guess.py**（0検索） | 約70社×4〜8通り | **接触候補5社のうち4社**（米澤製油・アステリア・長息生活ブランドサイト・STI-IR） |
| **Web検索** | 43回 | 接触候補への寄与1社（堀河屋野村：PR TIMES の会社 URL 欄から公式）。残り42回は公式URLが出ず。最後の12回は歩留まり0 |
| gBizINFO（gz.py） | 約25社 | 所在地の照合（公式の住所と一致＝同一法人）に効く。公式URLは出ない |

- **Web検索の要約は小さいメーカーの公式URLをほぼ返さない**（販売店・比較記事・ふるさと納税が並ぶ）。長い尾では「guess → JAN兄弟 → gBiz → 検索」の順にし、検索は最後
- **PR TIMES の会社概要欄に URL がある**ことがある（堀河屋野村：本文に無くても右の会社情報に URL）
- ブランドサイトの会社概要に「発売元」と「総代理店」が並ぶ型（長息生活：発売元ルピナス／総代理店アシストが小売店向けスターターセット）＝窓口を2つ書く
- 推定ドメインの落とし穴：同名の別業種（ルピナス・デザイン、STI の同名でない会社、竹内農園＝岡山の米）。**タイトルだけで HIT にせず、本文で商品名を見る**
- BSD sed で日本語を含むファイルを置換すると壊れることがある／Python 3.9 は非常に長い日本語の行で「Non-UTF-8 code」と誤って止まる → 先頭に `# -*- coding: utf-8 -*-` を付ければ通る
