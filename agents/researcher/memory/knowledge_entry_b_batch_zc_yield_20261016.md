## 手順（再利用）
1. batchZB の道具を `batch<記号>/` にコピーし、mk_keepa.py と build.py のファイル名・範囲だけ差し替える。sp3.py（キャッシュ済みなら待たない・販売業者の行が無くても止めない）と sg.py は batchZA から
2. **他バッチの html キャッシュを先に流用する**（URL の md5 が同じ）。今回は特商法90件のうち8件
3. 特商法は45件ずつ2回に分けて取ると Bash の10分制限に収まる（間隔5秒・各約5分）
4. **jan.py（新設）**：Keepa raw の eanList を前方一致で走査する索引（jidx.json・初回1回だけ作る・0 token）。事業者コードの兄弟でカート保持店＝輸入元本人を確定できる（INCOCO＝FW1 と同じ 4537167＝ニューポート）
5. 大手のブランド（花王・ハウス・小林製薬・ジョンソン）は ov.py で**既存台帳の大手行に重複で寄せる**。新しい大手行を作らない
6. 組み上げ → xdup.py（並行組のファイルも読む）→ leak.py ＋ 特商法の全販売業者名で公開版を照合 → 67_／64_ を作る

## 判定で足した型
- **公式に「現在、メーカー直接での新規業者様とのお取引は中断。問屋へ」**（ハシモト＝カタヌキ菓子）＝除外。窓口は備考に残す
- **公式が自社で Amazon に出店していると明記・WEB SHOP 限定販売**（お掃除ソムリエ＝iPS）＝要確認（窓口は採る）。Z9 の「公式が Amazon へ誘導」と同じ扱い
- **公式に商品が載っていないが報道が販売元とする**（HUNTER ENERGY＝Future Technology）、かつカート保持店が「公式販売店」を名乗る＝要確認（正規代理店本人の可能性）
- **キューのメーカー欄・ブランド欄が販売店名で、製品は大手の純正部品**（シチズンのキャパシター）＝大手1行。公開版では build.py の RETAIL で販売店名を伏せる
- **公式サイトの表示が外国大手グループに変わっている**（フジタ製薬→Virbac）＝大手グループは大手1行
- 推定ドメインの同名別会社：yamadaseika.co.jp（東大阪の米菓）≠かりんとうの山田製菓（安城）、phoenix-co.jp（大阪のアパレル輸入）≠馬油のフェニックス、spice-inc.co.jp（赤坂の SPICE GROUP）≠雑貨の SPICE OF LIFE（未確定）、chinsuko.co.jp（新垣ちんすこう本舗）≠有限会社新垣菓子店（chinsuko.com）。**同名・同業の別会社はgBizの所在地と公式の本社で突き合わせて決める**

## 失敗しかけたこと
- チケットの「現在地」へのイシュー追記を Edit で試みて不一致で失敗し、作業後まで気づかなかった。**Edit が失敗したら、その場で Python で差し込み直す**（着手時のイシュー宣言が完了時の追記になった）
- 除外の内訳を手で数えて「確度高17」と書きかけた。CSV から数えると16（同番地の1行を含む）。**内訳は CSV から機械で数えてから書く**（Z9 の失敗の再発防止が効いた）
