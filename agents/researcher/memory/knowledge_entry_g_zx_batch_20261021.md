## 失敗とリカバリ
- **ov.py に社名を投げ漏らした**（Keepa のブランド名だけ投げ、公式で分かった運営会社名＝長寿乃里・インターコスメ・リベルタ等を投げなかった）。xdup.py で9件が後から既存台帳と同社と分かった。→ **公式で正式社名が分かった時点で ov.py を回し直す**。xdup は build 後の最後の網として必ず回す（feedback_cross_batch_dedup_after_build と同じ型の2回目）
- recs.py で判定を後から変えるときは、元の呼び出しを消さずに末尾で `del R[k]` → 再定義した（置き換えの理由が残る）

## 判定の型（今回足したもの）
- 公式の問い合わせページに「Amazonへの出品は全てお断り」→ **除外**（§3.3-12 の名指し不可）。ツーウェイワールド
- 公式に「公式オンラインストアのみで販売（外のサイトでは販売しない）」→ **後回し**（Amazon の名指しはない）。宇部煎餅店
- 一般購入品の「転売禁止」の記載だけ → 接触候補のまま、卸・取引の案内欄に記載（DREXEL・おちゃのこさいさい）
- 公式サイトが無く PR TIMES の自社リリースだけ → 要確認（リリースの個人の窓口は転記しない）
- Keepa のメーカー欄が OEM 工場（中日本カプセル・コスメクリエイトプロダクツ）の行は、ブランドサイトの特商法の販売業者を打診先にする
