## 手順（ZK/ZL からの差分だけ）
1. sid は `raw/prodbb_*` と `raw/prod_wideD_*`（入口(d)）を mtime 新しい順に読んで 100/100
2. 道具は batchZL をコピーし、build.py と scan.py だけ batchZK 版（特商法の販売業者名を伏せる SPN 処理入り）に差し替えた

5. **https が 403 でも http で開くサイトがある**（都一・ジャンプ・ショーワ）。403 で「公式未特定」にしない

## 判定で足した型
- **scan.py の誤検知**：カネヨ石鹸（kaneyo.com）で sakurakaneyo.com のお断りが当たった。scan.py はホスト名の endswith で照合するので、**短いドメインは別会社のキャッシュを拾う**。当たったら URL のホストを必ず見る
