# Amazonセット商品×JAN×ブランド名の整理（2026-10-20 / 社長の事実確認・チケットIDなし）

## 結論の骨子（再利用用）
1. セット＝販売単位が違う商品 → 単品JAN流用不可、セット用の別GTINが要る（GS1基準の二次情報で一致）。
2. 「同じメーカーに合わせる」の正体＝AmazonがJANの事業者(GS1登録者)と入力ブランド名を照合する仕組み。不一致で 8572（GS1事業者情報との矛盾・公式スタッフ回答）、5461（そのブランドのASIN作成制限）、5665（出品実績のないブランド名）。
3. 他社品セットを自社JANで出すと「JAN事業者=自社 / ブランド=他社」で矛盾。正規ルートは (a)メーカー公式セットJANに相乗り (b)ブランド=自社orノーブランド品で異なる商品を組む（同一商品まとめ売りはノーブランド不可とされる） (c)メーカーLOA。
4. 米国は2024-10頃から「元メーカー梱包 or LOA・単一ブランド」に厳格化（ギフトバスケット例外）。JPに同じ改定があったかは未確認。

## 調査上の学び
- **このクラウド環境は WebFetch も curl も外部ブロック**（ENOTFOUND / proxy CONNECT 403）。WebSearch しか通らない。一次情報（セラセンヘルプ・gs1jp.org）は取れない前提で、確度を一段下げて報告する。
- セラセンJPヘルプはそもそもログイン必須（knowledge_amazon_official_primary_sources.md）。セット品規約はヘルプID 201645990 とされる → 社長ログインで原文確認が確実。
- 英語圏情報（バンドル規約・GS1照合）は豊富だがJP適用は別問題。必ず「米国の話」とラベルを付ける。
