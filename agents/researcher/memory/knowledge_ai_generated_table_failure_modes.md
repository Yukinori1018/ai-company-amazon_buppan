# AI生成比較表の壊れ方 — 実測サンプル（Genspark製 FBA納品代行比較表 vs 公式9社）

- **記録日**: 2026-08-21 / T-20260821-010
- **記録者**: サトル（リサーチャー）
- **種類**: 失敗パターンの分類（今後のAI生成資料の扱いに直結）

## 何をやったか

社長が2026-08-09に共有した Genspark AI Sheets 製「FBA納品代行業者 比較表」（9社）を、**各社公式サイトの料金ページで1社ずつ突合**した。母集団9社・検証項目は初期費用/月額/単価/最低ロット/対応不可品目/所在地/納期。

## 結果：問題18件の内訳

| 分類 | 件数 | 代表例 |
|---|---|---|
| **相違**（公式と食い違う） | 9 | タイシン「初期費なし」→ 実際は**保証金5万円**／糸星「月額なし」→ **パレット3,000円/月が荷受に必須**／FBA代行センター「ラベル貼り100円」→ 実際は**検品・出品登録込みの基本料金100円**（項目名ごと誤り） |
| **出典が一次情報でない** | 2 | ユニストック→`imitsu.jp`（一括見積アグリゲータ）／FBA代行センター→`fujilogi.net`（**別会社のブログ記事**） |
| **裏取り不能**（公式に該当記述なし） | 2 | びーぷらす「月間2万点以上の実績」／ユニストック「大規模運用向き」 |
| **重大な記載漏れ** | 5 | びーぷらすの**物価対応調整金5%**／タイシンの**最低ロット目安**／FBA代行センターの**小口契約不可**／糸星の段ボール有料・補填制限／ほっこりーなの公式専門サイトの存在 |

**一致していた項目も多数ある**（びーぷらす・おりおんは料金項目がほぼ全一致）。「AI生成＝全部嘘」ではなく、**壊れ方に偏りがある**のが要点。

## 壊れ方の法則（再現性あり）

1. **公式サイトのトップに大書きされた数字は正しく取れる。**「1点31.5円〜」「10円/個」など。SEO的に目立つ数字は拾える。
2. **利用規約・注意事項・FAQに埋まった条件は落ちる。**保証金5万円、最低ロット、小口契約不可、5%調整金——**判断をひっくり返す情報ほど、目立たない場所にある**。
3. **「要見積」「要確認」は"調べていない"のサイン。**ユニストックもFBA代行センターも公式に料金表があった。AIが到達できなかった（＝アグリゲータ止まり）だけ。
4. **URLが第三者サイトのとき、その行の中身は信用できない。**出典URLのドメインが業者本体でなければ、その行は全部再取得が必要。
5. **項目名のすり替えが起きる。**「基本料金100円/点（検品・登録・ラベル込み）」を「ラベル貼り100円」と書く。**単価は数字より"何が含まれるか"を先に確認する。**
6. **サマリ行での過度な一般化。**「就労支援系は月額固定費ほぼ無料」→ 4社中1社は月3,000円必須、1社は保証金5万円。**カテゴリ単位の断定は必ず例外を潰してから書く。**

## 運用ルール（今後こうする）

- AI生成の比較表を受け取ったら、**まず出典URLのドメインを全行チェック**する。業者本体でない行は「未調査」として扱う（一致/相違の判定すらしない）。
- 裏取りは**料金ページだけ見ない**。「利用規約」「注意事項」「よくある質問」を必ず開く。**保証金・最低ロット・契約種別・免責はここにしかない。**
- 単価を写すときは **必ず「この金額に何が含まれるか」を1行で併記**する。含まれる範囲が違う数字を同じ列に並べない（memory `knowledge_compare-tables-need-substitute-vs-complement` と同根）。
- カテゴリのサマリ行（「◯◯系は△△」）は、**構成メンバー全社を確認してからでないと書かない**。
- 「要見積」「要確認」と書く前に、公式サイトを自分で開いたか自問する。開いていないなら「未調査」と書く。**この2つを混同すると、次の人が"調べても無駄"と誤解する。**
