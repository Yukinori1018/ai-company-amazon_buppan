## 入口(c) 固有の事実（ZF/ZG との違い）
1. **キューの「カート保持セラー」（9/30値）と Keepa の現在 buyBoxSellerId は別物になっている行が多い**。sid は product raw の `stats.buyBoxSellerId`（無ければ `buyBoxSellerIdHistory` の末尾）から作り、特商法はその現在値で取った。判定の根拠は「2026-10-17 の現在値の店」と書く
2. 層3 のカートは大半が販売店（自己発送の小売）＝層3 の歩留まりは入口(b) より高いはず、と思ったが、**公式に届かない社が多く接触候補は 25/154（16%）**。要確認が 49 と最大
3. 層5 でも資本金で中小に戻る社がある：鎌倉紅谷（316人・資本金1,000万円）・三立製菓（480人・2億500万円）。**中小企業基本法の製造業は「資本金3億円以下 OR 従業員300人以下」**。キューの「大手（従業員◯人）」だけで落とさない
4. 層4 の「【公式】◯◯」という店名でも、特商法が個人で複数ブランドを扱う（N organic＝シロク品も同店）なら**ブランド公式ではなく販売店**。本人カート扱いにしない

## 手順で足したこと（再利用）
1. **ov.py はキューのメーカー名だけでなく、調べて確定した正式社名で組み上げ後にもう一度 xdup を回す**。今回 xdup で後から重複が11件出た（クリロン化成＝A33・松栄堂＝M1212・丸島醤油＝I890・イースター＝C201・オーパデザイン＝ZH4007 ほか）。キューの表記（BOS・北海道・マルシマ醤油）では既存台帳に当たらない
2. 公式で JS の SPA（moradia.jp・my-o2.jp）は curl で中身が取れない＝「会社情報を取得できない」要確認で止める。**frameset/リダイレクトの `URL=` を grep すると本体が見つかる**（purasesu.co.jp → purasesu-inc.com）
3. shoyeido.co.jp は裸ドメインが 403、`www.` 付きで 200。**403 を見たら www 付きと UA 付きで1回ずつ試す**
4. 公開版の漏れ検査に「特商法の販売業者名 × 公開版」の逆照合を足した（leak.py は 9/30 のキュー値しか見ない）。今回、輸入元候補として備考に書いた販売店名（4120）が1件引っかかった→非公開メモへ移した

## 追記：検索待ち23行の片付け（2026-10-17 夜・無人・24_連絡先_recheck_20261017c.csv）
- 結果（N=23）：接触候補6／要確認12（公式未特定11・国内輸入元1）／大手2／除外2／重複1。Web検索37回（1社2回まで・枠60）＝実効の到達は 9/23（39%）
- 🔴 **定型文の備考を信じない**：ZI で検索待ちにした行は備考が一律「カート保持店は別会社＝本人カートではない」だった。片付けの最初に **sid.json（ASIN→現在のカート sid）× sp_all.txt（特商法）を全行引き直す**こと。今回それで MERIN（KURUKURU.inc＝公式本社と同住所）と Polanite（店名＝ブランド名）の本人カートが出た
- 当たる検索語の型：「株式会社◯◯ ＋固有の商品名」→ 楽天の直営店・通販の「加工者／販売者」表記・プレスリリースが出る。届いたら **推定ドメイン（社名ローマ字.co.jp）を curl で即確認**（東邦 toholtd.com・ナルビー nalbie.co.jp・マテラ materra.jp は検索結果のURL無しでも当たった）
- 外れ方の型：商品名が一般名（カフェイン200・ボディブラシ・高麗人参茶）／社名が一般語（フロンティア・リアライズ）＝2回目でもほぼ当たらない。**2回目は「ブランド固有語」がある社だけに打つ**と枠が浮く
- 判定で足した型：①公式が「Amazon の転売が多いので公式店を出した」＝牛乳石鹸と同じ「転売お断り」扱いで除外（For-S）②商品名に「純正品」＋他社の型番＝ブランド欄は出品者のラベル。製造元で判定（タカラスタンダード＝大手）③公式「エンドユーザーへの卸売りはしない・代理店か小売店で」＝接触候補に置き、流通形態の後回し候補と明記（ナルビー）④独自ドメインが無く楽天直営店の会社概要だけ＝出典を明記して接触候補（ソーキ・upink と同じ）
- 確定社名で既存台帳と照合すると2件当たった（KURUKURU＝Z5・セロトーレ＝I897）。**既存行が「要確認」で今回が「接触候補」なら、今回の行を残して寄せ方を秘書に上げる**（逆に寄せると打診先が消える）
- 手順メモ：python3.9 で日本語のキーワード引数（`卸・取引の案内=`）は「・」が識別子にならず SyntaxError（エラー文は Non-UTF-8 と誤解を招く）。dict は文字列キーで書く
