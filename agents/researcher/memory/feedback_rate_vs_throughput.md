# 率で比べると必ず誤る — 分母と工数を揃えてから並べる（2026-09-21）

T-20260920-005 S-5。タケシの計画に「展示会は成約率10%以上↑なので最優先」とあった。

## 起きたこと

- 展示会の買い手側成約率は**実測45%**（ギフトショー報告書・2回一致・N=2,320）。10%どころではない。
- ところが**分母が違った**。45% の分母は「会場でした商談」、2% の分母は「送ったメール」。
- 工数あたりに直すと **展示会0.14社/h vs メール0.48社/h で逆転**した。展示会は率が3倍でも年6.8社しか取れない。

## ルール

1. 率を表に並べる前に、**分母を1列足す**。分母が違う率は同じ表に入れない。
2. 率の隣に必ず **「1年で何社」「社長の投下時間」「1時間あたり」** を置く。社長の制約は週20時間で、率ではなくスループットで縛られている。
3. 「率が高い経路」を推す前に、**その経路の上限スループット**を出す。上限が目標を下回るなら、率がいくら高くても主線にならない。
4. タケシが置いた `↑` `↓` の定性記号は、**裏を取ると符号は合っていても桁が違う**ことがある。定性記号は必ず数字に置き換えてから返す。

## 副産物

「率が高いが遅い経路」と「率が低いが速い経路」が見えたら、**第3の型（打診の向きが逆の経路）**を探すと当たることがある。今回はザ・商談モール（1案件で平均5.1提案が向こうから来る）が出た。
