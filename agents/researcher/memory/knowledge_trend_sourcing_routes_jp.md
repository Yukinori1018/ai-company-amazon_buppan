初出：T-20260906-006 Phase 1
用途：「SNSやトレンドから売れる商品を先回りして探す」と聞かれたら、まずこれを読む。

## 1. この分野の一番大事な構造（これを外すと全部やり直し）

**速さと独占は両立しない。**

| | 兆し検知時点で商品はどこにあるか | リードタイム | 独占の余地 |
|---|---|---|---|
| SNSでバズった商品 | 既に国内小売に流通済み | **5〜12日** | **ほぼゼロ** |
| クラファン・展示会・地域産品 | まだ一般販売前 | **30〜180日** | **最大** |

**「短リードタイム × 独占あり」の象限は空。** 社長の2つのアイデア（①地元で有名→独占 ②SNSバズ→先行逃げ切り）は
同じ探索ではなく**正反対の設計**を要求する。1本のスキームに混ぜると両方壊れる。

## 2. リードタイムの律速は「検知」ではなく「t3＝取引口座の開設」

```
T = t1検知 + t2商品特定 + t3仕入れ経路の確保 + t4発注→着荷 + t5検品ラベル + t6FBA発送→受領
```
- 小売買付 5〜12日 ／ 既存卸 6〜15日 ／ **メーカー直（新規）19〜53日（うち t3 が 7〜30日）** ／ クラファン 95〜188日
- **t6（FBA受領反映3〜5日）は誰にも縮められない。** 全経路共通のコスト。
- **兆しの検知精度をいくら上げても、t3 が30日なら先行逃げ切りは成立しない。**
  → **仕入れ先との関係づくりは、アカウント停止中の今こそ先に済ませる作業。**

## 4. 適法性の現在地（2026-08-31 ハルオ判定の射程を誤読しないこと）

- **NO なのは「API 経由の機械的収集・保存」**（YouTube Data API / X / TikTok Research / Instagram）。
- **人が見る／公開ランキング／RSS／検索経由は未判定。** ここを「全部NO」と早合点すると経路が9割消える。
- **RSS は Data API ではない**（例：`https://www.youtube.com/feeds/videos.xml?channel_id=<ID>`）。ただし当職の見立てであり判定はハルオ。
- Amazon の公開ランキングは**規約でスクレイピング禁止**。人が見る運用に限定。

## 5. 「まず実測すべき3本」の選び方（この基準は再利用できる）
