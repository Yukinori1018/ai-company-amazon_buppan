## 判定で足した型
- カート保持店の特商法の住所が、キューの gBiz 照合先と同じ部屋番号（シィホース⇔富士丸商事：千代田区一番町20-3 プレミエール一番町1301号）＝関連会社のカート → 本人カート（確度高）
- カート保持店の運営責任者名に製造元の社名（「トキハ産業(株)nakagawa」）→ 本人カート（確度高）
- 公式に「正規販売店以外の保証はしない・転売に注意」（神楽坂発酵美人堂）＝注意喚起で転売禁止ではない → 接触候補（メイスイ型）
- 「当店商品の営利目的（転売や景品など）での使用はご遠慮ください」（伊藤久右衛門）＝転売お断り → 除外（わかさ生活型）
- 海外ブランドでも日本法人・国内総代理店が公式で確認できれば接触候補（ミューレ・ジャパン。前例：ZH 3993 TePe／クロスフィールド）。輸入元が分からないときだけ「要確認：国内輸入元未特定」
- 楽天の自社店の会社概要しかない社（ヤマリュウ・三明物産）は、製造元か販売元か分からないので要確認に置いた（並行 ZP は松岡製菓を楽天の【公式】店で接触候補にしている＝秘書判断）

## Web検索の歩留まり（N=29）
- 当たった型：海外ブランド＋「輸入元」（SOLSTICKAN）／商品名＋「製造販売元」で大手が出る（DENT.MAXIMA・米唐番）
- 外れた型：EC 店の自社ブランドらしきもの（Venry・くらしVenus・おててがあど・NEIGHBOR CLOWN・Topwell）／一般名＋小さな食品会社（丸金食品・リアライズプランニング）／海外の調味料（友加）。これらは検索前に「カート保持店＝運営元か」を特商法で先に疑う方が安い
