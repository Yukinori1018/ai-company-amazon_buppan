# 社長の「本丸」＝ネット販売に疎い中小メーカー（2026-08-31 明言）

## 社長の言葉（原文）

> 本丸はネット販売に疎い、中小メーカーから仕入れて、利益率高く売る。**独占販売に繋げること**です。
> しかし、今は実績が全くないので、少しでも利益が出るように**数を打ちたい**という思いがあります。それを忘れないでください。
> ネットでの仕入れ先以外に仕入れ先がないか調査して下さいね。それが**SNS（XやYoutubeなど）も考えて**といった趣旨です。

## これが意味すること（設計の根っこ。忘れると全部やり直しになる）

**「ネット販売に疎い」＝ 定義上そのメーカーは Amazon に出品していない。**

| 探索の起点 | 母集団の定義 | 本丸が入るか |
|---|---|---|
| Keepa / Amazon 商品ページ | Amazon で売れている商品を作っている会社 | **入らない（定義上0%）** |
| NETSEA / スーパーデリバリー / orosy | 既にネット卸に載せている会社 | **入らない**（載せている＝疎くない） |
| 展示会・産地組合・直売所・SNS発信者 | 製造している会社（ECの有無を問わない） | **入る** |

**T-20260831-004 で候補2,614件の本命が16%しかなかったのは、精度ではなく母集団の定義の問題だった。**

## 二段構え（成果物には必ずラベルを付ける）

| 段階 | 目的 | 経路 | 利益率 |
|---|---|---|---|
| **今** | 実績づくり・数を打つ | 卸プラットフォーム（NETSEA/orosy/SD等） | **5%でも可** |
| **本丸** | 高利益率・**独占販売** | ネット外（展示会・産地組合・SNS・EC無しメーカー） | 高利益率 |

**混ぜると社長が判断できない。経路ごとに「どちらの段階か」を明記すること。**

## 独占販売という出口（評価軸に必ず入れる）

- 既に Amazon で売れているメーカーは**独占を渡さない**
- 自社で売る気がない／売り方が分からないメーカーほど**独占を渡す可能性がある**
- **orosy は仕入元が開示されない設計（規約第5条）＝独占交渉の相手に到達できない。本丸には使えない**

## 実測した中核数字（2026-08-31・T-20260831-005 Phase B）

展示会出展社（国内表記）を無作為抽出し Keepa Product Search で照合：

| 指標 | N=66 時点 | Phase A（N=18） |
|---|---|---|
| Amazon に自社ブランド商品あり（strict一致） | **33.3%** | 33.3% |
| **Amazon にいない側** | **66.7%** | 66.7% |
| **社名で1件もヒットしない** | **45.5%** | — |

**再現している。** ただし注意：
- **66.7% は「不在率の上限」。** 社名≠ブランド名の会社が全部「不在」に落ちる（実測中に `トヨタ自動車（株）` が strict NO と判定された）
- **確実な下限は「1件もヒットしない 45.5%」**
- **「競合ゼロ」と「需要ゼロ」は同じ数字で観測される。** 切り分けは商品のJANを取ってから Keepa を引く以外にない

## 今日から0円・社長の手0回で動く本丸リストは2本

1. **展示会出展社 2,353社を「Amazon不在」で切った側**（既存データ＋Keepa 10トークン/件）
2. **経済産業大臣指定 伝統的工芸品 244品目の産地組合**（`kougeihin.jp` の `/craft/` 275ページに**組合名・住所・TEL・FAX**が構造化掲載。robots.txt は `/craft/` を許可）

## SNS で機械的に探せるのは実質 YouTube だけ

| SNS | 可否 | 根拠（2026-08-31 公式） |
|---|---|---|
| YouTube | **可**（唯一の実用解） | `search.list` は**1日100回**の独立クォータ・1unit/回。他EPは10,000units/日（docs 最終更新 2026-06-01） |
| X | 有料 | **pay-per-use pricing**（docs.x.com）。単価ページのURLは特定できず |
| TikTok | **申請承認制** | 「Once your application is approved」。利用資格の要件は記載なし |
| Instagram | **未確認** | ハッシュタグ検索の公式ドキュメントが 404/400 |

**社長の指示：「フォロワーは少なくてもいい。むしろ少ない方が本丸に近い」** → 登録者数の**少ない順**に並べること。多い順ではない。
