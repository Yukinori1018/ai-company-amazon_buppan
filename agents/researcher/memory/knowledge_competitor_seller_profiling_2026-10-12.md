# 競合セラーの「売り方」を事実で分ける手順（2026-10-12 / T-20261012-001 06）

## 依頼パターン
当社の試算で赤字の棚に第三者が何社も出品している → 社長「他のセラーはどうしているのか調査したか？」。
**答えるべきは「彼らの仕入れ値」ではない（外からは分かりようがない）。「どの価格なら・どの買い方なら黒字か」を逆算し、見える事実（業態・在籍期間・カート獲得率）と照合して、経路を消していく。**

## 手順（再利用できる形）
1. Keepa の保存データがあれば再利用（`offers` に過去の全出品者・`buyBoxStats` に1年のカート獲得率と平均価格・`liveOffersOrder` がいまの出品者の添字）。兄弟は `offers=20,buybox=1,history=1` で4 ASIN＝29トークン
2. 出品者プロフィール `https://www.amazon.co.jp/sp?seller=<ID>` は curl＋普通のUAで読める（340KB前後）。「特定商取引法に基づく表記」から 販売業者／住所（都道府県）／古物商許可証番号、`(\d+)％が肯定的 \(評価：N\)` で12か月の評価数
3. ストア `https://www.amazon.co.jp/s?me=<ID>&marketplaceID=A1VC38T7YXB528` の `<h2 aria-label="...">` が1ページ16件の商品名、`"totalResultCount":N` が出品数。**連続で叩くと1.4KBの空ページが返る**（4件連続で出た）。60秒置いて20秒間隔で取り直したら全部取れた
4. 出品一覧は `https://www.amazon.co.jp/gp/product/ajax/aodAjaxMain/?asin=<ASIN>&pc=dp&experienceId=aodAjaxMain&filters=%257B%2522all%2522%253Atrue%252C%2522new%2522%253Atrue%257D`。`id="aod-pinned-offer"` がカートの持ち主（「出荷元」「販売元」の次の行）、`id="aod-offer"` が他の出品
5. 小売の最安：Yahoo! は `shopping.yahoo.co.jp/search?p=<JAN>` の `__NEXT_DATA__` に price・point.totalPointRate・store。楽天は**型番では0件、JANで18件**（`search.rakuten.co.jp/search/mall/<JAN>/`）。フリマは [[knowledge_furima_sold_price_harvesting_2026-10]]
6. 業態を4型に分ける：A 居座ってカートを取り続ける／B 高値で置いて本体の品切れを待つ／C 自分の店の値段のまま出す卸型（他モール併売）／D 他販路の在庫を回す。**古物商許可の表示＝せどり型の目安**（新品を卸から買うだけなら不要）
7. 「買値の上限」＝Amazon からの入金−仕入れ以外の費用、を売価4点（いまの本体／いまのカート／主役のカート平均／昨年末の高値）×費用3通り（代行経由／自分で納品・卸／自分で納品・小売）で表にする。小売の実質最安と当社の卸率を当てる

## 分かったこと（次回の置き値）
- サンリオ おせわセット（ベビー）3色：主役は**個人・古物商ありの1社が発売7日後から3色・カート獲得率43〜49%**。年末2か月にカートの約2/3。小売から買う方法は4,950円で売っても▲455円で不成立
- **卸率67%でも「自分で納品」なら売価4,596円以上で黒字**。おりおん経由は4,706円。差96円は代行費（作業89＋振込7）。代行を使う当社は、薄い棚で常に一段不利
- **Keepa のカート保持者（深夜）と昼の出品一覧が違った**（Vita 4,300円→Amazon 本体4,208円）。本体価格が1日に何度も 4,208⇄4,669円を行き来する棚では、カートの持ち主は時間で変わる。§3.3 の確認は**画面の時刻を書く**
- 一次卸の利益の薄さの公開数字：ハピネット玩具事業 2025年3月期 売上1,694億・セグメント利益91億（約5.4%・gamebiz 2025-05-13）。玩具・キャラクター雑貨の掛け率の一次資料は見つからない（矢野経済『玩具産業白書』は有料）

## 失敗と注意
- source-terms-guard の数値検知は**漢数字も数える**。「掛け率…（二次）」の「二」が数字扱いで引っかかった。「一次情報ではない」と言い換えて通した。表に「掛け率」「上代」の語と数字を同じ行に置かない（公開情報でも止まる）。Amazon の公開値は「参考価格」と書く
- HTML の凡例のクラス名を図の領域のクラス名（`.red` `.peak`）と同じにすると、凡例が絶対配置になって図が崩れる。headless Chrome でスクショして確認した（`--user-data-dir` を別にし、`&` で起動して15秒後に pkill。`timeout` コマンドは無い）
- 個人セラーの氏名・番地・電話は成果物に書かない（都道府県と個人/法人まで）。セラーIDと Keepa の月別時系列は agent_output へ
