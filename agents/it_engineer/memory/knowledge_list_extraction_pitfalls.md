# 名簿・HPから項目を抜くときの落とし穴（T-20260920-002 S-F）

## 1. 「載っていない」は正規表現の取りこぼしを疑う

サトルの S-B は日本スポーツ用品工業協会を「TEL 2件のみ」と実測していたが、
**実際は113社中111社に TEL/FAX が載っていた**。表記が `(011)-826-3533` で、
`0\d{1,4}-\d{1,4}-\d{3,4}` に掛からなかっただけ。

**対象を1つ目で切り捨てる前に、生HTMLを自分の目で見ること。** 日本語サイトの電話表記は
少なくともこれだけある：`03-1234-5678` / `(03)-1234-5678` / `03(1234)5678` /
`０３－１２３４－５６７８`（全角）/ `03 1234 5678` / `TEL.03.1234.5678`。

## 2. 電話番号の判定は「桁数」で行う。区切り文字ではない

郵便番号 `003-0862` と電話番号は、パターンだけでは分けられない。

- 3ブロック必須にする（郵便番号は2ブロックなので落ちる）
- 数字だけにして桁数を見る：**固定・0120＝10桁／携帯・0800＝11桁**
- 住所の地番（`増森207-1`）も3ブロックに見えることがあるので、先頭が `0` であることを要求する

## 3. TEL と FAX は「一番近いマーカー」で決める

`TEL 03-1111-2222 FAX 03-1111-3333` は必ずこの形で並ぶ。
「前後24文字に fax が含まれるか」で判定すると、**1つ目の番号が次の項目の FAX を拾う**。
番号からの距離を測って、近い方のマーカーを採ること。

## 4. 「何を作っているか」は title / meta description が一番歩留まりがよい

本文から `事業内容：` を探すより、`<title>` と `<meta name="description">` の方が取れる
（今回 107/107 で何かしら取れた。本文パターンだけなら49）。
サイト運営者が自分で書いた1行なので、AI要約より正確で、人の確認コストも低い。

**ただし `会社案内 | ◯◯株式会社 / ◯◯株式会社の会社概要、沿革…` のような定型文が混ざる。**
これを「主な製品」欄に入れると、分かっていないのに分かったように見える。
社名を消して残りの長さを測る方法は、社名が繰り返されるので効かない。
**製品語（製造・販売・用品・器具・加工…）を含むか、という肯定判定の方が確実。**
含まないものは捨てずに残すが、列名を「サイト説明（要確認）」にして確度を分けた。

## 5. 列を混ぜない

- 「名簿URL（団体の一覧ページ）」と「自社HP」を同じ列にしたのが、今回の差し戻しの一因だった
- 「取扱品目（名簿に書いてあった事実）」と「サイト説明（機械が拾った文）」も別列にする
- 空欄は「未取得（出典に記載なし）」と「該当なし」を別の文字列にする。「未調査」は両方を
  飲み込んでしまい、**次に何をすればいいか分からなくなる**（既存CSVの EC 列1,006行がそれだった）

## 6. モールの出店確認は、相手のサーバに行かずに済む

楽天・Yahoo!・Amazon は機械取得が規約違反だが、**メーカー自身のHPに「楽天市場店はこちら」と
貼ってある**。自社HPのリンク先ホスト名を見るだけで、0円・0リスクで判定できる（ハルオが
05 §4-0 で第一選択として指定）。
ただし**リンクが無い＝出店していない、ではない**ので「無」とは書かず「未確認」にする。
