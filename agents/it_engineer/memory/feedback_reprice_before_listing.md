# 仕入れリストを出す直前に Amazon 価格を取り直す（2026-09-12 / T-20260909-002）

**事実:** スキャン時点(2026-08末)の価格で組んだ9候補を Keepa 現在値で引き直したら、**5件が赤字に転落**（MOST ¥5,780→¥3,480 など）。さらにプリジアプロは1点+43円でも、**仕入れ先の定額送料693円で注文単位は赤字**だった。

**ルール:**
- 社長に出す仕入れリストは、出す当日の価格で必ず再計算する。`product?stats=30&offers=20&only-live-offers=1&buybox=1` で9 ASIN = 53 token。
- 「現在の最低価格」＝ライブ新品オファーの (価格+送料) 最安とカート価格の低い方。カート価格はオファー一覧より安いことがある（LAN: カート¥1,100 / オファー最安¥1,650）ので両方見る。
- 利益は1点で見るだけでなく、**仕入れ先の送料込みの注文単位**でも赤字判定する。定額送料の社は「何点積めば黒字か」を出し、それが回転上限を超えたら外す。
- 社長様式（T-20260904-004/03 の SKU カード）は `build_05.py` が CSS ごと流用して生成できる。余計な説明は一切入れない（社長「すごく見難い」2026-09-12）。
