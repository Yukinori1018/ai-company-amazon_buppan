# キャラ雑貨は「価格帯」で落ちる。知財の前に採算で決着する

2026-09-21 / T-20260920-003 / 成果物 14

## 結論（再利用できる数字）

販売手数料10%・FBA配送代行415円・免税で原価×1.1・粗利500円という当社の前提だと、
**卸率55%で粗利500円を出すのに必要な最低売価は 3,102円**。利益率20%も取るなら **4,369円**。
文房具（15%）は 3,735円／9,223円。服&ファッション小物（8.4%）は 2,943円／3,739円。

**卸率の天井**（売価を上げ切ったときの利益率上限 = 1 − 手数料率 − 1.1×卸率）：

| 卸率 | 利益率上限 | 粗利500円の最低売価 |
|---:|---:|---:|
| 50% | 35.0% | 2,615円 |
| 55% | 29.5% | 3,102円 |
| 63.6% | 20.0% | 4,576円 |
| 67% | 16.3% | 5,614円 |

→ **卸率が63.6%を超えると、売価をいくら上げても利益率20%に届かない。**
丸進で実測できた唯一の卸率は67%。これが代表値なら丸進では20%は数学的に不可能。
**仕入先を評価するとき、最初に聞くべきは個別の卸値ではなく卸率の分布。**

計算コードは `agent_output/T-20260920-003/sanrio8/calc.py`（`min_price_for` / `min_price_for_margin`）。
次に同じ判定をするときは ASIN を差し替えるだけで回る。

## 今回の実測（サンリオ 36,000 ASIN）

`monthlySold>=100` かつ `current_AMAZON=-1` は **7件**（昨日8件・1件は monthlySold が100を割って離脱）。
**利益が取れるのは0件。** 価格帯が 590〜1,980円に集中しており、しきい値3,102円の半分以下。
5件は「仕入値が0円でも粗利500円に届かない」。

## 踏んだ罠と、次回そこで止まらないための手順

1. **「Amazon本体不在」は状態ではなく窓。** 7件中6件が一時不在（数日〜2週間前に抜けた）で、恒常不在は1件のみ。
   判定は `stats.outOfStockPercentage90[0]`（index 0 = AMAZON）と `csv[0]` の最終有値時刻の**両方**を見る。
   **Keepa の価格履歴は階段関数で、値は次の点まで持続する。**「最後の有値が4月」＝「4月以降不在」ではない。
   ここを一度読み違えた（oos90=19% と最終有値2026-04-06 が矛盾して見えた）。矛盾に見えたら生の tail を出して確認する。
2. **本体が戻ると売価が戻る。** 7件すべてで、本体不在時の価格は本体在庫時の 1.3〜2.7倍。
   **現在のカート価格で採算を組むと本体復帰で全部赤字。**「現在価格で計算しても落ちる」という向きで使うなら安全。
3. **カートの有無を必ず見る。** 計算上だけ通った1件（B0BFK44R71・5,000円）は `stats.buyBoxPrice = -1` で
   **カートが付いていなかった**＝その価格では売れていない。`offers=20`（6トークン/ASIN）で取れる。
   **価格が観測できることと、その価格で売れていることは別。**
4. **恒常不在だけで拾うと終売品が混ざる。** 唯一の恒常不在 B01MSH0I42 は EAN なし・`model` が ASIN 自身の
   任天堂 amiibo カードで、ブランド「サンリオ(SANRIO)」に誤タグされた行。既出の
   `knowledge_discontinued_bias_in_margin_ranking` の実例。**EAN の有無は終売・誤タグの一次フィルタとして効く。**
5. **レビュー数・評価は `offers` を付けないと -1 のまま。** `stats=90` だけでは更新されない（既出の鮮度の罠）。

## トークン実績

**60トークン**で決着（Product Finder 1／`/product stats=90` 8件 8／`offers=20` 8件 51）。
`offers=20` は **6トークン/ASIN**。候補が10件以下なら offers を付けて一発で取るのが安い。

## 次の抽出条件（タケシに渡した3条件）

1. Amazon 実売価格 3,100円以上（`current_NEW_gte: 3100` を**ブランドより先に置く**）
2. 単独 ASIN またはバリエーション兄弟3以下（`monthlySold` は家族合計なので）
3. 本体の在庫期間が直近90日で1割以下（＝恒常不在）＋ EAN あり（終売除け）

ブランドを入口にすると価格帯で全滅する。**価格帯を入口にする。**
