# ランクを緩めても母数はほとんど増えない（2026-09-21 / T-20260920-005 S-1）

**「ASIN が2倍になったから母数も2倍」は誤り。** 実測すると ASIN 2.06倍に対し社数は1.76倍しか増えない。

## 実測値（Keepa domain=5・本体なし・15ルート）

| 緩和 | ASIN | 社数 | **既に名簿にいた率** |
|---|---:|---:|---:|
| 現行 ランク5万・FBA2人以上 | 80,700 | 2,425 | — |
| ランク30万まで | 165,900 (×2.06) | 4,270 (×1.76) | 各層 83〜90% |
| ＋規制3カテゴリ（ドラッグ/ビューティー/食品） | +19,939 | +1,572 | 24% |
| FBA1人以上・ランク30万 | 3,431,200 | 21,232（桁の目安） | 17〜36% |

**深いランクの商品は、たいてい「すでに知っている会社の売れていない商品」。**
だから商品が増えても会社は増えない。**母数を語るときは必ず「既存との重複率」をセットで出すこと。**

## 決定的な質の指標: monthlySold はランク5万位で崖になる

Amazon 公表の月間販売数が付いている標本の割合（`product` の `monthlySold`・history=0 でも取れる・0 token）:

| 層 | monthlySold あり | 月100個以上 |
|---|---:|---:|
| 現行 ランク5万以内 | 20.5% | 9.5% |
| ランク5万→10万 | 0.3% | 0% |
| ランク10万→20万 | **0%** | 0% |
| ランク20万→30万 | 0.3% | 0.3% |
| **規制3・ランク5万以内** | **56.0%** | **31.2%** |

- **ランク5万位を超えると公表販売数はほぼ存在しない。** Amazon のバッジ閾値がその辺にある。
- つまり**ランク緩和は社長既定「月100個以上で入口を切る」（[[feedback_volume_sellers_only]] 相当）と原理的に両立しない**。
- 逆に**規制3カテゴリはランクを緩めずに現行より良い条件で母数を65%増やせる**。薬機法・食品表示の確認が要るので法務とセット。

## どんな会社が混じるかは、ランクとFBAで逆向きに動く

| 層 | 国内中小・ストアなし | 中国系OEM疑い |
|---|---:|---:|
| 現行 ランク5万 | 18.3% | 22.2% |
| ランク10万→20万 | 28.6% | 8.9% |
| **FBA1人・ランク5万以内** | 14.5% | **61.4%** |

- **中国系OEM はランク5万以内に集中している。** 深いランク帯はむしろ国内ニッチメーカーの裾＝打診先として濃い。
  「緩める＝質が落ちる」は**ランク軸では逆**。落ちるのは「売れているか」のほうだけ。
- **FBA を1人まで緩めるのは別物。** 6割が中国系OEM で、かつ「FBA在庫を二重に持つ転売業者がいない」＝
  型A が前提にしている**転売需要の実証が無い**。母数の水増しにしかならない。

## 見積りの置き値

- 標本2,176件＋165ブランド×2条件で **8,891 token / 6時間27分**（token は上限1,200・毎分20の回復律速＝1日28,800）
- 巨大な層（100万 ASIN 級）は全件一覧を諦めてランク値クラスタ標本にすると 33,000 → 1,000 token
