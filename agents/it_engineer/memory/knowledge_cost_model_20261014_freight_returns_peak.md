## 卸率の表示ずれ

- 直し方：**"58.2%" の文字列で書く**（`ratio_cell`）。読み込み時は列だけ `UNFORMATTED_VALUE` でも読み、表示に%があり生値>5 なら表示ずれと判定（`ratio_from_sheet`）。生値≦5 は正しい分数（赤字の120%=1.2 を壊さない）
