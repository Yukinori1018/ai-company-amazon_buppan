# 人の「再確認」CSV は元の行を代表ASINで差し替える（2026-10-12 T-20260930-001 担当RC）

## 手順（再利用可）
1. 再確認ファイル（24_連絡先_recheck_*.csv）は **単独の入力にしない**。batch の glob から `_recheck` を外し、代表ASINが一致する元の行を差し替える（並び順は元の位置のまま＝送信順の前提が変わらない）
2. 読む範囲は `--recheck=タグ`（ファイル名の「24_連絡先_」の次から「_」まで）。**採取中のファイル（recheck2）は名前で除外**できる。省略時は全部読む＝完成したら引数を外すだけで効く
3. 秘書の判断（規模の論点を接触候補のまま／社名の括弧書きを外す）は `RC_DECISIONS`、重複の寄せ先への追記は `RC_MERGES` にコードで残す（データとして見える・同期のたびに同じ値に戻る）
4. 検算：①シート退避 ②dry-run で第1弾の入/出を社名で ③3回同期 ④全セル突合（日付シリアルを正規化） ⑤「接触候補になった行の行方」を打診順の区分で数える

## 気づき
- **正式社名が変わると行キーが変わる**。社長入力列は正式社名で引き当てるので、入力済みの行の社名が再確認で変わると入力が落ちる（今回は入力0行で影響なし。missing 警告が出るか必ず見る）
- 再確認で社名が揃うと、別バッチの「重複」行が dedupe で消える（ヘイセイ）。行数の減少は縮小ガードの9割以内でも、**どの行が消えたかを ASIN で出す**
- 接触候補63社 → 第1弾9社（14%）。落ちた最大要因は出品許可が必要（35）、次が月販表示なし（13）。「接触候補が増えた」は第1弾が増えたことにならない（§3.3-36）
- 打診文CSVの「代表ASIN」列は実は URL が入っている。社名ではなく ASIN を正規表現で抜いて突合する
