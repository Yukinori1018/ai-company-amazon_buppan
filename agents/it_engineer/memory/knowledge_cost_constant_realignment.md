2. **値を変える前に**、保存済みキャッシュで新旧比較を回す。旧・新ともに `CostAssumptions(...)` を明示指定すれば
   既定値に依存しない。`netsea_scan.build_candidates()` と `keepa_facts.jsonl` だけで再評価でき、Keepa 0トークン・2分強。
   スクリプト：`agent_output/T-20260904-006/compare_netsea.py`（`ns.BEAT.beat` と `ns.log` を潰して心拍を汚さない）。

   増えたのは大口切替（+110）のせいで、おりおん化（−40）単独では黒字→赤字314件。合計だけ報告すると逆の印象を与える。

  注記だけ足して「新しい判定は fba_cost.py」と書く。
