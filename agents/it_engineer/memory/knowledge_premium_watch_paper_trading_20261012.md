## 設計の要点（再利用できる型）
1. **紙の上の取引は「開始時に固定する値」と「毎日変わる値」を分ける。**開始日・原価・ロット・平常価格は watchlist に追加時に固定し、以後書き換えない。日次の観測は (日付, ASIN) で置き換え。損益は毎回 history から全部計算し直す → 同じ日に何度走らせても漂わない
2. **同じ日の Keepa はファイルにキャッシュして2回目は叩かない**（トークン節約と決定性の両方）
3. 費用は台帳と同じ `fba_cost._scenario` を原価0で回して「1個の入金」にする。式を二重に持たない
4. キーゾン再現式は agent_output の kz_estimate.py をコピーし、テストで200件同値を確認（agent_output は Git 除外なので import 依存にしない）

## 気づき
