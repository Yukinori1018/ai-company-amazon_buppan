## 新しく使った型
### 1. 「お断り」はシートの接触ステータス列に直接書く（recheck ではない）
- 社長入力列（接触ステータス・接触日・メモ）は sync_ledger.py が**正式社名キー**でシートの現在値を保持する（OWNER_COLS / key_of）。だから同期の前にシートへ直接書けば、以後の同期で消えない
- 手順：全タブ退避 → gspread で該当行の接触ステータス＝お断り・メモに理由を追記（RAW）→ 同期。照合は正式社名の完全一致＋75_打診返信トラッカー.csv で裏取り
- 🔴 落とし穴：dashin_order.py の DRAFTED（下書き済の固定リスト）が接触ステータスより先に当たる。ナチュラルウェーブ・第一酵母はお断りでも打診順は「下書き済」のまま。直すなら classify() で接触ステータス「お断り」を DRAFTED より先に見る
- 🔴 正式社名を recheck で書き換えると、キーが変わって社長入力列が引き継がれない。送信済・お断りの社の正式社名は変えない

### 2. 並行組の同社は「正式社名キーで寄る」
- ZK 4420 と ZM 4555（サクラカネヨ）は正式社名が同じなので、ZM の行は作られない（入力では消えたように見える）。recheck で重複に書き換えても数には出ない。前後比較で「入力にあってシートに無い行」を数え、重複判定以外がこの型かを確かめる
