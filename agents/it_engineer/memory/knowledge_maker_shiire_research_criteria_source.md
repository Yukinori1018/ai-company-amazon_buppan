> T-20260831-004（2026-08-31）で全素材を機械走査した結果。
> 当社の候補抽出パイプライン（scan_v14 / v15）が参照する数値の出所を確定させたもの。

## 結論: 数字が書いてあるのは PDF だけ

| 素材 | ランキング条件の記載 |
|---|---|
| サンプル版マニュアル PDF（申込特典・EC STARs Lab.） | **あり。5万位以内（1〜50,000）**。3基準の3番目 |
| 画面収録 1時間49分（`画面収録 2026-06-10 11.11.48.mov`） | **なし**（該当フレーム0枚） |
| スクリーンショット56枚 | **なし** |
| 完全版マニュアル | **社長が未所持**（セミナー参加時配布） |

PDF は**テキストレイヤーを `pdftotext` で直接抽出**した。OCR ではないので誤読の余地がない。「10万位」という文字列は PDF に存在しない。

## 3基準（PDF の記載）

1. Amazon 本体が出品していないこと
2. FBA のライバルセラーが2人以上いること
3. ランキングが5万位以内であること

**「大カテゴリ順位かサブカテゴリ順位か」はどの素材にも書かれていない。** 当社の実装ではここを自分で決める必要がある（Keepa の BSR はサブカテゴリ順位の罠があるので、`reference_keepa_reading_pitfalls.md` を必ず参照）。

## 「10万位」説について

社長は「10万位から下位が目安」とご記憶。**手元の素材に裏付けは1件もなく、反証（5万位）だけがある。** ただし記憶違いと断定はできない。

- 録画は 11:11:48 開始で、リサーチ基準の説明（10:56頃）は**録画開始前**。第1章 STEP1 は1フレームも残っていない
- **録画に音声トラックが無い**。質疑応答25分（11:35〜、12:00〜、12:16〜、12:55〜）は講師のカメラ映像のみ。口頭補足は原理的に復元不能
- 完全版マニュアルの入手は先方への問い合わせ＝§4.1（第三者連絡）。自分では踏めない

## 実装への申し送り

数値を1つに決め打ちしない。**5万位を本線にしつつ、閾値をパラメータにして「10万位まで拡げたときの件数増」を並記できるようにしておく**と、社長がその場で判断できる。母数を増やす副作用が数字で見える形にするのが肝心（社長は「欲しい情報の母数を増やすのが目的。いらない情報で母数を増やすな」と明言されている。`feedback_maximize_pool_not_ranking.md` 参照）。

なお `docs/reference/maker-shiire/seminar-20260610-realtime-notes.md` §2 の「売れ筋ランキング5万位以内」は PDF 由来であり、録画・スクショから確認されたものではない。**受講記録の記述と、映像で裏が取れている記述は別物**として扱うこと。今回の全文 OCR では §8 の内容と矛盾は出ず、新事実も出なかった。
