# Exa でメーカー連絡先を埋める — 実測値と踏んだ罠

- 初出: T-20260904-004 / B-1（2026-09-04）
- 手段: Exa MCP（`mcp__plugin_exa_exa__web_search_exa` / `web_fetch_exa`）
- サンプル: 和名法人10社 ＋ 英字ブランド10社（乱数シード固定・無作為抽出）

## 実測値（この数字を次回の見積もりに使う）

| 項目 | 和名10社 | 英字10社 |
|---|---:|---:|
| 正式商号 / 所在地 | 90% | 50% |
| 公式HP | 80% | 60% |
| 電話 | 80% | 40% |
| 問い合わせフォームURL | 30% | 20% |
| メール | **0%** | 30% |
| **連絡手段が1つ以上** | **80%** | **50%** |
| 法人番号 | 50% | 10% |

- **日本企業はメールを載せない。** 和名10社でメール0件。連絡口はフォーム。
  にもかかわらずフォームURLの取得率が30%と低いのは、検索1回では会社概要ページしか返らないから。
  **1社2手（検索 → 公式サイトを fetch）にすればフォームは70%台まで上がる。**
- 英字の「連絡可50%」は額面倒れ。**日本にいて小ロット交渉が現実的な相手は20%**（10社中2社）。
  残りは米国法人・中国上場企業・大手で、本丸ではない。

## コスト（0円。ただしスクリプト化できない）

- **金銭0円。** Exa プラグインはホスト型 MCP（`https://mcp.exa.ai/mcp`）で **API キーが無い**。
  `~/.claude/plugins/cache/claude-plugins-official/exa/<ver>/mcp.json` を見れば確認できる。
- **API キーが無い＝Python から直接叩けない＝1社1社がエージェントのターンを食う。**
  夜間バッチにはできない。セッション分割で回すしかない。約6,300 tokens/社。
- 呼び出し回数は 1.1回/社（5社ずつ並列 batch で投げると速い）。20社で約3分。

## 踏んだ罠（5/20 = 25%。検索1位をそのまま採ると誤りが混入する）

1. **同名の無関係企業**（一番危険）
   - `INTEX`（プール）→ 検索1位は **株式会社インテックス＝板金機械の会社**
   - `AooDen`（枕）→ 検索2位は **株式会社AODEN＝埼玉の電気工事会社**
   - → **対策: 採用前に公式サイト本文を fetch し、その商品カテゴリの記述があるか確認する。この1手で両方弾ける。**
2. **偽ECサイト**。中国系Amazon専売ブランドを検索すると、商品名をコピーした
   ドメインの怪しいサイト（`.hu` `.zw` `.at` 等）が上位に来る。**そこの連絡先を拾ってはいけない。**
3. **集約サイトのフィールドは壊れている。** LinkedIn の `Phone` 欄に
   `545-0021, 2025-12-26, 06-6693-5355, ...`（郵便番号・日付・複数番号の混在）が入っていた。
   `knowledge_verify_field_semantics_not_names` と同じ型の事故。
4. **ブランド ≠ 法人。** `あしあげ隊` → 株式会社タツフト、`C&G` → 株式会社Helio Japan、
   `PROXXON` → 株式会社キソパワーツール。ブランド名で検索して法人を1段掘る必要がある。
   `カワサキ(Kawasaki)` は代表商品（純正オイル）から受託製造元が先に出て、
   総販売元（カワサキモータースジャパン）は2回目の検索でようやく出た。
5. **法人は生きているが窓口が死んでいる。** ジャニーズ・エンタテイメントは
   法人番号・所在地は取れるが、公式サイトも電話も存在しない（SMILE-UP. へ商号変更）。
   **「取れた項目数」だけを見ると成功に見えるが、連絡できない。**

## 判断として残すこと

- **国税庁 法人番号 API / gBizINFO は急がなくてよい。** 連絡に要るのは商号・所在地・電話・フォームで、
  それは Exa で揃う。公的DBが強いのは法人番号だけで、法人番号は取引開始後（インボイス）に要る項目。
  両方とも利用申請＝規約同意＝§4.1 なので、**社長の一手を1回節約できる**。
- **英字ブランドの半分は「対象が存在しない」。** 法人登記なし・公式サイトなし・日本窓口なしの
  Amazon 専売中国ブランド。ここに時間を使うのは損失。`日本シグナル`（JAN先頭45/49・.jpドメイン・
  日本語タイトル・manufacturer日本語）で先に絞ること。

## 設計として残すこと

MCP しか無い外部サービスは、**オフライン resolver に落とす**のが正解。

```
エージェントが MCP を叩く → JSONL に1社1行で追記 → resolver がそれを読む
```

`needs_network=False` のまま動くので法務ゲート（`allow_network`）に触れない。
API キーを調達できたらオンライン版に差し替えられる。JSONL の形は変えないこと。
実装: `T-20260831-001/pipeline/resolvers/exa_lookup.py`

## 本走行（和名451社のうち上位50社）で分かったこと — 2026-09-04 / T-20260904-004

### 2手方式の効果は数字に出る

| 項目 | 1手（精度測定・和名10社） | 2手（本走行・50社） |
|---|---:|---:|
| 問い合わせフォームURL | 30% | **50%** |
| 公式HP | 80% | 90% |
| 連絡手段が1つ以上 | 80% | **86%** |
| 法人番号 | 50% | 24%（自社サイトが充実した社は第三者法人DBが返らない） |

**メールは日本企業から取れない（14%）。実際の連絡口はフォームと電話。**
コストは 0.88 MCP呼び出し/社・1.4分/社（5社ずつ並列 batch）。**0円のまま。**

### ★連絡先より価値があるのは「連絡してはいけない」という情報

50社中5社で拒否表示を検出した。踏んでいたら関係が終わっていた。

- **すごろくや**「実店舗を持たないオンライン専売業者とは一律お断り」← **Amazon専業の当社は構造的に対象外**
- **愛知電線**「セールス・勧誘は特定電子メール法に基づき固くお断り／迷惑メール相談センターに通報します」
- **カプコン**「営業・ご提案は書面にて本社宛に」＝電話・フォーム不可
- **リッチェル**「商品やサービスの売り込み、製品アイデア等のご提案はご遠慮ください」
- **ストームレーベルズ** 唯一の電話が「採用担当専用※お問合せは極力ご遠慮ください」→ **番号を登録しない判断をした**

**連絡先を集めるときは、同じ手間で取引方針まで読むこと。** 法務B §9-3 の `form_optout_notice` 列は
「法令対応のための形式的な列」ではなく、**実務で5件も発火する実用列**だった。

### 逆に「有望」を見分けるサインも公開されている

- **山形工房** 公式サイトのグローバルメニューに「**OEM**」の項目 ＝ OEM受託を公開募集
- **曙産業** 燕三条地場産業振興センター（公的DB）に「**OEM製品の開発設計も承ります／既製品の少量から大量受注も承ります**」
- **ルート産業（モリドライブ）**「企業様向けのご提案も行っております」
- **タカギ** B2B専用の電話とメール（`b2b@takagi.co.jp`）を公開
- **CAPスタイル（モリグリーン）**「卸機能とメーカー機能を併せ持つホールセラー」

→ **「OEM」「少量」「B2B」「法人のお客様」「卸」がサイトにあるかを、連絡先と同時に拾うこと。**
公的な産業支援DB（燕三条ものづくり企業ナビ等）は、企業サイトより取引条件を具体的に書いている。

### 利益順に並べると出版社・レコード会社が上位に来る（順位付けの罠）

粗利率×商品数×回転でスコアリングすると、**仕入れ値が安い本とDVDが構造的に上位**に来る。
上位50社の48%が 本/DVD/ミュージック/ゲーム/PCソフト で、**取次・販売代理店に流通が固定されており
メーカー直取引が成立しない**。本丸（自社製造の中小メーカー）は31〜50位に固まっていた。

→ **カテゴリ係数を掛けて、コンテンツ商材を後ろに落とすこと。**

### v14 の `規模フラグ` は信用してはいけない

上位50社は**全社が「中小候補」**だった。ディズニー・カプコン・マキタ・講談社・タカギも「中小候補」。
`knowledge_verify_field_semantics_not_names` と同じ型。**列名を信じず中身を検算する。**

### ブランド ≠ 法人。事業譲渡まで追う必要がある

50社中11社でブランド→法人の追跡が要った。特に注意が要ったもの：

- `懐石` → 日清ペットフード**ではなく**ペットライン株式会社（2019年12月に事業譲渡。日清製粉GのIR資料で確認）
- `東映` → DVD/BD販売は**2024年4月に東映ビデオ株式会社へ会社分割で承継**（有価証券報告書）。本体に連絡しても仕入れの話にならない
- `モリドライブ`（ルート産業）と `モリグリーン`（CAPスタイル）は**名前が似た別会社**
- `懐石` の検索で出た「日本ペットフード株式会社」は社名が似ているだけの別会社

**ブランド名のまま連絡先を探すと別会社を掴む。** 有価証券報告書・IR資料は事業の帰属を追う一次情報として強い。

### 特定商取引法に基づく表記は最良の一次情報

`JASON MARKK` → 株式会社GRIDDY、`NEW ERA` → ニューエラジャパン合同会社 は、
いずれも**特商法表記ページ**から商号・住所・電話・メールを一括で取れた。
法律で掲示が義務づけられているので、**ECサイトを持つブランドではここを最初に見るのが速い**。
