# Keepa API の課金は完全な定額。トークン切れで金は動かない（2026-08-31 公式確認）

**「24時間回して課金は大丈夫か？」と聞かれたら、この結論をそのまま使ってよい。**
出典は公式 `keepa.com/api-docs/plans-tokens.html` と `request-basics.html`（2026-08-31 実取得）。

---

## 結論

| 論点 | 事実 |
|---|---|
| 課金方式 | **月額前払い・自動更新の定額**。プランの違いは「1分あたり何トークン生成されるか」だけ |
| 従量課金・超過料金 | **存在しない**。ドキュメントに該当項目が無い |
| トークンが尽きたら | **HTTP 429**（`You are out of tokens.`）。課金は発生しない |
| 公式の明言 | トークンバケット方式なので、契約分を誤って使い切ることはできない、と書かれている |
| 請求が動く操作 | プランの**アップグレード/ダウングレード**と**追加契約**だけ。どちらもダッシュボードでの明示操作 |
| ダウングレード | 28日に1回だけ。差額は返金されず Keepa アカウントへのクレジット |

→ **常時稼働させても追加費用は1円も出ない。CLAUDE.md §4.1（金銭）に該当しない。**

## トークンの仕様（設計に効く数字）

- バケット容量 = `レート × 60`。**未使用トークンは60分で失効するので貯め込めない**
- 当社のプランは **20/分**（＝上限1,200・1,200/時・28,800/日・約89万/月）
- `tokensLeft` は**負にもなる**。「送信時点で残高が正なら実行する」仕様のため
- `tokenFlowReduction` — **API 経由の商品トラッキングは補充レートそのものを下げる**。
  当社は tracking を使っていないので現在 0.0。**使うときはここを必ず見ること**

## 単価（公式表）

| リクエスト | トークン |
|---|---|
| 商品リクエスト | 1 / ASIN |
| ↑ の offers 付き | **+6 / オファーページ（1ページ最大10オファー）** |
| Product Finder | 10 + 結果100件ごとに1（**1ページ最大10,000件・ページングで合計10,000件が上限**） |
| セラー情報 | 1 / ID |
| Deals | 5 / 150件 |
| ベストセラーリスト | 50 / リスト（最大10万ASIN） |

**Product Finder の 10,000件上限は設計に直撃する。** 1クエリで到達できるのは1万件までなので、
それ以上の母集団を掘るには価格帯などでシャードに割るしかない（当社の25シャードはこれが理由）。

## 未確認で残っていること

**api-docs 側にクォータの記述は見当たらなかった**が、常時稼働での実測はまだない。

## 取得のしかた（次に調べる人へ）

`keepa.com/#!api` は **SPA + Cloudflare で WebFetch は 403**。
**`keepa.com/api-docs/*.html` は静的で curl も WebFetch も通る。**

    curl -sL -A "Mozilla/5.0 ..." https://keepa.com/api-docs/plans-tokens.html
