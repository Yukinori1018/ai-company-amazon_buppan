# 走行中のジョブから読むときは、スナップショットでなく元ファイルを読む

2026-09-08 / T-20260907-001。

`summarize.py` が作る `candidates.csv` を入力にしていたため、
**915件時点のデータで社長への提出物を作っていた**（実際は2,981件まで進んでいた）。
スナップショットは「最後に summarize を打った時点」で止まる。走行中はすぐ古くなる。

**append-only の元ファイル（`passed.jsonl`）を直接読む。** 重複は asin で潰す。
走行中に読むので**最終行が千切れていることがある** → `try/except` で捨てる。

> 派生ファイルを入力にするときは「これは誰がいつ更新するのか」を必ず確認する。
> 自動で追随しないなら、それは入力に使ってはいけない。

**社長に出す成果物は、1コマンドで最新化できる形にしておく**（`refresh.sh`）。
提出頻度が上がると、手順が2つ以上ある時点で必ず古いものを出す。
