## 自動生成は使えなかった
- ラベル（直前の文字）は「前の欄の文字」を含むので、ラベルから値を当てる自動生成は電話欄にメールが入るなど誤りだらけだった。**分岐は手書きが早くて確実**。生成物は下書き程度。
- 空打ちの戻り値だけでは「違う欄に違う値」が見えない。**dryrun で name=値 の一覧も取って目で見る**のが要。

## 新しく見た型
- ラジオの value が番号や英字（0〜4・torhihiki・net）の社が多い → **ラベル文字でラジオを選ぶ rt(name, 文字)** を追加。labels→親（入力が1つだけの親）→次のテキストの順で読む。
- **窓口URLと入力URLが違う**社が71社中10社：区分一覧ページ（ゆとりの空間・オーサワ）、iframe 埋め込み（BowNow・HubSpot）、www なしで証明書エラー（サンヨー堂）、案内ページ（山真）、外部フォーム（secure-cloud）。CSV に「入力するURL」列を必ず持つ。
- **HubSpot の埋め込みは別ドメインの枠**でコンソールから届かない → 共有URL `https://share-<hublet>.hsforms.com/2<base64url(formGuid)><portalIdを36進>` を直接開けば普通のページとして入れられる（デルフォニックスで確認）。
- **折りたたみの中のフォーム**（山脇製菓「こちらをクリック」）は値は入るが見えない。スクリプト側で開いてから入れる。
- ページ側で**最初からチェック済みの同意・性別**がある（黒瀬の「ご利用にあたって」、由比缶詰所の性別=男性）。自分が入れたものではないので社長の確認事項に書く。
- B-cart（Bellwoods）は直接アクセスで403「不正なページ遷移」。トップから辿る。

## 「お断り」文言の判定（秘書の基準をそのまま運用）
- 「営業・セールス・売り込みお断り」は広告・人材・出展勧誘向けで、仕入れの相談は対象外と判断して残した（EM生活・三幸産業・阿川食品・レッドハート・七福醸造）。
- Amazon 出品者・転売を名指しで断る文言は B 区分22社では0件。A 区分のデルフォニックス（消費者FAQに「転売は原則お断り」）は外さず注意書きにした。
