# カート保持セラー名とメーカー名・ブランドの機械照合（層4の別名先行キュー）

T-20260930-001 / 2026-10-11 夜。スクリプト：`workspace/output/agent_output/T-20260930-001/52_layer4_prefilter.py`（Git 管理外。規則はファイル冒頭に書いてある）

## 何のためか
キューの層4「本人カート疑い」は、人が100行見ても接触候補が0〜1社しか出ない（W・X の実測）。当たりは「カート保持セラーが実は別会社」の行だけだった。そこで照合で並べ替えて、別名の行から先に人が見る。**行は捨てない**（§3.3-34）。

## 効いた規則（評価順）
1. メーカー名の語がセラー名と重なる → 一致（公式を名乗っていてもこちらを優先）
2. セラー名が 公式/直営/直营/メーカー/直販/official を含む → 公式名乗り
3. ブランド語は含むが、セラー名が販売店・代理店・専門店・正規店・取扱店を名乗る → **別名（2266型）**
4. ブランド語が重なる → 一致／5. どれでもない → 別名
- 正規化は NFKC・小文字・ひらがな→カタカナ・会社種別の除去・記号の除去。**括弧の中も別の語として残す**（読み仮名・英字表記が入っている）
- 語の最小長は英数3字・その他2字。ただし**名前全体なら英数2字も可**（SG株式会社・Ｔ・Ｊ株式会社がこれで拾えた）

## 落とし穴
- **キューの「ブランド」欄に店名が入っている行がある**（2266 のブランド＝「Pエンタメストア」）。ブランド一致だけで「本人」とすると当たりを捨てる。メーカー名との一致とブランドとの一致を分けて扱うこと
- 「公式」と販売店語が両方ある店（純炭粉末公式専門店・【公式】…正規輸入代理店）は公式名乗りを優先した
- カナと英字の対応（ゴッパ合同会社 vs GOPPA）は取れない。別名に誤って入るが、並べ替えだけなので許容した
- 層5（大手）は小売がカートを持つのが普通で、別名の大半を占める（47/59）。層4の別名を先頭、層5の別名をその後ろにした

- X：除外84 → 一致64＋公式19＋別名1（X2327 かに専門店 鮮度の鬼）

## 再利用
同じ型の依頼（「セラー名と社名が違う行だけ先に」）は、このスクリプトの `judge()` をそのまま使う。新しいバッチで検算するときは、既存 batch の「判定」列と照合結果をクロス集計する（`除外` が一致/公式に何割入るか）。
