# 社長に渡す「連絡先リスト」の品質基準（T-20260904-004 で明文化）

秘書カズヨ経由で繰り返し出てきた条件。次に同種の依頼が来たらこれを満たす。

## 絶対条件

1. **間違った連絡先は「取れなかった」より悪い。**
   社長が別会社に連絡してしまうから。したがって
   - 検索1位をそのまま採らない（実測で約25%が別会社）
   - 裏取りできなかった項目は**空欄のまま**にして、確度列に「要確認」と書く
   - 推測で埋めない。これは省略可能な努力目標ではなく、成果物の合否条件

2. **打診メールの本文・署名に URL を一切貼らない。**
   Amazon ストアURL・自社サイト・SNS すべて。貼った瞬間に特定電子メール法
   2条2号の「広告宣伝ウェブサイトへの誘導」に該当し、
   相手の「営業お断り」表示が**法的効力を持つ**（法務ハルオ判定 v1.0）。
   白が黒に転ぶ唯一の分岐点なので、CSV のヘッダ注記として毎回出力し続ける。

3. **打ってはいけない相手を上位リストに載せない。**
   注記で「D/E には打診しない」と書いてあっても、社長はリストを上から順に消化する。
   注記で止める設計にしない。**リストから外す。**

## 優先順位のシグナル（本丸＝ネット販売に疎い中小メーカー）

上げる: OEM / 受託 / 小ロット / 少量から の記載、B2B専用連絡先、卸が本業、
従業員数が小さい、⭐「個人事業主も対象」の明記（399社で1社だけ・最強）。

落とす: コンテンツ商材（本・DVD・CD・ゲーム）と大手。
理由は「取次・専門卸に流通が固定されていて、版元/開発元に打診しても
小売への卸の話にならない」から。今回、キュー後半はほぼこれで、
新書館が公式に「出版取次店 日本出版販売、トーハン」と書いているのが典型例。
限定版・初回生産限定・生産終了ハード向けは**継続供給が構造的に無い**ので更に下。

## 報告は数字で

処理社数 / 取得率（項目別）/ A〜E 内訳 / 打診可能社数。
「連絡手段あり」の定義は**電話・フォーム・メールの3つ**。
公式HP は連絡手段に数えない（送れないから）。ここを混ぜると率が水増しされる。
