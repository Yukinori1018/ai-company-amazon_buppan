## 罠: 検索語を無視しても、それらしい件数が返る

卸問屋.com の検索フォームは `onSubmit="return false"` で、実際は JS（`K_TopSearch`）が action に `?sName=` を付けて送る。
POST 本文だけ送ると検索語が無視され、**全商品の新着一覧（2,416件）が返る**。ブランド名でも JAN でも同じ 2,416。
最初の1本（アイリスオーヤマ 2,416件）を見て「当たった」と思いかけた。

対策（検索系を叩く前に必ず3本）:
1. 実在が分かっている語（詳細ページで見た JAN）→ 1件前後になるか
2. 無意味な語（`zzqqxx不存在`）→ 0件になるか
3. 違う2語で件数が違うか

3本が通るまで本番を回さない。**同じ件数が2回続いたら検索が効いていないと疑う。**
フォームは HTML の action だけでなく、onSubmit / onclick の JS 関数（外部 .js にあることが多い）まで読む。

## 規模の線

どこも自動取得の明示禁止は無いが、登録前は「件数を当てる手作業規模」に留めた（2秒間隔・上位30ブランド・国分は JAN 最大10/ブランド）。価格は取らない。全件照合は会員登録（§4.1）の後。
