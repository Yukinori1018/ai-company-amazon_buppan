# NETSEA の「商品名はケース・卸値は1個」— 食品の幻の利益（2026-09-15 / T-20260909-002 #12）

## 何が起きたか

月100以上の738件で「利益率10%以上31件、うち食品が大半」→ 社長に「食品を解禁するか」を聞く直前だった。
入数を直すと **食品23件中22件が赤字**。残る1件は Amazon 本体あり。**食品で黒字になるのは0〜1件だった。**

## 罠の形（pack.py の罠3 の実例）

国分ネット卸: 商品名「マルハニチロ さば水煮 月花 x24」、卸値 381円（税抜）。
Amazon: 「200g×12個入×(2ケース)」6,960円。

`resolve_multiplier` は「NETSEA 24個 / Amazon 24個 → 倍率1」と判定する。
しかし NETSEA の口設定（`netsea_items.jsonl` の `set[]`）は **label「24個入り」・price 381・set_num 24**。
つまり **381円は1缶の値段で、24缶まとめて注文する**という意味。1ケース381円（1缶16円）と読んでいた。

## 見分け方（機械でできる）

1. **`set[].set_num` が商品名の数と同じなら、卸値は1個単価**（国分ネット卸で3件確認）
2. 表記に依存しない保険: **売価 ÷ 原価 ≥ 4 なら「単価仮定」で原価 = 単価 × Amazon の入数**（大きい方＝安全側）
3. 1個あたりの原価を暗算する（16円のさば缶は存在しない）

## 同時に見つけたもの

- `pack.py` の二重読み:「【2個セット】…105g×2」を 2×2=4 と読む（同じ2の言い直し）。738件中2件。安全側の誤りだが黒字を落とす（カムテクト）。未修正・残課題
- #8 食品キーワード（部分一致）の誤爆: 738件中75件（水43・油7…）。熊野「油」脂、「塩」素系。**食品判定は Amazon カテゴリ（食品・飲料・お酒＋ドラッグストア>栄養補助食品）で行う**
- Keepa の重量がケース品で1本分のことがある（トイレハイター 500g → 実13.9kg）
- 「セット」の中身が別JANの組み合わせ（サロンリンク S&C）→ 同社の対のJANの口単価を足す

## 手順（再利用できる形）

1. 未確認の行は、倍率1（原価が最小）でも利益率5%に届くかで先に落とす（111件 → 3件）
2. 残りは Amazon 実ページ（商品説明の「入数」・ユニット数）と NETSEA の `spec_size`・`set[]` を突き合わせる
3. 手で確定したものは OVERRIDE に根拠文つきで書く。**卸値は PUBLIC リポに書かない**（JAN から読む）
4. 出力の上位は必ず実物で目視（今回もトイレハイターは実ページでしか確定できなかった）
