## 学び
1. **新規行数はバッチ行数の合計にならない**（299→+273）。重複行は既存/並行バッチの同社に寄るので、報告は「新規273行＝内訳」で出す
2. **秘書の「残す」「後回し」より基準チェックと出品可否が先に効く。**ミツエイ・上野風月堂（残す）は掛けで基準NG、鳥繁産業（後回し）も掛け39%で先に基準NG、大王製作所（後回し）は出品不可で先に落ちる。報告では「秘書判断どおりにならなかった社」を名指しで返す
3. 「5%に必要な掛け40%<40%」の表示は丸め（39.x%）。報告で誤読されないよう注記する
4. 楽天直営店しか窓口がない社はコード上の特別扱いなし（通常の接触候補として判定される）
