# ブラウザの「出品者1件」は未ログインで削られた数字だった

T-20260920-003 / 2026-09-20。**原因を 9/20 中に訂正済み。現象は実在するが理由が違った。**

## 何が起きたか

社長とカズヨが商品ページで「出品者1件だけ」を見た。Keepa では
B0FQDWCGQD が稼働8本/8社（**Amazon 本体を含む**）、B0C1J9QV1H が4本/4社。

**真因は「未ログインだったこと」。** 未ログイン状態では Amazon がお届け先を既定の海外拠点
（今回 Nadi 6CJP）に置くため、海外配送に対応しない出品が一覧から丸ごと落ちる。
**ログインすれば複数社が見え、Keepa の数字と整合した**（カズヨが実画面で確認）。

→ 当初カズヨが立てた「アカウント設定が海外になっている」という見立ては**誤り**。
アカウントを直す必要はない。**ログインしてから見ればよい**だけ。

## 教訓

- **一番危ないのは Amazon 本体が消えることだった。** 本体の有無は仕入れの生死を決めるので、
  取りこぼすと「競合のいない優良 ASIN」に見えてしまう。今回まさにそう見えていた。
- **出品者数・Amazon 本体の有無は Keepa を正とする。** `availabilityAmazon`（0=在庫あり / -1=本体なし）と
  稼働オファーの `isAmazon`。Keepa の `isShippable` は国内配送可の意味で、閲覧側の状態に左右されない。
- 成果物では**ブラウザ観測との差を必ず表に並べる**。黙って Keepa の数字だけ出すと
  社長の画面と食い違い「言っていることが違う」になる。
- **現象の報告と原因の断定を分ける。** 現象（出品が消える）は正しく、原因（アカウント設定）は
  間違っていた。原因を断定する前に「ログインして再現するか」を試せば1手で分かった。
