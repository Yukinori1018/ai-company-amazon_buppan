# PUBLIC リポへの機密混入を止める型（既定を反転する／commit を止める）

2026-09-06 / T-20260904-004。NETSEA の卸値を含む HTML が PUBLIC リポへ push された事故の再発防止。
**同型の事故は 2026-08-31（卸価格227行）にも起きており、これが2回目。**

## 何が本当の原因だったか

「サブエージェントが `.gitignore` に書き忘れた」ではない。
**直接原因は別セッションの `git add -A` に巻き込まれたこと**であり、
構造的原因は **`.gitignore` の既定が「載せる」だったこと**。
書き忘れが危険側に倒れる設計は、いつか必ず事故る。人の注意力で支える設計にしない。

このリポは `.claude/scripts/github-sync.sh` が30分ごとに `git add -A` → `commit` → `push` する。
**成果物フォルダに新しいファイルを置いた瞬間、放置すれば30分後に世界に公開される**と考えること。

## 型1: `.gitignore` をホワイトリストに反転する（1フォルダ2分）

```gitignore
*        # 既定＝載せない
!*/      # ただしディレクトリは降りる（下の負パターンを効かせるため必須）
!.gitignore
!載せてよいファイル名
```

- `!*/` を忘れると、サブディレクトリごと除外されて中のホワイトリストが効かない。ここが唯一の罠
- **既に追跡済みのファイルには `.gitignore` は効かない**（git の仕様）。だから機械ゲート（型2）が要る
- 検算は `git check-ignore -q` を追跡ファイル全件に回して「誤って ignore された数」を数える。
  `git ls-files` の前後比較も併せて取る（56→56 のように数字で言う）

## 型2: pre-commit フックで止める（`.githooks/pre-commit`）

- **`github-sync.sh` は `git commit` を呼ぶので、pre-commit で止めれば自動同期にも効く。** ここが要点
- 置き場は `.git/hooks/`（追跡されない）ではなく **`.githooks/`（追跡される）＋ `git config core.hooksPath .githooks`**
- **`core.hooksPath` はローカル設定**。新しい clone・worktree・クラウドセッションでは未設定＝ゲートが効かない。
  → `.claude/hooks/session-start.sh` に**毎セッション冪等に張り直す3行**を入れた。
  「フックを置いた」は「フックが動いた」の証拠にならない

### 誤検知で運用を壊さないための3原則

1. **新規に index へ入るファイルだけ見る**（`git diff --cached --name-only --diff-filter=AC`）。
   追跡済み `.md` の編集で毎回止まる作りにしたら、翌日には `--no-verify` が常態化して無意味になる
2. **拡張子でスコープを絞る**。行データが載るのは `.csv/.json/.html` 系。`.py`/`.sh` は見ない
3. **散文と行データを区別する**。`.md` は `|` 始まりの表行かカンマ3つ以上の行だけを数える。
   しきい値は既存ファイルの実測から決める（今回: 法務判定 E_ は表行に「卸値」が5行 → しきい値6）

### 必ず入れる2つ

- **バイパス**（`--no-verify` / 環境変数）と、その使い方を**フック自身のエラーメッセージに印字**する
- **fail-open**。検査が失敗したら警告して commit を通す。ゲートが落ちて全社の commit が不能になる方が被害が大きい。
  検知したときだけ落とす（本体をサブシェルで動かし、戻り値2＝検知のときだけ exit 1）

## bash の実装で踏んだ罠

- **`$(git diff -z)` は壊れる。** bash はコマンド置換で NUL バイトを捨てるため、
  ファイル名が区切りなしで連結される。**一時ファイルに落として `while IFS= read -r -d ''` で読む**
- **`cat <<MSG`（クォート無しヒアドキュメント）はバッククォートを展開する。**
  メッセージ中の `` `!ファイル名` `` が「command not found」になった。**`<<'MSG'` を使い、変数は `printf` で別途出す**
- `grep -F -c` は「マッチした**行**数」であって出現回数ではない。メッセージの文言をそれに合わせる
- **`git` は日本語パスを8進エスケープする。** 比較・検算では `git -c core.quotePath=false` を常に付ける
  （同日カズヨがこれを踏んで push 済みを未 push と誤読した）

## 検算のやり方（「置いた」で終わらせない）

- **ミューテーション**：実際に汚染ファイルを作って `git add -f` し、本当に止まるかを見る
- **逆方向**：正当なファイル・既存の解説文が止められないかを見る。片方だけでは検算にならない
- **事故の再現**：今回の実ファイル（03 の HTML）で `git add -A` して載らないこと、
  `git add -f` して止まることを両方確認した。合成データだけで満足しない
