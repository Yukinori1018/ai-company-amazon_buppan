# お断りへのお礼：理由が「生産数の限り（供給の制約）」で、相手が「またの機会に」と書いてきた場合

初出 2026-10-19（T-20260930-001 / 有限会社近藤酢店（延命酢・マルヤス）のお断りへのお礼）。
親：knowledge_maker_reply_thanks_and_referral.md §1（5行の型）。兄弟：knowledge_maker_reply_decline_no_recontact.md（荘快堂）／knowledge_maker_reply_decline_reseller_conflict.md（播磨園製茶）。いずれも Mac 側ブランチ `claude/nighttime-work-checkin-iTWEa` にあり、このチェックアウトには無いので別ファイルにした。マージ時は親 §1 に統合してよい。

## 型の選び方（3社で分岐が揃った）
| 断りの理由 | 将来の一言 | 実例 |
|---|---|---|
| 再接触を断っている | 外す。代わりに説明への礼 | 荘快堂 |
| 条件が変わっても戻らない理由（卸先どうしの重なり） | 外す | 播磨園製茶 |
| **相手側の一時的な事情（生産数）＋相手から「またの機会に」** | **入れる。相手の言葉「またの機会」を受ける** | 近藤酢店 |

判定の1問：**「相手は自分から再会の扉を開けているか？」** 開けていれば5行の型どおり将来の一言を入れ、相手の語を拾う。

## この回の判断
1. **将来の一言は「生産のご状況が変わりましたら、またの機会にお声がけいただけますと幸いです」**。
   - 「またの機会」は相手の語。拾って返すと「あなたの言葉を受け取りました」になり、売り込みにならない
   - 主語は相手（お声がけいただける）。当社から「改めてご連絡します」は再度の売り込みの予告なので使わない（親メモの原則）
   - 「生産の状況が変わられましたら」は不採用。尊敬の「られる」を「状況」という物事に付けると敬語として据わりが悪い →「ご状況が変わりましたら」
   - 「生産にゆとりが出ましたら」「増産の際は」も不採用。相手に増産を期待している（＝こちらの都合を押し付ける）ように読める
2. **「魅力的な内容」への感謝は「過分なお言葉まで頂戴し」**とお礼の文に1句だけ足した。
   - 「魅力的とのお言葉」と引くと、当社の提案を当社が褒め直す形になり自画自賛に読める。「過分」は謙遜なので向きが正しい
   - 独立した1文にしない。礼が主役になると、断りの文脈で浮く
3. **少量でも／数量を絞って等の代案は出さない。** 供給制約への代案は、断りを受け入れていない（再提案）に読める。禁止語「少量」にも当たる
4. 「現状は」→「現在は」。相手の語を全部なぞると要約ではなくオウム返しに見えるので、理由の核（生産数に限り）だけ拾った
