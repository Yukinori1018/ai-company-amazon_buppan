# 仕入れ先への「振込済み＋発送指示」返信メールの型（2026-10-20 / T-20260930-001 ムカデ博士・アイ・ビー・アール）

## 依頼パターン（再利用可）
卸値で合意 → 請求書が届く → 社長が振込済み、の段階でメーカーに返す1通。ファイル保存は不要で、本文を返答で返す（送信は社長／§4.1）。

## 本文の順序（この順が読み手の処理順）
1. 請求書のお礼＋**請求書No.・伝票No.を本文に書く**（先方が入金消込みで照合できるように）
2. 振込日・金額・**振込名義の差し込み欄**（名義違いで消込みが止まるのが一番の事故）
3. ■見出しで「お届け先」「バーコード」を分ける（先方の出荷担当がそこだけ読めるように）
4. 発送日の連絡依頼＋理由（代行業者への入庫予定連絡）。追跡番号は「可能でしたら」で添える
5. 未回答の質問の再確認は最後に1文。締め

## 判断と理由（次回も同じ判断をする）
- **納品代行宛ての宛名は「〔代行業者指定の宛名〕」として欄を分ける**。代行業者は宛名に当社名や会員番号を入れる指定があることが多く、住所だけでは入庫で迷子になる。
- **バーコードは「貼付不要・通常の荷姿のままで」と書く**。「不要」だけだと先方が別の加工（個別包装など）を気にする余地が残る。
- **販売価格は「出品してよいか」と許可を求めず、「6,050円での出品を予定しております」と伝える形にする**。メーカーが販売価格を指示する流れ（再販売価格の拘束＝独占禁止法で問題になりうる）を当社から招かないため。前回メモ（knowledge_maker_outreach_form_copy.md）と同じ方針。依頼文どおりの「よいか」版も別案として秘書に渡し、選べるようにした。
- 差し込み欄は〔 〕で統一。送信前チェック＝「〔」で検索して0件。公開リポなので住所・電話は文書に書かない。
