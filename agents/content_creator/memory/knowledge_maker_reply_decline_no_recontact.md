# お断りへのお礼：相手が「今後の引き合いは控えて」と書いてきた場合

初出 2026-10-19（T-20260930-001 / 荘快堂のお断りへのお礼）。
親：knowledge_maker_reply_thanks_and_referral.md（Mac 側ブランチ `claude/nighttime-work-checkin-iTWEa` にある。このチェックアウトには無かったので別ファイルにした。マージ時に親の §1 へ統合してよい）。

## 型の差分（5行の型の「将来の一言」を外す）
- 通常の5行：名乗り／お礼／理由の言い換え＋承知／**将来の一言**／結び
- 相手が再接触を断っている場合：**将来の一言を削り、代わりに「相手が手間をかけて説明してくれたこと」への礼を置く**。「お声がけいただけますと」は相手の明言に反するので使わない
- 「今後こちらからのご連絡は控えます」は**入れない方を推奨**（荘快堂で採用）。理由：
  1. 将来の一言を削った時点で、もう再接触の含みは無い。わざわざ宣言すると断られたことを強調し、拗ねた・突き放した印象が出る
  2. **「控えてほしい」の主語を読む**。荘快堂の原文では、その要望は「問屋様 → 荘快堂」へのもの（EC 専業の引き合いを問屋に回さないで、の意）で、当社宛ての要望ではなかった。当社が「控えます」と応じると読み違えに見える
  3. 宣言型（B案）を使うなら範囲を「本件について」「御社へ」に限る。問屋への言及は入れない（どの問屋か当社は知らない）
- 「ご丁寧に／丁寧にご説明」は、相手の返信が**長く理由を尽くしている時は誠実に読める**（短い返信の時だけ皮肉になる。親メモの注意は短文時の話）
- 相手のお詫び（「お詫び申し上げます」）には触れない。「お気になさらず」は上から目線に読める

## 手順（再利用）
1. 原文を段落ごとに読み、各文の**主語**（誰の方針・誰の要望か）を確定する
2. 再接触を断る文言があるか確認 → あれば将来の一言を外す
3. 理由は相手が最も重視した価値（荘快堂＝長年の取引先との関係）を言い換えて「承知」
4. 宛名の法人格は台帳 CSV（04_連絡先_上位50社_公開版.csv 等）の「正式社名」列で確認
5. 件名は Gmail の返信で自動付与の「Re: 元の件名」。元の件名が手元に無ければ〔元の件名〕で残す
6. 検査：禁止語・署名一致・住所電話の実値なし・字数（署名除き150〜250字。今回 A案168字／B案218字）
