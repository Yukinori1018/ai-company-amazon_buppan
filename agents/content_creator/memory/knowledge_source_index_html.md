記録 2026-09-04（T-20260904-004 タスク C-2 / 01_初回仕入れ判定 の再生成）。
[knowledge_judgment_sheet_and_live_csv.md](knowledge_judgment_sheet_and_live_csv.md) の続き。**同じ HTML の3回目の生成**。

## 1. 引き継ぎ回で最初にやるのは「前回のコマンドの復元」

前任（別セッション）は `01` の生成コマンドを**どこにも残していなかった**（`_build_02_maker_list.py` は残っていたのに 01 は無し）。
復元は**成果物の HTML から逆算**した。再現に必要な情報は全部 HTML の中に落ちている。

| 引数 | 復元元 |
|---|---|
| `--box` | `<section class="sec sec-box sec-XXX">` と直後の `<h2>` を全部拾う |
| `--kicker` / `--note` | `<p class="kicker">` / `<p class="prov">` |
| `--cellmark` | `<span class="pill pill-XXX">` の中身を `sort -u` |
| `--title` | `<title>` |

> **一般則: 生成コマンドは成果物と同じフォルダに `_build_<連番>_<名前>.sh` として置く。**
> 今回 `_build_01_judgment_sheet.sh` を deliverables に置いた。次の担当が逆算作業をしないで済む。

## 2. 「本文を改変せずに目立たせる」の手札が1枚増えた — アンカー

依頼は「本文の `[#5]` から出典一覧の該当行へ飛べるように。**文字は足さないこと**」。
`<span class="ref">` を `<a class="ref" href="#src-5">` に変えるだけで満たせる。**見た目を span と完全に同じにするのが肝**
（`text-decoration:none`、色も据え置き。hover でだけアクセント色）。文字数ゼロで機能だけ増える。

- **リンク先が実在する番号だけリンクにする。** 原稿に無い番号にリンクを張ると、押しても何も起きない死んだリンクになる。
  実装は「先に出典表を走査して番号集合を作り、その集合にある `[#n]` だけ `<a>` にする」。今回は 179箇所/88番が 1:1 で全解決
- 飛んだ先が分かるよう `tr:target` に背景と左帯を付けた。`scroll-margin-top` を入れないと行が画面の一番上に張り付く

## 3. 判定語のハイライトは**必ず「セル文頭限定」にする**

「未実施」を「一致」と誤読させないため検証欄をピル化した。素の部分一致で `不一致=danger` とすると、
**別の行の「購買者情報の不一致」に当たって無関係な行が赤くなる**（実際に事故る直前だった）。
`^` を付けたら文頭限定、という指定を実装した。判定語（一致／不一致／部分一致／未実施）は必ずこちらを使う。

**印刷（モノクロ）で色は消える。** 色だけで区別していると印刷した瞬間に「一致」と「未実施」が同じ四角になる。
`muted` は**破線**にして、印刷 CSS でも破線を維持した。**色で分けたら、必ずもう1つ形でも分ける。**

## 4. 6列＋URL の表は「列幅を指定しないと壊れる」

自動列幅は URL 列に幅を持っていかれ、要旨の列が縦1文字帯になった（1行が画面の半分の高さ）。
`<colgroup>` ＋ `table-layout:fixed` で `3em,27%,21%,15%,11%,23%` を指定して解決。
狭幅で列が潰れないよう `min-width:600px` を入れ、溢れは既存の横スクロールコンテナに受けさせた。

**溢れの確認は画像ではなく数値で。**
- 画面: `document.documentElement.scrollWidth == clientWidth`（500 / 900 / 1400px の3点で確認 → ページ溢れ0）
- 印刷: **`@media print{...}` の中身を素の CSS として展開したコピー**を作り、640 / 700 / 794px で
  `table.scrollWidth > container.clientWidth` を確認（`.tw` を `overflow:hidden` にしているので、
  溢れではなく**黙って切れる**。切れは画像では気づけない）

## 5. 環境の罠（時間を溶かした）

- **macOS の bash に `timeout` は無い。** 付けたコマンドは即エラーで落ち、「Chrome が失敗した」と誤診した
- **`--force-dark-mode` は巨大ページで固まる**（2分でタイムアウト）。ダークは `@media (prefers-color-scheme: dark)` を
  展開したコピーで撮る。印刷確認と同じ手が使える
- headless の `--screenshot` は **URL フラグメントでスクロールしない**（真っ白な PNG が出る）。
  特定の行を撮りたいときは、JS で `offsetTop` を測ってから縦長スクショを `sips` で切る

## 6. やらなかったこと（判断として残す）

**出典URLを `<a>` 化しなかった。** 原稿は素のURL文字列で、リンク記法ではない。
アンカーは「依頼で明示的に許可された追加」だが、外部リンク化は**原稿に無いものをHTMLに出す**側に寄る。
