# 20社分の打診文を「送信用シート」まで仕上げる型（方式A）

初出 2026-10-04（T-20260930-001 / 送信キュー上位20社）。
兄弟：[knowledge_maker_first_contact_email_zero_listings.md](knowledge_maker_first_contact_email_zero_listings.md)（量産の骨格・9/21）／[knowledge_maker_outreach_drafts.md](knowledge_maker_outreach_drafts.md)（1社ずつの打診・9/13）。
**今回は「型」ではなく「送れる20通」まで作った回。**作業中に対象が4回入れ替わった（差替2・除外5・補充3・窓口変更多数）。

## 1. 手順（再利用できる形）

1. 前回の文面集（T-20260915-002/14）を土台にし、**新方針（§3.5）との差分だけ**直す。返信後の文面は流用して重複させない
2. PUBLIC 版の型（deliverables/07・【 】プレースホルダ）を正にし、**実値版（53）は 07 からスクリプトで生成**する。手で2つ持つと食い違う
3. 20社分は **辞書（社ごとの窓口・個別文・入力メモ・根拠）＋型のテンプレ＋生成スクリプト（52_build.py）**。対象の入れ替えは辞書の1行で済む。今回4回入れ替わっても破綻しなかったのはこの作りのおかげ
4. フォームは **字数上限を assert で機械判定**（800字・300字）。改行も1字に数える前提
5. 個別文の根拠は**公式ページの事実を1つ**。リサーチャーの取得キャッシュ（51_check/html）を読むのは可（相手の作業には触らない）
6. 3稿は「差し込み後の実物」で読む。**3行目＋個別文＋件名だけを20社並べて読む**と重複が一目で分かる

## 2. 3稿で見つけた重複2種（どちらも型の構造から必ず出る）

| 重複 | 直し方 |
|---|---|
| 3行目「御社の〇〇を仕入れたい」の直後に、個別文で「〇〇を Amazon で拝見しました」（20社中14社） | **個別文では商品名を繰り返さない。**公式で読んだ事実（創業・販路・制度）を足す役に絞る |
| 1行目「Amazon.co.jp で…ネットショップ」の後に「正直に申し上げます。販売先は Amazon です」 | 「正直に」の段落は**相手の懸念を先に言い当てる**1文（「Amazon をご懸念なさるメーカー様が多いことも承知しております」）に置換 |

前回メモ（9/21）の「同じ主張が2回出ていないか専用に1周」がまた効いた。**型＋差し込みの構造では、差し込み欄と型の固定文がぶつかって重複が出る**。差し込み後の実物で読むこと。

## 3. 失敗：画面に出ていない文言を根拠に書いた

自前の本文抽出（タグ除去）で **HTML コメント `<!-- -->` を消していなかった**。エレキットの「取扱店募集」リンクはコメントアウトされていて画面に出ないのに、それを根拠に「取扱店募集のご案内を拝見しました」と書いた。サトルの 51 で判明し差し替え。
→ **本文抽出は `<!--.*?-->` も除く。**「拝見しました」と書く事実は、画面に出ているものだけ。

## 4. 自社の公開物と送り先の食い違いを先に見る

会社概要と /partners に「食品（要冷蔵・冷凍を含む）は取扱いを見合わせ」とあるのに、送信対象20社の半数が健康食品・飲料・茶のメーカーだった。添付した瞬間に「食品を扱わない店が食品メーカーに打診」になる。
→ **打診文を作る前に、自社の会社概要・取引方針ページの「扱わないもの」と送り先のカテゴリを突き合わせる。**解決は社長判断（サイト更新＝外部公開）なので、A/B/C＋推奨で返す。今回は「非食品から第1波、記載修正を並行」を推奨。

## 5. 書き方の決め（理由つき）

- 「販売価格は御社のご指定に従います」→「**希望小売価格を尊重し**」。価格の指定を求める書き方は独禁法の論点（法務10 §5）
- 公式の製品名が取れないとき、**括弧付きの名称を作らない**（「4in1 レトロゲーム」と書きかけた＝公式名に見える偽名）。種類名で呼ぶ
- 流通が特殊な社は1行で型を変える：正規販売代理店制→紹介先を「正規販売代理店様」／過去に卸先を限った記録→先に「現在お受けいただけるか」を尋ね、依頼文の頭に「お受けいただける場合は、」
- 転売禁止を明記している社には、**読んだことを正面から書く**（「承知しております。だからこそ正規のお取引として」）。触れずに送ると読んでいないことが露呈する
- 効能を書かない（健康食品・化粧品）。数字（販売数・出品者数）を書かない。値崩れに触れるのは画面で確認できた社だけ

## 6. フォームの実地で出たもの（次回の入力メモの雛形）

本文300字制限／Webサイト URL 必須（当社 HP を入れる。資産台帳で保有確認）／業種の選択肢に「ネット通販」が無い→「その他」／電話番号必須（日中つながる番号）／種別「正規代理店希望」「販売希望」「卸取引のご希望」を選ぶ／「営業お断り」の注記→冒頭の「仕入れのご相談です。売り込みではございません」が効く。
