## この回の新しい学び
1. **相手が自分の非（「ご迷惑をおかけしており」）を認めている文は、言い換えにも入れない。** 言い換えると、相手が卸先に迷惑をかけた事実を当社が改めて口にすることになる。理由は「商品が重なってしまうことから」と現象だけで受ける。「バッティング」も引かない（相手の言葉をそのまま返すと、要約ではなく指摘に読める）
2. **「既存の取引先への配慮を尊重する一言」は、評価語を使わずに受け止める。** 「ごもっともと存じます」「当然のことと存じます」は相手の判断を当社が採点する形になり、上から目線に読める →「既存の卸先様を大切になさるお考えと受け止めております」を採用
3. **当社も Amazon で売る側なので、共感を示す一文（「重なるご負担はよく分かります」等）は入れない。** 当社が問題の当事者側であることを強調し、弁明に読める
4. 同じ語の反復を避ける：「卸先様」が3回出たので、理由の文は「お取引先様どうし」、尊重の文は「既存の卸先様」と分けた
5. 理由が「条件が変われば再開する話ではない」型なので、荘快堂と同じく将来の一言は外し、代わりに2行目で「ご事情まで丁寧にお知らせいただき」と説明への礼を置いた（返信が長く理由を尽くしているので「丁寧に」は皮肉にならない）
