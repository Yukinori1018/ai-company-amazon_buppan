# お断りへのお礼：相手が「体制が整ったらこちらからお願いする」と約束してきた場合

## この回の判断
1. **将来の一言は「増産の体制が整いましたらお声がけくださるとのお申し出、ありがたく存じます。その節は、どうぞよろしくお願いいたします。」**
   - 近藤酢店の「お声がけいただけますと幸いです」（依頼形）は使わない。相手はもう約束しているので、依頼すると約束を聞いていないように読める。受け取る形（「お申し出、ありがたく存じます」）にする
   - 「増産」は相手の言葉なので返してよい（近藤酢店で不採用にしたのは、相手が言っていない増産を当社が持ち出す形だったから）
   - 「心待ちにしております」「楽しみにお待ちしております」は不採用。増産を急かしているように読める
   - 「整われましたら」は不可（体制という物事に尊敬語は付けない）
   - 当社から再度連絡する予告は入れない（声をかけるのは先方）
2. **「願ってもないお話」への受けは「過分なお言葉まで頂戴し」で1句だけ**（近藤酢店と同じ）。「」で引用すると、当社の提案を当社が褒め直す形になる
3. **「生産能力も限界に近い」は「生産のご状況から、現在は新しいお取引が難しいとのこと」と言い換える。** 「限界」をそのまま返すと、相手の苦しい事情を当社が口にすることになる。「ご都合」は言い訳扱いに読めるので不採用
4. 相手のお詫び（「誠に勝手ではございますが」「ご容赦賜りたく」「メールにて恐縮ですが」）には触れない。「お気になさらず」は上から目線（荘快堂メモと同じ）
5. Amazon・楽天での既存販売には触れない（当社も Amazon で売る側。播磨園製茶メモと同じ理由）
6. 「お言葉」が2回出たので、将来の一言は「お申し出」に替えた
