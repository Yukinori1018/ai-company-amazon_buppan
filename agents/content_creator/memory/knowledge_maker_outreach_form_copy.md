# メーカー打診：消費者向けフォームから取引相談を送る文面の型（2026-10-16 / T-20261016-001）

## 依頼パターン（再利用可）
メーカーに卸・取引の窓口がなく、公式の窓口が「購入品の問い合わせフォーム」と「お客様相談室の電話」しかない場合に、フォームの文面と電話スクリプトを作る。

## 手順
1. リサーチャーの窓口調査を読み、フォームの欄・必須かどうか・お断り表示の有無を確認する。
2. 法務の打診ルール `deliverables/T-20260904-004/B1L_営業お断り表示への打診可否_法務判定.md` §3-4 を読む（URLを貼らない／身元を明かす／実績を誇張しない／1社1通）。
3. 欄ごとの書き方の表を作る。購入日のように書く内容がない必須欄は「自由記入／日付だけ／空欄可」の3通りで書き方を用意する。日付しか入らない場合は送信日を入れ、本文の末尾に注記を1行足す。
4. 本文は「何の連絡か → 窓口違いのおわびと案内のお願い → 自己紹介 → 希望（箇条書き2行）→ 相手の方針に沿うという一言 → 署名」の順。500字前後。
5. 電話は「何の電話かを2文で言う → お願いは窓口を聞く1つだけ」。断られたらすぐ終える。

## 依頼文と違う書き方にした点（次回も同じ判断をする）
- **「Amazonで玩具等を販売する事業者」→「販売に向けて仕入れ先を探している。販売実績はまだない」**。社内の販売実績はゼロ（handover.md）。法務ルールで誇張は禁止。秘書の依頼文でも、事実と食い違う自己紹介は直してから理由を添えて返す。
- **「販売価格の方針に沿う」とは書かない**。再販売価格の拘束（独占禁止法）を連想させる。代わりに「ブランドや商品の取り扱いに関するご方針」と書く。
- 「売り込みではなく」より「**購入品の問い合わせではなく**」。消費者向けの窓口では、受け手の誤解（クレームだと思われる）に合わせた打ち消しのほうが効く。
- ASIN は本文に書かない（メーカーの担当者には通じない）。台帳の数字が JAN コードかどうか確かめられないときは品番の欄は空欄にする。
