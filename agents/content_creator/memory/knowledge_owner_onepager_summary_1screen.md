## 今回うまくいった最大の理由：依頼側が内容を確定していた

過去2回は「分量指定と内容指定が衝突」して未達を出した。今回は秘書が**載せる内容を5ブロックに確定し「足すな・収まらなければ注釈から削れ」**まで指定してきた。
→ **要約の依頼を受けたら、着手前に「載せるもののリスト」を先に合意する。**文章を短くする作業ではなく、**ブロックを選ぶ作業**なので、選ぶ権限が無いと分量は守れない。

## 分量の実績（次回の見積りの基準値）

| ブロック | 実測 |
|---|---|
| ヘッダ（kicker＋h1＋lead） | 約200px |
| 結論節（KPIカード3枚＋2枚＋1文・囲み枠） | 約330px |
| 6行の表＋見出し＋補足1行 | 約430px |
| 箇条書き5行＋見出し | 約290px |
| A/B/C 表（3行）＋見出し＋前振り1行 | 約330px |
| 注釈5行（囲み枠） | 約330px |

**目次を消すと約200px 減る**（h2 5本のとき）。1画面ものでは目次は要らない — 結論がファーストビューから押し出される方が害が大きい。

## 変換器に足した2つ（md が唯一の正という原則は維持）

- **`--no-toc`** — 目次を出さない。短い資料用。
- **`--kpi "h2見出し"`** — その節の**「1行だけの表」をKPIカード**（ラベル小＋数字32px）にする。md では普通の表なので、テキスト版も壊れない。
  - 2行以上ある表はカードにしない（対応が読めなくなる）。同じ節に1行表が複数あれば全部カードになる（3枚＋2枚の2段組ができる）。
  - **ラベルにも `--cellmark` が効く**ようにした。`| 月営業利益 中央　仮置き |` で「仮置き」だけ破線ピルになる。社長の「数字には仮置きラベル」要求はこれで満たす。
  - カードは `flex:1 1 150px`。**値は4〜5文字まで**（「108万円」で限界）。長い値を入れると 32px の数字が折り返して不格好になる。

## 踏んだ罠

- **`--colwidths` で列幅を絞ると、`thead th` は nowrap なので見出し文字が隣の列に重なる。**「2028-09 月利 中央（上位20%）」が隣と重なった。**対策は列を分けること**（中央／上位20% の2列に割り、日付は h2 見出しへ逃がす）。文字を小さくする方向で直さない。
- headless Chrome は1本ずつ。**並行させると全部固まる。**固まった時に `pkill` すると**走っている別ジョブも道連れ**で exit 144 になる（今回4回）。1回の起動に1〜3分かかる前提で、**起動 → ファイルができるまで until で待つ → 次**の直列運用にする。

## 数字の扱い（社長提出物の共通ルール）

- **合計と内訳が別走なら、足しても合わない。**今回も合計61万に対し内訳の和は約52万。**隠さず注釈に1行**（「合計と内訳は別走の計算なので、足し上げても小数まで一致しません」）。
- 内訳は**検証（04）§9 の差し替え後の値だけ**を使う。依頼文に例示された数字（①50万）が**差し戻し前の値**であることがある。**例示より原典。**

## 印刷（A4）

2ページに収まり、表の横溢れなし。**KPIカードは印刷だと「仮置き」ピルが1行を食って数字が下に落ちる**（画面では同じ行に収まる）。読めるので直していないが、印刷前提の資料ではラベルにピルを入れない方がきれいになる。
